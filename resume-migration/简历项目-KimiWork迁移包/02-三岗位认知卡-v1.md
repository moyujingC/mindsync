## 认知卡一：AI 应用工程师 / 大模型应用工程师

1. **岗位本质**：让 AI 应用在真实环境里稳定产生价值。不是"会调 API"，而是能交付可靠的系统。
2. **能力主张（按重要性排序）**：
   - ① AI 原生开发全流程：需求拆解 → 规格 → AI 生成引导 → 代码审查 → 调试 → 部署排障
   - ② 模型评测与选型判断（视觉/文字模型、评测集、降级策略）
   - ③ 工程质量意识（CI/CD、测试、发布流、运维自动化）
   - ④ 快速进入陌生领域并产出（学习力）
3. **招聘方的雷**：手写代码能力（18 年经验但语言断档）→ 不回避，正面框定为"AI 原生开发方式"；只投自己也在用 AI coding 的团队，这类团队 2026 年正在快速变多。
4. **差异化优势**：2200+ 提交的系统实证、真实上线且可访问的产品、方法论来自真实失败（v1 报废）、懂业务懂客户（纯工程师没有）。
5. **不争**：算法/模型训练深度、大厂工程背书、现场手写算法题。
6. **证据映射**：
   - ① ← v1 报废 → SDD/Harness 重建；MindSync 六阶段门
   - ② ← 双模型选型决策（DeepSeek V4 + qwen-vl-max、评测淘汰、降级策略）
   - ③ ← 维塔士/笑游 CI/CD 历史 + 三服务器 + nightly smoke/auto-repair + 5 个测试类 PR
   - ④ ← 疗愈领域 0→1（知识库三次重构 + 产品上线）

## 认知卡二：FDE / AI 解决方案工程师

1. **岗位本质**：连接客户问题、技术方案和交付结果的人。进入客户的真实业务现场，把"想用 AI"翻译成可试点、可验收的方案，并对落地结果负责。（崔兴原话改写）
2. **能力主张（按重要性排序）**：
   - ① 高信任场景的需求诊断：从访谈中识别真实目标、约束、风险（不是问"你要什么"）
   - ② 非标准化业务 → 标准化交付的翻译能力（SOP、知识库、验收口径）
   - ③ 方案设计与边界管理：能承诺什么、不能承诺什么
   - ④ 技术可行性判断（懂 AI 能力边界，不卖空中楼阁）
3. **招聘方的雷**：没有大厂/知名企业 AI 交付案例 → 正面框定：FDE 的核心是"进入陌生业务的能力"，房产 5 年就是 150+ 次"进入陌生客户业务"的交付；AI 侧有自己的产品和系统做技术背书，且明确不夸大（本人原则：不包装未成交的服务）。
4. **差异化优势**：技术 + 高信任咨询 + 创业闭环的三重组合在市场上几乎没有竞争者；自己就是"一人公司 AI 落地"的活案例；孵化出年成交 2 亿的经纪人证明方法论可复制。
5. **不争**：大厂项目履历、纯技术深度、英文交付（外企 FDE 岗除外）。
6. **证据映射**：
   - ① ← 房产客户访谈→定制方案（150+ 客户、70% 转介绍）；保险需求诊断
   - ② ← SOP/知识库/培训体系（上岗周期 18→6 个月；孵化 30+ 经纪人）
   - ③ ← 委托协议与法务打磨"能承诺/不能承诺"；AI 产品安全边界设计（曼曼拦截）
   - ④ ← 模型选型、两段式链路、上线产品；v1→v2 的工程判断

## 认知卡三：AI 产品经理（中小团队 / 产品负责人方向）

1. **岗位本质**：在资源受限的小团队里，从真实问题定义产品，并推动它从 0 到 1 上线。不是写 PRD 的岗位，是"对产品结果负责"的岗位。
2. **能力主张（按重要性排序）**：
   - ① 从真实场景定义产品的能力（需求不是脑补的，来自一线服务）
   - ② 产品判断与取舍（范围、分层、定价、什么不做）
   - ③ AI 输出的产品化：质量标准、评测、边界（AI PM 区别于传统 PM 的核心）
   - ④ 端到端推动能力（一个人走完需求→上线全流程，小团队最缺这个）
3. **招聘方的雷**：没有公司内的产品经理 title → 正面框定：只投"需要能独立交付的产品负责人"的中小团队/创业公司，不投大厂分工型产品岗；产品本身就是最好的作品集（可现场演示）。
4. **差异化优势**：懂技术（9 年研发）+ 懂业务（7 年高信任服务）+ 有审美（疗愈师反馈 UI 有调性）+ 自己就是目标用户（曼陀罗产品源于自己的服务场景）。
5. **不争**：大厂产品方法论（AARRR 八股）、管理过产品团队、数据驱动的增长案例。
6. **证据映射**：
   - ① ← 产品源于自己 100+ 小时个案的真实痛点；用户分层与四类动机决策
   - ② ← Lite/Pro 分层与定价逻辑；Pro 仅升级不独立售卖；五类产品矩阵决策；卡牌项目"上线前叫停"
   - ③ ← 两段式链路设计、golden case 评测集、安全边界协议
   - ④ ← 需求→设计→开发→部署→试用全流程独立完成；小红书早期变现
