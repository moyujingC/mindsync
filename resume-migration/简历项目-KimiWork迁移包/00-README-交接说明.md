## 二、方法论（已确认，不要回退）

**自上而下的写法，分两步：**
1. 先为每个岗位建立"内心 JD"（岗位认知卡）：这个岗位要证明什么能力、招聘方担心什么雷、差异化优势是什么、明确不争什么。
2. 再从经历中提炼与认知卡匹配的证据写入简历，**每条带真实数据**，每条过 "so what" 检验。

**明确否决的做法：** 自下而上堆事实（"过于具体、不够抽象"）；任何失真或无法在面试中辩护的表述（"宁可后期做叙事提炼，也不要先失真；失败经历不可怕，失真经历才危险"）。
