# QA 清单（逐张过）

1. 尺寸：`sips -g pixelWidth -g pixelHeight` = 2160×2880（1080×1440 @2x）。
2. 渲染脚本溢出告警必须为 0（内容底边距页脚带 ≥12px）。
3. 标题宋体渲染成功（非回退黑体）：巨字有宋体衬线特征。
4. 页码三方一致：页眉右 `NN / NN`、文件名编号、卡组顺序。
5. 左条颜色与卡组约定一致（交替/封面定色）。
6. 步骤卡：有且仅有一个 `.note`，note ≤2 行；条目 3~4 个。
7. 总览卡：有 `.kicker` + `.title-ul`；条目均布无堆底（末条目底边距页脚 ≥12px）。
8. 无 inline style、无组件外 class。
9. 画布密度 ≥75%；中段不出现 >15% 画布的纯空白带（总览卡均布后自然满足）。
10. 文案无编造数据/案例；品牌名为一镜一书体系，无参考稿残留字样。
