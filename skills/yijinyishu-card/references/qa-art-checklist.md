# 插画拼贴风 QA 清单（逐张过）

1. 尺寸：竖版 sips = 2160×2880；横版 sips = 2160×1216。
2. 渲染脚本无「图片缺失」「溢出风险」告警。
3. 插画中无任何文字/字母/数字/水印/logo（生图硬规则）。
4. 主图取景合理（人物/主体不被遮罩切掉关键部分）；不满意用 `img_focus` 调或重生。
5. 标题宋体渲染成功（衬线特征明显）；徽章文字 ≤5 字、居中。
6. para ≤2 行；sub 一行；整套卡组徽章配色轮换规律一致。
7. 水印为「轻疗愈」，无参考稿（读完以后/俞心行等）残留字样。
8. 小圆图与主图色调协调（同 prompt 风格前缀保证）；m2/m3 缺省时无空白占位残留。
9. 平台选对：小红书/图文用 portrait，公众号配图用 landscape。
