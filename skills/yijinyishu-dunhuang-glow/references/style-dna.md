# 敦煌柔光风 · 风格 DNA

## 0. 第一性原理：温柔的光影 > 一切

这套风格存在的理由是"有光影的温柔"（用户原话）。任何决策冲突时，柔光、安静、留白优先。
反面教材 = 元素全堆（飞天+藻井+金蝶+飘带+粒子+商队同框）、金色饱和拉满、对比过硬——成品"又脏又乱"。

## 1. 色板（低饱和是铁律）

| 角色 | hex | 用法 |
|---|---|---|
| 夜空主色 | `#1E2D4D` → `#253860` | 平滑垂直渐变，占画面 50%+，渐变内无纹理 |
| 月光/亮部 | `#F5EFE2` / `#F0E3CF` | 柔光晕、沙丘受光面、月牙 |
| 鎏金点缀 | `#D4A054` / `#E0B46A` | 只做微光/轮廓光， Champagne 金，不橙不黄爆 |
| 赭红 | `#C87850` | 微量 rare accent，不出现在大面积 |
| 玉绿 | 梳子本体 | 唯一允许的中等饱和色（品牌资产） |

绝对禁止：青黑（cyan-black）、橙色 blowout、高饱和金、荧光感。

## 2. 光影

- 漫射月光 + 细腻 bloom，明暗结构明确但过渡平滑（见第 6 节：温柔不等于灰，暗部压得住、高光亮得出）。
- 星星：寥寥几颗、小、暗；光尘：稀疏。
- 光源 ≤ 2 个（通常月牙 + 主体自身辉光）。

## 3. 构图铁律

1. **单一主体**居中或三分点，占画面 ≤ 25%。
2. **辅助元素 ≤ 2 个**（金蝶 2-3 只算 1 个、驼队剪影算 1 个、单条飘带算 1 个）。
3. **大留白**：干净平滑的天空占画面一半以上，无云无星带。
4. 元素之间不触碰、不重叠、不顶边。
5. 沙丘只作底部安静的前景带，纹理柔和。

## 4. 母题库（每次最多取 2）

玉梳+圆镜（品牌第一母题，可单出）——**形象锁定**：必须用 `--comb` 模式以 `references/comb-logo.png` 为锚图生图，葫芦形玉身/圆镜金框/朱红花心/蓝珐琅云纹/金线梳齿一律原样，prompt 不得重设计梳子；纯文字模式禁出梳子｜月牙｜金蝶（≤3）｜驼队剪影（远景、小）｜飞天（单条简单飘带，非群舞）｜单朵金莲｜鎏金藻井圆盘（作唯一主体时才用，纹样要简）｜经卷｜星河（淡淡的，不抢）

## 5. 质感

柔和笔触感厚涂、边缘虚柔、梦幻薄雾；**拒绝**密集卷草纹、满屏 filigree、复杂装饰面。

## 6. 影调结构（v3 修订，最高优先级）

温柔不等于灰。"有光影的温柔"= **明确的明暗结构**：

- 最暗部必须压得住：深靛 `#141E38` 丝绒感，**绝不发灰、绝不提亮**；禁雾/霾把黑色抬起来。
- 最亮部必须亮得出来：高光 `#F8E8B8` 真发光，主体在深夜空中有明确辉光对比。
- 中间调平滑过渡，但整体**禁止灰蒙蒙**（gray haze / washed-out mid-tones）。
- 对应生成器 STYLE 常量 v3.1；改动需回归全系列套图。

## 7. 飞天与飘带（v3.1 修订）

- 飞天 = **平面装饰性敦煌壁画美学**：身体与衣带由流动丝带构成，线条修长优雅，轻盈 2D 绘画感。
- **绝对禁止 3D**：不是泥塑、不是雕塑、不是人偶，无塑料质感 shading、无厚重渲染身体。
- **飘带/衣物暖单色铁律**：只允许 ivory / cream / pale champagne gold / soft warm white，最多一根极淡赭红线；**禁止彩虹飘带**，禁止蓝、青、绿、紫、粉出现在衣物飘带上。
- 纯丝带场景（无人物）同理：丝带留在金系暖单色家族内。

## 8. v4.2 定版（2026-10-03，用户四轮反馈收敛）

- **渲染语言**：半扁平柔和绘画感 + 适度细节（法器莲瓣环+细金线+小宝石点；飘带褶皱+金边）。禁 CG 写实（v4 太杂）、禁纯剪影（v4.1 太简）。
- **必须有真实发光体**：金色法器/月亮为发光核心，bloom 光晕 + 适量四点星芒 + 金尘（深色版）。
- **暗部** = 群青/靛紫有色相（#10143A/#2A1F52），暖金=亮核+香槟中间调+深金边三层。
- **飘带** = 高明度带多色（蛋白石感：香槟/象牙/玉青 #9FD8C8/蜜桃/藕粉），统一罩暖光，彩色只上受光侧。
- **构图** = 竖版 2:3，法器唯一精神焦点，飞天视线+飘带+地面光带闭环引导驼队指向法器，大块纯净留白压字，全画面 ≤5-6 元素。

## 9. 浅色版配方（v4.2-light，场景句级收口，不动全局 STYLE）

深色版的星光装饰在亮底上会变成"闪/花哨"，浅色版必须：
- 哑光柔光：NO star sparkles / NO glitter / NO dust motes / no shiny effects；鎏金感靠漫射暖光不靠闪光粒子。
- 法器纹样再简一层（莲瓣环+少量金线即可）。
- 飘带配色反而要**更丰富**（亮底易单调）：象牙/香槟为底 + 玉绿腰封为点睛 + 玉青/藕粉/蜜桃/蓝绿飘带。
- 沙丘/云都要安静哑光；蝴蝶 ≤1。
