# 卡片版式配方（layout recipes）

每配方 = 标题类型 + 组件组合 + 最小密度要求。content 字段只拼这些组件。

## 信息结构 → 版式映射（分块前先定结构）

| 信息结构 | 识别特征 | 版式 |
| --- | --- | --- |
| 单一问题+论据 | 一个论点 + 若干支撑点 | R1 / R5 |
| 步骤 / 时间线 | Day 0→N、①②③ 流程 | R2 |
| 方向 / 案例对比 | A/B 两方案、结果说明 | R3 |
| 双向判断 | 适合 / 不适合、是 / 不是 | R4 |
| 递进层级 | 五段模型、成熟度、金字塔 | R6 阶梯卡 |
| 自测 / 判定 | 逐问判定、是/否分支 | R7 判定条卡 |
| 数字亮点 | 单个关键数字撑一个论点 | R8 大数字卡 |
| 对话体 | 客户说 X / 你答 Y | R9 对话卡 |

禁止无差别套 R1——结构本身的特点（递进、对比、判定）必须用对应版式表达出来。

## R1 问答-列表卡（最常用）
问句 title + `.lead`（一句论断）+ `ul.blist`（5~8 条）+ `.banner`。
适用：「企业需要配合什么」「数据会不会泄露」式 FAQ。
最小密度：内容 ≥75% 画布高；列表 ≥5 条。

## R2 问答-编号项卡
问句 title + `.lead-sm`（背景说明）+ 3~5 个 `.num-item`（① 加粗引导 + 灰说明）+ `.banner`。
适用：流程/时间线（Day 0 → Day 2）、步骤（①确认目标 ②观察现场）。
最小密度：num-item ≥3 或 lead-sm + banner 必存其一。

## R3 标签-段落卡
title + `.lead` + 2~4 组 `.kicker` + `.kicker-text`（RESULT 01 / DIRECTION A 式）。
适用：结果说明、方向对比、案例拆解。
最小密度：kicker 组 ≥2。

## R4 分组对比卡
title + `.lead` + `.group-label`（适合/不适合、你们是/你们不是）+ 两组 `ul.blist`。
适用：双向判断题。两组列表条数差 ≤2。

## R5 封面宣言卡
（模板外扩展：title 置顶 + 巨型断句 + 一句 lead；可用 theme 差异与内容卡区分。）
宣言句分行要有呼吸，禁止塞满；底部放账号身份行。
最小密度：title-xl 之外 ≥2 个内容层（lead / blist / banner 组合）；禁止「巨题 + 单句 lead」交差——下半屏会空，按 QA 清单密度项打回。

## 收尾金句卡
单 `.lead` 或单 `.banner` + 页脚；画布欠填时用字号和留白承担，不补装饰。

## R6 阶梯卡（递进层级）
问句 title + `.lead`（一句定性）+ `.ladder` 3~5 阶（每阶：no 序号 + t 32/800 阶名 + d 27 灰一句）+ 可选 `.banner`。
适用：段位模型、能力成熟度、从易到难一切「一阶比一阶重」的内容。
最小密度：阶梯 ≥3 阶；序号语义只能是「递进」，并列关系禁用（并列用 blist）。

## R7 判定条卡（自测/分支）
问句 title + `.lead-sm`（判定规则一句）+ `.judge` 4~6 行（q 问题 + v 判定结果）+ `.banner`。
适用：自测表、决策分支、「符合 A 走 X，否则往下」式内容。
最小密度：judge ≥4 行；v 列必须短（≤6 字），长结论放 d 或 banner。

## R8 大数字卡（数字亮点）
问句 title + `.lead` + `.bignum` 1~2 个（n 150/800 数字 + d 30 灰注解一句）+ 可选 `.banner`。
适用：关键指标、对比数字、案例数据点。禁止编造数字（沿用禁忌）。
最小密度：bignum ≥1；d 注解 ≤2 行。

## R9 对话卡（客户/专家问答）
问句 title + `.lead-sm` + `.qa` 2~3 组（qq 客户原话引述 + aa 你的判读/接法）+ `.banner`。
适用：访谈体、真实客户问答、「这句话是第几段」式判读。
最小密度：qa ≥2 组；qq 必须是引述体（「」包裹的原话感）。
