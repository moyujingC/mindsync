# Prompt 手册 · 水彩拼贴风

生成器 `scripts/generate.mjs` 自动拼接：

```
{STYLE 风格前缀}\n\n画面内容：{你的 prompt}\n\n画幅：{横版|竖版}，主体居中偏{右|中}，构图适配 {size}。
```

STYLE 前缀已含：水彩拼贴媒介、四个 hex 主色、米色纸底、晕染/撕纸/枝叶质感、禁文字。
所以你的 prompt **只写画面内容**：谁、在哪、做什么、周围有什么、什么光线。

## 构图模板

### A. 满版大图（hero 卡配图，加 `--bleed`）

骨架：`整幅画面充满构图、不留边框：中央{主场景人物+动作+神情}；四周环绕{n}幅圆形撕纸小图——{意象1}、{意象2}、{意象3}；小图与大图之间以撕纸拼贴和水彩斑块自然衔接，米色纸底从撕纸缝隙中露出，背景{远山/晨光等}`

实例（已验证出图）：

> 整幅画面从头到脚充满构图、不留边框：中央一位年轻女性在窗边软椅上抱着笔记本涂鸦曼陀罗图案，神情平和；她的四周环绕四幅圆形撕纸小图——月亮与床的睡眠场景、丰盛的健康餐盘、草地上做瑜伽的人、听诊器与体检单；小图与大图之间以撕纸拼贴和水彩斑块自然衔接，深蓝、赭石、灰绿配色，米色纸底局部从撕纸缝隙中露出，背景远山晨光

要点：中央大图 + 3~4 个小图意象最稳；小图意象与卡片条目一一对应，全图叙事。
注意：撕纸边最终由排版层 SVG mask 再撕一次，图中自带的撕纸衔接是「画中画」层次，两者不冲突。

### B. 单场景图（拼贴布局主图/小圆图）

骨架：`{视角，可省}：{主体}{动作}{随身物件}，{环境}，{光线/天色}；{情绪词}`

实例：

- 主图：`一位年轻女性坐在窗边软椅上，抱着笔记本随手涂鸦曼陀罗图案，手边一杯热茶，窗外是柔和的远山与晨光；人物姿态放松安静，神情平和`
- 小圆图：`俯拍视角：双手用彩色铅笔在纸上画一个圆形曼陀罗图案，桌上散落几支笔与一杯茶，温暖安静`
- 小圆图：`一个人盘腿坐在草地上闭眼呼吸练习，胸口处画着柔和的光芒，背景是淡淡的山与树`

要点：一张图只讲一个场景；主图人物 + 小图意象（物件/动作）；横版主图人物放右侧、左侧留出空间（文字栏在左）。

## 翻车模式 → 修法

| 现象 | 修法 |
| --- | --- |
| 图中出现文字/字母/假字 | 缩短 prompt（长 prompt 诱发模型「补完」文字）；确认 STYLE 禁则生效；重抽 |
| 配色跑偏（出现荧光色/大面积粉紫） | prompt 里点名 `深蓝、赭石、灰绿配色`；删掉冲突色描述词 |
| hero 图四边留白边 | 确认加了 `--bleed`；prompt 首句写明「整幅画面充满构图、不留边框」 |
| 圆图裁切切掉主体 | 主体居中、远离四边；重生成时用 `img_focus`（排版层）微调取景 |
| 画面太满、没有留白 | 删元素；加「留白充足」「背景简洁」 |
| 风格滑向二次元/照片 | 重申 `手绘水彩拼贴插画、编辑插画风格`；避免「精致」「高清」「真实」类词 |
| 人物五官怪异 | 改为中景/背影/侧影；弱化面部描述，强化姿态与场景 |

## 一套卡的工作分配（与 yijinyishu-card 配合）

- hero 版式：1 张满版大图（--bleed, portrait）。
- collage 版式：1 张主图（portrait 或 landscape 按画幅）+ 1~3 张小圆图（portrait 即可，排版层圆形裁切）。
- 同套图共用一个主题意象池（如「曼陀罗涂鸦」贯穿主图与小图），色调由同一 STYLE 前缀保证。
