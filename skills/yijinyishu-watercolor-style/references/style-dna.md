# 风格 DNA · 一镜一梳水彩拼贴风

从「俞心行疗愈学院 / 读完以后」系列参考稿取样，供生图 prompt 与人工核对共用。

## 媒介与质感

- 媒介：手绘水彩拼贴插画（watercolor collage illustration），编辑插画（editorial）气质，不是儿童画、不是二次元、不是照片写实。
- 纸感：米色水彩纸底带细纹理；色块有晕染、沉淀、干笔痕。
- 拼贴：不同场景像撕下的纸片拼在一起，撕纸边缘毛糙、露出纸底；片与片之间可用水彩斑块自然衔接。
- 点缀：少量植物枝叶（鼠尾草绿）、小浆果、小太阳圆点；点到为止，不堆满。

## 配色（写 prompt 时带 hex，防跑偏）

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 纸底 | `#f7f2e7` | 画布底色，从撕纸缝隙/边缘露出 |
| 深蓝 | `#1f3d6b` | 主色之一：衣物、水面、夜空、阴影 |
| 赭石 | `#b8623c` | 主色之一：暖阳、陶土、果实、强调物 |
| 灰绿 | `#6c7f5c` | 主色之一：植物、远山、灰调绿 |
| 辅助绿 | `#43684a` | 深一点的绿，层次用 |

套图内三色轮动，单张图 1~2 个主色 + 纸底即可，避免彩虹化。

## 光影与情绪

- 光线：柔和自然光、暖晨光/夕照；无强烈对比、无霓虹、无夜景高光。
- 情绪：温暖、安静、被照顾感；人物神情平和、动作放松。
- 密度：留白充足，宁可空不要满；画面干净。

## 人物

- 普通年轻女性/中性人物为主，日常姿态（坐、走、画、抱膝、伸展）。
- 不追求五官特写精致度，重姿态与氛围；避免性感化、避免夸张表情。

## 画幅与构图

| 画幅 | 尺寸 | 用途 |
| --- | --- | --- |
| portrait（竖） | 1024×1536 | 3:4 卡片（小红书/公众号图文/贴图） |
| landscape（横） | 1536×1024 | 16:9 公众号正文配图 |

## 平台尺寸口径（发布前按这张表选画幅）

| 平台/形态 | 比例 | 生图尺寸（generate.mjs） | 卡片导出（yijinyishu-card，@2x） |
| --- | --- | --- | --- |
| 小红书图文（图集） | 3:4 | portrait 1024×1536 | 1080×1440（2160×2880） |
| 公众号图文（文内竖图） | 3:4 | portrait 1024×1536 | 1080×1440（2160×2880） |
| 公众号贴图号（小绿书/图片消息） | 3:4 | portrait 1024×1536 | 1080×1440（2160×2880） |
| 公众号正文配图 | 16:9 | landscape 1536×1024 | 1080×608（2160×1216） |

- 竖版三形态共用一条生产线，一套竖卡三个平台都能发。
- 横版只用于公众号文章正文内的配图，不生小红书。
- 生图尺寸是模型输出（不直接发布），导出尺寸由排版层模板决定，别混用。

两类构图：

1. **满版大图（--bleed）**：整幅画面充满、元素延伸到四边；多个场景意象以撕纸拼贴/水彩斑块衔接成一幅；适合「一张卡一个主题」的 hero 配图。
2. **单场景图**：一个主体场景，主体居中偏中上、四周留呼吸空间；适合拼贴布局的主图（拱形裁切）与小圆图（圆形裁切）。小图各取一个独立意象（物件/动作/小场景）。

## 硬禁令

- 图中不出现任何文字、字母、数字、水印、logo（含手写体假字）。文字 100% 由 HTML 模板渲染。
- 不画边框、不画相框、不画明信片样式外框（拼贴纸片之间的撕裂边除外）。
- 圆形/拱形裁切由排版层 mask 处理，所以单场景图主体必须居中、远离四边。
