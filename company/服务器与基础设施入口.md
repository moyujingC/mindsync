这份文档是 `墨予镜` 公司层面的基础设施入口。

它的职责不是取代项目级 runbook，而是提供一个稳定的总入口，让任何 Agent 在需要登录服务器、核对运行时宿主机、定位 runner / Paperclip / 部署节点时，先知道应该去哪里找、先连哪台机器。

具体服务细节、环境变量、部署命令与验收口径，仍以对应项目的项目级运维文档为准。

## 1. 使用原则

1. 先在这里确认“是哪一类机器、属于哪个项目、主入口文档是哪份”
2. 再进入对应项目 runbook 执行登录、部署、排障或验证
3. 不要把真实服务器信息只留在聊天记录、shell 历史或临时笔记里
4. 当服务器地址、登录方式、宿主角色发生变化时，应同时更新这里和对应项目 runbook

## 3. 文档边界

- 公司层：
  - 维护“有哪些机器、属于谁、怎么登录、主入口文档在哪”
- 项目层：
  - 维护服务职责、目录、systemd、env、部署、排障与验收细节

## 4. 当前治理要求

1. 新增服务器时，必须先把入口补到本文件，再补项目 runbook
2. 真实 SSH 入口不得只写成 `<host>` 占位符
3. 如果某台机器使用专属 SSH key，应在公司层入口明确写出 key 路径
4. 如果某台机器同时有公网入口和 Tailscale 入口，应两者都记录，但标明推荐口径
