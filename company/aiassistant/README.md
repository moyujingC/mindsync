# AI Assistant 目录

> 状态：`current`

> last_updated：`2026-05-07`

`aiassistant` 是 `MindSync` 中承载私人执行助理、自动复盘、知识沉淀与内容转译的公司级目录。

## 1. 目录职责

- 承接 AI 自动生成的每日 / 每周复盘
- 承接用户主导的 Research Knowledge 沉淀入口
- 承接内容矩阵的二次转译入口
- 承接未来更自动化的助手能力扩展

## 2. 目录结构

- [modules/](./modules/README.md)
  - 模块定义与边界
- [automations/](./automations/README.md)
  - 自动运行任务与调度说明
- [outputs/](./outputs/README.md)
  - 自动生成的复盘与阶段性输出

## 3. 当前约束

- `Research Knowledge` 仍以用户主动讨论为主
- 自动复盘默认留在 `aiassistant` 工作流内
- 内容矩阵只接收转译后的结果，不直接接原始复盘
