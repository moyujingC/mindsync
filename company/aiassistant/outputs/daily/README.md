这一层存放私人执行助理按日期沉淀的每日日志。

## 记录规则

- 文件按日期命名，例如 `2026-05-07.md`
- 每日自动复盘默认写入当天文档
- 同一天在 Codex 窗口继续讨论计划、执行反馈或调整事项时，优先追加到当天文档
- 这里是私人执行助理输出，不默认写入 Research Knowledge
- 临时工作区状态、未提交文件等不作为日志正文记录，除非用户明确要求保留
