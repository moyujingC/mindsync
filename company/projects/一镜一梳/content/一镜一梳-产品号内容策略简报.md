# 一镜一梳产品号内容策略简报

> 项目：一镜一梳
> 归档项目：一镜一梳
> 目标账号：一镜一梳
> 版本：v1.0
> 日期：2026-04-08
> 适用阶段：启号阶段

> 说明：本文件只服务 `一镜一梳` 产品号，重点是用户教育、价值建立、产品认知与阶段进展同步，不承载 `墨予镜` 个人第一人称表达。

## 1. 账号定位与目标

- 核心定位：面向自我理解、轻疗愈与曼陀罗体验人群的产品号
- 核心目标：建立“什么是一镜一梳、它能帮助谁、为什么值得尝试”的基础认知
- 当前阶段目标：先把账号启起来，连续输出可信内容，让用户知道我们不是泛玄学号，也不是纯营销号

## 2. 目标受众

- 对曼陀罗绘画、自我理解与情绪觉察感兴趣的人
- 希望通过轻量方式开始心理自我探索的人
- 对疗愈类产品感兴趣，但对“神神叨叨”表达保持警惕的人
- 想先了解方法与产品，再决定是否体验的人

## 3. 当前适合写什么

启号阶段优先写下面四类内容：

1. 用户教育
   - 什么是曼陀罗绘画
   - 曼陀罗解读适合解决什么问题，不适合解决什么问题
2. 方法理解
   - 为什么一张画可以成为自我理解入口
   - `一镜 Lite 版` 和 `一梳 Pro 版` 分别在做什么
3. 产品认知
   - 产品当前主路径是什么
   - 为什么先做手机端 Web
   - 为什么强调结构化报告而不是模糊安慰
4. 阶段进展
   - 当前推进到了哪
   - 哪些能力已明确，哪些还在验证

## 4. 当前不适合写什么

- 把产品号做成纯 build in public 账号
- 夸大疗愈效果或做医学、诊断式承诺
- 把还未正式确认的功能写成既成事实
- 过早讲过多价格促销与转化话术
- 把个人经历和个人表达挪成产品号主视角

## 5. 内容结构配比

启号前四周建议采用下面的配比：

- `50%` 用户教育与方法理解
- `30%` 产品认知与差异说明
- `20%` 阶段进展与轻量 build in public

## 6. 语气与表达要求

- 温和，但不悬浮
- 专业，但不装懂
- 可理解，但不神秘化
- 强调“帮助用户更看见自己”，而不是“替用户下定论”

## 7. 内容真实性要求

1. 产品定位以正式 spec 为准
2. 当前阶段只能写已经明确存在的主路径与输出
3. 不虚构用户案例、疗效或反馈
4. 如提到报告类型，应与当前 `Lite / Pro` 口径一致

## 8. 发布节奏建议

- 启号首周：连续发布 `2-3` 条，建立账号定位
- 启号后两周：每周 `2` 条，保持稳定露出
- 有明确阶段进展时，再插入 1 条项目进展类内容
