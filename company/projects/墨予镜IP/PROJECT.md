# 墨予镜 IP 项目入口

> 状态：current
> 最后更新：2026-04-02
> 项目类型：个人 IP / 内容与表达治理项目

这份文档是 `墨予镜 IP` 在 `mindsync` 里的项目级入口。

它用于收束与 `墨予镜` 这个个人账号直接相关的定位、表达边界、个人素材基线，以及各业务项目映射到个人账号时产生的内容资产。

## 1. 这个项目是什么

`墨予镜 IP` 不是某一个产品项目，而是创作者本人的个人 IP 项目。

它承载的是：

- `墨予镜` 账号的人设与身份边界
- 第一人称写作所依赖的真实信息
- 个人方法论、观点与 build in public 表达
- 各业务项目映射到 `墨予镜` 账号后形成的内容资产

它不替代具体产品项目。

像 `一镜一梳`、`怀瑾握瑜` 仍然各自负责：

- 产品定位
- 用户问题
- 产品演进
- 产品账号内容

但只要内容最终发布在 `墨予镜` 账号下，就应优先归档到 `墨予镜 IP` 项目，而不是混放回产品项目目录。

任何 Agent 第一次进入 `墨予镜 IP` 项目时，默认优先读取以下材料：

1. [PROJECT.md](/Users/xinran/Downloads/dev/mindsync/company/projects/墨予镜IP/PROJECT.md)
2. [个人真实信息与表达基线.md](/Users/xinran/Downloads/dev/mindsync/company/projects/墨予镜IP/个人真实信息与表达基线.md)
3. [company/内容矩阵.md](/Users/xinran/Downloads/dev/mindsync/company/内容矩阵.md)
4. [company/项目与仓库映射.md](/Users/xinran/Downloads/dev/mindsync/company/项目与仓库映射.md)

如果任务还引用了某个具体业务项目作为素材来源，还必须继续读取该项目入口与对应材料。

例如：

- `怀瑾握瑜` 相关 build in public 内容，还必须补读 [company/projects/怀瑾握瑜/PROJECT.md](/Users/xinran/Downloads/dev/mindsync/company/projects/怀瑾握瑜/PROJECT.md) 及其研究 / 状态材料

## 3. 这里应该放什么

这里优先放：

- `墨予镜` 账号定位与表达规则
- 已确认的个人真实信息与表达基线
- 面向 `墨予镜` 账号产出的选题、策略、大纲、草稿
- 按来源项目归档的个人号内容资产

建议目录结构：

- `content/<来源项目>/`
  - 存放该项目映射到 `墨予镜` 账号后的内容资产

## 4. 这里不优先放什么

这里不优先放：

- 产品定义本身
- 产品 spec、架构、实现计划
- 产品号专属内容资产
- 未确认真实性的个人背景设定

## 5. 与其他项目的边界

默认边界如下：

- `company/projects/墨予镜IP/`
  - 管 `墨予镜` 账号本身，以及所有发布到该账号的内容资产
- `company/projects/一镜一梳/`
  - 管 `一镜一梳` 的项目定义与产品号资产
- `company/projects/怀瑾握瑜/`
  - 管 `怀瑾握瑜` 的项目定义与产品号资产

如果一份内容同时涉及某个产品项目和 `墨予镜` 账号，按下面规则归档：

- 以产品账号发布：归产品项目
- 以 `墨予镜` 账号发布：归 `墨予镜 IP` 项目
