# 墨予镜个人真实信息与表达基线

> 状态：current
> 最后更新：2026-04-10
> 用途：为 `墨予镜` 个人账号提供第一人称写作事实基线

这份文档用于约束 `Content Lead` 和其他会代写个人号内容的 Agent。

原则只有一条：

- 任何以 `墨予镜` 第一人称写出的内容，都必须以这里已确认的信息为准

如果这里没有写明，就视为“未确认”，不能直接写进正式内容。

这里还要额外补一条：

- “本人真实想法” 和 “公开写作时采用什么表达方式” 不是一回事

Agent 不得把：

- 某个未经确认的内部判断
- 某个项目文档里的表述
- 某次未审核的草稿口径

直接当成 `墨予镜` 个人号对外表达。

## 1. 已确认的身份信息

当前已确认：

- 你正在运营 `墨予镜` 这个个人 IP
- 这个账号承载的是你本人的真实表达，而不是虚构人设
- 账号内容会包含：
  - build in public
  - AI 产品与开源学习拆解
  - 疗愈、成长与方法论表达

当前新增确认：

- 你本人并不排斥“玄学”这一取向，也不是基于“反玄学”立场在思考问题
- 但这不等于你会在 `墨予镜` 个人号里直接、直白地使用同样的说法
- 在公开写作中，你可能会：
  - 换成大众更容易接受的表达
  - 调整措辞
  - 暂时回避某些过于直白的判断

因此 Agent 必须区分：

1. 你真实认可什么
2. 你公开时准备怎么说

这两层如果没有被你本人明确确认，就都不能擅自代写。

## 2. 当前已确认但仍需持续补齐的真实信息

以下信息可以逐步补充；未补充前，Agent 不得擅自写成确定事实：

- 个人职业经历时间线
- 当前职业状态与阶段
- 已做过哪些真实项目
- 已服务过哪些真实人群
- 哪些案例可以公开讲，哪些不能讲
- 哪些观点是稳定立场，哪些只是阶段性判断
- 哪些表述是你习惯使用的语气与措辞

## 3. 写作硬规则

所有 Agent 必须遵守：

- 没写进这里的个人经历，不能写成“我经历过”
- 没被你确认的观点，不能写成“我一直认为”
- 没被你允许公开的案例，不能写成内容素材
- 如果来源只是某个项目文档，只能写项目事实，不能自动补成个人故事
- 没被你审核通过的项目文档、策略文档、内容草稿，不能直接当成你本人的对外立场
- 不得把“更容易被大众接受的表达”误写成“你真实的底层判断”
- 也不得反过来把“你真实认可的内容”直接写成你会公开直说的话

## 4. 文档可信度规则

对 `墨予镜` 个人号写作来说，文档默认分三层可信度：

### 第一层：可直接作为第一人称依据

- 你本人明确审核过并确认的个人信息
- 你本人明确确认过的观点卡
- 你本人明确确认过的表达方式示例

### 第二层：可作为背景参考，但不能直接写成第一人称

- 项目 `PROJECT.md`
- spec
- 内容策略简报
- 研究结论
- 其他正式项目文档

这些材料最多只能支持：

- 主题判断
- 项目事实
- 背景信息

不能直接支持：

- “我为什么这样想”
- “我一直相信什么”
- “我真实在意什么”

### 第三层：不能直接作为依据

- 未经你审核的草稿
- Agent 之间相互 handoff 的推断性内容
- 任何已经被你指出“和本人意思有差距”的表达

这类材料只能作为：

- 反例
- 待修正对象

不能再被下一轮内容继续引用放大。

## 5. 信息不足时允许的交付

如果要写 `墨予镜` 个人号内容，但这份文档仍不够支持成稿，允许的交付是：

- 需要你补充的个人素材清单
- 采访提纲
- 待确认版内容结构
- 标注了“需本人补充”的大纲草案
- 观点卡候选
- “真实判断 / 对外表达” 双层拆分稿

不允许直接交付：

- 已完成的第一人称成稿
- 带具体个人经历细节的故事化文章
- 带具体个人案例的口播脚本
- 把项目文档改写一下就当成个人号文章
- 把 Agent 自己推断出的语气当成你的真实口吻

## 6. 推荐的个人号协作方式

今后如果要为 `墨予镜` 个人号准备内容，默认优先顺序改为：

1. 先抽主题
2. 再列“你真实怎么想”的问题
3. 再列“你准备对外怎么说”的问题
4. 先由你补观点卡或关键句
5. 最后再决定是否进入成稿

默认不要再走：

`项目材料 -> Agent 直接写完整第一人称稿`

而应改成：

`项目材料 -> 采访提纲 / 观点卡 / 待确认结构 -> 本人补充 -> 成稿`

## 7. 后续维护方式

建议后续把新增信息按下面维度持续补齐：

- 身份与长期定位
- 职业经历时间线
- 真实项目经历
- 真实用户 / 咨询 / 服务经历
- 稳定观点
- 表达禁区
- 公开表达策略
- 哪些真实想法会保留、转译或回避
