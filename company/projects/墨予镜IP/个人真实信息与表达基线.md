# 墨予镜个人真实信息与表达基线

> 状态：draft
> 最后更新：2026-04-02
> 用途：为 `墨予镜` 个人账号提供第一人称写作事实基线

这份文档用于约束 `Content Lead` 和其他会代写个人号内容的 Agent。

原则只有一条：

- 任何以 `墨予镜` 第一人称写出的内容，都必须以这里已确认的信息为准

如果这里没有写明，就视为“未确认”，不能直接写进正式内容。

## 1. 已确认的身份信息

当前已确认：

- 你正在运营 `墨予镜` 这个个人 IP
- 这个账号承载的是你本人的真实表达，而不是虚构人设
- 账号内容会包含：
  - build in public
  - AI 产品与开源学习拆解
  - 疗愈、成长与方法论表达

## 2. 当前已确认但仍需持续补齐的真实信息

以下信息可以逐步补充；未补充前，Agent 不得擅自写成确定事实：

- 个人职业经历时间线
- 当前职业状态与阶段
- 已做过哪些真实项目
- 已服务过哪些真实人群
- 哪些案例可以公开讲，哪些不能讲
- 哪些观点是稳定立场，哪些只是阶段性判断
- 哪些表述是你习惯使用的语气与措辞

## 3. 写作硬规则

所有 Agent 必须遵守：

- 没写进这里的个人经历，不能写成“我经历过”
- 没被你确认的观点，不能写成“我一直认为”
- 没被你允许公开的案例，不能写成内容素材
- 如果来源只是某个项目文档，只能写项目事实，不能自动补成个人故事

## 4. 信息不足时允许的交付

如果要写 `墨予镜` 个人号内容，但这份文档仍不够支持成稿，允许的交付是：

- 需要你补充的个人素材清单
- 采访提纲
- 待确认版内容结构
- 标注了“需本人补充”的大纲草案

不允许直接交付：

- 已完成的第一人称成稿
- 带具体个人经历细节的故事化文章
- 带具体个人案例的口播脚本

## 5. 后续维护方式

建议后续把新增信息按下面维度持续补齐：

- 身份与长期定位
- 职业经历时间线
- 真实项目经历
- 真实用户 / 咨询 / 服务经历
- 稳定观点
- 表达禁区
