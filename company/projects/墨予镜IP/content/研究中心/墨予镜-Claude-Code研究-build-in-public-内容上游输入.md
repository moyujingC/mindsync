## 6. 推荐论点

- Claude Code 真正强的，不只是模型，而是会话编排、skill 协议和多 Agent 协作协议
- skill 的价值不在“加命令”，而在把复杂工作流从 prompt 里拆出来，变成可复用对象
- 对一人公司来说，最容易忽视的一层，不是角色层，而是方法层
- 如果没有 skill，Agent 往往会每次从头组织一次方法，质量就会波动
- 研究、产品、架构、内容之间要稳定协作，不能只靠聊天，要靠 artifact 和 skill
