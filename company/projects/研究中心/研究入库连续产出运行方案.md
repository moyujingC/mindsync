这份文档用于把“研究中心持续产出并进入知识库”从原则，收束成一条现在就能反复执行的链路。

目标不是做更多研究，而是稳定地产生三类结果：

1. 可复用的研究结论
2. 可正式入库的知识条目
3. 可 handoff 给产品、内容、架构或商业的上游输入

## 1. 当前要跑通的链路

默认必须跑通的不是单篇研究，而是下面这条闭环：

`线索进入 -> 研究任务 -> 综合结论 -> 事实核查 / review -> 知识入库 -> handoff`

其中：

- 没有进入 `knowledge-ingest`
  - 研究还不算真正沉淀
- 没有形成 `handoff`
  - 研究还没有真正服务下游

## 2. 当前优先服务对象

研究中心当前连续产出，优先服务下面四个对象：

1. `墨予镜` 个人 IP
2. `一镜一梳`
3. `怀瑾握瑜`
4. 全公司 Agent 方法与协作能力

如果一个研究主题暂时无法明确服务这四类对象之一，就不进入本轮高优先级流水线。

## 3. 单个研究主题的最小输出包

每个正式研究主题，至少要产出下面 4 类文件中的 3 类；如果目标是入库，则 4 类都要有：

1. `tasks/`
   - 研究任务 brief 或任务定义
2. `research/`
   - 正式研究记录、综合结论或事实核查记录
3. `kb/` 或 `knowledge/`
   - 结构化知识候选或正式知识条目
4. `handoff/` 或 `delivery/`
   - 面向下游角色的交接说明

默认不能停在“只有一份研究笔记”。

## 4. 每周最小节奏

研究中心按周至少完成以下最小产量：

1. `2` 个新研究线索进入任务池
2. `1` 份正式综合结论
3. `1` 份可入库知识条目或知识候选
4. `1` 份面向下游角色的 handoff

如果本周研究较重，允许减少线索数量，但不能让：

- `综合结论`
- `知识入库`
- `handoff`

三者同时缺位。

## 5. 研究任务分三层管理

### 5.1 线索层

适合放：

- 待跟踪链接
- 值得看的创作者
- 值得拆的产品
- 值得追的开源项目

要求：

- 只写为什么值得看
- 不在这一层堆原始资料收藏夹

### 5.2 研究层

适合放：

- 正式 brief
- 拆解记录
- 综合判断
- 事实核查记录

要求：

- 必须回答研究问题
- 必须收口成结论，而不是继续发散

### 5.3 入库层

适合放：

- 能复用的模式
- 方法论
- 判断框架
- 反复会遇到的表达、案例与结论

要求：

- 必须具备迁移价值
- 必须明确可服务哪些下游对象

## 6. 默认题材配比

为了同时服务知识库和内容制造，当前题材配比建议固定为：

1. `40%` 业务线直接相关研究
   - 例如职业服务、曼陀罗疗愈、用户教育、服务设计
2. `30%` 内容选题与表达研究
   - 例如同行内容打法、爆点结构、表达空位
3. `20%` AI 方法与 Agent 协作研究
   - 例如 Harness Engineering、SDD、TDD、Agent 工作流
4. `10%` 探索型线索
   - 只保留少量新方向预研

## 7. 与内容制造的交接规则

如果研究结果要服务内容制造，默认必须多走一步：

`研究综合结论 -> 内容上游输入 -> Content Lead 转译`

内容上游输入至少应包含：

1. 这个主题为什么现在值得讲
2. 当前市场上已经怎么讲
3. 哪些说法不能直接复用
4. 我们自己的观点框架是什么
5. 哪些表述可以给 `墨予镜`
6. 哪些表述应该给产品号

如果没有这一步，`Content Lead` 很容易只拿到零散材料，无法稳定出稿。

## 8. 入库前质量门

下列任一情况成立时，不进入正式知识库：

1. 只有观点，没有事实依据
2. 只有案例，没有模式抽象
3. 只有拆解，没有对 `墨予镜` 的启发
4. 没有说明可服务哪个下游对象
5. 与现有知识条目高度重复，但未说明增量

此时允许先写成：

- `知识候选`
- `待复核条目`

但不标记为正式长期资产。

## 9. 当前推荐执行顺序

每次研究中心开始一个新周期时，默认按下面顺序推进：

1. 从业务线和内容线各选 `1` 个高优先级对象
2. 先产出 brief，锁定研究问题
3. 完成综合结论
4. 立即判断哪些部分值得入库
5. 同步生成 handoff 给 `Content Lead`、`Product Spec Lead` 或 `Architect`

默认不建议：

- 连续写很多 brief 但不进入综合结论
- 连续做很多拆解但不决定是否入库
- 连续积累很多知识候选但不 handoff 给下游

## 10. 眼下的最重要目标

眼下研究中心不是缺“研究方向”，而是缺“稳定出成品”。

因此当前执行重点固定为：

1. 每周都要有可入库内容
2. 每周都要有可转给内容制造的上游输入
3. 每周都要把至少一个研究结果沉成长期资产

做到这三点，研究中心才算真正跑起来。
