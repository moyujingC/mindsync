`墨予镜课程平台` 的规格文档按四层组织，阅读顺序固定：

1. [设计层 Spec](./设计层.md) — 是什么、不是什么、边界在哪
2. [控制层 Spec](./控制层.md) — 状态怎么转、错了怎么办（最重要，改动需最谨慎）
3. [工程层 Spec](./工程层.md) — 用什么技术、代码怎么组织
4. [验收层 Spec](./验收层.md) — 怎么算对、怎么算错

层间约束方向：设计层约束控制层和工程层，控制层约束工程层的改动节奏，验收层反向校验以上三层。下层文档不得与上层冲突；冲突时以上层为准并回改下层。
