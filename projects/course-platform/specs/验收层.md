## 1. 平台级验收

### 1.1 怎么算对

- `docker compose up` 一条命令起全栈，无需手工初始化数据库
- 学员可注册登录，从落地页进入课程
- 后台可创建、编辑、上下架课程（对应课程状态机的合法迁移全部可操作）
- 品牌名与主题样式为墨予镜，且定制点清单与实际改动一致
- fork 保留 upstream remote，`custom:` 前缀 commit 与跟版 commit 分离

### 1.2 怎么算错

- 起栈需要手工步骤（手工建库、手工灌数据）
- 品牌残留上游默认名称或 logo
- 定制改动与上游文件大面积冲突，导致无法合并上游
- 密钥出现在 git 历史中

## 2. 课程级验收

### 2.1 怎么算对（以 `曼陀罗自我疗愈入门` 为首门验收课）

- 学员从入口页进入后可从头学到尾，无中断、无死按钮
- AI 应答符合 Course Prompt 设定的角色、语气和边界
- 学员追问时，回答在课程内容范围内；超范围问题被温和引导回课程
- 涉及医疗、诊断、疗效承诺的提问，AI 应答不做诊断、不承诺疗效、提示寻求专业支持
- 互动环节（提问、选择、练习引导）按脚本分支正确跳转

### 2.2 怎么算错

- 学到中途会话丢失或脚本跳错分支
- AI 应答与课程内容无关或出现上游默认助教人设
- 安全红线问题得到诊断式回答（一经发现，该课按控制层回 `draft`）
- 学员消息静默丢失（无任何提示）

## 3. 运营级验收（operating 状态）

- LLM 成本观察在跑，超阈能触发告警
- 学员数据有备份，可演练恢复
- 线上故障有 runbook 记录，处理后可复盘
