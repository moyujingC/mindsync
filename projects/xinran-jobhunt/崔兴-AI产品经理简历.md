- **定位重定义（最有价值的取舍）**：服务对象从「来访者直接使用」改为「疗愈师使用」，来访者不接触产品、交付物为报告文件，删除 To C 二阶段演进；成功指标整体从来访者侧改为疗愈师侧——编辑率、采纳率、交付完成率全部以疗愈师为准。**一个决策连锁消解三个待决问题**（来访者数据可见性、链接权限、模式伪造）。
- **Agent 资源与工具治理**：6 个工具白名单（不扩充）+ 按 6 类问题各自写死的调用序列（前序输出作后序输入，序列外一律禁止调用）+ 输出缺来源标注视为不完整、禁止输出；解读 Agent 只写不读、问答 Agent 只读不写，回答依据以链路产物为准、正文为辅。
- **AI 输出质量与可信度**：不测「模型好不好」，测「疗愈师拿到手改不改」与「AI 会不会越界」。报告生成一次出两版——干净版给来访者、溯源版给疗愈师逐条核查；输入预处理六步全部程序化，黄金集 18/18 通过、单张 ≤0.6 秒；报告问答在真实个案上 18 问扩量实测（六类问题 ×「解读参谋」「应答准备」两场景）——锚定 97.8%、相关 5.00、准确 4.83、边界标注 100%、安全越界 0 条、可转述性 5.00、延迟 P95 8.4 秒。口径：单 run 验证，judge 为 LLM 评分。用户侧编辑率 <30%、采纳率 >70% 仍是**目标值，待试点回填**。评估治理：裁判独立于被测模型、可复现配置快照、常规题与安全题分桶、指标期望值变更留痕（防「改考卷」）。
- **问答 Agent 的双场景分化**：同一 Agent 按场景配置——「解读参谋」（专业、深、多视角，L1，不限轮次）与「应答准备」（通俗可转述、给可能性不给定论、附边界口径提醒，L2，≤15 轮）；助手永不直接面对来访者。多轮历史为窗口原文保留 + 超窗滚动摘要 + 轮次硬限，每轮问答（含护栏拒绝与降级话术）落盘留痕。
- **安全的产品设计**：L1 基础安全 7 项 + L2 标准安全 10 项验收，任一红禁发；应答准备场景按「输出可能被转述给来访者」的标准审核；危机信号双侧覆盖（输出侧拦截 + 输入侧疗愈师录入原话触发风险提醒）。
- **主动记录局限**：① 未上线、无真实疗愈师使用数据，采纳率 / 编辑率 / 问答使用率 / 交付完成率全部是目标值；② 18 问是单份报告上的单 run 验证，跨个案泛化性未测，judge 为 LLM 评分、人工评审仍在进行中；③ 前端未建，暂无可交互 Demo；记忆模块与自动意图判别未做。评测当天抓出的两类真实缺陷（模型吐非法 JSON、断言把合规免责误判为违规）已当天闭环修复。
