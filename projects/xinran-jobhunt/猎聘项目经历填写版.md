## 1. 曼陀罗绘画 AI 解读产品 / 一镜一梳

项目名称：曼陀罗绘画 AI 解读产品 / 一镜一梳

开始时间：2025.01

结束时间：至今

公司名称：知行工坊 / 独立项目

项目职务：独立产品负责人 / 独立开发推进者

项目描述：

面向 To C 用户构建曼陀罗绘画上传与 AI 解读 Web MVP，围绕画作上传、三圈识别、Lite / Pro 解读报告、付费升级、报告追问与历史记录，形成完整产品闭环。

项目定位为曼陀罗绘画解读与自我探索工具，不做心理治疗、医疗诊断或长期陪伴。首版重点解决人工解读耗时长、标准化程度低、依赖咨询师经验的问题，将原本依赖人工经验的服务拆解为可开发、可验证、可迭代的 AI 产品流程。

项目职责：

1. 负责产品问题定义、用户主路径设计和 MVP 范围收敛，明确画作上传、三圈识别、Lite 报告、Pro 升级、追问和历史记录等核心模块。
2. 设计 Lite / Pro 两层产品结构，Lite 用于首次体验和快速理解，Pro 用于完整报告、深度解读和追问承接。
3. 设计两段式报告生成链路：Vision Pass 先生成画作级视觉基准，Reasoning Pass 再结合视觉基准、主题 Prompt Pack、输出规范和用户意图生成最终报告。
4. 建立质量门和安全边界，要求系统保留视觉证据、支持三圈带读、限制追问范围，避免医疗化、诊断化和过度承诺表达。
5. 持续维护产品规范、报告契约、Prompt 模板、交付文档和主路径联调材料，推动项目从概念设计进入可落地执行。

项目业绩：

1. 完成 To C Web MVP 核心路径设计，覆盖上传、识别、报告生成、付费升级、追问和历史记录等关键环节。
2. 将人工曼陀罗解读服务转化为可开发方案，形成用户路径、报告契约、Prompt 模板和交付文档。
3. 建立 Lite / Pro 产品分层、两段式报告生成链路、质量门控和安全表达边界，为后续产品上线、测试和商业化验证打下基础。

## 2. 知行工坊 / 一人公司的 AI 工作系统

项目名称：知行工坊 / 一人公司的 AI 工作系统

开始时间：2026.01

结束时间：至今

公司名称：知行工坊 / 独立项目

项目职务：系统设计者 / 一人公司工作空间搭建者 / Agent 协作机制推进者

项目描述：

自建自用一人公司的 AI 工作系统 MindSync，采用 Monorepo 架构统一管理公司治理、项目入口、角色定义、知识库、共享工具和阶段产物，支撑 AI 产品开发、研究、内容创作、求职材料制作等多项目并行推进。

项目重点不是单个工具，而是把零散聊天、文档、代码、任务、知识和交付记录收束到同一套可维护的工作系统中，降低 AI Agent 接手任务时的上下文成本，提升个人公司在多项目并行时的可追踪性和交付稳定性。

项目职责：

1. 设计 MindSync Monorepo 工作空间结构，搭建 `agents / company / projects / shared / knowledge-base` 五层目录，划分公司治理、项目执行、角色职责、共享工具和知识沉淀边界。
2. 整合 AI 产品、研究、内容、求职材料等项目对象，通过统一项目入口和阶段产物管理，支持多项目并行推进。
3. 基于本地 Codex / Claude Code、Paperclip 等工具，探索多角色 AI 协作、任务回写、知识治理和上下文交接机制。
4. 将 spec、task、QA、delivery 等阶段产物纳入项目闭环，保证需求、实现、验证和交付过程可追踪、可回溯。
5. 完成个人作品集网站的云服务器部署和基础运维，覆盖 Linux 服务器、Nginx 静态站点发布、域名解析、HTTPS 证书配置和线上访问排查。

项目业绩：

1. 搭建公司自用内核与多项目工作区的 Monorepo 架构，提升项目资料复用、任务追踪和协作效率。
2. 明确 AI Agent 接手项目所需的入口、边界、任务状态和交付记录，降低重复解释和上下文丢失成本。
3. 将零散聊天记录、文档和项目资料沉淀为长期可维护的工作系统，支撑 AI 产品、内容、研究和求职材料并行推进。
4. 将作品集从本地构建同步到线上服务器，形成可访问、可排查、可复用的部署流程。

## 3. 房产定制化方案与经纪人孵化体系

项目名称：房产定制化方案与经纪人孵化体系

开始时间：2019.11

结束时间：2024.12

公司名称：上海领马房地产咨询有限公司 / 一家房地产经纪有限公司

项目职务：创始合伙人 / 一线业务打样者 / 培训体系建设者

项目描述：

在房产咨询工作室中，以单边代理和客户利益优先为原则，为客户提供买房、卖房、信贷、装修、售前美化、民宿运营、出租管理等定制化服务。项目同时覆盖一线客户服务和组织能力建设，将复杂交易经验沉淀为经纪人孵化、培训和服务流程体系。

该项目面对的是高客单价、高信任成本、周期长、风险点多的房产交易场景，需要在客户需求诊断、预算约束、区域判断、交易风险、跨方资源协同和服务交付之间持续平衡。

项目职责：

1. 负责客户需求诊断、预算评估、城市区域分析和交易风险识别，为客户制定个性化买卖房及资产配置方案。
2. 整合房源、信贷、装修、法务、财税、民宿运营和出租管理等多方资源，推动复杂交易流程闭环。
3. 基于一线服务案例，提炼标准化操作流程、知识库、风控节点和协作规则，提升团队服务稳定性。
4. 负责独立房产经纪人的招募、培训和孵化，建立从零基础到独立服务客户的成长路径。
5. 在关键客户和复杂项目中亲自打样，将客户沟通、方案设计、风险控制和交付复盘转化为可复制的方法。

项目业绩：

1. 通过 2 名经纪人及 2 名助理团队，实现年营收约 200 万元，相当于传统 20 人中介门店的业绩水平。
2. 累计服务 150 余名高净值客户，其中约 70% 客户来自转介绍，形成较强客户信任和口碑传播。
3. 成功孵化 30 余名经纪人，将新人从零基础到独立上岗的周期由 18 个月缩短至 6 个月。
4. 将个人一线服务经验转化为 SOP、知识库、风控节点和培训体系，提升组织交付效率。

## 4. 主机游戏与移动应用研发项目

项目名称：主机游戏与移动应用研发项目

开始时间：2008.07

结束时间：2016.01

公司名称：昱泉国际 / 维塔士 / 上海星为棋信息科技有限公司 / 上海乔布堂信息科技有限公司

项目职务：游戏程序员 / 游戏开发工程师 / 项目经理 / 技术负责人 / App 开发

项目描述：

早期参与多款游戏及移动应用研发，覆盖 MMORPG《射雕英雄传》、Wii 版《席德梅尔的海盗》移植、跨平台 AAA 项目《Generator Rex: Agent of Providence》、公司自研游戏引擎达芬奇 Wii 版本，以及知识管理类 App 和多个外包项目。

项目横跨客户端、服务器、主机平台、移动端和工具链开发，既包含 C++、Lua、Python、C#、Objective-C、Java、JavaScript 等多语言工程实践，也包含后期技术负责人、项目经理和小团队管理工作。

项目职责：

1. 参与或主导 UI 系统、任务系统、组队系统、成就与排行榜系统、自动寻路、基础渲染、天空盒、地形渲染、粒子系统等模块开发。
2. 参与资源管理系统压缩、打包、美术支持工具和 UI 编辑工具开发，支持策划、美术、测试等角色高效协作。
3. 在 Wii、Xbox 360、PS3 等平台项目中处理跨平台适配、调试和性能相关问题。
4. 在后期项目中担任项目经理、技术负责人及制作人角色，负责技术选型、版本节奏、任务分配、流程规范和跨角色协作。
5. 持续撰写技术文档和项目文档，支持团队交接、问题排查和版本发布。

项目业绩：

1. 参与多款商业游戏、跨平台主机项目和移动应用项目，形成完整的软件研发、跨模块协作和版本交付经验。
2. 在复杂系统拆解、跨平台适配、技术文档、工具链建设和研发流程协作方面建立扎实工程基础。
3. 完成从技术执行到项目推进角色的转型，逐步建立产品视角、团队协作能力和项目管理能力。
4. 为后续 AI 产品、工作系统搭建和复杂项目交付提供工程判断、系统拆解和跨职能沟通基础。
