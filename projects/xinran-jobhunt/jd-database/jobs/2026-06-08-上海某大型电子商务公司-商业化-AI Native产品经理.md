## 文字版 JD

一、团队与业务介绍

商业化团队

是平台商业变现的核心引擎，服务于电商、品牌等客户的营销需求。本岗位隶属于电商广告业务线，并非独立分组，将深度联动电商、搜索、社区等业务，负责电商广告产品的规划、迭代与落地，打造平台特色的“种草 - 搜索 - 转化”全链路广告产品，助力客户实现生意增长，同时支撑平台商业化收入目标达成。

二、岗位职责

1. 负责小红书电商广告产品（效果广告 / 搜索广告 / 信息流电商广告）的全生命周期管理，包括需求调研、产品规划、方案设计、项目推进与上线落地。
2. 基于电商客户（品牌 / 商家）的投放痛点与平台业务场景，优化广告定向、竞价、归因、素材生成等核心模块，提升广告投放效率与 ROI。
3. 联动电商、数据、算法、运营等跨团队，推动广告产品迭代与创新，探索 AIGC、AI Agent 等技术在广告场景的落地应用，打造差异化产品能力。
4. 搭建并优化广告产品的数据指标体系，通过数据复盘与用户反馈，持续迭代产品策略，解决业务问题，支撑业务目标达成。
5. 沉淀电商广告产品的方法论与行业解决方案，为不同行业客户提供适配的广告产品能力，助力平台广告业务的规模化增长。

三、任职要求

1. 3 年以上互联网广告产品经理经验，有电商广告 / 效果广告 / 搜索广告产品经验者优先。
2. 熟悉主流广告平台（巨量引擎 / 腾讯广告 / 百度 / 小红书聚光）的产品逻辑，了解电商广告竞价、定向、归因、转化全链路流程。
3. 具备独立的产品规划与方案设计能力，能基于业务痛点输出完整的产品方案、PRD 文档，并推动跨团队落地执行。
4. 具备较强的数据敏感度，能通过数据定位产品问题，驱动产品迭代优化，熟练使用 SQL / Excel / Tableau 等数据分析工具优先。
5. 具备良好的跨团队沟通协调能力、逻辑思维能力与项目推进能力，能在复杂业务场景下高效推进项目落地。

（二）加分项

1. 有电商平台（淘宝 / 京东 / 拼多多）或内容平台电商广告产品经验，熟悉“内容种草 - 广告投放 - 电商转化”链路者优先。
2. 有 AIGC / AI Agent 在广告场景的落地经验，如 AI 广告素材生成、AI 投放优化、AI 智能策略等相关项目经验者优先。
3. 服务过头部电商 / 消费品品牌客户，沉淀行业广告解决方案者优先。
4. 了解社区生态与用户行为逻辑，对内容营销与广告结合有深入理解者优先。
