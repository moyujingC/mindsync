## 文字版 JD

【岗位使命】

我们是一家品牌营销、电商运营、私域用户运营服务公司，正在从传统人力驱动的服务模式，升级为流程驱动、AI 赋能、知识资产沉淀型组织。  
我们希望寻找一位既懂 AI 应用与系统架构，又能深入理解业务流程的人，协助公司搭建内部 AI 工作系统，将营销、电商、私域、内容生产、项目管理、客户复盘等日常工作流程标准化、智能化、资产化。  
你将和创始人、业务负责人、项目团队一起，推动公司内部 AI 平台和工作流体系的建设，让 AI 真正进入日常业务，而不是停留在工具尝鲜层面。

【核心职责】

1. 业务流程梳理与系统化重构  
   - 深入理解公司现有业务，包括品牌营销、电商运营、内容生产、项目管理、客户服务等模块；  
   - 协助团队梳理关键业务流程，识别重复性高、经验依赖重、协同效率低、知识沉淀弱的环节；  
   - 将业务流程拆解为可标准化、可数据化、可 AI 辅助的工作节点。  
2. AI 工作流设计与落地  
   - 基于公司业务场景，设计 AI 辅助工作流，包括但不限于：  
   - 客户 Brief 解析：自动提炼客户需求、目标、风险、交付要求；  
   - 内容策划：生成小红书选题、脚本、达人 Brief、内容方向；  
   - 电商运营：日报分析、销售异常提醒、ROI 复盘、活动策略建议；  
   - 私域运营：用户分层、话术生成、SOP 设计、转化路径优化；  
   - 项目管理：会议纪要、任务拆解、风险预警、项目复盘；  
   - 知识库沉淀：案例、流程、模板、Prompt、复盘文档结构化管理。  
3. 内部 AI 平台 / 工具体系搭建  
   - 根据公司阶段选择适合的技术方案，可能包括：企业知识库、AI 工作流平台、Agent 系统、Prompt 管理系统、自动化流程工具；  
   - 飞书 / 企业微信 / Notion / 本地知识库集成，Dify、Coze、RAG、OpenAI API 等工具和框架；  
   - 不要求所有系统自研，但需要能判断哪些适合用现成工具，哪些需要轻量开发，哪些暂时不值得做。  
4. 与业务团队共创试点项目  
   - 选择 1-3 个高价值场景进行试点，例如：  
   - 电商日报与销售复盘 AI 助手；  
   - 小红书内容选题与种草转化工作流；  
   - 私域运营 SOP 与用户分层 AI 助手；  
   - 项目复盘与客户案例沉淀系统；  
   - 公司内部流程资产知识库。  
   - 通过试点验证效率提升、质量提升和团队使用意愿，形成推广到更多业务模块。  
5. 培训团队并推动组织使用  
   - 为业务团队设计 AI 使用规范、流程模板、提示词模板和操作手册；  
   - 培训 Account、内容、电商、私域、设计、项目管理等团队，让 AI 成为日常工作方式；  
   - 持续收集业务反馈，优化工作流，避免 AI 系统变成“搭好了但没人用”。  

【任职要求】

1. 3 年以上产品经理、系统架构、业务流程数字化、AI 应用落地相关经验。  
2. 熟悉 AI 大模型应用场景，了解以下至少部分工具或技术：  
   - ChatGPT / Claude / Gemini  
   - Dify / Coze / LangChain / RAG  
   - 知识库搭建  
   - Workflow / Agent  
   - API 集成  
   - 自动化工具  
   - 企业协同工具集成  
3. 有较强的业务理解能力，能听懂业务团队的真实需求，而不是只从技术角度出发。  
4. 有流程拆解能力，能把复杂业务拆成节点，插入 AI 输出，责任分工明确。  
5. 有项目推进能力，能从 0 到 1 推动试点落地，而不是只提方案。  
6. 能和非技术团队沟通，愿意深入一线业务场景。  

加分项：

1. 有营销、电商、内容、私域、CRM、广告、品牌咨询行业经验。  
2. 做过企业内部知识库、AI 助手、AI 工作流系统。  
3. 有咨询公司、数字化转型、SaaS 产品、MarTech 产品经验。  
4. 熟悉小红书、天猫、京东、私域用户运营、内容生产流程。  
5. 能做轻量原型、工具选型、低代码搭建或基础开发。  
6. 有从 0 到 1 搭建企业内部系统的经验。

## 匹配判断

### 匹配点

- 这条样本对 `AI 转型咨询顾问` 主线很关键，因为它把“业务流程重构 + 工具选型 + 试点推广”写得很实

### 缺口

- 如果经历里没有服务行业、电商、私域、内容运营上下文，会损失一部分场景贴合度
- 如果只会讲产品思路，不会讲 Dify / RAG / API / 工作流落地，也会被判定不足

### 风险

- 岗位标题的“负责人”可能会吸引更资深候选人，但薪资和经验范围更像中段执行 owner
- 这类岗位往往高度依赖创始人和业务团队配合，真实推进难度可能高于 JD 描述
