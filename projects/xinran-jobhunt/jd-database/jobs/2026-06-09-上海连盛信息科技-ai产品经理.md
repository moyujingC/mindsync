## 文字版 JD

职位描述：

1. 负责公司智能客服的 C 端产品设计，定义 AI 与用户的交互范式，包括对话流、多模态交互，打造流畅、高效且具有品牌风格的对话体验。
2. 基于大模型能力，挖掘 C 端用户在服务场景下的潜在需求，设计主动服务、个性化推荐等创新能力，利用 AI Agent 能力解决咨询并直接闭环用户业务需求。
3. 深度分析 C 端用户的咨询行为、对话日志及评价数据，通过数据发现用户在自助服务中的体验断点，通过 Prompt 工程、知识库、工作流、Agent 系统优化等手段，持续提升回答能力、丰富度及“理解用户”的程度。
4. 协同研发、算法、B 端策略产品、UI 设计及运营团队，将后台复杂的 AI 能力转化为前台简单易用的用户功能，对 C 端用户的最终服务体验和效果负责。

职位要求：

1. 本科及以上学历，留学经验优先，具备用户同理心和产品思维，对用户体验和人机交互有深刻理解，有 C 端对话式产品或智能客服类产品经验者优先。
2. 擅长通过用户行为数据分析产品问题，具备从模糊的用户反馈中提炼核心需求的能力。
3. 具备优秀的逻辑思维、跨部门沟通技巧，能站在用户视角推动技术和策略团队的交付质量提升。

## 职责拆解

- 做 C 端智能客服交互和对话体验设计
- 基于大模型和 Agent 做主动服务与推荐能力
- 用对话日志和评价数据持续优化服务质量
- 协同算法、研发、策略产品和运营把后台 AI 能力转成前台功能

## 任职要求拆解

- 这是偏 `C端智能客服 / 对话式产品` 的 AI PM
- 岗位重点不在底层模型研发，而在用户交互、体验优化和客服场景闭环
- Prompt、知识库、工作流、Agent 已经进入产品职责，说明岗位带有一定工程化产品特征
- 但整体仍更偏 C 端服务产品，而不是企业 AI 平台或解决方案岗
