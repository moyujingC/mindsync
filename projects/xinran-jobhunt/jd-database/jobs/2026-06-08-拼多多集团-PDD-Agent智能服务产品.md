## 文字版 JD

大模型这一波，行业都在找落地场景。最天然的那个场景，多数人会下意识跳过 电商的客服与售后。而我是这块的产品负责人。

逻辑直接：大模型的核心能力是自然语言理解和生成，而消费者跟平台高频交互、最低赖自然语言的环节，就是售前咨询和售后服务。用户心智早已建立，不需要市场教育。我们在拼多多做的，就是把 Agent 真正跑在这个场景里 同时覆盖 ToB 商家服务、ToC 消费者体验、售前咨询、售后处理。这个场景丰富度，行业里很难找到第二个。

关于团队

组织扁平。产品、算法、工程在同一个团队，决策链短，没有跨部门拉通的损耗。

关于回报

薪酬对标互联网行业 Top 水平，不设涨幅天花板，每年 1-2 次调薪窗口。

关于背景

不要求大模型或 AI 相关经历。我们更看重对业务场景的理解力、需求拆解能力和推进能力 这些是互联网产品基本功，AI 认知可以快速补齐来。组内去年社招的几位产品同事，入职前都没有 AI 经验，现在 Agent 需求都在独立推进。

岗位职责

1. 负责消费者侧 Agent 产品（售后客服、消费者咨询场景）的规划与落地，从问题场景拆解、Agent 链路设计、工具与知识库定义，到效果评估和持续迭代
2. 负责商家侧智能服务产品的规划与落地，通过 Agent 直接处理或辅助人工处理商家售前售后问题，降低商家服务成本、提升处理时效
3. 主导 Agent 能力与具体业务场景的映射设计，定义任务边界、交互形态和人机协同机制；推动现有 NLU / 决策树架构向 LLM + Agent 架构迁移
4. 与算法、工程、业务团队协同优化端到端体验，对解决率、用户满意度、人工成本节省等核心指标负责

任职要求

1. 1 年以上产品经验，电商 / 服务 / B 端方向皆可，不要求大模型背景
2. 逻辑清楚，数据敏感，有独立拆解复杂问题的能力
3. 具备高度责任心和较强的自我驱动力、抗压能力，善于合作，善于协调和调度资源推动业务发展

加分项

有以下行业经验：互联网 / 电子商务 / 人工智能
