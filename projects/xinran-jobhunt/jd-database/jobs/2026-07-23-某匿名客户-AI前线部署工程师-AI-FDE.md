岗位概览：产品 / 技术序列，AI 前线部署工程师（AI FDE），要求 5 年以上经验；上海嘉定，50-80k，招 3 人。

岗位职责：

1. 深入行业场景，将客户模糊需求拆解成技术路线图；主导需求分析、技术选型和架构设计，产出可落地的 AI 解决方案与 Agent 产品方案。
2. 结合上下文工程、Harness 工程（面向工作流的工程化编排）和 CI/CD，建立从需求到交付的 AI 驱动研发提效闭环。
3. 落地 SDD（规范驱动开发），运用 OpenSpec、Spec Kit、Superpower 等方法，结合 TDD，保障 AI 生成代码的质量、可维护性和交付可靠性。
4. 开发 AI 提效工具与自动化工作流，向内部团队和行业客户做技术培训、运营推广，将 AI Coding 融入生产工作流并形成可量化 ROI。
5. 面向非研发效能场景，与行业客户沟通、挖掘业务痛点，形成可复用的落地方案与工程实践。

岗位要求：

- 本科及以上，计算机、软件工程、数学、物理等理工科相关专业；3 年以上软件开发或 ToB 项目交付经验，特别优秀者可放宽。
- 具备端到端应用开发与交付能力，至少精通 Python、Go、Java、TypeScript 中一门后端语言，并熟练 React 或 Vue。
- 深度使用 Codebuddy、Claude Code、Cursor 等 AI Coding 工具；理解上下文工程与 Harness 工程；有用 AI Coding 迭代存量项目或从 0 到 1 完整项目的经验。
- 有 OpenSpec、Spec Kit、Superpower 等 SDD 方法的实践和定制化经验，或主导过团队 AI Coding 规范提效体系。
- 熟悉 TDD / BDD，能独立或借助 AI 建设自动化测试框架和质量门禁。
- 熟悉 CI/CD，有将 AI Coding 接入 DevOps 工作流的经验；了解 Docker、Kubernetes（K8s）和公有云，大厂云经验优先。

## 职责拆解

- 这是偏客户现场的解决方案型 FDE：先做需求和架构，再推动工程交付与复用。
- 将 AI Coding、上下文工程、SDD、测试和 CI/CD 打成一套研发提效交付方法。
- 面向客户及内部团队进行培训推广，要求能把技术方法转换为可被采用的工作流。
- 同时探索非研发场景的 AI 提效，强调业务理解和可复用工程实践。

## 任职要求拆解

- 硬门槛集中在全栈工程、AI Coding 实战、工程质量和 DevOps，而非单纯产品规划。

- 候选人需能把方法落在完整项目，而不仅会使用单个 AI 编程工具。
- 客户沟通、技术培训和 ROI 表达意味着交付能力要兼顾工程与采用推进。

## 匹配判断

### 匹配点

- 现有 FDE 材料已覆盖 Python、React、TypeScript、AI 工作流、结构化交付、验收口径、CI/CD 和云服务器部署，可对齐该岗位的部分工程与交付语言。
- 已有使用 Codex / Claude Code 进行多角色协作、任务回写和交付跟踪的实践，和岗位强调的 AI Coding 工作流有直接关联。
- 技术、咨询与业务流程拆解的复合背景，适合将模糊业务需求转成方案与可执行工作流的部分。

### 缺口

- 需证明完整的端到端全栈交付深度：后端服务、前端应用、测试、部署和持续迭代应能讲成同一条真实案例。

- Docker、K8s、公有云及客户现场 AI 交付的成熟经验，需要如实确认边界，不能泛化为既有能力。

### 风险

- 用人公司匿名，岗位实际业务、团队规模、雇佣关系和现场要求暂不可判断。
- 50-80k 对应的工程深度较高；若团队期望资深全栈技术负责人，现有产品/流程侧证据不足以单独覆盖。
