职位描述：

你将做什么

1. 负责 AI Agent 在生产力/协作场景中的产品定义、原型验证与迭代，输出 PRD 及可演示的 MVP 原型。
2. 深度理解用户工作流（任务、文档、沟通、异步协作），设计能减少协作负担、提升团队效能的 Agent 交互形式。
3. 亲自使用代码或低代码工具（Vibe Coding）快速搭建产品原型，验证核心假设，与工程师高效协同。
4. 基于数据与用户行为，持续优化 Agent 的记忆、规划与工具调用能力。
5. 跟踪 AI 协作工具行业动态，完成竞争分析与机会判断。

我们希望你

1. 本科及以上学历，专业不限，3-8 年产品经验。
2. 对 AI Agent 有实践经验，能独立“Vibe Coding”。
   不要求系统级工程能力，能够用 AI 工具快速跑通可演示的产品逻辑。
3. 有生产力工具（任务/项目/文档协作）或团队协作 SaaS 的产品经验。
4. 对用户工作流有强烈同理心，极简主义产品审美，结果导向。

加分项

1. 曾在 Linear、Notion、Slack 等团队或生态工作过。
2. 有创业经历（联合创始人、0-1 产品负责人）。

寻途未来已完成由头部基金领投的两轮融资，资金将主要用于大模型能力的深度研发、产品生态拓展及海外市场布局，进一步夯实公司在「AI + 深度知识工作」领域的技术与产品领先地位。

未来，寻途未来科技将继续坚持“用 AI 改变获取知识和认知的方式”的理念，探索人工智能与知识生产方式的深度融合，推动知识工作效率与创造力的革新，为全球用户提供值得信赖的智能化解决方案。

## 匹配判断

### 匹配点

- 这条岗位把“AI 产品经理”与“自己能上手做原型”结合得很清楚，是很有代表性的一类样本
- 它比 Builder 岗更强调产品定义、用户工作流和交互设计，适合和前面的 Builder 样本做分层对照
- 它明确把 Vibe Coding 写进主要求，说明产品岗也开始被要求具备更强的原型交付能力
- 它的公司语境是 AI Native 知识工具，对知识工作、协作工具和心流体验有强烈偏好

### 缺口

- 需要后续观察这类“AI Native 产品经理”岗位在市场中占比有多高
- Linear、Notion、Slack 这类加分项更偏某种产品文化，不一定是普遍门槛
- 岗位描述带有较强公司风格，需要和更传统公司样本区分开看

### 风险

- 这条 JD 容易让人误以为是纯产品岗，但其实对上手能力要求很高
- 它的“极简审美、结果导向、AI Native 团队文化”有明显主观筛选色彩
- 因为公司定位较鲜明，这类样本在综合分析时要防止风格偏差带来的误判
