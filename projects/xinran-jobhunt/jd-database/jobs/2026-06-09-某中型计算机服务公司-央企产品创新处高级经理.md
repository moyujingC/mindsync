## 文字版 JD

岗位职责：

1. 产品营销策略规划，结合市场需求与竞争环境，制定公司产品、品牌策略及销售渠道管理，组织营销活动，统筹六大产品服务线（物流数据服务 / 行业云服务 / 供应链解决方案 / 细分领域 IT 应用 / 多式联运数智化 / 生态运营）的市场布局；
2. 负责集团内外部数据资源整合，设计数据产品化路径；
3. 推动前沿技术与物流场景的结合，确保产品需求精准传递；
4. 与数据资源侧、技术侧、场景侧合作，构建产品落地生态；
5. 定义核心指标，建立产品价值量化评估体系，促进产品孵化；
6. 完成领导交办的其他工作任务。

任职条件：

1. 大学本科及以上学历（具备相应学位），计算机、数据科学专业硕士研究生及以上学历优先；
2. 具有 3 年及以上相关岗位工作经验，具备数字科技创新公司和国内外知名物流供应链公司从业经历；
3. 具有数字化产品管理、市场营销等专业知识和实战经验，具备物流供应链港航、口岸、航空、公路等行业应用场景的数字化解决方案能力，产品、销售、实施经历，有过带团队和项目实施经验；
4. 具有较强的产品管理能力、突出的合作拓展能力；
5. 具有较强的团队协作精神、综合协调能力、语言沟通能力、抗压能力和责任意识。
