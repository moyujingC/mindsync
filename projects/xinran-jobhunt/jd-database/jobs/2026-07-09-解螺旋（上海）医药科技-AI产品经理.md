## 文字版 JD

### 岗位职责

1. 负责 AI Agent 工具的 0-1 产品设计与落地，独立完成需求分析、产品方案设计及迭代优化。
2. 利用 coding 能力直接参与 AI 工具开发与原型验证，懂代码、能落地。
3. 每周至少产出 1 个可使用的 Agent 工具，快速验证产品想法。
4. 深入业务场景、挖掘用户痛点，推动 AI 工具在产品流程中的实际应用。
5. 跟进项目进度，协调研发、设计等资源，确保按时高质量交付。

### 任职要求

1. 2 年以上产品经理经验，有完整产品从 0 到 1 经历。
2. 6 个月以上 Python / JavaScript 等 coding 经验，能读懂代码、参与开发。
3. 有 0-1 Agent 项目经验，熟悉 LLM / Agent 框架优先。
4. 大厂背景优先；有头部互联网公司产品经验者加分。
5. 逻辑、沟通和独立推动能力强。
6. 有 AI 工具实际使用经验和产品 sense，不只停留在了解层面。

## 匹配判断

- 匹配点：Agent 原型、Vibe Coding、0-1 产品验证和跨资源推进与现有实践贴近。
- 缺口：需要用可运行原型和代码参与证据回应“每周一个可用 Agent”的高强度要求。
- 市场信号：AI 产品经理继续向 Builder（构建者）和快速原型能力靠拢。
