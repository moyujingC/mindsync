上海阶跃星辰智能科技正在招聘。

岗位：AI Coding 产品经理（模型方向）

城市 / 薪资 / 年限 / 学历：上海 / 35-50K / 经验不限 / 本科

岗位定位：

负责 AI Coding 场景下的模型能力产品化，深入理解前沿大模型在代码生成、推理、理解等方面的能力边界，定义模型能力到编程产品的转化路径，推动模型持续进化以满足开发者真实需求。

主要职责：

- 模型能力产品化：与研究团队协作，判断模型在编程场景的能力边界，定义哪些能力可产品化、哪些需继续投入，将用户痛点转化为模型优化目标。
- 模型评测与迭代：建立编程场景评测体系（evals），持续跟踪模型表现，对比竞品模型差异，驱动模型能力迭代。
- 研究到产品的桥梁：拉通研究与工程团队，定义模型能力的对外呈现方式（API / 产品交互 / 默认行为），协调研究进度与产品节奏。
- 行业洞察：跟踪 AI Coding 竞争格局，前瞻性规划产品方向，探索编程之外的相邻场景拓展。

任职要求：

必须具备：

- 3 年以上产品经验，其中至少 1 年工程师经历。
- AI 技术理解，熟悉大模型的训练、评测、推理等基本原理。
- 日常深度使用 AI Coding 工具，对模型能力有 hands-on 体感。
- 能在模糊场景中从矛盾反馈里提炼优先级，推动决策。

优先考虑：

- 做过模型评测体系设计或 AI benchmark 相关工作。
- 有 Developer Tools、IDE、CLI 等开发者产品经验。
- 能用 Claude Code 等 AI 工具做原型验证。

## 职责拆解

- 这条不是普通 AI 应用产品岗，而是模型能力和开发者产品之间的桥梁。
- 核心职责是把模型能力边界翻译成产品能力、API 行为、交互默认值和评测指标。
- `evals`（模型评测）是岗位中心任务之一，要求能把开发者痛点转化为可重复测试的模型优化目标。
- 需要同时理解研究团队、工程团队、产品节奏和开发者真实需求。

## 任职要求拆解

- 需要有 AI Coding 工具的高频使用体感，最好能讲清 Claude Code、Cursor、IDE 插件或 CLI 的具体差异。
- 需要理解大模型训练、评测、推理这些基本概念，但不要求算法研究员深度。
- 工程师经历是硬性信号，至少要能证明自己长期与代码、工程工具和开发流程打交道。
- 模糊问题优先级判断很重要，因为模型反馈经常是矛盾的：有些来自模型能力，有些来自产品交互，有些来自用户预期。

### 需要补足的证据
