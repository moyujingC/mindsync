### 职位详情

把 AI 塞进 IP 宇宙里。

起点 / 网文内容生态 / 漫剧与短剧 / IP 衍生 / 海外业务 / Agent 产品化。

这里不是“找一个人维护 AI 功能”，而是希望找到能把 AI 变成业务增长引擎的人。阅文有大量 IP，AI 正在重塑 IP 改编链路。

你可能会参与：

- 网文到漫剧 / 短剧的 AI 改编流程
- 分镜、脚本、角色设定、视觉风格的产品化
- 内容生产工具链设计
- AI 与人类创作者协同机制
- IP 资产库和角色资产管理
- 面向制作、运营、发行的效率工具

我们不是要做“AI 一键生成爆款”的幻觉产品。我们要做的是：把一个好故事变成更多形态、更高效率、更可规模化的内容产品。

### 海外业务方向

让中国故事更好地走向海外。海外业务是重点方向。

你可能会做：

- 多语言翻译与本地化产品
- 海外用户内容推荐与增长工具
- 面向不同文化市场的内容理解系统
- AI 辅助海外运营、投放、用户洞察
- WebNovel 等海外业务场景下的 AI 产品创新

这不是简单翻译。真正的问题是：一个中国故事，如何被不同国家、不同文化、不同用户真正看懂、喜欢，并愿意持续消费。

### Agent 方向

我们非常关注 Agent，但不迷信概念。

你可能会探索：

- 作者 Agent
- 编辑 Agent
- 运营 Agent
- IP 改编 Agent
- 海外本地化 Agent

### 任职要求

你不一定来自大厂，也不一定必须是传统内容行业背景。

但我们希望你具备：

- 对 AI 产品有真实使用经验，不只是只看过几篇文章
- 理解大模型、Agent、多模态、RAG、工作流等基本概念
- 能把技术能力翻译成业务价值
- 对内容、小说、漫画、短剧、IP、海外市场至少有一个方向真的感兴趣
- 有产品 sense，知道什么是“用户真的会用”
- 有项目推进能力，能从模糊问题推进到上线验证
- 不怕脏活，愿意钻业务流程、数据、用户反馈和真实场景

如果同时具备以下特质，会非常加分：

- 自己深度使用 AI 工具
- 做过内容产品、创作者工具、社区、推荐、增长、商业化
- 做过 AIGC、多模态、Agent、AI 工作流产品
- 熟悉网文、漫画、短剧、游戏、潮玩、IP 衍生任一领域
- 有海外产品、本地化、全球化增长经验
- 能写清楚需求，也能和算法、工程、业务团队一起打仗

## 匹配判断

### 匹配点

- 薪资 35-45K，明确高于当前月薪 2 万+ 目标，值得作为 P0 主投样本。
- 岗位不强制大厂和传统内容行业背景，给非行业原生候选人留了入口。
- 你的 AI 产品、Agent / Workflow（工作流）、知识库 / RAG、复杂流程拆解和咨询式需求诊断，能对应“把技术能力翻译成业务价值”。
- 曼陀罗 AI 解读、内容/研究系统、个人 IP 和作品集叙事，可以支撑“内容理解 + AI 产品化 + 用户场景”的切入。
- 早期游戏研发经历可以轻量连接 IP、互动内容、角色/任务系统和复杂生产流程。

### 缺口

- 没有直接的网文、阅文生态、IP 改编、短剧或海外内容运营经验。
- 没有明确的 WebNovel、海外本地化、推荐增长或内容商业化项目事实。
- 内容行业语境需要快速补齐，尤其是作者、编辑、运营、IP 改编、海外发行之间的工作流。

### 风险

- 如果面试官强看内容行业经验，可能会被认为行业理解浅。
- 岗位可能更偏内容产品 / 增长工具 / 海外业务，而不是通用 AI 产品平台。
- 若只讲 Agent、RAG、工作流等技术词，容易显得脱离内容业务。

### 建议定位

不要把自己包装成“网文行业候选人”。更稳的定位是：

> 我不是传统网文行业背景，但我关注的是内容业务里的 AI 产品化：如何把创作、改编、翻译、本地化、推荐、运营这些流程拆成可被 Agent、工作流和 RAG 支持的产品能力。我过往经历更偏技术、咨询和 AI 产品实践，适合从流程诊断、工具设计和业务落地角度切入。

### 开聊 / 面试追问方向

- 内容生产效率：作者、编辑、运营在哪些环节最耗时？
- IP 衍生：网文到短剧 / 漫画 / 海外内容时，哪些信息需要结构化复用？
- 海外本地化：翻译之后，怎么判断当地用户真的看懂、喜欢并持续消费？
- Agent 产品化：作者 Agent、编辑 Agent、运营 Agent 分别应该解决什么具体任务，失败后谁接管？

## 市场信号

- 内容平台正在把 AI 从“生成工具”推向“IP 改编链路、内容生产链路和海外增长链路”。
- Agent 在内容行业的落点不是抽象助手，而是作者、编辑、运营、改编、本地化等明确角色。
- 企业更关注“AI 是否能进入业务增长引擎”，而不是单点 AI 功能。
- 这条样本应归入 `内容/IP AI 产品 + Agent 产品化 + 海外本地化` 观察桶。
