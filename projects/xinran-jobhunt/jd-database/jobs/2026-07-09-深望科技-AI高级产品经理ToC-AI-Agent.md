## 文字版 JD

负责公司 AI 医疗 Agent 的 App、小程序、H5 等 C 端产品规划设计和生命周期管理；研究用户在诊疗、用药、复诊、健康管理和长期康复中的真实需求，持续优化用户体验与长期留存；负责 AI Agent 能力建设，包括 LLM、数据反馈闭环、算法评测、Prompt 与工作流设计、知识库和记忆机制；推动算法、工程、数据、医学、运营团队协同；建立评估体系并以数据驱动迭代；关注医疗合规、隐私、医疗安全及 AI 风险控制。

要求本科及以上、六年以上互联网产品经验；有完整 C 端产品和独立复杂产品模块经验；有医疗服务、健康管理、慢病管理等经验优先；具备 AI 产品或 AI Agent 实战，熟悉 LLM、RAG、知识图谱、Prompt Engineering、Tool Use / Function Calling；有 0-1、AI Copilot、健康助手、多智能体或 Workflow 经验优先。
