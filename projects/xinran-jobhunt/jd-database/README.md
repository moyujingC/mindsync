# JD 数据库

这个目录是 `馨冉求职` 的岗位输入层。

目标很直接：把你发来的岗位截图，沉淀成结构化岗位卡，再反过来指导三版简历怎么改。

## 目录

- `index.yaml`
  - 岗位总索引，方便快速筛选和汇总
- `jobs/`
  - 每个岗位一份独立记录
- `templates/`
  - 模板文件

## 你怎么用

你只需要做一件事：

- 看到喜欢的岗位，截图发给我

我会负责：

1. 从截图里提取岗位信息
2. 新建岗位卡到 `jobs/`
3. 更新 `index.yaml`
4. 输出这条岗位对应的简历优化建议

## 岗位卡命名规则

建议格式：

```text
YYYY-MM-DD-company-role-short-id.md
```

例如：

```text
2026-06-08-byte-ai-pm-b001.md
```

## 状态字段约定

- `new`：刚录入，未分析完成
- `parsed`：岗位信息已整理
- `analyzed`：已完成简历映射和建议
- `archived`：已过期或不再跟进

## 简历轨道字段约定

- `ai-pm`
- `ai-consulting`
- `fde`

## 我们后面怎么用这些数据

单条岗位用于：

- 判断投递价值
- 选哪版简历
- 给出定制修改建议

多条岗位累积后用于：

- 提炼高频关键词
- 看市场对你的真实要求
- 找出三版简历共同缺口
- 决定作品集和自我介绍优先补什么
