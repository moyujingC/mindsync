## 二之二、本人自述的「切入模式」（主线素材，本次新增）

本人对自己职业路径的概括（原话提炼）：**每次进入新领域都是从技术岗位切入，再转向更靠近"决定做什么"的角色**——

- 实艺：入职时是**资深程序员带初级程序**，项目来了才有机会转制作人；
- 镜月：是**通过技术切进 APP 开发行业**的，但技术只是入口，真实目的是做产品经理；
- 现在切入 AI：同样是用技术技能切进去。

本人原话判断：「虽然很多年没写过程序，但以这段时间的情况看，我觉得我是可以做一个程序员的——程序的底子、技术的基本功还在。」

**可用表述（简历/面试）**：技术是入场券，不是终点；进新领域靠技术落地，站稳后转向产品与决策。这正好对应 AI 应用工程师 / FDE 需要的"既写代码又做判断"。

## 二之五、转型决策链：房产 → 疗愈 → 曼陀罗 → AI（2026-09-25 本人回答）

**为什么离开房产 → 转疗愈 → 选曼陀罗 → 用 AI（只留结论）**

- **离开房产**：行业下行、赛道没落；房产一做 5 年，退出是被动。
- **主动交代的失败（面试可讲，简历不写）**：房产下行这一波**自己也亏了不少钱**。归因为两点——① 能力跟不上欲望；② 当时对世界没有系统认知，容易被自媒体信息带着走、失去判断力。
- **转疗愈（对外口径）**：40 岁前后形成稳定的长期兴趣方向——**第一次觉得有一件事可以做一辈子**（对中国传统文化、宇宙观的系统性兴趣）。不写具体经典、不写心灵体验。
- **为什么是曼陀罗（三条，可直接讲）**：① 足够根本；② **一个工具能覆盖完整个案流程**（觉察 → 接纳 → 释放 → 整理 → 清理 / 显化）；③ **入门快，适合逻辑脑**。
- **为什么是 AI（可直接讲的时间线判断）**：本人是 AI 重度使用者、工具控，AI 让他从量变到质变、拓展出新能力；2024.01 上知乎《AI 全栈工程师》课程（当时技术明显不成熟）→ **2025 年中判断 Agent 时代要来** → **2025 年底判断 AI 可以在企业落地**；期间**靠 AI 把编程捡了回来**，因此转入该行业。

## 二之六、稳定性事实核对（2026-09-25 本人纠正 · 重要）

**本人纠正**：外界看是"频繁跨行"，但**绝大多数变动不是主动跳槽**，而是外部事件：

| 节点 | 性质 | 说明 |
| --- | --- | --- |
| 昱泉国际（2008–2009） | **被动** | 金融危机叠加公司被收购，大规模裁员 |
| 维塔士（2009–2012，约 3 年） | 主动离职 | **已待满 3 年**才主动离开 |
| 笑游（2012–2013） | 主动离职，但**属人生中断** | 当时面临"是否移民"的重大决策 |
| 实艺（2013–2014） | **被动** | 创业项目失败 |
| 镜月（2014–2016） | **被动** | 创业项目失败 |
| 自由职业（2016–2017） | 主动 | 项目制，本就短期 |
| 友邦（2017–2019） | 主动转赛道 | 进入房产 |
| 房产（2019–2024，5 年） | **被动** | 行业下行、赛道没落 |

**结论（可直接用于回答"稳定性"质疑）**：8 次变动中**只有 2 次是主动跳槽**（维塔士且已满 3 年、笑游且因移民决策中断），其余 6 次是裁员、项目失败、行业下行。**不是一天一个想法，是每次都被外部事件推着走，且每段都做满了事。**

**结论（对外唯一口径）**：不是一天一个想法——8 次变动里 6 次由外部事件造成（裁员 / 项目失败 / 行业下行），2 次主动（维塔士已满 3 年；笑游因家庭移民决策中断），房产一做 5 年。用事实表回答稳定性质疑。

> 修正：笑游 → 实艺的**离职**原因 = 面临是否移民的重大决策导致中断；此前记录的"项目管理转制作人"是**角色**变化，不是离职原因。
