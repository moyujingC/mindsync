### 3.2 旧版 To C（web.jingshu.cc）

**演进三段式**：

1. **阶段一（2026.02）**：Lovable 快速验证 v1。因文档过时导致 AI 生成频繁出错、UI 移植失败，主动报废；沉淀原则「文档必须成为 AI 的一等事实源」。
2. **阶段二（2026.03）**：独立仓 ai-mandala 两周重写，**183 commits**（GitHub 公开可查 moyujingC/ai-mandala）。FastAPI 后端 + 面向普通用户和疗愈师的两个前端；可沉淀可检索的五行解读知识库（20 种失衡类型、三环框架）；specs/ 决策记录；国产模型五维测评框架；CI/CD 三环境（开发 / 预发布 / 生产）；按风险分 5 级的安全协议。
3. **阶段三（2026.04 至今）**：迁入 MindSync Monorepo（projects/aimandala）。建立六阶段交付门、golden case 回归验证，并把"视觉草稿 → 议题报告"两段式端到端链路接入线上 API 主链；具备夜间自动冒烟测试与受控自动修复能力；web.jingshu.cc 持续内测。

**模型与质量**：

- 文字模型 DeepSeek V4；视觉模型 qwen-vl-max（豆包兜底）；候选模型 GLM 经 9 张测试图 × 3 轮重复生成的稳定性评测后淘汰。
- 两段式生成链路：先让视觉模型把画作转成自然语言"画面事实描述"，再让推理模型按议题生成解读（直接输出结构化 JSON 会丢失画面细节，故改用自然语言并保留 A/B 对照）。
