## 面试追问草稿

1. 如果问“你怎么判断一个业务问题该用 Agent、工作流、低代码还是流程重构”：按 `问题频率 -> 人工成本 -> 错误风险 -> 数据/权限条件 -> 可验证收益 -> 维护成本` 回答。
2. 如果问“AI 产品不是只写方案，你怎么推进落地”：回答 `先做可试用原型，再设验收指标，拉真实业务用户试用，记录失败案例，补培训和 SOP，最后用节省时间、错误率、采纳率验证`。
3. 如果问“FDE 怎么处理客户现场需求不清”：按 `业务目标 -> 角色流程 -> 现有系统/数据 -> AI 可做与不可做 -> PoC 范围 -> 验收指标 -> 上线兜底` 回答。
4. 如果问“human-in-the-loop 是什么”：用通俗说法，`不是让 AI 全自动，而是在高风险、低置信度或异常分支保留人工确认点`。
5. 如果问“为什么企业 AI 岗位反复提 Dify / Coze / n8n”：回答 `这些工具降低了从想法到原型的成本，但真正难点是业务流程、权限数据、评测指标和持续维护`。
