## 背景

本次写简历，目标是做一份"中文主简历母版"，用于后续按 JD 裁剪成定制版本。

过程中发现 AI 辅助写简历的效果不如写 PRD/SDD/TDD 好，原因是写简历需要先把自己的叙事想清楚，而这个没法由 AI 代劳。

本次讨论的目的是先把"简历逻辑"想清楚，再逐段落实具体措辞。

---

## 一、为什么之前 AI 写的简历不满意

### 核心问题

写简历和写产品文档的差异：

- **产品文档**：你先把思考做完，AI 帮你翻译成结构化文档 → 结果质量好
- **简历**：你自己还没把"我是谁"的叙事想清楚，AI 在真空里写 → 结果像 JD 语言

### 17年资深职场人的困境

- 内容全面 → 每段只能高度概括 → 没有细节，不打动人
- 写细节 → 篇幅不够 → 只能选几段写
- 压缩粒度和影响力表达之间有矛盾

### AI 写简历的常见问题

1. 默认用"JD 语言"写，而不是"成就语言"
2. 写出来的像职位描述（负责XXX、实现YYY），而不是你在过程中的独特贡献
3. 各能力模块之间容易出现重复，翻来覆去讲同一件事
4. 听起来像"自吹自擂"

---

## 二、简历结构调整的核心思路

### 从"时间线简历"转向"能力简历"

原来习惯：按时间线平铺每段经历，每段3行 → 结果是"看起来像JD"

新思路：按能力主线组织，每段只讲清楚一件事，不重复。

### 去能力模块，让能力长在故事里

原来结构的问题：
- 能力模块单独列出，每个配1个锚点
- 锚点之间容易重复
- 容易像"自吹自擂"

新思路：
- 不单独提炼能力标签
- 直接写"做了什么、沉淀了什么"，让读者自己得出结论
- 同一件事不在两个地方同时提

### AI方向实践前置

调整后的结构：
1. 一句话定位（1行）
2. AI方向实践（前置，说明当前在做什么）
3. 工作经历（时间倒序）
4. 教育背景（1行）

## 三、核心能力定义

### 四个核心能力（内在一致的工作模式）

> 能定义问题——不是拿到已知问题去解，而是先搞清楚真正要解决的是什么
>
> 能跨越边界——技术懂一些、业务懂一些、能做翻译、能把东西推进落地
>
> 能建立信任——在复杂场景中让人愿意把真实需求告诉你
>
> 能把经验产品化——不只自己会做，还能沉淀成可复用的流程或产品

这四个能力不是并列的标签，而是一个连贯的工作方式的四个维度。

### 技术底座 + 快速学习

- 有扎实的技术基础
- AI时代看的不是过去会什么、现在会什么，看的是能不能持续快速学习
- 而且要围绕解决问题有效学习，不是为学而学

## 四、什么是"复杂高信任场景"

### 核心特征

1. 问题非标准、复杂，没有通用答案
2. 需要较深的信任关系才能推进
3. 方案必须定制化，不能套模板
4. 决策后果重大（金额大、影响深）

典型例子：医疗、法律、高端理财、房产、疗愈、教育咨询

### 项目经理 vs 制作人的区别

**项目经理（笑游）：**
- 搭流程、搭工具、推动协作
- 角色本质：**协作的基础设施**

**制作人（狮蚁）：**
- 负责进度规划、任务分派、会议主持、招募
- 选定美术方案、技术方案
- 主导项目方向，不只是保证项目交付
- 团队在上海+西安两地，有异地协作
- 角色本质：**项目全局责任人**

制作人还有一个独特的点：项目经理可以只做"执行层面的推动"，但制作人要在"做什么、怎么做、谁来做"上做取舍——这意味着要有创作判断，而不只是管理判断。这段经历让你"第一次产生创业念头"，不是偶然的——制作人的角色让你第一次站在了"全局视角"上。

- **早期（游戏程序员）**：不是纯技术执行，而是处于"技术、美术、策划、测试"四方协作的核心——天然的跨角色协作场域，只是以交付为主
- **中期（项目经理/制作人）**：从"参与协作"转向"推动协作"，再到"全局责任人"
- **近期（房产/保险/疗愈）**：协作对象变成客户，变成信任关系主导

所以"跨越边界"的能力，根比原来想的更深——不是后来习得的能力，是一直都有，只是形态在变。

## 五、六边形战士的边界意识

### 承认有能力，但也有边界

- 我确实有多个能力，但精力有限
- 即便能干，我也不会都自己干
- 要和人合作，要有团队效果

这不是弱点，而是成熟度的体现。

### 协作能力的底座

六边形战士的价值，不是自己干所有事，而是：
- 有能力支撑协作（能听懂各方的语言）
- 有能力推动协作（能把多方整理成可推进的动作）
- 有能力沉淀协作成果（能把经验变成可复用的方法）

## 六、AI时代的价值思考

### 核心洞察

**AI时代的价值转移：execution（执行）的价值在下降，judgment（判断）的价值在上升。**

AI擅长：写代码、做分析、生成内容、识别模式 — 这些都是"执行"

AI不擅长：
- 定义边界模糊的问题
- 在复杂敏感场景中建立信任
- 理解真实的人、真实的顾虑
- 在多方利益冲突中推动决策

### 企业真正稀缺的人

1. **能定义问题**——不是拿到已知问题去解，而是先搞清楚真正要解决的是什么
2. **能跨越边界**——技术懂一些、业务懂一些、能做翻译、能把东西推进落地
3. **能建立信任**——在复杂场景中让人愿意把真实需求告诉你
4. **能产品化**——不只自己会做，还能沉淀成可复用的流程或产品

这四点恰恰是 AI 不擅长、但你有的能力。

### 你的竞争力来源

- 不是在学 AI 用什么工具
- 而是有真实经历验证过的判断力
- 这类能力是 AI 很难替代的

## 九、核心能力六边形模型

### 六边形能力图（最终版）

```
┌─────────────────────────────────────┐
│                                     │
│              解决问题               │  ← 目标
│                                     │
│         跨界协作  建立信任           │  ← 做事方式
│                                     │
│    技术底座    快速学习    产品化    │  ← 基础能力
│                                     │
└─────────────────────────────────────┘
```

### 逻辑层次

- **基础能力**（底层）：技术底座、快速学习、产品化
- **做事方式**（中层）：跨界协作、建立信任
- **目标**（顶层）：解决问题

### 说明

- "解决问题"覆盖了"先搞清楚真正要解决的是什么"这个关键点
- "跨界协作"替换原来的"跨越边界"——强调多方协同和翻译能力
- 这六个能力构成一套连贯的工作模式，而不是散落的标签

### 能力观版本

能定义问题、跨越边界、建立信任、把经验产品化；有技术底座，快速学习，当前正把这些能力落地到AI方向。

### 三个方向微调

- AI产品经理：强调"定义问题+产品化"
- AI解决方案架构师：强调"跨越边界"
- AI转型咨询顾问：强调"建立信任"
