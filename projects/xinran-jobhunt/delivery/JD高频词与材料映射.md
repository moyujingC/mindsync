# JD 高频词与材料映射

> 状态：持续维护  
> 首版日期：2026-07-06  
> 项目：馨冉求职  
> 用途：把 JD 数据库、每日岗位筛选、猎头岗位、平台竞争力分析和面试反馈里的共性信号，转成可执行的材料迭代依据。  
> 维护原则：单条 JD 不直接改主材料；同一信号连续出现在 3-5 条 JD、猎头反馈或面试反馈中，再进入材料审核。
> 最近更新：2026-07-06，吸收 2026-07-01 至 2026-07-06 每日筛选信号，并记录已触发的材料动作。

## 1. 当前结论

招聘方现在筛的不是“会 AI”这个泛标签，而是能把 AI 放进真实业务流程、做出可验证交付的人。当前最值得持续维护的能力表达是：

> 进入业务场景，识别可被 AI 改造的流程，设计 Agent / RAG / Workflow 方案，推进 PoC / MVP / Demo，建立知识库、评测口径、质量门和安全边界，并把结果沉淀为可复用方案、SOP、培训材料或交付文档。

这句话拆成 8 组高频信号。

| 优先级 | 高频信号 | 典型 JD 语言 | 材料映射 |
|---|---|---|---|
| P0 | `Agent / 智能体 / Workflow / Multi-Agent` | Agent 解决方案、智能体落地、工具调用、工作流编排、人机协同 | 在线简历母版、AI 产品经理版、FDE 版都要显性保留 |
| P0 | `业务场景 / 客户需求 / 客户现场 / 流程改造` | 客户需求澄清、业务痛点、业务流程、客户现场、行业解决方案 | 房产咨询、保险、FDE、AI 转型咨询表达都要承接 |
| P0 | `PoC / MVP / Demo / 原型验证 / 0 到 1` | 可演示原型、PoC 方案、MVP 验证、技术验证、试点落地 | 曼陀罗 AI 产品、MindSync、早期工程经历都可承接 |
| P0 | `RAG / 知识库 / 数据治理 / 结构化知识` | 企业知识库、检索增强生成、数据流、知识底座、项目知识库 | MindSync、Prompt Pack、报告知识层、SOP / 知识库 |
| P1 | `评测 / 质量门 / Guardrails / 安全边界` | 评估体系、质量标准、自动化评测、护栏、上线后监测 | 曼陀罗项目和 MindSync 已能承接，后续可继续补证据 |
| P1 | `方案设计 / 售前 / 交付 / 验收` | 方案 PPT、技术方案书、投标文件、客户答疑、验收指标 | FDE 版、AI 转型咨询顾问版、猎头版优先承接 |
| P1 | `培训赋能 / SOP / 组织推广 / AI 工具采用` | 产品培训、Workshop、使用规范、内部推广、案例库 | 房产经纪人孵化体系、MindSync、组织知识库承接 |
| P2 | `行业 AI 转型 / 垂直行业 AI` | 医疗 AI 转型、制造业 AI 升级、消费品企业 AI 产品化 | 先作为观察和面试练习，暂不重写主叙事 |

## 2. 阶段更新：6/13 结论与 7 月新增信号

### 2.1 6/13 仍然有效的判断

6/13 的核心判断没有失效：招聘方筛的不是泛泛“会 AI”，而是能把 AI 放进真实业务流程、做出可验证交付的人。下面几组关键词仍是主线：

- `Agent / 智能体 / Workflow / Multi-Agent`
- `业务场景 / 客户需求 / 客户现场 / 流程改造`
- `PoC / MVP / Demo / 原型验证 / 0 到 1`
- `RAG / 知识库 / 数据治理 / 结构化知识`
- `评测 / 质量门 / Guardrails / 安全边界`
- `方案设计 / 售前 / 交付 / 方法论沉淀`

## 3. 已连续增强的信号

来源：

- 6 月 JD 数据库中已反复出现 `Agent`、`Workflow`、`AI Native`、`AI Builder`、`智能体应用`。
- 7 月每日筛选中继续出现金融 Agent、广告 Agent、NoCode / CatPaw、企业级 Agent 解决方案、通信场景智能体落地。

材料动作：

- AI 产品经理版：继续强调“不是聊天机器人，而是任务流程、产品路径和评测闭环”。
- 作品集：后续如果要补证据，优先解释曼陀罗项目里的报告追问边界和 MindSync 的 Agent 协作机制。

面试追问：

### 3.2 评测、质量门与持续迭代

### 3.3 ToB AI 产品、解决方案与 FDE 交付

## 5. 材料修改触发规则

### 5.1 应该进入材料审核

- 同一信号在 2-3 天内连续出现，并且跨公司、跨来源重复。
- 同一信号已经出现 3-5 条以上，并且当前简历没有明确承接。
- 猎头或 HR 明确指出某个表达影响推荐。
- 面试中对方反复追问某个项目，但作品集或简历没有证据承接。
- 平台竞争力分析持续低估某项能力，且岗位本身确实匹配。

### 5.2 暂不改主材料

- 只有一条 JD 的个性化要求。
- 来源只是摘要页、聚合页或猎头列表，完整 JD 未核实。
- 岗位明显偏算法、纯销售、纯传统项目经理或高管负责人。
- 修改会造成项目事实夸大。
