## 面试追问草稿

1. 如果问“你怎么把专业工作流做成 AI Agent 产品”：按 `用户角色 -> 原始流程 -> 高价值痛点 -> 数据 / 知识来源 -> RAG 或 Agent 流程 -> 原型 -> 评测指标 -> Demo / ROI -> 上线反馈` 回答。
2. 如果问“RAG 和 Agent 在专业知识产品里怎么分工”：通俗说，`RAG 负责把可信资料找回来并引用，Agent 负责把多步任务串起来，例如检索、比较、生成草稿、检查风险和交给人确认`。
3. 如果问“没有 IP 行业经验怎么办”：回答 `不包装成专利专家，而是强调复杂知识工作流拆解、用户访谈、知识库 / SOP 沉淀、AI 产品原型、评测和跨团队推进能力；行业细节需要入职后与专家共创`。
4. 如果问“AI 产品怎样证明业务价值”：用 `adoption（采用率）/ time saved（节省时间）/ accuracy（准确率）/ human handoff（人工接管）/ repeat usage（复用）/ revenue influence（收入影响）` 组织回答。
5. 如果问“Responsible AI guardrails 是什么”：通俗说，`不是让模型更保守，而是定义哪些内容必须引用来源、哪些步骤要人工确认、哪些输出要拒答或降级处理`。
