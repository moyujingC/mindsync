## 面试追问草稿

1. 如果问“你如何把解决方案团队的需求转成产品需求”：按 `业务场景 -> 用户角色 -> 流程断点 -> 数据/知识输入 -> AI 可做边界 -> PRD -> 原型 -> 上线评估` 回答。
2. 如果问“Agent 和 Workflow 有什么区别”：用通俗说法回答，`Agent 更像会调用工具和做多步决策的执行者，Workflow 更像把步骤、责任和质量检查固定下来的流程骨架`。
3. 如果问“你怎么做 AI 产品评测”：用 `业务指标 + 使用指标 + 质量指标 + 风险指标` 四层回答，例如效率、采纳率、准确率、人工兜底率、异常率。
4. 如果问“为什么适合 FDE / 解决方案顾问”：重点讲 `业务流程拆解、可运行原型、客户语言到技术语言的翻译、交付闭环`，不要包装成纯算法或纯销售。
