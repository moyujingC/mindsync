这里是 `mindsync` Monorepo 中各项目的工作区入口。

每个项目目录都应有自己的 `PROJECT.md`，并与 `company/projects/<项目名>/` 形成双入口：

- `company/projects/<项目名>/`
  - 公司视角的项目定位、研究、纪要、内容资产
- `projects/<project-slug>/`
  - 项目视角的实现、需求、脚本和交付
