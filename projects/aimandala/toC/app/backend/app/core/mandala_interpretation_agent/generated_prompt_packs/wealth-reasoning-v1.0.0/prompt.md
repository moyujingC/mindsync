本文把曼陀罗基础层信号翻译成财富关系议题语言。当前是人工审核用总表，不直接作为 runtime 规则表。

## 1. 字段说明

| 字段 | 说明 |
|------|------|
| 基础信号 | 来自曼陀罗基础层的画面、五行、跨圈或组合模式信号。 |
| 基础状态含义 | 不带财富关系主题时的状态解释。 |
| 财富关系翻译 | 进入财富关系议题后的解释方向。 |
| 候选财富条款 | 可映射的财富条款。 |
| 报告位置 | 建议进入报告的段落。 |
| 表达边界 | 必须避免的结论。 |

## 2. 颜色与五行信号

| 基础信号             | 基础状态含义                 | 财富关系翻译                           | 候选财富条款                                                                                | 报告位置         | 表达边界                     |
| ---------------- | ---------------------- | ------------------------------ | ------------------------------------------------------------------------------------- | ------------ | ------------------------ |
| 外圈红色 / 火明显       | 火向外散，行动、情绪和热度外放。       | 财富能量容易被情绪、即时感受或冲动行动带走。         | `wealth.emotional_spending`、`wealth.low_action`                                       | 现实财富流动、行动与消耗 | 不写成现实漏财定论，不判断真实消费金额。     |
| 弱火多 / 淡红、粉色、淡橙明显 | 热情、行动力和被爱感偏弱，渴望回应。     | 赚钱动力可能受认可、情绪回应和自我价值感影响。        | `wealth.approval_driven_earning`、`wealth.low_action`                                  | 动力来源、价值感     | 不写成用户依赖或没有行动力。           |
| 金多 / 白色多 / 留白多   | 标准、边界、评判、切分和防御增强。      | 财富中可能表现为定价压力、证明自己、价值感紧绷或资源被切开。 | `wealth.low_deservingness`、`wealth.approval_driven_earning`、`wealth.resource_leakage` | 价值感、资源边界     | 不把金多直接写成坏事；金也可能代表执行力和边界。 |
| 土弱 / 土零散不成片      | 承载、稳定和容器感不足。           | 有机会或进账时，保存、承接和稳定使用资源的能力需要加强。   | `wealth.low_capacity`、`wealth.scarcity_and_insecurity`                                | 承载力、资源容器     | 不预测用户存不住钱。               |
| 水火相冲             | 恐惧与热情、行动与情绪之间拉扯。       | 想行动、想赚钱，但容易被焦虑、害怕损失或情绪波动打断。    | `wealth.low_action`、`wealth.emotional_spending`、`wealth.scarcity_and_insecurity`      | 行动力、情绪与财富流动  | 不写成心理诊断。                 |
| 木无根              | 有成长动力，但滋养不足、落地不足或缺少支持。 | 想发展、想突破，但机会、资源、支持或稳定节奏不足。      | `wealth.low_action`、`wealth.low_capacity`、`wealth.value_expression_block`             | 成长动力、机会承接    | 不写成用户没有能力。               |

## 3. 结构与组合信号

| 基础信号 | 基础状态含义 | 财富关系翻译 | 候选财富条款 | 报告位置 | 表达边界 |
|----------|--------------|----------|--------------|----------|----------|
| 白色割裂 / 金截断 | 标准、边界或评判把能量切开。 | 行动、热情或价值表达被外界标准、自我评判、信息压力打断。 | `wealth.approval_driven_earning`、`wealth.low_action` | 卡点机制、行动中断 | 不能只凭截断信号生成财富结论。 |
| 外圈留白多 / 外圈弱 | 对外呈现、现实连接或行动出口不足。 | 价值还没有充分进入市场、客户、合作或现实交换。 | `wealth.low_world_connection`、`wealth.value_expression_block` | 世界连接、价值表达 | 不把内向、学习或灵性倾向写成问题。 |
| 中圈缠绕 / 拉扯 / 断裂 | 情绪、人际和当下能量有纠结。 | 关系、人情、合作或认可需求可能影响价值交换和资源边界。 | `wealth.exchange_boundary_imbalance`、`wealth.receiving_and_pricing_pressure`、`wealth.emotional_spending` | 背景线索、交换边界 | 不展开成亲密关系报告。 |
| 外圈边界缺口 / 破损 | 现实边界不稳，外界影响容易进入。 | 资源保存、合作边界、付出回报和现实承接可能需要加强。 | `wealth.resource_leakage`、`wealth.exchange_boundary_imbalance` | 资源边界、现实承接 | 不判断用户真实存款、支出或债务。 |
| 外圈厚重闭合 | 防御、谨慎、保护和外部压力增强。 | 对风险、支持、合作和被看见可能比较紧，财富流动通道变窄。 | `wealth.difficulty_receiving_support`、`wealth.scarcity_and_insecurity` | 安全感、支持通道 | 不把自我保护写成问题。 |
| 碎点多 / 能量分散 | 注意力、方向或能量分散。 | 目标、行动、资源使用或价值表达较分散，需要先收束主线。 | `wealth.scattered_goals`、`wealth.resource_leakage`、`wealth.low_action` | 行动建议、目标收束 | 不替用户做职业或商业取舍。 |
| 中心清晰但外圈弱 | 内在价值或方向较清楚，但外化不足。 | 已有内在价值感或想法，但进入现实交换、市场和客户连接还不够。 | `wealth.value_expression_block`、`wealth.low_world_connection` | 价值表达、世界连接 | 不承诺市场反馈或成交结果。 |
| 画面厚重 / 过满 | 用力、负担、压力和紧绷增强。 | 财富行动可能带有辛苦赚钱、责任过重、休息不足或安全感紧绷。 | `wealth.hardship_earning_belief`、`wealth.scarcity_and_insecurity`、`wealth.low_capacity` | 深层机制、疗愈建议 | 不否定用户现实努力和责任。 |
| 色块分割明显 | 内在矛盾、取舍两难或能量不连续。 | 财富目标、行动方向或价值表达可能不够统一，需要先看清主线。 | `wealth.scattered_goals`、`wealth.low_action`、`wealth.success_visibility_threat` | 卡点机制、行动建议 | 不替用户做现实选择。 |

## 4. 跨圈状态信号

| 基础信号 | 基础状态含义 | 财富关系翻译 | 候选财富条款 | 报告位置 | 表达边界 |
|----------|--------------|----------|--------------|----------|----------|
| 内稳中顺外圆 | 内在、当下能量和现实呈现较一致。 | 财富状态较容易形成内在允许、行动承接和现实表达。 | 正向状态 | 资源与优势 | 不承诺财富结果。 |
| 内缺中乱外散 | 内在迷茫、情绪内耗、现实消耗同时出现。 | 财富关系议题可能同时牵动安全感、行动力和资源边界。 | `wealth.scarcity_and_insecurity`、`wealth.low_action`、`wealth.resource_leakage` | 核心主轴 | 不写成全面失败或严重问题。 |
| 内好中乱外稳 | 内在方向尚可，但情绪和关系层有纠结，现实仍能维持。 | 财富上可能不是能力不足，而是关系、情绪或交换边界在影响流动。 | `wealth.exchange_boundary_imbalance`、`wealth.emotional_spending` | 背景线索、卡点机制 | 不把关系线索抢成主线。 |
| 内弱中顺外强 | 内在不够自信，但人际和现实表现较强。 | 外在能做事、能承接责任，但配得感或自我价值可能跟不上现实发展。 | `wealth.low_deservingness`、`wealth.low_capacity` | 深层机制、价值感 | 不否定用户已有现实能力。 |

## 5. 使用规则

- 先写画面事实，再写财富关系翻译。
- 单一信号只作为候选解释，不能单独定性用户财富状态。
- 多个信号共同指向同一条款时，该条款可作为报告主轴候选。
- 若信号指向关系、家庭、身体、情绪，必须按 [../12-财富关系中的浮现议题回译规则.md](../12-财富关系中的浮现议题回译规则.md) 回译到财富主线。
- 所有表达都必须保留“可能、像是、从画面看起来”等缓冲语气。

## 6. 主次使用说明

本表不直接给固定权重，主次关系在报告生成时按以下方式判断：

- 多个信号共同指向同一财富条款时，该条款可作为主候选。
- 只有一个信号指向某条款时，该条款只能作为次候选或追问线索。
- 外圈信号优先落到现实行动、资源承接、价值交换和现实落地。
- 中圈信号优先落到情绪、关系、交换边界与认可压力，并回译到财富主线。
- 内圈信号优先落到配得感、安全感、允许拥有和自我价值。
- 若同一画面同时出现外圈和中圈强信号，应先写外圈财富状态，再用中圈解释其背后的情绪、关系或交换机制。

本文说明财富关系翻译条目进入报告时应放在哪个位置。它用于人工审核报告结构，也为后续结构化 routing 提供依据。

## 1. 报告模块

| 模块 | 作用 | 适合进入的翻译 |
|------|------|----------------|
| 画面依据 | 说明报告不是凭空判断，而是来自画面观察。 | 颜色、形状、圈层、五行、跨圈状态的事实描述。 |
| 财富状态总览 | 给用户一个本次财富主线的整体感受。 | 多个信号共同指向的主轴，例如承载力、行动力、资源边界。 |
| 逐圈财富解读 | 分别解释内圈、中圈、外圈在财富关系议题里的含义。 | 圈层位置明确的颜色、形状、五行和留白信号。 |
| 核心卡点机制 | 解释财富卡住的可能机制。 | 配得感、安全感、求认可、承载力、行动力、价值表达等条款。 |
| 背景线索嵌入 | 提及关系、家庭、情绪、身体等背景，但回到财富主线。用户可见报告中不单独命名为“浮现议题”。 | 中圈关系拉扯、家庭压力、情绪消费、身体收缩等信号。 |
| 资源与优势 | 说明用户已有的支持性力量。 | 内稳、中顺、土稳定、金有执行力、水有信息流、木有成长动力等。 |
| 低风险建议 | 给可执行、低压力、不替用户决策的调整方向。 | 行动收束、情绪觉察、边界练习、价值表达练习、承载力练习。 |

## 2. Lite 与 Pro 使用差异

Lite 报告：

- 只选 1 个主轴。
- 最多展开 2 个财富条款。
- 其他议题线索只作为财富机制的背景提示，不展开长链路，不单独起章。
- 建议保持低压和短句。

Pro 报告：

- 可选 1 个主轴和 1-2 个辅助线索。
- 可逐圈解释财富含义。
- 可使用 1-2 个其他议题线索解释财富机制，但标题和结论仍使用财富语言。
- 可给更细的练习方向，但不做完整疗愈课程。

## 3. 路由规则

### 3.1 进入财富状态总览

满足以下任一条件，可以进入财富状态总览：

- 至少 2 个基础信号共同指向同一财富条款。
- 同一圈层出现多个支持同一方向的信号。
- 用户明确提问与该条款一致。

### 3.2 进入核心卡点机制

适合进入核心卡点机制的信号：

- 金多、白色切分、外界标准强。
- 土弱、土零散、承载不稳。
- 水火冲突、火被金截断、行动热情不连续。
- 外圈弱、外圈缺口、外圈厚重闭合。

### 3.3 进入背景线索嵌入

适合进入背景线索嵌入的信号：

- 中圈缠绕、拉扯、断裂：关系和交换边界。
- 内圈收缩、中心空缺：自我价值和配得感。
- 厚重、过满、深色、防御：安全感和身体承载。
- 家庭、父母、责任、成功压力等用户语言。

写作要求：

- 在正文中嵌入到“核心卡点机制”“逐圈财富解读”或“低风险建议”里。
- Lite 不使用“浮现议题回译”“关系议题”“家庭议题”等用户可见标题。
- Pro 如需小标题，也使用财富语言，例如“交换边界里的关系压力”“承载力里的安全感线索”。

## 4. 禁止路由

- 单一信号不能直接进入“核心结论”。
- 关系线索不能路由成完整关系报告。
- 身体线索不能路由成健康判断。
- 财富线索不能路由成财务预测、投资建议、职业选择或商业决策。
- 来源状态不足的条目不能作为强结论，只能作为候选解释或追问线索。

## 1. 使用原则

- 先看颜色是什么，再看落在哪一圈，再看深浅、面积、留白和相邻关系。
- 同一种颜色在不同圈层的财富语义不同。
- 颜色在财富关系议题里不是单独定论，而是进入条款和报告模块的线索。
- 暧昧色、渐变色、浓重色、浅色和留白都要保留不确定性。

## 4. 白色、留白与金

| 金多 | `reviewed_case_rule` | 标准、要求、评判和证明压力强，容易影响价值感和行动持续性。 | `wealth.low_deservingness`、`wealth.approval_driven_earning` | 价值感、核心卡点 | 不否定努力和执行力。 |
| 土零散不成片 | `reviewed_case_rule` | 承载力不足，资源、责任和现实机会不容易形成稳定容器。 | `wealth.low_capacity`、`wealth.resource_leakage` | 承载力、资源容器 | 不预测存不住钱。 |
| 水火相冲 | `reviewed_case_rule` | 热情被恐惧、犹豫或情绪打断，行动力被内在冲突牵引。 | `wealth.low_action`、`wealth.emotional_spending`、`wealth.scarcity_and_insecurity` | 行动力、安全感 | 不写成心理诊断。 |
| 绿色多但偏暗 | `reviewed_case_rule` | 上进心和财富成长愿望强，但压抑、疲惫和孤军奋战感明显。 | `wealth.hardship_earning_belief`、`wealth.low_action`、`wealth.value_expression_block` | 动力来源、深层机制 | 不做身体诊断。 |
| 紫色单一且留白多 | `reviewed_case_rule` | 内在信念、灵感或学习强，但现实落地、世界连接和财富行动不足。 | `wealth.low_world_connection`、`wealth.value_expression_block`、`wealth.low_action` | 价值表达、世界连接 | 不把灵性倾向写成问题。 |
| 土生金但火克金 | `reviewed_case_rule` | 有进账、资源进入或现实价值产出，但保存和稳定承接容易被情绪、关系和冲动消耗。 | `wealth.low_capacity`、`wealth.emotional_spending`、`wealth.resource_leakage` | 现实财富流动、资源保存 | 不写成收入预测或资产判断。 |

## 4. 报告使用规则

- Lite 报告最多选 1 个组合模式作为主轴。
- Pro 报告可以选 1 个主组合和 1 个辅助组合。
- 如果组合模式与颜色、形状、圈内五行和跨圈状态共同指向同一条款，该条款优先级提高。
- 组合模式必须配画面证据，不单独输出结论。

## 5. 使用边界

- 本表只做财富关系翻译，不取代高频组合模式原文。
- 来源状态不足时，只能作为候选解释或追问线索。
- 所有财富表达都必须保留可能性，不输出财务预测、投资建议或职业决策。

## 1. 手册定位

财富关系议题不是“用户有没有钱”“能不能赚钱”的判断题。

在本知识库中，财富关系议题是一组围绕金钱、价值、资源、行动、身体、家庭和世界关系展开的复合议题。它要回答的不是“如何立刻变有钱”，而是：

- 用户如何理解金钱。
- 用户是否允许自己拥有、收取、保存和使用财富。
- 用户如何把自己的价值表达给世界。
- 用户的金钱关系背后牵动了哪些安全感、自我价值、父母关系和身体行动模式。
- 用户如何从紧绷、证明、逃离或补偿中，转向更有生命力的创造和交换。

## 2. 写作原则

财富关系议题手册按“书”的方式维护，不按 YAML 字段压缩。

写作时应保留：

- 概念展开。
- 机制解释。
- 来源差异。
- 用户语言。
- 报告表达。
- 疗愈方向。
- 风险边界。

结构化条款只抽取其中稳定、可调用的片段。

## 3. 财富报告知识地图

本节是财富关系议题 MVP 报告的内容地图。它按报告需要组织模块，不按现有电子书数量组织，也不要求每个模块现在都已完成来源回填。

状态使用规则：

- `source_supported_draft`：已有来源层材料可以支持初版表达，但还需要 review。
- `ai_draft`：当前用于搭建报告结构，不能当成来源结论。
- `source_needed`：报告需要该模块，但当前缺少足够来源，应作为后续补书和回填重点。

### 3.1 金钱本质与投射

`source_supported_draft`

报告需要先解释“钱在画面里可能承载什么”。如果不建立这个入口，财富解读容易滑向现实收入判断或理财建议。

当前来源基础：

- 《对财富说是》第一章支持“金钱承载安全、自由、尊严、爱、接纳等投射”的方向。

报告中可表现为：

- 钱不只对应收入和资产，也可能对应用户对安全、尊严、自由和被支持的感受。
- 当画面出现紧缩、断裂、遮挡或无法流动的财富线索时，可以先从“金钱承载了什么感受”进入，而不是直接判断财务能力。

### 3.2 金钱信念与无意识脚本

`source_supported_draft`

报告需要识别用户是否带着固定金钱脚本行动，例如“必须很辛苦才配赚钱”“有钱危险”“更多才安全”“钱留不住”。这些脚本会影响用户如何要钱、收钱、花钱和保存资源。

当前来源基础：

- 《对财富说是》第二章列出多类限制性金钱态度，可作为第一批脚本候选。

缺失来源类型：

- 金钱心理、财务治疗、家庭金钱脚本相关材料。

报告中可表现为：

- 这里可能有一个旧脚本在影响你和钱的关系。
- 这个脚本不一定来自现实能力不足，也可能来自过去对金钱、安全和归属的学习。

### 3.3 配得感与自我价值

`source_supported_draft`

报告需要判断用户是否允许自己拥有、收取、被支付、被看见。配得感不足会影响收费、谈判、展示价值和承接机会。

当前来源基础：

- 《对财富说是》第二章涉及“不敢要钱”“不值得感”。
- 《对财富说是》第七章涉及重写生命评语和自我评价。

缺失来源类型：

- 羞耻、自我价值、自我接纳、女性财富关系议题相关材料。

报告中可表现为：

- 你可能并非没有价值，而是内在还没有完全允许自己把价值放到台前。
- 如果画面中价值线索被压低、遮住或放在边缘，可以提示用户观察“我是否允许自己被支付、被选择、被支持”。

### 3.4 安全感、匮乏与控制

`source_supported_draft`

报告需要处理“总是不够”“必须抓紧”“一放松就危险”的状态。财富关系议题里很多紧绷并不来自金钱数量本身，而来自安全感系统对不确定性的反应。

当前来源基础：

- 《对财富说是》第一章支持金钱与安全投射。
- 《对财富说是》第二章支持“更多”“抓住钱”等金钱态度。

缺失来源类型：

- 创伤知情安全感、焦虑、控制感、依恋相关材料。

报告中可表现为：

- 钱像是在替安全感工作。
- 报告只能提示觉察，不能判断用户现实财务是否安全。

### 3.5 父母关系与家庭金钱脚本

`source_supported_draft`

报告需要允许财富线索回到家庭经验，因为用户对钱、成功、承担、收受和风险的早期学习常与家庭环境有关。

当前来源基础：

- 《对财富说是》第二章和第三章提供父母金钱观、父母关系与财富通路的来源素材。
- 当前跨来源对照只在奥南朵体系内部成立，不能作为跨流派结论。

缺失来源类型：

- 家庭系统、代际影响、家庭财务社会化、依恋与亲子关系材料。

报告中可表现为：

- 画面可能提示你回看早期家庭中关于钱、成功、承担和安全的学习。
- 表达必须使用“可能相关”“值得观察”，不能写成父母决定用户财富状态。

### 3.6 家族忠诚与不允许成功

`ai_draft`

报告需要保留这一模块，因为财富增长有时会牵动归属感、背叛感、超过父母或离开原家庭的心理压力。

当前来源基础：

- 《对财富说是》第二章和第三章有家族忠诚素材，但目前仍属于同一作者体系内部材料。

缺失来源类型：

- 家庭系统、家族治疗、代际创伤、社会流动压力相关材料。

报告中可表现为：

- 当用户一边想要成功、一边害怕成功带来关系距离时，可以提示“成功是否被体验成离开或背叛”。
- 该模块暂不适合生成强结论，只适合作为追问线索。

### 3.7 金钱羞耻与不敢收钱

`source_supported_draft`

报告需要覆盖羞耻、收费、开价、谈薪、讨债、收礼和接受支持。财富报告如果缺少这一块，会漏掉很多真实的财富阻滞。

当前来源基础：

- 《对财富说是》第二章提供”有钱羞耻””不敢要钱””负债羞耻”等直接证据，已完成逐条回填（证据ID：`wealth.money_shame.say_yes_to_money.*`）。

缺失来源类型（已降级为次优先）：

- 羞耻研究（临床心理学层面）材料。
- 边界与谈判心理材料。

报告中可表现为：

- 你可能不是不想收，而是”收”的动作会触发羞耻、亏欠或被评价的压力。
- 这种对钱的羞耻感，可能来自早年家庭教育中关于金钱和道德的学习。
- 报告可以给出低风险觉察：先看见”收”这个动作背后带着什么，而不是急着调整价格或谈判策略。

使用边界：
- 不替用户制定价格或谈判策略。
- 不把金钱羞耻写成道德判断或人格缺陷。
- 如果用户提到债务危机或强烈羞耻反应，提示寻求专业支持。

### 3.8 情绪、消费与保护性习惯

`ai_draft`

报告需要识别消费、拖延、逃避、冲动决策背后的保护功能。这个模块能把“漏财”从道德批评改成情绪理解。

当前来源基础：

- 《对财富说是》第七章对“坏习惯可能是无意识保护策略”的摘要可弱支持。

缺失来源类型：

- CBT、ACT、情绪调节、成瘾替代、消费心理相关材料。

报告中可表现为：

- 这里先不评价花钱对错，而是看消费是否承担了安抚、逃离、补偿或自我证明的功能。
- 对强迫性消费、成瘾或债务危机，只能提示寻求专业支持。

### 3.9 身体连接、恐惧与行动力

`source_supported_draft`

报告需要连接“看见了但做不到”“想行动但身体收缩”“机会来了却退回去”等状态。财富流动要进入行动，行动会触发身体、恐惧和风险承受。

当前来源基础：

- 《对财富说是》第四章支持恐惧、压力和改变对行动的影响。
- 《对财富说是》第五章支持身体连接、姿势、直觉和行动力的关系线索。

缺失来源类型：

- 身体取向疗愈、创伤知情行动、ACT 行动承诺、行为激活材料。

报告中可表现为：

- 财富线索不只在“想不想”，也在身体是否能承接下一步行动。
- 身体感受只能作为觉察线索，不能作为投资、辞职、创业等高风险决策依据。

### 3.10 事业、能力与价值交换

`source_supported_draft`（部分）+ `ai_draft`（机制说明部分）

报告需要覆盖价值表达、能力定价、服务边界、职业身份和交换关系。否则财富解读会过度内在化，缺少现实交换层。

当前来源基础：

- 《对财富说是》第六章提供”热情、真实需要、真实行动”相关线索。
- 《ACT 就这么简单》第 19 章（价值）和第 21 章（承诺行动）已完成逐条回填（证据ID：`wealth.low_action.act_simple.*`、`wealth.value_expression_block.act_simple.*`）。

缺失来源类型（已降级为次优先）：

- 职业发展、价值定价、服务关系、边界、市场反馈相关材料。

报告中可表现为：

- 你可能需要把”我有什么价值”翻译成”我如何让世界看见并交换这个价值”。
- 从”有价值”到”被看见”之间，有时卡住的不是能力，而是行动和真实价值之间的连接还不够清晰。
- 财富行动不一定是要大动作，先从小的、可执行的一步开始。
- 报告不能承诺收入结果，只能提示表达、行动和边界方向。

使用边界：
- 不替用户做职业选择或商业决策。
- 不承诺客户、成交或市场反馈。
- 不把不外向写成问题。

### 3.11 世界链接、客户、市场与合作

`source_needed`

报告需要看用户是否愿意进入世界、连接客户、表达需求、接受反馈和建立合作。财富不是只在内部发生，也发生在用户和外部系统之间。

当前来源基础：

- 现有来源支持较弱，只能从热情、真实行动和责任感获得上位启发。

缺失来源类型：

- 关系心理、服务设计、销售沟通、合作边界、市场反馈、社群与客户关系材料。

报告中可表现为：

- 画面可能提示你的价值还没有稳定进入外部交换。
- 这不是要求外向或强销售，而是观察你是否允许自己被世界看见、回应和选择。

### 3.12 热情、真实需要与内在富足

`source_supported_draft`

报告需要给财富关系议题一个生命力出口。只谈创伤、匮乏和卡点，会让报告沉重；只谈赚钱行动，又会失去疗愈视角。热情、真实需要和内在富足可以作为收束方向。

当前来源基础：

- 《对财富说是》第六章支持快乐、热情、真实需要。
- 《对财富说是》第七章支持内在富足、自我评价和责任觉知。

缺失来源类型：

- ACT 价值行动、积极心理学、身心资源、意义感与职业生命力材料。

报告中可表现为：

- 财富流动可以从更真实的需要和更有生命力的行动开始。
- 内在富足不能被写成“现实贫困不重要”，也不能用来要求用户忍受剥削或放弃现实权益。

### 3.13 风险边界与不做范围

`source_supported_draft`

报告必须持续保留风险边界。财富关系议题天然容易被误读成财务建议、投资判断、职业决策或确定性承诺。

当前来源基础：

- 《对财富说是》来源评估已整理财富疗愈的安全边界。

缺失来源类型：

- AI 安全、心理健康风险、财务建议合规边界、危机干预边界材料。

报告中必须避免：

- 判断用户收入、资产、债务或投资前景。
- 给出买卖、创业、离职、借贷、融资等决策建议。
- 把家庭、父母、身体或画面符号写成确定因果。
- 对创伤、成瘾、债务危机、家庭暴力、自伤风险做 AI 单独处理。

## 4. 财富关系议题的核心问题

### 4.1 钱不只是钱

`source_supported_draft`

《对财富说是》的研究摘要指出，人会把身份、安全、自由、尊严、爱和接纳投射到金钱上。这一点可以作为财富关系议题的基础入口：当用户谈钱时，常常也在谈自己是否安全、是否被尊重、是否被允许、是否有自由。

产品化表达时，应避免写成“你的钱代表你的全部安全感”。更稳妥的表达是：

> 从财富关系议题看，钱在这里可能不只是数字，它也承载着你对安全、自由、被认可和被支持的感受。

### 4.2 财富关系包含内在和外在两条线

`ai_draft`

财富关系至少有两条线：

- 内在线：我是否值得、是否安全、是否允许拥有、是否能接住。
- 外在线：我是否表达价值、是否行动、是否和世界交换、是否建立合作关系。

报告生成时不能只写内在线，否则容易变成纯心理解释；也不能只写外在线，否则容易变成行动建议或赚钱建议。财富报告要把两条线连起来。

### 4.3 主议题锚定与背景线索翻译

`ai_draft`

用户选择财富关系议题时，报告的主线必须始终是财富。这里的财富既不是单纯的金钱数字，也不是纯心理能量，而是同时具有物质和能量两面：

- 物质面：收入、支出、承接、保存、行动、价值交换、现实机会。
- 能量面：安全感、配得感、自我价值、情绪流动、家庭脚本、身体行动力。

因此，财富报告通常优先看外圈和中圈，因为外圈更接近现实行动、物质呈现和外界交换，中圈更接近能量流动、情绪、人际和关系牵引。同时，内圈和中圈也必须被读取，用来解释财富卡点背后的深层原因。

报告中允许出现其他议题线索，但必须满足一个条件：它们要被翻译回财富主线，并自然嵌入财富机制或建议里。

写作规则：

- 关系线索出现时，翻译为价值交换、付出边界、求认可、讨好、被支持或资源互惠。
- 情绪线索出现时，翻译为消费冲动、行动中断、财富焦虑、能量外散或安抚需求。
- 健康和身体线索出现时，翻译为行动力、承载力、风险承受、身体是否能接住下一步。
- 家庭和原生家庭线索出现时，翻译为金钱脚本、安全感来源、成功许可、承担模式或收受能力。

报告不应写成：

> 你在亲密关系中容易讨好。

更适合写成：

> 这条关系线索放到财富关系议题里，更像是在提醒你：为了获得认可而过度付出，可能会影响你为自己的价值开价、拒绝不合适的交换，或稳定接住回报。

报告不应写成：

> 你有原生家庭伤痛。

更适合写成：

> 这类早期安全感线索放到财富关系议题里，可能会影响你是否相信自己值得拥有资源，也可能让赚钱和花钱更容易被焦虑驱动。

如果某个背景线索和财富主线关系弱，报告应暂不展开，只保留为后续追问方向。

## 5. 当前七个核心卡点

以下 7 个卡点是当前 `ai_draft`，用于组织报告和后续证据回填，不代表财富关系议题已经完整。

### 5.1 配得感不足

`ai_draft`

配得感不足关注的是：用户是否觉得自己值得拥有更多，是否值得被支付、被支持、被看见。

它在报告里不应被写成“你不配得”，而应写成一种拉扯：

> 这里更像是在说一种“我值不值得拥有”的拉扯。你可能不是没有能力创造价值，而是内在还没有完全允许自己稳定地接住更多。

《对财富说是》中的“不敢要钱”“不值得感”“重写生命评语”可以为这个方向提供 draft 证据，但还需要回到章节正文复核。

### 5.2 匮乏感和安全感不足

`ai_draft`

匮乏感不是单纯的“现实中钱少”。它更像是一种内在预设：即使有进账，也觉得不够；即使暂时稳定，也担心未来失控。

报告表达应避免判断用户现实财务状况。可以写：

> 这里更像是安全感在向钱借力：钱越重要，内在越容易紧绷。

《对财富说是》中关于金钱投射和“更多”的无意识态度，可作为 draft 证据。

### 5.3 求认可式赚钱

`ai_draft`

求认可式赚钱指的是：赚钱、成绩、客户认可不只是现实目标，也变成了“我好不好”的证明。

这类用户可能很努力，但努力背后有紧绷和评判。报告要避免否定努力本身，而是区分：

- 创造价值。
- 证明自己。

当前来源支持较弱，只能由“金钱承载身份、尊严、爱和接纳投射”提供上位启发。

### 5.4 情绪型漏财

`ai_draft`

情绪型漏财关注的是：消费是否承担了情绪安抚功能。

这不是批评用户“乱花钱”。更准确的表达是：

> 钱在替情绪出口工作。消费本身可能不是问题，问题是它承担了太多安抚功能。

《对财富说是》中“坏习惯可能是无意识保护策略”的方向，可以弱支持这一条，但不能直接证明情绪消费。

### 5.5 承载力不足

`ai_draft`

承载力不足关注的是：用户是否能接住机会、收入、资源、责任和被看见。

它不等于“不会赚钱”，也不等于“存不住钱”。更稳妥的说法是：

> 这条线索不一定是在说你没有财富能力，更像是在说“接住财富”的容器还需要变稳。

《对财富说是》中关于抓住钱、赶紧花钱、不敢要钱等无意识金钱态度，可以部分支持承接与持有这个方向。

### 5.6 行动力不足

`source_supported_draft`

行动力不足关注的是：想法、热情、价值和计划是否能落地到现实行动。

《对财富说是》第五章关于身体连接、身体姿势、直觉和行动力的摘要，可部分支持这一条。第四章关于恐惧、目标和改变，也可支持“行动被恐惧和压力限制”的方向。

报告表达应避免把行动力不足写成“懒”。可以写：

> 财富流动需要行动承接；如果行动一再被打断，价值就很难真正进入现实交换。

### 5.7 与世界链接不足

`ai_draft`

财富不是只发生在用户内部。财富还需要进入表达、服务、合作、市场、客户和资源交换。

这一条提醒报告不要只停在内在心理，也要看用户是否愿意把价值表达给世界。

《对财富说是》第六章关于快乐、热情、真实需要和真实行动的内容，只能弱支持这一条的上位方向，不能直接替代市场、客户或合作关系材料。

## 6. 暂未充分展开但必须保留的方向

当前 7 条只是第一版骨架，不能代表财富关系议题的全部。

后续必须继续展开：

- 金钱羞耻。
- 不敢收钱 / 不敢开价。
- 家庭金钱脚本。
- 父亲关系与事业财富。
- 母亲关系与收受能力。
- 家族忠诚和不允许成功。
- 辛苦赚钱信念。
- 有钱危险。
- 身体失连与财富行动。
- 受害者故事与责任感。
- 热情、快乐和真实需要。
- 内在富足与外在创造。

这些方向不应强行塞进现有 7 条里。它们可以成为后续新条款、子条款或专题章节。

| 价值表达受阻 | 关注能力、经验或热情是否被稳定表达、说明、展示和交付给世界。 | 用户有内容、有经验、有愿望，但现实中没有形成稳定表达路径。 | 你的价值可能已经存在，但还没有被整理成别人能看见、理解和交换的形式。 | 什么让它还没有被别人看见？ | 不替用户做职业决策；不承诺客户或成交。 | `source_supported_draft`，由 ACT 价值行动部分支持。 |
| 目标混乱与能量分散 | 关注财富目标是否太多、太散、相互冲突。 | 画面零散、碎点多、方向不一、中心失焦，或用户同时想抓很多事。 | 不是没有想法，而是同时想抓住太多方向，反而让行动难以形成稳定主线。 | 你现在最想先抓住的是什么？ | 不替用户做现实选择；不把分散写成能力差。 | `ai_draft` |
| 接受支持困难 | 关注是否习惯一个人扛，不容易接受帮助、资源、合作、礼物或机会。 | 用户总说“我自己来”，不容易收下支持，画面又偏封闭或外圈断开。 | 财富不只来自自己用力，也来自能否接受合适的支持。 | 你最不容易接住的支持是什么？ | 不把独立写成问题；不要求用户必须接受所有帮助。 | `ai_draft`，与金钱羞耻/收受议题相邻。 |

### 6.1.1 不敢收钱与开价压力

`ai_draft`

这一条关注“收”的动作：收费、谈价、收礼、接受支持、被支付、被选择。它不等同于配得感不足，配得感偏内在价值判断，不敢收钱偏现实交换动作。

报告表达可以写：

> 这条财富线索更像是在提示：你不是没有价值，而是在“把价值拿出来交换”时容易紧一下。收钱、开价或接受支持，可能会触发亏欠、被评价或怕对方失望的压力。

### 6.1.2 辛苦赚钱信念

`ai_draft`

这一条关注用户是否把“辛苦、牺牲、扛住”当成赚钱的默认条件。它常与责任、家庭期待、求认可和身体透支相连。

报告表达可以写：

> 财富在这里可能和“必须很用力才配得到”绑在一起。画面如果呈现压迫、厚重、绷紧或过度填满，可以提示用户观察：我是否把轻松、支持和顺流体验排除在财富之外。

### 6.1.3 有钱危险与成功压力

`ai_draft`

这一条关注用户是否在靠近成功、曝光、资源增加时体验到危险。危险可能来自被嫉妒、被要求、被看见、被分离、被攻击，或担心关系失衡。

报告表达可以写：

> 这不一定是在说你不想要财富，也可能是在说“更多”会带来压力。成功、被看见、被需要，有时会让人同时兴奋和后退。

### 6.1.4 保存困难与资源外泄

`ai_draft`

这一条关注资源是否容易被消耗、分散或交出去。它和情绪型漏财不同，情绪型漏财偏情绪安抚，资源外泄偏边界、承接、分配和现实压力。

报告表达可以写：

> 从财富关系议题看，这里更像是在提示资源容器不够稳。钱、时间、精力或机会进来以后，可能很快被外界需求、关系消耗或临时压力带走。

### 6.1.5 付出失衡与交换边界

`ai_draft`

这一条关注用户是否容易多给、少收、不好意思拒绝，或把被喜欢、被认可放在公平交换之前。它属于关系线索进入财富关系议题后的交换边界翻译。

报告表达可以写：

> 这条关系线索放到财富里，更像是在看交换边界：你是否容易先照顾别人，再考虑自己的价值、价格和承受范围。

### 6.1.6 价值表达受阻

`ai_draft`

这一条关注用户是否有能力、经验或热情，但没有被稳定表达、包装、说明、展示和交付给世界。它不是要求用户外向，而是看价值是否能被外部理解。

报告表达可以写：

> 你的价值可能已经存在，但还没有被整理成别人能看见、理解和交换的形式。财富流动不只需要能力，也需要表达路径。

### 6.1.7 目标混乱与能量分散

`ai_draft`

这一条关注财富目标是否太多、太散、相互冲突，导致行动缺少主线。它适合对应画面中零散、碎点、方向不一、密度不均或中心失焦的信号。

报告表达可以写：

> 这里更像是在提示财富能量分散：不是没有想法，而是同时想抓住太多方向，反而让行动难以形成稳定主线。

### 6.1.8 接受支持困难

`ai_draft`

这一条关注用户是否习惯一个人扛，不容易接受帮助、资源、合作、礼物、推荐或机会。它和世界链接不足相关，但更偏“收受”和“被支持”的能力。

报告表达可以写：

> 财富不只来自自己用力，也来自能否接受合适的支持。画面如果呈现封闭、拒绝进入、边界厚重或外圈断开，可以提示用户观察：我是否只允许自己付出，不太允许自己被支持。

### 6.1.9 进账辛苦但保存不稳

`reviewed_case_rule`

这一条来自 11 个完整案例审核后的组合规则。外圈出现土生金时，可提示现实资源、进账、价值产出或行动成果；如果同时出现火克金，尤其是红火靠近或切入金，资源进入后可能又被情绪、人情、冲动消费、关系期待或自我证明带走。

报告表达可以写：

> 这里不是在判断你现实中赚多少钱，而是在看财富流动方式：画面里有资源进入的线索，但保存和稳定承接还不够顺。你可能能靠责任感、努力和现实行动带来进账，但钱、精力或机会也容易被情绪、关系期待或临时消耗带走。

使用边界：

- 不做收入、资产、负债或投资预测。
- 不把“留不住钱”写成定论，应写成资源保存和财富容器的可能线索。
- 需要结合外圈结构、土金比例、火金位置和用户主诉。

### 6.1.10 无根成长与机会支撑不足

`reviewed_case_rule`

这一条来自“无根之木”的五行关系。木代表成长、机会、上进、行动愿望和事业生发；水代表滋养、智慧、信息流、支持和情绪稳定。木没有水滋养，或同圈有水但木没有与水相接时，可翻译为有成长力但根基不足。

报告表达可以写：

> 这条线索更像是在说：你不是没有成长力，也不是没有赚钱或行动愿望，而是这股向上的力量缺少稳定滋养。机会、能力或计划如果缺少信息、支持、情绪稳定和现实连接，就容易变成“很努力，但不容易长稳”。

使用边界：

- 不写成用户没有能力。
- 不把所有木都统一判断，应按圈内具体木元素是否接触水分别判断。
- 如果出现在外圈，可优先翻译为事业、客户、市场、行动和现实机会的支撑不足。

### 6.1.11 标准切分导致财富能量不连续

`reviewed_case_rule`

真实白色、留白和色块缝隙属于金能量。它们如果把同类颜色、同类形状或同一能量切成一块块，可进入“金切分其他能量”的财富关系翻译。

报告表达可以写：

> 画面里有一种“被切开”的感觉。放到财富关系议题里，这可能不是单纯没行动，而是行动、价值表达或资源流动经常被标准、评判、关系边界或外部规则打断。你可能不是不努力，而是努力很难连成一条稳定的财富主线。

使用边界：

- 只使用真实画作内部留白和白色，不把模板黑线或三圈标记线当成金。
- 如果发生在中圈，优先翻译为情绪、人际、家庭标准影响财富流动。
- 如果发生在外圈，优先翻译为现实行动、价值交换和资源保存被打断。

### 6.1.12 灵性愿景与现实落地断层

`reviewed_case_rule`

紫色需要结合阴阳判断：浅紫、渐变、莲花状、开放感强时，可偏木阳，表达灵感、贵气、高维链接和灵性苏醒；深紫、浓重、封闭时，可偏火阴，表达神秘、压抑、封闭和不接地气。

报告表达可以写：

> 这里的紫色线索放到财富关系议题里，不一定是在说钱本身，而是在看内在愿景和现实交换之间的距离。你可能有很强的精神追求、直觉或高维连接，但这些内容还需要被翻译成外界能理解、能交换、能落地的价值形态。

使用边界：

- 不把紫色固定写成木或火。
- 不把灵性追求写成问题，只提示它和现实财富行动之间是否存在断层。
- 外圈留白多时，可提示现实落地、行动表达和财富交换不足。

## 7. 来源补充优先级

如果要把财富关系议题推进到 MVP 可用，补源优先级按报告缺口排序，不按书籍到达顺序排序。

第一优先级：

- 金钱心理 / 财务治疗 / 金钱脚本：补足金钱信念、收费、收受、储蓄和消费模式。
- 家庭系统 / 代际影响 / 家庭金钱观：补足父母关系、家族忠诚、不允许成功。
- 羞耻 / 自我价值 / 配得感：补足不敢收钱、不敢开价、价值感和被看见。
- 创伤知情安全感：补足匮乏、控制、风险承受和高风险用户边界。

第二优先级：

- ACT / CBT：补足价值行动、认知脚本、情绪调节和行为改变。
- 身体取向疗愈：补足身体收缩、行动阻滞和身体觉察边界。
- 职业发展 / 价值交换 / 服务边界：补足事业、客户、定价和市场连接。

第三优先级：

- 女性与财富、亲密关系与金钱、创业者财富心理：用于增强报告分群表达，不作为第一版 MVP 的硬前提。

- 财务预测。
- 收入承诺。
- 投资建议。
- 职业决策建议。
- 心理诊断。
- 家庭关系确定因果。

财富报告可以写成：

- 画面中呈现出的财富关系线索。
- 用户当前在金钱、安全、自我价值、行动和世界链接中的可能状态。
- 可低风险尝试的觉察方向。
- 后续是否适合进入主题方案或 21 天方案的提示。

本文定义财富报告中如何处理其他议题线索。

财富是主议题时，报告可以提到自我价值、家庭、关系、情绪、身体和事业，但这些内容必须服务财富主线。它们不是独立报告，也不能抢走用户这次选择的主题。

运行时写作原则：这些线索只作为财富机制的背景解释，不在 Lite 报告中单独命名为“浮现议题”，也不单独开一个用户可见章节。Pro 可以更细，但仍应把它们写进财富机制、现实表现或建议里。

## 1. 定位

本文不是完整的自我价值、家庭、关系或身体知识库。

它是一层主议题和其他议题线索之间的翻译规则，用来回答：

- 哪些其他议题线索可以进入财富报告。
- 进入后应该翻译成哪类财富机制。
- 最多展开到什么深度。
- 哪些表达必须避免。
- 后续独立议题知识库建好后，应该如何挂接。

当前文件以财富为主议题，但结构要预留通用化空间。后续亲密关系、家庭、自我价值等议题独立成库后，可以用同样结构建立：

```text
primary_topic -> emergent_topic -> translation_role -> allowed_depth -> translated_mechanisms
```

## 2. 总规则

财富报告的主线固定为：

```text
画面信号 -> 财富状态 -> 财富机制 -> 背景线索 -> 现实表现 -> 低风险建议
```

其他议题线索只允许出现在三个位置：

1. 机制拆解：解释财富卡点为什么会形成。
2. 背景线索：把其他议题翻译回财富机制。
3. 调整建议：给低风险觉察动作，不给完整疗愈方案。

其他议题线索不允许：

- 单独展开成另一份报告。
- 替代财富主线。
- 在 Lite 报告里以“浮现议题”“关系议题”“家庭议题”等模块标题出现。
- 生成诊断。
- 生成家庭、关系、身体或职业决策结论。
- 用“父母导致”“关系导致”“身体说明”等确定因果表达。

## 3. 背景线索与财富回译

### 3.1 自我价值

允许进入财富报告的情形：

- 画面显示内圈收缩、中心空缺、金多、被切割、价值线索被压低。
- 用户问题涉及“不值得”“不敢收钱”“不敢被看见”“怕别人觉得我不值”。

回译方向：

- 配得感。
- 被支付能力。
- 价值可见度。
- 收受能力。
- 求认可式赚钱。

报告表达：

> 自我价值线索放到财富关系议题里，更像是在看：你是否允许自己的价值被看见、被支付，并稳定地接住回报。

嵌入式表达：

> 这部分更适合放回“配得感”和“被支付能力”来看：你可能已经有价值，但在被看见、被报价、被回报时，身体和心里还需要一点确认。

避免：

- 不写“你没有价值感”。
- 不把价值感问题写成人格缺陷。

### 3.2 家庭与原生家庭

允许进入财富报告的情形：

- 画面出现强边界、防御、收缩、负担感、内外不一致。
- 用户提到父母、家庭责任、家族期待、赚钱压力或成功后关系变化。

回译方向：

- 金钱脚本。
- 成功许可。
- 承担模式。
- 收受能力。
- 家族忠诚。
- 安全感来源。

报告表达：

> 家庭线索放到财富关系议题里，不是为了判断父母或家庭，而是观察早期关于钱、成功、承担和收受的学习，是否还在影响你现在如何拥有和流动资源。

嵌入式表达：

> 如果画面里有责任感和收缩感同时出现，可以轻轻看见：一些关于钱、成功和承担的旧学习，可能还在影响你接住资源时的松紧度。

避免：

- 不写父母决定用户财富状态。
- 不用家庭系统解释替代心理诊断。
- 不把家族忠诚写成确定结论。

### 3.3 亲密关系与人际关系

允许进入财富报告的情形：

- 中圈缠绕、拉扯、断裂、色块分割明显。
- 外圈边界破损、缺口、被外界消耗。
- 用户提到合作、伴侣、客户、同事、人情压力。

回译方向：

- 价值交换。
- 付出和回报。
- 价格边界。
- 讨好和拒绝。
- 资源互惠。
- 接受支持。
- 关系认可消耗。

报告表达：

> 关系线索放到财富关系议题里，更像是在看交换边界：你是否容易先照顾别人，再考虑自己的价值、价格和承受范围。

嵌入式表达：

> 这里不一定是关系本身有问题，更像是财富流动里有一部分能量先流向照顾、回应或维持和气，自己的价格和边界反而排到了后面。

案例规则补充：

- 中圈火被金切分，常翻译为热情、付出和行动被关系标准、评价或求认可打断。
- 火克金同时带有讨好、委屈或期待回应时，可翻译为“为了关系认可消耗财富行动力”。
- 关系结论可以作为画面直接线索进入报告，但必须回到财富中的价值交换、付出边界、收受能力和资源保存。

避免：

- 不展开成亲密关系报告。
- 不指责用户讨好。
- 不要求用户切断关系。

### 3.4 情绪调节

允许进入财富报告的情形：

- 红色、火感、外放、断裂、线条杂乱、颜色浓烈或情绪描述强。
- 用户提到焦虑消费、冲动消费、拖延、内耗或害怕钱不够。

回译方向：

- 情绪型漏财。
- 财富焦虑。
- 行动中断。
- 安抚性消费。
- 能量外散。
- 保护性习惯。
- 情绪化资源消耗。
- 进账后的保存不稳。

报告表达：

> 情绪线索放到财富关系议题里，更像是在看钱是否承担了安抚功能。消费、拖延或犹豫不一定是能力问题，也可能是情绪在寻找出口。

嵌入式表达：

> 当情绪起伏和资源流动连在一起时，可以先不急着责备自己，而是观察：钱是否有时被拿来缓解焦虑、证明自己，或让当下好过一点。

案例规则补充：

- 外圈土生金同时出现火克金时，可翻译为“有资源进入，但容易被情绪、人情、冲动消费或自我证明消耗”。
- 外圈红火明显时，不直接写成漏财定论，应写为财富能量外散、情绪带动消费或行动节奏被感受牵引。
- 火被金切成一块块时，可写行动和热情不连续，情绪状态影响财富主线稳定性。

避免：

- 不写用户乱花钱。
- 不诊断成瘾、焦虑症或强迫行为。
- 债务危机和强迫性消费需要提示外部专业支持。

### 3.5 身体与安全感

允许进入财富报告的情形：

- 内圈深色、收缩、厚重、尖锐、身体感描述强。
- 外圈厚重、防御、过满或压迫。
- 用户提到身体紧、怕行动、机会来了退回去。

回译方向：

- 承载力。
- 行动力。
- 风险承受。
- 身体是否能接住下一步。
- 安全感系统。
- 休息和恢复空间。

报告表达：

> 身体线索放到财富关系议题里，更像是在看你的系统是否能接住更多行动、曝光、机会和资源。这里不需要逼自己立刻冲出去，而是先让身体有一点可承受的稳定感。

嵌入式表达：

> 这部分可以先回到承载力来看：机会和资源不只需要头脑愿意，也需要身体觉得“我可以慢慢接住”。

避免：

- 不做健康判断。
- 不把身体反应当成投资、辞职、创业等决策依据。
- 不鼓励用户忽视现实医疗或心理支持。

### 3.6 事业、使命与价值表达

允许进入财富报告的情形：

- 外圈弱、留白多、外圈空、中心清晰但外化不足。
- 用户提到赚钱方向、能力表达、客户、市场、定价、作品或服务。

回译方向：

- 价值表达。
- 服务边界。
- 客户和市场连接。
- 真实需要。
- 行动主线。
- 可交换的价值形态。
- 机会滋养。
- 现实落地。

报告表达：

> 事业线索放到财富关系议题里，更像是在看：你的价值是否已经被整理成别人能看见、理解并愿意交换的形式。

嵌入式表达：

> 这条线更适合落在价值表达上：把能力整理成别人能理解、能选择、也愿意付费交换的形式，可能是下一步更现实的财富动作。

案例规则补充：

- 无根之木进入财富报告时，翻译为成长、机会、事业方向或行动愿望有，但缺少滋养、信息流、支持系统、情绪稳定或资源连接。
- 木是否有根，需要看圈内具体木元素是否与水相邻或相接，不能只看同圈是否有水。
- 紫色偏木阳时，可翻译为灵感、愿景、贵人感和高维资源；若外圈落地不足，需要继续回译为价值表达和现实交换不足。

避免：

- 不给职业决策建议。
- 不承诺客户、成交、收入或市场反馈。
- 不把用户不外向写成问题。

## 4. 展开深度

财富报告中的其他议题线索分三种深度：

- `hint`：只点一句，作为可能背景。
- `brief`：用一小段解释其财富含义。
- `supporting_mechanism`：进入机制拆解，但仍必须回到财富主线。

Lite 报告默认只允许 `hint` 或 `brief`，并且必须嵌入财富机制或建议中，不单独设标题。

Pro 报告可以使用 `supporting_mechanism`，但每份报告最多展开 2 个其他议题线索。超过 2 个时，只保留最能解释财富主线的线索。

### 4.1 深度选择规则

- 当其他议题线索只是辅助背景时，用 `hint`。
- 当需要说明为什么财富卡点会出现时，用 `brief`。
- 当画面证据和用户主诉共同指向某一机制时，才用 `supporting_mechanism`。
- 单一信号不足时，宁可降级，不要升级。

### 4.2 写作降噪规则

- 用户可见报告优先写“这部分可以回到财富里的某个机制来看”，少写“浮现出某某议题”。
- Lite 报告不使用“浮现议题回译”“关系议题”“家庭议题”等章节标题。
- Pro 报告如果需要标出辅助线索，标题也应使用财富语言，例如“交换边界里的关系压力”“承载力里的安全感线索”。
- 如果一条背景线索不能自然回到收钱、花钱、保存、行动、定价、交换、承载或价值表达，就不进入本次报告。
- 结尾的下一次探索建议可以提议独立议题，但正文不要提前把用户带进另一份报告。

## 5. 平滑过渡到独立议题知识库

后续如果某个浮现议题已经建成独立知识库，不需要推翻本文。

过渡方式：

1. 保留本文作为跨议题翻译层。
2. 在结构化 YAML 里补 `source_topic_clause_refs`。
3. 报告生成时仍先看 `primary_topic`。
4. 独立议题知识库只提供更稳的背景机制和表达，不改变主报告框架。

示例：

```yaml
primary_topic: wealth
emergent_topic: family
source_topic_clause_refs:
  - family.parental_money_message
  - family.loyalty_conflict
translated_mechanisms:
  - money_script
  - success_permission
  - receiving_capacity
```

这样未来家庭议题可以独立生成家庭报告，也可以在财富报告里作为背景机制出现。两者的差异由 `primary_topic` 决定。

## 6. 写作检查

每次生成财富报告时检查：

- 是否明确主议题仍是财富。
- 浮现议题是否已经翻译成财富机制。
- 是否没有展开成另一份报告。
- 是否没有使用确定因果。
- 是否没有给财务、职业、医疗或心理诊断建议。
- 是否保留低风险觉察出口。

## 7. 下一次曼陀罗探索建议

财富报告结尾可以推荐下一次曼陀罗探索方向。推荐必须来自本次画面中浮现但没有完全展开的线索。

具体推荐方向、触发线索和禁止表达见 [13-下一次探索建议映射表.md](13-下一次探索建议映射表.md)。

推荐不是固定销售话术，而是报告的延展路径。它需要回答：

- 本次画面浮现了什么未展开线索。
- 为什么这个线索值得单独画一幅曼陀罗继续看。
- 下一次意图可以如何锚定。
- 本次报告为什么不展开成完整解读。

数量限制：

- Lite 报告最多推荐 1 个方向。
- Pro 报告最多推荐 2 个方向。
- 没有足够证据时，可以不推荐。

推荐优先级：

1. 与本次财富主线关系最强的浮现机制。
2. 画面证据最清楚的方向。
3. 用户输入里已经提到、但本次没有展开的方向。
4. 更适合作为下一次意图的具体议题，例如父亲关系、母亲关系、亲密关系、健康身体或事业发展。

推荐示例：

```text
下一次可以把意图锚定在“我和父亲关系中的权威、规则和成功感”。

本次财富画面里出现了规则感、外部评价和成功压力相关线索。因为本次主轴是财富，所以这里只把它翻译成价值表达和收钱压力。如果你想继续探索，可以单独画一幅曼陀罗，看这条线索是否和父亲关系、权威感或被认可的方式有关。
```

禁止表达：

- 不说“你一定有父亲议题”。
- 不制造焦虑式复购。
- 不同时推荐过多方向。
- 不把下一次探索建议写成当前报告的确定结论。

本文从 11 个原始案例中反推财富关系议题的解读方式，作为议题层的案例反推材料。

当前它只适合作为财富样本回归，不适合作为财富关系主题的完整映射依据。基础层解读流程见 [../../../20-流派层/10-曼陀罗/00-曼陀罗基础层解读流程.md](../../../20-流派层/10-曼陀罗/00-曼陀罗基础层解读流程.md)。

它不是财富关系议题的完整体系入口。11 个案例数量有限，不能代表完整财富关系议题。完整财富关系议题需要优先基于心理学流派、疗愈流派、金钱关系、家庭系统、创伤和行为模式等材料建立议题框架，再由画面信息与议题条款做对应。

本文件只用于观察案例里已经出现过的财富表达、卡点和调整方向。

## 1. 议题定位

财富关系议题在案例中通常不只看“能不能赚钱”，还会同时看：

- 财富进账是否稳定。
- 是否漏财、为情绪买单。
- 能否存钱、能否承载财富。
- 财富动力来自热爱、成长、逃离，还是求认可。
- 行动力、心力、身体能量是否支撑财富目标。
- 与家人、亲密关系、集体标准的拉扯是否消耗财富能量。

## 2. 常见画面线索

### 外圈红色多

原始经验：外圈红色多，可以直断财富状况是在漏财。

案例中常见解释是：火是往外散发热量的，是消耗型的；外圈又属于物质圈，结合起来看，就是漏财的习惯。

常见表现：

- 花钱爽快。
- 不太考虑性价比。
- 为感受或情绪买单。
- 看到喜欢就想买。

### 外圈花边、圈圈点点、星星点点

外圈是花边、圈圈点点、星星点点等小图案很多的，看起来很漂亮的，可以直断绘画者漏财，留不住钱。

案例中也会把小圆、星星、三角形等看成成长果实或外在机会，但如果这些形状零散、不成片、被金截断，则会转为“成果不稳、自己不满意、财富难以承接”。

### 外圈颜色单一且面积大

如果解读的是财富，外圈颜色单一且面积比例大，说明意识空间更倾向于赚钱，每天想的是怎么赚更多钱。

但也可能偏向有形、实际、性价比层面，对意识、能量、智慧等无形抽象层面把握不准，导致成长受限。

## 3. 财富进账模式

### 有进账但不满意

案例里常见表达：

- 财富上是有进账的，但比较零星，她不是特别满意。
- 现在财富上有进账，也比较稳定，但相对较少，没有达到预期。
- 进账相对比较零碎，对财富进账不满意。

常见画面依据：

- 外圈有土、金、水的正向流动，但比例不平衡。
- 火生土、土生金、金生水出现，但颜色不够稳定。
- 外圈有机会或生机，但被金截断，力量不能凝聚。

### 能赚钱但存不住

案例里常见表达：

- 财富方面能赚钱，但也存不住钱，花钱比较多，为情绪买单，或者为个人成长买单。
- 能赚钱，但也漏财，属于冲动型消费，只要自己开心就好。
- 喜欢买好看的、好玩的东西，花钱不太计算数字，没有性价比的头脑，存不下钱。

常见画面依据：

- 火克金，且火不稳定。
- 粉色多、弱火多、情绪多。
- 外圈向外的能量大于向内收束的能量。
- 土无法成片，财富承载力不足。

### 财富承载力不足

案例里常见表达：

- 需要进一步扩容自己的承载力，稳定自己的能量，财富才会越来越好。
- 财富承载力和持续增长受限。
- 对财富的承载力到了一定瓶颈。

常见画面依据：

- 土少金多。
- 土零零散散不成片。
- 土是弯曲条状、小圆状、无法成片。
- 深褐色土、暗黄色土，代表疲惫、压抑、自卑、限制性信念。

## 4. 财富卡点

### 为情绪买单

案例中多次把漏财和情绪挂钩：

- 漏财是为情绪买单，且能量不和财富对频。
- 情绪消耗大量能量，经常会觉得累，心力不够。
- 过不了情关的女生通常很难赚钱。

常见画面依据：

- 弱火多。
- 水火相冲。
- 金克木导致委屈、郁闷、自我否定。
- 中圈情绪消耗影响外圈行动力。

### 求认可模式

财富卡点经常不是“不努力”，而是努力背后的动力不稳。

案例表达：

- 底层能量模式是想要证明自己和求认可。
- 自我淬炼还是为了得到更多的认可。
- 在集体中提供价值和生机是好事，但要把底层求认可的渴望去掉，贵人缘和财富会越来越好。

常见画面依据：

- 金多、金克木。
- 火克金。
- 弱火、橙色、粉色明显。
- 对外界标准、集体标准、家人认可特别敏感。

### 财富动力不纯粹

案例 11 中有一个重要判断：

赚钱的动力不是出于热爱，而是出于逃离，这也是为什么财富始终难以提升的原因。一个人的初心不纯粹，财富显化之路就容易掉坑、走弯路。

常见画面依据：

- 中圈情感受伤严重。
- 深蓝水、阴性水、情绪暗流明显。
- 土箭头指向外圈，想通过财富逃离原生家庭或压抑环境。

## 5. 调整方向

案例里的财富调整，不是只给赚钱建议，而是先调能量底层。

常见建议：

- 把心沉稳下来，财不入急门。
- 把焦点放在目标上，减少觉受对自己的影响。
- 断舍离自我评判，多夸奖自己，欣赏自己。
- 多画黄色，提升承载力。
- 多画蓝色，让自己放松下来。
- 多画红色，提升心力、丰盛感和欢喜心。
- 站桩、八段锦、腹式呼吸，把脾胃浊气、肝淤排出。
- 写感恩日记、幸福日记，提升对红尘和财富的热爱。
- 打开人际链接，接纳他人真实的优点和缺点，从沟通打开财富新局面。

## 6. 使用提醒

生成财富报告时，不应只判断“有钱 / 没钱”。应先看主题，再看外圈物质与行动力，同时回看中圈能量和亲密关系是否在消耗财富能量。

财富关系议题的核心不是单一进账判断，而是：进账、漏财、承载力、行动力、求认可模式、情绪消耗、与世界链接能力。

## 7. 适用边界

当前文件只能作为：

- 财富样本回归。
- 组合信号与条款的经验对照。
- 财富报告表达的参考。

不能作为：

- 财富关系主题完整映射表。
- 穷举式视觉构成依据。
- runtime 的唯一财富规则源。

# 解读与个案沟通流程

> 状态：draft
> 文档版本：0.1.0
> date：2026-05-13
> owner：CEO / Knowledge Base
> source_of_truth：当前目录/30-应用适配/10-aimandala/01-解读与个案沟通流程.md
> 原始来源：01-曼陀罗解读手册原文.md
> 整理方式：原文保真重组

本文从 `01-曼陀罗解读手册原文.md` 中拆出解读时如何与案主沟通、如何做完整个案的流程经验。

## 1. 解读沟通的六大流程

原文将上千个解读个案经验整理为六大流程：

1. 建立信任。
2. 确定目标。
3. 打开内心。
4. 爆破卡点。
5. 清理情绪。
6. 定制方案。

## 2. 建立信任

你的语言要有疗愈感。在咨询关系正式确定之前，疗愈师往往需要跟案主做前期沟通。前期沟通并不是简单地确定时间、价格等，更重要的是跟案主建立信任。

如果案主对你的能力还在不停地质疑，或者让你极力去证明自己值某个价格，那说明给他做个案的时机还没到，可以建议他缓一缓，考虑清楚了再做。

原文提醒：信任关系不是用一番话或者一套话术就能够解决的。这种信任关系的沉淀，来源于平日的短视频、推文、朋友圈的内容输出。

只有让案主感受到你的专业性，和语言当中的疗愈感，再加上时机成熟，自然就会有案主主动来找你。

## 3. 确定目标

下一步，要确定的是案主的目标：通过个案解决什么问题？

不要漫无边际地解读。因为一个人从小到大的伤痛、负面情绪，是永永远远挖掘不完的。

案主当下最迫切要解决的问题，就是他的痛点。

目标有的案主刚开始内心打不开，或者不愿意深入说，也可以问：这幅曼陀罗的绘画主题是什么？借此打开话题。

## 4. 打开内心

原文指出，一个疗愈师的水平高低，很大程度上取决于能不能打开一个人的内心，让他把伤痛袒露出来。

原文给出几句推进个案节奏的话：

1. 别害怕，在这里你是安全的。
2. 在这里，一切都是被允许的。
3. 亲爱的，你知道吗？这个世界上没有别人，只有你自己。

在案主描述自己卡住了，或者不愿意打开时，可以适当使用这些话推进个案节奏。

## 5. 爆破卡点

这一步是帮助案主找到伤痛事件背后的根源事件。

例如有案主想解决的问题是：跟女儿的关系不好，沟通上有很大的隔阂和障碍，似乎无论怎么做都走不近女儿的内心，经常聊着聊着就闹矛盾。

这时，可以通过她画的曼陀罗寻找事件背后的根源事件，例如：她的掌控欲是不是很强？她跟自己的母亲关系好不好？她近期的情绪、脾气好不好等。

根源事件的挖掘，要看案主敞开的程度。不一定每一个人都能做得很深，具体要看案主的意愿，和疗愈师的感知力。

## 6. 清理情绪

一旦冰山下面的“真相”浮出水面，下一步就是在主意识层面，告诉案主要清理和调整的方向。

原文示例：

“母亲对女儿的过分的关爱和担心，其实也是一种控制。因为你担心的念头一产生时，你的身体是紧绷的，释放的情绪是恐惧的，女儿无形中接收到了这些信号，就会躲着你了。”

“只要你放松下来，给她自由的空间去体验和成长，即使中间有些磕磕碰碰没关系的。放下你紧绷的情绪，你们的关系逐渐就能够缓和了。”

除了主意识的语言引导以外，还可以让案主画黑色清理画，清理内在的恐惧；以及画蓝色清理画，让身体保持放松。结合曼陀罗的情绪清理，个案效果会更快速显现。

## 7. 定制方案

最后一步，就是设计一套绘画方案。

原文示例：

清理方案：每天画 14 张黑色清理画，7 张蓝色清理画，坚持 21 天；21 天后反馈个案效果。

显化方案：每周绘画 1 张彩色订单画，一边画一边观想女儿小时候，跟她融洽、有爱地相处，大家一起相处时最开心的种种画面。

原文提醒：有的个案能六步全走完，把个案做得很深。有的也许做得浅一点，案主敞开的程度也没那么深。具体的火候，需要多练习才能把握得精准、到位。

## 8. 完整个案流程

原文把完整个案拆为六个阶段：

1. 个案准备。
2. 引领觉察。
3. 找到根源。
4. 清理情绪。
5. 检视效果。
6. 锚定信念。

## 9. 第一阶段：个案准备

个案就是针对案主的问题，给他做一次较为彻底的解决和疗愈。要做到“快、狠、准”。而要精准地找到案主的核心问题，必须借助曼陀罗这个工具，辅助案主做创伤事件的挖掘。

首先，疗愈师可以让案主准备好一本曼陀罗绘画和一套画笔。一个安静、能够独处的环境，保证在个案开工的时间内不被打扰。然后指引案主，绘制第一张彩色曼陀罗。

面对一些难以进入状态的案主，可以为其选择几首轻柔的纯音乐。一边听着音乐一边绘画，更容易让案主的状态平静下来。

即使案主画上 1 个小时左右，疗愈师也不要催促，只需要静静地陪伴即可。

前期准备非常重要。疗愈师要轻柔地告诉案主：我会在这里陪着你，直到你绘画完毕。当你画好了，就告诉我。别担心，有我在，一切都是安全的。

个案工具：让案主绘制第一张彩色曼陀罗，根据自己的心意和喜好涂色。

## 10. 第二阶段：引领觉察

当案主绘画完毕后，要将以下问题依次问他：

1. 在绘画的过程中，你感觉如何呢？
2. 你希望通过个案，解决什么问题呢？
3. 现在，我邀请你，通过这幅曼陀罗做一个内在的觉察，你愿意吗？

如果在这个过程中，案主很抗拒，或者情绪爆发，则必须先安抚好案主，不能将流程强行推进下去。

当案主状态稳定，也回复“愿意”，就可以结合案主想要解决的问题，做针对性的解读。

新手解读师如果对解读的知识点和内容不是很纯熟，可以先给自己缓冲时间。在这个阶段先收集到案主的曼陀罗，然后再另行预约解读时间，给自己充足的时间做好详细的解读笔记。

可对案主说：很感谢你的信任。我需要一点时间，对你的作品做一个详细的解读。我们把个案解读时间定在 X 月 X 日 XX 时可以吗？

个案工具：曼陀罗解读笔记，即场解读或提前准备均可。

## 11. 第三阶段：找到根源

这一步是最考验疗愈师功力的，因为有很多功夫超出了曼陀罗解读以外的心理学底蕴。新手解读师也不要惧怕，大胆尝试就行。任何经验都是从零开始积累的。

开始时要重复锚定案主的问题，让问题变得聚焦。否则解读的内容会太过发散，很难做到效果。

解读句式：

从你的曼陀罗中，可以看出……；因为你的用色 / 结构 / 布局 / 形态是……的，因此你面对这个问题时会……

重点是对自己的解读内容给出理论依据。有了依据才能让案主信服。

原文示例：

从你的曼陀罗中，可以看出你的消费习惯不太节制，容易乱花钱；因为你在外圈画了像火焰形状的红色，外圈代表物质圈，红色的火能量代表着一种发散，因此你的消费习惯会很随性，花钱不太节制。

当把能够解读到的内容告诉案主后，真正的根源问题挖掘才刚刚开始。

可以继续问：

1. 回到你最初的问题。听完我对你的曼陀罗解读后，你的感受是什么？
2. 这份感受，是让你舒服的，还是不舒服的呢？

## 12. 第四阶段：清理情绪

清理阶段，至少每天要让案主抽出 30 分钟去画清理画。

每天可以画 3 张以上，最好能画到 7 张。以 7 天为一个清理周期。

如果有几个主题需要清理，就告诉案主用色和清理的画法，分配好每天清理画的数量。

在清理周期内，可以隔 2-3 天问一次案主绘画清理画的感受和体会，及时跟进案主的变化。

个案工具：按照定制的绘画方案进行绘画清理。

## 13. 第五阶段：检视效果

清理阶段结束后，要让案主再次绘画一幅彩色曼陀罗。

然后拿出第一阶段的曼陀罗作品，做对比解读。

告诉案主第一次的作品和这次的作品有什么变化，这意味着哪些情绪已经减少，让案主通过曼陀罗直观地看到自己的实际变化。

个案工具：让案主绘制一张彩色曼陀罗，根据自己的心意和喜好涂色。

## 14. 第六阶段：锚定信念

最后一步，要夯实基础，巩固效果。让案主把这份疗愈的能量带回现实生活，提升生命质量和幸福感。

沟通句式参照：

1. 当你看到自己的变化后，之前的问题还能困扰你吗？
2. 下一次，当你遇到类似的问题，你有信心去解决吗？
3. 伸出双手，给自己一个充满爱和有力量的拥抱。让我们带着这份爱和力量，结束这次的个案。

## 15. 使用提醒

用户对报告进行追问时，可以借鉴本文中的“锚定问题 - 解释依据 - 询问感受 - 进入清理方向”的沟通结构。

生成疗愈方案时，可以借鉴“清理方案 + 显化方案 + 检视效果”的结构。

在产品化使用时，需要把个案表达转为安全、温和、非诊断式的建议，避免承诺疗愈结果。

本文从 11 个原始案例中反推解读报告的组织顺序。

## 1. 报告基本顺序

案例中的完整解读通常按这个顺序展开：

1. 凭直觉描述整体画面。
2. 确定绘画者的曼陀罗主题。
3. 以神识为准划分三圈。
4. 识别本图颜色和五行属性。
5. 逐圈解读。
6. 结合五行相生相克关系做综合判断。
7. 回到用户主题，说明卡点。
8. 给出生机和调整方案。

## 2. 开头：整体画面直觉

多个案例会先写“拿到图的瞬间”或“首先凭直觉来描绘一下整体看到的画面”。

案例表达：

- 我的直觉是：像花圈，漂亮，情感丰富，情绪多，渴望被看见。
- 我的直觉是：漂亮、内在阴寒、有很多项链、珠宝、爱美。
- 它的整体特征是：水火两重天，案主的脾气会容易被点着。
- 画面特征是：整张曼陀罗颜色画得比较粗糙，很多线条画出线了，整体看着偏凌乱。

用途：

- 快速进入案主当前状态。
- 让报告不只是规则堆砌，而有疗愈师面对作品时的第一感。
- 帮助打开用户心防。

## 3. 主题确认

案例每次都会先确认主题：

- 主题是个人成长和财富。
- 主题是我值得拥有幸福和爱。
- 主题是两性情感关系。
- 主题是事业发展。
- 主题是财富提升。
- 主题是自我提升。

报告不应泛泛分析所有方面。主题决定解读重点，也决定哪些画面信息优先被调用。

## 4. 三圈推进

案例中的三圈语义基本稳定：

- 第一圈 / 里圈：意识、情感、过去、自己内心的想法，自己与自己的关系。
- 第二圈 / 中圈：能量、财富能量、现在和亲人之间的情感关系。
- 第三圈 / 外圈：物质、财富、身体、未来、行动力，别人怎么看 Ta。

报告写作时应逐圈推进，不要把三个圈的信息混成一段。

## 5. 每圈内部写法

每一圈通常按这个顺序写：

1. 这一圈代表什么。
2. 有哪些颜色和形状。
3. 这些颜色分别对应什么五行。
4. 相生相克关系是什么。
5. 面积比例、深浅、是否截断、是否成片。
6. 推出对应的意识、情绪、关系、财富或行动力判断。
7. 必要时回到主题解释影响。

## 6. 判断句式

案例中高频句式：

- 从第一圈可以看出……
- 说明案主……
- 由此可看出……
- 还可以看到……
- 为什么说……？因为……
- 结合中圈到外圈的能量状态来解读……
- 这也是为什么……的原因。

这些句式的作用是把画面证据和解读判断连起来，避免只给结论。

## 7. 生机写法

案例里的解读不是只指出问题，也会指出生机：

- 但这也是她的勇气和生机所在。
- 这是非常值得赞扬的，也是曼陀罗解读师要给到案主的生机。
- 内在生起了欢喜心。
- 有了新的生机。
- 能看到自己更多的可能性。

报告中应避免只有卡点和负面判断。每个主要卡点后，至少要给出一个可转化方向。

## 8. 调整方案写法

调整方案通常包含：

- 意识调频：认知、转念、放下评判、锚定目标。
- 能量调频：呼吸、站桩、八段锦、冥想、情绪清理。
- 曼陀罗绘画：具体颜色、张数、周期、主题。
- 行动建议：做计划、找工作、专注目标、每天小行动。
- 关系建议：建立边界、减少讨好、链接他人、理解家人。

调整方案需要尽量具体，不只写“多爱自己”“提升能量”。

## 9. 报告边界

案例里的语言有强烈一线疗愈师风格。生成报告时可以保留疗愈感，但需要注意：

- 不把身体判断写成医学诊断。
- 不把财富判断写成财务承诺。
- 不把心理创伤判断写成临床诊断。
- 保留“可能”“倾向于”“从画面看起来”等缓冲表达。

## 10. 使用提醒

报告生成不是把画面语言、流派解释和议题条款依次罗列，而是根据用户主题和画面证据组织成一条解释链。

推荐结构是：

整体直觉 -> 主题确认 -> 三圈逐层解读 -> 综合模式 -> 主题卡点 -> 生机 -> 调整方案。

# 解读报告生成最小规则

> 状态：draft
> 文档版本：0.1.3
> date：2026-05-28
> 变更说明：修正 Lite / Pro 分流字段，明确 `user_segment` 只表示用户类型，`report_version` 才表示报告版本。
> owner：CEO / Knowledge Base
> source_of_truth：当前目录/30-应用适配/10-aimandala/03-解读报告生成最小规则.md
> product_decision：projects/aimandala/docs/decisions/2026-04-06-用户分群与产品矩阵决策.md

本文把 `aimandala` 的解读报告生成流程收成一版可直接执行的最小规则。

## 1. 目的

目标不是一次性写出完整疗愈体系，而是先让报告生成有统一入口、统一顺序、统一安全边界。

## 2. 运行前读取顺序

生成前按这个顺序读：

1. 用户分群与产品矩阵决策。
2. 体系框架。
3. 数据结构与运行架构。
4. 来源索引。
5. 议题层文件。
6. 个案沟通流程。
7. 报告组织规范。
8. Lite / Pro 报告分流与交付口径。
9. 运行时知识包。

## 3. 报告产品边界

报告负责：

- 解释这张画在表达什么。
- 命名用户状态。
- 梳理用户模式。
- 连接现实议题。

报告不负责：

- 连续训练。
- 长周期改变。
- 替代主题方案。
- 替代 21 天定制方案。

因此，报告可以给轻量调整建议，但不要把报告写成完整训练产品。

产品主分层固定为：

`入口产品 -> 解读产品 -> 主题转化产品 -> 长期陪伴产品`

`Lite / Pro` 只属于解读产品内部的深度分流，不是产品架构主分层。

## 4. 最小输入

最小输入必须包含：

- 用户主题。
- 用户想解决的具体问题。
- 用户分群或进入动机，如果已知。
- 报告版本：Lite / Pro / 未知。
- 画面整体直觉。
- 里圈、中圈、外圈的观察。
- 颜色、形状、布局的观察。
- 不能确认的地方。

如果主题没有确认，先补主题，不要直接开始下判断。

## 5. 生成步骤

1. 先写整体直觉，只写看见了什么和第一感受。
2. 再确认主题，说明这次报告聚焦什么。
3. 再按里圈、中圈、外圈逐层展开。
4. 每层都先描述观察，再给出解释。
5. 最后把三圈信息收束成综合模式。
6. 回到用户主题，说清楚最可能的卡点。
7. 一定要写出生机，而不是只写问题。
8. 最后给出可执行的调整方案。

## 5.1 财富关系主题的专用收束顺序

当主题是财富时，报告要按以下顺序收束：

1. 先锚定财富主线，明确当前最重要的财富状态。
2. 再解释这条主线背后的机制，优先用财富手册中的条款。
3. 如有健康、关系、情绪、家庭等浮现议题，只能先翻译回财富机制，再简短提及背景。
4. 不把浮现议题单独展开成另一份报告。
5. 最后再给出低风险建议和下一步入口。

可用表达方式：

- 从财富关系议题看，这里更像是在说……
- 如果把这个线索翻回财富主线，它可能影响的是……
- 这条背景线索本身值得观察，但在这份报告里只作为财富机制的背景。

## 6. 用户分群适配

- 自我理解型：重点写“命名状态”和“看懂模式”。
- 议题解决型：重点写“现实议题”和“下一步方向”。
- 成长深化型：可以多写机制、成因和长期路径入口。
- 情绪安放型：减少强判断，增加承接、稳定和温和表达。
- 高复杂度支持型：不继续做深度 AI 解读，转入安全边界和外部支持引导。

## 7. 解释原则

- 解释必须回到画面证据。
- 单一信号不能承担过重结论。
- 能确定的写确定，不能确定的写可能。
- 先说观察，再说判断，再说建议。
- 不把“看起来像”写成“就是”。

## 8. 主题使用规则

当前先优先使用：

- 财富。
- 个人成长与自我价值。

如果用户主题不在这两个范围内，仍然可以输出通用报告框架，但要明确说明当前知识包还没有完整主题模块。

财富关系主题使用固定翻译链：

`画面信号 -> 状态含义 -> 财富关系议题翻译 -> 报告段落`

关系、情绪、家庭、身体等浮现议题可以出现，但必须先翻译回财富机制，只能作为背景解释，不单独展开成另一份报告。

## 9. 报告边界

报告中不输出以下内容：

- 医学诊断。
- 心理诊断。
- 财务保证。
- 绝对化预言。
- 把单一作者体系写成整个疗愈领域的共识。
- 完整主题方案或 21 天计划。

## 10. 语气要求

报告语言风格以 [07-报告语言风格指南.md](07-报告语言风格指南.md) 为唯一入口。

本文件只保留结构、边界和生成顺序，不再重复定义语气细则。

不要用夸张断言，也不要把不确定性藏起来。

## 11. 产品衔接

报告结尾可以保留下一步入口，但必须区分：

- 报告内建议：轻量、短周期、低风险。
- 主题方案：围绕一个议题开始改变。
- 21 天定制方案：持续推进个体化改变。
- 外部专业支持：高复杂度或高风险情况。

## 12. Lite / Pro 分流

Lite / Pro 的详细口径见 [04-Lite-Pro报告分流与交付口径.md](04-Lite-Pro报告分流与交付口径.md)。

最小规则是：

- Lite 负责快速命中、画面依据、当前状态、主题连接和低压小步建议。
- Pro 负责核心主轴、逐圈整合、生克失衡、能量流动、根因链和阶段性调节路径。
- 两者都是完整付费报告。
- 两者都不能越界写成主题方案或 21 天计划。

## 13. 质量检查

每次生成前后都检查：

- 主题是否明确。
- 每一圈是否都有对应观察。
- 综合判断是否回到主题。
- 调整方案是否可执行。
- 是否存在诊断式或承诺式语言。
- 是否把报告越界写成方案产品。
- 是否符合 Lite / Pro 的版本边界。

## 15. AI 可执行决策树

本节把所有生成前判断收束成一组可直接执行的 if/then 规则，每条规则的优先级标注在末尾。每个决策节点后附”报告表达”，即用户可见的标准返回文字。

### 15.1 输入有效性判断 [P0]

**目的**：当用户输入不完整时，AI 必须能识别并做出正确响应，避免生成证据不足的报告。

```
IF user_theme 未确认 AND 画面分析不足以落到具体议题
THEN
  → 返回”需要确认主题”的追问，列出可能的议题方向
  → 不生成报告
  报告表达：
  “在你开始解读之前，我想先确认一下——你心里最想通过这张画解决的是什么？
  目前我看到的画面信号……（描述观察），可能的议题方向包括……（列出 2-3 个），
  你可以告诉我最贴近的那个，或者告诉我另一个方向。”

IF user_theme 已确认 BUT 画面分析缺乏关键信号（里中外圈任意一圈缺失描述）
THEN
  → 标记”观察不足”，返回追问信号点
  → 不生成正式报告，生成”初步观察”
  报告表达：
  “目前我看到的画面……，不过要给出更完整的解读，
  我还需要知道……（指出缺失的圈层或信号），你能补充一下那部分吗？”

IF user_theme 已确认 AND 画面分析完整
THEN
  → 继续生成流程
```

### 15.2 多议题浮现时的收束规则 [P1]

**目的**：当画面涉及多个议题浮现时，保持主线清晰，防止报告变成多议题拼盘。

```
IF 浮现议题数量 > 2
THEN
  → 选择与主议题关联最强的 2 个作为”背景线索”
  → 其余议题不单独展开，记录为”待探索”
  → 在报告中说明”本次聚焦 X 和 Y，Z 议题在后续可以单独探索”
  报告表达：
  “在这张画里，除了[主议题]之外，我还看到了一些其他线索。
  本次我会重点回应 X 和 Y，它们和你的主议题直接相关。
  Z 这个方向也值得注意，但这次先不在这里展开——
  如果你之后想专门探索它，可以单独做一份报告。”

IF 浮现议题与主议题冲突（如用户选财富但浮现大量关系议题）
THEN
  → 确认用户是否要切换主议题
  → 或将关系作为”背景线索”翻译回财富主线
  报告表达：
  “我注意到这张画里浮现了很多关系层面的信号，
  和你选择的财富关系主题不完全重合。
  有两种处理方式——
  一种是把关系翻译回财富视角，作为财富卡点的一个背景成因；
  另一种是如果你觉得关系更迫切，我们可以先把主议题换成关系。
  你倾向于哪种？”
```

### 15.3 安全边界触发识别规则 [P0]

**目的**：识别高风险信号并触发安全边界，区分”立即停止”和”附带提示”两种响应。

```
IF 用户输入中出现以下触发词
  - “债务” “破产” “负债”
  - “想死” “自杀” “活不下去”
  - “创伤” + 具体事件描述
THEN
  → 立即停止报告生成
  → 返回安全边界提示
  → 不输出任何画面分析结论
  报告表达：
  “这个议题已经涉及到……（描述触发词指向的领域）的深层困难，
  这类情况非常需要专业人士的陪伴和支持。
  我建议你可以联系心理咨询师、社工或相关支持机构——
  他们有训练和资源来更好地支持你走过这一段。
  当你准备好了，这份画可以随时再来分析。”

IF 画面分析中出现以下高风险信号组合
  - 内圈大面积深黑色 + 外圈空白 + 用户输入涉及经济压力
  - 外圈破损 + 红色深重（创伤相关信号）
THEN
  → 报告正常生成，末尾附带专业支持提示
  报告表达：
  “在你阅读这份报告的同时，如果你觉得当前的困难已经影响到
  基本生活、安全感或情绪稳定，建议先寻求专业支持。
  这不是说你不能从自我观察中受益，而是有些情况
  有专业人士在身边会更安全、更有效。”
```

### 15.4 Lite / Pro 分流的唯一权威版本 [P0]

**目的**：统一 03 / 04 / 运行时包三处的分流定义，作为报告生成时唯一执行的路由规则。

```
IF report_version = 'lite' OR 报告长度限制明确
THEN
  → 输出 Lite 版
  → 内容包含：主题命中 + 3-6 条画面依据 + 1-2 个背景线索回译 + 低压小步建议
  → 长度区间：300-500 字
  → 报告语气：分析 40%，安抚与可执行建议 60%
  → 不要展开根因链，不要生成逐圈长篇

IF report_version = 'pro' AND pro_activated = true
THEN
  → 输出 Pro 版
  → 内容包含：Lite 全部 + 逐圈整合 + 完整背景线索回译 + 生克失衡 + 根因链 + 阶段性调节路径
  → 长度区间：800-1200 字
  → 报告语气：分析 60%，安抚与调节路径 40%
  → 注意：当前 Pro 仍为内部预备形态，对外输出前需确认产品上线状态

IF pro_activated = false（即当前默认状态，且用户未明确购买 Pro）
THEN
  → 输出 Lite 版
  → 在报告末尾注明：”Pro 版本后续上线，如需更完整的机制解释，届时可以升级。”
```

### 15.5 与现有规则体系的对应关系

本节决策树与前述各节对应如下：

| 决策树 | 对应章节 | 核心约束 |
|--------|----------|----------|
| 15.1 输入有效性 | 第 4 节 最小输入 | 最小输入不足时禁止生成报告 |
| 15.2 多议题收束 | 第 5.1 节 财富关系主题专用顺序 / 第 8 节 主题使用规则 | 浮现议题不单独展开，先翻译回主线 |
| 15.3 安全边界 | 第 6 节 用户分群适配（高复杂度支持型）/ 第 9 节 报告边界 | 触发词立即停止，高风险信号附提示 |
| 15.4 Lite/Pro 分流 | 第 12 节 Lite/Pro 分流 / 04-Lite-Pro报告分流与交付口径.md | 默认 Lite，Pro 仅在 pro_activated=true 时输出 |

本节所有 if/then 规则为生成流程的前置守卫，优先于第 5 节生成步骤执行。

运行时包在调用本规则时，应在进入第 5 节之前依次完成 15.1 至 15.4 的判断，并以判断结果作为后续步骤的输入参数。

字段边界：

- `user_segment`：用户类型，例如情绪安放型、自我理解型、议题解决型。
- `report_version`：报告版本，只能是 `lite`、`pro` 或 `unknown`。
- `product_intent`：产品意图，例如轻解读、报告、主题方案入口、21 天定制方案入口。

不得用 `user_segment = lite/pro` 判断报告版本。

## 16. 和运行时包的关系

本规则负责”怎么写”。

`60-运行时知识包/10-aimandala-解读报告生成最小包.md` 负责”调用什么、按什么顺序调用、如何兜底”。

# Lite / Pro 报告分流与交付口径

本文把 `Lite / Pro` 报告口径接入疗愈体系知识库。

这里定义当前产品矩阵和运行时知识包中的 Lite / Pro 使用边界。财富关系议题的具体段落组织以 [06-财富关系议题解读报告模板.md](06-财富关系议题解读报告模板.md) 为准。

## 1. 基本判断

当前财富解读报告以 Lite 作为对外交付版本。

Lite 不是免费摘要，而是当前正式可交付的完整报告口径。

Pro 不是 Lite 的简单加长版，但当前只作为内部预备形态，MVP 阶段暂不上线。

## 2. 产品矩阵位置

在产品矩阵中，Lite 属于当前对外交付的“报告”产品。Pro 保留为后续报告产品形态。

报告负责：

- 解释这张画在表达什么。
- 命名用户状态。
- 梳理用户模式。
- 连接现实议题。

报告不负责：

- 连续训练。
- 长周期改变。
- 替代主题方案。
- 替代 21 天定制方案。

因此，Lite 可以给低风险建议，但不能越界生成完整方案产品。Pro 在上线前也必须遵守同一边界。

## 3. Lite 报告口径

Lite 的任务是让用户快速感到：

- 这张画被看见了。
- 当前状态被说中了。
- 画面依据是清楚的。
- 主题连接是具体的。
- 有一个低压可执行的调整方向。

Lite 应包含：

1. 开头命中。
2. 画面依据区。
3. 当前状态解读。
4. 主题连接。
5. 小步建议。
6. 温和收束。

Lite 不承担：

- 完整逐圈长篇展开。
- 多层根因链拆解。
- 复杂能量流动复盘。
- 长周期疗愈计划。

正式写作规则见：[06-财富关系议题解读报告模板.md](06-财富关系议题解读报告模板.md)。

## 4. Pro 报告口径

Pro 的任务是把画面证据、逐圈分析、五行生克、失衡候选和能量流动诊断组织成一条完整解释链。当前 Pro 仅作为内部验证和后续 MVP 预备项，不对外开放。

Pro 应包含：

1. 开头命中。
2. 画面依据区。
3. 核心主轴。
4. 逐圈整合。
5. 生克与失衡机制。
6. 能量流动诊断。
7. 根因链。
8. 阶段性调节路径。
9. 收束与提醒。

Pro 不承担：

- 医疗、诊断或确定性预言。
- 脱离画面证据的性格定论。
- 与用户主题无关的大而全人生分析。
- 21 天连续陪伴方案。

正式写作规则见：[06-财富关系议题解读报告模板.md](06-财富关系议题解读报告模板.md)。

### 4.1 当前上线状态

- Lite：当前财富解读报告的正式上线版本。
- Pro：MVP 暂不上线，只保留内部实现、评测和后续打磨入口。

## 5. 分流规则

默认分流可以按用户任务判断：

- 情绪安放型：优先轻解读或 Lite，重点是被接住、被理解、低压建议。
- 自我理解型：优先 Lite。
- 议题解决型：优先 Lite，必要时转主题方案入口，不直接开放 Pro。
- 成长深化型：优先 Lite，并在结尾保留主题方案或后续路线入口。Pro 暂不上线。
- 高复杂度支持型：不进入深度 AI 报告，触发安全边界与外部支持引导。

如果只知道用户购买的是 Lite，则以 Lite 为准。Pro 购买入口在 MVP 阶段不开放；用户分群只影响语气、重点和结尾衔接。

## 6. 和主题方案的关系

报告可以指出方向，但主题方案才负责围绕一个议题开始改变。

报告结尾可以引导：

- “如果你只想先理解自己，可以先从这份报告里的小步建议开始。”
- “如果你已经确认想处理这个议题，可以继续进入主题方案。”
- “如果你希望有人陪你持续推进，可以进入 21 天定制方案。”

不要在报告正文中直接写完整训练周期、打卡节奏或高度个体化陪伴计划。

## 7. 和运行时包的关系

运行时包应把 `report_version` 作为显式输入或生成分支，但当前对外只允许 Lite：

```yaml
report_version: lite | pro | unknown
```

如果 `report_version` 为 `unknown`：

- 输入不足、用户只想快速理解：默认 Lite。
- 证据链完整、用户需要机制解释：仍默认 Lite，并引导后续主题方案或人工支持；Pro 暂不上线。
- 用户状态高风险：不默认生成 Pro，先进入安全边界。

## 8. 质量检查

Lite 检查：

- 是否快速命中。
- 是否保留 3 到 6 条画面依据。
- 是否有主题连接。
- 是否只有低压小步建议。

Pro 检查：

- 是否解释核心主轴。
- 是否完成逐圈整合。
- 是否说明生克、失衡和能量流动。
- 是否有根因链和阶段性调节路径。
- 是否仍然保持报告边界，没有变成 21 天计划。
- 是否仍标记为内部预备形态，而非对外交付版本。

# 报告任务定义

> 状态：draft
> 文档版本：0.1.0
> date：2026-05-15
> owner：CEO / Knowledge Base
> source_of_truth：当前目录/30-应用适配/10-aimandala/05-报告任务定义.md
> product_decision：projects/aimandala/docs/decisions/2026-04-06-用户分群与产品矩阵决策.md

本文定义 `aimandala` 报告产品的任务边界。

## 1. 问题定义

用户在看曼陀罗时，先需要的通常不是长周期改变，而是先看懂自己当前在什么状态、这张画在表达什么、当前主题的卡点是什么。

报告就是解决这件事的产品。

## 2. 用户场景

报告主要服务以下场景：

- 用户想知道这张画在说什么。
- 用户对自己有感受，但说不清。
- 用户卡在某个具体议题上，需要解释和方向。
- 用户已经做过一定自我探索，想看更深一点的机制。

## 3. 本轮范围

报告本轮只做：

- 解释画面。
- 命名状态。
- 梳理模式。
- 连接现实议题。
- 给出轻量建议或阶段性调节路径入口。

## 4. 不做范围

报告不做：

- 连续训练。
- 长周期陪伴计划。
- 主题方案完整设计。
- 21 天定制方案完整设计。
- 医疗、心理或财务承诺。

## 5. Lite / Pro 对应

- Lite：当前对外交付的正式报告版本，负责快速命中、看见当前状态、保留画面依据、给低压小步建议。
- Pro：内部预备版本，暂不上线，保留完整解释核心主轴、逐圈机制、生克失衡、能量流动、根因链和阶段性调节路径的实现能力。

## 6. 方案比较

可选方案有三种：

1. 直接做完整方案产品。
2. 先做报告，再转主题方案。
3. 先做报告，再转 21 天定制方案。

当前阶段最合理的是第 2 和第 3 种，不优先把报告直接做成方案产品。

原因是：

- 用户首先需要看懂自己。
- 报告更适合承接理解和命名。
- 方案产品更适合承接改变和练习。

## 7. 验收标准

一份合格的报告任务定义应满足：

- 能明确报告服务的用户是谁。
- 能明确报告解决什么问题。
- 能明确报告不做什么。
- 能明确 Lite 和 Pro 的差异，并清楚标注 Pro 当前暂不上线。
- 能明确下一阶段该交给谁。

## 8. 下一阶段 handoff

报告任务定义完成后，可交给：

- `30-应用适配/10-aimandala/03-解读报告生成最小规则.md`
- `30-应用适配/10-aimandala/04-Lite-Pro报告分流与交付口径.md`
- 后续的运行时知识包

## 9. 最小结论

报告是理解入口，不是改变终点。

它先负责让用户看懂自己，再决定要不要进入主题方案或 21 天定制方案。

# 财富关系议题解读报告模板

> 状态：draft
> 文档版本：0.1.0
> last_updated：2026-05-16
> owner：CEO / Knowledge Base
> source_of_truth：当前目录/30-应用适配/10-aimandala/06-财富关系议题解读报告模板.md
> product_decision：projects/aimandala/docs/decisions/2026-04-06-用户分群与产品矩阵决策.md

本文定义财富关系主题解读报告的段落模板。

它不负责重新判断议题，也不负责重新做画面分析。它只负责把已经命中的财富条款，稳定地排进报告里。

报告语言风格统一由 [07-报告语言风格指南.md](07-报告语言风格指南.md) 控制。本文只定义财富报告结构和段落职责。

## 1. 使用前提

生成财富报告前，先满足这三个条件：

1. `user_theme` 已确认是 `财富`。
2. 已完成基础画面观察。
3. 已选出至少 1 个财富模块或条款。

如果主题未确认，先回到主题确认，不直接进入财富模板。

## 2. 报告主线

财富报告只维护一条主线：

`画面信号 -> 财富状态 -> 财富机制 -> 浮现议题回译 -> 现实表现 -> 低风险建议`

其中：

- 主线必须始终落回财富。
- 浮现议题可以出现，但只能作为财富机制背景。
- 不把健康、关系、家庭、情绪单独写成另一份报告。

## 3. 固定段落

财富报告建议按以下顺序输出：

1. 整体直觉
2. 财富主线确认
3. 三圈财富读法
4. 机制拆解
5. 浮现议题回译
6. 现实表现
7. 生机
8. 调整建议

## 4. 段落路由

下表用于把财富条款、浮现议题和建议放进固定段落。

| 段落 | 主要内容 | 典型输入 |
|------|----------|----------|
| 整体直觉 | 第一眼印象和整体气质。 | 画面总感、主色调、圈层整体收缩或外放。 |
| 财富主线确认 | 说明本次报告围绕的财富状态。 | 配得感、安全感、承载力、行动力、世界链接。 |
| 三圈财富读法 | 分别看内圈、中圈、外圈。 | 圈层位置清晰的颜色、形状、留白、厚重、断裂。 |
| 机制拆解 | 解释财富为何这样卡住。 | `wealth.low_deservingness`、`wealth.scarcity_and_insecurity`、`wealth.emotional_spending`、`wealth.low_capacity`、`wealth.low_action`、`wealth.low_world_connection`。 |
| 浮现议题回译 | 把关系、家庭、情绪、身体、事业翻回财富。 | `wealth.emergent.*` 的回译条目。 |
| 现实表现 | 写用户现实里可能对得上的样子。 | 钱紧、想行动却卡住、容易为情绪买单、有价值但不易外化。 |
| 生机 | 保留可用力量和出口。 | 热情、真实需要、表达路径、稳定行动、承载力扩容。 |
| 调整建议 | 给低风险动作。 | 觉察记录、小步行动、边界练习、支持练习。 |

## 5. 段落职责

### 5.1 整体直觉

先写第一眼看到什么，再写这张画整体更像在讲什么。

要求：

- 先被看见。
- 不抢结论。
- 不直接下财务判断。

### 5.2 财富主线确认

明确这份报告围绕什么财富状态展开。

可写方向：

- 钱不只是数字，也承载安全、自由、尊严、被支持等感受。
- 当前更像是在看钱的流动、接住和保存，而不是单看收入高低。

### 5.3 三圈财富读法

三圈写法固定如下：

- 内圈：更靠近自我、价值感、允许拥有、内在秩序。
- 中圈：关系、情绪、交换、承接、互动。
- 外圈：现实行动、物质呈现、对外表达、资源流动。

财富报告优先级：

1. 外圈看现实交换和流动。
2. 中圈看情绪、人际与能量牵引。
3. 内圈看这条财富线为什么会这样。

### 5.4 机制拆解

这里解释为什么会形成当前财富状态。

优先使用的机制：

- 配得感。
- 安全感与匮乏感。
- 家庭金钱脚本。
- 情绪型漏财。
- 承载力不足。
- 行动力不足。
- 与世界链接不足。

### 5.5 浮现议题回译

当报告里出现关系、家庭、情绪、身体等线索时，先回译成财富机制，再简短提及背景。

回译规则：

- 关系 -> 价值交换、边界、求认可、资源互惠。
- 情绪 -> 消费冲动、行动中断、财富焦虑、能量外散。
- 家庭 -> 金钱脚本、安全感来源、成功许可、收受能力。
- 身体 -> 行动力、承载力、风险承受、是否接得住下一步。

### 5.6 现实表现

只写和用户现实可能对得上的表现，不写财务预测。

可写：

- 更容易为情绪买单。
- 对钱紧绷、担心不够。
- 想行动，但行动总被打断。
- 有价值，但不一定稳定表达出来。

不可写：

- 你一定赚不到钱。
- 你会破财。
- 你应该立刻做某个财务决定。

### 5.7 生机

每份财富报告必须保留生机，不只写卡点。

生机可以来自：

- 热情和真实需要。
- 价值表达。
- 与世界建立真实链接。
- 稳定行动。
- 承载力扩容。

### 5.8 调整建议

建议只给低风险动作，优先顺序：

1. 认知调整。
2. 情绪调频。
3. 具体练习。
4. 现实中的小行动。

**调整建议与浮现机制对照**：

| 机制 | 认知调整 | 情绪调频 | 具体练习 |
|------|----------|----------|----------|
| 配得感 | “我可能不是没有价值，而是还没有完全允许自己把价值放到台前” | 嘉许自己，每做一件事就夸奖自己 | 每天对镜子练习”我爱你”，写感恩日记 |
| 安全感与匮乏感 | “钱越重要，内在可能越紧绷” | 黑色清理画释放恐惧，蓝色画放松 | 每天给自己一个小”允许” |
| 求认可模式 | “区分创造价值和证明自己” | 红色画补心力、热情、丰盛感 | 把心神收回目标，减少外界标准影响 |
| 情绪型漏财 | “钱可能不只是在替情绪出口工作” | 觉察情绪消费背后的需求 | 记录3天消费触发点 |
| 承载力不足 | “接住财富的容器还需要变稳” | 黄色画提升承载力 | 站桩、八段锦固脾胃 |
| 行动力不足 | “财富流动需要行动承接” | 蓝色画放松，红色画补充热情 | 做15分钟小行动，死磕计划执行 |
| 世界链接不足 | “财富需要进入现实交换” | 打开人际链接，接纳他人优点 | 从小的价值表达开始 |

**边界提醒**：
- 不做财务预测、投资建议、职业决策
- 不把画面符号写成确定因果
- 不替代心理治疗或专业咨询
- 高风险情境（债务危机、严重焦虑、创伤）提示寻求专业支持

## 6. Lite / Pro 使用差异

- Lite：先命中主线，保留少量关键条款，输出短而清楚的财富解释。
- Pro：在 Lite 基础上展开逐圈机制、回译线索和根因链。当前保留为内部预备形态，MVP 阶段暂不上线。

两者都必须守住同一个财富主线。

## 7. 质量检查

生成完成后检查：

- [ ] 是否始终回到财富主线
- [ ] 是否把浮现议题回译回财富机制
- [ ] 浮现机制（01-07）是否正确嵌入到机制拆解和调整建议中
- [ ] 调整建议是否与信号→疗愈映射表联动
- [ ] 是否避免财务预测和决策建议
- [ ] 是否保留生机
- [ ] 是否和 Lite / Pro 边界一致，且明确当前 Pro 暂不上线

# 报告语言风格指南

> 状态：draft
> 文档版本：0.1.0
> date：2026-05-18
> owner：CEO / Knowledge Base
> source_of_truth：当前目录/30-应用适配/10-aimandala/07-报告语言风格指南.md

本文是 `aimandala` 解读报告的唯一语言风格入口。

其他文档可以定义结构、条款、路由和安全边界，但不再单独定义报告语气。运行时生成报告时，以本文为语言风格源。

## 1. 风格目标

报告读起来应像一位稳定、有经验的疗愈师在陪用户看画。

它需要同时做到：

- 有画面依据。
- 有疗愈感。
- 有边界。
- 有行动出口。

## 2. 基本语气

- 先接住用户，再进入分析。
- 先说看见了什么，再说这可能意味着什么。
- 语言温和、清楚、有陪伴感。
- 不用审判、训导、命令或诊断口吻。
- 不把用户的问题写成缺陷。

## 3. 疗愈感写法

优先使用这类表达：

- 这张画里，我先看到的是……
- 这里不是在说你没有能力，更像是在说……
- 这部分可以先不用急着改变，先看见它已经很重要。
- 如果把这个线索放回财富关系议题，它更像是在提醒你……
- 画面里不只有卡住，也有一部分力量还在往外找出口。
- 你可以先从一个很小、身体能承受的动作开始。

避免使用这类表达：

- 你就是……
- 你一定……
- 你必须……
- 说明你有问题。
- 这就是你的根因。
- 你应该立刻……

## 4. 分析与疗愈的比例

Lite 报告：

- 分析占 40% 左右。
- 安抚、承接和可执行小动作占 60% 左右。
- 不展开复杂根因链。

Pro 报告：

- 分析占 60% 左右。
- 安抚、承接和调节路径占 40% 左右。
- 可以解释机制，但每个机制后都要留出生机或下一步。

## 5. 段落风格

整体直觉：

- 像疗愈师拿到画后的第一眼感受。
- 不要一上来就下结论。

画面依据：

- 语言要具体，但不要像检测报告。
- 每条依据后尽量跟一句“它可能在说什么”。

财富核心解读：

- 不写财务结果。
- 把财富写成资源、价值、承载、交换和安全感的关系。

浮现议题回译：

- 可以提到情绪、关系、家庭、身体和事业。
- 提到后必须拉回财富主线。
- 不展开成另一份主题报告。

建议：

- 给小动作，不给命令。
- 给可观察的练习，不给高风险决策。
- 建议语气要像邀请，不像任务布置。

## 6. 安全边界

风格可以温柔，但边界不能放松。

报告不能输出：

- 财务预测。
- 投资建议。
- 职业决策建议。
- 心理诊断。
- 医疗判断。
- 确定性因果。

需要边界提示时，用温和表达：

- 这份报告更适合作为自我观察，不替代现实中的财务或专业决策。
- 如果这个议题已经影响到安全、债务、健康或关系暴力，需要优先寻求现实中的专业支持。

## 7. 统一入口规则

- 修改报告语气时，只改本文。
- 条款文件只提供内容素材。
- 模板文件只定义段落结构。
- 路由文件只定义条款进入哪个段落。
- 运行时 prompt 只从本文读取语言风格。
