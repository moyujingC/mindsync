# 曼陀罗基础层解读流程

> 状态：draft
> 版本：0.1.0
> date：2026-05-18
> owner：CEO / Knowledge Base
> source_of_truth：当前目录/20-疗愈体系/20-流派层/10-曼陀罗/00-曼陀罗基础层解读流程.md

本文定义曼陀罗基础层的正式使用顺序。当前目录不再按原手册章节顺序组织，而是按实际解读流程组织。

## 1. 标准流程

基础层解读按以下顺序进行：

```text
画面识别与描述
  -> 圈内五行解读
  -> 圈内元素关系判断
  -> 跨圈能量解读
  -> 议题翻译
```

这条流程用于区分“看见了什么”和“解释成什么”。AI 生成报告时，应先完成画面事实描述，再进入五行和议题解释，避免直接从颜色或形状跳到主题结论。

## 2. 画面识别与描述

目录：`10-画面识别与描述/`

这一层只回答“画里有什么”，包括：

- 三圈边界和画面区域。
- 颜色、深浅、浓淡、渐变、面积和留白。
- 形状、方向、完整度、尖锐度、闭合度。
- 结构、重复、切分、疏密、内聚或外散。

颜色和形状在这里先作为视觉事实描述，不直接生成完整结论。

## 3. 圈内五行解读

目录：`20-圈内五行解读/`

这一层把颜色和形状转成五行元素，并在每一圈内部判断元素关系。

使用规则：

- 五行分析只限圈内元素之间的关系，不把一个圈整体判成单一五行。
- 颜色和形状都是五行判断输入。比如红色和三角形都可进入火，绿色和长条形都可进入木。
- 判断时看具体元素是否相邻、相生、相克、被切分、无根、失衡或不能成循环。
- 真实白色、纸面留白和色块缝隙可作为金能量候选；模板黑线、印刷线稿和三圈标记线不作为画作元素。

## 4. 跨圈能量解读

目录：`30-跨圈能量解读/`

这一层处理内圈、中圈、外圈之间的整体关系。

使用规则：

- 三圈联动使用三才、圈层语义和能量流动，不用五行生克替代。
- 内圈偏本源和内在，中圈偏当下能量和关系，外圈偏现实行动和外界呈现。
- 跨圈解读要看内外是否一致、能量是否贯通、现实是否承接内在，而不是把跨圈颜色强行做五行生克。

## 5. 组合模式

目录：`40-组合模式/`

这一层记录多个信号共同出现后的综合判断。组合模式不替代基础规则，只作为高阶综合判断和报告语言参考。

使用边界：

- 已审核案例规则可以进入报告候选，但仍需结合画面事实、圈层和用户主题。
- 组合模式不是穷举式映射表，不能作为 runtime 的唯一依据。
- 未命中的画面可以回到基础层推理，不应因为组合表没有覆盖就忽略画面事实。

## 6. 议题翻译

议题翻译不放在曼陀罗基础层内，而放在 `20-疗愈体系/10-议题层/`。

基础层只输出：

- 画面事实。
- 五行元素。
- 圈内五行关系。
- 跨圈能量状态。
- 组合模式候选。

财富、关系、事业、健康等议题如何解释这些信号，由各议题自己的翻译文件决定。

# 画面分析基础

## 定位

本文档是曼陀罗画面分析的基础框架，定义如何对一幅曼陀罗画作进行系统分析。

---

## 一、三圈划分

### 1.1 划分方式

曼陀罗画面从中心到边缘划分为三个同心区域：

| 圈层     | 位置         | 定义          |
| ------ | ---------- | ----------- |
| **内圈** | 中心区域（约1/3） | 最核心的圆域      |
| **中圈** | 中间区域（约1/3） | 内圈与外圈之间的过渡带 |
| **外圈** | 边缘区域（约1/3） | 最外围的圆域      |

### 1.2 边界判定

当圈层边界不清晰时，按以下优先级判定：

1. **形状边界**：明显的形状分界处
2. **颜色分界**：颜色变化的分界线
3. **比例估算**：约1/3等分

### 1.3 三圈的理论依据

三圈划分基于以下理论：

| 理论来源       | 内圈       | 中圈        | 外圈        |
| ---------- | -------- | --------- | --------- |
| **佛教密宗坛城** | 内坛（本尊殿）  | 中坛（菩萨/护法） | 外坛（防护/屏障） |
| **荣格人格结构** | 自性/集体无意识 | 个体无意识     | 人格面具      |
| **东方哲学**   | 天（灵性）    | 人（情绪/人际）  | 地（身体/现实）  |
| **心理空间隐喻** | 核心自我     | 人际区域      | 公共区域      |

---

## 二、画面分析要素

### 2.0 AI 视觉识别边界

以下规则专门用于 AI 识别，不用于反向否定疗愈师的人工判断。

- 模板黑线、印刷线稿、三圈标记线只用于识别形状边界或圈层边界，不计入画作颜色、画作元素或五行证据。
- 画作本身的白色、纸面留白、图案间空隙可以识别为金能量。
- 画面上外圈的外边以内，只要有真实留白，都可以作为金能量候选；是否参与某个生克关系，还要看它是否与对应元素在同圈内形成有效相邻或切分。
- 三圈标记图只用于确认圈层，不读取标记线颜色。
- 若原画作与三圈标记图颜色判断冲突，以原画作为准。

### 2.1 颜色

| 分析维度 | 内容 |
|----------|------|
| 颜色种类 | 画面使用了哪些颜色 |
| 颜色深度 | 浅色/正色/深色 |
| 颜色分布 | 各圈的颜色分布情况 |
| 颜色主次 | 以哪种颜色为主 |

### 2.2 形状

| 分析维度 | 内容 |
|----------|------|
| 形状种类 | 画面中出现的形状类型 |
| 形状特征 | 锐利/柔和/规则/不规则 |
| 形状方向 | 向上/向下/向内/向外 |
| 形状组合 | 形状之间的组合关系 |

### 2.3 位置关系

| 分析维度 | 内容 |
|----------|------|
| 位置分布 | 元素落在哪个圈层 |
| 相互位置 | 元素之间的上下/左右/内外关系 |
| 边界关系 | 元素与圈层边界的相对位置 |

---

## 三、各圈特殊关注点

### 3.1 内圈关注点

| 关注点 | 说明 |
|--------|------|
| 中心充盈度 | 中心是否有内容，还是空洞 |
| 中心形状 | 中心区域的形状特征 |
| 核心能量 | 内圈整体的能量状态 |

内圈也可进一步看作“魂、天、本源层”。

看什么：

- 中心图形是否完整。
- 中心是否有空缺、断裂或留白。
- 线条是粗还是细。
- 颜色是纯色还是杂色，深还是浅。
- 形状是尖锐还是圆润。

解读逻辑：

- 规整圆满：本心稳定，内在自洽，有内核力量。
- 残缺空白：内心迷茫，初心迷失，内在空虚，缺乏安全感。
- 深色居多：内在压抑，心事重，自我封闭。
- 浅色柔和：内心纯净，通透，觉知力强。
- 尖锐棱角：内在倔强，执念重，内心有对抗。
- 圆润曲线：本性温柔，包容，随顺。

### 3.2 中圈关注点

| 关注点 | 说明 |
|--------|------|
| 过渡状态 | 与内圈、外圈的过渡是否自然 |
| 能量流动 | 中间区域的能量是否顺畅 |
| 图案密度 | 中圈图案的密集程度 |

中圈也可进一步看作“气、人、情绪层”。

看什么：

- 中间花纹是否清晰。
- 缠绕线条是否顺畅，还是混乱、打结。
- 色块分布是否连续，还是被切割成多块。
- 图案是否有断裂、分层或反复回旋。

解读逻辑：

- 线条流畅：情绪稳定，人际和顺，能量通畅。
- 线条杂乱缠绕：内耗严重，纠结焦虑，感情内耗，人际关系拉扯。
- 色块分割明显：内心矛盾，双重性格，取舍两难。
- 色彩浓烈：情绪外放，感性重，爱恨分明。
- 色彩寡淡：情感疏离，不愿走心，习惯性克制。

### 3.3 外圈关注点

| 关注点 | 说明 |
|--------|------|
| 边缘完整性 | 边缘是否闭合，还是有破损/遗漏 |
| 边缘厚度 | 边缘的厚薄程度 |
| 边界清晰度 | 与外界的边界是否清晰 |

外圈也可进一步看作“形、地、现实层”。

看什么：

- 外围花边是否繁复。
- 边框是否闭合。
- 是否有缺口、破损或漏空。
- 装饰是繁还是简。
- 外圈颜色是厚重深色还是明亮浅色。

解读逻辑：

- 边框完整闭合：防御感强，边界清晰，懂得保护自己，生活安稳。
- 边框缺口破损：外界消耗大，容易被影响，无边界，易受他人拖累。
- 花边繁复：在意他人眼光，人设包袱重，社交思虑多。
- 外圈简约：活得通透，不在意世俗评价，行事随性。
- 外圈厚重深色：现实压力大，生活负担重，安全感不足。
- 外圈明亮浅色：外在运势顺，人缘好，现实环境宽松。

## 四、跨圈观察记录

本文档只负责记录跨圈观察项，不在这里生成跨圈综合结论。

画面识别阶段需要记录：

- 内圈、中圈、外圈是否都完整、规整或都有缺口。
- 三圈之间的颜色、形状和结构是否自然过渡。
- 内圈的状态是否能被中圈承接。
- 中圈的能量是否能流向外圈。
- 外圈是否能承接内在意图并形成现实表达。

跨圈综合判断统一进入 ../30-跨圈能量解读/01-三圈结构法.md，不在画面识别阶段提前下结论。

# 形状感知法

> 状态：draft
> 版本：0.1.1
> date：2026-05-16
> owner：CEO / Knowledge Base
> source_of_truth：当前目录/20-疗愈体系/20-流派层/10-曼陀罗/10-画面识别与描述/03-形状识别与感知.md

> 整理方式：原文保真重组

本文从 `01-曼陀罗解读手册原文.md` 中拆出“形状感知法”，作为画面识别和五行判断的形状入口。

## 1. 定位

曼陀罗中的形状及其排列，也代表着绘画者的某种心理暗示。

从远古时期，人们就通过形状来表达和沟通，后来形状又发展为符号和图腾，被认为是通往不同空间的钥匙，反映了人类对自然和超自然力量的理解和崇拜。

曼陀罗中的形状也可以通往不同的意识空间。在绘画曼陀罗的过程中，画者的意识能量会逐渐归拢和整合，渐渐地回归自性。

在运用形状进行解读时，可以结合颜色、五行相生相克、高频组合模式等一起解读，这样能获得更多细节和具体信息。

形状在基础层有双重用途：

- 画面识别用途：描述画面中出现了什么形状、方向、完整度、闭合度、尖锐度和分布。
- 五行判断用途：把形状作为五行元素候选，再结合颜色、圈层和相邻关系进入圈内五行解读。

使用时先看：

- 形状是什么。
- 形状落在哪一圈。
- 形状是否完整、闭合、尖锐、圆润。
- 形状方向是向内、向外、向上，还是散开。
- 形状是否被其他颜色或形状分割。

## 2. 大圆

特征描述：大圆代表容纳、包容、承载、保护等含义。很多曼陀罗本身就是一个大圆，圆形取自“天体运行”，宇宙运行的轨迹是围绕圆在运转，星球也是圆的，代表自成一体。

同时圆形本身也是生命起始之初，是生命的形状，比如蛋、花苞、种子、卵子、子宫，组成人体的细胞等，因此圆也具有孕育的含义。这个世界是一个圆，我们经常说一花一世界，每一朵花都是一个天然的曼陀罗。

五行属性：土属性。

代表含义：容纳、承载力、孕育、有资源、安于现状、能量自成一体。也代表舒适区、安全区、自我保护、忍辱负重、逆来顺受等。

原文解释：能量自成一体，可能别人觉得他有很多缺点，但他自己觉得很好，不内耗。

在解读大圆的时候，要看其内部是否被其他形状将其分割。如果有，说明绘画者能量无法自成一体，容易有内在冲突。

例图判断：如果内圈里是大圆，通常表示绘画者内心有和平、安好的能量，有一个自己比较享受的空间，对现状中的很多事情能够接受。

## 3. 小圆

特征描述：小圆只有自己的小世界，无法容纳更多，甚至会排斥外面的世界，偏向于自我保护。

五行属性：金属性。

代表含义：有边界感、努力、注重价值；也代表挑剔、评判、害怕犯错、疑心较重等。

通常在曼陀罗里有一排小圆，代表绘画者有比较多恐惧，以前可能发生过一些事情，吃过亏、上过当或受过伤害，形成一种自我防御模式。

如果特别小的圆在外圈排成一列，也可能代表绘画者身体上有结节或淤堵。

例如外圈有一排小圆，代表绘画者对外界有恐惧和不安全感，以前吃过亏或上过当。如果圆圈是蓝色，蓝色为水属性，水代表智慧、信息的流通等，表明绘画者很可能在信息上吃了亏，曾经听信别人的信息产生了损失，现在对外界信息会很谨慎。

## 4. 三角形

特征描述：三角形有三个尖角，就如自然界中燃烧的火焰一样，主炎上，向上突破发展的趋势。这种能量是有起伏、有波动的，具有跳跃性和不稳定性，就如燃烧时的火焰，时而火势猛烈，时而减弱，要看曼陀罗里是否有木来作为支撑力。

同时三角形具有尖角，具有尖锐性，能够突破某些规定，象征进取、冲突等力量。

五行属性：火属性。

代表含义：有进取心，有心气，想象力丰富，热情活泼，愉悦；也代表爱面子，容易着急、急躁，愤怒上头，定力不够，难以在一件事情上一直专注，容易半途而废，虎头蛇尾，在兴趣和目标上经常改变，缺乏自律，害怕失去自由，害怕别人的看法和评价，不喜欢无聊等。

如果三角形的尖角对准内圈，说明绘画者有自我评判的习惯。

如果三角形的尖角对准外圈，说明绘画者想要突破现状，且容易遇到阻碍。

例图判断：如果内圈有多个向外的三角形，可能表示绘画者当下有开心、愉悦和向外发展的能量，但如果火能量没有木来支撑，也容易表现为能量不稳定、情绪体验丰富、行动被情绪拖拽，甚至陷入自我批评和心累。

## 5. 条状、长方形

特征描述：长方形是方形的延伸，象征着“木”的能量，可以扎根在土地，不断向上生长，具有生生不息和生机的特点。

同时长方形也通常让人联想木头、积木、现代建筑等，因此它也代表着不开窍、固执、一根筋、坚韧等。同时它自身内在有一种独立性、原则性和稳定性等特征。

五行属性：木属性。

代表含义：有原则、独立、生机、向上生长、积极向上、精进、三观正直；也代表耿直、固执、一根筋、以自我为中心，希望别人都听自己的，害怕失去自尊，有时候会对别人说教等。

例如中圈有很明显的深绿色长方形，且长方形比较小，被土包围着，说明绘画者在和家人的相处上，表面上很忍耐、很包容，实际上自己压抑了一些怨怒，有些地方想不通、钻牛角，身体上可能会有肝淤。

## 6. 正方形

特征描述：天圆地方，正方形也代表土属性，和大圆相似。

正方形和大圆的区别在于：大圆相对偏圆滑，在待人接物上相对圆融、更能忍耐，而正方形更突出土属性中稳固、坚固、踏实、诚实可信等含义。

正方形更让人感觉到可靠和踏实。同时正方形具有四个相等的边和四个直角，呈现出完美的平衡和对称性，因此也具有正直、三观正、有秩序、有规范和标准等含义。

五行属性：土属性。

代表含义：做事有规律，有规范，稳定，踏实，有秩序，组织安排可靠、周到，让人可信赖；也代表有棱有角不懂变通，木讷，过于谨慎，做事束手束脚，可能会拒绝改变，害怕不确定性，也害怕自己的努力没有结果。

例如外圈是绿色的正方形，面积比较小，既有土属性，又有木属性，且正方形面积小，土能量偏弱，绿色偏淡，也属于弱木。木克土，代表绘画者想要改变现状，但又抗拒变化，难以接纳改变所要面对的未知，面对外界的一些机会比较谨慎，也会担心自己的付出没有回报。

## 7. 波纹状

特征描述：波纹状让人联想到海浪、水波纹、涟漪等，它代表着水的能量。水的能量可以滋润万物，给万物养分，同时它也有惊涛拍岸、洪水泛滥的时候。

遇水则发，水为财富能量的象征。水也具有承载力，能承载信息的流通，因此波纹状也代表着新信息的流动。俗语说左右逢源，就是指这个人的水能量充足，沟通力很好。

五行属性：水属性。

代表含义：信息、才华、财富、具有同情心、滋养力、沟通力、灵活；也代表动荡不安、不稳定、对情绪和他人的话语敏感、恐惧心、玻璃心，害怕面对不确定性，害怕损失。

水波纹在内圈，说明内心动荡不安。

水波纹在中圈，说明最近能量波动比较大，情绪不稳定。

水波纹在外圈，代表外界接二连三发生一些事情，让绘画者感到烦躁或害怕面对。

例如外圈有很明显的水波纹，说明外面这些人和事，一个波浪接着一个波浪，绘画者总觉得外面接二连三地发生一些事，让 Ta 心底里会有一些莫名的害怕、紧张感、慌乱感，有时候甚至不知道怎么回应，回应的方式自己也不是很满意，会产生自我怀疑。

## 8. 使用边界

- 形状感知法只回答“画面里出现了什么形状，以及这个形状在曼陀罗语境下通常代表什么”。
- 形状本身不能单独生成完整结论，必须结合颜色、三圈位置、五行强弱和相邻结构。
- 同一种形状在不同圈层、不同颜色和不同朝向下，含义会发生变化。
- 形状例图只能作为判断参考，不应直接复制成报告结论。

> 状态：draft

> owner：CEO / Knowledge Base
> source_of_truth：当前目录/20-疗愈体系/20-流派层/10-曼陀罗/10-画面识别与描述/04-颜色识别与感知.md
> 原始来源：01-曼陀罗解读手册原文.md
> 整理方式：原文拆解 / 按颜色重组

本文从 `01-曼陀罗解读手册原文.md` 中重新拆出各种颜色对应的解读，作为画面识别和五行判断的颜色入口。

本文按“视觉颜色”组织，方便解读报告先识别颜色，再进入圈内五行、生克关系、跨圈能量和主题路由。五行原理、相生相克和元素系统在 `20-圈内五行解读` 目录维护。

颜色在基础层有双重用途：

- 画面识别用途：描述画面中出现了什么颜色、颜色深浅、面积、渐变、留白和分布。
- 五行判断用途：把颜色作为五行元素候选，再结合形状、圈层和相邻关系进入圈内五行解读。

## 1. 使用顺序

看颜色时先看四件事：

- 颜色是什么：红、黄、蓝、黑、绿、白、紫、橙、粉、玫红、咖色、金色等。
- 颜色落在哪一圈：内圈、中圈、外圈。
- 颜色状态如何：深、中、淡、浓重、过淡、渐变、面积大、零散不成片。
- 颜色之间有没有关系：是否被隔断、是否相生相克、是否形成循环。

## 2. 通用颜色状态

### 2.1 外圈颜色单一且面积大

外圈颜色单一且面积比例大，表示绘画者近期更关注物质、有形层面。

如果主题是财富，意识空间更倾向于赚钱、物质结果和现实收益。如果主题是身体，则更关注运动、饮食、医药等身体管理。

使用提醒：

- 先定三圈，再看颜色比例。
- 某种颜色比例过多时，可以判断这一类能量出现卡点。
- 不能只凭“颜色多”下结论，还要进入五行平衡和三圈位置判断。

### 2.2 渐变色

渐变色表示绘画者正在转变、调整，或试探着做出改变。

- 渐变色在内圈或中圈：内心想改变一些事情，对决定仍有犹豫，想做但还没确定。
- 渐变色在外圈：已经在现实层面试探着做出调整。

### 2.3 颜色浓郁、深重

颜色过于深重、浓郁，尤其是颜色涂满时，常见含义是：

- 渴望强烈。
- 进取心强。
- 容易着急、紧张、焦虑、担忧。

### 2.4 颜色浅、轻

颜色过淡，常见含义是：

- 心力不足。
- 行动力不足。
- 容易拖延、躺平。
- 湿气重，容易内耗。

## 3. 绿色

绿色在手册中归为木属性。

### 3.1 基础含义

- 正常：生机、成长、向上、独立、界限、乐观、学习、精进、愿意付出和分享。
- 太过：固执、评判多、容易自我批评或批评他人，容易暴躁，有掠夺式生长的倾向。
- 不足：怨气、嫉妒、郁闷、忧郁、憋闷，安全感不足，容易依赖他人；在财富主题中可能表现为信心不足、抗压力不强、行动力不足。

### 3.2 深绿

- 内圈：内在可能有伤痛或忧郁，无法释放；也可能有一套强固的思想体系，容易固执、钻牛角尖，对自我有严重评判。
- 中圈：近期可能郁闷、孤独，觉得身边人不理解自己，也可能对亲近的人有评判。
- 外圈：有担当，但容易以自我为中心，做事固执，对外界或他人有评判，别人可能觉得不好接近。

### 3.3 中绿

- 内圈：内在开始有信心和独立想法，对未来和自己有希望。
- 中圈：近期能量积极向上，能感染身边人；也可能需要独处和界限感。
- 外圈：外人容易认为绘画者三观正、积极、爱学习、独立性强，愿意付出和分享。

### 3.4 淡绿

- 内圈：内在有希望萌芽，但力量较弱，容易反复，需要被保护和认可。
- 中圈：相处中容易讨好或依赖对方，缺主心骨，遇到选择时容易优柔寡断。
- 外圈：别人觉得好相处，但本人对能力不够自信，行动力较弱，需要更多韧性。

## 4. 红色

红色在手册中归为火属性。

### 4.1 基础含义

- 正常：阳光、快乐、积极向上、热情、热爱、欣赏、创造力。
- 太过：着急焦虑，有伤痛，自我牺牲，爱而不得，善变，三分钟热度，容易半途而废。
- 不足或淡红：心力不足，热情不够，求爱求温暖，拖延，没有动力，容易依赖。

### 4.2 深红

- 内圈：有伤痛或愤怒积压在心底，压抑情绪无法释放，可能来自原生家庭或早年不公平对待。
- 中圈：对亲近的人有压抑和愤怒，不敢表达感受，积累久了可能爆发。
- 外圈：容易上火或压力外显；财富主题中容易漏财、攒不住钱，为感受或情绪买单。

### 4.3 中红

- 内圈：阳光、善良，能够温暖他人，但心情容易起伏，安全感不足，希望获得认可。
- 中圈：与亲近的人有归属感，愿意热情付出，但可能让对方感到压力。
- 外圈：外人眼中热情阳光，赚钱有动力，但热情难持续，容易急、三分钟热度，消费容易受感觉影响。

### 4.4 淡红

- 内圈：喜欢美好和温暖，但力量不够，对生活欢喜心不足，赚钱动力和担当力偏弱。
- 中圈：亲密关系中被动，渴望对方主动给温暖，情绪起伏大。
- 外圈：心力不足，持续力和爆发力不足，容易拖延和疲惫。

### 4.5 外圈红色多

外圈红色多，是手册中的直断法之一，尤其用于财富漏洞判断。

常见表现：

- 花钱不太考虑性价比。
- 花钱爽快，不喜欢反复比较。
- 容易为情绪买单。

解读依据是：红色属火，火向外发散；外圈对应物质和现实层，组合后容易表现为财富能量外漏。

## 5. 黄色

黄色在手册中归为土属性。

### 5.1 基础含义

- 正常：憨厚、宽容、接纳、尊重边界，有承载力，务实、靠谱、稳定、重承诺。
- 太过：头脑僵化、固执、不懂变通，容易逆来顺受、忍辱负重。
- 不足：对自我或他人不够接纳，内在自卑，焦虑，社交恐惧，遇事容易抗拒或逃避。

### 5.2 中黄色

- 内圈：内在相对稳定，有主心骨，对自我的接纳力提升，也可能渴望安定和承载力。
- 中圈：对亲近的人比较接纳、宽容，情绪相对稳定，能承担责任，但不太表达情感。
- 外圈：外人觉得可靠、可信赖，愿意把事情交给 Ta 做；财富上可能相信努力赚钱，但对来钱渠道想象较窄。

### 5.3 深黄色

- 内圈：不够接纳自己，容易逃避问题、掩饰不安和错误，容易自责，思维固执。
- 中圈：顾家、能担责，但能量疲惫，背负不属于自己的压力，容易抱怨委屈。
- 外圈：不懂变通，缺乏灵活性，对权威小心谨慎，容易复制过去经验，付出多收获少。

### 5.4 咖色

咖色在手册中被看作凝结在地底的土，常与伤痛相关。

- 内圈：自卑感强，无力改变，倾向逃避或忍耐，可能与家庭信任受损有关。
- 中圈：近期悲伤、难过、不舒坦，和亲近的人不愿沟通，信任受损。
- 外圈：外人可能觉得木讷、固执；本人对世界有不接纳、不信任和怀疑，也可能有愧疚感。

### 5.5 淡黄偏金色

- 内圈：内在灵性苏醒，渴望灵性进步，或有宗教信仰。
- 中圈：能量不稳定，容易受外界影响，开心时来财，不开心时漏财。
- 外圈：不接地气，有点飘，光谈爱和理想，不落地，行动力不足。

## 6. 白色、留白与金色

白色和留白在手册中归为金属性，二者解读一致。金色不等同于金属性。

### 6.1 白色 / 留白

- 基础含义：标准、要求、执行力、性价比、自律、价值感，也可能代表评判、压力、恐惧和不安全感。
- 内圈：做事有标准，能力强，对自己有要求；但也容易内在空虚、自我评判、爱比较、缺乏安全感、爱面子。
- 中圈：近期能量不足，评判较多，能量较低；与家人在一起容易被评判，或自己对另一半有诸多要求。
- 外圈：赚钱能力和执行力较强，做事结果导向，花钱谨慎；但身边人可能觉得有压力。

### 6.2 金色

金色在手册中不按金属性处理，而代表：

- 灵性。
- 灵性苏醒。
- 宗教信仰。
- 光和爱。

## 7. 黑色与蓝色

黑色和蓝色在手册中都归为水属性。

### 7.1 基础含义

- 正常：智慧、才华、深思熟虑、沟通合作、信息流动、滋养他人、懂分寸。
- 太过：善变、反复无常、恐惧和不安全感多，容易自我牺牲、愤怒、报复，陷入情绪漩涡。
- 不足：不懂变通、固执、没有分寸、表达卡住。

### 7.2 黑色

- 内圈：为冬藏的水，代表伤痛、恐惧或不安全感。
- 中圈：对家人也无法敞开，不安全感强烈，担忧多。
- 外圈：对世界不信任，有恐惧，可能有社恐倾向。

### 7.3 深蓝色

- 内圈：自我意识强，喜欢独处、钻研和研究；正向可成为专业人士，负向容易钻牛角尖。均匀深蓝也可代表内观、静修、冥想，带斑深蓝代表伤痛。
- 中圈：在家需要独处和充电，能量相对稳定，但遇事容易引起情绪波动，亲人可能觉得不够热情。
- 外圈：别人认为 Ta 专业，对事情有高认知。

### 7.4 中蓝色

- 内圈：智慧在生发，爱学习，接触更多智慧，与内在连接增加；也可能想得多做得少。
- 中圈：与亲近的人或爱人沟通较好，相处舒服；付出也需要回报。
- 外圈：做的事情能得到外界认可，外界信息接触多，对机会有敏锐感知，人缘较好。

### 7.5 浅蓝色

- 内圈：内心温柔、清新、浪漫，聪明，但也可能优柔寡断，不敢表达真实自己。
- 中圈：容易多愁善感，渴望交流但难以真实表达需求，情绪波动快，决定容易变化。
- 外圈：希望改变外界，渴望外界成为自己想要的样子，容易失望和产生怨气；行动上犹豫，做事拖延。

## 8. 紫色

紫色在手册中属于暧昧色，可定为火属性，也可定为木属性，需以解读师当下用神为准。

### 8.1 基础含义

紫色代表神秘、浪漫、自尊心强、动力和热情不足、渴望被关注。也有紫气东来之意，可代表贵气、高贵、直觉。

### 8.2 紫色的阴阳辅助判定

实践中，紫色定木还是定火，以疗愈师当下神识和个案用神为准。AI 解读不能直接调用神识，可先用画作阴阳特征做辅助判定，再结合圈层、形状和相邻颜色确认。

| 视觉特征 | 归类 | 阴阳 | 解读倾向 |
| --- | --- | --- | --- |
| 浅紫、渐变、莲花状、开放感强 | 木 | 阳 | 紫气东来、贵气、高维链接、灵性苏醒 |
| 深紫、浓重、封闭、块状压住空间 | 火 | 阴 | 神秘高冷、压抑、封闭、不接地气 |

这条规则只用于 AI 辅助判断，不替代疗愈师在个案中的用神判断。

### 8.3 正常紫色

常见含义：

- 贵气。
- 直觉力。
- 魅力。
- 信仰。
- 艺术感。
- 神秘。
- 成熟稳重。

也可能伴随高冷、热情不足、渴望关注、自尊心强、动力不够等问题。

如果紫色被金隔断成一小块一小块，说明直觉接收断续，不知道如何贯通到生活和真实感悟中，也可能做事动力不足、持续性不够。

### 8.4 紫色过重

紫色面积大、颜色暗、浓重或笔触重时，常见含义：

- 直觉较强。
- 挑剔、高冷、封闭、压抑。
- 紧张、严肃、心事重、忧郁。
- 不切实际，不接地气。
- 喜欢独处，不愿与外界过多接触。
- 执着于自己的认知，容易钻牛角尖。

### 8.5 紫色过淡

紫色过淡时，常见含义：

- 喜欢默默努力，喜欢待在自己的空间。
- 爱幻想。
- 灵性有所发展，但不稳定。
- 心情躁动，可能迷茫。
- 信仰或信念力量不够，容易摇摆。

如果淡紫呈花苞状，说明第七脉轮准备打开一点，但能量不足、不稳定。若同时呈现渐变，说明固有信仰或信念正在转变，也可能正在犹豫某些决定。

## 9. 橙色

橙色属于暧昧色，介于火和土之间。手册中统一归为火属性，但因为不是纯正红色，所以仍属于弱火。

AI 解读橙色时，也可以用阴阳特征细分：

- 明橙、饱满、开放：偏阳，常见为活力、自信、开朗和积极。
- 淡橙、发虚、面积散或力量不足：偏阴，常见为不自信、依赖、向外求认可和能量不足。

### 9.1 正橙色

- 负向：渴望爱、渴望认可和温暖，缺乏自给自足的动力，需要不断从外界获得认可来确认自己足够好，有控制欲，害怕失控。
- 正向：有活力，有自信，性格开朗，积极向上，内心欢喜愉悦。
- 延伸：正橙色也代表对福报的承载，对贵人和财富的吸引。

### 9.2 淡橙色

淡橙色常见含义：

- 不自信。
- 有点社恐，只想自己待着。
- 脾胃不好，精力不足。
- 兴趣寥寥，情绪低落。
- 有点懒散，对世界缺少好奇心和好感度。
- 渴望爱、温暖和更多认可。

### 9.3 橙色过重

橙色过重常见含义：

- 有些自负。
- 听不进别人好的意见，固执己见。
- 容易钻牛角尖。
- 对别人有控制欲。
- 压抑焦虑，对世界封闭，没有敞开心扉。

## 10. 淡粉色

淡粉色属火属性，且是弱火。

粉色也可用阴阳特征细分：

- 正粉、饱满、明亮：偏阳，常见为美好、付出、分享温暖。
- 淡粉、发虚、浅弱：偏阴，常见为渴望被爱、依赖、等待回应。

常见含义：

- 恋爱和美好。
- 撒娇。
- 对爱有很多幻想和渴望。
- 渴望被呵护。
- 对对方有依赖，希望对方懂自己、保护自己。

## 11. 玫红色

玫红色属火属性，也属于弱火。

常见含义：

- 喜欢美好。
- 想要分享更多美好。
- 是否有行动，需要结合相邻颜色和结构判断。
- 比粉色更稳重成熟，但内在仍然是渴望爱和呵护。

如果玫红色挨着黄色，可按火生土理解，表示美好感受落实到具体行动。

## 12. 粉红、玫红、橘红等弱火

弱火属性颜色通常既能够付出爱和温暖，也会向外求取爱和温暖。

当外界给到的爱不稳定，或并不刚好满足绘画者想要的爱时，容易出现：

- 求而不得。
- 委屈。
- 伤心。
- 苦闷。
- 情绪拖累行动力。

这里的情伤不只指爱情，也包括父母亲情、兄弟姐妹、朋友、同事等关系。

## 13. 疗愈用色提示

手册在个案流程中给出过清理和补充用色提示：

- 黑色：清理恐惧、不安全感。
- 蓝色：清理灵活性、固化的思维。
- 红色：补充心力、热情，清理愤怒。
- 黄色：清理委屈。
- 绿色：恢复平静，找到平衡感。

这些提示属于疗愈方案入口，使用时应结合个案主题、画面结构和用户反馈，不应直接当作通用处方。

## 14. 使用边界

- 本文是颜色入口，不是完整五行体系。
- 同一种颜色必须结合圈层、深浅、面积、结构和相邻颜色判断。
- 暧昧色的五行归属存在弹性，紫色、橙色等不能机械固定。
- 报告生成时应把颜色解读写成“可能呈现的状态”，不能写成医学、财务或人格诊断。

## 1. 本目录收什么

- 五行感知法，包括金、木、水、火、土的颜色、形状和状态判断。
- 同一圈内元素之间的相生、相克、反常、失衡和循环不成局。
- 五行失衡类型，例如克太过、反克、相生太过、子盗母气等适合曼陀罗解读的类型。
- 真实白色、纸面留白、色块缝隙作为金能量候选的判断规则。
- 各五行关系在画面中的可观察依据和使用边界。

## 2. 本目录不收什么

- 不把一个圈整体判成单一五行。
- 不用五行生克替代三圈联动。
- 不收完整主题解读，例如财富议题里的资源流动、安全感或价值交换。
- 不收纯视觉描述，纯描述应放在 `10-画面识别与描述/`。

## 3. 上下游关系

- 上游：`10-画面识别与描述/` 提供颜色、形状、留白、位置和相邻关系。
- 本层输出：圈内五行元素、元素强弱、元素相邻关系、五行生克和失衡候选。
- 下游：`30-跨圈能量解读/` 使用每圈内部状态，但不跨圈套用五行生克。
- 下游：`40-组合模式/` 可把多个圈内五行关系沉淀为高命中组合。
- 下游：议题层把五行状态翻译为财富、关系、健康等主题语言。

## 4. 维护规则

- 判断五行时必须回到具体元素，不用“这个圈属木”代替元素识别。
- 同一圈内的颜色、形状、留白可以共同参与五行判断。
- 跨圈只传递“这一圈内部五行状态如何”，不直接做跨圈五行生克。

# 五行感知法

> 状态：draft
> 版本：0.2.0
> date：2026-05-13
> owner：CEO / Knowledge Base
> source_of_truth：当前目录/20-疗愈体系/20-流派层/10-曼陀罗/20-圈内五行解读/01-五行感知法.md
> 原始来源：01-曼陀罗解读手册原文.md
> 整理方式：原文保真重组

本文从 `01-曼陀罗解读手册原文.md` 中拆出“五行感知法”，作为五行属性判断的基础经验来源。

## 1. 定位

五行是中国道家的文化体系，无极生太极，太极生阴阳，阴阳生四象，四象生五行。

曼陀罗的解读里就是通过五行金木水火土来承载和体现。

从一个人绘画曼陀罗的颜色里，可以划分出其五行归类，根据每个色彩所代表的五行属性，分析出绘画者的意识和能量，以及绘画者所认知的现实情况。

原文提醒：五行是一个非常宏大的框架体系，它包含了颜色、五常、五脏六腑、时间、方位、五谷等，从一个枝节就能衍生出很多细节。

作为曼陀罗解读师，不要满足于专栏能给到的知识。知识是死的，人是活的。对天地和人生的感悟，对于解读来说是更重要的部分。

要以天地为师，更多地去感悟天地、阴阳和五行，不断地从生活和大自然中获得观察和领悟，以此完善五行框架。

常规颜色的明暗、浓淡、纯度、面积和过渡方式，统一见 ../10-画面识别与描述/04-颜色识别与感知.md。形状作为五行输入的基础说明，见 ../10-画面识别与描述/03-形状识别与感知.md。

## 2. 五行生克基础

五行相生：

- 木生火。
- 火生土。
- 土生金。
- 金生水。
- 水生木。

五行相克：

- 木克土。
- 土克水。
- 水克火。
- 火克金。
- 金克木。

相生：代表滋养、生长、助推。要注意相生并不一定完全是好事，要看其平衡情况。生得太过，对于母体来说是一种消耗。

相克：代表规整、梳理、克制。克并不代表不好，也要看其平衡情况。克得太过，或者克制的力量太微弱，都是有损平衡的。

## 2.1 圈内元素识别原则

五行分析只用于圈内元素之间的关系判断，不把一个圈整体判成单一五行。实际解读时，应先在内圈、中圈、外圈各自识别具体元素，再观察这些元素之间是否相邻、相生、相克、被切分、反耗或不能成局。

使用规则：

- 同一个圈内可以同时存在多个五行元素。
- 判断五行关系时，优先看具体元素和元素之间的位置关系，不用“这个圈属木”“这个圈属火”代替细分识别。
- 三圈联动分析使用三才、三圈语义和能量流动规则，不使用五行生克来替代。
- 疗愈师三圈标记图只用于确认边界，标记线颜色不作为五行证据。
- 若原画和三圈标记图存在颜色冲突，以原画为准。

## 3. 木属性

曼陀罗中绿色是木属性，长条形也是木属性。

木主仁，其性直，其情和，其味酸，其色青，具有生长、向上的特性。

木正常：偏直觉型，耿直，固执，独立，会有自己的界限和空间感；有生机，要求阳光，积极，乐观，向上；喜欢成长，爱学习，爱精进；三观正，讲仁义，愿意付出，结果能够与人分享。

木太过：因为要一路向上发展，听不进去别人意见，评判心多，容易自我批评，批评他人，容易暴躁，固执。像野草一样，自私，侵占，野蛮生长，掠夺式生长。

木不足：有怨气，嫉妒不仁，郁闷，忧郁，憋闷。在情感方面，自我内在力量不足，安全感不足，容易依赖他人。在财富方面，做事信心不够，抗压力不强，过于谨慎，肝胆气不足，精神不济，行动力不足，容易疲惫。

身体对应：肝胆，筋骨，眼睛，腿脚。

此图绿色比例过多，绿色属木，木太过。

绘画者近来生机勃勃，要一路向上发展，但也会出现太过固执的情况，听不进别人好的建议，情绪上容易暴躁。

### 3.1 木在中心圈

深绿：一般内在有伤痛或者忧郁，无法释放。如果深绿色出现在内圈，很可能说明绘画者内在有自己的一套思想体系，比较能抱元守一，活在负面状态下，很容易变得固执，思维比较一根筋，听不进去别人的意见，容易撞了南墙又撞南山。也可能代表绘画者有才华有能力，对自身要求和期待都比较高，俗称“自视甚高”，但现实中往往容易受挫或者被打压，内在想不通的时候，容易对自我有严重评判，容易郁郁寡欢。

中绿：能量比较平和，多数是正面含义。如果中绿是在内圈，说明绘画者开始有了更多信心和独立的想法，想要向上成长，对未来、对自己有了更多的希望，能自己给自己生机。

淡绿：像嫩芽，嫩草，淡绿色的力量相对弱一些，它没有中绿色那么强的生机，但也没有深绿色那样的固执和评判。淡绿在里圈，绘画者可能经历过黑暗的过往，迎来了春天，内心有了一些对自己对生活的希望，但还不敢完全相信会好起来，容易经历反复，勇气和力量相对较弱，需要被保护，被周围人认可和呵护。也可能绘画者本身内在力量不足，信心不够，有些自卑，习惯依赖他人，把力量外放在他人身上。

### 3.2 木在中间圈

深绿：绘画者近期可能很郁闷、很忧郁或很孤独，觉得身边的人不理解自己，周围人打压自己等，也有可能对身边人有评判，看不上亲近的人，觉得他们不如自己积极上进、有追求，他们的成长步伐跟不上自己。

中绿：绘画者近期能量比较积极向上，积极的精神容易感染到身边的人。也可能代表他比较喜欢独处，在家里要有一定的空间感和界限感，与他人相处比较有界限，彼此尊重对方，独立性比较强，能力不错，但也要结合五行相生相克和里圈来看待。

淡绿：绘画者与人相处时容易讨好对方，依赖对方，希望对方给予自己更多安全感和爱，自己缺乏主心骨和主见，遇到选择时会优柔寡断，期待别人给自己选择或者答案。会害怕冲突，遇到问题时容易逃避。

### 3.3 木在最外圈

深绿：绘画者比较有担当，但也容易以自我为中心，做事有自己的一套，比较固执。可能有种“孤芳自赏”的感觉，觉得别人都不理解自己，别人达不到自己的高度，容易对别人有评判，但 Ta 通常会憋着不说，更多是在心里评判，内在有憋闷，情绪容易暴躁。别人也觉得他不好接近，经常会对他有一些误解，也可能说明领导或环境对他有所打压。

中绿：外人会认为他三观正，积极向上，爱学习爱成长，独立性强，愿意付出和分享，乐于助人，对他的风评都很好。

淡绿：别人觉得他很好相处，活泼可爱，他自己却没有信心，对自身能力不自信，需要获得他人的认可来补充信心，做事会有比较多顾虑，会考虑是否满足别人的期待和标准，想要向上成长但内在力量不足，很难持续给自己鼓劲，行动力相对比较弱，需要更多坚韧的力量，需要历经更多的打磨。

## 4. 火属性

曼陀罗中红色是火属性，三角形也是火属性。

火主礼，其性急，其情恭，其味苦，其色赤，具有炎热、向上的特性。

火正常：阳光，快乐，积极向上，付出比较多，欢喜心，热情，热爱，欣赏，创造力。

火太过：特别容易着急焦虑，有伤痛，自我牺牲，爱而不得，善变，三分钟热度，容易半途而废，有始无终。

火不足（弱火）：湿寒体质，对爱有匮乏，求爱求温暖，不爱动，拖延，没有动力，心累，容易三分钟热度，朝三暮四，有始无终，小女人，有依赖情节。

身体对应：心脏，小肠。

注意：粉红色、藕荷色、玫红色等颜色为暧昧色，可归为弱火。暧昧色即不属于天地五行属性的颜色（红黄蓝黑绿白），是调和出来的颜色。

此图红色过多，且红色浓度高，红色属火，火太过。

绘画者最近容易心急焦虑，可能有点上火，睡眠质量不高，要么难以入眠，要么多梦。想得多做得少，容易三分钟热度，半途而废。很可能已经掉坑或有伤痛。

### 4.1 火在中心圈

深红：代表有伤痛、有愤怒积压在心底，压抑的情绪无法释放。为人善良，不懂得表达感受，有情绪更多是积压在心底，容易钻牛角尖。伤痛可能是来自于原生家庭，比如从小遭受不公平待遇，被虐待、被语言或行为暴力对待等。

中红：为人阳光，容易快乐，善良，能够温暖他人，待亲近的人比较热情，笑点和泪点都比较低，但心情容易起伏，安全感不够，受外界影响很大，对自己没信心，很希望获得他人的认可。

淡红：喜欢美好，温暖，内在善良，但力量和热情不够，求爱求温暖，对生活的欢喜心不够，对红尘淡淡的，赚钱动力不足，担当力不够，遇事容易逃避。

### 4.2 火在中间圈

深红：情绪压抑了很久，没有释放的出口，急躁，对亲近的人有压抑、愤怒。可能出于依赖对方或者对方太过强势，只能忍受，不敢表达自己的感受和情绪。但积累时间长了，很可能会爆发，要么一点小事就点燃情绪，要么身体突然生病。

中红：和亲近的人有归属感，为人热情、付出；另一方面可能让对方觉得过于亲近，产生压力、有负担。情绪起伏比较大，这几天开心，过几天难过担忧，安全感不足，容易着急，口头禅是“快点”“快点”。

淡红：与亲近的人不亲密，热情不起来。亲密关系里比较被动，小女人，喜欢撒娇，但内心希望得到对方的温暖，希望对方主动。情绪起伏大，力量外放，如遇人不淑容易造成情感伤痛。

### 4.3 火在外圈

深红：身体有炎症，易上火，心脉受损，心脏力量不足。容易漏财，攒不住钱，花钱有些冲动，为感受或情绪买单。虽然表面看着和大家一样，或者看着很阳光，但实际上内在对外界的规则或标准会有对抗，与人打交道不对路时容易压抑愤怒或难过。

中红：身体容易上火。对外人很热情，在别人眼中是个欢喜阳光的人，别人很容易亲近。赚钱有动力有热情，但这种热情很难持续。做事容易着急，三分钟热度，没有坚持力，不自律，给自己定的规则经常被感受影响，财富进账忽高忽低，为情绪买单，看到喜欢就想买，不大考虑性价比，很难攒住钱。

淡红：湿寒体质，心脏力量不够，做事有心无力，容易拖延，持续力和爆发力都不足，经常感觉到疲惫，觉得自己被世界排挤在外，花钱和赚钱都不开心，没有心力。

## 5. 土属性

曼陀罗中黄色是土属性，正方形或类正方形也是土属性。

土主信，其性重，其情厚，其味甘，其色黄，具有长养、化育的特性。

土正常：憨厚，宽容，接纳，会尊重别人的喜欢和界限；有承载力，做事务实，认真，靠谱，脚踏实地，稳定；为人忠孝至诚，看重承诺，容易取得别人信任。

土太过：头脑僵化，比较固执，转不过弯；愚拙不明，反应笨笨的，容易不辨情况相信别人，也可能是抗拒别人；内向好静，内在有自卑，容易有疲惫感；遇事会逆来顺受，忍辱负重。

土不足：对自我或他人不够接纳，内在有自卑，容易焦虑，有社交恐惧；遇事容易抗拒，逃避；不讲信用，不通情理。

身体对应：胃、脾、肌肉。

此图黄色分布在第二圈和第三圈，零零散散不成片，黄色属土，土气较衰。

绘画者对家人和外人都不太接纳，容易对现状不满意，标准较多，容易评判别人做得不好的地方，Ta 可能不会将这种评判说出来，更多是放在心里。遇到事情可能会抗拒逃避，不愿意面对。一般来说，对别人不接纳，折射的也是对自我的不接纳。

### 5.1 土在中心圈

中黄色：代表这段时期内在相对比较稳定，为人靠谱，可以为自己做主，有自己的主心骨，对自我的接纳力有提升；也可能代表渴望得到安定，渴望提升自身承载力。

深黄：代表地面下的土地，没法接纳自己，会逃避问题，掩饰自己的不安和错误，容易自责。思维方式和做事都会比较固执，尤其是圆形或正方形的深黄，有自成一体的思想，基本听不进去别人的意见，可能表面上说好，但实际上仍然我行我素。

咖色：有点像凝结在地底的土，代表伤痛。绘画者可能自卑感比较强烈，但又无力改变，倾向于逃避或忍耐。比如曾经很相信别人，结果别人辜负他，导致绘画者内在受伤，关闭心门，选择不再相信他人和世界。一般这类人原生家庭有伤痛，对家庭失去信任；不被父母信任；总是被父母用言语打压；被父母抛弃（父母离异、出轨）等。

淡黄偏金色：代表内在灵性苏醒，渴望在灵性上进步，或者代表有宗教信仰。

### 5.2 土在中间圈

中黄色：在中圈，对亲近的人比较接纳、宽容，情绪相对稳定，能够承担责任，有承载力，但如果不能放松下来，身心也会比较疲惫；不太能表达自己的情感，有些话会憋在心里，因为担心对方不理解，更倾向于做事而不是说漂亮话。

深黄色：顾家，能担责任，但是能量很疲惫，背负了不属于自己的责任，容易抱怨委屈。近期能量不舒展，有很多压抑。和家人相处的时候也压抑，不能接纳对方的缺点，忍辱负重的感觉，背负了不属于自己的压力，很累想要逃避，同时也会有怨气，觉得别人对不起自己，认为自己付出更多，会比较强势。

咖色：最近情绪悲伤、难过、不舒坦。和亲近的人不愿意沟通，把自我封闭，对另一半或家人存在不信或信任度受损的情况，一般和另一半会有间歇性冷战。

淡黄偏金色：能量不稳定，一会儿很有爱，一会儿很受伤，容易被外界能量影响，开心就会来财，不开心漏财比较快。

### 5.3 土在外圈

中黄色：为人可靠，可信赖，在别人眼里是老实人，很值得信任，愿意把事情交给他去办。本人赚钱会有点辛苦，对金钱的信念和来钱的渠道有限制性信念，一般只相信努力才能赚钱，只相信上班拿工资能赚钱，事实上，努力只是其中一个赚钱要素。对未来缺乏远见和想象力。老黄牛式努力，容易被别人冒领功劳。

深黄色：脾胃不好，肌肉僵硬，不懂变通，为人固执，没有创造力，缺乏灵活性。对于权威可能小心谨慎，唯唯诺诺，不肯改变，把过去的经验复制到未来，自己不想改变，甚至对抗外界的变化，容易付出多收获少。

咖色：脾胃不好，容易有湿寒。别人会认为他很木讷，固执，说不通；本人会对这个世界有很多不接纳，不信任和怀疑，内在有愧疚，不敢呈现真实的自己，想要掩饰自己的一些作为。比如把钱借给了别人没有按时还，或者做了很多不符合仁义道德的事，不想被知道，但内在一直有愧疚在折磨 Ta。

淡黄偏金色：不接地气，有点飘，赚不到钱，光谈爱和理想，不落地，行动力不足。

## 6. 金属性

曼陀罗中白色、留白的部分是金属性，小圆、半圆都属于金属性。

金主义，其性刚，其情烈，其味辣，其色白，具有清静、肃杀、收敛的特性。

金正常：为人刚毅果断，疏财仗义，深知廉耻，自律，要求完美，能干，聪明，努力，执行力强，性价比，有价值，自我价值感高。

金太过：有勇无谋；标准和要求多，追求完美，容易自我批评，批评他人；会背负很多不必要的压力，活得比较累；相对比较强势，待人苛刻，身边人难以亲近，和 Ta 在一起比较累；恐惧和不安全感多，焦虑多。

金不足：倾向于讨好别人，界限感不足，自我空间被挤压，容易委屈，容易难过。

身体对应：肺，支气管，皮毛。

注意金属性是白色，而金色则代表灵性、灵性的苏醒、宗教信仰、光和爱等。

此图白色主要分布在第二圈，比例较大，白色属金，金太过。

第二圈代表情感，在第二圈金气太过，说明近期绘画者可能比较焦虑或委屈，对家人愿意付出，但家人不领情，可能和家人有争吵。Ta 自身的标准和要求多，对身边人有很多要求，相对比较强势，家人跟 Ta 在一起时会比较累。

白色，留白，在曼陀罗里都是金属性，两者解读是一样的。

补充识别规则：

- 画作内部真实的白色、纸面留白、色块之间的空隙，都可作为金属性候选。
- 外圈外边界以内的真实留白，也可作为金能量候选。
- 留白如果把同类颜色、同类形状或同一能量切成一块块，可进入“金切分其他能量”的组合判断。
- 模板自带黑色线稿、印刷线条、铅笔轮廓、疗愈师三圈标记线，不作为画作金、水或其他五行证据。

### 6.1 金在中心圈

白色：做事有标准，能力强，对自己有要求；但也容易内在空虚，自我评判，评判自己不够好；爱比较，比较后又觉得自己不够好，会自我攻击；缺乏安全感，爱面子。

### 6.2 金在中间圈

白色：说明绘画者近期能量不足，评判较多，能量较低，不是很开心。与家人在一起要么被评判，要么自身有控制欲，对另一半有诸多要求，容易爆发争吵。

### 6.3 金在外圈

白色：说明绘画者属于性价比类型，赚钱能力也强，花钱比较谨慎，能够迎合集体意识，行动力较强，能力不错，能在平台或工作中吃得开，做事结果导向。但是身边人跟他在一起也会比较累，因为他比较爱批评人，有 Ta 在的地方气压比较低。

## 7. 水属性

曼陀罗中黑色和蓝色都是水，波浪状也是水属性。

水主智，其性聪，其情善，其味咸，其色黑，具有滋润、向下的特性。

水正常：有智慧，有才华，为人深思熟虑；与人沟通合作好，语言清和，人脉广，能够滋养他人，陪伴他人，愿意帮助他人；温润如玉，懂分寸，知进退，知世故而不世故；信息的流动和交换。

水太过：心性没修好就会喜欢说是非，善变，性情反复无常，行事反复无常；胆小，恐惧感和不安全感较多；自我牺牲，内在有怨气；像洪水，愤怒、报复，容易陷入情绪漩涡。

水不足：不懂变通，固执；没有分寸；说话比较卡，喉轮卡，有话说不出，有苦难言。

身体对应：肾、后腰、循环系统，耳朵，膀胱。

此图大面积的蓝色、黑色，蓝色和黑色属水，比例较大，水气太过。

说明绘画者近期情绪多变，内在不安全感强烈，情绪有时如狂风暴雨，说来就来，控制不住自己，会很愤怒和暴躁；有时又恢复如常，温柔清新。做决策的话，容易摇摆，非常善变。如果遇到这种图的伙伴，暂时不宜与 Ta 合作。

### 7.1 水在内圈

黑色：为冬藏的水，代表有伤痛或恐惧和不安全感。

深蓝色：自我意识强，性格安静，喜欢独处，喜欢钻研、研究，如果正向发展，可以成为某个领域的专业人士，如果负向发展，容易钻牛角尖，陷入自己的逻辑里出不来。均匀的深蓝在里圈，也代表最近绘画者在内观、静修、冥想等，通过链接内在不断滋养自己。带斑的深蓝代表伤痛。

中蓝色：自我意识强，智慧在生发，最近爱学习，接触更多的智慧，和内在的链接增加，能滋养自己；也可能心里面有一些湿寒，更多是接触智慧、学习智慧，但没有真正去实践。有可能想得多做得少。

浅蓝色：绘画者内心温柔，清新，有浪漫情怀，很聪明，但也会聪明反被聪明误，做决策时也会优柔寡断，可能盲目跟随，也可能不自信，不敢表达真实的自己。同时绘画者对于智慧也渴望提升，但容易想得多，做得少。

### 7.2 水在中圈

黑色：对家人也无法敞开，不安全感强烈，担忧多。

深蓝：在家喜欢独处，需要有自己的空间来充电和做研究，否则会很郁闷很痛苦；能量相对比较稳定，但遇事情也容易对境生心，引起情绪波动；与亲人关系一般般，不是特别爱沟通，亲人会觉得他不是特别热情。

中蓝：与亲近的人或爱人有良好的沟通，相处舒服；付出也需要有回报，否则容易多抱怨。

浅蓝：容易多愁善感，容易悲观，家人也劝不住；渴望和另一半有更多交流，但是无法真实地表达自己的需求，可能用责备、抱怨等来引起对方注意，需要对方来猜；情绪波动比较快，反复无常；做的决定也容易快速变化，别人不能当真，当真就容易起冲突；愿意付出，但也渴望对方的回报，如果对方没有回应，自己会有很多抱怨。

### 7.3 水在外圈

黑色：对世界不信任，有恐惧，一般会有点社恐。

深蓝：别人认为 Ta 很专业，对事情看法有高认知。

中蓝：最近财运不错，做的事情能得到外界的认可；近期与外界接触的信息比较多，对外界的机会有敏锐的感知力；待人温柔，别人与 Ta 相处如沐春风，能受到滋养，人缘比较好。

浅蓝：希望改变外界，渴望外界的人事物成为自己想要的样子，但一般都会失望，容易产生怨气。一直在寻找合适的机会进阶，但行动上也会有所犹豫。做事比较拖延，湿寒气重。

## 1. 五行相生相克原理

五行相生相克是基础知识，大家一定要熟记，并且能明晰其中相生相克背后的大自然原理，最好能在脑海中有对应的画面，后面才能将大自然的原理贯通到绘画者意识规律和曼陀罗的解读中。

## 2. 五行相生

木生火、火生土、土生金、金生水、水生木。

相生：助力、提携、给予、帮助等含义。

木生火：因木性温和，易燃，劈木钻木可生火。

火生土：因为火灼热，能燃烧万物，火烧完之后成为灰烬，灰即为土，故而火生土。

土生金：因为金藏于山石里，矿山、岩石中会产金，且山石中至刚至阳之物就是玉，金子和玉五行皆属金，特别是潮湿的山石，聚土成金。

金生水：古人观察到，在寒冷的早晨，金属表面会产生小水珠。这是因为金属表面较冷，空气中的水蒸气会在金属表面凝结形成水珠，故而金生水。

水生木：因水有滋养温润使树木生长出来，木需要依赖水的滋养才能成长，故而水生木。

## 3. 五行相克

木克土、土克水、水克火、火克金、金克木。

相克：制约、制衡、压制、管教、打击等含义。

木克土：树木生长要破土而出，根茎要破土扎入更深的泥土，且山上的土石，需要树木的根茎才能制衡巩固，否则大雨一来就会产生泥石流，故木克土。

土克水：古语云，“水来土掩”，所有河川的堤防、堤坝，都由土石所砌成，以阻挡水患，故土克水。

水克火：这个很好理解，灭火得用水，故水克火。

火克金：所有金属物质，以火加温到某一程度，均可化为液态，甚至蒸发成为气态，故火克金。火克金也有冶炼、提纯金的含义。

金克木：凡是木材，都要用金属制的斧头或锯子砍劈、修建，故金克木。

## 4. 高级理解

五行的每一个元素，均与其他四个元素连接在一起，所以有“生他”“克他”“被生”“被克”的关联性。

例如以“木”为中心来观察，木生火、木克土、木被水生、木被金克。也就是每一个五行元素一定与其他四个元素有关系，缺一不可。

生他：即以此一元素为中心，生其他的五行，有帮助提拔他人之意思与力量，但亦损耗本身的力量。

被生：即此一元素接受到其他五行所生，有受他人帮助、照顾、提拔之意与力量。

当生一方的力量太强而被生一方的力量太弱时，这种生实际上就成为了克对方，这就是所谓的“生多为克”。

克他：即以此一元素为中心，克其他的五行，有制约、平衡、克制、管教他人等意思，亦稍微损耗本身之力。

被克：即此一元素被其他五行所克制，有受到他人平衡、压制、打击、管教等意思，其本身之损耗比较大。

五行相克也不一定就是坏事，有时反而是好事。比如金克木的一个典型场景是用剪刀修剪树枝，去除杂枝和歧枝，这有利于树木的生长。又比如父母一定要管教孩子，孩子才不会长歪。

某一元素太多或太少，结构会有所偏颇，都不是平衡。

## 5. 反常关系

在曼陀罗的解读里，解读出来的信息会有正面，但更多偏向负面。

完整五行失衡从理论上可以扩展为 30 种。当前曼陀罗解读先纳入 20 种，暂不纳入 10 种。当前采用的整理稿见：03-五行失衡类型.md。

纳入原则：

- 只处理画面中相对容易观察到的“某一元素过旺、压制、反耗或反制”。

- 五行失衡只用于圈内元素之间的关系判断，不用于三圈联动分析。
- 五行关系必须落到圈内具体元素之间，不把“一个圈”整体判定为某个五行。
- 判断相生相克时，需要观察颜色、形状、面积和相邻关系。某个元素是否真正得到滋养或压制，不能只看同一圈是否出现了对应五行。

### 5.1 圈内局部关系补充

已审核案例确认了两条使用规则：

- 无根之木：同一圈内没有水，木可判为无根之木；同一圈内有水但某个木元素没有与水相邻或相接，这个木元素仍可判为无根之木。
- 金切分：真实白色、纸面留白、色块之间的留白缝隙，都可作为金能量候选；当留白切断同类颜色或同类形态时，可判为金切分其他能量。

这些规则用于解释元素之间的局部关系，不用于替代三圈联动。三圈联动仍按内圈、中圈、外圈各自语义判断。

- 子病犯母 5 种：子方过旺，反耗母方。

- 在 ToC 报告中，这两类最多作为“待观察线索”，不作为正式失衡类型输出。

## 原文重组


木主仁，正向代表独立，自主，自信，生机，成长，积极，欣赏，三观正，有主见等；负向代表固执，侵占，郁闷，恼怒，自我中心等。

火主礼，正向代表热情，动力，勇气，爱，给予，快乐，欢喜心；负向代表自我牺牲，善变，急躁，爱面子，索取等。

木生火的解读里，相生关系通常为正向解读，但也要看颜色和比例，以下为具体说明。

一、看木和火的面积比例

比例均衡、木多火少、火多木少，都会有不同解读，且不均衡的更多偏向负向解读。

1、比例均衡

木生火在内圈，绘画者自信、独立，内在有很多生机，对未来有希望，不断地成长，内在生出了欢喜心，对自己和生活有了更多热情，更懂得爱自己。

木生火在中圈，说明绘画者近期能量不断在提升，心情也还不错，有更多欢喜心。同时家庭关系也在进步，绘画者努力和精进收获了很多，也愿意和家人分享自己的奋斗果实，很爱护家人。但家里人是否理解他，还要另当别论。因为木生火，他会比较有主见，如果家里也有一位比较固执强势的人，矛盾就会爆发。

木生火在最外圈，说明外界有一些新的机会，点燃了绘画者的动力和热情。

2、木多火少

木积压得太多，没有用在正确的地方去生火，说明绘画者容易生闷气，心里面有评判有标准，对人不服，固执己见，遇到别人不认同自己，容易评判和恼怒，尤其是木颜色很深的绘画者，ta的怒火一般不发出来，全压制在心里，积累到一定程度必定会爆发，要么伤害自己身体，要么伤害情感关系或财富。

这幅曼陀罗第二圈木多火少，说明绘画者独立自主，很需要自己的独处空间补充能量，运用独处的时光来思考或探索自己喜欢的事情，但经常会感觉不开心，心里有郁结，尤其对家人会固执己见，有自己的标准和要求，当家人违背自己的意思，会发脾气，或者看到家里面某些事情不合理，就容易产生不满。

3、木少火多

这种情况木全被消耗，也生不出这么多火，这个火一般是虚火。说明绘画者近期也在成长和努力，但可能比较爱面子、虚荣，但内在底气不足，心里发虚，内心力量不够，不自信。别人觉得他过得很好，实际上并不是。人生如戏，全靠演技。绘画者表面看起来很厉害、大方热情，很可能是假装的。

这幅曼陀罗最外圈木少火多，说明面对外人时是热情好客的，愿意付出，会让人感觉很温暖，同时绘画者也比较爱面子，容易急躁，总想快点要结果，但总是求而不得，会感到失望或愤怒，心里底气不足，觉得自己不够好。

二、看木和火的颜色

比如木如果是浅绿色，就属于木不足。浅绿色的木，好比春天刚发芽的嫩叶、嫩芽，是新生的，柔嫩的，需要更多呵护和滋养，经不起风雨，未来需要继续成长，方向是要具备更多坚韧和笃定。

同时浅绿色的木很难用来生火，嫩芽起不来火，所以火也很可能是绘画者本身的火或者是虚火，说明绘画者会有比较多的依赖，不能独立自主、从一而终完成一件事，TA喜欢鲜花和掌声，爱面子，但又觉得自己能力不足，实力还不够，能量上会有拉扯。

这幅曼陀罗的木为嫩木，说明绘画者心里还不够成熟，心里会有依赖，未来还需要更多独立和坚韧的力量。

## 案例审核补充

无根之木用于判断木是否真正得到水的滋养。它不是按整个圈层判定，而是观察圈内具体木元素和水元素的关系。

判定规则：

- 同一圈内没有水，木可判为无根之木。
- 同一圈内有水，但某个木元素没有与水相邻或相接，这个木元素仍可判为无根之木。
- 若同一圈内有多组木，需要分别判断每组木是否接触水，不能因为某处木被水滋养，就推定全部木都有根。

财富议题中，无根之木可翻译为成长愿望、能力、机会、事业方向或行动热情存在，但缺少滋养、信息流、支持系统、情绪稳定或资源连接。表达时应保留“有成长力，但根基和滋养不足”，不写成用户没有能力。

## 1. 定位

曼陀罗解读的三圈结构。

曼陀罗的解读法中，最基础的就是三圈结构法。

三圈结构法，就是给曼陀罗的解读做一个结构的定位，这个定位会决定后续精微的解读。

三圈结构具体是指哪三圈？就是内圈，中圈，外圈，也可称为第一圈，第二圈，第三圈。

## 2. 三圈划分原则

特别需要注意的是，在曼陀罗的涂色画中，有一些图案的三圈划分，似乎有很多种方式。

那究竟怎么划分才是正确的呢？如果划分错了，是不是后面解读的内容也是错的呢？

原文给出的答案是：三圈的划分以你的神为准。你认为哪里是第一圈，那里就是第一圈。这个没有标准答案，而以解读师的神识为基础。神识是灵动的，不是死板固定的公式。每个人认定的三圈可能都是不一样的。

唯一的要求是：买定离手，落子无悔。意思是如果你自己确定好后，在解读的过程中，千万不要变来变去。只要划分好了，就接着往下解读。

## 3. 三圈内涵

三圈结构解读法是曼陀罗解读中的重中之重。

从手册案例中可见，三圈常被这样使用：

- 第一圈 / 内圈：代表过去、意识、内在渴望、自己内心的想法、童年伤痛等。
- 第二圈 / 中圈：代表当下、能量、情感、情绪、和家人的关系、财富能量等。
- 第三圈 / 外圈：代表未来、物质、财富、行动力、别人怎么看待 Ta 等。

## 4. 解读步骤

### 第一步：确定绘画者的主题

解读主题是什么？财富、情感还是健康。

确定主题其实也是确定你解读的重点，这样更容易具有针对性，能打开绘画者的心扉。

如果每个主题都讲一遍，一则太过分散，二则对案主的实际帮助不大。

有的案主对于每个主题都想要知道，通常这类案主会想要得多，容易眉毛胡子一把抓。还是要与他确定偏重点。在解读过程中，也可以根据他的反馈确定他的偏重点。

### 第二步：确定三个圈的结构

确定好主题后，以你的神为准确定三个圈的结构。

确定三圈是以你当下的神识来划分，由你来界定一二三圈的划分。

原文提醒：不用担心划分得不对，怎么分都是对你。《易经》讲神准，你当下的神识所在就是神准。

### 第三步：确定三圈后，找切入点解读

可以按顺序从第一圈解读，也可以从第三圈开始解读，还可以从你认为这幅曼陀罗里最突出的特点来切入进行解读。三种切入点作为开始都是对的。

这中间会结合五行相生相克解读法，才能捕捉到更多信息。

## 5. 使用提醒

后续用于 AI 报告生成、追问和疗愈方案时，三圈结构不应被处理成机械坐标。它是解读师建立画面定位和解释顺序的方法。

AI 可以使用“内圈 / 中圈 / 外圈”的语义框架，但需要保留“先定主题，再定三圈，再找切入点”的顺序，避免一上来泛泛分析所有主题。

## 6. 三圈联动核心规则

三圈不能只分别看，还要连起来看。联动判断适合用于报告中的综合模式，不应替代每一圈的具体画面依据。

三圈联动使用三才、圈层语义和能量流动，不使用五行生克替代。五行生克只用于圈内元素之间的关系判断。

- 内稳中顺外圆：三层都规整，身心合一，运势平稳，内在外在统一。
- 内缺中乱外散：三层都差，内心迷茫、情绪内耗、现实奔波不稳。
- 内好中乱外稳：本心通透，但情绪感情纠结，现实生活还算安稳。
- 内弱中顺外强：内心不自信，但情商人际好，现实事业物质不错。

在情感里压抑自己，情绪波动很大；缺少欢喜心和热爱，赚钱的动力不足，会很在意别人的眼光。

1、画曼陀罗用黑色扫画或打圈画，诚实地面对自己，对着曼陀罗表达自己对某位家人的愤怒、难过和失望，允许情绪真实地流淌出来，持续绘画3周以上，每天至少12张。

2、第1点做完后，还要做与家人链接的冥想，去看到对方的经历和认知层次，设身处地地站在ta的角度考虑，慢慢做到因懂得而慈悲。冥想过程中如果还有怨念，那就再画曼陀罗进行清理。最后一定要转念：自己从这段关系里，获得什么成长礼物？

3、写幸福日记，持续3个月以上。财富的基础是对红尘的热爱，如果刚开始没有，那就以假修真，先把自己放进幸福欢喜的状态，每天聚焦美好的事物，每天关注幸福的小事，可以建立一个幸福日记本，记录所发现的美好。

4、一周细画3次以上曼陀罗，多用红色或绿色，锚定一个主题：我是安全的、我是勇敢的。财富偏爱勇敢的人。害怕别人的眼光，害怕别人的评判，就永远被困在别人的唾沫里，你会失去自己的力量，也会丢失进入财富大门的钥匙。
