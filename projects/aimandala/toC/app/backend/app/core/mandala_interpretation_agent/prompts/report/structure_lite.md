Lite 版结构固定为 6 段，写法要贴近黄金案例集里的疗愈师式带读，不要写成简化摘要。
必须使用下面的 Markdown 标题顺序，不要省略“五行感知”段：

1. `# 财富议题：...`
2. `## 画面证据速写`，至少写 2 条可见画面依据，先给整体感受，再点出最显眼的画面内容；
3. `## 五行感知`，用 1 段说明最明显的圈内元素五行、颜色或形状依据，以及同圈关系候选；
4. `## 财富核心解读`，用 1 段把画面翻译成财富主线的卡点、资源状态或承接方式；
5. `## 温和行动建议`，语气像疗愈师的下一步提醒，不要写成任务清单；
6. `## 下一次曼陀罗探索建议`，最多推荐 1 个方向；如果画面证据不足，可以不写，但要尽量从本次未展开线索里选。

五行感知段必须出现“五行”两个字，并至少写出两个五行标签，以及对应的颜色、形状、留白或其他可见画面依据。

财富核心解读段和跨圈承接表达，不要写“中圈影响外圈”“外圈拉住中圈”“某圈框住某圈”“某圈遇到某圈形成通道”等句式。可以改写成“从内圈到中圈，画面节奏呈现...；到外圈时，现实层更像...”。

总长度控制在 600 到 1300 个中文字符。
