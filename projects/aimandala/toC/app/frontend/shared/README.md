# Shared Frontend Layer

这里承接 `一镜一梳` To C 前端的共享层。

当前目录分成三类：

- `types/`
  - 对齐当前后端 `V2` 的 DTO 和流程类型
- `api/`
  - 多渠道可复用的请求 client 和 service
- `core/`
  - 不依赖平台能力的流程状态与纯函数
- `design-system/`
  - 双端共享 UI 的设计令牌和语义命名基线
- `ui/`
  - 当前第一批双端共享展示组件

当前这层的默认约束：

- 不依赖浏览器 DOM
- 不依赖小程序 API
- 不依赖原生 App API
- 不放路由
- 不放文件上传、支付、登录这类平台强依赖行为

也就是说，这里优先沉淀：

- 接口契约
- 业务语义
- 双端统一身份与会话契约
- 共享设计系统
- 共享展示主体

而不是平台壳。
