# 心理疗愈初访助理自用试点记录

> 状态：active
> 开始日期：2026-07-19
> 账号：一镜一梳
> 实现方式：Coze（扣子）编程
> 知识库：飞书
> 记录用途：保存产品与服务流程的事实、测试结果和安全检查；未来可据此另行整理内容，不能直接作为公开文案或个案素材。

## 1. 试点目标

为一镜一梳建立一条有明确安全边界的初访链路：公众号初访 -> 用户自愿添加企业微信 -> 企业微信继续沟通或由人工接管。

当前候选承接内容包括曼陀罗艺术疗愈解读、个案、课程和合作。试点用于验证信息收集、服务说明和人工交接，不提供心理诊断、治疗建议、风险分级或危机干预结论。

## 2. 当前设计基线

```text
公众号初访助理
  -> 说明工具身份、服务性质、隐私和非咨询边界
  -> 收集最少必要的预约前信息
  -> 识别需立即转人工的情形
  -> 用户自主选择添加企业微信
企业微信跟进助理 / 人工服务台
  -> 确认服务意向和预约安排
  -> 发送已审定的资料、规则或人工沟通入口
  -> 人工优先接管敏感、复杂或风险情形
```

- 公众号与企业微信的聊天记录默认隔离，不自动迁移完整原始对话。
- 用户明确同意后，才交接必要的预约前信息和下一步；用户拒绝不影响其获得基础说明。
- 飞书知识库只存放已审定的服务说明、FAQ、知情同意、危机转人工与版本记录；不存放原始个案记录。
- 内容侧仅可使用经单独同意后形成的、不可回溯个体的周期聚合洞察，例如匿名主题和频次区间；不得保留可还原的原话、个案片段或身份线索。

## 3. 记录规则

每次迭代只补充一条实验记录，保留当时的条件、结果和判断。

- `测试对象` 必须标为自己、模拟用户、受邀测试者或真实线索。
- `证据` 写明截图、Coze 版本、匿名测试日志或人工观察的存放位置；没有证据就标“未留存”。
- 任何真实个案、联系方式、健康与心理状态信息均不写入本文件。
- 真实用户测试前，必须检查知情同意、退出路径和危机转人工是否可用。
- 公开内容只能引用通过隐私检查的产品过程结论，且必须清楚标注自用试点、模拟测试或受邀测试阶段。
