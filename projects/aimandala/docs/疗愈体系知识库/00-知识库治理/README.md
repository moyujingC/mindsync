## 协作规则

在本目录工作时：

- 新增或修改治理文件后，同步更新当前 README
- 重大决策应先记录到 `01-知识库建设决策记录.md`，再执行
- P0 级缺口修复计划已记录在单独文件，按计划执行并更新
- 治理文件不直接定义产品规则，产品规则应放在 `30-应用适配/`
