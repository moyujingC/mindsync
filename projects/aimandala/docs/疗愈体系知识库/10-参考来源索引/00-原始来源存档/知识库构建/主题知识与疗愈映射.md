## 定位

本文是 Aimandala 主题知识的总入口。

主题知识采用“一主题一文档”的维护方式。本文只保留主题总览、挂载原则、字段说明和主题文档链接；每个主题的完整知识内容以对应主题文档为准。

主题的作用是给解读落点，不是替代画面依据。同一画面特征在不同主题下，应挂载到不同知识库解释。

## 主题挂载原则

主题挂载发生在用户输入阶段：

- 画作：必填。
- 用户所选主题：必填。
- 绘制前意图：选填。
- 绘画过程感受：选填。

主题决定后续知识库挂载，但不能覆盖画面事实。用户意图和绘画感受应在报告中被回应，但只作为辅助上下文，不能替代三圈五行推导。

## 单主题文档字段

每个主题文档必须完整保留旧 V2 主题 Python 模块中的以下顶层对象：

- `THEME_CONFIG`：主题 ID、中文名、核心议题、五行主题含义和疗愈模板。
- `COLOR_MEANINGS`：该主题下五行 / 颜色 / 深浅 / 三圈的具体解读。
- `INTERACTIONS`：该主题下五行相生相克的互动解释；若 V2 源文件未提供，主题文档必须明示。
- `INSIGHT_TEMPLATES`：用户可见洞察模板。
- `IMBALANCE_MAPPINGS`：失衡类型在该主题下的具体表现、核心洞察和疗愈方向。
- `HEALING_PRESCRIPTIONS`：该主题下的疗愈议题和建议。

## 主题映射方式

主题映射主要处理：

- 同一失衡类型在不同主题下的现实表现。
- 同一圈层在不同主题下的解释优先级。
- 同一疗愈方向在不同主题下的落地动作。

例如外圈红色：

- 财富事业：更容易连到花钱、消耗、入不敷出、机会推进方式。
- 亲密关系：更容易连到热情、情绪表达、亲密中的消耗。
- 身体健康：更容易连到上火、炎症、心火或身体消耗。

## 疗愈建议原则

疗愈建议必须来自前面的解读链：

```text
画面依据 -> 逐圈五行感知 -> 生克关系 -> 失衡浮现 -> 主题现实表现 -> 调节方向
```

建议不能只写“多觉察自己”。

合格建议应满足：

- 低压，用户当天可以开始。
- 对应具体主题。
- 能回应核心卡点。
- 不夸大疗愈承诺。
- 对高风险信号保留转介或专业支持提示。

## Lite / Pro 差异

Lite：

- 给出一个用户能立刻理解的核心状态。
- 保留必要画面依据。
- 给出一个低压小步建议。

Pro：

- 展开主题下的机制链。
- 说明根因链和现实表现。
- 给出分阶段调节方向。
- 让用户看到为什么是这条建议，而不是泛泛安慰。
