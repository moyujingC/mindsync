# 疗愈方案 - 21天疗愈营

> 来源文件: `app/core/healing_programs.py`
> 创建时间: 2026-03-05
> 版本: v1.0

---

## 概述

基于五行失衡类型，提供完整的21天结构化疗愈方案。每个方案包含觉察期、行动期、整合期三个阶段，通过音频引导、书写练习、小行动、曼陀罗绘画等多元方式，帮助用户恢复五行平衡。

---

## 疗愈三阶段

| 阶段 | 时间 | 名称 | 目标 |
|-----|------|------|------|
| **Week 1** | 第1-7天 | 觉察期 | 看见问题，接纳现状 |
| **Week 2** | 第8-14天 | 行动期 | 小步尝试，建立新习惯 |
| **Week 3** | 第15-21天 | 整合期 | 巩固成果，找到平衡 |

---

## 任务类型

| 类型 | 说明 | 示例 |
|-----|------|------|
| **音频引导** | 冥想/觉察练习 | 身体扫描、情绪观察 |
| **书写练习** | 结构化日记 | 情绪倾倒、感恩记录 |
| **小行动** | 日常生活调整 | 身体摇晃、淋浴冥想 |
| **曼陀罗绘画** | 每周一次 | 自由绘画、主题绘画 |
| **休息日** | 整合与放松 | 无任务，自由安排 |

## 疗愈方案列表

### 1. 水多木漂型

| 属性 | 内容 |
|-----|------|
| **名称** | 让水流动 |
| **核心问题** | 如何让内在海洋流动起来，而不是淹没自己 |
| **适用人群** | 情绪丰富但容易感到疲惫、想得多做得少 |
| **关键词** | 情绪流动、放下过度思考、小步行动 |

**Week 1 觉察与流动**：
- Day 1: 允许情绪存在 + 情绪倾倒书写 + 身体摇晃
- Day 2: 身体的水流 + 淋浴冥想
- Day 3: 给情绪命名 + 情绪日记
- Day 4: 休息日
- Day 5: 曼陀罗绘画（自由表达）
- Day 6: 观察触发点 + 小步行动清单
- Day 7: 周回顾 + 感恩练习

## 曼陀罗绘画安排

每个21天疗愈方案包含4次曼陀罗绘画：

| 次数 | 天数 | 主题 |
|-----|------|------|
| **第1次** | Day 1 | 初始状态（自由绘画） |
| **第2次** | Day 7 | 一周觉察后的表达 |
| **第3次** | Day 14 | 两周行动后的变化 |
| **第4次** | Day 21 | 疗愈旅程总结 |

## 函数接口

### get_healing_program

获取指定失衡类型的疗愈方案。

**参数**: `imbalance_type: str` - 失衡类型，如 "水多木漂"

**返回值**: 疗愈方案字典

```python
{
    "name": "让水流动",
    "description": "适合情绪丰富但容易感到疲惫...",
    "duration_days": 21,
    "weeks": {
        1: {
            "phase": "觉察期",
            "theme": "觉察与流动",
            "tasks": [...]
        }
    }
}
```

### get_daily_task

获取某天的具体任务。

**参数**:
- `imbalance_type: str` - 失衡类型
- `day: int` - 第几天（1-21）

**返回值**: 当日任务详情

### get_mandala_prompt

获取曼陀罗绘画的引导语。

**参数**:
- `imbalance_type: str` - 失衡类型
- `session: int` - 第几次（1-4）

**返回值**: 绘画引导语和主题
