## 定位

本文列出当前 Aimandala 运行时知识库文件，并说明它们的用途。

这些文件不是 Markdown 单一真值源，而是运行时投影、编译产物或评测产物。若它们与 Markdown 真值源冲突，应回到 Markdown 真值源修正，再重新生成运行时投影。

## builds/current

`builds/current` 是当前后端读取的运行时索引和评测输出。当前 `index.json` 仍可能指向 `aimandala-v2.1`；切换到 v2.2 需要另做运行时替换和回归验证。

| 文件 | 用途 |
| --- | --- |
| `builds/current/index.json` | 当前 runtime 读取的编译后索引。 |
| `builds/current/evals/summary.json` | 当前知识包评测摘要。 |
| `builds/current/evals/toc-mvp-fixture-001.json` | fixture 001 的知识包评测输出。 |
| `builds/current/evals/toc-mvp-fixture-002.json` | fixture 002 的知识包评测输出。 |
| `builds/current/evals/toc-mvp-fixture-003.json` | fixture 003 的知识包评测输出。 |
| `builds/current/evals/toc-mvp-fixture-004.json` | fixture 004 的知识包评测输出。 |

## builds/candidates

`builds/candidates` 是候选知识包构建结果，不是当前默认 runtime。

| 文件 | 用途 |
| --- | --- |
| `builds/candidates/test-v22/index.json` | 候选 test-v22 的编译索引。 |
| `builds/candidates/test-v22/quality.json` | 候选 test-v22 的质量检查结果。 |
| `builds/candidates/v2.2-theme-md/index.json` | v2.2 Markdown 主题知识候选编译索引。 |
| `builds/candidates/v2.2-theme-md/quality.json` | v2.2 Markdown 主题知识候选质量检查结果。 |

## packs/v2.1

`packs/v2.1` 是旧兼容 YAML 知识包。除非处理后端兼容、回归对照或迁移问题，不应把它当成当前知识整理目标。

## 使用规则

- 修改流派规则时，先改 Markdown 真值源。
- 修改运行时消费格式时，再更新 `packs/v2.2`。
- 修改 pack 后必须重新生成 `builds/current/index.json`。
- 评测输出只作验证证据，不作为规则来源。
