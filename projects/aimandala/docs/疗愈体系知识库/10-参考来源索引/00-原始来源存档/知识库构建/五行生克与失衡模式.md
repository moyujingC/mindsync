## 定位

本文定义 Aimandala 当前五行生克和失衡模式的 Markdown 单一真值源。

五行生克分析必须建立在逐圈颜色、形状和画面依据之上。失衡不是先验标签，而是在逐圈分析过程中浮现出来的候选。

## 基础关系

相生关系：

```text
木 -> 火 -> 土 -> 金 -> 水 -> 木
```

相克关系：

```text
木 -> 土 -> 水 -> 火 -> 金 -> 木
```

## 分析顺序

每一圈先看圈内关系：

1. 本圈出现了哪些五行。
2. 哪个五行最强，哪个最弱。
3. 是否形成相生、相克、过强、过弱。
4. 是否出现“生多为克”“克不动”“反向压制”。
5. 这种关系如何影响本圈对应的现实层面。

圈内分析完成后，才能进入整体能量流动诊断。

## 失衡浮现原则

失衡候选来自以下证据组合：

- 某一颜色面积过大或过少。
- 某一颜色过深、过浅或填得过满。
- 形状和颜色的五行属性冲突。
- 圈内生克过度或无法转化。
- 某一圈明显强于或弱于其他圈。
- 直断命中特征与逐圈证据互相印证。
- 用户主题、意图、绘画感受与画面证据形成稳定关联。

只有当画面依据、主题语境和逐圈关系能连起来，失衡候选才可以进入报告核心判断。

## 运行时常见失衡类型

| 类型 | 关系 | 基础机制 |
| --- | --- | --- |
| 水多木漂 | 水生木太过 | 情绪或滋养过多，成长根基不稳 |
| 火多土焦 | 火生土太过 | 热情过度，承载力被烧焦 |
| 木多火塞 | 木生火太过 | 想法或成长欲过多，热情表达被堵住 |
| 土多金埋 | 土生金太过 | 承担过多，价值被掩盖 |
| 金多水浊 | 金生水太过 | 标准过多，情绪和智慧流动受阻 |
| 水多火灭 | 水克火太过 | 情绪或恐惧压制热情和行动 |
| 火多金熔 | 火克金太过 | 冲动破坏标准和边界 |
| 金多木折 | 金克木太过 | 规则、批评或标准压制成长 |
| 木多土陷 | 木克土太过 | 扩张破坏承载和稳定 |
| 土多水干 | 土克水太过 | 控制或承担压干流动性 |
| transition-overload | 过渡负荷 | 新旧节奏暂时不同步 |

## 与主题的关系

同一种失衡在不同主题下表现不同。

例如 `金多木折`：

- 通用主题：标准压制成长。
- 财富事业：完美拖延机会，不配得感影响行动。
- 亲密关系：挑剔压制爱意。
- 亲子关系：批评压制孩子成长。

因此失衡类型不能单独进入报告，必须挂载用户主题。

## 与最终报告的关系

Lite 可以只输出一个核心卡点和一个低压调整方向。

Pro 必须保留机制链：画面依据 -> 五行关系 -> 失衡浮现 -> 现实表现 -> 根因链 -> 调节路径。
