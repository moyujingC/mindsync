## 定位

本文定义 Aimandala 当前形状五行感知的 Markdown 单一真值源。

形状是颜色之后的重要辅助维度。形状用于补充、验证、加强或修正颜色判断，不能脱离画面事实单独发挥。

## 形状五行基础映射

| 五行 | 常见形状 | 基础能量 |
| --- | --- | --- |
| 木 | 长方形、直线、条形、网格、放射状 | 生长、发展、延伸、向外展开 |
| 火 | 三角形、尖角、星形、菱形、火焰状 | 上升、突破、热度、不稳定 |
| 土 | 正方形、方形、矩形、十字、容器状 | 稳定、承载、规则、边界 |
| 金 | 圆形、圆弧、椭圆、环形、扇形 | 圆满、完整、收束、保护 |
| 水 | 波浪、螺旋、不规则、点状、水滴 | 流动、变化、情绪、深度 |

## 分析顺序

每一圈按以下顺序分析：

1. 记录主要形状。
2. 记录形状排列：放射、重复、环绕、散乱、对称、集中。
3. 判断形状边缘：圆润、尖锐、规整、断裂。
4. 映射到五行属性。
5. 判断形状与颜色是否一致、加强或冲突。
6. 结合圈层语义翻译成现实状态。

## 形状与颜色的关系

形状不是独立抢结论的维度。

它主要处理三种关系：

- 加强：颜色和形状五行一致，例如红色三角形，火性更强。
- 调和：形状让颜色能量更稳定，例如红色被方形承载。
- 冲突：颜色和形状五行相克或方向不同，例如红色圆形，火和金同时出现。

## 常见形状提示

| 形状 | 提示方向 |
| --- | --- |
| 圆形 / 环形 | 圆满、保护、边界、完整，也可能封闭 |
| 三角形 / 尖角 | 突破、上升、焦灼、攻击性或不稳定 |
| 方形 / 矩形 | 稳定、承载、规则，也可能僵硬 |
| 条形 / 放射状 | 生长、外放、扩展，也可能单向用力 |
| 波浪 / 螺旋 | 流动、情绪、循环，也可能纠结 |
| 点状 / 星点 | 零散、装饰、注意力分散，也可能轻盈活跃 |

## 与最终报告的关系

Lite 报告中，形状只需要支撑最关键的画面依据。

Pro 报告中，形状应进入机制分析：它如何加强颜色、如何造成冲突、如何影响圈内能量流动。
