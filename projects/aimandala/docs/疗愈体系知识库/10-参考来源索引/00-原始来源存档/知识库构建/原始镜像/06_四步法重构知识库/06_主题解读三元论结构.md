# 主题解读三元论结构

> 创建时间: 2026-03-05
> 更新说明: 将主题知识库从二元论扩展为三元论

---

## 问题背景

之前的主题解读知识库 (`theme_knowledge_base.py`) 只区分了两种状态：
- **太过**（颜色浓重）：如深绿、深红、深黄、深白、深蓝
- **不足**（颜色浅淡）：如淡绿、粉红、淡黄、淡白、淡蓝

这导致无法解读**正常/适中**状态，无法完整覆盖曼陀罗绘画的实际情况。

---

## 三元论结构

### 颜色状态的三级分类

| 颜色深浅 | 元素状态 | 对应颜色 | 心理含义 |
|---------|---------|---------|---------|
| **浓重** | 太过 | 深绿、深红、深黄、深白、深蓝 | 能量集中但可能淤堵，情绪压抑，过度表达 |
| **适中** | 正常 | 中绿、中红、中黄、中白、中蓝 | 能量平和，平衡健康，正面表达 |
| **浅淡** | 不足 | 淡绿、粉红、淡黄、淡白、淡蓝 | 能量弱，缺乏生机，需要滋养 |

### 解读维度的三元对应

对于每个**主题 × 元素 × 圈层**组合，现在有三个解读版本：

**示例：父亲关系 × 木 × 内圈**

| 状态 | 解读关键词 | 疗愈方向 |
|------|----------|---------|
| **太过（深绿）** | 独立、抗争、自我意识强烈 | 学习柔和沟通，转化抗争为合作 |
| **正常（中绿）** | 平衡、尊重、健康成长 | 继续保持这种平衡，成为关系典范 |
| **不足（淡绿）** | 压抑、依赖、自我价值低 | 培养自我肯定，逐步建立个人边界 |

## 数据结构变化

### 原结构（二元论）

```python
"木": {
    "内圈": {
        "深绿": { ... },  # 只有太过
        "淡绿": { ... }   # 只有不足
    }
}
```

### 新结构（三元论）

```python
"木": {
    "内圈": {
        "深绿": { ... },  # 太过
        "中绿": { ... },  # 正常 ← 新增
        "淡绿": { ... }   # 不足
    }
}
```

### 完整的颜色状态映射

| 元素 | 太过 | 正常 | 不足 |
|-----|------|------|------|
| **木** | 深绿 | 中绿 | 淡绿 |
| **火** | 深红 | 中红 | 粉红 |
| **土** | 深黄 | 中黄 | 淡黄 |
| **金** | 深白 | 中白 | 淡白 |
| **水** | 深蓝 | 中蓝 | 淡蓝 |

> **注意**: 白色系用"深白"表示大面积纯白（金太过），"中白"表示适量留白（正常），"淡白"表示留白不足（金不足）。

## 解读内容模板

每个状态包含以下字段：

```python
{
    "interpretation": "主要解读文字，描述该状态下的心理特征和生活表现",
    "keywords": ["关键词1", "关键词2", "关键词3"],
    "life_manifestations": [
        "具体生活表现1",
        "具体生活表现2"
    ],
    "healing_direction": "疗愈方向和建议"
}
```

### 不同状态的解读侧重点

| 状态 | 解读侧重点 | 疗愈方向关键词 |
|------|----------|--------------|
| **太过** | 过度表达、淤堵、压抑、可能的问题 | 疏泄、释放、减少、平衡、转化 |
| **正常** | 平衡、健康、良好状态、正面特质 | 继续保持、珍惜、深化、成为榜样 |
| **不足** | 缺乏、匮乏、需要滋养、潜在问题 | 补充、滋养、增强、建立、练习 |

## 与五行元素解读的对应

主题解读的三元论与 [06_五行元素太过与不足解读.md](06_五行元素太过与不足解读.md) 中的通用解读相呼应：

| 元素 | 通用太过 | 通用正常 | 通用不足 |
|-----|---------|---------|---------|
| 木 | 固执、暴躁、评判 | 独立、成长、有边界 | 怨气、嫉妒、依赖 |
| 火 | 焦虑、上火、多梦 | 热情、创造力、喜悦 | 湿寒、拖延、心累 |
| 土 | 僵化、愚拙、自卑 | 憨厚、宽容、稳定 | 不接纳、社交恐惧 |
| 金 | 有勇无谋、强势、苛刻 | 刚毅、自律、有价值 | 讨好、界限不足、委屈 |
| 水 | 是非、恐惧、反复 | 智慧、沟通、分寸 | 固执、不懂变通 |

主题解读将通用含义特化到具体主题（如父亲关系、财富事业等）中。

## 使用示例

### 查询解读

```python
from app.core.theme_knowledge_base import get_interpretation

# 查询父亲关系中，内圈木元素太过（深绿）的解读
result = get_interpretation("父亲关系", "木", "内圈", "深绿")

# 查询母亲关系中，中圈火元素正常（中红）的解读
result = get_interpretation("母亲关系", "火", "中圈", "中红")
```

### 根据颜色深浅判断状态

```python
def get_color_state(element: str, intensity: str) -> str:
    """
    根据元素和颜色深浅获取状态标识

    Args:
        element: 五行元素 (木/火/土/金/水)
        intensity: 深浅 (深/中/淡)

    Returns:
        颜色状态标识
    """
    color_map = {
        "木": {"深": "深绿", "中": "中绿", "淡": "淡绿"},
        "火": {"深": "深红", "中": "中红", "淡": "粉红"},
        "土": {"深": "深黄", "中": "中黄", "淡": "淡黄"},
        "金": {"深": "深白", "中": "中白", "淡": "淡白"},
        "水": {"深": "深蓝", "中": "中蓝", "淡": "淡蓝"},
    }
    return color_map.get(element, {}).get(intensity)
```
