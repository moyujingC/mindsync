# 直断特征 - 快速识别关键心理特征

> 来源文件: `app/core/direct_judgments.py`
> 创建时间: 2026-03-05
> 知识等级: 初级（快速诊断）

---

## 概述

基于画面整体特征的直接判断规则，用于快速识别关键心理特征和模式。

---

## 直断规则列表

### 1. 涂色很满深色为主

| 属性 | 内容 |
|-----|------|
| **画面特征** | 画面整体涂得很满，深色为主 |
| **核心含义** | 焦虑担忧的情绪，除了焦虑还有恐惧 |
| **详细解读** | 可能处于压力较大的状态，需要情绪释放的出口 |
| **建议** | 建议进行情绪疏导，找到安全的表达方式 |
| **严重程度** | 高 |

---

### 2. 整体泛白颜色偏淡

| 属性 | 内容 |
|-----|------|
| **画面特征** | 整体泛白，颜色偏淡 |
| **核心含义** | 做事无力量感，喜欢躺平 |
| **详细解读** | 可能与父亲关系疏远，或母亲强势导致父亲没有力量 |
| **建议** | 重建自我价值感，找到内在动力源 |
| **严重程度** | 中 |

---

### 3. 思虑过重喜好操心

| 属性 | 内容 |
|-----|------|
| **画面特征** | 大面积黄色 |
| **核心含义** | 思虑过重，喜好操心 |
| **详细解读** | 黄色代表'思'，生活中很照顾别人，像太阳一样温暖。但面积过大代表思虑过度，把心思放在别人身上 |
| **建议** | 学会平衡自我关怀与照顾他人 |
| **严重程度** | 中 |

---

### 4. 喜欢分享开口来财

| 属性 | 内容 |
|-----|------|
| **画面特征** | 明显有蓝色+绿色 |
| **核心含义** | 喜欢分享，开口来财 |
| **详细解读** | 蓝色代表喉轮，绿色代表心轮，代表愿意敞开与他人分享，在优秀的表达力和共情力下更容易开口来财 |
| **建议** | 保持开放心态，善用沟通能力 |
| **严重程度** | 积极 |

---

### 5. 入不敷出热情奔放

| 属性 | 内容 |
|-----|------|
| **画面特征** | 外圈有成片红色（相邻色非绿色） |
| **核心含义** | 入不敷出，热情奔放 |
| **详细解读** | 曼陀罗外圈有一圈成片红色，红色属火，意味着燃烧，引申为入不敷出 |
| **建议** | 注意能量管理，平衡付出与收获 |
| **严重程度** | 中 |

---

### 6. 关注外表过手财神

| 属性 | 内容 |
|-----|------|
| **画面特征** | 外圈颜色五颜六色、零零碎碎、花边 |
| **核心含义** | 关注外表，过手财神 |
| **详细解读** | 爱美、爱打扮、要面子，容易做'过手财神'（钱来得快去得也快） |
| **建议** | 关注内在价值，建立健康的财富观 |
| **严重程度** | 中 |

### 7. 表里如一

| **详细解读** | 内外一致，真实坦诚，不伪装 |

| **严重程度** | 积极 |

### 8. 不想说啥无声沉默

| 属性 | 内容 |
|-----|------|
| **画面特征** | 整张留白较多 |

| **详细解读** | 对于世界没有什么想要表达的东西，感知力较弱。或者曾经的表达不被看见后对这个世界有所保留或失望 |
| **建议** | 找到安全的表达方式，逐步重建表达信心 |
| **严重程度** | 中 |

---

### 9. 心门关闭

| 属性 | 内容 |
|-----|------|
| **画面特征** | 外圈留白多，但里圈或中圈涂的颜色3个以上 |
| **核心含义** | 心门关闭 |
| **详细解读** | 对外界不热情，自己有想法，只是对外界有防备 |
| **建议** | 探索防备的原因，在安全的关系中尝试开放 |
| **严重程度** | 中 |

## 颜色深度判断规则

### 深色

| 属性 | 内容 |
|-----|------|
| **判断标准** | 颜色饱和度高，接近色卡深色区 |
| **指标特征** | 力量感强、情绪浓烈、可能压抑 |

### 浅色

| 属性 | 内容 |
|-----|------|
| **判断标准** | 颜色饱和度低，接近色卡浅色区 |
| **指标特征** | 力量感弱、情绪柔和、可能逃避 |

### 混合

| 属性 | 内容 |
|-----|------|
| **判断标准** | 深浅色都有 |
| **指标特征** | 情绪复杂、内外不一致、正在整合 |

## 留白分析

### 大量留白

| 属性 | 内容 |
|-----|------|
| **核心含义** | 保留空间，可能缺乏表达欲或对世界失望 |
| **内圈含义** | 内在空虚或不愿面对 |
| **外圈含义** | 对外在世界保持距离 |

### 少量留白

| 属性 | 内容 |
|-----|------|
| **核心含义** | 充分表达，可能追求完美或焦虑 |
| **内圈含义** | 内在丰富，自我要求高 |
| **外圈含义** | 积极与外界互动 |

### 无留白

| 属性 | 内容 |
|-----|------|
| **核心含义** | 完全填满，可能有控制欲或焦虑 |
| **内圈含义** | 害怕空虚，需要填满一切 |
| **外圈含义** | 想要掌控所有空间 |

## 函数接口

### analyze_whitespace

分析留白比例。

**参数**: `whitespace_ratio: float` - 0-1之间的数值

**返回值**:
```python
{
    "level": "大量留白" | "适量留白" | "少量留白" | "无留白",
    "meaning": "...",
    "inner_meaning": "...",  # 如有
    "outer_meaning": "..."   # 如有
}
```

**判断标准**:
- `> 0.4` → 大量留白
- `> 0.15` → 适量留白
- `> 0.05` → 少量留白
- `<= 0.05` → 无留白

### match_direct_judgments

根据观察到的特征匹配直断。

**参数**: `observed_features: list` - 特征列表，如 `["外圈成片红色", "大面积黄色"]`

**返回值**: 匹配的直断列表
