# 颜色深度解读 - 各色系在三圈中的详细含义

> 来源文件: `app/core/color_meanings.py`
> 创建时间: 2026-03-05
> 版本: v2.0（融合版：手册文本 + 结构化数据）

---

## 概述

本文档是颜色深度解读的**融合版本**，结合《曼陀罗解读手册》原文文本与结构化数据，为AI解读提供完整的知识基础。

### 数据结构设计

每个颜色的解读包含以下字段：

| 字段 | 说明 | 示例 |
|-----|------|------|
| `element` | 所属五行 | 木、火、土、金、水 |
| `color_names` | 颜色名称列表 | ["绿色"] |
| `nature` | 五行自然属性 | 生长、向上、独立 |
| `virtue` | 五常对应 | 仁、义、礼、智、信 |
| `organs` | 对应身体器官 | 肝胆、筋骨、眼睛 |
| `normal_traits` | 正常状态特质 | 偏直觉型，耿直，固执... |
| `too_much_traits` | 太过状态特质 | 听不进去别人意见... |
| `too_little_traits` | 不足状态特质 | 有怨气，嫉妒不仁... |
| `shades` | 各深浅色阶的详细解读 | 见下表 |

### 色阶结构（三元状态）

每个色阶（浅色/中色/深色）包含：

| 字段 | 说明 |
|-----|------|
| `name` | 色阶名称（如"深绿/墨绿"） |
| `state` | 状态：太过/正常/不足 |
| `core_meaning` | 核心含义（一句话概括） |
| `keywords` | 关键词标签 |
| `circles` | 三圈详细解读（内圈/中圈/外圈） |

### 圈层解读结构

每个圈层的解读包含：

| 字段 | 说明 |
|-----|------|
| `interpretation` | 手册原文（完整解读文本） |
| `manifestations` | 表现标签列表（从原文提取的关键点） |
| `healing` | 疗愈方向与建议 |

### 颜色分析原则

1. **颜色优先**：颜色是主要分析维度，视觉最直接
2. **深浅重要**：同一种颜色，深浅不同含义截然不同
3. **面积重要**：面积比例决定该五行的影响力大小
4. **圈层语境**：同一颜色在不同圈含义不同

## 各颜色详细解读

### 红色（火）

**核心含义**: 喜悦、热情，也代表不稳定

#### 五行整体特质（三元状态对照）

| 状态     | 色阶    | 核心特质             | 关键词           |
| ------ | ----- | ---------------- | ------------- |
| **太过** | 深红/暗红 | 压抑的红，有伤痛，愤怒积压在心底 | 伤痛、愤怒、压抑、钻牛角尖 |
| **正常** | 中红/正红 | 喜悦热情，但可能起伏不定     | 阳光、善良、热情、起伏   |
| **不足** | 淡红/粉红 | 渴望爱与温暖，力量不够，容易逃避 | 美好、善良、动力不足、逃避 |

#### 太过状态（深红/暗红/酒红）

**核心含义**: 压抑的红，有伤痛，愤怒积压在心底

| 圈层     | 含义                                                                                                         | 表现                       |
| ------ | ---------------------------------------------------------------------------------------------------------- | ------------------------ |
| **内圈** | 代表有伤痛、有愤怒积压在心底，压抑的情绪无法释放。为人善良，不懂得表达感受，有情绪更多是积压在心底，容易钻牛角尖。伤痛可能是来自于原生家庭，比如从小遭受不公平待遇，被虐待、被语言或行为暴力对待等          | 情绪积压、不善于表达、容易钻牛角尖、原生家庭伤痛 |
| **中圈** | 情绪压抑了很久，没有释放的出口，急躁，对亲近的人有压抑、愤怒。可能出于依赖对方或者对方太过强势，只能忍受，不敢表达自己的感受和情绪。但积累时间长了，很可能会爆发，要么一点小事就点燃情绪，要么身体突然生病      | 情绪积压已久、对亲人压抑愤怒、容易爆发、身体隐患 |
| **外圈** | 身体有炎症，易上火，心脉受损，心脏力量不足。容易漏财，攒不住钱，花钱有些冲动，为感受或情绪买单。虽然表面看着和大家一样，或者看着很阳光，但实际上内在对外界的规则或标准会有对抗，与人打交道不对路时容易压抑愤怒或难过 | 身体炎症、漏财、冲动消费、内在对抗        |
|        |                                                                                                            |                          |

**疗愈方向**: 找到安全的情绪释放方式，学习表达真实感受，疗愈童年创伤

#### 正常状态（中红/正红）

**核心含义**: 喜悦热情，但可能起伏不定

| 圈层 | 含义 | 表现 |
|-----|------|------|
| **内圈** | 为人阳光，容易快乐，善良，能够温暖他人，待亲近的人比较热情，笑点和泪点都比较低，但心情容易起伏，安全感不够，受外界影响很大，对自己没信心，很希望获得他人的认可 | 阳光快乐、善良温暖、情绪起伏、渴望认可 |
| **中圈** | 和亲近的人有归属感，为人热情、付出；另一方面可能让对方觉得过于亲近，产生压力、有负担。情绪起伏比较大，这几天开心，过几天难过担忧，安全感不足，容易着急 | 有归属感、热情付出、情绪起伏大、安全感不足 |
| **外圈** | 身体容易上火。对外人很热情，在别人眼中是个欢喜阳光的人，别人很容易亲近。赚钱有动力有热情，但这种热情很难持续。做事容易着急，三分钟热度，没有坚持力，不自律，给自己定的规则经常被感受影响，财富进账忽高忽低，为情绪买单，看到喜欢就想买，不大考虑性价比，很难攒住钱 | 热情阳光、赚钱有动力、三分钟热度、难攒钱 |

**疗愈方向**: 建立内在稳定感，减少对外界评价的依赖，保持热情但学会稳定

#### 不足状态（淡红/粉红）

**核心含义**: 渴望爱与温暖，力量不够，容易逃避

| 圈层 | 含义 | 表现 |
|-----|------|------|
| **内圈** | 喜欢美好，温暖，内在善良，但力量和热情不够，求爱求温暖，对生活的欢喜心不够，对红尘淡淡的，赚钱动力不足，担当力不够，遇事容易逃避 | 喜欢美好、力量不够、赚钱动力不足、容易逃避 |
| **中圈** | 与亲近的人不亲密，热情不起来。亲密关系里比较被动，小女人，喜欢撒娇，但内心希望得到对方的温暖，希望对方主动。情绪起伏大，力量外放，如遇人不淑容易造成情感伤痛 | 不亲密、被动、撒娇、情绪起伏 |
| **外圈** | 湿寒体质，心脏力量不够，做事有心无力，容易拖延，持续力和爆发力都不足，经常感觉到疲惫，觉得自己被世界排挤在外，花钱和赚钱都不开心，没有心力 | 湿寒体质、拖延、疲惫、心力不足 |

**疗愈方向**: 从自我关爱开始，逐步建立内在力量，培养对生活的热情

#### 特殊位置警示

| 位置 | 含义 | 细节 |
|-----|------|------|
| **外圈红色成片** | 漏财、入不敷出、消耗型 | 火是往外散发热量的，外圈红代表燃烧消耗，金钱来得快去得快，过手财神（相邻有绿色除外） |
| **外圈红色零碎** | 爱美、爱打扮、要面子 | 外圈颜色五颜六色零碎，花边状，代表关注外表 |

**风险提示**: 外圈成片红色且颜色浓烈，财务风险高

**警告信号**:
- 红色连片且无外圈绿色
- 深红色占比过高
- 外圈成片红色无绿色

### 黑色（水）

**核心含义**: 伤痛

**呈现形式**:
- **直接黑色**: 伤痛直接呈现，不愿隐藏
- **夹杂暗物质**: 在其他颜色中夹杂黑色，伤痛被包裹

| 圈层 | 含义 |
|-----|------|
| **内圈** | 原生家庭带来的创伤，未表露出来 |
| **中圈** | 伤痛已瞒不住，亲近的人能看到 |
| **外圈** | 伤痛已包不住，不想隐瞒，有力量表达不满 |

### 紫色（火或木）

**归属说明**: 暧昧色，可归为弱火或木属性

**核心含义**: 神秘、浪漫、自尊心强、缺乏动力和热情、渴望被关注、紫气东来、高贵、高维下载链接、与第七脉轮相关、直觉力、贵气、魅力、信仰、艺术感、成熟、稳重

#### 三元状态对照

| 状态 | 核心特质 | 表现 |
|-----|---------|------|
| **太过** | 挑剔、高冷、封闭、压抑、紧张、严肃、心事重重、忧郁、偏向消极、不切实际 | 最近直觉不错，可能有女巫的能量（直觉灵敏，做梦很准），但也会挑剔、高冷、封闭。紫色画的特别深重，笔触很重，面积比例大，颜色很暗或很浓的，基本上都有些封闭，喜欢独处，不喜欢与人过多接触。嘴上不说，但心里会挑剔别人，看不上别人 |
| **正常** | 紫气东来，高贵、高维下载链接、与第七脉轮相关、直觉力，贵气，魅力、信仰、艺术感、神秘、成熟、稳重 | 介于太过和不足之间的平衡状态，但也有高冷，热情不足，渴望被关注，自尊心特别强，动力不够等问题 |
| **不足** | 喜欢自己默默努力，喜欢待在自己的空间；爱幻想；灵性有所发展，但不稳定 | 近期心情躁动，可能有些迷茫；信仰或信念力量不够，容易摇摆不定 |

#### 各圈层解读

| 圈层 | 含义 |
|-----|------|
| **内圈** | 灵性追求，直觉力发展，但可能不接地气；偏火：自我封闭，活在自我世界；偏木：追求灵性但不易落地 |
| **中圈** | 在关系中重视精神交流，可能有距离感；感知力强但挑剔，拿自己的标准衡量别人，不易亲近 |
| **外圈** | 给人神秘高贵印象，外人觉得有距离；比较高冷，外人觉得不好接近 |

**来源**: 芷默老师文章《颜色解读：紫色篇》+《曼陀罗解读手册》

### 橙色（火+土）

**归属说明**: 暧昧色，介于火和土之间

**核心含义**: 付出、控制、照顾者

**形成**: 黄色+红色=橙色

#### 三元状态对照

| 状态 | 核心特质 | 表现 |
|-----|---------|------|
| **太过** | 自负，听不进去别人意见，固执己见，钻牛角尖，对别人有控制欲 | 有些自负，听不进去别人好的意见，会固执己见，容易钻牛角尖，对别人有控制欲。也代表压抑焦虑，对这个世界有封闭，没有敞开心扉 |
| **正常** | 有活力，有自信，性格开朗，积极向上，内心欢喜愉悦 | 介于火和土之间，正面意义代表有活力，有自信，性格开朗，积极向上，内心欢喜愉悦，正橙色也代表对福报的承载，对贵人和财富的吸引 |
| **不足** | 不自信，有点社恐，只想自己待着，脾胃不好，精力不足，兴趣寥寥，情绪低落 | 不自信，有点社恐，只想自己待着，脾胃不好，精力不足，兴趣寥寥，情绪低落，有点懒散，对这个世界缺少一份好奇心和好感度，渴望爱和温暖，渴望更多认可 |

#### 各圈层解读

| 圈层 | 含义 |
|-----|------|
| **内圈** | 从小照顾家庭多，想证明自己，认为自己不够好；温暖善良，渴望爱与认可，但可能依赖外界 |
| **中圈** | 在情感中用力过猛，以爱之名控制，容易评判；与家人相处温暖，愿意为家人付出 |
| **外圈** | 对这个世界有控制欲，赚钱动力足但付出多收获少；对外人热情，有吸引力，贵人运好 |

### 粉色（火）

**强度**: 弱火

**归属说明**: 弱火属性，属于暧昧色

**核心含义**: 恋爱和美好的颜色，有撒娇的味道，对爱有很多幻想和渴望，像小女人一样渴望被呵护，对对方有依赖

**心理特征**: 对自己心疼和怜悯，爱自己的力量弱，内心善良易满足

**行为特征**: 在亲密关系中被动，不会主动进攻，习惯等待，想做小女人/小男人，不想扛事

**注意**: 通常弱火属性的颜色如粉红、玫红、橘红，都是能够付出爱和温暖，但也会向外求取爱和温暖。生活中别人给你的爱是不稳定的，或者TA给你的爱未必刚好满足你、刚好是你想要的，所以这类宝宝外求的过程中容易受情伤

| 圈层 | 含义 |
|-----|------|
| **内圈** | 爱自己的力量弱，对自己心疼，内心善良但渴望被呵护；内在温柔，渴望被爱，依赖性强 |
| **中圈** | 对亲近的人重情重义，但被动等待，偶尔给惊喜但缺乏主动性；在亲密关系中撒娇，希望被呵护 |
| **外圈** | 希望世界对他更好，对外人彰显义气，但容易依赖外界认可；关注外表，爱美，容易为情绪消费 |

**疗愈方向**: 增加正红色，练习主动表达需求，建立行动力

### 玫瑰红（火）

**强度**: 弱火

**归属说明**: 弱火属性

**核心含义**: 代表喜欢美好，也想要分享更多美好，但具体有没行动还不知道，与粉色相比，玫红色显得更稳重成熟些，但内在能量不变，也是渴望爱和呵护

| 圈层 | 含义 |
|-----|------|
| **内圈** | 成熟稳重的外在，内心仍渴望爱；内心浪漫，追求精神层面的共鸣 |
| **中圈** | 在关系中稳重但仍有期待；对亲密关系有浪漫幻想，希望被当作特别的人对待 |

## 颜色组合解读

颜色组合的解读在**四步法**中通过以下方式处理：

### 1. 直断阶段（第一步）
识别特定的颜色组合模式：

| 组合模式 | 含义 | 判断依据 |
|---------|------|---------|
| **蓝色+绿色** | 喜欢分享，开口来财 | 蓝色代表喉轮，绿色代表心轮，代表愿意敞开与他人分享 |
| **紫色+黄色** | 对信任感缺失 | 先天好但后天没跟上，对人际关系有怀疑 |

### 2. 生克分析阶段（第四步）
分析颜色间的五行生克关系：

| 组合 | 五行关系 | 解读 |
|-----|---------|------|
| **红色+绿色** | 火生木 | 热情推动成长，但火过旺会塞木 |
| **绿色+黄色** | 木克土 | 主见与承载之间的张力 |
| **黄色+蓝色** | 土克水 | 思虑与智慧之间的制约 |

**注意**: 颜色组合解读不再是独立功能，而是整合到四步法的直断和生克分析中。

## 函数接口

### get_color_meaning

获取指定颜色的基础含义。

**参数**:
- `color: str` - 颜色名称
- `shade: str = None` - 色阶（浅/中/深），可选
- `circle: str = None` - 圈层（内圈/中圈/外圈），可选

**返回值**: 颜色含义字典，未找到返回 `None`

**示例**:
```python
from app.core import get_color_meaning

# 获取绿色基本信息
result = get_color_meaning("绿色")

# 获取深绿色在内圈的含义
result = get_color_meaning("绿色", shade="深绿", circle="内圈")

# 使用别名查询
result = get_color_meaning("墨绿")  # 自动映射到绿色
```

### get_color_detailed_interpretation

获取颜色的详细解读（融合版）。

**参数**:
- `color: str` - 颜色名称

### get_special_color_meaning

获取特殊颜色（暧昧色）的含义。

**参数**:
- `color: str` - 特殊颜色名称（如"紫色"、"橙色"）
- `element_preference: str = None` - 五行偏好（"火"/"木"等），可选

**返回值**: 特殊颜色解读字典

**示例**:
```python
from app.core import get_special_color_meaning

# 获取紫色解读（无偏好）
result = get_special_color_meaning("紫色")

# 获取紫色解读（偏向火）
result = get_special_color_meaning("紫色", element_preference="火")
```
