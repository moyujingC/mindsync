# 通用解读知识库（理论整合版）

> 创建时间: 2026-03-05
> 文件位置: `app/core/general_interpretations.py`
> 版本说明: 基于五行理论整合的三元论结构（太过/正常/不足）

---

## 概述

通用解读知识库提供**无主题**的五行解读，作为所有主题特化解读的**基础层**。

### 为什么需要通用解读？

1. **作为主题解读的 fallback** - 当特定主题缺少某条解读时，回退到通用版本
2. **支持无主题解读场景** - 用户未选择特定主题时，提供基础解读
3. **统一的解读框架** - 所有主题特化解读都基于相同的结构

## 三元论结构

与主题解读一致，通用解读采用**三元论**：

| 状态 | 含义 | 疗愈方向 |
|-----|------|---------|
| **太过** | 能量过度集中，可能淤堵 | 疏泄、释放、减少 |
| **正常** | 能量平衡健康 | 继续保持、深化 |
| **不足** | 能量偏弱，需要滋养 | 补充、增强、建立 |

### 颜色与状态映射

```python
COLOR_STATE_MAPPING = {
    "深绿": ("木", "太过"),
    "绿色": ("木", "正常"),
    "淡绿": ("木", "不足"),
    # ...
}
```

## 五行通用解读详情

### 木元素 - 生长、扩张、独立
**对应脏腑**: 肝胆、筋骨、眼睛、腿脚

#### 内圈（自我）

| 状态 | 解读 | 关键词 | 疗愈方向 |
|-----|------|--------|---------|
| **太过** | 自我意识强烈，固执己见，独立但容易与他人产生冲突，内心有评判和抵抗 | 固执、独立、评判、抵抗 | 学习柔和与接纳，转化固执为坚定，减少评判，增加包容 |
| **正常** | 健康的自我意识，有清晰的边界感，独立而有生机，积极向上 | 独立、生机、成长、清晰边界 | 继续保持这种健康的独立状态，在成长中保持平衡 |
| **不足** | 自我价值感低，独立性差，容易依赖他人，内心有怨气和压抑 | 依赖、压抑、怨气、自我价值低 | 建立自我肯定，培养独立意识，学习健康地表达需求和情绪 |

#### 中圈（当下关系）

| 状态 | 解读 | 关键词 | 疗愈方向 |
|-----|------|--------|---------|
| **太过** | 当下倾向于坚持己见，在人际关系中不易妥协，可能引起冲突 | 坚持、冲突、不易妥协 | 练习倾听和共情，学习在坚持与妥协之间找到平衡 |
| **正常** | 当下在关系中能够保持独立又灵活，既有原则又能合作 | 灵活、合作、原则、平衡 | 继续保持这种健康的人际互动模式 |
| **不足** | 当下在关系中容易妥协，难以坚持自我，可能感到被压抑 | 妥协、压抑、无边界 | 学习设立健康边界，从小事开始坚持自己的想法 |

#### 外圈（未来/外在表现）

| 状态 | 解读 | 关键词 | 疗愈方向 |
|-----|------|--------|---------|
| **太过** | 未来倾向于独立开创，不愿受传统束缚，有强烈的突破欲望 | 开创、突破、独立、反叛 | 将独立精神转化为建设性力量，在创新中保持与环境的和谐 |
| **正常** | 未来能够在继承与创新之间找到平衡，既独立又融入 | 传承、创新、平衡、融入 | 继续发展健康的独立性，在成长中保持与他人的连接 |
| **不足** | 未来可能缺乏突破的勇气，容易随波逐流，难以实现自我价值 | 跟随、缺乏勇气、迷茫 | 探索内心真正的渴望，逐步建立自信和独立能力 |

## 通用解读 vs 主题特化解读

| 维度 | 通用解读 | 主题特化解读 |
|-----|---------|-------------|
| **适用范围** | 所有场景 | 特定主题（如父亲关系、财富事业） |
| **内容深度** | 基础心理特征 | 主题相关特化表现 |
| **使用时机** | 无主题选择 / fallback | 用户选择了特定主题 |
| **数据结构** | element -> circle -> state | theme -> element -> circle -> state |

### 层级关系

```
通用解读（基础层）
    ↓ 特化
主题解读（应用层）
    - 父亲关系
    - 母亲关系
    - 财富事业
    - 身体健康
    - 亲密关系
    - 亲子关系
    - 个人成长
```

## 与主题解读的对比示例

### 示例：内圈 + 木 + 太过

**父亲关系主题特化**：

**财富事业主题特化**（假设）：
> 在事业发展上倾向于独立创业，不愿受雇于人，有自己的想法和规划，但可能与上级或合作伙伴产生分歧。
