## 一、五行颜色体系

| 五行 | 代表颜色 | 色系范围 | 关键词 |
|------|---------|---------|--------|
| **木** | 绿色、青色、翠色 | 绿色系（浅绿→深绿→墨绿） | 生长、独立、发展 |
| **火** | 红色、紫色、橙色、粉红色 | 红色系（粉红→正红→深红→紫） | 热情、能量、情绪 |
| **土** | 黄色、咖啡色、茶色、褐色 | 黄色系（米黄→土黄→咖啡→褐） | 稳定、包容、滋养 |
| **金** | 白色、金色、银色 | 白色/金色系（乳白→银白→金） | 收获、纯洁、界限 |
| **水** | 黑色、蓝色、灰色 | 黑色/蓝色系（浅蓝→深蓝→黑→灰） | 智慧、流动、深度 |

### 颜色深度解读

**同一五行内，颜色深浅代表能量状态：**

- **浅色/淡色**：能量不足、尚未激活、潜在状态
- **正色/饱和色**：能量平衡、自然流动、健康状态
- **深色/浓色**：能量过载、压抑积累、需要释放

## 二、三环结构框架

| 圈层 | 维度 | 时间 | 对应 | 关系主题 | 解读内容 | 共振状态 |
|------|------|------|------|---------|---------|---------|
| **里圈** | 意识 | 过去 | 灵 | 我和自己的关系 | 对自己的看法、原生家庭/过往伤痛、自我价值 | 认知层面 |
| **中圈** | 能量 | 现在 | 心 | 我的亲密关系 | 爱人/闺蜜/亲朋、情感互动模式 | 情绪层面 |
| **外圈** | 物质 | 未来 | 身 | 我和世界的关系 | 对世界的看法、物质/事业、身体/财富 | 具体呈现 |

## 三、颜色深度解读（以红色为例）

### 红色总论

红色：三角形，五行|火，五常|礼，五脏|心，六腑|小肠，五志|喜，五官|舌，身体|脉，五藏|神

- **火生土** = 红色生土黄色
- **木生火** = 绿生红
- **水克火** = 黑/蓝克红
- **火克金** = 红克白

火主礼，其性急，其情恭，其味苦，其色赤。

- **火盛之人**：头小脚长，上尖下阔，浓眉小耳，精神闪烁，为人谦和恭敬，纯朴急躁
- **火衰之人**：黄瘦尖楞，语言妄诞，诡诈妒毒，做事有始无终

红色代表一个人的热情和喜悦的生命状态。红色很少或者没有，代表对生活没有热情和期待。红色过多而没有水克制，代表情绪失控。

### 红色三圈解读

#### 1. 淡红色（失落的红）

**核心含义**：失落、伤感。默认自己被排挤或者辜负了而心寒。有无力感。

| 圈层 | 解读 |
|------|------|
| **里圈** | 情绪跳跃不动，没有力量，心情低落，容易悲伤，没兴趣，欲望值低 |
| **中圈** | 对亲近的人感情比较淡漠 |
| **外圈** | 觉得自己被这个世界排挤，对外面发生的事情不感兴趣。淡漠，无力，沮丧 |

#### 2. 正红色（喜悦的红）

**核心含义**：喜悦、热情，也代表不稳定。红色面积过大说明比较狂，抗拒，不屈服。

| 圈层 | 正面解读 | 负面解读 |
|------|---------|---------|
| **里圈** | 有意识调整状态，与他人常互动，主动关心人 | 心情忽上忽下，心情好就积极，心情不好就悲观 |
| **中圈** | 为人热情，乐于付出，与他人常互动，关心别人，会向身边人示好 | 与人相处有依赖感，狂热，有压力 |
| **外圈** | 对世界有喜悦，有欢喜心，有赚钱的动力，心动来源于物质 | 喜怒形于色，不成熟，遇事不稳定。零碎的红色，过手财神，如果红色连成片，代表入不敷出（有同等面积绿除外） |

#### 3. 深红色（压抑的红）

**核心含义**：压抑的红，淤堵的红——有伤痛

| 圈层 | 解读 |
|------|------|
| **里圈** | 有愤怒压抑的情绪需要被释放 |
| **中圈** | 对亲近的人有压抑的感觉，甚至厌烦，心塞，情绪没有出口 |
| **外圈** | 内心其实有抑郁的倾向，对世界有比较多的厌烦 |

## 四、常见直断特征

### 画面整体特征

| 画面特征          | 心理解读                                                     |
| ------------- | -------------------------------------------------------- |
| **涂色很满，深色为主** | 焦虑担忧的情绪。画面整体涂的很满，除了焦虑还有恐惧                                |
| **整体泛白，颜色偏淡** | 做事无力量感，喜欢躺平。也代表和父亲的关系疏远或者家里母亲强势父亲本身也没有力量                 |
| **思虑过重，喜好操心** | 大面积黄色，生活中很照顾别人，像太阳一样温暖。黄色也代表"思"，意味把心思放在别人身上，面积过大代表思虑过度   |
| **喜欢分享，开口来财** | 明显有蓝色+绿色，蓝色代表喉轮，绿色代表心轮，代表愿意敞开与他人分享，在优秀的表达力和共情力下更容易开口来财   |
| **入不敷出，热情奔放** | 曼陀罗外圈有一圈成片红色，红色属火，意味着燃烧，引申为入不敷出（相邻色是绿色除外）                |
| **关注外表，过手财神** | 外圈颜色五颜六色，零零碎碎，花边，代表爱美，爱打扮，要面子，容易做过手财神                    |
| **表里如一**      | 内圈和外圈的颜色完全一致                                             |
| **不想说啥，无声沉默** | 整张留白比较多，对于这个世界没有什么想要表达的东西，感知力较弱。或者曾经的表达不被看见后对这个世界有所保留或失望 |
| **心门关闭**      | 外圈留白多，但里圈或中圈涂的颜色是3个以上，代表心门关闭，自己有想法，只是对外界不热情              |

## 五、使用说明

### AI 解读时的应用流程

1. **颜色识别**：识别画面主色调（占比最高的1-3种颜色）
2. **五行归类**：将颜色归类到五行（木火土金水）
3. **圈层定位**：观察该颜色在里圈/中圈/外圈的分布和浓度
4. **深度判断**：判断是淡色、正色还是深色
5. **综合解读**：结合五行属性+圈层含义+深度状态，生成个性化解读

### 注意事项

- **没有好坏**：颜色只有状态差异，没有优劣之分
- **动态变化**：同一人在不同时期的曼陀罗颜色会有变化，反映能量流动
- **整体观察**：不要只看单一颜色，要看颜色之间的关系（生克、平衡）
- **结合用户反馈**：AI解读后询问用户"这是否符合你当前的状态？"进行校准
