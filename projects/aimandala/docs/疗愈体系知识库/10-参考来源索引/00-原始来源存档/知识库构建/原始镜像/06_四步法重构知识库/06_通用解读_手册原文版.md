## 概述

本版本直接从《曼陀罗解读手册》第二章"五行感知法"提取原文，保留芷墨老师的原始表述方式，作为通用解读的**权威版本**。

### 与理论整合版的区别

| 维度       | 手册原文版           | 理论整合版           |
| -------- | --------------- | --------------- |
| **来源**   | 手册原文直接提取        | 基于五行理论整合        |
| **语言风格** | 芷墨老师原话，口语化      | 结构化描述，规范化       |
| **结构**   | 按颜色分类（深绿/中绿/淡绿） | 按状态分类（太过/正常/不足） |
| **覆盖度**  | 部分圈层有缺失（如金元素）   | 5元素×3圈×3状态完整覆盖  |
| **特殊颜色** | 包含紫色、橙色、粉红、玫红   | 标准五行颜色          |

## 五行通用解读详情

### 木元素 - 生长、向上、独立

**五行属性**: 木
**对应品德**: 仁
**对应脏腑**: 肝胆、筋骨、眼睛、腿脚

#### 基本特征

| 状态 | 特征描述 |
|-----|---------|
| **正常** | 偏直觉型，耿直，固执，独立，会有自己的界限和空间感；有生机，要求阳光，积极，乐观，向上；喜欢成长，爱学习，爱精进；三观正，讲仁义，愿意付出，结果能够与人分享 |
| **太过** | 因为要一路向上发展，听不进去别人意见，评判心多，容易自我批评，批评他人，容易暴躁，固执。像野草一样，自私，侵占，野蛮生长，掠夺式生长 |
| **不足** | 有怨气，嫉妒不仁，郁闷，忧郁，憋闷。在情感方面，自我内在力量不足，安全感不足，容易依赖他人。在财富方面，做事信心不够，抗压力不强，过于谨慎，肝胆气不足，精神不济，行动力不足，容易疲惫 |

#### 内圈（自我）

| 颜色     | 状态  | 解读原文                                                                                                                                                                                  |
| ------ | --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **深绿** | 太过  | 一般内在有伤痛或者忧郁，无法释放。如果深绿色出现在内圈，很可能说明绘画者内在有自己的一套思想体系，比较能抱元守一，活在负面状态下，很容易变得固执，思维比较一根筋，听不进去别人的意见，容易撞了南墙又撞南山。也可能代表绘画者有才华有能力，对自身要求和期待都比较高，俗称'自视甚高'，但现实中往往容易受挫或者被打压，内在想不通的时候，容易对自我有严重评判，容易郁郁寡欢 |
| **中绿** | 正常  | 能量比较平和，多数是正面含义。如果中绿是在内圈，说明绘画者开始有了更多信心和独立的想法，想要向上成长，对未来、对自己有了更多的希望，能自己给自己生机                                                                                                            |
| **淡绿** | 不足  | 像嫩芽，嫩草，淡绿色的力量相对弱一些，它没有中绿色那么强的生机，但也没有深绿色那样的固执和评判。淡绿在里圈，绘画者可能经历过黑暗的过往，迎来了春天，内心有了一些对自己对生活的希望，但还不敢完全相信他会好起来，容易经历反复，勇气和力量相对较弱，需要被保护，被周围人认可和呵护。也可能绘画者本身内在力量不足，信心不够，有些自卑，习惯依赖他人，把力量外放在他人身上   |

#### 中圈（当下关系）

| 颜色 | 状态 | 解读原文 |
|-----|------|---------|
| **深绿** | 太过 | 绘画者近期可能很郁闷、很忧郁或很孤独，觉得身边的人不理解自己，周围人打压自己等，也有可能对身边人有评判，看不上亲近的人，觉得他们不如自己积极上进、有追求，他们的成长步伐跟不上自己 |
| **中绿** | 正常 | 绘画者近期能量比较积极向上，积极的精神容易感染到身边的人。也可能代表他比较喜欢独处，在家里要有一定的空间感和界限感，与他人相处比较有界限，彼此尊重对方，独立性比较强，能力不错，但也要结合五行相生相克和里圈来看待 |
| **淡绿** | 不足 | 绘画者与人相处时容易讨好对方，依赖对方，希望对方给予自己更多安全感和爱，自己缺乏主心骨和主见，遇到选择时会优柔寡断，期待别人给自己选择或者答案。会害怕冲突，遇到问题时容易逃避 |

#### 外圈（外在表现）

| 颜色 | 状态 | 解读原文 |
|-----|------|---------|
| **深绿** | 太过 | 绘画者比较有担当，但也容易以自我为中心，做事有自己的一套，比较固执。可能有种'孤芳自赏'的感觉，觉得别人都不理解自己，别人达不到自己的高度，容易对别人有评判，但Ta通常会憋着不说，更多是在心里评判，内在有憋闷，情绪容易暴躁。别人也觉得他不好接近，经常会对他有一些误解，也可能说明领导或环境对他有所打压 |
| **中绿** | 正常 | 外人会认为他三观正，积极向上，爱学习爱成长，独立性强，愿意付出和分享，乐于助人，对他的风评都很好 |
| **淡绿** | 不足 | 别人觉得他很好相处，活泼可爱，他自己却没有信心，对自身能力不自信，需要获得他人的认可来补充信心，做事会有比较多顾虑，会考虑是否满足别人的期待和标准，想要向上成长但内在力量不足，很难持续给自己鼓劲，行动力相对比较弱，需要更多坚韧的力量，需要历经更多的打磨 |

### 火元素 - 炎热、向上、光明

**五行属性**: 火
**对应品德**: 礼
**对应脏腑**: 心、小肠
**备注**: 粉红色、藕荷色、玫红色等颜色为暧昧色，可归为弱火

#### 基本特征

| 状态     | 特征描述                                                        |
| ------ | ----------------------------------------------------------- |
| **正常** | 阳光，快乐，积极向上，付出比较多，欢喜心，热情，热爱，欣赏，创造力                           |
| **太过** | 特别容易着急焦虑，有伤痛，自我牺牲，爱而不得，善变，三分钟热度，容易半途而废，有始无终                 |
| **不足** | 湿寒体质，对爱有匮乏，求爱求温暖，不爱动，拖延，没有动力，心累，容易三分钟热度，朝三暮四，有始无终，小女人，有依赖情节 |

#### 内圈（自我）

| 颜色 | 状态 | 解读原文 |
|-----|------|---------|
| **深红** | 太过 | 代表有伤痛、有愤怒积压在心底，压抑的情绪无法释放。为人善良，不懂得表达感受，有情绪更多是积压在心底，容易钻牛角尖。伤痛可能是来自于原生家庭，比如从小遭受不公平待遇，被虐待、被语言或行为暴力对待等 |
| **中红** | 正常 | 为人阳光，容易快乐，善良，能够温暖他人，待亲近的人比较热情，笑点和泪点都比较低，但心情容易起伏，安全感不够，受外界影响很大，对自己没信心，很希望获得他人的认可 |
| **淡红** | 不足 | 喜欢美好，温暖，内在善良，但力量和热情不够，求爱求温暖，对生活的欢喜心不够，对红尘淡淡的，赚钱动力不足，担当力不够，遇事容易逃避 |

#### 中圈（当下关系）

| 颜色 | 状态 | 解读原文 |
|-----|------|---------|
| **深红** | 太过 | 情绪压抑了很久，没有释放的出口，急躁，对亲近的人有压抑、愤怒。可能出于依赖对方或者对方太过强势，只能忍受，不敢表达自己的感受和情绪。但积累时间长了，很可能会爆发，要么一点小事就点燃情绪，要么身体突然生病 |
| **中红** | 正常 | 和亲近的人有归属感，为人热情、付出；另一方面可能让对方觉得过于亲近，产生压力、有负担。情绪起伏比较大，这几天开心，过几天难过担忧，安全感不足，容易着急，口头禅是'快点'、'快点' |
| **淡红** | 不足 | 与亲近的人不亲密，热情不起来。亲密关系里比较被动，小女人，喜欢撒娇，但内心希望得到对方的温暖，希望对方主动。情绪起伏大，力量外放，如遇人不淑容易造成情感伤痛 |

### 土元素 - 长养、化育、稳定

**五行属性**: 土
**对应品德**: 信
**对应脏腑**: 脾、胃、肌肉

#### 基本特征

| 状态 | 特征描述 |
|-----|---------|
| **正常** | 憨厚，宽容，接纳，会尊重别人的喜欢和界限；有承载力，做事务实，认真，靠谱，脚踏实地，稳定；为人忠孝至诚，看重承诺，容易取得别人信任 |
| **太过** | 头脑僵化，比较固执，转不过弯；愚拙不明，反应笨笨的，容易不辨情况相信别人，也可能是抗拒别人；内向好静，内在有自卑，容易有疲惫感；遇事会逆来顺受，忍辱负重 |
| **不足** | 对自我或他人不够接纳，内在有自卑，容易焦虑，有社交恐惧；遇事容易抗拒，逃避；不讲信用，不通情理 |

#### 内圈（自我）

| 颜色 | 状态 | 解读原文 |
|-----|------|---------|
| **深黄** | 太过 | 代表地面下的土地，没法接纳自己，会逃避问题，掩饰自己的不安和错误，容易自责。思维方式和做事都会比较固执，尤其是圆形或正方形的深黄，有自成一体的思想，基本听不进去别人的意见，可能表面上说好，但实际上仍然我行我素 |
| **中黄** | 正常 | 代表这段时期内在相对比较稳定，为人靠谱，可以为自己做主，有自己的主心骨，对自我的接纳力有提升；也可能代表渴望得到安定，渴望提升自身承载力 |
| **淡黄** | 不足 | 不接地气，有点飘，赚不到钱，光谈爱和理想，不落地，行动力不足 |
| **咖色** | 太过（特殊色） | 有点像凝结在地底的土，代表伤痛。绘画者可能自卑感比较强烈，但又无力改变，倾向于逃避或忍耐。比如曾经很相信别人，结果别人辜负他，导致绘画者内在受伤，关闭心门，选择不再相信他人和世界。一般这类人原生家庭有伤痛，对家庭失去信任；不被父母信任；总是被父母用言语打压；被父母抛弃（父母离异、出轨）等 |

### 金元素 - 清静、肃杀、收敛

**五行属性**: 金
**对应品德**: 义
**对应脏腑**: 肺、支气管、皮毛
**备注**: 金属性是白色，而金色则代表灵性，灵性的苏醒，宗教信仰，光和爱等

#### 基本特征

| 状态 | 特征描述 |
|-----|---------|
| **正常** | 为人刚毅果断，疏财仗义，深知廉耻，自律，要求完美，能干，聪明，努力，执行力强，性价比高，有价值，自我价值感高 |
| **太过** | 有勇无谋；标准和要求多，追求完美，容易自我批评，批评他人；会背负很多不必要的压力，活得比较累；相对比较强势，待人苛刻，身边人难以亲近，和TA在一起比较累；恐惧和不安全感多，焦虑多 |
| **不足** | 倾向于讨好别人，界限感不足，自我空间被挤压，容易委屈，容易难过 |

#### 内圈（自我）

| 颜色 | 状态 | 解读原文 |

### 水元素 - 滋润、向下、流动

**五行属性**: 水
**对应品德**: 智
**对应脏腑**: 肾、后腰、循环系统、耳朵、膀胱

#### 基本特征

| 状态 | 特征描述 |
|-----|---------|
| **正常** | 有智慧，有才华，为人深思熟虑；与人沟通合作好，语言清和，人脉广，能够滋养他人，陪伴他人，愿意帮助他人；温润如玉，懂分寸，知进退，知世故而不世故；信息的流动和交换 |

| **不足** | 不懂变通，固执；没有分寸；说话比较卡，喉轮卡，有话说不出，有苦难言 |

|-----|------|---------|
| **黑色** | 太过 | 为冬藏的水，代表有伤痛或恐惧和不安全感 |
| **深蓝** | 太过 | 自我意识强，性格安静，喜欢独处，喜欢钻研、研究，如果正向发展，可以成为某个领域的专业人士，如果负向发展，容易钻牛角尖，陷入自己的逻辑里出不来。均匀的深蓝在里圈，也代表最近绘画者在内观，静修，冥想等，通过链接内在不断滋养自己。带斑的深蓝是代表伤痛 |
| **中蓝** | 正常 | 自我意识强，智慧在生发，最近爱学习，接触更多的智慧，和内在的链接增加，能滋养自己；也可能心里面也会有一些湿寒，更多是接触智慧，学习智慧，但没有真正去实践。有可能想得多做得少 |
| **浅蓝** | 不足 | 绘画者内心温柔，清新，有浪漫情怀，很聪明，但也会聪明反被聪明误，做决策时也会优柔寡断，可能盲目跟随，也可能不自信，不敢表达真实的自己。同时绘画者对于智慧也渴望提升，但容易想得多，做的少 |

#### 中圈（当下关系）

| 颜色 | 状态 | 解读原文 |
|-----|------|---------|
| **黑色** | 太过 | 对家人也无法敞开，不安全感强烈，担忧多 |
| **深蓝** | 太过 | 1）在家喜欢独处，需要有自己的空间来充电和做研究，否则会很郁闷很痛苦；2）能量相对比较稳定，但遇事情也容易对境生心，引起情绪波动；3）与亲人关系一般般，不是特别爱沟通，亲人会觉得他不是特别热情 |
| **中蓝** | 正常 | 1）与亲近的人或爱人有良好的沟通，相处舒服；2）付出也需要有回报，否则容易多抱怨 |
| **浅蓝** | 不足 | 1）容易多愁善感，容易悲观，家人也劝不住；2）渴望和另一半有更多交流，但是无法真实地表达自己的需求，可能用责备、抱怨等来引起对方注意，需要对方来猜。3）情绪波动比较快，反复无常。4）做的决定也容易快速变化，别人不能当真，当真就容易起冲突。5）愿意付出，但也渴望对方的回报，如果对方没有回应，自己会有很多抱怨 |

#### 外圈（外在表现）

| 颜色 | 状态 | 解读原文 |
|-----|------|---------|
| **黑色** | 太过 | 对世界不信任，有恐惧，一般会有点社恐 |
| **深蓝** | 正常/太过 | 别人认为TA很专业，对事情看法有高认知 |
| **中蓝** | 正常 | 最近财运不错，做的事情能得到外界的认可；近期与外界接触的信息比较多，对外界的机会有敏锐的感知力；待人温柔，别人与TA相处如沐春风，能受到滋养，人缘比较好 |
| **浅蓝** | 不足 | 希望改变外界，渴望外界的人事物成为自己想要的样子，但一般都会失望，容易产生怨气。一直在寻找合适的机会进阶，但行动上也会有所犹豫。做事比较拖延，湿寒气重 |

## 特殊颜色解读

### 紫色

**五行归属**: 暧昧色（可定为火或木）

| 状态 | 解读原文 |
|-----|---------|
| **基本含义** | 神秘、浪漫、自尊心强、缺乏动力和热情、渴望被关注、紫气东来、高贵、高维下载链接、与第七脉轮相关、直觉力、贵气、魅力、信仰、艺术感、成熟、稳重 |
| **太过** | 最近直觉不错，可能有女巫的能量（直觉灵敏，做梦很准），但也会挑剔、高冷、封闭、压抑、紧张、严肃、心事重重、忧郁、偏向消极、有点不切实际，不接地气。紫色画的特别深重，笔触很重，面积比例大，颜色很暗或很浓的，基本上都有些封闭，喜欢独处，不喜欢与人过多接触。嘴上不说，但心里会挑剔别人，看不上别人 |
| **不足** | 喜欢自己默默努力，喜欢待在自己的空间；爱幻想；灵性有所发展，但不稳定；近期心情躁动，可能有些迷茫；信仰或信念力量不够，容易摇摆不定 |
| **正常** | 紫气东来，高贵、高维下载链接、与第七脉轮相关、直觉力，贵气，魅力、信仰、艺术感、神秘、成熟、稳重；也有高冷，热情不足，渴望被关注，自尊心特别强，动力不够等问题 |

### 橙色

**五行归属**: 暧昧色（介于火和土之间，归为火属性，属于弱火）

| 状态 | 解读原文 |
|-----|---------|
| **基本含义** | 正橙色：有活力，有自信，性格开朗，积极向上，内心欢喜愉悦，对福报的承载，对贵人和财富的吸引；淡橙色：渴望爱、渴望认可和温暖，缺乏自给自足的动力 |
| **太过** | 有些自负，听不进去别人好的意见，会固执己见，容易钻牛角尖，对别人有控制欲。也代表压抑焦虑，对这个世界有封闭，没有敞开心扉 |
| **不足** | 不自信，有点社恐，只想自己待着，脾胃不好，精力不足，兴趣寥寥，情绪低落，有点懒散，对这个世界缺少一份好奇心和好感度，渴望爱和温暖，渴望更多认可 |
| **正常** | 介于火和土之间，正面意义代表有活力，有自信，性格开朗，积极向上，内心欢喜愉悦，正橙色也代表对福报的承载，对贵人和财富的吸引 |

### 粉红色

**五行归属**: 火属性，弱火

**解读原文**:
> 恋爱和美好的颜色，有撒娇的味道，对爱有很多幻想和渴望，像小女人一样渴望被呵护，对对方有依赖，希望你懂我，希望你保护我

**备注**: 通常弱火属性的颜色如粉红、玫红、橘红，都是能够付出爱和温暖，但也会向外求取爱和温暖。生活中别人给你的爱是不稳定的，或者TA给你的爱未必刚好满足你、刚好是你想要的，所以这类宝宝外求的过程中容易受情伤

### 玫红色

**五行归属**: 火属性，弱火

**解读原文**:
> 代表喜欢美好，也想要分享更多美好，但具体有没行动还不知道，与粉色相比，玫红色显得更稳重成熟些，但内在能量不变，也是渴望爱和呵护

## 通用解读（手册原文）vs 主题特化解读的关系

### 层级关系说明

```
通用解读（基础层）
    ↓ 特化
主题解读（应用层）
    - 父亲关系
    - 母亲关系
    - 财富事业
    - 身体健康
    - 亲密关系
    - 亲子关系
    - 个人成长
```

### 示例对比

**通用解读（本文件）**：
> 内圈深绿：一般内在有伤痛或者忧郁，无法释放...容易变得固执...

**父亲关系主题特化**：
> 童年时期自我意识强烈，可能过早独立或与父亲有权力抗争...

可以看出，主题解读是通用解读在特定主题下的具体化表达。
