### 1.3 核心观点

**观点1：不确定性intolerance（IU）是忧虑维持的核心因素**
对不确定事件的过度恐惧（认为不确定=危险），导致通过持续担忧来"预防"可能的负面结果。IU与创伤后的控制需求可能相关联——创伤后IU可能是控制需求的体现。

**观点2：压力是认知评价的产物，而非单纯外部刺激**
CBT压力模型核心："压力源→感知评价→压力反应"。同一压力源因个人评价不同产生不同压力反应。与赫尔曼的互补：赫尔曼描述"创伤如何改变评价系统"，CBT描述"评价如何影响压力反应"。

**观点3：认知重构与行为实验是改变核心信念的主要技术**
认知重构（Cognitive Restructuring）通过质疑非理性信念改变情绪；行为实验（Behavioral Experiments）通过有计划行动测试信念，比纯粹认知重构更直接有效。适合"我知道但感受不到"的僵化信念。

### 1.7 使用边界

- **不替代诊断**：CBT自助书籍不应用于心理诊断
- **不替代专业治疗**：严重焦虑障碍、抑郁等需专业治疗师
- **自助手册 ≠ 治疗**：书系提供自助方法，但不替代专业一对一治疗
- **谨慎用于创伤核心议题**：创伤核心信念需要专业创伤治疗，CBT自助书籍仅作为辅助
- **文化适用性注意**：部分CBT技术（如暴露练习）在东方文化背景下需适度调整

### 2.3 核心观点

**观点1：体验循环（Experiential Cycle）是心理问题的核心动力学模型**
感知→识别→赋能→行动→充分接触→吸收→消退→撤回→感知……当循环在某一阶段被卡住时，形成"未完成事件"。这是格式塔理解心理问题的核心框架，与赫尔曼创伤记忆无法整合有联系。

**观点2：觉察（awareness）是格式塔的核心治疗机制**
觉察不是认知上的理解，而是身体-情绪-认知的整体感知。格式塔的觉察包含三维：对自己、对他人、对情境。把潜意识意识化，帮助看到未觉察的模式和选择。

**观点3：接触与边界是人际关系的核心**
健康的接触需要清晰的边界。边界过弱→融合/过度依赖；边界过强→退缩/过度孤立。边界问题是关系议题中的具体表现形式。

### 2.7 使用边界

- **不替代专业训练**：悬搁需要练习，不是简单"不判断"
- **不替代创伤核心治疗**：觉察适合在安全环境中使用，严重创伤需要先建立安全感
- **"此时此刻"不否定过去**：格式塔不否定过去的重要性，只是强调在当下看待过去
- **不混淆"觉察"与"治愈"**：觉察是入口不是终点，不能认为"觉察就能治愈"
- **与赫尔曼框架互补不替代**：格式塔提供关系和觉察维度，赫尔曼提供复原框架，两者互补

## 3. 来源使用规则

### 3.1 不可混用的组合

| 组合 | 原因 |
|------|------|
| 格式塔"悬搁" + CBT"认知重构" | 两者方向相反：悬搁是允许判断存在，重构是主动挑战判断 |
| 格式塔觉察 + 赫尔曼"见证" | 两者高度一致但格式塔觉察更宽泛，不可混用同一操作概念 |
| CBT自动思维 + ACT认知解离 | ACT解离是"与想法保持距离"，不改变内容；CBT重构是改变内容 |
