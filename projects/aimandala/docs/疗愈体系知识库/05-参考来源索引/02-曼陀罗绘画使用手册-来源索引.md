## 1. 来源定位

`02-曼陀罗绘画使用手册原文.md` 是一份面向曼陀罗绘画学习者的使用手册，内容覆盖新手认知、绘画前准备、三大核心画法、四种涂色方法，以及十类专项绘画练习。

这份材料和 `01-曼陀罗解读手册原文.md` 的侧重点不同：

- `01-曼陀罗解读手册原文.md` 偏向画面识别、作品解读、三圈结构、五行生克和解读表达。
- `02-曼陀罗绘画使用手册原文.md` 偏向绘画前引导、带练步骤、练习主题、涂色动作和课程练习设计。

## 2. 当前用途

本来源当前优先服务 `疗愈课程体系` 的首门课：

- 课程名称：`曼陀罗自我疗愈入门`
- 课程项目入口：`projects/healing-courses/PROJECT.md`
- 首门课规格：`projects/healing-courses/specs/2026-05-22-曼陀罗自我疗愈入门课程-SPEC.md`

可吸收进课程的方向包括：

- 第一课对“曼陀罗绘画是什么”和“曼陀罗绘画有哪些作用”的通俗解释。
- 绘画前的环境准备、心理准备、工具准备和主题确认。
- 三大核心画法：清理画法、疗愈画法、显化画法。
- 四种涂色动作：快速扫画法、打圈画法、单色慢画法、彩色慢画法。
- 十类专项练习中的入门级练习素材，例如定位、问问题、安定身心、改善关系、父母和解、三圈绘画等。

## 3. 使用边界

使用这份材料时，需要保留以下边界：

- 它可以作为课程讲义、带练脚本、练习单和创作者方法论的参考，不直接作为诊断、治疗或保证疗效的依据。
- 原文中涉及身体、细胞记忆、五脏六腑、频率、显化、金钱能量等表达时，应在课程中改写为自我觉察、情绪安顿、意图澄清或练习体验，不写成医学结论或确定性承诺。
- 面向新手课程时，优先选择低风险、可暂停、可复盘的练习；涉及强烈情绪、创伤、深层关系议题或大量连续清理时，需要增加安全提示。
- 课程中如使用“显化”“向宇宙下订单”等表达，应解释为愿望澄清、意图设定和行动提醒，不承诺外部结果必然发生。
- 涉及宗教传统的内容只作为文化和艺术背景，不作为宗教传播。

## 4. 后续拆解方向

后续可按课程需要拆解为：

- 入门讲义条目：曼陀罗绘画是什么、为什么适合自我疗愈。
- 课前准备条目：空间、材料、静心、主题和感恩记录。
- 基础画法条目：清理、疗愈、显化。
- 涂色动作条目：扫画、打圈、单色慢画、彩色慢画。
- 练习单条目：问问题、安定身心、关系练习、父母和解、三圈绘画。
- 安全边界条目：何时暂停、何时寻求专业支持、如何避免过度解读。
