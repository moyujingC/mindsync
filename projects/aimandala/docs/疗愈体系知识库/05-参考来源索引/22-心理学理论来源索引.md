### 1.2 核心概念

**序位（Hierarchy）**：爱与关系有其自然秩序。在家庭系统中，序位低者不能帮助序位高者（孩子不能"拯救"父母）。

**归属（Belonging）**：每个家庭成员都有归属的权利。被排除的成员会通过纠缠的方式在系统中制造影响。

**施与受平衡（Give and Take Balance）**：健康的关系需要施与受相对平衡。过度付出或过度索取都会破坏关系。

**纠缠（Entanglement）**：当一个系统成员被排除或被遗忘，其他人会在无意识中承担这个被排除者的命运（疾病、成功障碍、关系困难）。

## 2. 创伤与复原

### 2.1 来源定位

| 字段 | 内容 |
|------|------|
| source_id | trauma_recovery |
| source_title | 创伤与复原（Trauma and Recovery） |
| source_author | 朱迪思·L. 赫尔曼（Judith Lewis Herman） |
| source_location | `projects/research-center/kb/sources/healing/创伤与复原/` |
| atoms_location | `projects/research-center/kb/atoms/healing/创伤与复原-*.md` |
| source_type | 学术著作 / 心理学教科书 |
| review_status | draft |
| atoms_count | 18条（已提取） |

### 2.2 核心概念

**创伤三症状群**：
- **过度警觉（Hyperarousal）**：持续预期危险，难以放松
- **记忆侵扰（Intrusion）**：创伤记忆萦绕不去（噩梦、闪回、情绪触发）
- **禁闭畏缩（Constriction）**：麻木、解离、放弃反应

**复原三阶段模型**：
1. 安全阶段（Establishing Safety）
2. 回忆与哀悼（Retrospective Remembrance）
3. 重新连接（Reconnection）

**见证（Witnessing）**：在安全的治疗关系中，将创伤经历说出来并被他人见证，是复原的核心机制。

**复合性 CPTSD**：长期、反复的创伤（特别是早期养育创伤）可导致 CPTSD，不同于 PTSD 的单次创伤。

### 2.5 使用边界

- **不替代创伤治疗**：曼陀罗疗愈师不执行创伤治疗，但可以识别创伤信号并建议专业支持
- **创伤知情原则**：在解读和疗愈方案设计中，遵守创伤知情原则
- **赫尔曼 ≠ 海灵格**：赫尔曼的创伤框架与海灵格的家庭系统排列不能混用
- **不诊断 CPTSD**：CPTSD 诊断需要专业评估，曼陀罗解读中不出现诊断性语言
- **替代性受创风险**：疗愈师自身可能因持续接触案主的创伤材料而受影响，需有自我保护机制

## 3. ACT（接纳承诺疗法）

### 3.1 来源定位

| review_status | draft |
| atoms_count | 13条（已提取） |

### 3.2 核心概念

**心理僵化（Psychological Rigidity）**：痛苦不是来自情绪本身，而是来自心理僵化——无法在不同的情境中灵活调整。

**认知解离（Cognitive Defusion）**：与自己的想法拉开距离，看见"我有一个想法"而不是"我就是这个想法"。

**接纳（Acceptance）**：接纳不是顺从，也不是放弃改变，而是愿意允许情绪存在而不被它控制。

**当下觉察（Present Moment）**：从关系的"自动驾驶模式"中醒来，清醒地觉察当下。

**价值澄清（Values Clarification）**：区分短期目标和长期价值，价值是你真正想要成为的人的方向。

### 3.5 使用边界

- ACT 练习可作为疗愈方案的组成部分，具有科学实证支持
- 不替代严重心理问题的专业治疗（严重抑郁、焦虑障碍等需专业支持）
- ACT 中的"接受情绪"不等于"压抑情绪"——ACT 的接受是有觉察的容纳，不是被动屈服
- 疗愈师使用 ACT 语言时需经过基础训练，不能仅凭字面意思使用

### 4.2 核心概念

**转念作业（The Work）**：通过四个问题和一个反转，将引发痛苦的想法转变成可检验的、更灵活的想法。

**四个问题**：
1. 这是真的吗？
2. 我确定这是真的吗？
3. 当我相信这个想法时，我有什么反应？
4. 没有这个想法，我会怎样？

**反转**：将"他/她/它让我……"反转成"我让我……"

- 不适合在情绪急性发作或危机状态时使用
- 不替代专业心理治疗
- 疗愈师使用转念语言时需经过基础训练

## 5. 心理创伤疗愈（范德考克）

### 5.1 来源定位

| 字段 | 内容 |
|------|------|
| source_id | trauma_body |
| source_title | 心理创伤疗愈（The Body Keeps the Score） |
| source_author | 范德考克（Bessel van der Kolk） |
| source_location | `projects/research-center/kb/sources/healing/心理创伤疗愈/` |
| atoms_location | `projects/research-center/kb/atoms/healing/心理创伤疗愈-*.md` |
| wiki_location | `projects/research-center/kb/wiki/healing/心理创伤疗愈.md` |
| source_type | 学术著作 / 创伤治疗教科书 |
| review_status | draft |
| atoms_count | 13条（已整合入wiki） |

### 5.2 核心概念

**身体保存创伤**：创伤被编码在身体的感觉运动系统中——通过身体体验、感官印象和情绪记忆保存，而非仅通过语言和叙事保存。

**三层脑与创伤**：脑干（生存本能）持续激活 + 边缘系统（情绪脑）记忆增强 + 前额叶（调节功能）被抑制 = 创伤患者"知道但做不到"。

**战斗/逃跑/崩溃**：三种反应模式，迷走神经起关键作用。创伤后三种反应常被卡在"持续激活"状态。

**多疗法整合**：单一疗法不足以处理复杂创伤；需整合身体导向（瑜伽、神经反馈）和言语处理（EMDR、IFS）。

### 5.3 与赫尔曼框架的互补

| 维度 | 赫尔曼《创伤与复原》 | 范德考克《心理创伤疗愈》 |
|------|-------------------|----------------------|
| 核心命题 | 创伤是社会/人际现象 | 创伤编码在身体中 |
| 核心机制 | 见证（社会维度） | 身体保存创伤（神经科学） |
| 主要方法 | 言语/叙事入口 | 身体导向入口 + 言语处理 |
| 复原模型 | 三阶段（安全→回忆→重建联结） | 三层脑模型 + 多种反应模式 |

两者互补，不替代。

### 5.4 与疗愈体系的关联

| 浮现机制 | 关联方式 |
|----------|----------|
| 身体承载与行动力（06） | 身体警报系统失调是行动力不足的神经科学基础 |
| 安全感与匮乏感（02） | 安全关系通过神经调节帮助重建安全感 |
| 情绪能量与消耗（05） | 述情障碍是情绪无法整合的表达障碍 |
| 潜意识伤痛（议题本体） | 发展性创伤是潜意识伤痛的身体编码 |

### 5.5 使用边界

- 补充赫尔曼框架的神经科学维度，不替代赫尔曼框架
- 身体导向疗法需专业指导，不能替代专业治疗
- 述情障碍标签不能用于给创伤患者贴标签
- **范德考克框架与赫尔曼框架不可混用核心术语**（如将EMDR的"解离"与赫尔曼的"解离"混用）

## 6. 来源使用规则

### 6.1 不可混用的组合

| 组合 | 原因 |
|------|------|
| 海灵格（家庭系统排列）+ 赫尔曼（创伤疗愈） | 两者框架不同：系统排列关注代际动力，创伤疗愈关注个人复原，混用会造成理论混乱 |
| 范德考克（身体保存创伤）+ 赫尔曼（解离） | 两者机制不同：范德考克的解离是身体编码，赫尔曼的解离是记忆-情感断裂，不能混用 |
| ACT 的"认知解离" + 赫尔曼的"解离" | ACT 的认知解离是健康的认知灵活性，赫尔曼的解离是创伤后的防御反应，不能混用 |
| 凯蒂的"接纳" + 赫尔曼的"接纳" | 两者含义不同：凯蒂的接纳是对现实臣服，赫尔曼的接纳是在安全阶段后的意愿性接纳 |

### 6.2 来源引用规范

在疗愈体系知识库中引用上述来源时：
- 必须标注来源名称、作者，不可匿名引用
- 必须明确引用的是概念/机制/表达，还是疗愈方向
- 不得将单一作者体系内的表达泛化为完整共识
- 不得将来源理论直接写成曼陀罗解读的"规则"

### 6.3 来源升级路径

- `draft` → `reviewed`：需要对照原始书籍或权威材料审核 atoms 内容
- `reviewed` → `used_in_therapy`：需要通过疗愈师经验审核（临床验证）
- `used_in_therapy` → `validated_by_multiple_sources`：需要第二个独立来源的支持
