本文定义母亲关系主题解读报告的段落模板。

报告语言风格统一由 [07-报告语言风格指南.md](07-报告语言风格指南.md) 控制。本文只定义母亲关系报告结构和段落职责。

## 1. 使用前提

生成母亲关系报告前，先满足这三个条件：

1. `user_theme` 已确认是 `母亲关系`（或画面证据落到安全感/接受/分离/滋养主题）。
2. 已完成基础画面观察。
3. 已选出至少 1 个母亲关系条款。

## 2. 报告主线

母亲关系报告只维护一条主线：

`画面信号 -> 接受与安全感状态 -> 接受母亲/分离机制 -> 浮现议题回译 -> 现实表现 -> 低风险建议`

其中：

- 主线围绕母亲关系展开：接受、安全感、滋养、分离和和解。
- 浮现议题可以出现，但只能作为母亲关系背景。
- 不把亲密关系、财富、健康单独写成另一份报告。

## 3. 固定段落

母亲关系报告按以下顺序输出：

1. 整体直觉
2. 母亲关系主线确认
3. 三圈母亲关系读法
4. 机制拆解
5. 浮现议题回译
6. 现实表现
7. 生机
8. 调整建议

## 4. 段落路由

| 段落 | 主要内容 | 典型输入 |
|------|----------|----------|
| 整体直觉 | 第一眼印象和整体气质。 | 画面总感、内圈稳定度、颜色温暖或暗淡。 |
| 母亲关系主线确认 | 说明本次报告围绕的关系状态。 | 接受母亲、安全感、与母亲联结、分离与和解。 |
| 三圈母亲关系读法 | 分别看内圈、中圈、外圈。 | 接受与联结、滋养与分离、现实中的关系行动。 |
| 机制拆解 | 解释关系为何这样卡住。 | `mother.accepting_mother`、`mother.disappointment`、`mother.early_separation`。 |
| 浮现议题回译 | 把亲密/财富/情绪翻回母亲关系。 | 亲密→被接纳感；财富→来自母亲的财富；情绪→与母亲的情感共振。 |
| 现实表现 | 写用户现实里可能对得上的样子。 | 在关系中是否允许自己被爱、是否过度依赖或回避。 |
| 生机 | 保留可用力量和出口。 | 接受母亲、足够感、在分离中保持爱的连接。 |
| 调整建议 | 给低风险动作。 | 接受练习、足够感练习、分离练习。 |

## 5. 段落职责

### 5.1 整体直觉

先写第一眼看到什么，再写这张画整体更像在讲什么。

要求：先被看见，不抢结论，不直接下关系判断。

### 5.2 母亲关系主线确认

明确这份报告围绕什么关系状态展开。

可写方向：

- 母亲代表生命最初的安全感和被接纳的体验。
- 当前更像是在看与生命最初接纳者的关系，而不是单看母亲本身。

### 5.3 三圈母亲关系读法

三圈写法固定如下：

- 内圈：更靠近自我、被接纳感、安全感、与生命最初的关系。
- 中圈：滋养、情绪共振、被支持的能力。
- 外圈：现实行动、分离与独立、对外表达。

母亲关系报告优先级：

1. 内圈看接受母亲和内在安全感。
2. 中圈看滋养和情绪共振。
3. 外圈看分离与现实行动。

### 5.4 机制拆解

这里解释为什么会形成当前关系状态。

优先使用的机制（来自 [11-母亲关系议题手册.md](../20-疗愈体系/10-议题层/30-主议题报告包/40-母亲关系/11-母亲关系议题手册.md)）：

| 条款ID | 条款名称 | 核心描述 |
|--------|----------|----------|
| `mother.accepting_mother` | 接受母亲 | 我们如何接受我们的母亲，就如何接受我们的生命；谁接受了母亲，谁就光芒四射。 |
| `mother.rejection` | 拒绝母亲 | 我们指责母亲什么，我们就在指责我们的生命什么。 |
| `mother.disappointment` | 对母亲失望 | 对母亲赠予的爱感到失望，期待超过实际可能得到的。 |
| `mother.connection` | 与母亲的联结 | 在腹中时与母亲的联结是最深远的联结；接受母亲是获得财富和成功的钥匙。 |
| `mother.separation_pain` | 分离的痛苦 | 早年与母亲分离的经历可能导致内在决定"我放弃她"。 |
| `mother.adequate` | 母亲给予的足够了 | "够了，足够了。其他所有的一切我会在别处寻找并获得。"然后，爱可以继续。 |
| `mother.healthy_separation` | 与母亲健康分离 | 作为成年人与母亲分离但保持连接；不再依赖母亲，但保持爱的联结。 |
| `mother.avoidance` | 回避母亲 | 徒劳地等待母亲后，不再让她碰触，在她的爱面前封闭自己。 |

**画面信号对应**（来自议题手册）：

| 条款ID | 画面信号 |
|--------|----------|
| `mother.accepting_mother` | 内圈清晰稳定、颜色温暖 |
| `mother.rejection` | 内圈破损、颜色暗淡 |
| `mother.disappointment` | 内圈纠结、颜色混杂 |
| `mother.connection` | 内圈深远、能量丰富 |
| `mother.separation_pain` | 内圈有断裂、颜色不连贯 |
| `mother.adequate` | 颜色平衡、外圈开放 |
| `mother.healthy_separation` | 外圈清晰、内圈稳定 |
| `mother.avoidance` | 外圈厚重闭合、内圈弱 |

### 5.5 浮现议题回译

当报告里出现亲密关系、财富、情绪等线索时，先回译成母亲关系机制，再简短提及背景。

| 浮现议题 | 母亲关系翻译 | 报告深度 |
|----------|-------------|----------|
| 亲密关系 | 在亲密关系中是否允许自己被爱和接受 | hint/brief |
| 自我价值与配得感 | 在生命最初是否接受了足够的爱与接纳 | brief |
| 安全感与匮乏感 | 在与生命的关系中是否感到安全 | brief |
| 财富关系 | 来自母亲的财富与成功 | brief |
| 情绪 | 与母亲的情感共振和情绪模式 | supporting |

### 5.6 现实表现

只写和用户现实可能对得上的表现，不写关系预测。

可写：

- 在关系中允许自己被爱和接受，或难以接受。
- 对母亲有未被满足的期待，或能接受母亲如所是。
- 在早年可能有与母亲分离的经历。
- 在关系中保持距离或难以敞开。

不可写：

- 你与母亲关系一定有问题。
- 你应该怎么和母亲相处。
- 你的关系问题是母亲造成的。
- 你应该立刻做某个关系决定。

### 5.7 生机

每份母亲关系报告必须保留生机，不只写卡点。

生机可以来自：

- 能接受母亲如她所是，从她那里获得生命的力量。
- "够了，足够了"——母亲给予的已经足够。
- 能在分离中保持爱的连接。
- 接受母亲后光芒四射的潜力。

### 5.8 调整建议

建议只给低风险动作，优先顺序：认知调整 → 情绪调频 → 具体练习。

**调整建议与条款对照**：

| 条款 | 认知调整 | 情绪调频 | 具体练习 |
|------|----------|----------|----------|
| 接受母亲 | "我接受母亲如她所是，这是我获得生命力量的开始" | 温暖色冥想 | 每天对母亲说一句话感恩 |
| 对母亲失望 | "母亲给予的足够了，其他的我会在别处寻找" | 蓝色画放松期待 | 说"够了，足够了"练习 |
| 分离的痛苦 | "早年分离是我的经历，但它不决定我的现在" | 黄色画安全感 | 站桩固脾胃，提升内在安全感 |
| 回避母亲 | "我不需要改变母亲，我只是接受母亲如她所是" | 绿色画开放 | 每天做一件独立的事 |
| 足够感 | "母亲给予的足够了，我也给予自己足够的接纳" | 红色画补充热情 | 每天嘉许自己一次 |

**安全边界提醒**：
- 不判断现实母子关系的好坏
- 不做家庭因果归因
- 不把画面结论写成心理诊断
- 不替用户做关系决策
- 不把家庭系统语言直接写成事实因果
- 不输出医疗建议

**冥想参考**（来源《谁在我家》）：
> 亲爱的妈妈！我们现在要对母亲说什么？啊，我这么晚才真正认清你。

（可写入生机或调整建议，引用但不作为结论输出）

## 6. Lite / Pro 使用差异

- Lite：先命中主线，保留少量关键条款，输出短而清楚的关系解释。
- Pro：在 Lite 基础上展开逐圈机制、回译线索和根因链。MVP 阶段暂不上线。

## 7. 质量检查

生成完成后检查：

- [ ] 是否始终回到母亲关系主线（接受/安全感/滋养/分离）
- [ ] 是否把浮现议题回译回母亲关系机制
- [ ] 条款（mother.*）是否正确嵌入到机制拆解和调整建议中
- [ ] 是否避免关系预测和决策建议
- [ ] 是否保留生机
- [ ] 是否遵守安全边界
