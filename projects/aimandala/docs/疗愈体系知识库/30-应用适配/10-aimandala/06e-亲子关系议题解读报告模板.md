本文定义亲子关系主题解读报告的段落模板。

报告语言风格统一由 [07-报告语言风格指南.md](07-报告语言风格指南.md) 控制。本文只定义亲子关系报告结构和段落职责。

## 1. 使用前提

生成亲子关系报告前，先满足这三个条件：

1. `user_theme` 已确认是 `亲子关系`（或画面证据落到施与受序位/教养模式/代际传递主题）。
2. 已完成基础画面观察。
3. 已选出至少 1 个亲子关系条款。

## 2. 报告主线

亲子关系报告只维护一条主线：

`画面信号 -> 施与受序位状态 -> 代际传递/接受父母机制 -> 浮现议题回译 -> 现实表现 -> 低风险建议`

其中：

- 主线围绕亲子关系展开：施与受序位、接受父母、代际传递、恰当养育。
- 浮现议题可以出现，但只能作为亲子关系背景。
- 不把亲密关系、财富、健康单独写成另一份报告。

## 3. 固定段落

亲子关系报告按以下顺序输出：

1. 整体直觉
2. 亲子关系主线确认
3. 三圈亲子关系读法
4. 机制拆解
5. 浮现议题回译
6. 现实表现
7. 生机
8. 调整建议

## 4. 段落路由

| 段落 | 主要内容 | 典型输入 |
|------|----------|----------|
| 整体直觉 | 第一眼印象和整体气质。 | 画面总感、施与受平衡感、代际动力。 |
| 亲子关系主线确认 | 说明本次报告围绕的关系状态。 | 施与受序位、接受父母、代际传递。 |
| 三圈亲子关系读法 | 分别看内圈、中圈、外圈。 | 接受父母、内在序位、对外施与受。 |
| 机制拆解 | 解释关系为何这样卡住。 | `parenting.giving_receiving_sequence`、`parenting.rejection`、`parenting.presumption`。 |
| 浮现议题回译 | 把亲密/财富/情绪翻回亲子关系。 | 亲密→代际模式；财富→代际资源传递；情绪→代际情绪共振。 |
| 现实表现 | 写用户现实里可能对得上的样子。 | 在关系中是否承担了不该承担的、是否在修复父母。 |
| 生机 | 保留可用力量和出口。 | 接受父母如所是、回到自己位置、谦卑。 |
| 调整建议 | 给低风险动作。 | 接受练习、位置觉察、代际模式觉察。 |

## 5. 段落职责

### 5.1 整体直觉

先写第一眼看到什么，再写这张画整体更像在讲什么。

要求：先被看见，不抢结论，不直接下关系判断。

### 5.2 亲子关系主线确认

明确这份报告围绕什么关系状态展开。

可写方向：

- 亲子关系是代际之间的施与受序位——父母施与，孩子接受。
- 当前更像是在看施与受序位和代际传递模式。

### 5.3 三圈亲子关系读法

三圈写法固定如下：

- 内圈：更靠近自我、与父母的关系位置、内在序位。
- 中圈：代际之间的连接和传递、情绪共振。
- 外圈：现实中的施与受、与下一代的互动。

亲子关系报告优先级：

1. 内圈看接受父母和内在序位。
2. 外圈看代际传递和现实中的施与受。
3. 中圈看代际情绪和系统动力。

### 5.4 机制拆解

这里解释为什么会形成当前关系状态。

优先使用的机制（来自 [11-亲子关系议题手册.md](../20-疗愈体系/10-议题层/30-主议题报告包/50-亲子关系/11-亲子关系议题手册.md)）：

| 条款ID | 条款名称 | 核心描述 |
|--------|----------|----------|
| `parenting.giving_receiving_sequence` | 施与受序位 | 父母施与，孩子接受；父母优先于孩子，孩子必须一直是小的。 |
| `parenting.reversal` | 序位颠倒 | 孩子想给予父母他们没有从父母那里接受的，或父母想从孩子那里接受。 |
| `parenting.accepting_parents` | 全盘接受父母 | 孩子必须全盘接受父母如他们所是，没有任何其他愿望。拒绝父母的人，也在拒绝自己。 |
| `parenting.rejection` | 拒绝父母 | 内在拒绝或谴责父母，对生命的丰盛关闭心门。 |
| `parenting.reverence_for_life` | 对生命的敬畏 | 孩子通过父母看向久远的过去，看向生命最初来临的地方；所有父母都是对的人。 |
| `parenting.presumption` | 僭越 | 孩子想给予父母他们没有从父母那里接受的，或孩子想"修复"父母。 |
| `parenting.loyalty_pattern` | 忠诚模式 | 孩子对父母或家族的忠诚可能导致无意识的重复模式。 |
| `parenting.generational_transmission` | 代际传递 | 家族中没有被看到的人可能通过孩子来表达。 |
| `parenting.nurturing` | 恰当养育 | 父母给予孩子生命和爱，孩子接受父母如他们所是。 |

**画面信号对应**（来自议题手册）：

| 条款ID | 画面信号 |
|--------|----------|
| `parenting.giving_receiving_sequence` | 内圈小但清晰、外圈稳定 |
| `parenting.reversal` | 内圈大、外圈小或破损 |
| `parenting.accepting_parents` | 内圈清晰、颜色稳定 |
| `parenting.rejection` | 内圈破损、颜色暗淡 |
| `parenting.reverence_for_life` | 内圈深远、颜色柔和 |
| `parenting.presumption` | 内圈大但外圈弱、能量分散 |
| `parenting.loyalty_pattern` | 外圈有延伸、颜色有家族特征 |
| `parenting.generational_transmission` | 内圈有深色、颜色暗淡 |
| `parenting.nurturing` | 三圈平衡、颜色温暖 |

### 5.5 浮现议题回译

当报告里出现亲密关系、财富、情绪等线索时，先回译成亲子关系机制，再简短提及背景。

| 浮现议题 | 亲子关系翻译 | 报告深度 |
|----------|-------------|----------|
| 亲密关系 | 在代际中的亲密关系模式传递 | hint/brief |
| 自我价值与配得感 | 在接受父母中是否接受了自己的生命 | brief |
| 安全感与匮乏感 | 在代际中是否感到安全 | brief |
| 财富关系 | 代际中的资源传递模式 | supporting |

### 5.6 现实表现

只写和用户现实可能对得上的表现，不写关系预测。

可写：

- 在关系中可能承担了不该承担的，想"修复"父母。
- 对父母有期待，希望他们不同。
- 在亲子关系中有施与受序位的颠倒。
- 有一些无意识的忠诚或代际重复模式。

不可写：

- 你的亲子关系一定有问题。
- 你应该怎么和孩子相处。
- 你的问题是父母造成的。
- 你应该立刻做某个育儿决策。

### 5.7 生机

每份亲子关系报告必须保留生机，不只写卡点。

生机可以来自：

- 能接受父母如他们所是，并从中获得生命的力量。
- 愿意回到自己在关系中的位置——孩子就是小的。
- 愿意带着谦卑接受生命。
- 有些力量来自更大的系统，觉察本身就是开始。

### 5.8 调整建议

建议只给低风险动作，优先顺序：认知调整 → 情绪调频 → 具体练习。

**调整建议与条款对照**：

| 条款 | 认知调整 | 情绪调频 | 具体练习 |
|------|----------|----------|----------|
| 接受父母 | "我接受父母如他们所是，这是我获得生命力量的方式" | 温暖色冥想 | 每天对父母说一句接受的话 |
| 序位颠倒 | "我是我，父母是父母，我有我自己的位置" | 黄色画清晰位置 | 做15分钟独立行动，练习回到自己的位置 |
| 僭越 | "父母的事父母自己承担，我只需要承担我自己的" | 蓝色画平静 | 站桩固脾胃，提升内在稳定性 |
| 代际觉察 | "有些模式来自更大的系统，觉察本身就是开始" | 绿色画开放 | 每天花5分钟觉察代际模式 |
| 恰当养育 | "给予孩子我能给予的，同时让孩子接受他如所是" | 红色画补充热情 | 每天与孩子有一个无条件的时刻 |

**安全边界提醒**：
- 不判断现实亲子关系的好坏
- 不做家庭因果归因
- 不把画面结论写成心理诊断
- 不替用户做育儿决策
- 不把家庭系统语言直接写成事实因果
- 不把孩子的行为问题直接归因于家族系统
- 不输出医疗建议

**冥想参考**（来源《谁在我家》）：
> 亲爱的母亲（父亲），我从你那里接过它，一切，全部，和与之相关的一切，以及全部的代价——你已经付出的，和我要付出的。

（可写入生机或调整建议，引用但不作为结论输出）

## 6. Lite / Pro 使用差异

- Lite：先命中主线，保留少量关键条款，输出短而清楚的关系解释。
- Pro：在 Lite 基础上展开逐圈机制、回译线索和根因链。MVP 阶段暂不上线。

## 7. 质量检查

生成完成后检查：

- [ ] 是否始终回到亲子关系主线（施与受序位/接受父母/代际传递）
- [ ] 是否把浮现议题回译回亲子关系机制
- [ ] 条款（parenting.*）是否正确嵌入到机制拆解和调整建议中
- [ ] 是否避免关系预测和决策建议
- [ ] 是否保留生机
- [ ] 是否遵守安全边界（不做因果归因、不把孩子问题归因于家族）
