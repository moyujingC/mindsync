## 协作规则

在本目录工作时：

- 新增或修改报告规范后，同步更新当前 README
- 报告模板按议题独立维护，新增议题时创建对应模板文件
- 语言风格指南为跨议题通用规则，修改前需在 P0 计划中评估影响面
- 报告生成最小规则是运行时调用的基准，任何修改需通过质量门检查
