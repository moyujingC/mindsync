# 片段解读示范总索引

## 用途

本目录保存原始手册中的局部解读示范，用于校准颜色、形状、五行相生相克、比例失衡等局部规则。

片段示范只说明某一类画面信号如何被解释，不能直接替代完整报告结构。进入正式知识条目前，需要人工确认画面事实、适用边界和议题翻译方式。

## 图片命名规则

- 默认每个示范一个主图占位：`assets/example-xxx-slug.jpg`。
- 如果一个示范段落对应多张图，可以追加：`assets/example-xxx-slug-01.jpg`、`assets/example-xxx-slug-02.jpg`。
- 文本文件固定放在 `examples/example-xxx-slug.md`。

## 审核原则

- 先确认图片中是否确实存在对应信号，再沉淀规则。
- 五行关系只分析圈内元素之间的生克，不把整个圈判定成单一五行。
- 财富、情感、健康、关系等议题需要后续做议题翻译，不能直接把原文混合议题当作产品输出。
- 原文中疑似 OCR 错字先保留，人工审核时再统一校订。
