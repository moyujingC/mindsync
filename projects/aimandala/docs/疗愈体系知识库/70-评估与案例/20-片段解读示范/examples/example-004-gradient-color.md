#### 新手解读6式：渐变色

渐变色直断绘画者正在转变、调整或者试探着做出改变。

渐变色在里圈或中圈说明绘画者内心想要改变一些事情，对一些决定还在犹豫，想要去做，但还没确定下来；渐变色在外圈说明绘画者已经对试探着做出一些调整了。
