# stage02+stage03 黄金样例集

> 状态：draft
> 用途：PromptPilot 调试、视觉识别黄金输出标注、后续 schema 设计参考

本目录保存 11 个完整解读案例的 `stage02+stage03` 合并视觉观察黄金样例。

当前口径：

- `stage02+stage03` 合并处理，不再把“整体观察”和“结构化视觉证据”硬拆成两个互相割裂的阶段。
- 输入假设为两张图：用户原画作 + 疗愈师三圈标记图。
- 三圈标记图只用于确认内圈、中圈、外圈边界；标记线颜色、线条粗细和覆盖痕迹不属于画作内容。
- 输出只做视觉观察，不做心理诊断、财富判断、关系判断、健康判断或完整报告正文。
- 黄金输出必须支持后续步骤：圈内五行识别、圈内元素关系、跨圈能量流动、议题翻译。

本目录不是当前 runtime schema 的直接替换。它用于先确认“理想视觉输出长什么样”，再反向收敛 `visual_units` 定义、prompt 和程序 schema。
