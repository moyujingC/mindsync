# 完整案例人工审核操作说明

> 版本：0.1.0

> owner：CEO / Knowledge Base

本文用于指导 11 个完整解读案例的人工审核。目标不是复写疗愈师原文，而是把“图片事实 -> 画面信号 -> 五行关系 -> 议题翻译 -> 可沉淀规则”拆清楚，供新版曼陀罗解读智能体后续学习和回归测试。

## 1. 审核顺序

1. 打开单案例文档，例如 `cases/case-001.md`。
2. 先看原画作，不看原文结论，记录可见事实。
3. 再看三圈设定标记图，确认内圈、中圈、外圈边界。
4. 阅读疗愈师原始解读文本，标出哪些判断能被图片事实支持。
5. 填写单案例末尾的“人工审核区”。
6. 将可复用内容同步登记到 [02-案例规则沉淀表.md](02-案例规则沉淀表.md)。

## 2. 单案例审核区填法

### 画面事实

只写肉眼能看见的内容，不写解释。

建议记录：

- 三圈边界：内圈、中圈、外圈各自大致范围。
- 颜色：每圈出现了哪些主色、辅色、深浅、明暗、脏净。
- 形状：圆、点、线、条状、三角、方形、波纹、不规则块等。
- 分布：集中、分散、断裂、包围、遮挡、穿透、重复、留白。
- 边界：闭合、破损、外溢、压迫、松散。

### 画面信号标注

把画面事实翻译成候选信号，但不要直接下最终结论。

建议格式：

```md
- 事实：中圈粉色块被白色线条分割。
- 信号：中圈情绪/关系能量有被切断、被标准压住的倾向。
- 置信度：高 / 中 / 低。
```

### 五行元素与圈内生克

只分析圈内元素之间的五行关系，不把一个圈整体判定为某个五行。

建议格式：

```md
- 内圈元素：蓝色水、白色金。
- 圈内关系：金生水。
- 关系依据：白色结构环绕或贴近蓝色区域。
- 解释边界：只能说明内圈价值感/标准感与滋养/情绪之间有关联，不能直接推出财富结果。
```

### 议题映射

记录原文涉及的议题，以及未来能否翻译到财富议题。

建议拆成：

- 原始主题：案例原本的用户主题。
- 主要议题：原文主要解读的议题。
- 浮现议题：关系、原生家庭、健康、身体、事业、行动力等。
- 财富可用部分：如果用于财富报告，应放在哪个报告段落。
- 财富不可直接使用部分：需要保留为旁支解释，或暂不进入财富报告。

### 可沉淀规则

只写能跨案例复用的规则，不写个案命运判断。

建议格式：

```md
- 规则候选：中圈火被金切断时，可提示情绪表达/关系热度被标准、委屈或边界感压住。
- 适用条件：中圈内同时出现火性颜色和金性线条/留白，并有明显分割。
- 不适用条件：只是少量白色装饰，未形成切断或包围。
- 对应议题：情感、家庭关系、财富能量承接。
```

### 不应泛化内容

记录不能直接写进规则库的内容。

常见类型：

- 疗愈师对个案身体健康的判断。
- 缺少图片证据的心理推断。
- 单个案例中特别依赖用户主题的判断。
- 过强的财富结果预测。
- 需要专业诊断资质的表述。

## 3. 人工审核原则

- 先看图，再看原文，避免被结论带着倒推。
- 图片事实优先于原文措辞。
- 五行只用于圈内元素关系，三圈联动不使用五行替代。
- 同一个画面信号可以翻译到多个议题，但要区分主议题和浮现议题。
- 财富报告中可以提到关系、情绪、身体和家庭议题，但必须解释它们如何影响财富能量、承载力、行动力或关系交换。
- 所有沉淀规则先进入候选，不直接进入正式报告模板。

## 4. 审核完成标准

单个案例至少完成：

- `画面事实` 有三圈分层记录。
- `画面信号标注` 至少 3 条。
- `五行元素与圈内生克` 至少覆盖原文重点提到的圈层。
- `议题映射` 明确原始主题和财富可用部分。
- `可沉淀规则` 至少 1 条，或明确写“暂无可沉淀规则”。
- `不应泛化内容` 明确列出高风险判断。

11 个案例全部完成后，再进入规则合并和知识库回写。
