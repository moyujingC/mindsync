## 1. Agent 集群定义

本知识库的 "Agent 集群" 是指支撑曼陀罗解读报告生成、追问回答和疗愈方案生成的完整知识与运行时系统。它不是单一 Agent，而是一组协同工作的知识模块、运行时包和执行规范。

### 1.1 集群组成

```
疗愈体系知识库 Agent 集群
├── 知识库层
│   ├── 00-知识库治理
│   ├── 05-参考来源索引
│   ├── 20-疗愈体系
│   │   ├── 10-议题层
│   │   ├── 20-流派层（曼陀罗）
│   │   └── 30-疗愈方案层
│   ├── 30-应用适配（aimandala）
│   ├── 60-运行时知识包
│   └── 70-评估与案例
│
├── 运行时层
│   ├── foundation_prompt_pack
│   ├── wealth_prompt_pack
│   ├── visual_draft
│   └── final_report
│
└── 执行链路
    ├── Vision Pass（两阶段方案A）
    ├── Reasoning Pass
    └── Quality Gate
```

## 4. 运行链路评估

### 4.1 方案 A：正式默认链路（Two-Pass E2E）

```
用户原画作 + 三圈标记图 + 用户输入
  ↓
1. Vision Pass + foundation prompt pack
   → 输出：可复用视觉基准 visual_draft
  ↓
2. Reasoning Pass + wealth prompt pack + output prompt pack
   → 输出：财富议题 Lite / Pro 报告
  ↓
3. Quality Gate
   → 输出：质量门报告（不进入用户报告）
```

**评估**：
| 组件 | 状态 | 评估 |
|------|------|------|
| Visual Draft 生成 | 已有方案 | ✅ 端到端直出，不做重结构化 |
| Prompt Pack 组装 | 已有方案 | ✅ foundation / wealth / output 三段分离 |
| Report 生成 | 已有方案 | ✅ 财富主题稳定 |
| Quality Gate | 已有方案 | ✅ 定义了 9 项检查规则 |
