本目录保存可跨流派复用的通用疗愈方案，不依赖曼陀罗画面信号，可独立使用。

适合进入本层的内容包括：

- 觉察问题。
- 书写练习。
- 身体练习。
- 呼吸与冥想。
- 日常行动建议。
- 周期性陪伴方案。

**与曼陀罗手册的关系**：曼陀罗流派特定的疗愈经验保留在 `20-流派层/10-曼陀罗/50-疗愈方案经验`，本目录保存可跨流派使用的通用方案。

## 协作规则

在本目录工作时：

- 通用方案独立维护，不绑定具体画面信号
- 新增练习时标注适用情境和禁忌（如创伤、运动限制）
- 练习按"最小可用"原则设计：一个练习解决一个问题
- 所有练习均标注安全边界，不替代专业心理治疗

## 适用议题

以下议题的疗愈方案已部分覆盖：

- 财富议题（配得感、安全感、行动力）
- 亲密关系（边界、交换、施与受）
- 父亲关系 / 母亲关系（代际传递）
- 情绪能量（识别、调节、转化）
- 内在小孩（连接、接纳）
- 潜意识伤痛（模式觉察、改写）
- 内在渴望（觉察、表达）
- 天赋优势（识别、发挥）
