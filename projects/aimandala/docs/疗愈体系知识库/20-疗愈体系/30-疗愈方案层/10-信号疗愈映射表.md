## 映射表结构

```
画面信号 → 五行失衡类型 → 背景线索 → 议题条款 → 疗愈建议
```

**使用规则**：
1. 画面信号是识别入口，用于在解读时快速定位
2. 五行失衡类型是流派层解释
3. 背景线索是报告中的表达层
4. 议题条款是主议题中的具体卡点
5. 疗愈建议是低风险的觉察/练习方向

## 疗愈建议说明

### 觉察类建议

| 建议 | 适用场景 | 风险边界 |
|------|----------|----------|
| 观察自己的金钱紧绷感是从哪里来的 | 安全感与匮乏感 | 不做深层童年创伤挖掘 |
| 区分创造价值与证明自己 | 自我价值与配得感 | 不否定用户努力 |
| 观察当钱进来时是放松还是紧绷的 | 安全感与匮乏感 | 不判断用户现实财务 |
| 觉察情绪消费背后的需求 | 情绪型漏财 | 不批评用户消费习惯 |

### 练习类建议

| 练习 | 适用场景 | 风险边界 |
|------|----------|----------|
| 嘉许自己，每做一件事就夸奖自己 | 自我价值与配得感 | 不要求立刻改变行为模式 |
| 每天给自己一个小"允许" | 安全感与匮乏感 | 不做财务决策建议 |
| 写感恩日记/幸福日记 | 自我价值与配得感 | 只做觉察，不做财务调整 |
| 黑色清理画：清理恐惧和不安全感 | 安全感与匮乏感 | 不做心理治疗 |
| 黄色画：提升承载力 | 承载力不足 | 不承诺具体财富结果 |
| 蓝色画：放松和稳定情绪 | 水火相冲 | 不替代情绪管理专业支持 |
| 红色画：补心力、热情、丰盛感 | 匮乏感 | 不承诺财富增加 |

### 边界提醒

所有疗愈建议必须遵守：
- 不做财务预测、投资建议、职业决策
- 不把画面符号写成确定因果
- 不替代心理治疗或专业咨询
- 高风险情境（债务危机、严重焦虑、创伤）提示寻求专业支持
