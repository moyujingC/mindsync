本文档按类型分类保存身体和冥想练习，供疗愈师建议案主或生成疗愈方案使用。

**使用原则**：
- 身体练习优先于纯思维练习
- 从简单、短时开始，逐步深入
- 明确告知禁忌人群（如身体有伤者、孕妇、创伤后应激者）
- 练习时保持安全空间，不被打扰
- 不是所有的练习都适合所有人，根据身体情况调整

**禁忌人群**：
- 严重身体疾病或伤痛（需遵循医嘱）
- 严重心理创伤未经处理（优先寻求专业支持）
- 孕早期（某些呼吸和身体练习可能不适合）
- 癫痫患者（某些冥想练习可能触发发作）

## 1. 身体连接类

### 1.1 身体扫描

**目的**：建立身体与意识的连接，提升身体感知  
**时长**：10-15 分钟  
**步骤**：
1. 躺下或坐直，保持舒适的姿势，闭上眼睛
2. 从脚趾开始，将注意力缓慢移动到身体的每个部位
3. 每个部位停留几次呼吸，感受该部位的感觉（温度、紧张、放松、刺痛……）
4. 不评判感受，只是觉察
5. 最后，将注意力带到整个身体作为一个整体，感受整体状态

**适用情境**：情绪失调、身体感知迟钝、过度思维  
**禁忌**：严重创伤被激活时暂停，回归当下

### 1.2 地面连接

**目的**：当感到不踏实、漂浮、焦虑时，建立与大地的连接  
**时长**：5-10 分钟  
**步骤**：
1. 赤脚站在地面（或坐在椅子上，双脚平放）
2. 感受双脚与地面的接触点
3. 缓慢地将注意力从脚底向上传导：脚踝、小腿、膝盖、大腿
4. 感受身体越来越"沉"入地面
5. 想象自己像一棵树，根系深深扎入大地

**适用情境**：焦虑、漂浮感、不踏实、决策前  
**禁忌**：地面温度过低时注意保暖

### 1.3 呼吸扎根

**目的**：通过呼吸将注意力从思维带回身体  
**时长**：5 分钟  
**步骤**：
1. 坐直，脊柱自然伸展
2. 缓慢吸气，感受气息进入身体（空气的清凉感）
3. 缓慢呼气，感受气息离开身体
4. 将一只手放在腹部，感受呼吸时腹部的起伏
5. 继续这个呼吸节奏，每次呼气时，让身体更放松一点

**适用情境**：过度思考、情绪激动后、睡前  
**禁忌**：呼吸困难者降低呼吸深度

## 2. 情绪调节类

### 2.1 温度调节

**目的**：通过温度刺激快速改变情绪状态  
**时长**：30 秒 - 2 分钟  
**步骤**：
- **平静化**：双手浸泡温水中（不烫），感受温热放松手部血管
- **激活化**：双手接触冷水（如冰箱内的物品），快速刺激神经系统

**适用情境**：焦虑急性发作（平静化）、能量不足（激活化）  
**禁忌**：温度感知异常者慎用

### 2.2 身体表达

**目的**：让情绪通过身体表达而非压抑  
**时长**：5-10 分钟  
**步骤**：
1. 站直，双脚与肩同宽
2. 如果感到愤怒：将双手握拳，向前快速推出（反复），释放身体的愤怒能量
3. 如果感到悲伤：弯下腰，让头部自然下垂，双手自然垂摆
4. 如果感到恐惧：抱紧自己，双臂交叉在胸前，轻微摇摆
5. 每个动作持续 3-5 分钟，感受身体的变化

**适用情境**：情绪积压、身体紧绷、情绪无法通过语言表达  
**禁忌**：有身体伤痛者降低动作幅度

### 2.3 行走冥想

**目的**：将冥想带入日常行动，调节情绪  
**时长**：10-20 分钟  
**步骤**：
1. 以极慢的速度行走
2. 将注意力放在脚与地面接触的感觉
3. 每一步都清晰地感受：抬脚、移动、落地
4. 如果注意力飘走，温和地带回脚的感觉
5. 行走中保持呼吸自然

**适用情境**：情绪低落、动力不足、难以静坐  
**禁忌**：平衡障碍者放慢速度，或扶着固定物体

## 3. 自我慈悲类

### 3.1 自我拥抱

**目的**：通过身体动作传递自我慈悲  
**时长**：5 分钟  
**步骤**：
1. 坐或站，双手交叉放在胸前（或一只手放在心口，一只手放在腹部）
2. 感受手的温度和触感
3. 缓慢地对自己说（或在心中默念）："此刻我在"或"我已经很努力了"
4. 同时保持呼吸平稳
5. 如果可以感受到一丝温暖或放松，让这个感受停留

**适用情境**：自我批评强烈、羞耻感、低自我价值  
**禁忌**：身体接触触发创伤时，改为手掌放在胸口而非双臂交叉

### 3.2 内在小孩连接冥想

**目的**：与内在小孩建立连接  
**时长**：15-20 分钟  
**步骤**：
1. 以舒适的姿势坐或躺，闭上眼睛
2. 缓慢呼吸，让自己完全放松
3. 想象一个安静、安全的空间（如花园、海边、一个让你感到安全的地方）
4. 在这个空间里，想象一个孩子的形象（你的内在小孩）
5. 观察这个孩子：他的表情是什么？他在做什么？
6. 走近这个孩子，蹲下来，看着他的眼睛
7. 轻轻地对他说话：告诉他你在这里，你会照顾他
8. 如果可以，给他一个拥抱
9. 停留几分钟，感受这个连接
10. 缓慢地睁开眼睛

**适用情境**：内在小孩议题、被忽视感、童年创伤觉察  
**禁忌**：情绪反应可能较强，建议在安全、私密空间进行，出现强烈反应时暂停

## 4. 睡前与安神类

### 4.1 渐进式肌肉放松

**目的**：释放身体紧张，帮助入睡  
**时长**：15-20 分钟  
**步骤**：
1. 平躺，闭眼，从脚趾开始
2. 吸气时，将脚趾向上卷紧，保持 5 秒
3. 呼气时，完全放松脚趾
4. 依次向上移动：小腿 → 大腿 → 臀部 → 腹部 → 胸部 → 双手 → 手臂 → 肩膀 → 面部
5. 每个部位重复：紧-松的节奏
6. 最后，感受整个身体的重量完全沉入地面

**适用情境**：失眠、身体紧绷、焦虑  
**禁忌**：肌肉或关节疼痛者避开疼痛部位

### 4.2 感恩呼吸

**目的**：在睡前将注意力从担忧带回当下的美好  
**时长**：5-10 分钟  
**步骤**：
1. 平躺或坐，闭眼，缓慢呼吸
2. 每次呼气时，在心中默念一件当天值得感恩的事（不需要大，小事也可以）
3. 感受感恩的感觉在身体中扩散
4. 不需要想太多，只是感受

**适用情境**：睡前焦虑、反复担心明天、无法停止思考  
**禁忌**：无特殊禁忌

## 5. 练习搭配建议

| 情境 | 推荐练习 | 顺序 |
|------|----------|------|
| 情绪激动后恢复平静 | 地面连接 + 呼吸扎根 | 先地面，后呼吸 |
| 身体紧绷 | 渐进式肌肉放松 | 单独使用 |
| 过度思考 | 身体扫描 + 行走冥想 | 先扫描，后行走 |
| 睡前焦虑 | 感恩呼吸 + 渐进式肌肉放松 | 先感恩，后放松 |
| 情绪积压 | 身体表达 + 自我拥抱 | 先表达，后接纳 |
| 内在小孩议题 | 内在小孩连接冥想 + 与内在小孩对话（书写练习） | 先冥想，后书写 |
