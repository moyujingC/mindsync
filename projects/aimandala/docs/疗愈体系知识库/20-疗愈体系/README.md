本目录保存长期可复用的疗愈体系知识。

疗愈体系分为三层：

- `10-议题层`：从用户经验出发，整理用户会主动提出或在解读中浮现的议题。
- `20-流派层`：从专业知识出发，整理心理学流派、疗愈流派和曼陀罗等解释框架。
- `30-疗愈方案层`：把议题层和流派层连接成可执行建议。

当前曼陀罗放在流派层中，不等同于应用层。真正的产品应用规则放在 `30-应用适配`。
