- 这个流派适合解释哪些现象？

## 1. 流派通用子结构模板

> **新增（2026-05-28）**：曼陀罗的五级子结构（画面识别→圈内五行→跨圈能量→组合模式→疗愈方案）已沉淀为流派层的格式规范模板。所有新流派入驻本层时，需按以下子目录结构组织内容。

每个流派的子目录应包含以下五个核心模块（可根据流派特性调整模块数量，但模块顺序不可颠倒）：

| 模块 | 子目录 | 定位 | 内容说明 |
|------|--------|------|----------|
| 基础理论 | `01-基础理论/` | 流派核心概念 | 该流派的核心概念、理论基础、适用范围 |
| 识别/诊断框架 | `02-识别诊断/` | 信号识别 | 该流派用于识别议题的画面信号、诊断规则 |
| 层级解读 | `03-层级解读/` | 解读逻辑 | 该流派的解读逻辑（如曼陀罗的圈内解读/跨圈解读） |
| 组合模式 | `04-组合模式/` | 综合判断 | 多个信号共同出现时的综合判断规则 |
| 疗愈方案 | `05-疗愈方案/` | 干预建议 | 基于该流派的疗愈建议、操作经验 |

### 模块说明

#### 01-基础理论

存放流派的核心概念和理论基础，包括：

- 流派的起源和发展
- 核心术语定义
- 理论基础（如曼陀罗的五行理论、家庭系统排列的系统观）
- 适用范围和不适用范围

文件名建议：`00-<流派>基础理论.md`

#### 02-识别诊断

存放该流派用于从观察材料（画面、文字、对话等）中提取信号的方法和规则，包括：

- 识别哪些观察维度
- 每个维度的信号定义
- 信号与议题的初步映射
- 识别边界和安全限制

文件名建议：`01-信号识别框架.md`、`02-信号总目录.md`

#### 03-层级解读

存放该流派的解读逻辑，按层级组织，包括：

- 第一层解读（如曼陀罗的圈层信号）
- 第二层解读（如曼陀罗的五行信号）
- 后续层级的解读规则
- 层级的递进关系

文件名建议：`01-<层级名称>解读法.md`

#### 04-组合模式

存放多个信号共同出现时的综合判断规则，包括：

- 常见的高频组合模式
- 组合信号的解读逻辑
- 组合信号的置信度判断
- 组合模式的案例支撑

文件名建议：`01-高频组合模式.md`、`02-组合判断规则.md`

#### 05-疗愈方案

存放基于该流派的疗愈建议和操作经验，包括：

- 一线疗愈师的操作经验
- 觉察问题库
- 练习方案
- 风险边界和禁忌

文件名建议：`01-疗愈方案经验.md`、`02-觉察问题库.md`

### 使用规则

1. **新流派入驻**：按上述五模块创建子目录结构，模块内容为空的需在文件中说明"待建设"。
2. **现有流派扩展**：曼陀罗的五个子目录（10-画面识别与描述/、20-圈内五行解读/、30-跨圈能量解读/、40-组合模式/、50-疗愈方案经验/）已对应上述五模块，可作为其他流派的参照。
3. **模块简化**：如果某个流派天然只需要 3-4 个模块，可以合并相近模块，但不可跳过"基础理论"或"疗愈方案"两个核心模块。
4. **来源标注**：每个子模块文件必须标注来源状态（source_status）和 review_status。
