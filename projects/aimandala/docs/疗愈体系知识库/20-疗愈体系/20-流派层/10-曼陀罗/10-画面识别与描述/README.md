本目录负责曼陀罗基础层的第一步：看见画面，并把画面事实描述清楚。

## 1. 本目录收什么

- 三圈边界、圈层范围、边界不清晰时的判定方式。
- 颜色、深浅、浓淡、面积、渐变、留白和分布。
- 形状、方向、完整度、闭合度、尖锐度和分布。
- 结构、重复、疏密、切分、内聚、外散和过渡状态。
- AI 视觉识别边界，例如模板黑线、三圈标记线、真实留白和原画优先规则。

## 2. 本目录不收什么

- 不收完整主题解读，例如财富、关系、健康、事业等议题翻译。
- 不收圈内五行生克关系的完整解释。
- 不收跨圈综合判断结论。
- 不收疗愈建议、练习方案或行动处方。

## 3. 上下游关系

- 上游：用户上传的曼陀罗原画、人工确认的三圈边界、必要时的三圈标记图。
- 本层输出：结构化画面描述、颜色事实、形状事实、圈层位置、视觉识别注意事项。
- 下游：`20-圈内五行解读/` 使用颜色和形状作为五行判断输入。
- 下游：`30-跨圈能量解读/` 使用三圈观察项做跨圈状态判断。
- 下游：议题层根据基础层输出做财富、关系、健康等主题翻译。

## 4. 维护规则

- 先写画面事实，再写可能含义。
- 颜色和形状在本目录里先作为视觉事实，不直接生成主题结论。
- 如果一个内容已经进入五行关系、跨圈联动或议题翻译，应放到对应目录，不在本目录重复展开。
