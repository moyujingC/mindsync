# 画面分析基础

## 定位

本文档是曼陀罗画面分析的基础框架，定义如何对一幅曼陀罗画作进行系统分析。

---

## 一、三圈划分

### 1.1 划分方式

曼陀罗画面从中心到边缘划分为三个同心区域：

| 圈层     | 位置         | 定义          |
| ------ | ---------- | ----------- |
| **内圈** | 中心区域（约1/3） | 最核心的圆域      |
| **中圈** | 中间区域（约1/3） | 内圈与外圈之间的过渡带 |
| **外圈** | 边缘区域（约1/3） | 最外围的圆域      |

### 1.2 边界判定

当圈层边界不清晰时，按以下优先级判定：

1. **形状边界**：明显的形状分界处
2. **颜色分界**：颜色变化的分界线
3. **比例估算**：约1/3等分

### 1.3 三圈的理论依据

三圈划分基于以下理论：

| 理论来源       | 内圈       | 中圈        | 外圈        |
| ---------- | -------- | --------- | --------- |
| **佛教密宗坛城** | 内坛（本尊殿）  | 中坛（菩萨/护法） | 外坛（防护/屏障） |
| **荣格人格结构** | 自性/集体无意识 | 个体无意识     | 人格面具      |
| **东方哲学**   | 天（灵性）    | 人（情绪/人际）  | 地（身体/现实）  |
| **心理空间隐喻** | 核心自我     | 人际区域      | 公共区域      |

## 二、画面分析要素

### 2.0 AI 视觉识别边界

以下规则专门用于 AI 识别，不用于反向否定疗愈师的人工判断。

- 模板黑线、印刷线稿、三圈标记线只用于识别形状边界或圈层边界，不计入画作颜色、画作元素或五行证据。
- 画作本身的白色、纸面留白、图案间空隙可以识别为金能量。
- 画面上外圈的外边以内，只要有真实留白，都可以作为金能量候选；是否参与某个生克关系，还要看它是否与对应元素在同圈内形成有效相邻或切分。
- 三圈标记图只用于确认圈层，不读取标记线颜色。
- 若原画作与三圈标记图颜色判断冲突，以原画作为准。

### 2.1 颜色

| 分析维度 | 内容 |
|----------|------|
| 颜色种类 | 画面使用了哪些颜色 |
| 颜色深度 | 浅色/正色/深色 |
| 颜色分布 | 各圈的颜色分布情况 |
| 颜色主次 | 以哪种颜色为主 |

### 2.2 形状

| 分析维度 | 内容 |
|----------|------|
| 形状种类 | 画面中出现的形状类型 |
| 形状特征 | 锐利/柔和/规则/不规则 |
| 形状方向 | 向上/向下/向内/向外 |
| 形状组合 | 形状之间的组合关系 |

### 2.3 位置关系

| 分析维度 | 内容 |
|----------|------|
| 位置分布 | 元素落在哪个圈层 |
| 相互位置 | 元素之间的上下/左右/内外关系 |
| 边界关系 | 元素与圈层边界的相对位置 |

## 三、各圈特殊关注点

### 3.1 内圈关注点

| 关注点 | 说明 |
|--------|------|
| 中心充盈度 | 中心是否有内容，还是空洞 |
| 中心形状 | 中心区域的形状特征 |
| 核心能量 | 内圈整体的能量状态 |

内圈也可进一步看作“魂、天、本源层”。

看什么：

- 中心图形是否完整。
- 中心是否有空缺、断裂或留白。
- 线条是粗还是细。
- 颜色是纯色还是杂色，深还是浅。
- 形状是尖锐还是圆润。

解读逻辑：

- 规整圆满：本心稳定，内在自洽，有内核力量。
- 残缺空白：内心迷茫，初心迷失，内在空虚，缺乏安全感。
- 深色居多：内在压抑，心事重，自我封闭。
- 浅色柔和：内心纯净，通透，觉知力强。
- 尖锐棱角：内在倔强，执念重，内心有对抗。
- 圆润曲线：本性温柔，包容，随顺。

### 3.2 中圈关注点

| 关注点 | 说明 |
|--------|------|
| 过渡状态 | 与内圈、外圈的过渡是否自然 |
| 能量流动 | 中间区域的能量是否顺畅 |
| 图案密度 | 中圈图案的密集程度 |

中圈也可进一步看作“气、人、情绪层”。

看什么：

- 中间花纹是否清晰。
- 缠绕线条是否顺畅，还是混乱、打结。
- 色块分布是否连续，还是被切割成多块。
- 图案是否有断裂、分层或反复回旋。

解读逻辑：

- 线条流畅：情绪稳定，人际和顺，能量通畅。
- 线条杂乱缠绕：内耗严重，纠结焦虑，感情内耗，人际关系拉扯。
- 色块分割明显：内心矛盾，双重性格，取舍两难。
- 色彩浓烈：情绪外放，感性重，爱恨分明。
- 色彩寡淡：情感疏离，不愿走心，习惯性克制。

### 3.3 外圈关注点

| 关注点 | 说明 |
|--------|------|
| 边缘完整性 | 边缘是否闭合，还是有破损/遗漏 |
| 边缘厚度 | 边缘的厚薄程度 |
| 边界清晰度 | 与外界的边界是否清晰 |

外圈也可进一步看作“形、地、现实层”。

看什么：

- 外围花边是否繁复。
- 边框是否闭合。
- 是否有缺口、破损或漏空。
- 装饰是繁还是简。
- 外圈颜色是厚重深色还是明亮浅色。

解读逻辑：

- 边框完整闭合：防御感强，边界清晰，懂得保护自己，生活安稳。
- 边框缺口破损：外界消耗大，容易被影响，无边界，易受他人拖累。
- 花边繁复：在意他人眼光，人设包袱重，社交思虑多。
- 外圈简约：活得通透，不在意世俗评价，行事随性。
- 外圈厚重深色：现实压力大，生活负担重，安全感不足。
- 外圈明亮浅色：外在运势顺，人缘好，现实环境宽松。

## 四、跨圈观察记录

本文档只负责记录跨圈观察项，不在这里生成跨圈综合结论。

画面识别阶段需要记录：

- 内圈、中圈、外圈是否都完整、规整或都有缺口。
- 三圈之间的颜色、形状和结构是否自然过渡。
- 内圈的状态是否能被中圈承接。
- 中圈的能量是否能流向外圈。
- 外圈是否能承接内在意图并形成现实表达。

跨圈综合判断统一进入 [../30-跨圈能量解读/01-三圈结构法.md](../30-跨圈能量解读/01-三圈结构法.md)，不在画面识别阶段提前下结论。

```
Step 1：划分三圈
    ↓
Step 2：识别各圈颜色
    ↓
Step 3：识别各圈形状
    ↓
Step 4：记录位置关系
    ↓
Step 5：观察特殊关注点
    ↓
Step 6：记录跨圈观察项，移交跨圈能量解读
```
