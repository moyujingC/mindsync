# 曼陀罗基础层解读流程

> 状态：draft
> 版本：0.1.0

> owner：CEO / Knowledge Base
> source_of_truth：当前目录/20-疗愈体系/20-流派层/10-曼陀罗/00-曼陀罗基础层解读流程.md

本文定义曼陀罗基础层的正式使用顺序。当前目录不再按原手册章节顺序组织，而是按实际解读流程组织。

## 1. 标准流程

基础层解读按以下顺序进行：

```text
画面识别与描述
  -> 圈内五行解读
  -> 圈内元素关系判断
  -> 跨圈能量解读
  -> 议题翻译
```

这条流程用于区分“看见了什么”和“解释成什么”。AI 生成报告时，应先完成画面事实描述，再进入五行和议题解释，避免直接从颜色或形状跳到主题结论。

## 2. 画面识别与描述

目录：`10-画面识别与描述/`

这一层只回答“画里有什么”，包括：

- 三圈边界和画面区域。
- 颜色、深浅、浓淡、渐变、面积和留白。
- 形状、方向、完整度、尖锐度、闭合度。
- 结构、重复、切分、疏密、内聚或外散。

颜色和形状在这里先作为视觉事实描述，不直接生成完整结论。

## 3. 圈内五行解读

目录：`20-圈内五行解读/`

这一层把颜色和形状转成五行元素，并在每一圈内部判断元素关系。

使用规则：

- 五行分析只限圈内元素之间的关系，不把一个圈整体判成单一五行。
- 颜色和形状都是五行判断输入。比如红色和三角形都可进入火，绿色和长条形都可进入木。
- 判断时看具体元素是否相邻、相生、相克、被切分、无根、失衡或不能成循环。
- 真实白色、纸面留白和色块缝隙可作为金能量候选；模板黑线、印刷线稿和三圈标记线不作为画作元素。

## 4. 跨圈能量解读

目录：`30-跨圈能量解读/`

这一层处理内圈、中圈、外圈之间的整体关系。

使用规则：

- 三圈联动使用三才、圈层语义和能量流动，不用五行生克替代。
- 内圈偏本源和内在，中圈偏当下能量和关系，外圈偏现实行动和外界呈现。
- 跨圈解读要看内外是否一致、能量是否贯通、现实是否承接内在，而不是把跨圈颜色强行做五行生克。

## 5. 组合模式

目录：`40-组合模式/`

这一层记录多个信号共同出现后的综合判断。组合模式不替代基础规则，只作为高阶综合判断和报告语言参考。

使用边界：

- 已审核案例规则可以进入报告候选，但仍需结合画面事实、圈层和用户主题。
- 组合模式不是穷举式映射表，不能作为 runtime 的唯一依据。
- 未命中的画面可以回到基础层推理，不应因为组合表没有覆盖就忽略画面事实。

## 6. 议题翻译

议题翻译不放在曼陀罗基础层内，而放在 `20-疗愈体系/10-议题层/`。

基础层只输出：

- 画面事实。
- 五行元素。
- 圈内五行关系。
- 跨圈能量状态。
- 组合模式候选。

财富、关系、事业、健康等议题如何解释这些信号，由各议题自己的翻译文件决定。
