本目录负责曼陀罗基础层的第四步：解释内圈、中圈、外圈之间的能量关系。

## 1. 本目录收什么

- 三圈结构法，包括内圈、中圈、外圈的定位、划分和使用顺序。
- 内中外三圈之间的承接、断裂、贯通、外散、收缩和不一致。
- 三圈联动规则，例如内稳中顺外圆、内缺中乱外散等综合模式。
- 跨圈能量判断的报告表达边界。

## 2. 本目录不收什么

- 不收单个颜色、单个形状的基础解释。
- 不收圈内五行生克关系的具体规则。
- 不用五行生克替代三圈联动。
- 不收财富、关系、健康等议题翻译。

## 3. 上下游关系

- 上游：`10-画面识别与描述/` 提供三圈观察项。
- 上游：`20-圈内五行解读/` 提供每一圈内部的五行状态。
- 本层输出：跨圈能量状态、三圈承接关系、整体结构判断。
- 下游：`40-组合模式/` 可沉淀多个跨圈状态的高命中组合。
- 下游：议题层把跨圈状态翻译为具体主题报告段落。

## 4. 维护规则

- 先说明三圈各自看到了什么，再说明三圈之间如何联动。
- 三圈联动使用三才、圈层语义和能量流动，不跨圈套用五行生克。
- 如果一个判断只来自某个单圈内部，应回到 `20-圈内五行解读/`，不要写成跨圈结论。
