# 组合模式

本目录负责沉淀多个画面信号共同出现后的高命中综合模式。

## 1. 本目录收什么

- 来自手册直断经验、完整案例和人工审核的组合规则。
- 多个颜色、形状、五行关系、圈层状态共同出现后的判断。
- 已审核案例中的稳定模式，例如白色切分、木无根、火被金截断、土零散不成片等。
- 可进入报告候选的综合判断和使用边界。

## 2. 本目录不收什么

- 不收单一颜色解释，单色解释放在 `10-画面识别与描述/04-颜色识别与感知.md`。
- 不收单一形状解释，形状解释放在 `10-画面识别与描述/03-形状识别与感知.md`。
- 不收基础五行生克规则，五行规则放在 `20-圈内五行解读/`。
- 不收议题层完整报告文案。

## 3. 上下游关系

- 上游：画面识别、圈内五行解读、跨圈能量解读提供基础信号。
- 本层输出：组合模式候选、审核状态、适用边界和报告引用线索。
- 下游：议题层根据用户主题把组合模式翻译成财富、关系、健康等主题语言。
- 下游：结构化知识单元可引用本目录中已审核的组合模式。

## 4. 维护规则

- 组合模式不是穷举总表，未命中时应回到基础层推理。
- 每个组合模式都要写清楚画面依据，不能只写结论。
- 来自少量案例的规则必须标注审核状态，不能直接写成全体系共识。
