本目录负责保存曼陀罗流派中的疗愈建议、练习经验和后续行动方向。

## 1. 本目录收什么

- 曼陀罗绘画疗愈建议。
- 适合放在报告末尾的低压行动建议。
- 与画面信号相关的觉察练习、书写练习、绘画练习和复盘方式。
- 疗愈方案的使用边界和安全提醒。

## 2. 本目录不收什么

- 不收画面识别规则。
- 不收五行生克基础规则。
- 不收跨圈能量判断。
- 不收医疗、心理诊断、投资建议或确定性承诺。

## 3. 上下游关系

- 上游：基础层输出画面事实、五行关系、跨圈状态和组合模式。
- 上游：议题层决定用户当前关注财富、关系、健康还是其他主题。
- 本层输出：可执行、低压、安全的疗愈建议和练习方向。
- 下游：报告模板根据 Lite 或 Pro 深度选择不同数量和强度的建议。

## 4. 维护规则

- 建议必须服务于用户当前主题，不把报告改写成完整疗愈课程。
- 建议应低压、可执行、可选择，不制造用户负担。
- 涉及风险、创伤、身体或财务内容时，只能给觉察方向和寻求专业支持的提示。
