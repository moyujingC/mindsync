## 目录职责

议题层负责曼陀罗解读报告的**议题知识定义**，包含三个子层：

| 子层 | 目录 | 职责 |
|------|------|------|
| 议题本体 | `10-议题本体/` | 提供通用议题知识定义（条款、画面信号对照、使用边界） |
| 浮现机制 | `20-浮现机制/` | 提供背景线索翻译指南（浮现机制版），供主议题报告包引用 |
| 主议题报告包 | `30-主议题报告包/` | 提供主议题特定翻译（画面→议题翻译层 + 报告段落结构） |

---

## 三层定位与协作规则

```
议题本体（通用知识）
  └─ 提供议题条款、画面信号对照、使用边界
  └─ 不负责"画面翻译"，不写具体报告段落结构

浮现机制（背景线索翻译指南）
  └─ 提供 7 个背景线索的翻译规则
  └─ 被主议题报告包引用，作为报告中的背景层面

主议题报告包（主议题特定翻译）
  └─ 负责画面→议题翻译（翻译层）
  └─ 负责报告段落结构定义
  └─ 引用议题本体和浮现机制
```

### 与其他层的关系

- **与流派层（曼陀罗）**：议题层不重复曼陀罗的画面识别知识，曼陀罗知识由 `20-流派层/` 维护
- **与疗愈方案层**：议题层提供议题定义，疗愈方案层（`30-疗愈方案层/`）提供干预工具（觉察问题/书写练习/身体冥想）
- **与应用适配层**：主议题报告包通过翻译层为报告模板提供具体信号翻译规则

## 协作规则

1. **议题本体文件**：每份文件应声明 `source_of_truth` 和来源验证状态
2. **浮现机制文件**：每份文件应声明来源（case_verified / ai_draft / case_partial）和置信度
3. **主议题报告包**：新增主议题前先查看 `30-主议题报告包/00-主议题报告包模板.md`
4. **议题本体与主议题报告包的分工**：议题本体不负责画面翻译，主议题报告包不重复议题定义
5. **浮现机制引用**：主议题报告包通过 `> 浮现机制：...` 字段引用对应浮现机制
