本文定义财富报告中如何处理浮现议题。

财富是主议题时，报告可以提到自我价值、家庭、关系、情绪、身体和事业，但这些内容必须服务财富主线。它们不是独立报告，也不能抢走用户这次选择的主题。

## 1. 定位

本文不是完整的自我价值、家庭、关系或身体知识库。

它是一层主议题和浮现议题之间的翻译规则，用来回答：

- 哪些浮现议题可以进入财富报告。
- 进入后应该翻译成哪类财富机制。
- 最多展开到什么深度。
- 哪些表达必须避免。
- 后续独立议题知识库建好后，应该如何挂接。

当前文件以财富为主议题，但结构要预留通用化空间。后续亲密关系、家庭、自我价值等议题独立成库后，可以用同样结构建立：

```text
primary_topic -> emergent_topic -> translation_role -> allowed_depth -> translated_mechanisms
```

## 2. 总规则

财富报告的主线固定为：

```text
画面信号 -> 财富状态 -> 财富机制 -> 浮现议题回译 -> 现实表现 -> 低风险建议
```

浮现议题只允许出现在三个位置：

1. 机制拆解：解释财富卡点为什么会形成。
2. 浮现议题回译：把其他议题翻译回财富机制。
3. 调整建议：给低风险觉察动作，不给完整疗愈方案。

浮现议题不允许：

- 单独展开成另一份报告。
- 替代财富主线。
- 生成诊断。
- 生成家庭、关系、身体或职业决策结论。
- 用“父母导致”“关系导致”“身体说明”等确定因果表达。

## 3. 浮现议题与财富回译

### 3.1 自我价值

允许进入财富报告的情形：

- 画面显示内圈收缩、中心空缺、金多、被切割、价值线索被压低。
- 用户问题涉及“不值得”“不敢收钱”“不敢被看见”“怕别人觉得我不值”。

回译方向：

- 配得感。
- 被支付能力。
- 价值可见度。
- 收受能力。
- 求认可式赚钱。

报告表达：

> 自我价值线索放到财富议题里，更像是在看：你是否允许自己的价值被看见、被支付，并稳定地接住回报。

避免：

- 不写“你没有价值感”。
- 不把价值感问题写成人格缺陷。

### 3.2 家庭与原生家庭

允许进入财富报告的情形：

- 画面出现强边界、防御、收缩、负担感、内外不一致。
- 用户提到父母、家庭责任、家族期待、赚钱压力或成功后关系变化。

回译方向：

- 金钱脚本。
- 成功许可。
- 承担模式。
- 收受能力。
- 家族忠诚。
- 安全感来源。

报告表达：

> 家庭线索放到财富议题里，不是为了判断父母或家庭，而是观察早期关于钱、成功、承担和收受的学习，是否还在影响你现在如何拥有和流动资源。

避免：

- 不写父母决定用户财富状态。
- 不用家庭系统解释替代心理诊断。
- 不把家族忠诚写成确定结论。

### 3.3 亲密关系与人际关系

允许进入财富报告的情形：

- 中圈缠绕、拉扯、断裂、色块分割明显。
- 外圈边界破损、缺口、被外界消耗。
- 用户提到合作、伴侣、客户、同事、人情压力。

回译方向：

- 价值交换。
- 付出和回报。
- 价格边界。
- 讨好和拒绝。
- 资源互惠。
- 接受支持。
- 关系认可消耗。

报告表达：

> 关系线索放到财富议题里，更像是在看交换边界：你是否容易先照顾别人，再考虑自己的价值、价格和承受范围。

案例规则补充：

- 中圈火被金切分，常翻译为热情、付出和行动被关系标准、评价或求认可打断。
- 火克金同时带有讨好、委屈或期待回应时，可翻译为“为了关系认可消耗财富行动力”。
- 关系结论可以作为画面直接线索进入报告，但必须回到财富中的价值交换、付出边界、收受能力和资源保存。

避免：

- 不展开成亲密关系报告。
- 不指责用户讨好。
- 不要求用户切断关系。

### 3.4 情绪调节

允许进入财富报告的情形：

- 红色、火感、外放、断裂、线条杂乱、颜色浓烈或情绪描述强。
- 用户提到焦虑消费、冲动消费、拖延、内耗或害怕钱不够。

回译方向：

- 情绪型漏财。
- 财富焦虑。
- 行动中断。
- 安抚性消费。
- 能量外散。
- 保护性习惯。
- 情绪化资源消耗。
- 进账后的保存不稳。

报告表达：

> 情绪线索放到财富议题里，更像是在看钱是否承担了安抚功能。消费、拖延或犹豫不一定是能力问题，也可能是情绪在寻找出口。

案例规则补充：

- 外圈土生金同时出现火克金时，可翻译为“有资源进入，但容易被情绪、人情、冲动消费或自我证明消耗”。
- 外圈红火明显时，不直接写成漏财定论，应写为财富能量外散、情绪带动消费或行动节奏被感受牵引。
- 火被金切成一块块时，可写行动和热情不连续，情绪状态影响财富主线稳定性。

避免：

- 不写用户乱花钱。
- 不诊断成瘾、焦虑症或强迫行为。
- 债务危机和强迫性消费需要提示外部专业支持。

### 3.5 身体与安全感

允许进入财富报告的情形：

- 内圈深色、收缩、厚重、尖锐、身体感描述强。
- 外圈厚重、防御、过满或压迫。
- 用户提到身体紧、怕行动、机会来了退回去。

回译方向：

- 承载力。
- 行动力。
- 风险承受。
- 身体是否能接住下一步。
- 安全感系统。
- 休息和恢复空间。

报告表达：

> 身体线索放到财富议题里，更像是在看你的系统是否能接住更多行动、曝光、机会和资源。这里不需要逼自己立刻冲出去，而是先让身体有一点可承受的稳定感。

避免：

- 不做健康判断。
- 不把身体反应当成投资、辞职、创业等决策依据。
- 不鼓励用户忽视现实医疗或心理支持。

### 3.6 事业、使命与价值表达

允许进入财富报告的情形：

- 外圈弱、留白多、外圈空、中心清晰但外化不足。
- 用户提到赚钱方向、能力表达、客户、市场、定价、作品或服务。

回译方向：

- 价值表达。
- 服务边界。
- 客户和市场连接。
- 真实需要。
- 行动主线。
- 可交换的价值形态。
- 机会滋养。
- 现实落地。

报告表达：

> 事业线索放到财富议题里，更像是在看：你的价值是否已经被整理成别人能看见、理解并愿意交换的形式。

案例规则补充：

- 无根之木进入财富报告时，翻译为成长、机会、事业方向或行动愿望有，但缺少滋养、信息流、支持系统、情绪稳定或资源连接。
- 木是否有根，需要看圈内具体木元素是否与水相邻或相接，不能只看同圈是否有水。
- 紫色偏木阳时，可翻译为灵感、愿景、贵人感和高维资源；若外圈落地不足，需要继续回译为价值表达和现实交换不足。

避免：

- 不给职业决策建议。
- 不承诺客户、成交、收入或市场反馈。
- 不把用户不外向写成问题。

## 4. 展开深度

财富报告中的浮现议题分三种深度：

- `hint`：只点一句，作为可能背景。
- `brief`：用一小段解释其财富含义。
- `supporting_mechanism`：进入机制拆解，但仍必须回到财富主线。

Lite 报告默认只允许 `hint` 或 `brief`。

Pro 报告可以使用 `supporting_mechanism`，但每份报告最多展开 2 个浮现议题。超过 2 个时，只保留最能解释财富主线的议题。

## 5. 平滑过渡到独立议题知识库

后续如果某个浮现议题已经建成独立知识库，不需要推翻本文。

过渡方式：

1. 保留本文作为跨议题翻译层。
2. 在结构化 YAML 里补 `source_topic_clause_refs`。
3. 报告生成时仍先看 `primary_topic`。
4. 独立议题知识库只提供更稳的背景机制和表达，不改变主报告框架。

示例：

```yaml
primary_topic: wealth
emergent_topic: family
source_topic_clause_refs:
  - family.parental_money_message
  - family.loyalty_conflict
translated_mechanisms:
  - money_script
  - success_permission
  - receiving_capacity
```

这样未来家庭议题可以独立生成家庭报告，也可以在财富报告里作为背景机制出现。两者的差异由 `primary_topic` 决定。

## 6. 写作检查

每次生成财富报告时检查：

- 是否明确主议题仍是财富。
- 浮现议题是否已经翻译成财富机制。
- 是否没有展开成另一份报告。
- 是否没有使用确定因果。
- 是否没有给财务、职业、医疗或心理诊断建议。
- 是否保留低风险觉察出口。
