本目录收”浮现机制”。

浮现机制用于处理画面里已经出现某类深层线索，但证据还不足以落到具体主议题本体的情况。

例如财富报告中，中圈出现缠绕、留白切分、红色外放时，可以先解释为”关系与交换边界”或”情绪能量与消耗”，而不是直接判断为父亲关系、母亲关系或亲密关系。

## 1. 定位：本目录是共享浮现层

浮现机制是**跨议题共享层**，不是任何单一主议题的专用层。

同一个浮现机制可以在多份报告里被引用，但报告语言必须翻译回当前主议题：

- 在财富报告中引用”关系与交换边界” → 翻译为价值交换、付出边界、求认可。
- 在亲密关系报告中引用”关系与交换边界” → 翻译为关系动态、付出回报、边界感。
- 在健康身体报告中引用”情绪能量与消耗” → 翻译为身体紧张、行动阻滞、能量消耗。

各主议题的翻译层负责把浮现机制”翻译”成议题语言。本目录只提供浮现机制本身的定义和通用说明。

## 2. 第一批机制

| 浮现机制 | 通用定义 | 在财富中的翻译方向 |
|----------|----------|-------------------|
| 自我价值与配得感 | 解释值得拥有、值得被支付、能否接住支持。 | 配得感、被支付能力、价值可见度。 |
| 安全感与匮乏感 | 解释紧绷、控制、担忧和资源保存焦虑。 | 金钱紧绷、财富焦虑、承载压力。 |
| 关系与交换边界 | 解释人情、合作、付出回报和关系中的资源流动。 | 价值交换、付出边界、讨好与拒绝。 |
| 家庭系统脚本 | 解释父母、家族、责任、成功和归属对当前议题的影响。 | 金钱脚本、成功许可、承担模式。 |
| 情绪能量与消耗 | 解释情绪外放、内耗、补偿、冲动和行动中断。 | 情绪型漏财、财富焦虑、行动被打断。 |
| 身体承载与行动力 | 解释身体收缩、行动退回、承接不足和落地困难。 | 承载力不足、行动力弱、身体接不住机会。 |
| 事业表达与世界连接 | 解释价值表达、客户市场、现实连接和机会承接。 | 价值表达受阻、与世界链接不足。 |

## 3. 使用边界

- 浮现机制不是诊断。
- 浮现机制不是独立报告入口。
- 浮现机制必须翻译回当前主议题语言，不允许单独展开成另一份报告。
- 如果画面证据足够具体，可以进一步引用主议题本体，例如父亲关系、母亲关系或健康身体。
