## 角色声明

本目录下的 7 个文件是**背景线索的翻译指南**，不是议题本体。

两者的分工：

| | 议题本体 | 浮现机制（背景线索） |
|---|---|---|
| **定位** | 回答「这个议题本身是什么、范围在哪里」 | 回答「当它作为背景线索嵌入时，画面怎么识别、怎么表达」 |
| **使用场景** | 用户选择该议题为主议题时，生成完整报告 | 该议题作为其他主议题的背景线索时，嵌入到主议题报告中 |
| **内容重心** | 议题范围、常见卡点、疗愈方向 | 通用画面识别规则、与其他背景线索的区分、表达原则 |
| **主议题特定翻译** | 无 | 交给各主议题的翻译层（如「财富关系议题翻译层」） |

**双重角色设计**：同一议题（如「情绪能量」「自我价值」）可以同时存在于议题本体和浮现机制中——议题本体侧维护完整议题知识，浮现机制侧维护当它作为背景线索被调用时的翻译指南。两个版本各有分工，互不替代。

## 背景线索的定位

背景线索是**跨议题共享层**，不是任何单一主议题的专用层。

## 使用边界

- 背景线索不是诊断。
- 背景线索不是独立报告入口。
- 背景线索必须翻译回当前主议题语言，不允许单独展开成另一份报告。
- 如果画面证据足够具体，可以进一步引用主议题本体，例如父亲关系、母亲关系或健康身体。
