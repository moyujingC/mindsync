本目录收“浮现机制”。

浮现机制用于处理画面里已经出现某类深层线索，但证据还不足以落到具体主议题本体的情况。

例如财富报告中，中圈出现缠绕、留白切分、红色外放时，可以先解释为“关系与交换边界”或“情绪能量与消耗”，而不是直接判断为父亲关系、母亲关系或亲密关系。

## 1. 第一批机制

| 浮现机制 | 作用 |
|----------|------|
| 自我价值与配得感 | 解释值得拥有、值得被支付、能否接住支持。 |
| 安全感与匮乏感 | 解释紧绷、控制、担忧和资源保存焦虑。 |
| 关系与交换边界 | 解释人情、合作、付出回报和关系中的资源流动。 |
| 家庭系统脚本 | 解释父母、家族、责任、成功和归属对当前议题的影响。 |
| 情绪能量与消耗 | 解释情绪外放、内耗、补偿、冲动和行动中断。 |
| 身体承载与行动力 | 解释身体收缩、行动退回、承接不足和落地困难。 |
| 事业表达与世界连接 | 解释价值表达、客户市场、现实连接和机会承接。 |

## 2. 使用边界

- 浮现机制不是诊断。
- 浮现机制不是独立报告入口。
- 浮现机制必须服务当前主议题。
- 如果证据足够具体，可以进一步引用议题本体，例如父亲关系、母亲关系、亲密关系或健康身体。
