## 通用定义

解释价值如何被看见、被交换、被世界接住，以及用户是否愿意进入现实连接。

## 画面识别

待建设。以下为框架占位：

- 外圈留白多 / 外圈弱 → 价值还没有充分进入市场、客户、合作或现实交换
- 中心清晰但外圈弱 → 内在价值清楚，但外化不足
- 碎点多 / 能量分散 → 注意力、方向或能量分散

## 与其他背景线索的区分

| 背景线索 | 区分点 |
|---------|-------|
| 自我价值与配得感 | 事业表达侧重价值的市场交换；自我价值侧重内在认可和配得感 |
| 身体承载与行动力 | 事业表达侧重世界连接和机会承接；身体承载侧重承接力和落地 |

## 通用表达原则

- 不替用户做职业选择，不承诺市场反馈或变现结果
- 表达为「画面中可能呈现价值外化的状态……」而非「你与世界连接不足」

## 画面识别

### 3.1 外圈留白多 / 外圈弱 {#mechanism.career_expression.outer_weak}

**信号**：`外圈大面积留白` 或 `外圈颜色淡薄/单一`
**画面特征**：第三圈颜色少、空白多、或仅用极淡的色彩填充，与内圈/中圈的饱满度形成对比
**解读方向**：内在价值还没有充分进入现实交换、市场、客户、合作或关系。外圈代表与世界的接口，留白意味着还没有充分把自己的价值外化、与世界产生交换
**边界**：外圈留白也可能代表「刚起步」而非「缺乏」——需结合内圈是否有清晰的能量核心判断
**来源状态**：⚠️ ai_draft，需对照案例验证
**置信度**：⚠️ 低 → 🟡 中
**案例验证**：2 个案例——case-006（情感主题，外圈/中圈有大片空白 → 职业状态：关系被困/被动等待/无法离开）；case-010（财富关系主题，外圈弱火且被金所泻 → 职业状态：不喜欢工作但被迫上班，财富进账被动卡住）

### 3.2 中心清晰但外圈弱 {#mechanism.career_expression.center_clear_outer_weak}

**信号**：`内圈/中圈颜色饱满、形状清晰` + `外圈空白或淡薄`
**画面特征**：画面中心有丰富的颜色和清晰的形状，但向外延伸时突然变淡或空白
**解读方向**：内在价值和方向清晰，但「出不来」。想法多、愿景清晰，但与世界对接时断联。价值没有被转化为可见的结果或交换。这不同于外圈弱——后者内圈可能也不清晰，前者是内圈清晰但外化受阻
**区分注意**：与「灵性成长但不落地」（浮现机制01）不同——后者偏重内在提升和现实断层；这里是价值外化和市场交换的议题
**来源状态**：⚠️ case_partial（R-003 case-001、R-021 case-009 间接支持）
**置信度**：🟡 中（间接支持：外在表达有距离感、行动不连续性）
**案例验证**：2 个案例——case-001（个人成长主题，内圈水+金丰富/中圈粉红被金截断，外圈紫色条状被白色隔断 → 有价值核心但向外表达受限）；case-010（财富关系主题，内圈方向清晰但外圈弱火被金泻 → 内在有方向但外展受限，被动工作）

### 3.3 碎点多 / 能量分散 {#mechanism.career_expression.fragmentation}

**信号**：`画面中有大量小元素/碎点` + `没有明显的主要颜色或形状`
**画面特征**：画布上分布着许多小色块或小形状，没有一个主导的颜色或结构统领全局
**解读方向**：注意力、方向或能量分散。在事业上表现为：方向不聚焦、做很多事但没有主轴、什么都想做但什么都浅。与外圈弱不同——碎点是「太多」而非「不足」，是分散而非空缺
**边界**：碎点也可能代表「探索期」，需要结合时间线判断，不能直接写成「方向不清晰」
**来源状态**：✅ case_verified（R-009 case-003、R-019 case-008、R-025 case-011）
**置信度**：✅ 高（3 个案例）——成长行动力分散 → ✅ 高（4 个案例）
**案例验证**：原3个案例（R-009 case-003、R-019 case-008、R-025 case-011）+ case-007（事业发展主题，外圈蓝色云状+橙色圆点分散重复，中圈紫色尖瓣+黄色花形多方向重复 → "眉毛胡子一把抓，定位不清晰，分不清重点，能量和行动都有点分散和混乱，事业发展受阻"）
### 3.4 外圈能量向内收 {#mechanism.career_expression.energy_inward}

**信号**：`外圈有能量但整体向内聚集` 而非向外散发 + `与3.1外圈弱不同`
**画面特征**：外圈区域有颜色和能量，但不是向外扩散的形态，而是整体向画面中心聚合，外圈边缘反而偏淡或留白
**解读方向**：能量存在于外圈但方向错误——是向内收而非向外表达。这不同于外圈弱（外圈能量本身少），也不同于外圈留白多（外圈本身空白）。这里是能量在外圈但出不来、与世界连接的方向是错的。在事业层面，这可能表现为：有能力也有价值，但表现方式是对内积攒而非向外输出，或者与世界交换时是索取型而非给予型
**区分注意**：与3.2「中心清晰但外圈弱」的不同——3.2是外圈能量少，这里是外圈能量有但向内收；与3.1「外圈留白」的不同——3.1是外圈本身空，这里是外圈有能量但方向反了
**边界**：不写成「你不愿表达」，而是「画面中外圈能量向内聚集而非向外扩散，呈现一种价值能量存在但外化方向可能需要调整的状态」
**来源状态**：⚠️ ai_draft，待更多案例验证
**置信度**：⚠️ 低 → 🟡 中（1个案例）
**案例验证**：1 个案例——case-008（财富关系主题，外圈淡绿向外延展，但内在限制性信念强，不与世界链接，孤军奋战 → "如果封闭心门，全凭自己努力，不去打开自己和这个世界的链接，一方面财富能量会被卡住"，与世界交换的方向是向内/封闭而非向外/开放）

### 3.5 外圈颜色与内圈冲突 {#mechanism.career_expression.color_conflict}

**信号**：`外圈颜色与内/中圈颜色呈现对抗性组合` + `外圈表达受阻`
**画面特征**：外圈主要颜色与内/中圈主要颜色形成对抗（如内黄外青、内红外蓝等），且外圈的能量无法顺畅向外延伸，像是被内在冲突拉回
**解读方向**：外圈代表与世界连接和价值交换。外圈颜色与内圈冲突意味着案主想外化但被内在冲突拉回——意愿和能力在某种程度上被内在矛盾抵消了。在事业层面，这可能表现为：想做但感觉有内在阻力、价值输出了但感觉没有真正被认可、或交换过程中有强烈的内在拉扯感
**区分注意**：与情绪能量与消耗中的「水火相冲」（3.1）不同——3.1是内外圈之间的对冲，这里是外圈与内/中圈的颜色本身形成对抗结构，且阻碍的是价值外化而非行动犹豫
**边界**：不写成「你内心矛盾」，而是「画面中内圈与外圈颜色呈现对抗结构，价值外化路径上有内在的拉扯感，这可能影响与世界交换的顺畅度」
**来源状态**：⚠️ ai_draft，待更多案例验证
**置信度**：⚠️ 低（待验证）
**案例验证**：待验证——暂无明确对应案例，需在后续案例中寻找内圈暖色+外圈冷色且外化受阻的结构

### 3.6 中圈能量断层 {#mechanism.career_expression.mid_circle_disconnect}

**信号**：`中圈能量有但断裂` + `内圈与外圈仍有连接`
**画面特征**：中圈颜色存在但不连贯，有明显的断裂或空白带，内圈与外圈之间的能量流在中圈中断，整体画面呈现「内通外不通」的状态
**解读方向**：中圈代表价值交换和关系连接。中圈断层意味着在「自我价值→交换接口」这个环节出了问题——不是没有价值，也不是没有连接尝试，而是交换过程本身断了。在事业层面，这可能表现为：付出没有得到预期回报、合作进行到一半断掉、或关系网在某处断裂。断层与碎点不同——碎点是量太多太散，断层是质的中断
**区分注意**：与3.3「碎点多/能量分散」的不同——碎点是外圈太散，这里是中圈断裂；与3.2「中心清晰但外圈弱」的不同——3.2是外圈本身弱，这里是中圈传导路径断了
**边界**：不写成「你合作不顺利」，而是「画面中中圈能量出现断裂带，内在价值向外的传导路径可能在中途中断，这可能反映在价值交换或关系连接中的某个环节存在阻滞」
**来源状态**：⚠️ ai_draft，待更多案例验证
**置信度**：⚠️ 低（待验证）
**案例验证**：待验证——暂无明确对应案例，需在后续案例中寻找中圈断裂且内-外仍有能量连接的结构

## 6. 常见调整方案

> ⚠️ 以下内容均为 ai_draft，使用前需在报告中标注「以下建议方向需根据个案具体情况调整」，不可作为确定性疗愈方案。

### 外圈弱型（价值外化不足）

- 优先做「小范围试交换」：不要等完美方案，先把自己的价值以最小成本推向小范围市场或关系，积累真实反馈。
- 建立「外化仪式」：每天或每周做一个具体的「让价值被看见」的动作——哪怕是发布一条内容、写一封信、发一个提案。
- 检视是否有「内在评判」在阻止价值外化：是否觉得自己还不够好、不够专业、不够有资格？

### 中心清晰外圈弱型（价值出不来）

- 优先找到「出不来」的卡点：是方向不清晰？是恐惧？是缺少接口？还是缺一个具体的人？
- 做「价值翻译」练习：把自己的能力、愿景用最直接的方式表达给一个人听，然后收集反馈。
- 寻找一个能承接自己价值输出的「容器」：一个客户、一个合作方、一个平台，降低独自面对市场的恐惧。

### 碎点分散型（方向不聚焦）

- 优先做「减法」：找出自己最核心的 1-2 件事，放弃其他。碎片化不是因为没有选择，而是选择太多。
- 从「兴趣」转化为「承诺」：每天拿出固定时间只做一件事，直到这件事有了初步可见的结果。

## 7. 使用提醒

事业表达与世界连接作为背景线索时，报告中应判断：

1. 问题的核心：方向不清？价值没有外化？还是外化了但没有交换回来？
2. 内圈是否有清晰的价值核心？还是外化不足是因为内在本身不清晰？
3. 是「不想进入世界连接」还是「想但找不到路径」？
4. 当前是否有现实层面的机会被错过？还是只在内在徘徊？

**禁止句式**：
- 「你事业不顺利」→ 「画面中外圈能量偏弱，价值还没有充分进入现实交换」
- 「你与世界脱节」→ 「画面中内圈能量清晰但外圈空白，呈现一种价值向内凝聚但向外传导受阻的状态」
- 「你方向不清晰」→ 「画面中碎点多、能量分散，呈现一种方向需要聚焦的状态」

**建议句式**：
- 「画面中外圈留白较多，这种情况在曼陀罗中常对应一种价值还没有充分进入现实交换的状态——这不一定是能力问题，更可能是接口问题。」
- 「内圈颜色饱满、中心清晰，但向外延伸时突然淡薄，这种结构通常反映一种内在价值清楚、但外化路径还没有打开的状态。」
