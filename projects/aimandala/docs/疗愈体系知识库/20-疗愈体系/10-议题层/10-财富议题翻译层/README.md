本目录负责把曼陀罗基础层输出翻译成财富议题语言。

它不是新的画面识别规则，也不是完整财富手册。它位于两者中间，解决一个问题：同一个画面信号进入财富报告时，应该翻译成哪类财富状态、财富机制和报告段落。

## 1. 标准链路

```text
基础层信号
  -> 基础状态含义
  -> 财富议题翻译
  -> 报告模块位置
  -> 表达边界
```

例如：

```text
外圈红火明显
  -> 火能量外散、行动和情绪外放
  -> 财富能量容易被情绪和即时感受带走
  -> 放入“现实财富流动 / 行动与消耗”
  -> 不能写成现实漏财定论
```

## 2. 本目录收什么

- 基础层信号在财富议题中的翻译。
- 颜色、形状、五行关系、三圈状态和组合模式的财富语义。
- 翻译后对应的财富条款、报告模块和可用表达。
- 不能进入报告的表达边界。
- 需要后续证据回填或人工审核的翻译候选。

## 3. 本目录不收什么

- 不收原始画面识别规则。
- 不收圈内五行生克的基础定义。
- 不收完整财富理论手册。
- 不收最终报告成稿。
- 不替代 `50-结构化知识单元/40-wealth-report-routing.yaml`，后者只接收已稳定的结构化条目。

## 5. 维护规则

- 每条翻译都必须保留画面依据，不直接写成财富结论。
- 单一信号只能生成候选解释，多信号共同指向时才提高报告权重。
- 其他议题可以浮现，但必须回译到财富主线。
- 不输出财务预测、投资建议、职业决策、心理诊断或医疗判断。
- 证据状态不足的条目，只能作为草稿候选，不进入强结论。
