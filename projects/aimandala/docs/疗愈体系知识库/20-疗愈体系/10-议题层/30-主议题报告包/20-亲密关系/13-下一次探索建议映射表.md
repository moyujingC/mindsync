本文定义亲密关系报告下一次探索建议的映射规则。

## 1. 推荐原则

- 推荐必须来自本次画面中浮现但未完全展开的线索
- 不做焦虑式复购，不制造"关系处处有问题"的感觉
- 推荐方向应给用户希望和方向感
- Lite 报告最多推荐 1 个方向
- Pro 报告最多推荐 2 个方向

## 2. 不推荐的边界

- 不能因为画面中问题多就推荐多个方向
- 不能推荐用户没有浮现的议题
- 不能制造焦虑（"因为你这里有问题，所以要再做一次"）
- 不能承诺关系结果

## 3. 推荐方向映射

### 3.1 基于浮现线索的推荐

| 本次浮现线索 | 推荐探索方向 | 推荐理由 |
|--------------|-------------|----------|
| 依恋防御模式 | 个人成长/自我价值 | 先建立内在安全感再进入关系探索 |
| 交换失衡 | 亲密关系（再画一次） | 在关系中练习平衡的付出和接收 |
| 原生家庭影响 | 父亲关系/母亲关系 | 探索原生家庭亲密模式源头 |
| 情绪共振困难 | 情绪能量 | 先建立自我情绪觉察 |
| 安全感不足 | 个人成长/自我价值 | 先建立内在安全感 |
| 成长动力强 | 个人成长/意识扩容 | 在成长中整合亲密关系 |

### 3.2 基于圈层的推荐

| 圈层信号 | 推荐探索方向 |
|----------|-------------|
| 内圈强但中圈乱 | 个人成长（先整合内在） |
| 中圈强但外圈弱 | 事业/价值表达（先建立外在连接） |
| 三圈皆弱 | 个人成长（先建立基础） |
| 圈层差异大 | 意识扩容（先整合内外差异） |

## 4. 推荐表达模板

### 4.1 单一推荐（Lite）

```
基于本次画面，如果你希望继续探索，__议题可能是一个方向。
```

### 4.2 双重推荐（Pro）

```
基于本次画面，如果你希望继续探索，以下方向可能值得关注：

1. __议题：__（理由）
2. __议题：__（理由）

你可以根据自己的感受选择最想探索的方向。
```

## 5. 推荐优先级

1. 与本次画面主轴最相关的方向优先
2. 用户已有意愿或暗示的方向优先
3. 内在基础（内圈）优先于外在发展（外圈）
4. 不推荐多于 2 个方向
