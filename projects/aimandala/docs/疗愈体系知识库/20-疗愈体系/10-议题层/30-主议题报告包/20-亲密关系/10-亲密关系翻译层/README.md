本目录负责把曼陀罗基础层输出翻译成亲密关系议题语言。

## 1. 标准链路

```text
基础层信号
  -> 基础状态含义
  -> 亲密关系议题翻译
  -> 报告模块位置
  -> 表达边界
```

## 2. 与背景线索的关系

"关系与交换边界"是跨议题共享的背景线索。在亲密关系报告中，应：
- 优先使用本翻译层定义的亲密关系特有规则
- 背景线索作为补充，不替代主线
- 亲密关系特有的翻译方向：依恋模式、靠近-防御循环、付出-接收失衡

## 3. 本目录收什么

- 基础层信号在亲密关系议题中的翻译
- 颜色、形状、五行关系、三圈状态的亲密关系语义
- 翻译后对应的亲密关系条款、报告模块和可用表达
- 表达边界

## 4. 本目录不收什么

- 不收原始画面识别规则
- 不收完整亲密关系理论手册
- 不收最终报告成稿

## 5. 圈层对应关系

| 圈层 | 亲密关系翻译方向 |
|------|-----------------|
| 内圈 | 依恋模式、安全感基础、自我价值 |
| 中圈 | 关系动态、交换边界、情绪共振 |
| 外圈 | 现实连接、行动模式、向外表达 |

## 6. 维护规则

- 每条翻译都必须保留画面依据
- 单一信号只能生成候选解释，多信号共同指向时才提高报告权重
- 不输出关系决策、心理诊断或医疗判断
- 证据状态不足的条目，只能作为草稿候选
