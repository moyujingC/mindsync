## 2. 亲密关系报告中的圈层解读

```text
内圈 -> 依恋模式、安全感基础、自我价值

外圈 -> 现实连接、行动模式、向外表达
```

## 3. 与背景线索的关系

亲密关系报告应优先使用"关系与交换边界"背景线索翻译规则。

当画面中出现自我价值、安全感、家庭系统等线索时，应以亲密关系视角进行翻译，而不是直接展开为独立议题。

## 4. 下一次探索建议

亲密关系报告结尾可以给 1-2 个下一次曼陀罗探索方向。

推荐必须来自本次画面中浮现但未完全展开的线索，不做焦虑式复购，不制造"关系处处有问题"的感觉。

Lite 报告最多推荐 1 个方向。Pro 报告最多推荐 2 个方向。
