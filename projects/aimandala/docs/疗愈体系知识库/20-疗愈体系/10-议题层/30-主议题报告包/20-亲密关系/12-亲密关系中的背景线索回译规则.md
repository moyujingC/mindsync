本文定义其他议题如何进入亲密关系报告的翻译规则。

## 1. 回译原则

当画面中出现其他议题线索时，必须以亲密关系视角进行翻译：

- 背景线索不是诊断
- 背景线索不是独立报告入口
- 背景线索必须翻译回亲密关系主线，不单独展开成另一份报告
- 翻译后的表达应以亲密关系视角呈现

## 3. 深度分级说明

| 深度级别 | 说明 |
|----------|------|
| hint | 只点一句，不展开。例如："关系中可能有__的倾向。" |
| brief | 一小段解释其在亲密关系中的意义，仍回到亲密关系主线。 |
| supporting_mechanism | 进入机制拆解，但最终回到亲密关系主线。 |

默认限制：
- Lite 报告最多到 `brief`
- Pro 报告最多 2 个 `supporting_mechanism`
- 背景线索不能替代亲密关系主线

## 4. 表达模板

### 4.1 hint 级别

```
从画面来看，关系中可能有__的倾向。
```

### 4.2 brief 级别

```
在亲密关系中，这可能表现为__。从画面来看，__在关系中可能需要先__。
```

### 4.3 supporting_mechanism 级别

```
从画面来看，__在关系中可能带着更深层的模式。

在亲密关系中，这表现为__。这个模式可能与__有关。

从画面来看，建议先在关系中觉察__，而不是急于改变关系本身。
```

## 5. 使用规则

- 背景线索必须以亲密关系视角重新表述
- 不把背景线索展开成独立议题报告
- 优先翻译与亲密关系最相关的线索
- 翻译后仍应回到亲密关系主线
