## 1. 议题定位

事业发展议题在曼陀罗中对应一个核心问题：

**价值如何从内在走向外在、被世界看见、被交换并落地。**

这不是工作选择或职业规划，而是观察以下6个维度的状态：

| 维度 | 说明 | 核心问题 |
|------|------|----------|
| **价值外化** | 价值是否进入现实交换 | 我的价值有没有被看见？ |
| **行动落地** | 身体与行动力的关系 | 我的想法出得来吗？ |
| **方向聚焦** | 能量是聚焦还是分散 | 我知道自己要什么吗？ |
| **世界连接** | 与市场的接口是否打开 | 我与世界有交换渠道吗？ |
| **成功许可** | 是否允许自己成功 | 我允许自己成功吗？ |
| **三赢交换** | 交换模式是否平衡 | 我的成功是否需要牺牲？ |

## 2. 与财富关系议题的关系

**事业发展与财富关系议题高度相关但不等同。**

| 对比维度 | 财富关系议题 | 事业发展议题 |
|----------|----------|--------------|
| 核心问题 | 资源如何流进、留住、流出 | 价值如何从内在走向外在 |
| 侧重点 | 安全感、配得感、资源边界 | 价值外化、行动落地、世界连接 |
| 交换对象 | 金钱、资源、物质 | 市场、客户、合作、机会 |
| 外化形式 | 财富积累、收入增长 | 作品、贡献、被认可、被需要 |
| 典型卡点 | 不敢拥有、赚来辛苦、资源流失 | 价值出不来、方向不聚焦、与世界断联 |

**关系说明**：
- 财富是事业的外化结果之一——当事业价值被有效外化，财富作为交换媒介通常会随之而来。
- 财富关系议题中的"资源流失"和"赚来辛苦"，可能同时需要从事业发展维度理解（价值是否被充分外化、交换模式是否平衡）。
- 事业议题可以独立于财富关系议题单独成立：有人事业方向清晰但财务紧绷，有人财富充裕但事业价值感低。
- 两议题不应混用：选择主议题时，若画面同时出现事业和财富信号，应先确认用户当前最核心的张力是哪个。

## 3. 安全边界总则

事业发展议题有明确的安全边界，报告语言必须遵守：

**绝对禁止**：
- 不替用户做职业选择或创业决策（如"你应该辞职/创业/转型"）
- 不承诺市场反馈或变现结果（如"你能赚多少钱"）
- 不输出财务决策建议（如"你应该买/卖/投什么"）
- 不把画面符号写成确定因果（如"你与世界脱节是因为能力不足"）
- 不替代职业咨询（不说"你的事业方向应该是X"）

**表达替代规则**：

| 禁止句式 | 替换为 |
|----------|--------|
| 「你事业不顺利」 | 「画面中外圈能量偏弱，价值还没有充分进入现实交换」 |
| 「你与世界脱节」 | 「画面中内圈能量清晰但外圈空白，呈现一种价值向内凝聚但向外传导受阻的状态」 |
| 「你方向不清晰」 | 「画面中碎点多、能量分散，呈现一种方向需要聚焦的状态」 |
| 「你行动力差」 | 「画面中内圈有力但外圈断裂，能量落地路径可能有阻滞」 |
| 「你不允许自己成功」 | 「画面中可能存在一些对成功的压力或恐惧需要觉察」 |

**报告语气要求**：全程使用"可能"、"像是"、"从画面来看"等缓冲语气，不写确定性结论。

## 8. 三圈事业读法

事业发展报告优先使用以下三圈解读：

- **内圈**：价值核心、方向感、自我认可、成功许可——我是谁、我要什么、我允许自己要到吗。
- **中圈**：交换模式、反馈接收、关系连接——我的价值通过什么交换出去、谁在给我回应。
- **外圈**：价值外化、现实行动、市场/客户/合作、对外表达——我的价值有没有出得来、有没有人接住。

外圈是事业发展报告的第一优先级：中圈次之；内圈第三。
