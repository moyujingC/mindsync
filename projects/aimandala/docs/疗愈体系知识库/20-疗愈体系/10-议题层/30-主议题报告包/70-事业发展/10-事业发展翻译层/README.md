本目录负责把曼陀罗基础层输出翻译成事业发展议题语言。

它不是新的画面识别规则，也不是完整事业手册。它位于两者中间，解决一个问题：同一个画面信号进入事业发展报告时，应该翻译成哪类事业状态、事业机制和报告段落。

## 1. 标准链路

```text
基础层信号
  -> 基础状态含义
  -> 事业发展议题翻译
  -> 报告模块位置
  -> 表达边界
```

例如：

```text
外圈留白多
  -> 对外呈现、现实连接或行动出口不足
  -> 价值还没有充分进入现实交换、市场或合作
  -> 放入"世界连接 / 价值外化"
  -> 不能写成"你事业方向不清晰"
```

## 2. 本目录收什么

- 基础层信号在事业发展议题中的翻译。
- 颜色、形状、三圈状态和组合模式的事业语义。
- 翻译后对应的事业条款、报告模块和可用表达。
- 其他浮现议题（财富、情绪、关系等）回译到事业主线的规则。
- 不能进入报告的表达边界。

## 3. 本目录不收什么

- 不收原始画面识别规则。
- 不收圈内五行生克的基础定义。
- 不收完整事业理论手册。
- 不收最终报告成稿。
- 不替代职业咨询或财务建议。

## 5. 维护规则

- 每条翻译都必须保留画面依据，不直接写成事业结论。
- 单一信号只能生成候选解释，多信号共同指向时才提高报告权重。
- 其他议题（财富/情绪/关系）作为背景线索出现时，必须回译到事业主线。
- 不输出职业决策建议、创业指导、财务承诺或心理诊断。
- 证据状态不足的条目，只能作为草稿候选，不进入强结论。

## 6. 主次判断规则

- 多个信号共同指向同一事业条款时，该条款可以作为主轴候选。
- 外圈优先解释现实行动、价值外化、世界连接和机会承接。
- 中圈优先解释交换模式、反馈接收和关系连接。
- 内圈优先解释价值核心、方向聚焦和成功许可。
- 单一信号不得单独生成强事业结论。

## 7. 禁止句式（全程生效）

| 禁止句式 | 替换为 |
|----------|--------|
| 「你事业不顺利」 | 「画面中外圈能量偏弱，价值还没有充分进入现实交换」 |
| 「你与世界脱节」 | 「画面中内圈能量清晰但外圈空白，呈现一种价值向内凝聚但向外传导受阻的状态」 |
| 「你方向不清晰」 | 「画面中碎点多、能量分散，呈现一种方向需要聚焦的状态」 |
| 「你行动力差」 | 「画面中内圈有力但外圈断裂，能量落地路径可能有阻滞」 |
| 「你不允许自己成功」 | 「画面中可能存在一些对成功的压力或恐惧需要觉察」 |
| 「你应该辞职/创业/转型」 | 不写任何职业决策建议 |
| 「你能赚多少钱」 | 不承诺任何财务结果 |
