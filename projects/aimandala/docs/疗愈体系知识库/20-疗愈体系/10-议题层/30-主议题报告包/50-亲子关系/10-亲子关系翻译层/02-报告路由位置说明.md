本文定义亲子关系报告中的固定段落路由规则。

## 1. 亲子关系报告固定段落

| 段落序号 | 段落名称 | 主要内容 | 必填 |
|----------|----------|----------|------|
| 1 | 整体直觉 | 从整体画面描述亲子关系状态的第一印象。 | 是 |
| 2 | 施与受序位 | 内圈对应的序位状态、是否在正确位置上。 | 是 |
| 3 | 教养模式 | 中圈对应的养育方式、边界感、情绪卷入。 | 是 |
| 4 | 代际传递 | 外圈对应的代际模式、原生家庭影响。 | 是 |
| 5 | 核心发现 | 1-2 个主轴发现，从多个信号共同指向的条款中提炼。 | 是 |
| 6 | 接受父母/代际和解 | 其他议题浮现时，回译到接受父母机制的翻译。 | 否 |
| 7 | 疗愈方向 | 基于发现的卡点，给出方向性建议。 | 是 |
| 8 | 下一步探索（可选） | 下一个曼陀罗探索方向建议。 | 否 |

## 2. 圈层与段落的对应关系

| 圈层 | 对应段落 | 优先翻译方向 |
|------|----------|--------------|
| 内圈 | 段落2 | 施与受序位、自我价值与父母位置 |
| 中圈 | 段落3 | 教养模式、边界感、情绪共振 |
| 外圈 | 段落4 | 代际传递、原生家庭脚本、向外表达 |

## 3. 翻译优先级

当多个信号同时出现时，按以下优先级确定主轴：

1. 内圈信号优先（施与受序位是亲子关系的基础）
2. 中圈信号次之（教养模式是亲子关系的核心）
3. 外圈信号最后（代际传递是亲子关系的落地）

单一圈层信号不得生成强结论，需要多个信号共同指向同一方向。

## 4. 背景线索的处理

当画面中出现其他议题线索时：

| 浮现线索 | 亲子关系翻译方向 |
|----------|-----------------|
| 配得感/自我价值 | 在亲子关系中是否允许做自己、与孩子平等相处 |
| 安全感/匮乏感 | 在亲子关系中是否感到安全、是否过度担心孩子 |
| 交换边界 | 在亲子关系中的付出-接收模式（是否过度付出或索取） |
| 亲密关系 | 与伴侣的养育一致性与分歧、如何共同养育 |
| 家庭系统 | 原生家庭如何影响当下亲子互动模式 |
