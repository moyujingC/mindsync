本目录收可以作为产品主入口的报告包。

报告包负责把基础层画面信号、议题本体、浮现机制和应用模板组装成某个主议题的报告。

这里的关系是：

- `浮现机制` 提供共享背景线索。
- `背景线索` 是报告正文里的写法。
- `浮现议题` 仍然可以作为运行时标签存在，但不再是财富 Lite 报告中的显性章节名。

## 1. 当前报告包

- 新增主议题前先看：[00-主议题报告包模板.md](00-主议题报告包模板.md)

## 2. 报告包职责

- 定义该主议题如何读取三圈。
- 定义基础信号如何翻译到该主议题。
- 定义可调用哪些浮现机制。
- 定义什么时候可以引用其他议题本体。
- 定义报告结构、Lite / Pro 差异和下一次探索建议。
