报告包负责把基础层画面信号、议题本体、浮现机制和应用模板组装成某个主议题的报告。

这里的关系是：

- `浮现机制` 提供共享背景线索。
- `背景线索` 是报告正文里的写法。
- `浮现议题` 仍然可以作为运行时标签存在，但不再是财富 Lite 报告中的显性章节名。

## 2. 与议题本体的分工

> P1-4 修复：明确主议题报告包与议题本体的职责边界

主议题报告包和议题本体服务不同层级，不可相互替代：

| 维度 | 议题本体 | 主议题报告包 |
|------|---------|-------------|
| 职责 | 提供通用议题知识定义 | 提供主议题特定翻译（画面→议题） |
| 内容 | 议题条款、画面信号对照、使用边界 | 翻译层（颜色/形状/跨圈/组合）+ 报告段落结构 |
| 不负责 | 画面翻译；具体报告段落结构 | 议题通用定义；不重复议题本体条款 |
| 调用关系 | 被主议题报告包引用 | 引用议题本体 + 浮现机制 |

**协作规则**：
- 主议题报告包通过 frontmatter 的 `> 议题手册：...` 引用议题本体文件
- 主议题报告包通过 frontmatter 的 `> 浮现机制：...` 引用浮现机制文件
- 翻译层文件只负责画面信号翻译，不重复议题定义内容
- 浮现机制作为"背景线索"进入报告，不可替代翻译层

## 3. 报告包职责

- 定义该主议题如何读取三圈。
- 定义基础信号如何翻译到该主议题。
- 定义可调用哪些浮现机制。
- 定义什么时候可以引用其他议题本体。
- 定义报告结构、Lite / Pro 差异和下一次探索建议。
