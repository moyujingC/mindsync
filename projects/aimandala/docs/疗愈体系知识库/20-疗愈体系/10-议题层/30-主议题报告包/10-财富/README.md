## 2. 财富报告中的中圈

财富报告里的中圈优先解读为：

```text
情绪 / 关系 / 交换状态
  -> 价值交换
  -> 资源边界
  -> 情绪如何影响赚钱、收钱、花钱、谈价和合作
```

中圈不默认落到父亲关系、母亲关系或亲密关系。只有当用户输入或画面证据足够明确时，才进一步引用具体关系线索，并回到财富主线。

## 3. 下一次探索建议

财富报告结尾可以给 1-2 个下一次曼陀罗探索方向。

推荐必须来自本次画面中浮现但未完全展开的线索，不做焦虑式复购，不制造“哪里都有问题”的感觉。

Lite 报告最多推荐 1 个方向。Pro 报告最多推荐 2 个方向。

具体推荐方向按 [13-下一次探索建议映射表.md](13-下一次探索建议映射表.md) 执行。
