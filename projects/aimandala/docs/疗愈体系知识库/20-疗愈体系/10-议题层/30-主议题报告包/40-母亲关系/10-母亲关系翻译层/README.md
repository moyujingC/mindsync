本目录负责把曼陀罗基础层输出翻译成母亲关系议题语言。

## 1. 标准链路

```text
基础层信号
  -> 基础状态含义
  -> 母亲关系议题翻译
  -> 报告模块位置
  -> 表达边界
```

## 2. 与背景线索的关系

在母亲关系报告中，应：
- 优先使用本翻译层定义的母性照顾特有规则
- 背景线索作为补充，不替代主线
- 母亲关系特有的翻译方向：照顾者印象、依恋模式、被接纳感、情绪共振

## 4. 圈层对应关系

| 圈层 | 母亲关系翻译方向 |
|------|-----------------|
| 内圈 | 照顾者印象、情感基础、被接纳感 |
| 中圈 | 与照顾者的关系模式、依恋模式、情绪共振 |
| 外圈 | 与他人的关系模式、社会连接、向外表达 |

## 5. 维护规则

- 每条翻译都必须保留画面依据
- 单一信号只能生成候选解释
- 不输出心理诊断或医疗判断
