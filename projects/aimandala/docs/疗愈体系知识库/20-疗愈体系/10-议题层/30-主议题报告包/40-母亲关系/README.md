## 2. 母亲关系报告中的圈层解读

```text
内圈 -> 照顾者印象、情感基础、被接纳感
中圈 -> 与照顾者的关系模式、依恋模式、情绪共振
外圈 -> 与他人的关系模式、社会连接、向外表达
```

## 3. 与背景线索的关系

母亲关系报告应优先使用"家庭系统脚本"和"安全感与匮乏感"背景线索翻译规则。

当画面中出现照顾、依恋、被接纳、情绪共振等线索时，应以母亲关系视角进行翻译。
