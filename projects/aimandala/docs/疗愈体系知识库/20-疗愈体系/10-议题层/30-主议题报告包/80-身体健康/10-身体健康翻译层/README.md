本目录负责把曼陀罗基础层输出翻译成身体健康议题语言。

它不是新的画面识别规则，也不是完整的身体手册。它位于两者中间，解决一个问题：同一个画面信号进入身体健康报告时，应该翻译成哪类身体状态、身体机制和报告段落。

## 1. 标准链路

```text
基础层信号
  -> 基础状态含义
  -> 身体健康议题翻译
  -> 报告模块位置
  -> 表达边界
```

例如：

```text
内圈颜色偏暗、土色浓重
  -> 能量偏沉重、阻滞感
  -> 身体可能有湿寒积累，情绪承载偏重
  -> 放入"身体能量状态 / 湿寒与温暖"
  -> 不能写成身体有疾病或诊断
```

## 2. 本目录收什么

- 基础层信号在身体健康议题中的翻译。
- 颜色、形状、三圈状态和组合模式的身体语义。
- 翻译后对应的身体条款、报告模块和可用表达。
- 不能进入报告的表达边界。
- 医疗风险路由的信号识别。

## 3. 本目录不收什么

- 不收原始画面识别规则。
- 不收圈内五行生克的基础定义。
- 不收完整身体理论手册。
- 不收最终报告成稿。
- 不替代医疗诊断或建议。

## 5. 维护规则

- 每条翻译都必须保留画面依据，不直接写成身体结论。
- 单一信号只能生成候选解释，多信号共同指向时才提高报告权重。
- 其他议题可以作为背景线索出现，但必须回译到身体健康主线。
- 不输出医疗判断、心理诊断或医疗建议。
- 证据状态不足的条目，只能作为草稿候选，不进入强结论。
- 医疗风险信号必须加入提醒路由。

## 6. 主次判断规则

- 多个信号共同指向同一身体条款时，该条款可以作为主轴候选。
- 内圈优先解释身体核心能量、承载力基础和内在感知。
- 中圈优先解释情绪承载、身体感受积累和阻滞感。
- 外圈优先解释行动落地能力和现实互动。
- 单一信号不得单独生成强身体结论。
- 身体健康报告只维护一条主线：身体能量和承载力。
