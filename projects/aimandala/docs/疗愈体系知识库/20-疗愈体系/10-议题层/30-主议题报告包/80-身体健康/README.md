## 2. 身体健康报告中的三圈

身体健康报告里的三圈优先解读为：

```text
内圈：身体核心能量、内在安全感和自我接纳
  -> 身体承载力基础
  -> 内在身体感知
中圈：情绪承载、感受积累、滋养与阻滞
  -> 情绪的身体容器
  -> 感受积累与身体症状
外圈：现实行动、落地能力、与世界互动
  -> 行动落地能力
  -> 身体与现实
```

## 3. 安全边界总则

身体健康报告必须始终遵守以下边界：

- **不输出医疗判断**：不写成"你的身体有某种疾病"或"你有某种具体症状"
- **不说"身体导致"**：不说"你的身体问题导致了..."等因果表达
- **不替代医疗建议**：不输出具体的医疗或治疗建议
- **不说"必须运动"**：不把身体活动写成必须的疗愈方式
- **身体信号只是线索**：身体信号只能作为背景线索，不能生成诊断
- **不说"你身体不好"**：避免让用户对自己的身体产生负面评价

## 4. 医疗风险路由

当画面中出现以下信号时，必须在报告中加入医疗提醒路由：

| 画面信号 | 风险路由表达 |
|----------|--------------|
| 内圈颜色极度暗淡、有溃散感 | 建议用户如有身体不适，及时寻求专业医疗帮助。 |
| 身体特定部位有明显异常信号 | 身体信号只能作为线索，如有具体症状请咨询医生。 |
| 画面整体呈现极度收缩、无生机 | 本解读不替代专业医疗评估，身体信号仅供参考。 |
| 中圈出现极端阻滞、颜色极深 | 如有长期身体不适，建议寻求医疗专业人士评估。 |
