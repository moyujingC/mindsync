本目录负责把曼陀罗基础层输出翻译成父亲关系议题语言。

## 1. 标准链路

```text
基础层信号
  -> 基础状态含义
  -> 父亲关系议题翻译
  -> 报告模块位置
  -> 表达边界
```

## 2. 与背景线索的关系

"家庭系统脚本"是跨议题共享的背景线索。在父亲关系报告中，应：
- 优先使用本翻译层定义的父性权威特有规则
- 背景线索作为补充，不替代主线
- 父亲关系特有的翻译方向：权威印象、规则感、认可需求、成功许可

## 3. 本目录收什么

- 基础层信号在父亲关系议题中的翻译
- 颜色、形状、五行关系、三圈状态的父性关系语义
- 翻译后对应的父亲关系条款、报告模块和可用表达
- 表达边界

## 4. 圈层对应关系

| 圈层 | 父亲关系翻译方向 |
|------|-----------------|
| 内圈 | 权威印象、安全感基础、自我价值 |
| 中圈 | 与权威的关系模式、规则感、认可需求 |
| 外圈 | 与外部世界的关系、行动模式、社会连接 |

## 5. 维护规则

- 每条翻译都必须保留画面依据
- 单一信号只能生成候选解释，多信号共同指向时才提高报告权重
- 不输出心理诊断或医疗判断
- 证据状态不足的条目，只能作为草稿候选
