本文定义人际关系报告中的固定段落路由规则。

## 1. 人际关系报告固定段落

| 段落序号 | 段落名称 | 主要内容 | 必填 |
|----------|----------|----------|------|
| 1 | 整体直觉 | 从整体画面描述人际关系状态的第一印象。 | 是 |
| 2 | 边界与交换基础 | 内圈对应的边界感、交换模式、自我位置。 | 是 |
| 3 | 社交动态 | 中圈对应的社交模式、情绪共振、关系卷入。 | 是 |
| 4 | 现实连接 | 外圈对应的现实连接、向外表达、支持性关系。 | 是 |
| 5 | 核心发现 | 1-2 个主轴发现，从多个信号共同指向的条款中提炼。 | 是 |
| 6 | 背景线索 | 其他议题浮现时，回译到人际关系主线的翻译。 | 否 |
| 7 | 疗愈方向 | 基于发现的卡点，给出方向性建议。 | 是 |
| 8 | 下一步探索（可选） | 下一个曼陀罗探索方向建议。 | 否 |

## 2. 圈层与段落的对应关系

| 圈层 | 对应段落 | 优先翻译方向 |
|------|----------|--------------|
| 内圈 | 段落2 | 边界感、交换模式、自我价值位置 |
| 中圈 | 段落3 | 社交模式、情绪共振、关系卷入 |
| 外圈 | 段落4 | 现实连接、向外表达、支持性关系 |

## 3. 翻译优先级

当多个信号同时出现时，按以下优先级确定主轴：

1. 内圈信号优先（边界感是人际关系的基础）
2. 中圈信号次之（社交动态是人际关系的核心）
3. 外圈信号最后（现实连接是人际关系的落地）

单一圈层信号不得生成强结论，需要多个信号共同指向同一方向。

## 4. 背景线索的处理

当画面中出现其他议题线索时：

| 浮现线索 | 人际关系翻译方向 |
|----------|-----------------|
| 配得感/自我价值 | 在人际关系中是否允许被尊重、接受支持 |
| 安全感/匮乏感 | 在人际关系中是否感到安全、是否需要不断确认 |
| 交换边界 | 在人际关系中的付出-接收模式 |
| 亲密关系 | 与人际关系中的边界模式有何关联 |
| 家庭系统 | 原生家庭如何影响当下人际互动模式 |
