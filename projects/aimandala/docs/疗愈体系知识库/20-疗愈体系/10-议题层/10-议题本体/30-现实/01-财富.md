本文是 财富议题的主入口。

当前文件先定义财富议题的体系框架，不直接依赖画面信息。后续再把颜色、形状、圈层、五行生克等画面信息映射到这里的议题条款。

在 本知识库中，财富属于“用户主动议题”：用户容易直接选择“我想看财富、金钱、收入、事业变现、财富流动”。

但财富解读不能停留在钱本身。它通常会牵出一组背景线索，例如配得感、安全感、自我价值、家庭金钱脚本、求认可、行动力、承载力、与世界的链接。财富主议题负责承接用户入口，背景线索负责支撑深层解释和低风险建议。

## 1. 议题定义

财富议题不是单纯判断一个人“有没有钱”或“能不能赚钱”。

在 本知识库中，财富议题关注的是一个人与金钱、价值、资源、世界和行动之间的关系，包括：

- 如何看待金钱。
- 是否允许自己拥有财富。
- 如何创造和交换价值。
- 如何承接、保存和使用财富。
- 财富动力来自热爱、创造、服务、自由，还是来自恐惧、逃离、证明和补偿。
- 金钱关系背后牵动了哪些家庭、创伤、自我价值和安全感议题。

## 2. 议题范围

财富议题至少包括以下范围：

- 金钱信念。
- 自我价值感与配得感。
- 安全感与匮乏感。
- 赚钱动力。
- 行动力与持续性。
- 花钱模式与漏财模式。
- 存钱、守财与承载力。
- 家庭金钱脚本。
- 亲密关系中的金钱模式。
- 事业、能力、价值交换。
- 对世界的信任、热爱和链接。
- 身体能量对财富行动的支撑。

## 3. 主议题与背景线索

财富议题的推荐组织方式是：

```text
财富主议题
  → 背景线索
  → 具体条款
  → 报告表达
  → 追问回答
  → 疗愈方案
```

### 3.1 财富作为用户主动议题

用户主动选择财富议题时，常见关切包括：

- 我为什么赚不到钱。
- 我为什么存不住钱。
- 我为什么总觉得钱不够。
- 我适合怎样创造财富。
- 我的财富流动哪里卡住了。
- 我的金钱关系和家庭、关系、事业有什么关联。

这部分是报告的主线入口。

### 3.2 财富中常见的背景线索

财富解读中常见背景线索包括：

| 背景线索 | 在财富中的表现 |
|----------|----------------|
| 配得感 | 是否允许自己拥有更多，是否觉得自己值得被支付、被看见、被支持。 |
| 安全感 | 是否把钱当成安全感来源，是否长期担心不够用。 |
| 自我价值 | 是否把收入、成就、客户认可等同于“我好不好”。 |
| 家庭金钱脚本 | 是否承接了家族里关于钱、辛苦、亏欠、牺牲、风险的模式。 |
| 求认可 | 是否通过赚钱、努力、成绩来证明自己值得。 |
| 行动力 | 是否有想法但不落地，或行动容易被情绪、关系和自我怀疑打断。 |
| 承载力 | 是否能接住收入、机会、资源、被看见和更大的责任。 |
| 情绪能量 | 是否通过消费安抚情绪，或让焦虑、委屈、压力影响财富决策。 |
| 与世界的链接 | 是否愿意打开表达、合作、服务、市场和客户关系。 |

这些背景线索不是独立于财富之外的“另一个报告”，而是财富主议题下的深层解释层。它们可以对应议题本体里的浮现议题标签，但在用户可见报告里应嵌入财富主线，不作为显性章节。

## 4. 核心机制

财富议题中常见的核心机制包括：

- 金钱作为安全感的替代物。
- 金钱作为自我价值的证明。
- 赚钱作为逃离原生家庭、关系或环境的路径。
- 花钱作为情绪安抚。
- 努力赚钱背后的求认可模式。
- 害怕拥有、害怕失去、害怕被看见。
- 想要财富，但内在不允许自己真正拥有。
- 有能力创造价值，但承载力不足。
- 有赚钱机会，但行动力和持续性不足。

## 5. 常见卡点

### 5.1 配得感不足

表现为：

- 觉得自己不值得拥有更多。
- 拿到结果后仍然不满意。
- 需要不断证明自己才敢收钱。
- 对自己的价值有怀疑。

### 5.2 匮乏感和安全感不足

表现为：

- 对钱紧张、焦虑、患得患失。
- 有进账也不安心。
- 害怕未来不够用。
- 赚钱动力来自恐惧，而不是热爱和创造。

### 5.3 求认可式赚钱

表现为：

- 努力是为了被看见、被证明、被认可。
- 产出价值时很在意外界评价。
- 达不到标准就自我攻击。
- 把财富结果等同于“我好不好”。

### 5.4 情绪型漏财

表现为：

- 为情绪买单。
- 开心时奖励性消费，不开心时安抚性消费。
- 花钱不看性价比，只看当下感觉。
- 情感、家庭、成长焦虑带动支出。

### 5.5 承载力不足

表现为：

- 能赚钱但存不住。
- 有机会但接不住。
- 收入提升后很快出现新支出或新压力。
- 财富增长会带来焦虑，而不是稳定。

### 5.6 行动力不足

表现为：

- 想法很多，但落地少。
- 热情不持续。
- 容易被情绪和关系拖走。
- 计划常被外界标准、家庭关系或自我怀疑打断。

### 5.7 与世界链接不足

表现为：

- 不信任世界。
- 不愿意打开人际链接。
- 倾向于一个人扛。
- 不愿意向外表达价值。
- 对赚钱、客户、合作、市场缺少热爱。

## 6. 正向状态

财富议题的正向状态包括：

- 允许自己拥有财富。
- 能看见自己的价值，并愿意交换价值。
- 对金钱有稳定、清明、不紧绷的态度。
- 有行动力，也有持续性。
- 能赚钱，也能承载和保存财富。
- 愿意和世界建立真实链接。
- 能从热爱、创造、服务和自由出发赚钱。
- 财富增长不会破坏关系、身体和内在稳定。

## 7. 疗愈目标

财富议题的疗愈目标不是简单让用户“赚更多钱”，而是帮助用户：

- 看见自己的金钱信念。
- 看见财富背后的安全感和自我价值议题。
- 从恐惧、逃离、证明、讨好中抽离。
- 建立稳定的承载力。
- 恢复行动力和持续性。
- 建立与世界、他人和资源的健康链接。
- 形成更有生命力的财富创造方式。

## 8. 疗愈路径

可用的疗愈路径包括：

- 配得感练习。
- 自我价值确认。
- 安全感重建。
- 金钱信念梳理。
- 家庭金钱脚本觉察。
- 情绪消费觉察。
- 身体稳定练习。
- 行动力训练。
- 与世界链接练习。
- 财富感恩和丰盛感练习。

## 9. 条款索引

本体层只负责定义财富议题的大范围，不直接承担完整报告表达。后续报告生成时，建议优先对齐以下条款入口：

- 金钱本质与投射 -> 钱不只承载数字，也承载安全、自由、尊严、爱和接纳。
- 金钱信念与无意识脚本 -> 辛苦赚钱、有钱危险、更多才安全、钱留不住等脚本。
- 配得感与自我价值 -> 是否允许自己拥有、收取、被支付、被看见。
- 安全感、匮乏与控制 -> 钱是否在替安全感工作，紧绷和控制如何影响流动。
- 父母关系与家庭金钱脚本 -> 早期家庭中关于钱、成功、承担和收受的学习。
- 金钱羞耻与不敢收钱 -> 收费、开价、谈薪、收礼和接受支持时的羞耻或亏欠感。
- 情绪、消费与保护性习惯 -> 消费、拖延、逃避背后的情绪和保护功能。
- 身体连接、恐惧与行动力 -> 想行动但身体收缩、机会来了却退回去。
- 事业、能力与价值交换 -> 价值表达、能力定价、服务边界和现实交换。
- 世界链接、客户、市场与合作 -> 价值如何被看见、被回应、被交换。
- 热情、真实需要与内在富足 -> 从更真实的需要和生命力出发，而不是只盯着结果。
- 风险边界与不做范围 -> 财务建议、投资判断、职业决策、心理诊断都不进入财富报告。

## 10. 后续画面映射入口

后续可把画面信息映射到上述条款，例如：

- 外圈红色多，可能映射到情绪型漏财。
- 金多，可能映射到求认可、自我评判和外界标准。
- 土弱或不成片，可能映射到承载力不足。
- 水火冲突，可能映射到情绪消耗行动力。
- 木无根，可能映射到成长动力有但滋养不足。

这些映射只能作为解释线索，不应替代议题本身的体系判断。
