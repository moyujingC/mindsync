本目录收 17 个议题的本体知识。

议题本体回答：这个议题本身是什么、范围在哪里、常见卡点是什么、疗愈方向是什么。

它不直接等于产品入口。某个议题既可以作为用户主动选择的主议题，也可以作为其他主议题报告中的浮现议题。

这里的 `可作为浮现议题` 是角色元数据，表示该议题可以被其他主议题牵出。进入报告正文时，应由主议题报告包翻译成背景线索写法，不直接作为用户可见章节标题。

## 2. 标准字段

每个议题本体文件至少保留以下字段：

```text
> 状态：draft
> 内容来源状态：ai_draft
> 来源验证状态：source_verification_pending
> 用户入口角色：active_selectable / emergent_only / both
> 可作为主议题：是/否
> 可作为浮现议题：是/否
> MVP入口优先级：mvp / later / advanced
```

字段说明：

- `可作为浮现议题`：表示运行时可以作为其他主议题背后的角色标签。
- `背景线索`：不是本体元数据字段，而是报告写作口径；当浮现议题进入某个主报告时，应以背景线索方式嵌入主线。
