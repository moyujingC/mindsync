## 1. 目的

提供一份可直接落地的生产环境变量模板，覆盖：

- 后端（FastAPI）上传存储与 prompt runtime
- 前端（mobile-web）API 地址

当前默认目标环境为腾讯云（CVM + COS + 已备案域名）。

## 2. 后端 `.env.production` 模板

```bash
########################################
# AIMandala Backend - Production Env
########################################

# --- Upload storage ---
# 可选: local / s3 / oss / cos
AIMANDALA_UPLOAD_BACKEND=cos

# 腾讯云 COS
AIMANDALA_UPLOAD_COS_SECRET_ID=__REPLACE_ME__
AIMANDALA_UPLOAD_COS_SECRET_KEY=__REPLACE_ME__
AIMANDALA_UPLOAD_COS_BUCKET=ai-mandala-data-1305595349
AIMANDALA_UPLOAD_COS_REGION=ap-shanghai
AIMANDALA_UPLOAD_COS_KEY_PREFIX=aimandala/uploads

# 已备案域名或 CDN 域名（建议配置，便于前端直连图片）
# 生产建议: https://img.jingshu.cc
AIMANDALA_UPLOAD_COS_PUBLIC_BASE_URL=https://img.jingshu.cc

# 本地临时文件保留窗口（小时）
AIMANDALA_UPLOAD_LOCAL_RETENTION_HOURS=24

# --- Prompt runtime ---
# 可选: noop / http
AIMANDALA_PROMPT_RUNTIME_BACKEND=http

# 你的模型网关地址（必须可被后端服务器访问）
AIMANDALA_PROMPT_RUNTIME_HTTP_URL=__REPLACE_ME__
AIMANDALA_PROMPT_RUNTIME_HTTP_TIMEOUT_SECONDS=20

# 认证（如果网关不需要鉴权可留空）
AIMANDALA_PROMPT_RUNTIME_HTTP_API_KEY=__REPLACE_ME__
AIMANDALA_PROMPT_RUNTIME_HTTP_API_KEY_HEADER=Authorization

# 重试策略
AIMANDALA_PROMPT_RUNTIME_HTTP_MAX_RETRIES=2
AIMANDALA_PROMPT_RUNTIME_HTTP_RETRY_BACKOFF_MS=300
```

## 3. 前端 `.env.production` 模板

> 前端当前读取优先级：`VITE_AIMANDALA_API_BASE_URL` > `AIMANDALA_API_BASE_URL` > `NEXT_PUBLIC_AIMANDALA_API_BASE_URL`

```bash
########################################
# AIMandala mobile-web - Production Env
########################################

# 推荐使用 Vite 变量
VITE_AIMANDALA_API_BASE_URL=https://web-api.jingshu.cc

# 可选兼容（非必需）
# AIMANDALA_API_BASE_URL=https://web-api.jingshu.cc
# NEXT_PUBLIC_AIMANDALA_API_BASE_URL=https://web-api.jingshu.cc
```

## 5. 填值约束（腾讯云）

1. `AIMANDALA_UPLOAD_COS_PUBLIC_BASE_URL` 推荐使用你备案后的域名或 CDN 域名，而不是默认 `myqcloud.com`。
2. `VITE_AIMANDALA_API_BASE_URL` 必须与后端实际对外域名一致（含 `https`）。
3. `AIMANDALA_PROMPT_RUNTIME_HTTP_URL` 必须是后端服务器可访问的内网或公网地址。
4. 如果当前不准备接模型网关，可把 `AIMANDALA_PROMPT_RUNTIME_BACKEND` 改为 `noop`，主链会自动走 deterministic fallback。

## 6. 上线前最小自检

1. `GET /health` 返回 200。
2. `POST /api/v2/upload-image` 能返回 `storage_backend=cos` 且 `image_url` 指向备案域名。
3. `POST /api/v2/interpretations` + `GET /report?version=lite` 返回可读报告。
4. `POST /upgrade` + `GET /report?version=pro` 返回可读报告。
5. 网关不可用时仍能返回报告（验证 fallback 未破坏主链）。

## 7. 当前结论

这份模板已覆盖当前迁移链路的最小生产配置口径；迁移完成后，你只需要：

1. 按模板填实真实值。
2. 完成一次全链路 smoke test。
3. 再进入更细的运维收口（日志、告警、限流、清理任务）。
