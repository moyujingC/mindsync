## 4. 实施步骤

1. 定义新 contracts
   - `MandalaE2EInput`
   - `VisualDraft`
   - `PromptPackManifest`
   - `MandalaE2EResult`
   - `QualityGateResult`

2. 实现 `prompt_pack_builder.py`
   - 读取稳定前缀文件
   - 生成 pack hash
   - 组装静态前缀
   - 记录文件顺序

3. 改造视觉草稿生成
   - 输入原图和三圈标记图
   - 输出 `visual_draft.md`
   - 可选输出轻量 JSON 镜像

4. 改造报告直出
   - DeepSeek v4 Pro 读取稳定前缀
   - 动态区拼接 `visual_draft`、用户输入和 report_mode
   - 输出 `final_report.md`

5. 改造 quality gate
   - 去掉 16 stage 完整性检查
   - 检查视觉草稿、最终报告和越界内容
   - 检查内部词泄漏

6. 改造 artifact store
   - 写出 `agent_input.json`
   - 写出 `visual_draft.md`
   - 写出 `visual_draft.json`
   - 写出 `prompt_pack_manifest.json`
   - 写出 `final_report.md`
   - 写出 `final_report.json`
   - 写出 `quality_gate.json`
   - 写出 `run_summary.json`

7. 新增离线 runner
   - 跑同一张 MVP fixture
   - 生成 Lite 和 Pro
   - 保存真实模型结果

## 5. 非目标

- 不接入正式 API。
- 不实现报告追问智能体。
- 不生成真实可视化图片。
- 不重构上传、支付、用户、订单和历史记录。
- 不恢复旧 16 stage。
- 不把旧报告生成文档重新放回 active 入口。
