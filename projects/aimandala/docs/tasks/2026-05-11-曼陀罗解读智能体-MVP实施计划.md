实现 `曼陀罗解读智能体` MVP 离线原型。

## 4. 实施步骤

1. 定义 contracts
   - 输入合同
   - 输出合同
   - `stage_outputs`
   - `execution_trace`
   - `Report Context Package`

2. 实现 input collector
   - 读取 fixture 图片
   - 读取主题和用户输入
   - 固定三圈边界

3. 实现 knowledge pack builder
   - 从方法真值源和运行时知识包中生成精简知识包
   - 禁止塞入完整 Markdown 真值源

4. 实现 mandala interpretation agent
   - 按 5 个 execution block 执行
   - 输出 16 个 `stage-*`
   - 使用真实模型

5. 实现 quality gate
   - 检查结构
   - 检查用户可见文本
   - 检查旧链路泄漏

6. 实现 artifact store
   - 写出 QA 基线要求的 10 个文件

7. 跑 `toc-mvp-fixture-003`
   - 生成 Lite 报告
   - 生成 Pro 报告
   - 交给人工审阅

## 5. 非目标

- 不接入正式 API
- 不实现报告追问智能体
- 不生成真实可视化图片
- 不重构上传、支付、用户、订单和历史记录
- 不把旧报告生成文档重新放回 active 入口
