# 八议题报告生成配置化重构任务

> status：done
> owner：Engineer
> created_at：2026-05-28

## 目标

把 Aimandala 生成式解读报告从财富关系单议题硬编码，调整为八个主议题共用同一套生成链路。

当前需要支持：

- 财富关系
- 亲密关系
- 父亲关系
- 母亲关系
- 亲子关系
- 人际关系
- 事业发展
- 健康身体

## 技术边界

保留：

- 视觉基础层 `FoundationPromptPackBuilder`
- Lite / Pro 报告模式
- 两阶段生成链路：视觉观察 → 议题报告
- 旧财富/亲密关系 builder 的兼容入口

重构：

- 议题 prompt pack 由配置表驱动。
- 构建脚本按配置表生成 8 个 generated prompt packs。
- agent 根据用户主题选择议题 pack。
- 质量门从财富专属校验改为议题通用校验。
- 报告稳定规则从财富专属文案改为 topic-aware 通用规则。

## 不做范围

- 不重写 8 个议题知识库内容。
- 不改变视觉基础层识别规则。
- 不接入新的线上路由/API。
- 不处理 Pro 对外开放策略。

## 验收标准

- `scripts/build_mandala_prompt_packs.py --topic all` 能生成 foundation + 8 个议题包。
- 每个议题包包含本议题目录和对应 `06*` 报告模板。
- agent 运行时不再硬编码 `wealth_prompt_pack`。
- quality gate 不再使用 `missing_wealth_topic`。
- 现有 e2e 单元测试通过，并新增议题配置覆盖。
