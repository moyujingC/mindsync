本文档追踪疗愈体系知识库从来源层到报告包层的完整链路搭建进度。

## 完整链路（5层）

```
L1: 书籍来源层 (research-center/kb/sources/healing/)
    ├── 书籍原文 + 章节整理
    ├── 来源登记 + 元数据 + 使用边界
    └── 《谁在我家》《对生命说是》等

    ↓ 书籍 → 关键知识点提取
L1.5: 知识点提取层 (research-center/kb/atoms/healing/)
    ├── 按书籍组织的 atoms（51个文件）
    ├── 每条 atom 有来源标注 + 使用边界 + 状态
    └── 示例：对生命说是-习惯可能是无意识保护策略.md

    ↓ atoms → 议题映射
L2: 来源索引层 (05-参考来源索引/)
    ├── 按议题组织的来源映射表
    ├── 记录：来源位置 → 议题 → atoms候选
    └── 21-关系议题来源索引.md 等

    ↓ 议题本体化
L3: 议题本体层 (20-疗愈体系/10-议题层/10-议题本体/)
    ├── 议题定位 + 画面信号 + 来源状态
    └── 20-关系/01-亲密关系.md 等

    ↓ 产品化
L4: 报告包层 (20-疗愈体系/10-议题层/30-主议题报告包/)
    ├── 翻译层 + 议题手册 + 回译规则 + 探索建议
    └── 20-亲密关系/ 等
```

## 执行原则

1. **先索引后本体**：每条 atoms 必须有来源索引才能进入议题本体
2. **状态透明**：所有文件必须标注状态（draft / source_verified / source_needed）
3. **禁止反推**：案例反推不能替代上游来源
4. **禁止因果声明**：不允许把海灵格等理论语言写成事实因果
5. **禁止结果承诺**：不允许在报告中承诺关系/财富等现实结果
