# Specs

这里放 `一镜一梳` 当前生效、已进入审阅，或仍有参考价值的 spec。

当前目录不要按“文件越新越重要”来理解，而应按“先看母文档，再看页面链路，再看报告内容”来阅读。

## 当前统一口径

当前一级产品只保留三种：

- `Lite`
  - 支持 `全面解读` / `专题解读`
- `Pro`
  - 支持 `全面解读` / `专题解读`
- `Journey`
  - 基于多次历史画作的长期综合解读

当前 `To C MVP` 的单次上传主链路是：

1. `upload`
2. `detect`
3. `report-choice`
4. `selected-generating`
5. `selected-ready`
6. `history`

也就是：

- 上传作品
- 完成三圈识别
- 用户自己选择 `Lite / Pro`
- 进入对应 loading
- 进入对应结果页

当前不要再把流程写成：

- 系统先推荐 `Lite / Pro`
- 默认先买 `Lite` 再升级 `Pro`
- `Journey` 属于单次上传后的同层选择

## 使用规则

- 新增页面规则时，优先先改母文档与状态机总表，再补分文档

- 如果文档之间出现冲突，优先回到 `MVP页面状态机与页面映射总表` 和 `toc-mvp-spec` 收束
