## 1. 目的

本文件用于定义 `Lite / 全面解读` 的 prompt 提纲，目标不是直接产出最终 prompt 文案，而是先收束：

1. 这一版到底要生成什么
2. 输入信息该如何排序使用
3. 正文应该按什么顺序展开
4. 哪些写法必须避免

## 2. 这份 Prompt 要完成什么

`Lite / 全面解读` 要生成的是：

- 一份低压、成立、围绕用户当前整体状态展开的单次正式解读

它最核心要完成的 4 件事是：

1. 快速命中当前状态
2. 给出够成立的画面依据
3. 轻轻解释为什么会这样
4. 给一个低压下一步

## 3. 输入优先级

当前建议 prompt 按下面顺序使用输入：

1. `画作本身`
   - 永远是主要证据来源
2. `绘画过程中的感受`
   - 优先帮助建立命中感和状态解释
3. `绘画前意图`
   - 用来判断用户原本想看什么，以及现实关切点
4. `主题`
   - 此版本默认是 `general`，只作为整体阅读角度，不做专题收束

## 4. 生成目标

prompt 应明确要求模型输出下面 6 段内容：

1. `标题`
2. `开头命中`
3. `画面依据`
4. `当前状态解释`
5. `现实连接`
6. `一个低压下一步`

## 5. 每段生成要求

## 5.1 标题

要求：

1. 3-8 个字为宜
2. 要点出当前状态气候
3. 不要悬浮或故作深刻

## 5.2 开头命中

要求：

1. 第一段第一句就进入当前状态
2. 2-3 句即可
3. 先说中状态，再轻轻带出理解方向

## 5.3 画面依据

要求：

1. 至少给出 `2-3` 个关键画面锚点
2. 要形成 `观察 -> 判断` 的最小链路
3. 不要只罗列元素

## 5.4 当前状态解释

要求：

1. 只停在当前状态层
2. 必须至少吃进：
   - `绘画过程中的感受`
   - 或 `绘画前意图`
3. 不要上升到长期稳定机制

## 5.5 现实连接

要求：

1. 至少落一个最近生活面向
2. 用轻量、具体的方式表达
3. 不展开成人生分析

## 5.6 一个低压下一步

要求：

1. 只保留一个主动作
2. 动作要小、具体、做得到
3. 不写成练习清单

## 6. 语气要求

prompt 应明确要求生成语气满足下面 5 条：

1. 温柔，但不悬浮
2. 清楚，但不高压
3. 有共鸣，但不套路
4. 有依据，但不技术化
5. 有方向，但不催促

## 7. 明确禁止项

prompt 应明确禁止下面写法：

1. 写成安慰卡片
2. 写成缩短版 `Pro`
3. 写成大量形容词堆砌的散文
4. 写成长期人格定性
5. 一次给多个并列建议

## 8. 推荐 Prompt 骨架

当前建议 prompt 可按下面顺序组织指令：

1. `角色定义`
   - 你要生成的是一份 `Lite / 全面解读`
2. `任务定义`
   - 先看清当前整体状态，而不是做深层剖析
3. `输入说明`
   - 画作、意图、过程感受、默认 general 主题
4. `输出结构`
   - 标题、命中、依据、解释、连接、下一步
5. `语气要求`
6. `禁止项`
7. `输出前自检`

## 9. 输出前自检

prompt 末尾建议加上下面 6 条自检要求：

1. 开头是否前两句就出现命中
2. 是否有清楚的画面依据
3. 是否解释了为什么现在会这样
4. 是否落到真实生活面向
5. 是否没有越界写成深层机制分析
6. 是否只保留了一个低压下一步

## 10. 当前阶段收束结论

基于以上提纲，当前建议先收束到下面 4 个判断：

1. `Lite / 全面解读` 的 prompt 核心是低压命中，不是内容铺陈
2. `画作 + 过程感受` 应是这版最重要的输入组合
3. 输出结构必须固定收束为 `6` 段
4. 这份 prompt 的成功标准，是让用户觉得“被看见且不过重”
