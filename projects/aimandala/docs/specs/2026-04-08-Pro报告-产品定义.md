## 1. 目的

本文件用于统一定义 `Pro` 这一层商品，而不是再拆成四份看起来像不同一级产品的文档。

当前要回答的是：

1. `Pro` 到底是什么
2. `Pro` 主要服务谁
3. `Pro` 为什么同时支持 `全面解读` 与 `专题解读`
4. 两种解读方向的差异到底在哪里
5. `Pro` 与 `Lite`、`Journey` 的边界是什么

## 2. 当前收束判断

本轮先收束到下面 6 个判断：

1. `Pro` 是一级商品，不再拆成多个一级报告名
2. `Pro` 只有两种解读方向：
   - `全面解读`
   - `专题解读`
3. 用户没有选主题时，默认进入 `Pro / 全面解读`
4. 用户选了主题时，可以进入 `Pro / 专题解读`
5. 两种方向的价格仍属于同一层 `Pro`
6. `Pro` 仍然是基于单次画作的完整正式解读，不越界承担 `Journey`

## 3. 产品定位

`Pro` 的一句话定义是：

- 帮用户把这次画作真正看清楚，要么看清整体状态，要么围绕一个已选主题看清问题结构

它的本质是：

- `单次画作下的完整正式解读`

它不是：

- `Lite` 的加长版
- 只多一点字数的高价版
- 多次历史画作分析
- 训练计划
- 连续陪伴本身

## 4. 核心目标用户

### 4.1 第一优先用户

- `看懂自己型`

典型心态：

- “我不只想被接住，我想真正看明白自己现在怎么了。”
- “我想知道这张画到底在表达什么。”

### 4.2 第二优先用户

- `议题解决型`

典型心态：

- “我已经知道自己卡在关系、边界、表达或事业里。”
- “我想知道为什么这个问题会反复出现。”

### 4.3 可兼容用户

- `情绪安放型` 中已经愿意继续往下看的人

典型心态：

- “我先被接住了，但我不想只停在安慰。”

### 4.4 不优先服务的用户

以下用户不应默认由 `Pro` 主承接：

1. 当前承载力较低、只适合低压进入的用户
   - 更适合 `Lite`
2. 只有一次输入、但已经明确想看跨时间重复机制的用户
   - 当前也不能直接进入 `Journey`
3. 高复杂度支持型用户
   - 不应由 AI 报告主承接

## 5. Pro 的两种解读方向

## 5.1 全面解读

`Pro / 全面解读` 更适合回答：

- “我现在整体处在什么状态？”
- “这次画里最主要的拉扯和模式是什么？”

它更强调：

1. 从模糊到明白
2. 当前整体状态的整理
3. 主模式命名
4. 与现实生活的连接
5. 一个清楚但不压迫的下一步

## 5.2 专题解读

`Pro / 专题解读` 更适合回答：

- “为什么这个问题总卡在这个主题里？”
- “这张画为什么会指向关系 / 边界 / 情绪 / 表达 / 事业？”

它更强调：

1. 主题为什么成立
2. 该主题里的核心拉扯
3. 现实中的典型场景
4. `触发 -> 自动反应 -> 强化结果` 的最小闭环
5. 围绕该主题成立的下一步

## 5.3 共同点

两种方向虽然正文重心不同，但都属于同一个 `Pro` 商品层，共同承担下面 5 个一级任务：

1. 被看见
2. 被解释
3. 被命名
4. 被连接
5. 被指引

## 6. Pro 的共同成立标准

一份成立的 `Pro` 报告，至少要同时满足下面 6 条：

1. 开头有明显命中感
2. 画面依据与判断之间有稳定解释链
3. 能命名状态、拉扯或模式
4. 能落回现实生活，而不是停在抽象判断
5. 只给一个清楚主路径，不泛、不散
6. 主题存在时，正文结构真的发生变化，而不是只换标题

## 7. 与 Lite、Journey 的边界

## 7.1 与 Lite 的边界

`Lite` 负责：

- 先看见当前状态
- 先让用户低压进入

`Pro` 负责：

- 把这次输入看得更完整、更清楚

关键差异：

1. `Pro` 必须有更稳定的解释链
2. `Pro` 必须有模式命名
3. `Pro` 必须有更清楚的现实连接

## 7.2 与 Journey 的边界

`Journey` 负责：

- 基于多次历史画作解释重复机制与优先级

`Pro` 负责：

- 把单次画作做成完整正式解读

关键差异：

1. `Pro` 不做跨时间稳定判断
2. `Pro` 不假装已经看见最深层机制
3. `Pro` 的深度来自单次输入的完整性，不来自历史序列分析

## 8. 输入利用逻辑

`Pro` 当前默认应吃四层输入：

1. `主题`
   - 决定进入 `全面解读` 还是 `专题解读`
2. `绘画前意图`
   - 至少参与两处判断
3. `绘画过程中的感受`
   - 应进入解释链主段，而不是只做备注
4. `画作本身`
   - 仍是最主要的证据来源

## 9. 最小可交付版本

当前建议 `Pro` 的最小可交付单元为：

1. 一份单次画作的完整正式报告
2. 同一商品层下支持：
   - `全面解读`
   - `专题解读`
3. 报告正文至少覆盖：
   - 开头命中
   - 画面依据
   - 状态解释
   - 模式命名
   - 现实连接
   - 一个下一步

## 10. 结果页承接原则

`Pro` 的结果页不应把用户重新推回一堆套餐，而应优先给出最自然的下一步。

当前建议：

1. `Pro / 全面解读`
   - 更适合承接到 `Pro / 专题解读`
   - 或进入 `陪你画`
   - 或在积累多次历史画作后进入 `Journey`
2. `Pro / 专题解读`
   - 更适合承接到 `主题方案`
   - 或同主题再画一幅
   - 或在积累多次历史画作后进入 `Journey`

## 11. 当前阶段最重要的收束结论

基于以上定义，当前建议先收束到下面 5 个判断：

1. `Pro` 才是一级商品，`全面解读 / 专题解读` 只是它的两种解读方向
2. 两种方向应放在同一套产品定义里说明，不再各写成一级报告
3. `Pro` 的价值不在“更长”，而在“更完整地看清楚”
4. `Pro` 仍然只处理单次画作，不越界承担 `Journey`
5. 后续页面、字段、结果页分流都应回到这份母定义统一校验
