## 1. 目的

本文件用于定义 `Pro / 专题解读` 的 prompt 提纲。

它重点回答：

1. 这一版如何围绕用户已选主题生成完整正式解读
2. 怎样把主题真正写进正文主线
3. 怎样和 `Lite / 专题解读`、`Pro / 全面解读` 拉开差异

## 2. 这份 Prompt 要完成什么

`Pro / 专题解读` 要生成的是：

- 一份围绕用户已选主题展开、具有清楚主题判断、问题结构和现实场景解释的单次正式解读

它最核心要完成的 5 件事是：

1. 确认为什么是这个主题
2. 解释这个主题里的核心拉扯
3. 说明这个问题为什么会反复出现
4. 落到主题相关的现实场景
5. 给一个围绕该主题成立的主方向

## 3. 输入优先级

当前建议 prompt 按下面顺序使用输入：

1. `主题`
   - 这是这版成立的前提输入
2. `画作本身`
   - 主要证据来源
3. `绘画前意图`
   - 用于判断用户为什么会带着这个问题进入
4. `绘画过程中的感受`
   - 用于补强主题里的拉扯与自动反应

## 4. 生成目标

prompt 应明确要求模型输出下面 7 段内容：

1. `标题`
2. `主题命中开头`
3. `画面为何指向这个主题`
4. `该主题里的状态解释`
5. `该主题里的模式或问题闭环`
6. `该主题的现实连接`
7. `一个围绕该主题的主方向`

## 5. 每段生成要求

## 5.1 标题

要求：

1. 要带出明确主题感
2. 不能太泛
3. 要能承接后面的问题主线

## 5.2 主题命中开头

要求：

1. 第一段就要让用户知道这份报告在讲哪个主题
2. 开头既要命中用户，也要命中问题
3. 不要先写泛人格结论

## 5.3 画面为何指向这个主题

要求：

1. 必须说明为什么是这个主题，而不是别的主题
2. 至少给出 `2-4` 个关键画面锚点
3. 画面、意图、过程感受应从这里开始共同支持主题判断

## 5.4 该主题里的状态解释

要求：

1. 解释用户在这个主题里现在正经历什么
2. 至少形成 `依据 -> 状态 -> 拉扯` 的递进
3. 不要只写笼统人格描述

## 5.5 该主题里的模式或问题闭环

要求：

1. 至少形成 `触发 -> 自动反应 -> 强化结果` 的最小闭环
2. 闭环必须围绕该主题成立
3. 不要越界写成多次历史模式分析

## 5.6 该主题的现实连接

要求：

1. 至少落一个高相似度现实场景
2. 让用户知道这件事平时怎么发生
3. 要比 `Lite / 专题解读` 更具体、更完整

## 5.7 一个围绕该主题的主方向

要求：

1. 只给一个主路径
2. 方向要围绕该主题成立
3. 当前更适合落到同主题的继续观察、`再画一幅` 或页面内辅助延伸

## 6. 语气要求

prompt 应明确要求生成语气满足下面 5 条：

1. 聚焦
2. 清楚
3. 有解释力
4. 不训导
5. 有方向感但不过度推进

## 7. 明确禁止项

prompt 应明确禁止下面写法：

1. 标题有主题，正文还是通用深度文
2. 写成更长的 `Pro / 全面解读`
3. 写成单次画作无法支撑的深层根源分析
4. 场景不具体，只讲抽象判断
5. 一次给多个并列路径

## 8. 推荐 Prompt 骨架

当前建议 prompt 可按下面顺序组织指令：

1. `角色定义`
   - 你要生成的是一份 `Pro / 专题解读`
2. `任务定义`
   - 围绕用户已选主题，做一份完整正式解读
3. `输入说明`
   - 主题、画作、意图、过程感受
4. `输出结构`
   - 标题、命中、依据、解释、闭环、连接、主方向
5. `语气要求`
6. `禁止项`
7. `输出前自检`

## 9. 输出前自检

prompt 末尾建议加上下面 7 条自检要求：

1. 开头是否明确带出主题
2. 是否解释了为什么是这个主题
3. 是否存在一条可复述的主题解释链
4. 是否形成了最小问题闭环
5. 是否落到了具体现实场景
6. 是否只保留了一个主方向
7. 是否没有越界写成 `Journey`

## 10. 当前阶段收束结论

基于以上提纲，当前建议先收束到下面 4 个判断：

1. `Pro / 专题解读` 的核心不是“更聚焦而已”，而是主题真的改变了解释链
2. `主题 + 画作 + 意图 + 过程感受` 必须共同支撑这版输出
3. 输出结构必须固定收束为 `7` 段
4. 这份 prompt 的成功标准，是让用户觉得“这个问题终于被讲清楚了”
