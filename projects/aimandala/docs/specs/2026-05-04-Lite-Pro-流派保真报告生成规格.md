## 1. 问题定义

当前 Lite / Pro 报告能生成，但用户可见正文仍偏向泛化心理叙述。核心问题不是文案不够顺，而是报告没有稳定呈现一镜一梳自己的解读流派判断链。

本轮要关闭的缺口是：

1. `Layer 0` 已经有逐圈颜色、元素与深浅状态，但 narrative 层只消费成“内圈火、深浅居中”这类视觉摘要。
2. 主题知识包中已有 `主题 × 元素 × 色阶 × 圈层` 的解释、现实表现和疗愈方向，但 Lite / Pro 正文没有稳定取用。
3. 失衡判断可以进入 Pro，但它没有先建立在逐圈主题状态链上，容易显得像系统自行发挥。

## 2. 目标行为

Lite / Pro 生成时必须构建 `school_interpretation_chain`，每一圈至少包含：

1. 圈层：`inner / middle / outer` 与中文标签
2. 元素：如 `火 / 金 / 木`
3. 色阶：如 `中红 / 中白`
4. 状态：`太过 / 正常 / 不足 / 未判定`
5. 主题解释：来自当前主题包的 `interpretation`
6. 现实表现：来自当前主题包的 `manifestation` 或 `manifestations`
7. 疗愈方向：来自当前主题包的 `healing`
8. 来源：主题包路径与查询键

## 3. 本轮范围

本轮只修 Lite / Pro 报告生成主链：

1. 补齐主题色义查询对当前主题包结构的兼容。
2. 在 narrative plan 中生成流派判断链。
3. Lite 的“画面依据”必须能看到逐圈主题状态解释。
4. Pro 的“三圈证据/证据摘要”必须逐圈呈现主题状态解释。
5. debug / prompt skeleton 中必须保留结构化链条，便于后续 fidelity 检查。

## 4. 不做范围

本轮不做：

1. 重写全部报告合同。
2. 重训或重写 LLM 生成策略。
3. 修改原始知识包内容。
4. 新增前端页面结构。
5. 重新定义 20 种失衡体系。

## 5. 验收标准

固定财富事业样本 `toc-mvp-fixture-002` 至少满足：

1. Lite 报告包含 `中圈：金 / 中白 / 正常` 及财富事业主题解释。
2. Lite 报告包含来自主题包的具体句子，例如 `当下财务规划良好`。
3. Pro 三圈证据包含逐圈的元素、色阶、状态、主题解释、现实表现和疗愈方向。
4. narrative plan 的 `evidence_trace_summary.school_interpretation_chain` 有三圈结构化条目。
5. 主题色义查询同时支持：
   - `shades.<shade>.circles.<中文圈层>`
   - `shades.<shade>.<inner|middle|outer>`

## 6. 下一阶段

进入 implementation 前，先补测试锁定以上验收标准；实现完成后重导出 Lite / Pro golden，并补验证记录。
