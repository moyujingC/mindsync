## 4. 当前联调时应优先区分的两件事

### 4.1 preview vs runtime

- preview
  - 适合看页面壳
  - 不等于真实接口已经打通
- runtime
  - 才是正式联调路径

### 4.2 本地联调 vs 线上运维
