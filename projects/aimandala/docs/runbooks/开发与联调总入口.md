## 2. 当前最小启动路径

### 2.1 启动后端

```bash
cd $REPO_ROOT
export PYTHONPATH=$PROJECT_ROOT/toC/app/backend
uvicorn app.api.main:app --reload --host 127.0.0.1 --port 8000
```

健康检查：

```bash
curl -s http://127.0.0.1:8000/health
```

后端入口文档：

- [../../toC/app/backend/README.md](../../toC/app/backend/README.md)

### 2.2 启动前端

```bash
cd $PROJECT_ROOT/toC/app/frontend
npm run dev:mobile-web
```

前端入口文档：

## 4. 当前联调时应优先区分的两件事

### 4.1 preview vs runtime

- preview
  - 适合看页面壳
  - 不等于真实接口已经打通
- runtime
  - 才是正式联调路径

### 4.2 本地联调 vs 线上运维

- 本地联调
- 先看本页和 [本地联调手册.md](本地联调手册.md)
- 线上运维
  - 转到 [服务器部署与运维手册.md](./服务器部署与运维手册.md)
