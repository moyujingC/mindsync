## 5. 配置 handoff

本地 / staging 建议配置：

```bash
AIMANDALA_LLM_BACKEND=openai_compatible
AIMANDALA_LLM_MODEL=deepseek-v4-pro
AIMANDALA_LLM_CHAT_MODEL=deepseek-v4-pro
AIMANDALA_LLM_VISION_BASE_URL=https://ark.cn-beijing.volces.com/api/v3
AIMANDALA_LLM_VISION_MODEL=ep-20260316095322-94wf5
AIMANDALA_LLM_VISION_API_KEY=<VOLCENGINE_ARK_API_KEY>
AIMANDALA_LLM_VISION_FALLBACK_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
AIMANDALA_LLM_VISION_FALLBACK_MODEL=qwen-vl-max-latest
AIMANDALA_LLM_VISION_FALLBACK_API_KEY=<DASHSCOPE_API_KEY>
```

注意：

- API key 只进入私有 env 或部署密钥系统，不进入仓库。
- 生产配置切换必须另开 production change record。
- 如果文字模型仍未接入 DeepSeek V4，本轮不阻塞视觉默认接入；报告正文当前仍走 knowledge-first 本地主链。

## 6. 失败降级 handoff

执行顺序：

1. 豆包视觉：`AIMANDALA_LLM_VISION_*`
2. Qwen fallback：`AIMANDALA_LLM_VISION_FALLBACK_*`
3. 低置信度 LLM fallback：`method=llm_fallback`
4. 默认几何建议：`method=default`

产品侧处理：

- `llm_vision`：自动进入报告。
- `llm_vision_estimated`：可进入报告，但后续可在 UI 提示“估计识别”。
- `llm_fallback` / `default`：引导用户手动三圈或重试，不应作为高可信自动识别。
- 上传失败 / 图片不存在 / 后端 5xx：提示重试，不生成报告。
