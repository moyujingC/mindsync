这份文档用于给 `aimandala` 当前架构材料提供一个总览入口。

它不替代各专项架构文档，而是帮助快速回答三个问题：

1. 当前主系统由哪些关键子系统组成
2. 哪些文档负责解释这些子系统
3. 当我要理解或调整某一块架构时，应先看哪里

## 3. 与 spec / runbook 的边界

- `spec`
  - 回答做什么
- `architecture`
  - 回答怎么搭、怎么分层、为什么这样搭
- `runbook`
  - 回答怎么跑、怎么联调、怎么操作
