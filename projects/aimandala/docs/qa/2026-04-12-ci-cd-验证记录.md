## 1. 验证对象

本次验证对象为 `2026-04-12` 新增的 CI/CD、nightly smoke、Paperclip 故障路由与 auto-repair 基础设施。

## 2. 验收口径

### 2.1 目标行为

1. 共享脚本能够通过 Node 语法检查
2. dev / prod 的 basic smoke 脚本可直接执行
3. workflow 文件已经拆分为 `ci / deploy / nightly-smoke / auto-repair`
4. Paperclip 脚本支持聚合键与标签路由
5. 自动修复脚本只对白名单失败点工作

### 2.2 不在本轮验证范围

1. GitHub 上真实 runner 执行
2. GitHub Secrets / vars 在线配置
3. auto-repair 调用真实外部修复命令
4. runner watchdog 的跨主机 cron 落地

## 4. 风险判断

- 当前结论：`通过（本地与脚本层）`
- 当前残留风险：
  1. workflow 尚未在真实 self-hosted runner 上跑通
  2. Paperclip issue create/update 尚未在 GitHub Actions 运行态用真实 API 配置验证
  3. auto-repair 默认依赖外部 `AIMANDALA_AUTO_REPAIR_COMMAND`，未配置时只会建单不改代码
  4. 当前环境没有 `actionlint`，GitHub Actions 语义级 lint 仍建议在后续补上
