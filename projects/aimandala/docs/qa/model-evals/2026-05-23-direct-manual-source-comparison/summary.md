# 2026-05-23 直给手册原文 vs 结构化链路对比

## 结论

这次实验里，把完整的《曼陀罗解读手册原文》直接给视觉模型，再只加一句“按财富议题解读”，效果明显优于当前结构化链路的报告写作结果。

## 观察到的差异

### 1. 视觉识别更贴图

直给手册原文后，模型更容易把画面读成“整体画面 + 圈层结构 + 元素关系”的连续叙事，而不是先被一堆结构约束切碎。

### 2. 解释更像疗愈师

直出结果的语气更自然，能把画面感、财富感受和后续展开串起来，读起来更像在带用户看画，而不是在填模板。

### 3. 手册流派味道更完整

模型更容易沿着原手册的表达节奏去写，保留了那种“先看图，再顺着图讲”的方式，而不是被当前的提示词强行拉成通用心理报告。

## 现阶段的判断

当前的结构化链路仍然有价值，尤其适合：

- 作为视觉证据的稳定入口
- 作为后续报告生成的中间数据
- 作为质量门和回归测试的锚点

但如果目标是尽快做出“读起来像疗愈师”的财富报告，报告写作这一步很可能应该更靠近完整手册原文，而不是继续增加硬约束。

## 建议

1. 保留结构化视觉识别链路。
2. 报告写作层改成“手册原文 + 少量目标约束”的模式。
3. 先不要继续加细碎 prompt 规则，先确认这条直出路线的上限。
4. 后续再决定要不要把手册拆成“风格锚点 + 规则锚点 + 输出模板”三层。
