## 极简 Prompt 测试结论

- 改善点：
  - 输出明显更像自然观察，不再像规则清单填空。
  - 段落更顺，整体画面感、三圈视觉衔接、留白描述更易读。
  - 没有出现 JSON、机器标签或跨圈五行泄漏，质量门通过。
- 未改善点：
  - 蓝色三角形仍被归入中圈，和人工审核基准不一致。
  - 中圈仍被读成“浅蓝三角形 + 粉红菱形”，没有回到“粉色方块/近似方块 + 内部三角形”的人工基准。
  - 简化 prompt 可以改善语言质量，但不能解决圈层边界识别问题。

## 当前判断

- `observe.md` 不宜回到长规则清单；极简版更适合作为视觉观察任务入口。
- 圈层归属问题不应继续靠自然语言 prompt 硬压，下一步应考虑程序层或图像预处理层：例如裁出三圈区域分别传入模型，或为模型提供三张圈层裁剪图，而不是只靠一张标记图。

## 人工评审建议

- 先看视觉一致性，再看财富主线，再看疗愈师带读感。
- 如果 B 更自然，优点只反哺 A，不直接替换生产默认。
