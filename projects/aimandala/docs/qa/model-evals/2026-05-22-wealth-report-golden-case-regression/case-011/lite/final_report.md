回到财富这条主线，你内在其实一直有一个清楚而稳定的“我有什么价值”的认知，不是没有能力，也不是不愿意成长。问题在于，你内心有太多规则、标准和评判，像画面里一层层的留白那样，把你原本可以顺畅给予自己的肯定与滋养隔开了。这些标准甚至可能让你习惯性地用赚钱、成绩或别人的认可，来证明自己值得被看见。于是，外圈那些想去行动、想去创造财富的能量，虽然很多，却缺少内在情感的持续滋养，显得分散、用力而且疲惫，好像每一片叶子都在独自承担生长的压力。
