## 4. 当前仍需注意

这次冻结能阻断新的服务器端自动写入，但不会自动清理历史脏状态。

已知仍需单独处理：

1. `/opt/automation/app/mindsync` 已有脏改
2. `/opt/paperclip/app/paperclip` 仍是 dirty canary
3. `MIN-202` / `MIN-208` 仍是 execution workspace materialization 阻断样本
4. 恢复 heartbeat 前，需要先确认巡检区已同步到包含 `paperclip-multi-project-heartbeat.mjs` 的提交

## 5. 恢复条件

恢复服务器端自动写入前，至少需要满足：

1. 主镜像区和巡检区已清理或有正式解释
2. `paperclip-heartbeat.service` 能以只读模式成功运行
3. execution health strict gate 通过
4. 目标任务确实属于服务器必须执行的 deploy / smoke / maintenance
5. 用户明确批准临时解除 `PAPERCLIP_SERVER_AUTOMATION_FREEZE=1`
