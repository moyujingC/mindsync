## 6. 结论

当前建议：

1. `AIMANDALA_LLM_VISION_MODEL` 的第一生产候选先定为 `qwen-vl-max-latest`。
2. `glm-4v-plus` 作为备选模型保留。
3. `Doubao-Seed-1.6-vision` 暂不进入生产候选，先排查火山方舟 model id / endpoint / 图片输入协议是否正确。
4. Kimi 视觉模型未纳入本轮，因为本机尚未配置 `MOONSHOT_API_KEY` 和真实 Kimi 视觉 model id。

## 7. 后续动作

- 对 `qwen-vl` 与 `glm-vision` 做第二轮人工细看，重点比较三圈边界是否真的贴合图片，而不是只看结构化输出是否完整。
- 排查豆包视觉接口，确认 `Doubao-Seed-1.6-vision` 是否为可直接用于 OpenAI-compatible `chat/completions` 的 model id。
- 如补齐 Kimi API key 和 model id，再执行第二轮 4 模型对比。
- 在正式配置 `AIMANDALA_LLM_VISION_MODEL` 前，再用胜出模型跑一次端到端三圈识别 smoke。
