## 6. 结论

当前建议：

1. `AIMANDALA_LLM_VISION_MODEL` 的第一生产候选先定为 `qwen-vl-max-latest`。
2. `ep-20260316095322-94wf5` 作为并列候选进入第二轮人工细看。
3. `glm-4v-plus` 作为备选模型保留。
4. Kimi 视觉模型未纳入本轮，因为本机尚未配置 `MOONSHOT_API_KEY` 和真实 Kimi 视觉 model id。

## 7. 后续动作

- 对 `qwen-vl`、`doubao-vision` 与 `glm-vision` 做第二轮人工细看，重点比较三圈边界是否真的贴合图片，而不是只看结构化输出是否完整。
- 豆包后续应固定使用火山方舟接入点 `ep-20260316095322-94wf5`，不再使用 `Doubao-Seed-1.6-vision` 作为直接调用 model id。
- 如补齐 Kimi API key 和 model id，再执行第二轮 4 模型对比。
- 在正式配置 `AIMANDALA_LLM_VISION_MODEL` 前，再用胜出模型跑一次端到端三圈识别 smoke。
