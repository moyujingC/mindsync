## 解读过程链

这部分用于 QA 复盘：最终报告的表达可以沿用优化后的自然文案，但底层推导必须能回到原始解读手册的顺序。

- `stage-00-input-context` 输入上下文：先记录用户主题、创作意图、创作感受和图像引用，避免后续报告脱离用户当下问题。
- `stage-01-theme-selection` 确定解读主题：按手册要求先确定解读重点，再进入三圈和细节判断；本次主题会作为后续所有判断的投影口径。
- `stage-02-circle-boundary-decision` 确定三圈边界并锁定：按手册先定三圈，定完后不在解读中来回改动；QA 需要检查这一步是否明确留下边界和来源。
- `stage-03-direct-judgment-high-hit-check` 直断法高命中检查：直断法不是切入点选择，而是在三圈锁定后先检查高命中特征；命中项只能作为快速抓手，后续必须被逐圈颜色、形状和生克关系继续验证。
- `stage-04-per-circle-visual-evidence` 逐圈画面依据：先把每一圈可见的颜色、形状、比例、填充和结构说清楚，再进入状态解释；这是最终画面依据区的来源。
- `stage-05-per-circle-color-shape-element-reading` 逐圈颜色、形状与圈内生克解读：依据原始手册逐圈看颜色、深浅、面积、形状及本圈内部五行生克；用户可见正文要少术语，把关系翻译成现实状态。
- `stage-06-per-circle-imbalance-candidates` 逐圈失衡候选：失衡状态应在逐圈颜色、形状和圈内生克解读过程中浮现，而不是先给一个抽象标签再回填证据。
- `stage-07-whole-energy-flow-synthesis` 整体能量流动综合：逐圈解读之后再看整体；这里看的不是简单圈与圈之间的五行关系，而是内在、关系和外在呈现之间的能量流动是否顺、堵、倒灌或跳跃。
- `stage-08-conflict-blockage` 找冲突、卡点、堵点：在主题和画面证据基础上找到当前最影响用户的卡点，而不是泛泛讲所有主题。
- `stage-09-healing-goal` 建立调节目标：只有在判断成立后才给方向；Lite 给轻量觉察，Pro 给更完整的行动/清理/调节路径。
- `stage-10-lite-draft` Lite 过程稿：Lite 仍可使用上一版优化后的自然表达，但必须从前面证据链映射到字段。
- `stage-11-pro-draft` Pro 过程稿：Pro 不是 Lite 加长版，而是在同一手册逻辑上展开机制、根因链和调节方案。
- `stage-12-final-report` 最终报告：最终呈现可以是自然报告文案，但 QA 必须能从最终字段倒查到上面的手册推导链。

### 当前整体判断

第一眼先看到的，不是你要不要马上往前冲，而是你正在把自己重新收回来，确认现在这份力气能不能稳稳地落在自我认知与价值确立上。 如果把创作时的“先如实看看这张画带出来的感受，不急着下结论。”也放进来看，身体像是在提醒你：先观察清楚，不必急着下结论。 再往里看，三圈的走向也在说明同一件事：三圈依次呈现出「火 -> 金 -> 木」的变化。 所以这不是简单的停住，而更像你先把内在安顿好，再慢慢把成长、自主、创造带回现实。 它也提醒你：你正处在旧节奏尚未完全退场、新节奏又开始拉扯的过渡期。

### 画面依据

如果只看画面给人的感受，最先浮出来的是两股力量：一股是「金」的收拢和判断，另一股是「木」想把事情重新带回现实。 三层画面的走向也很清楚：这说明你仍优先保护核心边界，再逐步恢复向外连接。 换句话说，最里面这一层常会照见自我关系、原生家庭、过往伤痛、自我价值，现在更突出的是「火」特质。 放到现实里，往往会连到对自己的看法和自我认知 / 原生家庭带来的创伤或滋养 / 过往伤痛的疗愈状态；中间这一层更容易落到亲密关系、爱人/闺蜜/亲朋，现在更突出的是「金」特质。 放到现实里，往往会连到当前情感状态 / 与亲密他人的关系质量 / 情感表达方式。 从逐圈观察看，内圈主要呈现「火」的状态，颜色偏深，填充稳定，面积约10.9%；中圈主要呈现「金」的状态，深浅居中，填充稳定，面积约32.7%；外圈主要呈现「木」的状态，深浅居中，填充稳定，面积约56.4%

### 模式解释

情绪上，你现在不像没感觉，反而像一直在心里默默处理自我认知与价值确立这件事。 而最外层落出来的「木」感，也说明你并不是想完全退回去，只是想先弄清楚，接下来该用什么边界和姿态继续向外。 也因为内在深度与直觉智慧暂时偏弱，所以一旦节奏变快，你更容易先退回来，等自己重新有把握了再动。 这和你现在的状态也很像：你正处在旧节奏尚未完全退场、新节奏又开始拉扯的过渡期。 如果把创作时的“先如实看看这张画带出来的感受，不急着下结论。”也放进来看，身体像是在提醒你：先观察清楚，不必急着下结论。

久而久之，这会形成你的惯用模式：火克金，认知克制情感表达。你通常不是直接冲，而是先在心里把事情转过一遍，感觉对了才真正迈出去。

为了不再乱掉，你会自然长出一种防御：更强调清晰、距离感和判断标准。它看起来像「木」的收紧，但本质上是在替现在的你筛选什么值得继续打开。

当前最容易卡住你的，不是没有方向，而是主导能量和现实节奏还没完全接上。 尤其当内在深度与直觉智慧还没跟上时，你会在快要推进的那一刻先退回来。 这也是为什么你会反复遇到这样的卡点：你正处在旧节奏尚未完全退场、新节奏又开始拉扯的过渡期。

### 现实连接

在「通用解读」里，你最常出现的场景是：不是没有机会，而是每次准备投入时，都会先问自己现在这样推，会不会又把自己推乱。因为画面里更强的那股力量，会先把注意力拉回自我认知与价值确立。

这会让你在面对关键事情时，更在意稳不稳、清不清楚、承不承受得住，而不是先求快。 当内在深度与直觉智慧还偏少时，你也会更需要一点缓冲和回收。

这幅画提醒你的，不是逼自己立刻更强，而是先承认：你想稳住，不等于你退缩；只要先把自己接住，后面的行动会自己长出来。 你正处在旧节奏尚未完全退场、新节奏又开始拉扯的过渡期。
