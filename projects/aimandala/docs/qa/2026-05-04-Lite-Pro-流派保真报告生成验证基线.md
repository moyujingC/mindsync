## 1. 验证对象

验证 Lite / Pro 报告是否真正消费一镜一梳解读流派的中间判断链，而不是只消费压平后的 dominant element 和 imbalance projection。

## 2. 必测项

1. `ThemeService.get_theme_color_interpretation`
   - `wealth_career + 金 + 中白 + middle` 返回主题解释。
   - `wealth_career + 金 + 中白 + 中圈` 返回同一主题解释。
2. Lite 固定样本
   - `visual_elements_rendered` 包含逐圈判断链。
   - 至少包含 `中圈：金 / 中白 / 正常`。
   - 至少包含财富事业主题包原始解释 `当下财务规划良好`。
3. Pro 固定样本
   - `three_circles_detailed.middle.reading` 包含 `中圈：金 / 中白 / 正常`。
   - `three_circles_detailed.outer.reading` 包含财富事业主题解释。
4. Debug / narrative plan
   - `evidence_trace_summary.school_interpretation_chain` 有 3 条。
   - 每条至少包含 `circle / element / shade / state / interpretation / healing`。

## 3. 回归验证

实现完成后至少执行：

1. `pytest projects/aimandala/toC/app/backend/tests/unit/test_knowledge_runtime_v21.py -q`
2. `pytest projects/aimandala/toC/app/backend/tests/unit/test_pipeline_orchestrator.py -q -k 'school_interpretation_chain or wealth_career_reports_use_imbalance_direction_not_secondary_element'`
3. `python3 projects/aimandala/scripts/export_fixture_golden.py --fixture-id toc-mvp-fixture-001 --version lite`
4. `python3 projects/aimandala/scripts/export_fixture_golden.py --fixture-id toc-mvp-fixture-002 --version lite`
5. `python3 projects/aimandala/scripts/export_fixture_golden.py --fixture-id toc-mvp-fixture-002 --version pro`
6. `python3 projects/aimandala/scripts/validate_fixtures.py`

## 4. 通过条件

所有必测项通过，且重新导出的 golden 不再呈现只有泛化心理叙述、没有主题状态判断链的问题。
