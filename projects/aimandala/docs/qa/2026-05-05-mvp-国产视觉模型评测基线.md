这份 QA 基线用于定义 Aimandala MVP 阶段国产视觉大模型的最小评测标准。

评测目标不是判断模型“总体是否聪明”，而是判断它是否适合 `三圈识别` 这个具体任务。

## 1. 目标行为

被测视觉模型需要基于曼陀罗图片输出可用于三圈识别的结构化观察。

至少应覆盖：

- 画面中心位置
- 外圈 / 中圈 / 内圈的大致边界
- 主要颜色块
- 明显的偏移、空白、拥挤或断裂
- 可支撑后续 Lite / Pro 报告的视觉依据

## 2. 样本范围

本轮优先使用现有脱敏 fixture：

- `toc-mvp-fixture-001`
  - 图片：`projects/aimandala/fixtures/toc-mvp/assets/IMG_5057.jpeg`
  - 用途：Lite 基线样本
- `toc-mvp-fixture-002`
  - 图片：`projects/aimandala/fixtures/toc-mvp/assets/IMG_5060.jpeg`
  - 用途：Pro 正式链路样本
- `toc-mvp-fixture-003`
  - 用途：补充泛化样本
- `toc-mvp-fixture-004`
  - 用途：补充泛化样本

如需扩大样本，优先从 `assets/IMG_5065.jpeg`、`assets/IMG_5067.jpeg`、`assets/IMG_5075.jpeg`、`assets/IMG_5079.jpeg`、`assets/IMG_5081.jpeg` 中补入。

## 3. 候选模型要求

候选视觉模型必须满足：

- 国产或国产可控入口
- 支持图片输入
- 支持中文输出
- 可用于生产用户数据主链路
- 有明确 API 计费与稳定服务入口
- 可通过 Aimandala 后端或 RelayHub 形成可复现调用

## 4. 评测输出格式

每个模型对每张样本图至少输出：

```json
{
  "fixture_id": "toc-mvp-fixture-001",
  "model": "<model-id>",
  "center_observation": "...",
  "circle_boundaries": {
    "inner": "...",
    "middle": "...",
    "outer": "..."
  },
  "dominant_colors": ["..."],
  "structure_notes": ["..."],
  "risk_flags": ["..."],
  "confidence": "high | medium | low"
}
```

## 5. 通过标准

单个模型进入 MVP 默认候选，必须满足：

- 在至少 4 个正式 fixture 中，3 个样本达到人工可用。
- 不出现明显幻觉，例如看见不存在的大型对象、文字、人物或图案。
- 能稳定区分中心、外圈、中圈、内圈的大致结构。
- 输出能支持后续报告中的 `visual_basis`，而不是只给泛泛描述。
- 对不确定区域会说明不确定，而不是强行断言。
- 平均响应时间和错误率不阻塞上传后生成体验。

## 6. 淘汰标准

出现任一情况，应暂不作为默认生产候选：

- 无法可靠读取图片。
- 经常把画作描述成无关场景。
- 大量输出心理诊断结论，而不是视觉结构观察。
- 对三圈边界判断持续混乱。
- API 稳定性不足，连续出现超时、限流或无法复现。
- 不满足生产用户数据边界要求。

## 7. 人工评审维度

人工评审采用 Pass / Fail，不使用 1-5 分均值。

每条输出判断：

- `structure_pass`
  - 是否看清主要结构
- `circle_pass`
  - 是否能服务三圈识别
- `color_pass`
  - 是否抓住主要颜色与对比
- `grounding_pass`
  - 是否基于图片，不胡编
- `product_pass`
  - 是否能进入 MVP 生产候选

最终只看：

- 每个模型通过多少样本
- 失败原因集中在哪些模式
- 是否存在不可接受的生产风险

## 8. 最小验证记录

完成评测后，应新增一份验证记录，至少包含：

- 候选模型列表
- 每个模型的调用配置或入口
- 每张 fixture 的原始输出路径
- 人工 Pass / Fail 表
- 主要失败模式
- 推荐默认视觉模型
- 备选视觉模型
- 是否建议经 RelayHub 接入

## 9. 不在本轮评测范围

- 不评估完整心理疗愈效果。
- 不评估 Lite / Pro 全文报告质量。
- 不评估支付、历史记录、上传存储等产品链路。
- 不比较国外视觉模型。
- 不把开发用第三方中转纳入生产候选。
