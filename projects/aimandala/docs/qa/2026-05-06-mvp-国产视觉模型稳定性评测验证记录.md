说明：

- 三个候选都没有 API 层失败或空输出。
- 三个候选在同一 fixture 的 3 轮输出都不是逐字完全一致，说明模型输出存在自然语言层面的漂移。
- `doubao-vision` 的 confidence 最稳定，全部为 `high`。
- `qwen-vl` 输出通常最细，但耗时最高。
- `glm-vision` 最快，但描述更概括，且经常把“无风险”写入 `risk_flags`，后续产品接入前需要做字段语义清洗。

## 5. 人工评审初判

| candidate | structure_pass | circle_pass | color_pass | grounding_pass | product_pass | stability_pass |
| --- | --- | --- | --- | --- | --- | --- |
| `doubao-vision` | Pass | Pass | Pass | Pass | Pass | Pass |
| `qwen-vl` | Pass | Pass | Pass | Pass | Pass | Pass |
| `glm-vision` | Pass | Conditional | Pass | Conditional | Conditional | Conditional |

人工初判口径：

- `structure_pass`：能稳定识别中心、层次和放射/对称结构。
- `circle_pass`：能稳定描述内圈、中圈、外圈边界，不把三圈混成单层泛述。
- `color_pass`：主色识别与画面大体一致。
- `grounding_pass`：描述能落回图片中的可见元素，不大量引入不可见推断。
- `product_pass`：输出可直接支撑 Aimandala 后续 `visual_basis`，不需要大量清洗或重写。
- `stability_pass`：3 轮输出虽有措辞漂移，但核心观察不发生明显反转。

## 6. 结论

当前建议：

1. `qwen-vl-max-latest` 继续作为视觉模型第一候选，理由是细节最充分，适合作为报告 `visual_basis` 的上游观察。
2. `ep-20260316095322-94wf5` 作为并列候选保留，理由是稳定性和速度更均衡，且 3 轮 confidence 全部为 `high`。
3. `glm-4v-plus` 作为低成本/快速备选保留，但不建议直接作为 MVP 默认视觉模型，因为输出偏泛、confidence 波动更明显、`risk_flags` 语义需要清洗。
4. 进入真实产品接入前，应再用 `qwen-vl` 和 `doubao-vision` 各跑一次端到端三圈识别 smoke，比较最终报告中 `visual_basis` 是否稳定可读。
