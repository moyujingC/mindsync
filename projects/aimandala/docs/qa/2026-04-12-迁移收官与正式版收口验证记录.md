## 4. 验证结论

### 4.1 当前通过项

- 新生成正式链路、structured contract、upload contract、release 默认值都已在代码中收口
- 项目状态与迁移口径已切换到“新工作区继续开发”
- workflow 与 runbook 已补 smoke check / rollback 说明
- 本轮本地自动化、前端 typecheck/build、knowledge 脚本和公开入口 smoke check 均通过
- `release -> prod` 已真实执行，公网 `upload -> create -> Lite -> upgrade -> Pro -> history` 链路可用
- 生产容器已确认按 `/app/domain/knowledge/schemas` 读取 schema，不再依赖错误的 `/domain/...`
- 生产环境已经切到真实 `openai_compatible` LLM，主生成链路不再停留在 `noop`

### 4.2 当前限制

- 生产环境变量仍未达到正式版目标口径：
  - `cos` 尚未启用
- 因此当前可以确认“新仓库主链可继续开发、线上业务链路可运行、真实 LLM 已切入”，但还不能宣称“正式环境已完全按目标配置切流”
- 当前唯一剩余的正式化缺口，是上传资产仍未切到 `COS`

## 5. 风险判断

- 当前结论：`有条件通过`
- 条件：
  - 本地验证需全部通过
  - 真实部署前需按 runbook 执行 dev / prod smoke test
  - 生产环境补齐可用的 `AIMANDALA_UPLOAD_COS_*` 并切换到 `AIMANDALA_UPLOAD_BACKEND=cos`
  - 如正式主路径失败，应按回退方案切流，不扩大范围
