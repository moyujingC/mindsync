## 3. 手机端人工主路径验收

### 3.1 当前状态

- 状态：待执行
- 原因：当前缺少真实手机端人工操作记录，不能用已有自动化与 smoke 代替
- 约束：本项完成前，不应把 `2026-04-14` 这条线宣称为“首发验证完全闭环”

### 3.2 验收环境

- `prod` 前端入口：`https://web.jingshu.cc`
- `prod` 后端健康检查：`https://web-api.jingshu.cc/health`
- 建议设备：真实手机浏览器
- 建议网络：常规移动网络或家庭 Wi-Fi

### 3.3 执行清单

1. `upload`
   - 打开 `https://web.jingshu.cc`
   - 选择或拍摄一张曼陀罗图片
   - 确认上传成功，没有卡死、空白页或明显报错
2. `detect`
   - 确认三圈识别结果能够正常返回
   - 若需手动微调，确认交互可完成且页面不抖动、不丢图
3. `report-choice`
   - 确认 `Lite / Pro` 选择页可见
   - 确认价格、按钮、跳转语义符合当前 MVP 口径
4. `lite/pro`
   - 先完成 `Lite` 结果生成并确认结果页可读
   - 再执行升级到 `Pro`，确认 `Pro` 结果页可读
5. `history`
   - 返回历史列表
   - 确认刚创建的记录可见，且入口、缩略信息、时间顺序正常
6. `reopen`
   - 打开刚创建的一条历史记录
   - 确认能够重新进入结果页，且核心内容可读
