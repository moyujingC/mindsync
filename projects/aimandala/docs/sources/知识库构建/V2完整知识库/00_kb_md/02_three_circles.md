## 概述

三环结构是曼陀罗解读的核心维度，将画面划分为三个同心圆区域，分别代表：
- **内圈**：自我、过去、意识
- **中圈**：关系、现在、能量
- **外圈**：世界、未来、物质

---

## 三环一致性分析

### 表里如一

| 项目 | 内容 |
|-----|------|
| **模式** | 内圈和外圈颜色完全一致 |
| **解读** | 内外一致，真实坦诚，不伪装 |
| **建议** | 保持这份真实，同时学会适当保护自己 |

### 心门关闭

| 项目 | 内容 |
|-----|------|
| **模式** | 外圈留白多，但里圈或中圈涂的颜色3个以上 |
| **解读** | 对外界不热情，但内心丰富，有防备心理 |
| **建议** | 尝试逐步开放自己，找到安全的表达方式 |

### 表里不一

| 项目 | 内容 |
|-----|------|
| **模式** | 内圈颜色深，外圈颜色浅/白 |
| **解读** | 内心丰富但外在表现保守，或内心困扰但外表坚强 |
| **建议** | 探索内外不一致的原因，寻求更好的整合 |

### 外强中干

| 项目 | 内容 |
|-----|------|
| **模式** | 外圈颜色丰富，内圈留白或颜色少 |
| **解读** | 注重外在形象，但内心空虚或缺乏安全感 |
| **建议** | 关注内在成长，建立扎实的自我基础 |

## 函数接口

### get_circle_interpretation

获取指定圈层的解读框架。

**参数**: `circle_name: str` - 圈层名称（支持别名）

**返回值**: 圈层数据字典，未找到返回 `None`

**示例**:
```python
from app.core import get_circle_interpretation

# 通过标准名称
result = get_circle_interpretation("内圈")

# 通过别名
result = get_circle_interpretation("里圈")  # 同样返回内圈数据
```

### analyze_circle_coherence

分析三环一致性，识别特定模式。

**参数**:
- `inner_colors: list` - 内圈颜色列表
- `middle_colors: list` - 中圈颜色列表
- `outer_colors: list` - 外圈颜色列表

**返回值**:
```python
{
    "detected_patterns": ["表里如一", "心门关闭"],  # 检测到的模式
    "inner_colors": [...],      # 输入的内圈颜色
    "middle_colors": [...],     # 输入的中圈颜色
    "outer_colors": [...],      # 输入的外圈颜色
    "details": [{...}, {...}]   # 各模式的详细信息
}
```

**示例**:
```python
from app.core import analyze_circle_coherence

result = analyze_circle_coherence(
    inner_colors=["深绿", "黄色"],
    middle_colors=["粉红"],
    outer_colors=["白色"]
)

print(result["detected_patterns"])  # 输出: ["表里不一"]
```

## 三圈能量循环模型

### 概述

三圈不仅是空间结构，更是**能量流动**的通道。内在意识通过三圈结构显化为外在现实，外在经验又反馈重塑内在认知。

```
正向流动（理想状态）:
内圈(意识) → 中圈(能量) → 外圈(物质)
     ↑                      ↓
     └──────── 反馈 ────────┘
```

### 正向流动

| 流向 | 能量性质 | 解读重点 | 健康指标 |
|-----|---------|---------|---------|
| **内圈→中圈** | 意识显化为情绪 | 原生信念如何塑造情感反应 | 内圈颜色自然过渡到中圈 |
| **中圈→外圈** | 情绪转化为行动 | 情感状态如何影响外在行为 | 中圈能量顺畅流向外圈 |
| **外圈→内圈** | 经验内化认知 | 外在结果如何重塑自我认知 | 外在成就支持内在成长 |

**正向流动示例**:
- 内圈蓝(水) → 中圈绿(木) → 外圈红(火)
- 解读: 内在平静(水)滋养情感成长(木)，转化为外在热情与成就(火)

### 反向流动（阻滞状态）

当正向流动受阻时，能量可能反向倒灌：

| 流向 | 名称 | 常见表现 | 失衡类型 |
|-----|-----|---------|---------|
| **外圈→中圈** | 外界压力倒灌 | 工作压力导致情绪崩溃 | 外强中干 |
| **中圈→内圈** | 情绪反噬自我 | 关系创伤内化为自我否定 | 心门关闭 |
| **外圈→内圈** | 物质与意识脱节 | 追求成就但内心空虚 | 表里不一 |

**反向流动示例**:
- 外圈红(火) → 中圈白(金) → 内圈黑(水)
- 解读: 外在忙碌压力(火)克制情感表达(金)，导致内心恐惧逃避(水)

### 能量流动质量评估

| 评估指标 | 定义 | 正向表现 | 负向表现 |
|---------|------|---------|---------|
| **通畅度** | 能量流动顺畅程度 | 意识-情绪-行为一致 | 内心想A，做B，得C |
| **速度** | 从意识到显化的速度 | 想到即能做到 | 过度思考导致拖延 |
| **强度** | 各圈能量饱满程度 | 三圈适度分布 | 某圈过强/过弱 |
| **方向** | 整体流动方向 | 内→中→外正向 | 外→中→内倒灌 |

### 圈层内部微循环

每圈内部也存在五行生克关系：

| 圈层 | 内部循环 | 健康状态 | 失衡表现 |
|-----|---------|---------|---------|
| **内圈** | 认知-信念-价值观 | 自我认知统一 | 内心矛盾、自我冲突 |
| **中圈** | 情绪-情感-关系 | 情绪表达流畅 | 情感压抑或爆发 |
| **外圈** | 行为-结果-资源 | 行动有效 | 努力无果、资源匮乏 |

### analyze_energy_flow

分析三圈能量流动状态。

**参数**:
- `inner_elements: list` - 内圈五行元素列表
- `middle_elements: list` - 中圈五行元素列表
- `outer_elements: list` - 外圈五行元素列表

**返回值**:
```python
{
    "flow_direction": "forward",  # 流动方向
    "flow_quality": "healthy",    # 流动质量
    "path_analysis": {            # 路径分析
        "内圈→中圈": {"status": "generating", "description": "..."},
        "中圈→外圈": {"status": "restraining", "description": "..."}
    },
    "blockages": [],              # 阻滞点
    "recommendations": []         # 建议
}
```

### evaluate_energy_quality

评估三圈能量质量。

**参数**:
- `inner_area: float` - 内圈涂色面积比例（0-1）
- `middle_area: float` - 中圈涂色面积比例（0-1）
- `outer_area: float` - 外圈涂色面积比例（0-1）

**返回值**:
```python
{
    "intensity": {
        "内圈": "饱满",
        "中圈": "适中",
        "外圈": "不足"
    },
    "balance": "moderate",        # balanced/moderate/unbalanced
    "dominant_circle": "内圈",    # 主导圈
    "weak_circle": "外圈",        # 弱势圈
    "interpretation": "..."       # 综合解读
}
```
