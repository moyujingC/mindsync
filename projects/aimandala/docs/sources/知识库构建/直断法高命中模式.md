## 定位

本文是 Aimandala 当前直断法的 Markdown 单一真值源。

直断法用于检查画作是否出现高命中特征。它不是完整解读，也不是“选择切入点”。直断命中只能作为快速抓手，后续必须继续进入逐圈颜色、形状、五行生克、失衡浮现和能量流动诊断。

## 使用位置

直断法固定用于 `stage-04-direct-judgment-high-hit-check`。

它的输入应来自：

- `stage-03-visual-evidence` 的画面客观观察。
- 视觉大模型在 `stage-04-direct-judgment-high-hit-check` 的二次查看结果，与默认程序匹配结果一起做互验。
- OpenCV 或其他程序检测结果，若存在，只作为证据校验。

## 命中输出原则

每一个命中项都必须记录：

- 命中的直断模式。
- 对应的可见画面依据。
- 命中强度：`full_hit`、`partial_hit`、`not_enough_evidence`。
- 是否需要后续逐圈验证。
- 不能直接推出的结论边界。

直断命中不允许直接生成最终心理结论。

## 颜色深浅辅助规则

| 类型 | 判断标准 | 提示方向 |
| --- | --- | --- |
| 深色 | 饱和度高，接近色卡深色区 | 力量感强、情绪浓烈、可能压抑 |
| 浅色 | 饱和度低，接近色卡浅色区 | 力量感弱、情绪柔和、可能逃避 |
| 混合 | 深浅色都有 | 情绪复杂、内外不一致、正在整合 |

## 留白辅助规则

| 类型 | 判断标准 | 提示方向 |
| --- | --- | --- |
| 大量留白 | `whitespace_ratio > 0.4` | 保留空间，可能缺乏表达欲或对世界失望 |
| 适量留白 | `0.15 < whitespace_ratio <= 0.4` | 有表达也有空间 |
| 少量留白 | `0.05 < whitespace_ratio <= 0.15` | 表达充分，可能追求完美或焦虑 |
| 无留白 | `whitespace_ratio <= 0.05` | 完全填满，可能有控制欲或焦虑 |

## 与最终报告的关系

用户可见报告可以使用直断命中作为开头命中感，但必须满足：

- 先说明看到了什么。
- 再说明这可能提示什么。
- 最后说明还需要结合逐圈分析继续确认。

最终报告不应把直断标签直接甩给用户，也不应把直断写成诊断结论。
