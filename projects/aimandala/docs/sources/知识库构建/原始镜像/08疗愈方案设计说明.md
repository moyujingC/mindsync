# 疗愈方案设计说明

> 创建时间: 2026-03-07
> 更新说明: 明确2C灵犀Pro的疗愈方案定位——"一对一定制"而非"固定课程"

---

## 一、方案定位澄清

### 错误理解（已纠正）

~~21天疗愈营~~ ❌

- 容易误解为固定节奏、群体参与的"训练营"
- 用户以为是标准课程，每周固定内容

### 正确定位

**21天一对一曼陀罗疗愈方案** ✅

- **核心特征**：AI根据用户的每幅画作，动态生成个性化建议
- **交互模式**：用户上传画作 → AI解读 → 定制下周疗愈方向
- **非固定课程**：没有预设的固定任务，每次建议基于画作变化

---

## 二、方案流程设计

### 2C 灵犀Pro 完整流程

```
Day 1: 开营画
    ├── 用户上传第一幅曼陀罗
    ├── AI解读当前状态
    └── 生成 Week 1 定制化疗愈建议
        （音频主题 + 书写引导 + 日常练习 + 观察要点）

Day 7: 周中画
    ├── 用户上传第二幅曼陀罗
    ├── AI对比Day1画作，识别变化
    ├── 根据变化调整解读
    └── 生成 Week 2 定制化疗愈建议
        （调整疗愈方向，深化或转换焦点）

Day 14: 周中画
    ├── 用户上传第三幅曼陀罗
    ├── AI对比Day1/7/14三幅画作
    ├── 追踪能量变化趋势
    └── 生成 Week 3 定制化疗愈建议
        （整合期，准备结业）

Day 21: 结业画
    ├── 用户上传第四幅曼陀罗
    ├── AI对比四幅画作完整周期
    ├── 生成变化趋势报告
    └── 提供持续练习建议
```

### 关键设计原则

| 原则 | 说明 |
|------|------|
| **画作驱动** | 每次疗愈建议基于用户的实际画作，不是固定模板 |
| **动态调整** | Week 2的建议可能完全不同于Week 1，取决于画作变化 |
| **轻量陪伴** | 每周一幅画，日常任务5-10分钟，不形成负担 |
| **变化追踪** | 重点展示用户从Day1到Day21的变化轨迹 |

## 三、与代码实现的对应关系

### 当前代码 (`healing_programs.py`)

**现状**：5种失衡类型 × 21天固定任务模板

```python
# 示例：水多木漂型预设任务
"水多木漂": {
    "weeks": {
        1: {
            "phase": "觉察期",
            "tasks": [
                {"day": 1, "audio": "允许情绪存在", ...},  # 固定
                {"day": 2, "audio": "身体的水流", ...},    # 固定
                # ... 所有21天任务都是预设的
            ]
        }
    }
}
```

**问题**：这是"固定模板"，不是"动态定制"

### 目标设计

**应改为**：基于画作的动态生成系统

```python
# 目标：根据画作分析结果动态生成
class DynamicHealingGenerator:
    def generate_weekly_plan(
        self,
        current_analysis: MandalaAnalysis,      # 当前画作分析
        previous_analysis: Optional[MandalaAnalysis],  # 上幅画作（如有）
        imbalance_type: str,                    # 失衡类型
        week_number: int                        # 第几周
    ) -> WeeklyPlan:
        """
        根据画作变化动态生成下周疗愈方案
        """
        # 1. 分析画作变化趋势
        changes = self.compare_mandalas(previous_analysis, current_analysis)

        # 2. 根据变化调整疗愈焦点
        if changes.energy_flow_improved:
            focus = "深化当前进展"
        elif changes.new_imbalance_detected:
            focus = "调整疗愈方向"
        else:
            focus = "持续当前练习"

        # 3. 生成个性化任务
        return WeeklyPlan(
            audio_theme=self.select_audio(focus, imbalance_type),
            writing_prompt=self.generate_prompt(changes),
            daily_practice=self.suggest_practice(focus),
            observation_points=self.define_observations(changes)
        )
```

## 四、与2B方案的区分

| 维度 | 2C 灵犀Pro | 2B 明镜轻咨询 |
|------|-----------|--------------|
| **方案来源** | AI根据画作动态生成 | 智牧老师11个深度案例 |
| **指导方式** | AI自动化引导 | 疗愈师1v1指导 |
| **绘画频率** | Day1/7/14/21，每周一幅 | 根据个案需要，可能每天多幅 |
| **颜色使用** | 彩色为主，自由选择 | 清理期单色，显化期彩色 |
| **周期** | 固定21天 | 灵活，7-21天不等 |
| **核心目标** | 自我觉察与日常调节 | 深度清理与转化 |
