## 五行生克关系

### 相生关系（循环促进）

```
木 → 火 → 土 → 金 → 水 → 木
```

| 源头 | 生成 | 含义 |
|-----|------|------|
| 木 | 火 | 木生火（木燃烧生火） |
| 火 | 土 | 火生土（火烬成土） |
| 土 | 金 | 土生金（土中藏金） |
| 金 | 水 | 金生水（金属熔化为液） |
| 水 | 木 | 水生木（水润木生） |

### 相克关系（相互制约）

```
木 → 土 → 水 → 火 → 金 → 木
```

| 克制方 | 被克方 | 含义 |
|-------|-------|------|
| 木 | 土 | 木克土（木破土出） |
| 土 | 水 | 土克水（土能挡水） |
| 水 | 火 | 水克火（水能灭火） |
| 火 | 金 | 火克金（火能熔金） |
| 金 | 木 | 金克木（金能断木） |

## 函数接口

### get_element_by_color

根据颜色名称查找对应五行。

**参数**: `color_name: str` - 颜色名称

**返回值**:
```python
{
    "element": "木",      # 五行元素
    "name": "木",
    "colors": [...],      # 所有相关颜色
    "color_codes": [...], # 颜色代码
    "attributes": "...",  # 属性描述
    "organs": "...",      # 对应脏腑
    "emotion": "...",     # 对应情绪
    "direction": "...",   # 方位
    "season": "...",      # 季节
    "shape": "...",       # 对应形状
    "alias_of": "...",    # 映射到的标准颜色（可选）
    "original_color": "..." # 原始颜色名（可选）
}
```

**逻辑**:
1. 先在 `FIVE_ELEMENTS` 中直接匹配颜色
2. 如果未找到，通过 `COLOR_ALIASES` 映射后再查找

### analyze_color_balance

分析颜色五行平衡。

**参数**: `color_counts: dict` - 颜色计数字典，如 `{"红色": 3, "蓝色": 1, "黄色": 2}`

**返回值**:
```python
{
    "balance": "balanced" | "unbalanced" | "neutral",
    "dominant": ["火"],        # 过旺的元素列表
    "weak": ["水"],             # 过弱的元素列表
    "element_distribution": {   # 五行分布计数
        "木": 0, "火": 3, "土": 2, "金": 0, "水": 1
    }
}
```

**判断标准**:
- 超过平均值 1.5 倍 → 过旺 (dominant)
- 低于平均值 0.5 倍 → 过弱 (weak)

## 使用示例

```python
from app.core import get_element_by_color, analyze_color_balance

# 查询颜色对应的五行
element_info = get_element_by_color("深绿")
print(element_info["element"])  # 输出: 木

# 分析颜色平衡
balance = analyze_color_balance({"红色": 5, "蓝色": 1, "黄色": 2})
print(balance["dominant"])  # 输出: ["火"]
print(balance["weak"])      # 输出: ["金", "水"]
```
