## 知识库概述

本知识库为 AI 曼陀罗绘画解读系统提供完整的理论支撑和实践指南。当前方法入口采用**三圈五行解读流程**：

```
┌─────────────────────────────────────────────────────────┐
│  主题 -> 三圈锁定 -> 直断高命中检查                         │
│  -> 逐圈画面依据 -> 逐圈颜色/形状/圈内生克                  │
│  -> 逐圈失衡候选 -> 整体能量流动综合                         │
└─────────────────────────────────────────────────────────┘
```

## 三圈五行流程速查

### Step 1: 确定主题与三圈

**目的**: 明确本次解读落点，并锁定三圈边界。

**输出**: 主题、内圈/中圈/外圈边界和圈层语义

### Step 2: 直断高命中检查

**目的**: 查看是否命中新手解读6式或扩充直断条目。

**观察要点**:
- 涂色饱满度（满/适中/留白）
- 颜色深浅（深/中/浅）
- 9种直断模式匹配

**输出**: 0-3 个高命中提示，供后续逐圈验证

→ 详见 [05. 直断特征](05_direct_judgments.md)

### Step 3: 逐圈画面依据与颜色形状生克

**目的**: 逐圈分析可见元素、颜色状态、形状状态和圈内生克。

**执行动作**:
1. 识别每圈主要颜色
2. 判断深浅 → 对应太过/正常/不足
3. 分析面积比例
4. 识别形状与排列
5. 分析本圈内部五行生克

**输出**: 每圈画面依据、五行属性、状态和失衡候选

→ 详见 [03. 颜色含义](03_color_meanings.md)

### Step 4: 整体能量流动综合

**目的**: 逐圈之后看整幅画的能量流动。

**执行动作**:
1. 看内圈意识如何进入中圈关系和情绪
2. 看中圈关系和情绪如何进入外圈行动与结果
3. 看是否存在堵点、倒灌、跳跃或回流
4. 在主题下收束冲突、卡点和调节目标

**输出**: 主题卡点、整体能量流动判断、疗愈建议

→ 详见 [07. 五行生克乘侮](07_five_elements_advanced.md)
