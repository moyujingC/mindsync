## 概述

基于《曼陀罗解读手册》的标准解读流程，采用**四步法**：

```
┌─────────────────────────────────────────────────────────┐
│  第一步：直断（快速筛查）                                  │
│  ━━━━━━━━━━━━━━━━━━━━━━━━━                              │
│  基于画面整体特征的直接判断，快速抓住案主注意力              │
└─────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────┐
│  第二步：颜色分析（逐圈详细）                              │
│  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━                          │
│  逐圈分析颜色分布、深浅、面积 → 确定五行及状态             │
└─────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────┐
│  第三步：形状分析（整体+触发式）                           │
│  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━                         │
│  整体观察形状特征，颜色与形状冲突时细分析                   │
└─────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────┐
│  第四步：生克分析（圈级关系）                              │
│  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━                          │
│  圈内、圈间五行生克关系，识别失衡类型                       │
└─────────────────────────────────────────────────────────┘
```

## 第一步：直断（快速筛查）

| 属性 | 内容 |
|-----|------|
| **名称** | 第一步：直断（快速筛查） |
| **描述** | 基于画面整体特征的直接判断，快速抓住最突出的信息，打开案主心防 |

**执行动作**:
1. 观察画面整体特征（涂色饱满度、颜色深浅、留白比例）
2. 识别明显的直断模式（9种）
3. 快速判断整体情绪基调（焦虑/平静/压抑/积极等）
4. 作为解读的切入点和重点提示

**9种直断模式**:

| 直断模式 | 判断依据 | 含义 |
|---------|---------|------|
| **涂色很满深色为主** | 画面整体涂满，深色为主 | 焦虑担忧的情绪，除了焦虑还有恐惧 |
| **整体泛白颜色偏淡** | 整体泛白，颜色偏淡 | 做事无力量感，喜欢躺平 |
| **思虑过重喜好操心** | 大面积黄色 | 思虑过重，喜好操心，把心思放在别人身上 |
| **喜欢分享开口来财** | 明显有蓝色+绿色 | 喜欢分享，开口来财，喉轮+心轮敞开 |
| **入不敷出热情奔放** | 外圈成片红色（相邻色非绿色） | 漏财、入不敷出、燃烧消耗 |
| **关注外表过手财神** | 外圈颜色五颜六色、零零碎碎、花边 | 爱美、爱打扮、过手财神 |
| **表里如一** | 内圈和外圈颜色完全一致 | 真实坦诚，内外一致 |
| **不想说啥无声沉默** | 整张留白较多 | 不想表达，对世界有所保留或失望 |
| **心门关闭** | 外圈留白多，但里圈或中圈涂的颜色3个以上 | 对外界防备，自己有想法但不敞开 |

**颜色深浅指示**:

| 深浅 | 对应状态 | 含义 |
|-----|---------|------|
| **深色** | 太过 | 力量感强，情绪浓烈，可能压抑 |
| **浅色** | 不足 | 力量感弱，情绪柔和，可能逃避 |
| **混合** | 复杂 | 情绪复杂，内外不一致，正在整合 |

**留白分析**:

| 留白程度 | 含义 |
|---------|------|
| **大量留白** | 保留空间，可能缺乏表达欲或对世界失望 |
| **少量留白** | 充分表达，可能追求完美或焦虑 |
| **无留白** | 完全填满，可能有控制欲或焦虑 |

**注意**: 直断用于快速打开局面，后续需结合详细分析验证和深化。

## 第二步：颜色分析（逐圈详细）

| 属性 | 内容 |
|-----|------|
| **名称** | 第二步：颜色分析（逐圈详细） |
| **描述** | 逐圈分析颜色分布、深浅和面积，确定五行属性及状态 |

**执行动作**:
1. 识别内圈、中圈、外圈的主要颜色
2. 判断每种颜色的深浅（深/中/浅）→ 对应太过/正常/不足
3. 分析各颜色面积比例
4. 颜色五行映射
5. 记录异常颜色分布（如外圈成片红色等）

**颜色深浅与状态映射**:

| 深浅 | 状态 | 含义 |
|-----|------|------|
| **深色** | 太过 | 浓重、饱和度高 → 能量过度集中，可能淤堵 |
| **中色** | 正常 | 适中、均匀 → 能量平衡健康 |
| **浅色** | 不足 | 浅淡、饱和度低 → 能量偏弱，需要滋养 |

**分析原则**:

| 原则 | 说明 |
|-----|------|
| **颜色优先** | 颜色是主要分析维度，视觉最直接 |
| **深浅重要** | 同一种颜色，深浅不同含义截然不同 |
| **面积重要** | 面积比例决定该五行的影响力大小 |
| **圈层语境** | 同一颜色在不同圈含义不同 |

**输出**: 每圈的颜色分布、深浅状态、五行属性、面积比例

## 第三步：形状分析（整体+触发式）

| 属性 | 内容 |
|-----|------|
| **名称** | 第三步：形状分析（整体+触发式） |
| **描述** | 整体观察形状特征，在颜色与形状五行冲突时进行细分析 |

**执行动作**:
1. 整体观察画面形状特征（圆润/尖锐/规则/散乱）
2. 识别主要形状及其五行属性
3. **触发式细分析**：当颜色五行与形状五行明显冲突时
4. 辅助验证颜色分析的结论

**整体形状特征**:

| 特征 | 含义 |
|-----|------|
| **圆润为主** | 待人接物圆融，情商较高，沟通顺畅 |
| **尖锐为主** | 有棱角，可能急躁、固执或自我保护强 |
| **规则整齐** | 追求完美，自我要求高，可能有控制欲 |
| **散乱不规则** | 心神不宁，思绪混乱，情绪不稳定 |

**触发式分析（颜色vs形状冲突）**:

当颜色与形状的五行属性**相克**时，进行细分析：

| 代表意义 | 说明 |
|---------|------|
| **颜色代表** | 意图/情绪/内在需求 |
| **形状代表** | 行为模式/外在表现/习惯 |
| **冲突含义** | 想做的和实际做的不一致，内在冲突 |

**冲突示例**:

| 组合 | 颜色五行 | 形状五行 | 关系 | 解读 |
|-----|---------|---------|------|------|
| 红色+水滴 | 火 | 水 | 水克火 | 情绪想要热情，但行为趋于收敛 |
| 蓝色+三角 | 水 | 火 | 火克水 | 内心平静，但行为急躁冲动 |
| 绿色+圆形 | 木 | 金 | 金克木 | 想要成长，但被规则/圆满束缚 |

**注意**: 形状是辅助维度，颜色分析为主；不强制每个色块都分析形状冲突。

## 第四步：生克分析（圈级关系）

| 属性 | 内容 |
|-----|------|
| **名称** | 第四步：生克分析（圈级关系） |
| **描述** | 基于圈内的五行分布，分析生克关系、能量流向和失衡类型 |

**执行动作**:
1. 分析每圈内部的五行生克关系
2. 分析圈与圈之间的五行流向（内圈→中圈→外圈）
3. 识别五行失衡的具体类型（相乘/相侮/生多为克）
4. 综合判断20种失衡类型
5. 给出调整建议和疗愈方向

**生克原则**:

#### 相生

| 属性 | 内容 |
|-----|------|
| **性质** | 滋养、助推，但过犹不及 |
| **效果** | 助力、提携、给予、帮助 |
| **注意** | 生得太过，对母体是消耗（如土生金过多，土被耗虚） |

#### 相克

| 属性 | 内容 |
|-----|------|
| **性质** | 规整、梳理，必要但需适度 |
| **效果** | 制约、制衡、压制、管教 |
| **注意** | 克得太过会造成伤害，克不动则反受其害 |

**失衡类型**:

| 类型           | 说明                 | 示例            |
| ------------ | ------------------ | ------------- |
| **相乘（过度克制）** | 克的力量过强             | 木过度克土 → 木多土陷  |
| **相侮（反向克制）** | 被克方太强，反克对方         | 木太强反克金 → 木多金缺 |
| **生多为克**     | 生的方面积远大于被生的方（3倍以上） | 水多木漂          |

**三圈能量流向**:

| 流向        | 解读重点          |
| --------- | ------------- |
| **内圈→中圈** | 内在意识如何影响当下能量  |
| **中圈→外圈** | 当下能量如何显化为外在结果 |
| **整体循环**  | 三圈能量是否形成正向循环  |

## 函数接口

### interpret_mandala

完整的曼陀罗解读流程（四步法）。

**参数**:
- `inner_colors: List[Tuple[str, float]]` - 内圈颜色及面积
- `middle_colors: List[Tuple[str, float]]` - 中圈颜色及面积
- `outer_colors: List[Tuple[str, float]]` - 外圈颜色及面积
- `inner_shapes: Optional[List[str]]` - 内圈形状列表（可选）
- `middle_shapes: Optional[List[str]]` - 中圈形状列表（可选）
- `outer_shapes: Optional[List[str]]` - 外圈形状列表（可选）
- `whitespace_ratio: float` - 整体留白比例（0-1）
- `observed_features: Optional[List[str]]` - 观察到的特征列表（用于直断）

**返回值**: 完整解读报告字典

```python
{
    "steps": {
        "direct_judgment": {
            "whitespace_analysis": {...},
            "matched_judgments": [...],
            "key_insights": [...]
        },
        "color_analysis": {
            "内圈": [...],
            "中圈": [...],
            "外圈": [...]
        },
        "shape_analysis": {
            "overall_features": [...],
            "triggered_analyses": [...]
        },
        "five_elements_relations": {
            "circle_relations": {...},
            "imbalance_diagnosis": {...}
        }
    }
}
```

### match_direct_judgments

根据观察到的特征匹配直断。

**参数**:
- `observed_features: List[str]` - 观察到的特征列表，如 `["外圈成片红色", "大面积黄色"]`

**返回值**: 匹配的直断列表

---

### analyze_whitespace

分析留白比例。

**参数**:
- `whitespace_ratio: float` - 留白比例（0-1）

**返回值**: 留白分析结果

---

### analyze_five_elements_relationship

分析一个圈内的五行关系。

**参数**:
- `elements_in_circle: List[str]` - 圈内按顺序排列的五行元素，如 `["木", "火", "土"]`

**返回值**: 关系列表

```python
[
    {
        "from": "木",
        "to": "火",
        "type": "相生",
        "description": "木生火"
    }
]
```

---

### check_abnormal_relations

检查反常的五行关系。

**参数**:
- `elements_with_areas: Dict[str, float]` - 元素及其面积，如 `{"木": 0.5, "火": 0.1}`

**返回值**: 反常关系列表

**检查类型**:
- 生多为克: 生的方面积远大于被生的方（3倍以上）
- 严重: 5倍以上

---

### resolve_color_shape_conflict

解决颜色与形状生克关系冲突的综合判断。

**参数**:
- `color: str` - 颜色名称
- `shape: str` - 形状名称
- `color_element: str` - 颜色对应的五行
- `shape_element: str` - 形状对应的五行
- `relationship: str` - 生克关系类型（颜色克形状/形状克颜色）
- `color_area: float` - 颜色面积比例（0-1）
- `color_intensity: str` - 颜色深浅（深/中/浅）
- `shape_size: str` - 形状大小（大/中/小）

**返回值**:
```python
{
    "dominant_factor": "主导因素（color/shape/balanced）",
    "dominant_element": "主导的五行",
    "inner_conflict": "是否存在内在冲突",
    "interpretation": "详细解读",
    "psychology": "心理含义",
    "recommendation": "调整建议"
}
```

**权重计算**:
- 颜色权重 = 面积 × 深浅系数（深1.3/中1.0/浅0.7）
- 形状权重 = 基础0.3 × 大小系数（大0.5/中0.3/小0.15）
