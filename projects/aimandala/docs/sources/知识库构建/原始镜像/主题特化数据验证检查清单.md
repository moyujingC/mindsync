# 主题特化数据验证检查清单

## 概述

本文档提供验证7大主题特化数据质量的全面检查清单。适用于人工审核和自动化验证。

**验证范围：**
- 7个主题：general, intimate_relationship, wealth_career, health_wellness, personal_growth, father_relationship, mother_relationship, parent_child_relationship
- 4类数据：INSIGHT_TEMPLATES, IMBALANCE_MAPPINGS, HEALING_PRESCRIPTIONS, INTERACTIONS

---

## 第一部分：通用结构验证

### 1.1 文件结构检查

| 检查项 | 验证方法 | 通过标准 |
|-------|---------|---------|
| 文件命名规范 | 目视检查 | 使用 snake_case，如 `intimate_relationship.py` |
| 文件位置正确 | 路径检查 | 位于 `app/core/knowledge/themes/` 目录 |
| 导出项完整 | 代码检查 | 必须导出 THEME_CONFIG, COLOR_MEANINGS, INTERACTIONS, HEALING_PRESCRIPTIONS, INSIGHT_TEMPLATES, IMBALANCE_MAPPINGS |
| __all__ 定义 | 代码检查 | 包含所有导出常量名 |

### 1.2 数据类型检查

| 检查项 | 验证方法 | 通过标准 |
|-------|---------|---------|
| THEME_CONFIG 类型 | 类型检查 | Dict，必须包含 theme_id, theme_name_cn, core_issues |
| COLOR_MEANINGS 类型 | 类型检查 | Dict，二级结构为 element -> shades -> circles |
| INSIGHT_TEMPLATES 类型 | 类型检查 | Dict，必须包含6个角度键 |
| IMBALANCE_MAPPINGS 类型 | 类型检查 | Dict，最多包含10个 toC 失衡类型 |
| HEALING_PRESCRIPTIONS 类型 | 类型检查 | Dict，包含 issue_types 和通用方案 |

### 1.3 导入导出检查


| 具体表现 | list | 3-5条主题化表现 | 每条10-20字 |
| 转变方向 | str | 疗愈方向建议 | 20-40字 |
| 主题关键词 | list | 该失衡在该主题下的关键词 | 3-5个 |

### 4.3 主题差异化验证

**示例：验证 "水多木漂" 在不同主题下的差异化**

| 主题 | 核心矛盾示例 | 验证要点 |
|-----|-------------|---------|
| general | "想法丰富但缺乏执行力" | 通用表达 |
| intimate_relationship | "对关系有很多期待但难以落地" | 必须涉及关系 |
| wealth_career | "有很多赚钱点子但难以实施" | 必须涉及财富/事业 |
| health_wellness | "知道很多健康知识但难以坚持" | 必须涉及健康行为 |

**验证脚本：**
```python
def validate_imbalance_theme_consistency(imbalance_type: str, theme: str) -> List[str]:
    """验证失衡类型解读与主题的一致性"""
    mapping = IMBALANCE_MAPPINGS[theme][imbalance_type]
    errors = []

    # 检查主题关键词出现
    theme_keywords = THEME_KEYWORDS[theme]
    content = f"{mapping['核心矛盾']} {' '.join(mapping['具体表现'])}"

    has_theme_keyword = any(kw in content for kw in theme_keywords)
    if not has_theme_keyword:
        errors.append(f"{theme} 的 {imbalance_type} 未包含主题关键词")

    return errors
```

## 第十部分：自动化验证脚本

### 10.1 完整验证脚本

```python
#!/usr/bin/env python3
"""
主题特化数据验证脚本
使用：python validate_theme_data.py
"""

import sys
from typing import List, Dict
from app.core.knowledge.themes import (
    THEME_CONFIGS, INSIGHT_TEMPLATES, IMBALANCE_MAPPINGS
)

THEMES = [
    "general", "intimate_relationship", "wealth_career",
    "health_wellness", "personal_growth", "father_relationship",
    "mother_relationship", "parent_child_relationship"
]

REQUIRED_INSIGHT_ANGLES = [
    "你的底色", "你的矛盾", "你的模式",
    "你的防御", "你的卡点", "你的光"
]

ALLOWED_IMBALANCES = [
    "水多木漂", "火多土焦", "木多火塞", "土多金埋", "金多水浊",
    "水多火灭", "火多金熔", "金多木折", "木多土陷", "土多水干"
]

class ThemeDataValidator:
    """主题数据验证器"""

    def __init__(self):
        self.errors = []
        self.warnings = []

    def validate_all(self) -> bool:
        """验证所有主题数据"""
        print("=" * 60)
        print("主题特化数据验证")
        print("=" * 60)

        for theme in THEMES:
            print(f"\n验证主题: {theme}")
            print("-" * 40)
            self._validate_theme(theme)

        # 输出结果
        print("\n" + "=" * 60)
        print("验证结果")
        print("=" * 60)

        if self.errors:
            print(f"❌ 发现 {len(self.errors)} 个错误:")
            for error in self.errors:
                print(f"  - {error}")

        if self.warnings:
            print(f"⚠️  发现 {len(self.warnings)} 个警告:")
            for warning in self.warnings:
                print(f"  - {warning}")

        if not self.errors and not self.warnings:
            print("✅ 所有验证通过！")
            return True

        return len(self.errors) == 0

    def _validate_theme(self, theme: str):
        """验证单个主题"""
        # 验证结构
        self._validate_structure(theme)

        # 验证洞察模板
        self._validate_insight_templates(theme)

        # 验证失衡映射
        self._validate_imbalance_mappings(theme)

    def _validate_structure(self, theme: str):
        """验证数据结构"""
        # 检查配置存在
        if theme not in THEME_CONFIGS:
            self.errors.append(f"{theme}: 缺少 THEME_CONFIG")
            return

        config = THEME_CONFIGS[theme]
        required_fields = ["theme_id", "theme_name_cn", "description", "core_issues"]

        for field in required_fields:
            if field not in config:
                self.errors.append(f"{theme}: THEME_CONFIG 缺少字段 {field}")

    def _validate_insight_templates(self, theme: str):
        """验证洞察模板"""
        if theme not in INSIGHT_TEMPLATES:
            self.errors.append(f"{theme}: 缺少 INSIGHT_TEMPLATES")
            return

        templates = INSIGHT_TEMPLATES[theme]

        # 检查6个角度
        for angle in REQUIRED_INSIGHT_ANGLES:
            if angle not in templates:
                self.errors.append(f"{theme}: 缺少洞察角度 '{angle}'")
                continue

            # 检查内容
            template = templates[angle]
            if "角度" not in template or "示例" not in template:
                self.errors.append(f"{theme}: '{angle}' 缺少必要字段")

    def _validate_imbalance_mappings(self, theme: str):
        """验证失衡映射"""
        if theme not in IMBALANCE_MAPPINGS:
            self.errors.append(f"{theme}: 缺少 IMBALANCE_MAPPINGS")
            return

        mappings = IMBALANCE_MAPPINGS[theme]

        # 检查只允许 toC 失衡类型
        for imbalance in mappings.keys():
            if imbalance not in ALLOWED_IMBALANCES:
                self.errors.append(f"{theme}: 包含非 toC 失衡类型 '{imbalance}'")

        # 检查内容完整性
        for imbalance, mapping in mappings.items():
            required = ["核心矛盾", "具体表现", "转变方向"]
            for field in required:
                if field not in mapping:
                    self.errors.append(f"{theme}.{imbalance}: 缺少字段 '{field}'")

if __name__ == "__main__":
    validator = ThemeDataValidator()
    success = validator.validate_all()
    sys.exit(0 if success else 1)
```

2. **内容审核**（30分钟/主题）
   - 通读所有洞察模板，检查主题相关性
   - 通读所有失衡映射，检查差异化程度
   - 标记需要修改的内容

3. **一致性审核**（20分钟）
   - 对比 Lite/Pro 版本的一致性
   - 对比 Addon 文档与数据的一致性

4. **应用测试**（20分钟）
   - 运行实际解读生成测试
   - 检查输出质量
