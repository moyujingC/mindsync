## 3. ToB诊断流程（问诊确认机制）

### 3.1 为什么需要问诊确认？

```
【ToC版（灵犀AI）】
├── 基于颜色做初步判断
├── 适合：明显失衡、用户自我觉察
└── 局限：无法区分相乘vs相侮、子病犯母vs相生太过

【ToB版（明镜咨询）】
├── AI初步判断 + 疗愈师问诊确认
├── 适合：复杂情况、精确诊断
└── 优势：通过问诊区分易混淆类型
```

### 3.2 易混淆类型及问诊要点

#### 类型A：【相生太过】vs【子病犯母】

**共同特征**：A多，B受影响

**区分问诊**：
```
AI初步判断：绿色过多，可能木多火塞或木多水缩

疗愈师问诊：
Q1: "您最近是感觉想法太多难以表达（火塞），
     还是觉得精力枯竭、源泉耗尽（水缩）？"
     
Q2: "您的能量状态是向外膨胀的压抑感，
     还是向内收缩的枯竭感？"

判断：
- 膨胀压抑 → 木多火塞（相生太过）
- 收缩枯竭 → 木多水缩（子病犯母）
```

#### 类型B：【相乘】vs【相侮】

**共同特征**：A多，B受损

**区分问诊**：
```
AI初步判断：白色过多，可能金多木折或金多火熄

疗愈师问诊：
Q1: "您现在的状态是：
     A. 被压制、被砍伐的受伤感（木折）
     B. 主动压制、熄灭热情的冷漠感（火熄）"
     
Q2: "面对规则/压力，您是：
     A. 感到被伤害、想逃避（被克）
     B. 用冷漠/理性防御（反克）"

判断：
- 受伤逃避 → 金多木折（相乘，被克方受伤）
- 冷漠防御 → 金多火熄（相侮，反克对方）
```

### 3.3 标准化问诊流程

```
【Step 1】AI初步分析
├── 颜色提取（OpenCV）
├── 失衡类型候选（Top-3）
└── 生成案前分析报告

【Step 2】疗愈师问诊（语音/视频）
├── 确认能量流向（向外/向内）
├── 确认心理感受（膨胀/收缩/受伤/防御）
├── 确认行为模式（攻击/逃避/反制/顺从）
└── 明确最终失衡类型

【Step 3】生成精准方案
├── 基于确认的失衡类型
├── 结合用户具体情境
└── 生成个性化疗愈方案
```

### 3.4 问诊问题库（示例）

#### 针对【子病犯母】类型
```
通用问题：
1. "您现在的感觉更接近：
    A. 过度付出后的空虚
    B. 被索取后的疲惫
    C. 承担过多后的耗竭
    D. 过度收获后的虚浮
    E. 过度扩张后的枯竭"

2. "这种状态是最近才出现，还是长期累积？"

3. "您觉得自己的'源泉'还充足吗？"
```

#### 针对【相乘】vs【相侮】
```
通用问题：
1. "面对压力/规则，您的第一反应是：
    A. 感到被压制、想逃离（相乘-被克）
    B. 用冷漠/对抗来防御（相侮-反克）
    C. 顺应但内心不满（相乘-内化）
    D. 主动改变规则（相侮-外化）"

2. "您的情绪更多是：
    A. 受伤、委屈、压抑（被动）
    B. 愤怒、冷漠、防御（主动）"
```

## 4. 待补充的5种失衡类型（需定义）

### 4.1 【子病犯母】- 2种待补充

#### 金多土虚
```
定义：土生金，金过多反过来消耗土，导致土虚
曼陀罗特征：白色/金色多，黄色/棕色少且淡
心理表现：
- 过度收获、只取不予
- 根基不稳、虚浮焦虑
- 物质丰富但内心空虚
问诊要点：
- "您是否感觉拥有很多但内心空虚？"
- "您是否过度追求外在成就，忽略内在根基？"
调整方案：
- 减少白色/金色使用
- 增加黄色（土）：夯实基础、培养耐心
- 练习"给予"而非"索取"
```

#### 木多水缩
```
定义：水生木，木过多反过来消耗水，导致水源枯竭
曼陀罗特征：绿色多，黑色/蓝色少且淡
心理表现：
- 过度生长、过度扩展
- 源泉枯竭、后劲不足
- 表面繁荣、内在空虚
问诊要点：
- "您是否一直在努力前进，但感觉源泉枯竭？"
- "您的成长是否超出了您的滋养能力？"
调整方案：
- 减少绿色使用
- 增加黑色（水）：回归源头、补充能量
- 学习"暂停"而非"扩张"
```

### 4.2 【相侮】- 3种待补充

#### 火多水灼
```
定义：水克火，但火过旺反过来把水灼干
```

1. MVP阶段技术难以区分"颜色浅淡"vs"颜色病态"
2. 与抑郁症强关联，误识别风险高
3. 需要ToB疗愈师深度诊断，不适合ToC自动解读
