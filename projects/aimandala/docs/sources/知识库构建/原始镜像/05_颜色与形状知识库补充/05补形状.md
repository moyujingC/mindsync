# 知识库形状补全记录

## 背景

在完成颜色补全后，形状解读知识库也需要系统化补充。虽然五行中有基础形状映射，但缺乏：
- 形状在三圈中的详细含义
- 曼陀罗特有形状（小圆、大圆、旋转圆形等）
- 形状组合解读
- 形状大小/数量的含义

## 实施过程

### 1. 创建形状知识库文件

新建 `app/core/shape_meanings.py`，包含：

#### 1.1 形状五行映射（SHAPE_ELEMENTS）

| 元素 | 形状 |
|------|------|
| 木 | 长方形、直线、条形、竖线、横线、网格、放射状、树枝状 |
| 火 | 三角形、尖角、星形、菱形、箭头、金字塔、火焰状 |
| 土 | 正方形、方形、矩形、田字格、十字、梯形、容器状 |
| 金 | 圆形、圆弧、弧形、椭圆形、曲线、环形、半圆、扇形 |
| 水 | 波浪形、螺旋、不规则、点状、水滴、S形、涡旋 |

#### 1.2 基础形状三圈解读（SHAPE_MEANINGS）

每个形状包含：
- `core_meaning`: 核心含义
- `inner/middle/outer`: 三圈解读
- `positive/negative`: 正负向特质
- `variations`: 变体含义

示例（圆形）：
```python
"圆形": {
    "element": "金",
    "core_meaning": "圆满、完整、自我",
    "inner": "追求内在圆满，自我意识强",
    "middle": "在关系中追求和谐圆满",
    "outer": "对外展现完整自我形象",
    "positive": "圆满、完整、包容",
    "negative": "封闭、自恋、边界不清",
    "variations": {
        "小圆": "小的圆满、具体目标的达成",
        "大圆": "承载更多、包容性强",
        "多层圆": "层层保护或层层递进"
    }
}
```

#### 1.3 曼陀罗特有形状（MANDALA_SPECIFIC_SHAPES）

| 形状 | 元素 | 含义 |
|------|------|------|
| 小圆 | 金 | 小的圆满，具体目标达成 |
| 大圆 | 金 | 承载更多，包容性强 |
| 旋转圆形 | 金 | 动态的金，生生不息 |
| 方形几何 | 土 | 规则感强，结构化思维 |
| 凯尔特结 | 土/水 | 复杂的连接，多重关系 |
| 曼陀罗花 | 火/金 | 绽放的自我，美丽展现 |
| 辐射状 | 木 | 向外扩展，影响力 |
| 同心圆 | 金 | 层层保护或递进成长 |
| 花瓣形 | 木 | 绽放，生命力 |
| 网格状 | 木 | 结构，规划 |

#### 1.4 形状组合解读（SHAPE_COMBINATIONS）

| 组合 | 含义 | 五行关系 |
|------|------|----------|
| 圆形+三角形 | 圆满中有突破，稳定中求发展 | 金生火 |
| 方形+圆形 | 方圆并济，刚柔相济 | 土生金 |
| 波浪+螺旋 | 深度情绪波动，深层次探索 | 水+水 |
| 放射+圆形 | 影响力向外扩展 | 木+金 |
| 直线+曲线 | 刚柔并济，理性与感性平衡 | 木+金 |

#### 1.5 形状强度含义（SHAPE_INTENSITY）

- **大形状**: 能量集中，影响显著
- **小形状**: 能量分散，或刚开始发展
- **多形状**: 能量复杂，多面向发展
- **少形状**: 能量聚焦，单一面向
- **整齐排列**: 有序，规划性强
- **散乱分布**: 自由，随性
- **居中**: 核心关注，重要性高
- **靠边**: 边缘化，或资源外放

## 核心功能

### 获取形状五行
```python
from app.core import get_shape_element

element = get_shape_element("圆形")  # 返回 "金"
```

### 获取形状解读
```python
from app.core import get_shape_meaning

# 获取完整含义
meaning = get_shape_meaning("圆形")

# 获取特定圈层的含义
inner_meaning = get_shape_meaning("圆形", "inner")
```

### 分析形状分布
```python
from app.core import analyze_shape_distribution

shapes = ["圆形", "圆形", "三角形", "波浪形"]
analysis = analyze_shape_distribution(shapes)
# 返回: 主导元素、元素分布、总计数量
```

### 获取推荐形状
```python
from app.core import get_recommended_shapes

# 根据五行获取推荐形状
shapes = get_recommended_shapes("火")  # ["三角形", "星形", "箭头", "火焰状"]
```

## 与原有系统的整合

形状知识库与已有系统无缝整合：

1. **报告生成器**: `report_generator.py` 中的 `SHAPE_ELEMENTS` 现在可以从形状知识库导入
2. **颜色知识库**: 形状可以与颜色组合，形成更丰富的解读（如"红色三角形"）
3. **五行系统**: 形状五行与颜色五行可以交叉验证

## 后续建议

1. **形状+颜色组合**: 开发形状与颜色的联合解读（如"红色三角形" vs "蓝色三角形"）
2. **图像识别**: 集成形状识别算法，自动提取曼陀罗中的形状
3. **形状处方**: 根据缺失的五行推荐应画的形状
4. **动态形状**: 分析形状的方向、大小、数量的动态变化
