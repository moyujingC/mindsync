# 通用解读知识库（无主题版本）

> 创建时间: 2026-03-05
> 文件位置: `app/core/general_interpretations.py`

---

## 概述

通用解读知识库提供**无主题**的五行解读，作为所有主题特化解读的**基础层**。

### 为什么需要通用解读？

1. **作为主题解读的 fallback** - 当特定主题缺少某条解读时，回退到通用版本
2. **支持无主题解读场景** - 用户未选择特定主题时，提供基础解读
3. **统一的解读框架** - 所有主题特化解读都基于相同的结构

## 三元论结构

与主题解读一致，通用解读采用**三元论**：

| 状态 | 含义 | 疗愈方向 |
|-----|------|---------|
| **太过** | 能量过度集中，可能淤堵 | 疏泄、释放、减少 |
| **正常** | 能量平衡健康 | 继续保持、深化 |
| **不足** | 能量偏弱，需要滋养 | 补充、增强、建立 |

### 颜色与状态映射

```python
COLOR_STATE_MAPPING = {
    "深绿": ("木", "太过"),
    "绿色": ("木", "正常"),
    "淡绿": ("木", "不足"),
    # ...
}
```

## 使用示例

### 1. 获取通用解读

```python
from app.core import get_general_interpretation

# 获取木元素在内圈太过状态的解读

{
```

## 通用解读 vs 主题特化解读

| 维度 | 通用解读 | 主题特化解读 |
|-----|---------|-------------|
| **适用范围** | 所有场景 | 特定主题（如父亲关系、财富事业） |
| **内容深度** | 基础心理特征 | 主题相关特化表现 |
| **使用时机** | 无主题选择 / fallback | 用户选择了特定主题 |
| **数据结构** | element -> circle -> state | theme -> element -> circle -> state |

### 层级关系

```
通用解读（基础层）
    ↓ 特化
主题解读（应用层）
    - 父亲关系
    - 母亲关系
    - 财富事业
    - 身体健康
    - 亲密关系
    - 亲子关系
    - 个人成长
```

## 与主题解读的对比示例

### 示例：内圈 + 木 + 太过

**通用解读**：
> 自我意识强烈，固执己见，独立但容易与他人产生冲突，内心有评判和抵抗。

**父亲关系主题特化**：

**财富事业主题特化**（假设）：
> 在事业发展上倾向于独立创业，不愿受雇于人，有自己的想法和规划，但可能与上级或合作伙伴产生分歧。

## 扩展指南

### 添加新的颜色映射

```python
COLOR_STATE_MAPPING.update({
    "草绿": ("木", "正常"),
    "翠绿": ("木", "太过"),
    # ...
})
```

### 修改特定解读

```python
GENERAL_ELEMENT_INTERPRETATIONS["火"]["circles"]["内圈"]["太过"]["interpretation"] = "新的解读内容"
```
