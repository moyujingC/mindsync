这里收口 V4 知识库使用的原始案例源。

案例源的用途不是直接定义规则，而是用于观察资深疗愈师如何组织一次完整解读：

- 如何从主题进入解读。
- 如何划分三圈并逐圈推进。
- 如何把颜色、形状、五行和相生相克关系连起来。
- 如何从卡点给出生机。
- 如何把调整方案落到绘画、冥想、呼吸、站桩、行动练习等具体动作。

## 当前案例源

- 原始来源：projects/aimandala/docs/sources/知识库构建/原始解读案例篇11例.md

## 使用边界

- 案例可以作为报告表达、追问回答和疗愈方案生成的风格来源。
- 案例中的判断口径如果和 V4 当前规则冲突，以 V4 当前规则为准。
- AI 可以学习案例的解读顺序和语言节奏，不应逐句照抄案例。
