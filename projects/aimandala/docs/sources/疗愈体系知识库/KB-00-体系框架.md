## 定位

本文档定义疗愈体系知识库的完整体系框架。

体系目标是沉淀一套可用于解读报告、追问回答、定制化疗愈方案、课程和衍生产品的完整疗愈体系。曼陀罗解读是当前第一条应用链路，不是知识库的边界。

---

## 一、体系架构

### 1.1 三层架构

```
疗愈体系知识库/
│
├── KB-01/（曼陀罗应用层）
│   └── 画面分析基础
│
├── KB-02/（曼陀罗映射层）
│   └── 画面特征 → 解读条目
│
├── KB-03/（议题层）
│   └── 17个议题子文档
│
├── KB-04/（疗愈方案层）
│   └── 颜色处方/绘画/冥想/习惯
│
├── KB-05/（执行规范层）
│   └── 报告/追问/课程/疗愈方案输出规范
│
└── 参考文献/
```

| 层级 | 定位 | 内容 |
|------|------|------|
| **曼陀罗应用层** | 分析曼陀罗画面 | 划分三圈 → 分析颜色、形状、位置关系 |
| **曼陀罗映射层** | 画面特征→解读条目 | 元素+位置→条目、五行生克、圈层关系 |
| **议题层** | 疗愈体系框架 | 所有解读条目的出处 |
| **疗愈方案层** | 行动落地 | 颜色处方、绘画疗愈、冥想引导、生活习惯 |
| **执行规范层** | 应用输出规则 | 报告、追问、课程、疗愈方案、交互流程 |

### 1.2 层级关系

```
曼陀罗应用层（分析画作）
    ↓ 产出画面特征
曼陀罗映射层（建立连接）
    ↓ 产出解读条目
议题层（给出意义）
    ↓
疗愈方案（行动落地）
```

后续如果开发课程、训练营、内容产品或其他疗愈工具，应优先复用 `KB-03` 议题层和 `KB-04` 疗愈方案层，再在 `KB-05` 中新增对应输出规范。

## 二、画面层（KB-01）

### 2.1 三圈划分

曼陀罗从中心到边缘划分为三个同心区域：

| 圈层 | 位置 | 比例 |
|------|------|------|
| **内圈** | 中心区域 | ~1/3 |
| **中圈** | 中间区域 | ~1/3 |
| **外圈** | 边缘区域 | ~1/3 |

### 2.2 画面分析要素

| 要素 | 内容 |
|------|------|
| **颜色** | 颜色种类、深度、分布、主次 |
| **形状** | 形状种类、特征、方向、组合 |
| **位置关系** | 位置分布、相互位置、边界关系 |

### 2.3 各圈特殊关注点

| 圈层 | 关注点 |
|------|--------|
| **内圈** | 中心充盈度、形状、核心能量 |
| **中圈** | 过渡状态、能量流动、图案密度 |
| **外圈** | 边缘完整性、厚度、边界清晰度 |

## 三、映射层（KB-02）

### 3.1 映射逻辑

**基础映射**：元素 + 位置 → 解读条目

| 组合类型 | 示例 |
|----------|------|
| 单元素+位置 | 绿色+内圈 |
| 多元素+位置 | 红色+圆形+内圈 |
| 关系组合 | 内圈绿色+中圈黄色 |

### 3.2 分析维度

| 范围 | 分析内容 |
|------|----------|
| **同圈内** | 五行生克（颜色/形状的五行属性、相生相克） |
| **跨圈** | 三才关系（内→中→外的能量流动、联动模式） |

### 3.3 失衡类型

| 类型 | 说明 |
|------|------|
| **圈内失衡** | 单圈内部的五行失衡 |
| **三才失衡** | 内/中/外三圈之间的关系失衡 |

## 四、议题层（KB-03）

### 4.1 MVP议题（用户主动选）

| 议题 | 说明 |
|------|------|
| **财富** | 金钱能量流动模式、家族财富传承、限制性信念 |
| **事业/发展** | 天赋与事业匹配、职业身份认同、事业与使命 |
| **亲密关系** | 依恋模式、关系能量模式、原生家庭复制 |
| **父亲关系** | 阳性能量整合、家族男性动力、身体印记 |
| **母亲关系** | 阴性能量整合、家族女性动力、身体印记 |
| **亲子关系** | 代际传承、投射与认同、父母自我成长 |
| **健康/身体** | 身心连接、症状心理意义（脏腑经络在此） |

### 4.2 浮现议题（解读中带出）

| 议题 | 说明 |
|------|------|
| **性格特质** | 性格阴阳五行属性、防御机制、两面性 |
| **情绪能量** | 情绪能量属性、流动模式、核心与表层情绪 |
| **内在小孩** | 受伤年龄与类型、疗愈阶段、内在父母关系 |
| **潜意识伤痛** | 个人/集体潜意识、家族系统牵连、转化路径 |
| **内在渴望** | 渴望层次与来源、与恐惧的关系、实现路径 |
| **天赋优势** | 天赋五行类型、识别与阻碍、发展与整合 |
| **人际关系** | 互动模式、投射与边界、创伤与自我关系 |
| **灵性成长** | 三才连接、成长阶段、灵性与生活整合 |
| **意识扩容** | 意识层次、限制性信念、扩容路径 |
| **自我关系** | 自尊与自爱、自我接纳、自我价值 |
