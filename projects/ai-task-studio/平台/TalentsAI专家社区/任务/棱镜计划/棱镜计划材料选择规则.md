> 来源：用户补充的飞书材料选择说明

本文件用于后续筛选棱镜计划素材。目标不是找“模型看不懂”的怪题，而是找真实工作或生活场景中确实会出现、且版式和语义足够复杂的文件。

## 1. 不合格材料

以下类型不建议使用：

- 插画、低分辨率、抽象风格图片作为主要考点。
- 不符合真实场景的纯文字识别题。
- 日常生活中不会以图片/PDF形式提问的材料。
- 色盲测试题、验证码题。
- 整个 PDF 只有一道计算题，且不是现实场景文件。
- Prompt 严重脱离现实场景，例如统计某个符号、某几个字眼、纯粹数局部元素。
- 图片过于模糊，连人工都难以稳定判断图例或对象含义。

判断口径：

- 如果材料主要靠“刁钻、模糊、反常识”让模型出错，不合格。
- 如果问题不像真实用户在工作或生活中会问的问题，不合格。
- 如果人工也很难明确判定唯一答案，不合格。

## 2. 合格材料的基本特征

优先选择真实工作或生活中会出现的文件，文件本身应有明确用途。

合格材料通常具备：

- 文件长度 5-80 页。
- 真实业务、学习、研究、生活或政务场景。
- 有图文混排、表格、脚注、图例、公式、批注、扫描质量、双语对照、嵌套表等复杂版式。
- 答案需要从文件中定位、比对、综合，而不是直接关键词读取。
- 答案唯一、可核验，人工能说清证据位置。

## 3. 专业场景优先方向

优先从以下 15 类专业场景中找素材：

| 场景 | 典型文件 | 适合的难点 |
| --- | --- | --- |
| 财务/费控 | 增值税发票、对账单、财报、结算单 | 版式多、查重、表格密集、跨表勾稽 |
| 法务/合同/合规 | 商务合同、修订稿、政策文件、卷宗 | 条款非标、长文版本对比、检索难 |
| HR/招聘 | 简历、身份证、学位证、offer、背调报告 | 版式自由、字段映射、真伪核验 |
| 销售/CRM/客户 | 名片、营业执照、品牌手册、授权书 | 扫描质量参差、图文混排、字段映射 |
| 采购/供应链/物流 | 订单确认、装箱单、提单、资质质检 | 模板多变、真伪、时效、品类核验 |
| 科研/学习 | 论文、研究报告、大批文献 | 长文压缩、原文定位、表格还原 |
| 知识管理/内部提效 | 手册、规章、产品文档、扫描档案 | 解析质量、检索定位、扎根回答 |
| 内容/风控/审核 | 教程 PDF、举报证据、医疗金融资质 | 违规判定、关键信息提取、资质真伪 |
| 个人事务/报告产出 | 个人文档、可填写表单、HTML 报告 | 格式锁定、字段对位、版式语义 |
| 政务/官方交互 | 报税、签证、社保表单、政策批文 | 字段对位、版式语义、提炼要点 |
| 金融个人事务 | 银行账单、保单、理赔单、纳税证明 | 表格密集、字段和条款理解、真伪时效 |
| 医疗健康 | 病历、检验报告、影像报告、临床试验 | 专业术语、版式杂、跨文档 |
| 电子票据/凭证 | 机票、火车票、说明书、保修卡 | 版式多、二维码、图文混排 |
| 广告/商业化产出 | 效果报告、结案提案、行业研报 | 复杂版式、图表、模板、指标接入 |
| 战略/市场研究 | 行业报告、竞品分析、咨询报告 | 跨文档综合、图表/表格还原 |

## 5. 合格样本启发

### 5.1 建筑设计图集

适合点：

- 同页混排鸟瞰图、人视图、平面图、立面图、剖面图。
- 数字标注密集，且不同图形语言代表不同含义。

可出题方向：

- 根据户型图和立面图共同判断某个空间或构件。
- 对照平面图、剖面图、标注尺寸回答问题。

### 5.2 PPT 转 PDF 的论文解读材料

适合点：

- 标题、主图、数据框、实物照片、示意图同页混排。
- 同页多个百分比指向不同指标。
- 示意图上的 A/B/C/D 小箭头需要和正文命名对应。

可出题方向：

- 对照图中位置标签和文字描述找指定实验条件。
- 区分同页多个百分比属于哪个指标。

### 5.3 商业研究报告

适合点：

- 地图、柱状图、折线图、饼图、政策表、嵌套表混排。
- 装饰性大数字、标签框、勾选框容易干扰。
- 世界地图和右侧区域表格需要对应。

可出题方向：

- 根据地图区域和表格字段共同定位答案。
- 对比政策表中时间、政策名、内容摘要和勾选范围。

### 5.4 双栏学术论文

适合点：

- 双栏布局、公式编号、跨栏公式、希腊字母、上下标密集。
- 正文引用公式和图，需要来回定位。
- 多面板图和 3D 色阶图含非常规坐标标记。

可出题方向：

- 根据正文引用定位公式编号并解释变量关系。
- 在多面板图中区分不同条件或配置。

### 5.5 扫描版年报

适合点：

- 中英双语对照，扫描质量不稳定。
- 5 年财务表、千分位数字、单位只在表头声明。
- 脱敏黑块、嵌套渠道小计容易造成字段错配。

可出题方向：

- 根据表头单位换算财务数字。
- 区分总计、小计、渠道细分和年份列。

## 6. 对首单失败的解释

`2024 年新闻出版统计公报` 虽然有表格、脚注和单位混合，但仍然偏简单：

- 页数只有 6 页。
- 表格规整。
- 指标名称明确。
- 证据集中在单页。
- 没有复杂图片、图例、双栏、扫描质量、嵌套图表或多文件交叉。

这类材料适合练习，不适合作为需要两个模型都出错的正式素材。

## 7. 后续选材检查清单

选材前先问：

- 这是不是现实中真实会用到的文件？
- 人工能否稳定找到唯一答案？
- 模型是否需要跨页、跨图表、跨图例或跨文件理解？
- 是否存在版式复杂性，而不只是题目文字绕？
- 是否低敏、授权清楚、非 AI 生成或改写？
- 如果模型答错，错误能否归因到真实解析难点，而不是题目设计不合理？

满足以上条件后，再进入题目设计。
