# 视频文字稿自动采集实现记录

> 状态：delivered
> 日期：2026-07-26
> source_of_truth：`tools/influencer-tracker/src/jobs/video-transcript.mjs`

## 实现内容

1. 新增视频文字稿工作流，遍历本次 TikHub 详情采到的视频内容。
2. 从原始响应中寻找 `subtitle`、`caption`、`transcript` 类字段；有字幕文本或字幕 URL 时，先调用既有提纯组件。
3. 无字幕时从 `play_addr`、`play_url`、`video_url`、`download_addr` 类字段提取 HTTPS 媒体地址，限制单文件 300 MB，下载后运行 `ffmpeg + Whisper + 提纯`。
4. 成功时把清理稿作为本地研究证据接入研究请求；研究简报显示视频文字稿完成数。飞书只收到收件处理结果，不保存逐字稿全文。
5. 媒体下载、转写或字段解析失败时，文字稿记录为失败，但内容详情、评论、研究请求和收件箱处理不会回滚。

## 部署

- release 服务器已安装 `ffmpeg` 与 `openai-whisper`。
- Worker systemd（系统服务管理器）服务增加了 Whisper 的用户可执行目录到 `PATH`。
- 视频与文字稿产物保存在 `/opt/content-matrix-inbox/app/logs/media-evidence/`；验证产物单独在 `logs/media-evidence-validation/`。
