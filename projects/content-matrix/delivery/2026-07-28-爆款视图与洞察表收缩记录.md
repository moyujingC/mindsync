## 调整

“内容更新”是唯一内容池。L1 指标、双维评分与 L2 文字稿都回写同一条内容行，不建立第二个 L2 内容库。

`爆款选题候选` 是“内容更新”的筛选视图，用来快速查看互动表现突出的内容；它不等于正式选题库，也不自动生成结论。

“洞察与选题”表保留为空表，改作人工确认后的正式结论库。只有你决定沉淀某个选题、需求假设或跨内容观察时才创建记录。

```text
内容更新（唯一内容池）
-> 爆款选题候选视图（先看）
-> L2 文字稿回写同一行（按干货信号自动处理）
-> 人工决定
-> 洞察与选题（少量正式结论）
```

## 自动化边界

- `爆款选题分 >= 80`：只进入爆款视图。
- `干货信号分 >= 70`：自动创建 L2 内容提纯任务。
- 不再自动创建“选题洞察”任务或写入“洞察与选题”。
