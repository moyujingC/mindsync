# AI营销获客系统阶段 6 P1 总体验收记录

本文记录 P1 的完成状态。P1 的目标是把本地 artifact 中的内容、转写和评论样本，转成可进入飞书 `洞察与选题` 表的人审候选，并具备批量处理、失败隔离、重试和运维报告能力。

## 1. P1 范围

P1 覆盖的是：

```text
artifact -> enrichment -> 洞察候选 -> 批量写入飞书 -> 报告 -> 失败重试
```

这里的 `enrichment` 指内容理解结果，包括：

- 服务方向判断
- 用户问题
- 需求信号
- 洞察
- 选题候选

## 2. 已完成能力

### P1-1 enrich 内容理解

已支持从 artifact 和评论样本生成 `enrichment.json`。

当前规则版 enrich 不调用 LLM（大语言模型），输出默认进入 `待人工审核`。

### P1-2 enrichment 转飞书洞察候选

已支持把单个 `enrichment.json` 转成飞书 `洞察与选题` 候选。

候选类型包括：

- `用户需求`
- `选题`

写入飞书时按 `来源内容 + 洞察类型` 去重。

### P1-3 批量 enrichment 写入

已支持递归扫描目录里的 `enrichment.json`，汇总后批量写入飞书。

### P1-4 批量写入报告与状态回写

已支持：

- JSON 报告
- `--mark-processed` 回写本地 enrichment 的 `handoff`
- `disabled` / `written` / `duplicate` / `empty` 状态

### P1-5 批量失败隔离

已支持坏 `enrichment.json` 不阻断整批。

坏文件会进入报告：

```text
status: failed
error: ...
```

### P1-6 基于报告的失败重试

已支持从上一轮报告中提取 `status: failed` 的 `enrichmentPath`，只重试失败项。

### P1-7 飞书写入阶段部分失败隔离

已支持整批飞书写入失败后，按 enrichment 分组降级重试。

成功项继续写入，失败项进入报告。

### P1-8 失败报告 Markdown 化

已支持 `--markdown-report` 输出人工可读报告。

Markdown 报告包含：

- 摘要
- 状态汇总
- 失败项
- 错误原因
- retry 命令

### P1-9 enrichment 写入范围筛选

已支持：

- `--date`
- `--creator`

用于限制本次批量写入范围，避免误扫历史 artifact。

## 3. 当前主命令

生成 enrichment：

```bash
node src/cli/enrich-content.mjs \
  --artifact-dir fixtures/bilibili-artifact.example \
  --comments fixtures/bilibili-comments.example.json
```

批量写入：

```bash
node src/cli/write-enrichment-directory-insights.mjs \
  --root-dir logs/downloads/bilibili \
  --date 2026-07-16 \
  --creator B站样例账号 \
  --feishu config/feishu.local.json \
  --report logs/enrichment-writes/2026-07-16-B站样例账号.json \
  --markdown-report logs/enrichment-writes/2026-07-16-B站样例账号.md \
  --mark-processed
```

失败重试：

```bash
node src/cli/retry-failed-enrichment-insights.mjs \
  --report logs/enrichment-writes/2026-07-16-B站样例账号.json \
  --feishu config/feishu.local.json \
  --retry-report logs/enrichment-writes/2026-07-16-B站样例账号-retry.json \
  --markdown-report logs/enrichment-writes/2026-07-16-B站样例账号-retry.md \
  --mark-processed
```

## 4. 验收标准

P1 验收标准如下：

- 能从本地 artifact 生成 enrichment。
- 能把 enrichment 转成飞书洞察候选。
- 能批量处理多个 enrichment。
- 能写入飞书或在无飞书配置时 dry-run。
- 能输出 JSON 报告。
- 能输出 Markdown 运维报告。
- 能把处理状态回写到 enrichment。
- 单个坏 enrichment 不阻断整批。
- 飞书写入阶段失败时能定位到 enrichment。
- 能基于报告只重试失败项。
- 能按日期和账号限制批量处理范围。

## 6. P1 结论
