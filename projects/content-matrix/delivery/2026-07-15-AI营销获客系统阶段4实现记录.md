# AI 营销获客系统阶段 4 实现记录

本文记录第三轮后续阶段实现：

```text
brief -> 草稿种子 + 飞书状态回写
```

对应路线图中的阶段 4：内容生产闭环。

## 本轮目标

上一轮已经能从飞书 `洞察与选题` 生成 Markdown brief。本轮继续往内容生产链路推进：

1. brief 生成后，可以同步生成“草稿种子”。
2. 草稿种子不直接等于成稿，而是给人工扩写、编辑、配图和排版的输入。
3. 处理完成后，可以把飞书 `洞察与选题` 的状态回写，避免同一选题反复进入生产。

## 实现步骤

### 1. 草稿种子生成

改动位置：

- `projects/content-matrix/tools/influencer-tracker/src/analysis/content-brief.mjs`
- `projects/content-matrix/tools/influencer-tracker/src/jobs/build-briefs.mjs`
- `projects/content-matrix/tools/influencer-tracker/src/cli/build-briefs.mjs`

实现方式：

1. 在 brief 对象基础上新增 `draftSeed`。
2. 草稿种子包含：
   - 标题。
   - 发布账号候选。
   - 开头草稿。
   - 草稿结构。
   - 证据来源。
   - CTA。
   - 人工审核清单。
3. 新增 CLI 参数：

```bash
--draft-dir logs/drafts
```

4. 传入 `--draft-dir` 时，同一条洞察会同时输出：
   - `logs/briefs/*.md`
   - `logs/drafts/*-draft.md`

设计取舍：

- 草稿种子只做“第一版写作入口”，不自动生成成稿。
- 不直接写入 `accounts/墨予镜/` 或其他账号目录，避免把未审核材料混进正式账号资产。
- 后续进入哪个账号目录，由人工根据账号定位决定。

### 2. 飞书状态回写

改动位置：

- `projects/content-matrix/tools/influencer-tracker/src/jobs/build-briefs.mjs`
- `projects/content-matrix/tools/influencer-tracker/src/cli/build-briefs.mjs`

实现方式：

1. 新增 CLI 参数：

```bash
--mark-status 已验证
```

2. 如果传入 `--mark-status`，每条已生成 brief / draft 的洞察会被回写到飞书：

```text
洞察与选题.状态 = 指定状态
```

3. 默认不回写飞书状态，避免自动推进未确认内容。

设计取舍：

- 当前飞书状态选项里没有 `已生成brief`，所以先使用已有选项 `已验证`。
- 后续如果要更精细，应扩展飞书字段选项：`已生成brief`、`已生成草稿`、`已进入成稿`。
- `--mark-status` 是显式动作，日常应在人工确认后使用。

## 命令

只生成 brief：

```bash
node src/cli/build-briefs.mjs --feishu config/feishu.local.json
```

生成 brief 和草稿种子：

```bash
node src/cli/build-briefs.mjs \
  --feishu config/feishu.local.json \
  --draft-dir logs/drafts
```

生成 brief / 草稿种子，并回写飞书状态：

```bash
node src/cli/build-briefs.mjs \
  --feishu config/feishu.local.json \
  --draft-dir logs/drafts \
  --mark-status 已验证
```

## 当前系统状态

现在系统已经跑通：

```text
飞书博主账号
-> 内容更新
-> 远端去重
-> 运行报告
-> 选题候选
-> 洞察与选题
-> 候选去重
-> 已审核选题
-> Markdown brief
-> 草稿种子
-> 飞书状态回写
```

这一步已经把内容生产链路接到了“可人工扩写”的入口。

## 残留风险

1. 飞书状态选项仍不够细，`已验证` 不能精确表达“已生成 brief / draft”。
2. 草稿种子是模板化结构，不是最终成稿。
3. 还没有接入 `内容视觉工坊` 的配图、封面和排版命令。
4. 还没有把发布链接、互动反馈、私信线索回写到飞书或 `ai-service-studio`。

## 下一步建议

下一步优先做：

```text
飞书状态选项扩展 + draft seed 进入账号草稿目录的人工确认命令
```

目标：

- 增加更准确的状态：`已生成brief`、`已生成草稿`。
- 增加一个显式命令，把某条 draft seed 转存到指定账号目录。
- 不自动发布，不绕过人工审核。
