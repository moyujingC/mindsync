# AI 营销获客系统阶段 4 成稿编辑入口实现记录

本文记录第五轮后续阶段实现：

```text
账号草稿 -> 成稿编辑任务包
```

对应路线图中的阶段 4：内容生产闭环。

## 本轮目标

上一轮已经能把 draft seed 转存到账号草稿目录。本轮继续往成稿链路推进，但不自动生成最终成稿。

目标是新增一个明确的编辑入口：

```text
账号草稿 -> 成稿编辑任务包 -> 人工 / AI 分轮编辑
```

## 实现步骤

### 1. 新增 prepare-edit job

改动位置：

- `projects/content-matrix/tools/influencer-tracker/src/jobs/prepare-edit.mjs`

实现方式：

1. 读取账号草稿 Markdown。
2. 抽取标题。
3. 生成成稿编辑任务包。
4. 任务包包含：
   - 目标账号。
   - 草稿来源。
   - 编辑规则来源。
   - 编辑边界。
   - 结构审稿提示词。
   - 表达降噪提示词。
   - 待发检查提示词。
   - 原始草稿全文。

设计取舍：

- 不在工具里自动“润色成稿”，避免丢失人工判断。
- 不复制完整编辑 skill，只引用 `墨予镜文章成稿编辑Skill-v1`，并内置最小执行版。
- 输出放在 `logs/edit-packages/`，默认不进入正式账号资产目录。

### 2. 新增 CLI

改动位置：

- `projects/content-matrix/tools/influencer-tracker/src/cli/prepare-edit.mjs`
- `projects/content-matrix/tools/influencer-tracker/package.json`

命令：

```bash
node src/cli/prepare-edit.mjs \
  --draft ../../accounts/墨予镜/2026-07-15-从AI服务第一条样例视频看AI工作流诊断的真实需求-草稿.md \
  --account 墨予镜
```

默认输出：

```text
logs/edit-packages/<日期>-<标题>-成稿编辑任务包.md
```

## 当前系统状态

现在系统已经跑通：

```text
飞书博主账号
-> 内容更新
-> 远端去重
-> 运行报告
-> 选题候选
-> 洞察与选题
-> 候选去重
-> 已审核选题
-> Markdown brief
-> 草稿种子
-> 飞书状态回写
-> 账号草稿目录
-> 成稿编辑任务包
```

这一步把内容生产链路接到了“成稿编辑入口”，但仍保留人工判断。

## 残留风险

1. 当前任务包只给编辑提示词，不自动生成成稿文件。
2. 样例草稿来自 fixture，不适合直接发布。
3. 还没有接入内容视觉工坊的配图、封面和排版。
4. 还没有把发布反馈、私信和咨询线索回写飞书。
