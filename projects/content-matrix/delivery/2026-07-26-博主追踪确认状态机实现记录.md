# 博主追踪确认状态机实现记录

> 状态：partial
> 日期：2026-07-26
> source_of_truth：`tools/influencer-tracker/src/jobs/creator-tracking.mjs`

## 实现内容

- 新增 `creator:tracking` 命令，支持准备确认卡片和确认写入两个阶段。
- 准备阶段解析主页、检查同一平台账号是否已存在，并将待确认动作保存到本地 JSON 文件。
- 确认阶段校验主题后才写入飞书；已有账号更新原记录，保留其名称。
- 新增 Hermes 可读的 `creator-tracking` Skill，明确不允许未确认写入。
- 工具与文档已同步到 release 服务器。

## 运行边界

- 当前没有飞书 Gateway，Hermes 还不能接收飞书聊天事件。
- 主题与需求库路由未落地前，默认频率应保持“手动”；不能据此开启每日 Worker。
- 本工具不能由 Hermes 自由调用任意飞书写操作，只允许准备和确认两种固定动作。

## 下一步

1. 配置飞书自建应用的消息事件和 Hermes Gateway。
2. 实现主题登记簿、需求登记簿与“博主 x 主题 x 需求库”路由。
3. 通过聊天真实跑一次“追踪 -> 补充信息 -> 确认 -> 每日任务检查”验收。
