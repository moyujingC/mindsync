# AI 营销获客系统阶段 5 调度接入与失败 SOP 实现记录

本文记录路线图阶段 5 的第三轮实现：

```text
日常入口统一
-> 调度接入
-> 连续失败时暂停采集
```

## 本轮目标

在上一轮之后，阶段 5 还差三块：

1. 缺少一个可直接接 cron（定时任务）/ Automation Platform（自动化平台）的统一入口。
2. 缺少正式的失败处理 SOP。
3. 缺少“数据源失效时暂停采集”的真实动作。

这一轮就是把这三块补齐。

## 实现步骤

### 1. 新增 ops-daily 统一日常入口

改动位置：

- `projects/content-matrix/tools/influencer-tracker/src/jobs/ops-daily.mjs`
- `projects/content-matrix/tools/influencer-tracker/src/cli/ops-daily.mjs`

实现方式：

一次命令顺序执行：

1. `run-daily` 采集更新。
2. 写 `logs/runs/YYYY-MM-DD/*.json` 运行报告。
3. 从运行报告生成选题候选。
4. 真实飞书模式下把选题候选写入 `洞察与选题`。
5. 生成每日摘要。
6. 生成失败账号复核报告。

这让阶段 5 不再依赖多条零散命令，而是有了真正适合调度系统调用的单入口。

### 2. 新增可直接接 cron 的脚本

改动位置：

- `projects/content-matrix/tools/influencer-tracker/scripts/run-ops-daily.sh`

这个脚本会：

1. 进入 tracker 工具目录。
2. 调用 `node src/cli/ops-daily.mjs --feishu config/feishu.local.json --pause-source`。
3. 把运行输出追加到 `logs/ops-daily.log`。

这样做的目的很简单：

- 先给本地 cron 一个稳定入口。
- 后面接 Automation Platform 时，也可以沿用同一条命令。

### 3. 失败账号支持自动暂停采集

改动位置：

- `projects/content-matrix/tools/influencer-tracker/src/jobs/failure-review.mjs`
- `projects/content-matrix/tools/influencer-tracker/src/cli/failure-review.mjs`

新增能力：

```bash
--pause-source
```

当配合：

```bash
--mark-status --pause-source
```

一起使用时，达到连续失败阈值的账号会被回写为：

```text
最近状态 = 需人工处理
启用状态 = 暂停
失败原因 = 连续失败 N 次：<最后一次错误>
```

这意味着路线图中的这条任务已经从“文档建议”变成“真实动作”：

```text
数据源失效时暂停采集
```

## 失败处理 SOP

### 触发条件

满足以下任一条件时，进入失败处理：

1. 单次运行出现失败，但还未达到阈值。
2. 最近 7 天内同一账号连续失败达到 3 次。

### 处理流程

1. 先看 `logs/failure-reviews/<date>.md`。
2. 判断失败原因是：
   - 账号 ID 填错。
   - RSS / 数据源地址失效。
   - 平台限制或网络波动。
   - 字段映射问题。
3. 如果只是临时波动：
   - 保持账号启用。
   - 下一次继续观察。
4. 如果确认是稳定失效：
   - 执行 `failure-review --mark-status --pause-source`。
   - 让飞书中该账号进入 `需人工处理` + `暂停`。
5. 如果账号仍值得跟踪：
   - B 站修复 RSS 源后恢复。
   - 抖音 / 小红书切回手工导入。
6. 修复完成后，人工把飞书账号状态改回：
   - `启用状态 = 启用`
   - `最近状态 = 正常`

### 当前边界

- 本轮不会自动恢复账号，恢复动作仍然保留人工判断。
- 本轮不会因为一次失败就自动暂停。
- 本轮不会自动判断平台是否永久不可用。



```bash
node src/cli/failure-review.mjs \
  --date 2026-07-15 \
  --lookback-days 7 \
  --threshold 3 \
  --feishu config/feishu.local.json \
  --mark-status \
  --pause-source
```
