# AI 营销获客系统阶段 4 发布反馈实现记录

本文记录路线图阶段 4 的补齐实现：

```text
成稿
-> 发布反馈记录模板
-> 周复盘统计入口
```

## 本轮目标

阶段 4 原本已经有：

- 选题生成 brief
- draft seed
- 草稿转存
- 成稿编辑任务包
- 成稿骨架

但还缺一个正式交付物：

```text
发布反馈记录格式
```

这一轮就是把它做成真正可用的模板和命令，而不是只停留在路线图描述里。

## 实现步骤

### 1. 新增 prepare-feedback 命令

改动位置：

- `projects/content-matrix/tools/influencer-tracker/src/jobs/prepare-feedback.mjs`
- `projects/content-matrix/tools/influencer-tracker/src/cli/prepare-feedback.mjs`

实现方式：

输入一篇 `*-成稿.md`，自动生成：

```text
<账号目录>/feedback/<日期>-<标题>-发布反馈.md
```

模板包含：

- 发布平台、链接、发布时间。
- 阅读 / 点赞 / 收藏 / 评论 / 转发 / 私信。
- 是否出现真实问题、资料样本意愿、咨询意向、样本沟通。
- 是否需要转入 `ai-service-studio` 记录。
- 下一步动作清单。

### 2. 周复盘接入反馈统计

改动位置：

- `projects/content-matrix/tools/influencer-tracker/src/jobs/weekly-review.mjs`
- `projects/content-matrix/tools/influencer-tracker/src/cli/weekly-review.mjs`

新增统计：

- 发布反馈记录数。
- 进入样本沟通数。
- 本周反馈文件列表。

这让阶段 5 的周复盘不再只看“采集和内容产物”，也开始能接发布后的反馈记录。

## 命令

生成发布反馈模板：

```bash
node src/cli/prepare-feedback.mjs \
  --final-draft ../../accounts/墨予镜/2026-07-15-从AI服务第一条样例视频看AI工作流诊断的真实需求-成稿.md \
  --account 墨予镜
```

或直接运行：

```bash
npm run prepare:feedback
```

## 残留风险

1. 当前只是反馈记录格式，不是自动发布或自动抓取反馈。
2. 真实外部反馈仍需要人工填写。
3. 转入 `ai-service-studio` 仍靠人工判断，不自动同步。

## 下一步建议

```text

```
