# AI 营销获客系统阶段 5 每日摘要实现记录

本文记录路线图阶段 5 的第一轮实现：

```text
运行报告 -> 每日摘要
```

## 本轮目标

阶段 5 里，最缺的不是命令数量，而是每日运维视角：

```text
今天跑了几次？
新增多少内容？
产生了多少选题？
有没有失败账号？
内容生产链路今天有没有新增产物？
```

本轮实现就是把这些信息聚合成一份每日 Markdown 摘要。

## 实现步骤

### 1. 新增 daily-summary job

改动位置：

- `projects/content-matrix/tools/influencer-tracker/src/jobs/daily-summary.mjs`
- `projects/content-matrix/tools/influencer-tracker/src/cli/daily-summary.mjs`

实现方式：

1. 读取指定日期的 `logs/runs/YYYY-MM-DD/*.json`。
2. 读取指定日期的 `logs/topic-candidates/*.json`。
3. 扫描账号目录当天生成的草稿 / 成稿文件。
4. 聚合出：
   - 运行报告数。
   - 新增内容数。
   - 重复内容数。
   - 失败运行数。
   - 选题批次数。
   - 选题候选数。
   - 账号草稿数。
   - 账号成稿骨架数。
   - 失败账号列表。
5. 输出 Markdown 到：

```text
logs/daily-summaries/<date>.md
```

### 2. 兼容账号目录杂项文件

真实目录里存在 `.DS_Store`。

本轮修复：

- 扫描账号目录时只处理真正的文件夹。
- 避免把 `.DS_Store` 当目录导致摘要命令失败。

## 命令
