# AI 营销获客系统阶段 4 成稿骨架实现记录

本文记录第六轮后续阶段实现：

```text
成稿编辑任务包 -> 账号成稿骨架
```

对应路线图中的阶段 4：内容生产闭环。

## 本轮目标

上一轮已经能从账号草稿生成成稿编辑任务包。本轮继续推进到账号目录里的 `*-成稿.md` 文件，但仍不自动生成最终成稿。

目标是新增一个明确的文件骨架：

```text
logs/edit-packages/*成稿编辑任务包.md
-> projects/content-matrix/accounts/<账号名>/<日期>-<标题>-成稿.md
```

## 实现步骤

### 1. 新增 scaffold-final job

改动位置：

- `projects/content-matrix/tools/influencer-tracker/src/jobs/scaffold-final.mjs`

实现方式：

1. 读取成稿编辑任务包。
2. 抽取标题、草稿来源、原始草稿。
3. 生成账号目录下的 `*-成稿.md`。
4. 文件头明确标记：

```text
状态：待人工编辑
```

5. 文件内保留编辑进度清单：
   - 结构审稿。
   - 表达降噪。
   - 风格校准。
   - 待发检查。
   - 来源内容人工复核。

6. 如果同名成稿文件已存在，默认失败，必须显式传 `--overwrite`。

设计取舍：

- 不自动润色，不自动生成最终正文。
- 成稿文件只是账号目录里的编辑工作台。
- 继续保留原始草稿备份，避免编辑时丢失来源判断。

### 2. 新增 CLI

改动位置：

- `projects/content-matrix/tools/influencer-tracker/src/cli/scaffold-final.mjs`
- `projects/content-matrix/tools/influencer-tracker/package.json`

命令：

```bash
node src/cli/scaffold-final.mjs \
  --edit-package logs/edit-packages/xxx-成稿编辑任务包.md \
  --account 墨予镜
```

可选覆盖：

```bash
--overwrite
```
