# AI 营销获客系统阶段 4 反馈转样本沟通实现记录

本文记录阶段 4 的又一轮补齐：

```text
发布反馈
-> 样本沟通记录
```

## 本轮目标

路线图里有一条要求一直没真正打通：

```text
如果出现私信、咨询或样本沟通，进入 ai-service-studio 的记录系统
```

这轮把它做成了可执行命令，而不是只靠人工复制粘贴。

## 实现步骤

### 1. 新增 promote-feedback 命令

改动位置：

- `projects/content-matrix/tools/influencer-tracker/src/jobs/promote-feedback.mjs`
- `projects/content-matrix/tools/influencer-tracker/src/cli/promote-feedback.mjs`

实现方式：

1. 读取一份 `发布反馈.md`。
2. 检查其中是否明确标记：

```text
是否需要转入 ai-service-studio 记录：是
```

3. 如果满足条件，就往：

```text
projects/ai-service-studio/records/样本沟通记录.md
```

追加一行样本沟通记录。

这样阶段 4 和 `ai-service-studio` 之间就第一次有了真正的文件级 handoff（交接）。

### 2. 修正反馈模板默认值

上一轮模板里有一处潜在误导：

- `是否进入样本沟通：是 / 否`

这会让周复盘很难分辨“尚未填写”和“已经确认是”。

本轮修正为默认：

```text
是否出现资料样本意愿：否
是否出现咨询意向：否
是否进入样本沟通：否
是否需要转入 ai-service-studio 记录：否
```

这样周复盘不会把空白模板误统计成真实服务信号。

## 命令

当一条内容反馈已经确认要转入 `ai-service-studio`：

```bash
node src/cli/promote-feedback.mjs \
  --feedback ../../accounts/墨予镜/feedback/2026-07-15-xxx-发布反馈.md \
  --service-direction AI工作流诊断
```
