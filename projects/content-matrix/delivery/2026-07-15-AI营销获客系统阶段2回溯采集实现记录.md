# AI 营销获客系统阶段 2 回溯采集实现记录

本文记录路线图阶段 2 的第二轮实现：

```text
backfill-creator 命令
```

## 本轮目标

路线图阶段 2 明确要求：

```text
新增 backfill-creator 命令，支持 --limit 和 --since，并写入统一内容表。
```

本轮实现就是把这条能力补上。

## 实现步骤

### 1. 新增 backfill-creator job

改动位置：

- `projects/content-matrix/tools/influencer-tracker/src/jobs/backfill-creator.mjs`
- `projects/content-matrix/tools/influencer-tracker/src/cli/backfill-creator.mjs`

实现方式：

1. 从本地 JSON 或飞书 `博主账号` 表加载 creator。
2. 通过 `--creator-id` 或 `--creator-name` 选中单个账号。
3. 复用现有平台 adapter 拉取内容。
4. 支持：
   - `--limit`
   - `--since`
5. 写入前同时检查：
   - 本地 store
   - 飞书 `内容更新` 表已有 `内容唯一键`
6. 只写入真正新增内容。
7. 运行结束后把本次 backfill 记录进 store。

### 2. 命令示例

本地 dry-run：

```bash
npm run backfill:sample
```

真实飞书运行：

```bash
node src/cli/backfill-creator.mjs \
  --feishu config/feishu.local.json \
  --creator-name B站样例账号 \
  --limit 20 \
  --store logs/content-store.backfill.feishu.json
```

设计取舍：

- 当前仍然先服务 B 站 RSS 和 fixture，不扩展平台抓取边界。
- 当前回溯采集沿用统一内容表，不单独开回溯表。
- 真实表里暂未单独写 `采集模式 = backfill` 字段，因为阶段 1 的字段扩展还未收口。
