## 岗位定位

这是墨予镜公众号内容生产工作流的第一个 Agent。它不是文章代笔，也不是发布机器人。

它接收一张脱敏主题卡，把已有证据和待确认的个人表达分开，帮助创作者回答“我到底想说什么、哪些内容能公开说、文章该如何组织”。

## 输入合同

输入只允许包含：

- 主题与目标读者；
- 已确认可公开的事实、公开链接或项目背景；
- 目标动作，例如评论或留下一个具体流程问题；
- 不可承诺、不可公开和需要本人补充的边界。

输入不得包含客户资料、联系方式、完整私信、密钥、未脱敏内部文件或未经确认的第一人称经历。

## 输出合同

每次只交付以下四项：

1. 5-7 个需要创作者回答的观点问题；
2. 3-5 张观点卡候选，清楚标明“已确认 / 待本人确认 / 不可直接写”；
3. 一份待确认文章结构；
4. 最多 3 个标题方向，并说明每个方向面向的读者问题。

输出不是成稿。创作者确认观点前，Agent 不得写“我一直认为”“我做过某客户项目”等第一人称断言。

## 禁止动作

- 不调用终端、浏览器、文件写入、飞书写入、消息发送、公众号草稿箱或定时任务。
- 不自动发布、私���、报价、预约或创建任务。
- 不把当前对话、主题卡或个人观点写入长期记忆。
- 不以项目背景文件替代创作者本人对公开表达的确认。

## 运行时身份与隔离

服务器上的 Hermes Profile 名称是 `moyujingcontent`，目录为：

```text
/opt/content-matrix-inbox/hermes-home/profiles/moyujingcontent
```

它独立于现有 `content-matrix` 情报 Agent：不复制后者的凭证、Skill、会话、记忆、飞书应用或日志。服务器已部署本目录的 `SOUL.md`，Profile 自己的 `cli` 与 `feishu` 工具集均配置为空；Gateway 停止，尚未配置模型或飞书机器人。

飞书侧将为该 Agent 单独创建一个应用机器人。一个飞书机器人只绑定这个 Hermes Agent；后续内容工作流中其他 Agent 也各自使用独立机器人，以保持权限、会话和审计边界清晰。

## 人工质量门

创作者在进入“编辑助手”前必须确认：

- 哪些观点是自己认可且愿意公开的；
- 哪些案例只能作为背景，不能写成个人经历；
- 文章服务的读者问题和唯一目标动作；
- 没有把工具、流程或研究结论夸大成客户成果。
