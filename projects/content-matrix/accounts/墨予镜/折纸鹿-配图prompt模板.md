# 折纸鹿 · 生图 Prompt 模板

> 状态：current
> 版本：v0.1
> 日期：2026-08-18
> 用途：公众号配图 / 公众号封面 / 小红书封面的文生图 prompt 复用底稿
> 生成服务：aitechflux / gpt-image-2（或同等文生图）
> 视觉依据：[账号定位与视觉规范.md](账号定位与视觉规范.md)

## 怎么用

每张图 = 「通用风格底座」+「具体画面」+「通用负面清单」三段拼起来。

- 公众号配图 / 封面 / 小红书封面共用同一个底座和负面清单，只改中间「具体画面」段。
- 方括号 `[ ]` 是占位符，按当篇内容替换；折纸鹿的形态、颜色、风格描述不要动，保证跨图一致。

## 通用风格底座（复制）

```
一只橙色的折纸鹿（origami 折纸风格：纸张质感、清晰折痕、几何折面、棱角分明、微微可见纸张厚度），是「墨予镜」企业 AI 落地内容的固定视觉 IP。整体风格是编辑感商务插画：扁平几何、克制留白、浅底低饱和，类似高端商业杂志 / 企业 SaaS 配图质感。配色：暖白浅米基底 + 石墨深灰结构线条 + 橙色点睛，折纸鹿的折面用不同深浅的橙（焦糖橙到浅橙）表现明暗层次。
```

## 通用负面清单（复制）

```
不要出现任何文字、字母、数字、符号、标题、标签；不要写实照片感、不要 3D 渲染、不要塑料或金属质感（折纸应是纸的质感）；不要可爱化、低幼化、不要赛博朋克霓虹、不要营销海报感。
```

## 1. 公众号配图（横版 1080×720，氛围图）

```
[通用风格底座]

画面：橙色的折纸鹿安静地站在[场景描述]旁，呈观察、思考的姿态，几何化的鹿角清晰可见。
画幅：横版 16:9（1080×720）。

[通用负面清单]
```

场景示例（按文章内容挑或改写）：
- 一张企业工作台与白板旁
- 一条抽象的流程线 / 信息结构之间
- 一扇窗前，望向远处

## 2. 公众号封面（横版 900×383，氛围图）

```
[通用风格底座]

画面：橙色的折纸鹿作为画面主角，构图居中或偏一侧，四周留出大量干净空白（留给微信叠加标题）。
画幅：横版 900×383（2.35:1），主体不要贴边，标题区保持空白。

[通用负面清单]
```

## 3. 小红书封面（竖版 1080×1440）

```
[通用风格底座]

画面：橙色的折纸鹿作为视觉主角，占据画面中心偏上，几何折面与鹿角突出，构图简洁有力、记忆点强。
画幅：竖版 3:4（1080×1440）。

[通用负面清单]
```

## 说明

- 当前三套都是**无文字氛围图**：文字由公众号 / 小红书标题栏承担，图上不放字。
- 小红书若后续要叠标题字，可先出无字底图再单独叠字，保持折纸鹿本体不变。
- 折纸鹿的「橙 + 几何折面 + 分叉鹿角」是记忆点，换场景时不要改这三样，才能跨图保持同一 IP。
