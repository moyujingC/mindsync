> 状态：current

> 生成服务：aitechflux / gpt-image-2（或同等文生图）
> 视觉依据：[账号定位与视觉规范](账号定位与视觉规范.md)

## 怎么用

每张图 = 「通用风格底座」+「具体画面」+「通用负面清单」三段拼起来。

- logo / 头像 / 封面 / 配图共用同一个底座和负面清单，只改中间「具体画面」段。
- 方括号 `[ ]` 是占位符，按当篇内容替换；鹿吉祥物的形态、颜色、动作、风格描述不要动，保证跨图一致。
- 母版已定为：侧身站立，一只前蹄轻轻抬起，头微微侧转回望镜头，眼神明亮机灵。后续所有图复用这组锚点，只换场景 / 画幅 / 配件。
- 这是第 1 档锚点锁定做法；偏差超预期再升级到图生图。

## 通用风格底座（复制）

```
一只机灵可爱的 3D 鹿吉祥物，是「墨予镜」企业 AI 落地内容的固定视觉 IP，同时承担品牌 logo 职责。圆润柔和的头部、偏萌系的大头比例，几何化的分叉鹿角是核心记忆点，鹿角保持清晰的几何尖角。标准动作：侧身站立，一只前蹄轻轻抬起，头微微侧转回望镜头，姿态轻盈有动势，眼神明亮机灵、嘴角带淡淡笑意。

材质与光影：柔和光影、磨砂或软胶质感，圆润立体，干净有质感，不是写实照片、不是廉价塑料玩具。

配色：主色为克制、温暖的橙色，配暖白 / 浅米基底，可点缀石墨深灰；体积光影用不同深浅的橙表现层次。

风格：高端企业品牌 3D 吉祥物，可爱但不低幼，专业可信、机灵有灵气，类似「得到」App 猫头鹰的质感分寸。
```
