# 墨予镜 · FDE 系列卡片库

> 位置：projects/content-matrix/accounts/墨予镜/cards/
> 用途：存放《FDE 视角下的企业 AI 落地》连载系列的内容卡片
> 规则：草稿与成稿分离，卡片定内容，成稿定表达

---

## 目录结构

```
cards/
  inputs/          # 输入卡片：来自课程的单个观点
  themes/          # 主题卡片：一篇文章的一组卡片
  drafts/          # 文章草稿：由主题卡片拼装而成
  assets/          # 可复用资产：模板、checklist、话术
```

---

## 卡片流转

```text
课程原文 / Agent 输出
        ↓
inputs/     （一个观点一张卡）
        ↓
themes/     （一篇文章一组卡）
        ↓
drafts/     （卡片拼装成文章草稿）
        ↓
成稿文件（-成稿.md，放在墨予镜账号根目录）
```

---

## 输入卡片格式

每张输入卡片只写一个观点：

```markdown
# 卡片标题：一个可复用的判断

## 观点
这个观点是什么？

## 来源
谁在哪里说的？引用课程/章节。

## 边界
适用的边界条件是什么？

## 反例
常见误用或反例是什么？

## 我的判断
同意 / 修正 / 反对，以及为什么。
```

---

## 主题卡片格式

每篇长文对应一组主题卡片：

```markdown
# 主题卡片：文章标题

## 问题卡
这篇文章要解决什么问题？

## 认知卡
读者常见的错误认知是什么？

## 框架卡
你要给出的核心判断或框架是什么？

## 案例卡
用什么案例或证据支撑？

## 行动卡
读者可以怎么做？
```

---

## 命名规则

- 输入卡片：`inputs/YYYY-MM-DD-主题-观点关键词.md`
- 主题卡片：`themes/模块X-第X篇-文章标题.md`
- 草稿：`drafts/YYYY-MM-DD-文章标题-草稿.md`
- 资产：`assets/资产名称-v0.1.md`
