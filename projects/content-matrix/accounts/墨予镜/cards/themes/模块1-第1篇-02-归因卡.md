# 主题卡片 2：归因卡

## 核心判断

POC 后死掉，问题通常不在模型，而在**把 POC 当成了终点**。

## 为什么模型不是瓶颈

- 模型是大家都能买到的，不是壁垒
- 模型更聪明，解决不了系统级缺陷
- POC 期的人工盯着、精选样本、理想环境，掩盖了真实问题
- 死亡发生在"模型之外"：评估、状态、权限、可观测、反馈闭环

## 常见错误归因

| 错误归因 | 真实情况 |
|---------|---------|
| "模型不够强" | 模型只是提议者，工程系统才是裁判 |
| "Prompt 没写好" | 单次 Prompt 的成功无法复制到生产 |
| "数据不够" | 数据问题往往只是表面，根因是评估标准和反馈链路 |
| "业务不配合" | 业务配合的前提是 POC 设计时就定义了停止条件和成功指标 |
