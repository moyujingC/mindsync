# 主题卡片 4：框架卡

## 核心判断

POC 后死掉的新归因框架：**Harness 没搭起来**。

## 什么是 Harness

Harness 是套在模型外面、让模型在真实世界里可靠运行的一整套控制与运行环境。

它包括：
- 指令层（AGENTS.md / constitution）
- 执行循环层（Main Loop / ReAct / TAO）
- 工具与技能层（Tools / Skills / MCP）
- 上下文与记忆层
- 状态与规划层
- 拦截与护栏层
- 可观测与评估层
- 环境与运行层

## 为什么 Harness 是答案

- 模型决定智力上限，Harness 决定智力能在现实世界发挥几成
- POC 只验证了模型能力，Harness 验证的是系统能力
- FDE 的工作，就是把 POC 级的能力工程化成生产级 Harness
