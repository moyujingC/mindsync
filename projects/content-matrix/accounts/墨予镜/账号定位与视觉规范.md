## 1. 账号定位

`墨予镜` 是创作者本人的个人 IP 账号，归属于 `内容矩阵` 项目。

它承接的是创作者在 AI、产品、研究、内容、疗愈与个人成长交叉处的长期表达。这个账号应让读者感到：这是一个真实在做事的人，在用工程化的方法整理自己的实践、判断和边界。

### 1.1 一句话定位

```text
一个用 AI 做产品、做研究、做内容，也持续观察人如何在工具时代保持清醒的独立开发者 / 疗愈师。
```

### 1.2 账号角色

- 独立开发者：持续搭建产品、工作流、研究系统和内容工具。
- AI 重度使用者：分享真实协作经验、踩坑、边界和方法。
- 产品与研究实践者：把外部观察、开源拆解和项目实践转成可复用框架。
- 疗愈师 / 教练视角持有者：关注人的状态、精力、关系、成长和改变机制。

### 1.3 读者感知

读者打开 `墨予镜` 的内容时，应预期看到：

- 有真实项目现场，而不是抽象建议。
- 有方法和框架，但不压迫人。
- 有 AI 和技术，但人仍然在中心。
- 有成长和疗愈视角，但不做鸡汤式安慰。
- 有判断和边界，不追逐工具崇拜。

### 1.4 不适合的方向

- 纯教程号：只讲工具步骤、提示词模板、效率技巧。
- 情绪流量号：用焦虑、崩溃、逆袭制造点击。
- 玄学人设号：直接把神秘化表达作为第一层传播语言。
- AI 科技媒体号：只追热点、参数、模型发布和行业新闻。
- 产品营销号：把个人号变成产品功能宣传入口。

## 2. 内容气质

### 2.1 关键词

- 表达精准
- 真实
- 有边界
- 有方法
- 疗愈感
- 松弛
- 技术感
- 人文感

### 2.2 语气

默认语气是第一人称复盘 + 分享型表达。

句子应直接、具体，像在把一个真实问题讲清楚，再把其中可复用的观察分享出来。可以有个人判断，但不要替读者下过度绝对的结论，也不要使用居高临下的教学口吻。

适合：

- “我后来发现……”
- “这件事真正麻烦的地方在于……”
- “对我来说，这不是效率问题，而是质量风险。”
- “我现在会把这类任务降级处理。”

避免：

- “你必须……”
- “普通人只要掌握这套方法……”
- “真正厉害的人都……”
- “AI 时代不做这个就会被淘汰。”

### 2.3 内容母题

这里的母题是账号未来 1-3 年的内容领地设计，不是对当前几篇文章的归纳。近期内容可以从其中某一两条展开，但不能反过来限制账号的长期边界。

- 人如何在工具时代保持主体性：AI、自动化、效率、判断力、注意力、精力边界和生活节奏。
- 一人公司与独立创造者系统：从想法、研究、产品、内容、交付到复盘，如何搭建自己的长期操作系统。
- 产品、研究与内容的复合实践：产品观察、行业研究、开源拆解、知识资产、内容转译和作品化表达。
- 疗愈与成长的现代转译：情绪、关系、身体感、内在秩序、自我修复和改变机制，用大众能理解的语言表达。
- 职业与身份重建：求职、转型、能力表达、作品集、个人叙事，以及人在不同阶段如何重新组织自己。
- 东方文化、审美与个人方法：把传统文化、象征系统、节律感和审美体验转成当代可理解、可实践的表达。
- 真实项目现场：产品建设、工具选择、失败复盘、取舍过程和阶段性成果，让读者看到一个人如何把想法落到现实里。

## 3. 视觉素材规格

### 3.1 美术定位

```text
星际文明风 + 灵性科技 + 高维疗愈感
```

`墨予镜` 的视觉可以把科技和疗愈放在同一套世界观里：科技不是冰冷机器，疗愈也不是软塌塌的情绪安慰，而是一种更高维、更有秩序、更有能量感的文明系统。

画面应像来自一个更高级文明的知识界面、星图、能量场或疗愈舱。它有科技感，也有灵性；有未来感，也有安定感；有秩序，也有光。

关键词：

- 星际文明
- 灵性科技
- 高维疗愈
- 星图与能量场
- 光之建筑
- 神圣几何
- 透明界面
- 水晶质感
- 星云、光环、粒子、频率线
- 安定、开阔、被支持

避免：

- 冰冷硬科技。
- 机器人和机械脑袋。
- 赛博朋克霓虹街景。
- 普通 AI 工具官网风。
- 商业课程海报感。
- 过度玄学、廉价占卜、神秘主义符号堆砌。
- 卡通治愈、手账贴纸、低幼可爱。

### 3.2 色彩与材质

推荐色彩方向：

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 深空蓝黑 | `#07111F` | 深色封面、星际背景、主视觉空间 |
| 星云靛紫 | `#433B8F` | 高维、灵性科技、能量层 |
| 能量青 | `#4DD6D0` | 科技界面、频率线、疗愈光 |
| 月光银白 | `#F4F7FF` | 文字底、光体、留白 |
| 光晕金 | `#D9B86F` | 重点、核心能量、温度 |
| 星尘灰蓝 | `#8897B3` | 辅助信息、阴影、层次 |

材质方向：

- 半透明玻璃。
- 水晶、光体、能量膜。
- 细密星尘和微粒光。
- 柔和发光边缘。
- 有秩序的几何线，不做杂乱电路板。

### 3.3 公众号封面

- 推荐比例：`2.35:1`
- 推荐尺寸：`2350 x 1000` 或 `2048 x 872`
- 标题区：右侧或上方保留干净留白。
- 主视觉：星图、光之建筑、能量场、星际疗愈空间或高维知识界面，根据单篇文章确定。

构图要求：

- 需要为后期标题排版保留稳定区域。
- 入口图要能在公众号列表里识别标题和主题。
- 不让生图模型生成大量中文。

避免：

- 满版细节导致标题无处放。
- 图片里直接生成大量中文。
- 画面元素比文章主题更抢眼。

封面 Prompt 基线：

```text
Use case: WeChat public account article cover image, no in-image text.
Create a star-civilization style cover for a Chinese personal essay by "墨予镜".
Visual direction: spiritual technology, high-dimensional healing, advanced civilization, luminous order, calm power.
Scene: a vast cosmic knowledge space, star map, light architecture, transparent energy interface, or healing chamber from an advanced interstellar civilization.
Composition: landscape 2.35:1, clear focal point, clean title area for later Chinese typography, cinematic but not noisy.
Materials: translucent crystal, soft light field, star dust, geometric energy lines, silver-white glow, deep space background.
Color palette: deep space blue-black, nebula indigo, moonlight silver-white, energy cyan, subtle halo gold.
Text: none.
Avoid: robots, mechanical heads, cyberpunk street neon, cold corporate AI website, chaotic sci-fi UI, cheap occult symbols, cartoon healing stickers, readable fake Chinese text.
```

### 3.4 小红书封面

- 推荐比例：`3:4`
- 推荐尺寸：`1536 x 2048`
- 主标题：建议后期排版，不让生图模型直接生成。
- 视觉区和文字区必须分清，避免标题压住主体。

小红书需要比公众号更强入口感，但不能变成焦虑营销。

适合：

- 大标题 + 一句副标题 + 一个清晰视觉主题。
- 单图只讲一个判断。
- 信息层级能被快速扫读。

避免：

- 七八个信息块挤在一张图。
- 大红大黄流量标题。
- “焦虑痛点 + 夸张结果”式版面。

小红书封面 Prompt 基线：

```text
Use case: Xiaohongshu vertical cover image, no in-image text.
Create a vertical star-civilization style cover for "墨予镜".
Visual direction: spiritual technology, high-dimensional healing, future civilization, luminous and expansive.
Composition: 3:4 vertical, strong visual center in the upper two-thirds, clean lower or middle area for Chinese title overlay.
Subject: a star map, luminous portal, healing energy field, crystal interface, or high-dimensional knowledge structure.
Mood: open, supported, precise, healing, not anxious.
Color palette: deep space blue-black, nebula indigo, moonlight white, energy cyan, subtle gold light.
Text: none.
Avoid: dense text, red-yellow marketing template, robots, cyberpunk street, cheap mysticism, childish cute style, fake Chinese text.
```

### 3.5 公众号长文配图

公众号长文配图不是封面，也不是知识卡片。它只服务正文阅读节奏，让读者在一个段落后停一下。

规格：

- 推荐比例：`3:2` 或 `4:3`
- 推荐尺寸：`1536 x 1024` 或 `1600 x 1200`
- 插入频率：1500-2200 字一张，或只在关键转折处放一张。
- 一篇 3000-5000 字长文建议 2-4 张。

适合：

- 只表达当前段落的一个核心信息。
- 图片不抢正文，不承担完整论证。
- 能自然插入段落之间。

避免：

- 做成横版海报。
- 在图里写长句。
- 把整篇文章结构塞进一张图。
- 用封面式强标题。

正文配图 Prompt 基线：

```text
Use case: WeChat article inline illustration, no in-image text.
Create a horizontal inline illustration in star-civilization and spiritual technology style for a Chinese long-form essay by "墨予镜".
The image should support one section idea, not act as a cover or infographic.
Visual direction: high-dimensional healing, luminous structure, star map, energy field, transparent interface, sacred geometry.
Composition: horizontal 3:2, one clear visual idea, enough breathing space, calm but not plain.
Color palette: deep space blue-black, silver-white glow, energy cyan, nebula indigo, subtle halo gold.
Text: none.
Avoid: readable text, robots, cold dashboard UI, chaotic sci-fi panels, cyberpunk neon street, cheap occult symbols, marketing poster style.
```

### 3.6 小红书知识卡片

知识卡片用于把公众号长文里的判断、框架和方法拆成可保存、可滑读的图文。它应比正文配图更结构化，但仍保持简洁。

规格：

- 推荐比例：`3:4`
- 推荐尺寸：`1536 x 2048`
- 一组张数：3-7 张。
- 每张只讲一个判断或一个步骤。

单张结构建议：

1. 顶部：短标题，12 字以内优先。
2. 中部：一个视觉主题或结构图。
3. 下部：2-4 行解释文字或 3 个要点。
4. 页脚：账号名 `墨予镜`，低调放置。

卡片 Prompt 基线：

```text
Use case: Xiaohongshu knowledge card, Chinese layout.
Create one 3:4 knowledge card for "墨予镜" in star-civilization and spiritual technology style.
Theme: [card title].
Summary: [card summary].
Layout: clear Chinese title area, one high-dimensional visual structure or star-map diagram, concise explanation area, small account mark "墨予镜".
Visual direction: advanced civilization interface, luminous geometry, healing energy field, precise but warm.
Color palette: deep space blue-black, moonlight white, energy cyan, nebula indigo, subtle halo gold.
Constraints: keep Chinese text sparse and readable; do not generate long paragraphs or fake dense Chinese.
Avoid: crowded infographic, red-yellow marketing template, cyberpunk neon, robot face, childish stickers, cheap occult aesthetic.
```

### 3.7 账号头像

头像应成为跨平台稳定识别符号，不绑定真实肖像。推荐方向是“星际镜面 / 高维星图 / 光之印记”：让 `墨予镜` 的“镜”像一个可以映照星图和内在秩序的高维界面。

头像元素：

- 圆形星际镜面。
- 星图或光环结构。
- 简洁的神圣几何。
- 水晶或银白光体。
- 小尺寸下仍能识别的中心符号。

不建议：

- 真人 AI 肖像。
- 机器人头像。
- 复杂到小尺寸无法识别的图形。
- 与账号长期定位无关的装饰符号。

头像 Prompt 基线：

```text
Use case: social media avatar, circular crop.
Create a symbolic avatar for a Chinese personal IP named "墨予镜".
Visual concept: an interstellar mirror, high-dimensional star map, luminous seal, spiritual technology, healing civilization.
Composition: centered icon, strong silhouette, readable at small size, works in circular crop.
Materials: crystal, silver-white light, subtle star dust, geometric energy ring.
Color palette: deep space blue-black, moonlight silver-white, energy cyan, subtle halo gold.
Text: none.
Avoid: human portrait, robot, anime style, cyberpunk neon, cheap occult symbols, complex calligraphy, over-detailed illustration.
```

## 4. 公众号排版

### 4.1 排版气质

公众号排版应先服务长文阅读，再用少量星际文明元素建立账号识别。正文不建议整篇深色底，深空感更适合用于封面、分割、引用块、尾部 CTA 或局部强调。

关键词：

- 清晰正文
- 宽松行距
- 清晰标题层级
- 银蓝 / 能量青强调
- 星图式分割线
- 少量光感
- 配图之间有呼吸

### 4.2 建议参数

| 模块 | 建议 |
| --- | --- |
| 正文背景 | `#FFFFFF` |
| 外层底色 | `#F4F7FF` |
| 正文颜色 | `#273142` |
| 标题颜色 | `#07111F` |
| 小标题颜色 | `#433B8F` |
| 弱文字 | `#8897B3` |
| 引用背景 | `#F2F7FF` |
| 引用边线 | `#4DD6D0` |
| 段落间距 | `18px` |
| 小节间距 | `28px` |
| 小标题字号 | `20-22px` |
| 正文字号 | `16-17px` |
| 正文行高 | `1.85-2.0` |
| 图片圆角 | `8px` |
| 引用圆角 | `10px` |

### 4.3 文章结构

推荐结构：

1. 标题。
2. 一段短引子，直接进入真实问题。
3. 2-5 个小标题，每节只讲一个判断。
4. 关键句用引用块或加粗，不频繁上色。
5. 结尾用一个低调行动提示：留言、在看、转发给同样在思考的人。

### 4.4 排版禁区

- 大面积彩色底块。
- 连续使用居中大字。
- 每段都加粗。
- 大量 emoji 或装饰符号。
- 多层卡片嵌套。
- 过度课程化的“总结 / 行动清单 / 福利领取”视觉。

## 6. 使用规则

- 新文章先判断内容类型，再决定需要哪些视觉素材。
- 默认美术方向使用“星际文明风 + 灵性科技 + 高维疗愈感”。
- 求职向小红书可以更清晰、更结构化，但仍不要做强销售感简历海报。
- 所有涉及第一人称经历和个人立场的内容，仍受 [个人真实信息与表达基线](../../../../company/projects/内容矩阵/个人真实信息与表达基线.md) 约束。
