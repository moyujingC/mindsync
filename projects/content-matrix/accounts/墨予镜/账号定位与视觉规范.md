## 1. 账号定位

`墨予镜` 是创作者本人的个人 IP 账号，归属于 `内容矩阵` 项目。

它承接的是创作者在 AI、产品、研究、内容、疗愈与个人成长交叉处的长期表达。这个账号应让读者感到：这是一个真实在做事的人，在用工程化的方法整理自己的实践、判断和边界。

### 1.1 一句话定位

```text
一个用 AI 做产品、做研究、做内容，也持续观察人如何在工具时代保持清醒的独立开发者 / 疗愈师。
```

### 1.2 账号角色

- 独立开发者：持续搭建产品、工作流、研究系统和内容工具。
- AI 重度使用者：分享真实协作经验、踩坑、边界和方法。
- 产品与研究实践者：把外部观察、开源拆解和项目实践转成可复用框架。
- 疗愈师 / 教练视角持有者：关注人的状态、精力、关系、成长和改变机制。

### 1.3 读者感知

读者打开 `墨予镜` 的内容时，应预期看到：

- 有真实项目现场，而不是抽象建议。
- 有方法和框架，但不压迫人。
- 有 AI 和技术，但人仍然在中心。
- 有成长和疗愈视角，但不做鸡汤式安慰。
- 有判断和边界，不追逐工具崇拜。

### 1.4 不适合的方向

- 纯教程号：只讲工具步骤、提示词模板、效率技巧。
- 情绪流量号：用焦虑、崩溃、逆袭制造点击。
- 玄学人设号：直接把神秘化表达作为第一层传播语言。
- AI 科技媒体号：只追热点、参数、模型发布和行业新闻。
- 产品营销号：把个人号变成产品功能宣传入口。

## 2. 内容气质

### 2.1 关键词

- 表达精准
- 真实
- 有边界
- 有方法
- 疗愈感
- 松弛
- 技术感
- 人文感

### 2.2 语气

默认语气是第一人称复盘 + 分享型表达。

句子应直接、具体，像在把一个真实问题讲清楚，再把其中可复用的观察分享出来。可以有个人判断，但不要替读者下过度绝对的结论，也不要使用居高临下的教学口吻。

适合：

- “我后来发现……”
- “这件事真正麻烦的地方在于……”
- “对我来说，这不是效率问题，而是质量风险。”
- “我现在会把这类任务降级处理。”

避免：

- “你必须……”
- “普通人只要掌握这套方法……”
- “真正厉害的人都……”
- “AI 时代不做这个就会被淘汰。”

### 2.3 内容母题

这里的母题是账号未来 1-3 年的内容领地设计，不是对当前几篇文章的归纳。近期内容可以从其中某一两条展开，但不能反过来限制账号的长期边界。

- 人如何在工具时代保持主体性：AI、自动化、效率、判断力、注意力、精力边界和生活节奏。
- 一人公司与独立创造者系统：从想法、研究、产品、内容、交付到复盘，如何搭建自己的长期操作系统。
- 产品、研究与内容的复合实践：产品观察、行业研究、开源拆解、知识资产、内容转译和作品化表达。
- 疗愈与成长的现代转译：情绪、关系、身体感、内在秩序、自我修复和改变机制，用大众能理解的语言表达。
- 职业与身份重建：求职、转型、能力表达、作品集、个人叙事，以及人在不同阶段如何重新组织自己。
- 东方文化、审美与个人方法：把传统文化、象征系统、节律感和审美体验转成当代可理解、可实践的表达。
- 真实项目现场：产品建设、工具选择、失败复盘、取舍过程和阶段性成果，让读者看到一个人如何把想法落到现实里。

## 3. 视觉素材规格

### 3.1 美术定位

```text
纸本人文科技 + 克制结构感 + 安静观察视角
```

`墨予镜` 不是纯科技媒体号，也不是纯疗愈氛围号。它更适合一种被整理过、被驯化过的人文科技感：有科技语义，但不冰冷；有纸本和手感，但不低幼；有结构和秩序，但不做工具面板风。

这套视觉的核心不在“题材统一”，而在“气质统一”。即使内容涉及 AI、产品、电影、书摘、个人判断，它们放在一个账号里仍然应该成立，因为画面共享的是同一层骨架：

- 克制
- 安静
- 有留白
- 有结构
- 有编辑感
- 人仍然在场

账号的科技感不应表现为赛博朋克、机械感、参数感，而应表现为一种更冷静的认知气质：抽象、秩序、观察、折射、留白、被整理过的未来感。

#### 3.1.1 主风格骨架

- 纸张、纤维、胶带、留边、压痕、拼贴、手写线条。
- 杂志感、说明书感、研究卡片感、专栏页感。
- 低饱和、浅底、安静、轻呼吸感。
- 结构化，但不做冰冷表格或后台界面。
- 画面像“一个人在认真整理自己的判断”，而不是“一个工具在展示功能”。

#### 3.1.2 科技感的正确姿态

适合 `墨予镜` 的不是硬科技感，而是以下两类：

- 认知科技型：抽象空间、镜面、光、雾、折射、几何秩序、轻未来感。
- 人文科技型：纸本、留白、编辑感之上叠一层轻科技语义，让科技退到背景，把人的判断留在前景。

可以有科技主题，但科技应作为背景气候出现，而不是压过内容主体。

#### 3.1.3 风格库归纳出的共同气质

基于 `内容视觉工坊/风格库` 当前素材，可以明确看到几条稳定共性：

- 都很克制，不靠高饱和和强对比抢视线。
- 都有纸感、手感、编辑感。
- 都偏安静的结构化，不是随意拼贴。
- 都带观察者视角，更像整理与表达，而不是营销与喊话。
- 即使出现科技元素，也会被翻译进纸本和人文语境。

这意味着账号无需被限制在“星际文明风”或“赛博科技风”里。只要素材满足上面的共性，就可以进入 `墨予镜` 的主视觉体系。

#### 3.1.4 关键词

- 纸本人文科技
- 克制结构感
- 安静观察
- 编辑拼贴感
- 认知型未来感
- 轻科技语义
- 杂志感
- 说明书感
- 低饱和
- 被整理过的留白

#### 3.1.5 可选灵感

- 纸张、便签、拼贴、票据、页码、说明书、研究卡片。
- 光影、折射、玻璃、雾面、微弱发光、镜面反射。
- 杂志排版、专栏页、设计观察页、安静的知识海报。
- 东方审美、旧纸、器物、旅行、书信、地图、时间痕迹。
- 适度的 AI / 科技主题意象，如频率线、抽象结构、信息秩序、未来器物。

#### 3.1.6 避免

- 冰冷硬科技。
- 机器人和机械脑袋。
- 赛博朋克霓虹街景。
- 普通 AI 工具官网风。
- 强烈的数据面板和产品发布会视觉。
- 过度玄学、廉价占卜、神秘主义符号堆砌。
- 低幼手账贴纸、过度可爱化。
- 大面积蓝紫发光导致的“AI 平台海报感”。

### 3.2 色彩与材质

色彩只定义“气候”，不定义死板色值。生成配图时可以根据文章主题自由调配，不要求每张图都同时出现所有颜色，也不要求默认使用深色宇宙背景。

| 色彩气候 | 倾向 | 用法 |
| --- | --- | --- |
| 深色星域版 | 深蓝、蓝黑、靛紫、银白微光 | 宇宙、夜空、神秘感、强封面 |
| 浅色星域版 | 月光白、浅金、淡蓝、浅紫、珍珠光 | 疗愈、松弛、轻盈、正文配图 |
| 暖金沙海版 | 暖金、沙色、晨光白、淡橙 | 丝路、时间、传承、旅程 |
| 青绿能量版 | 青绿、湖蓝、银白、透明光 | 灵性科技、频率、系统、能量流 |
| 紫粉星云版 | 柔紫、粉紫、蓝紫、微金 | 梦境、高维、直觉、内在空间 |

使用规则：

- 封面可以深色，也可以浅色；由文章主题决定。
- 小红书封面可以更亮，但不要变成普通营销模板。
- 正文配图可以更轻，优先保证阅读节奏。
- 知识卡片优先保证文字可读，色彩只做氛围和层级。
- 不要把色彩方向写成硬性 palette token（调色板令牌），否则会限制单篇文章的发挥。

材质方向：

- 半透明玻璃。
- 水晶、光体、能量膜。
- 细密星尘和微粒光。
- 丝绸、光雾、星尘、细金线、透明界面。
- 柔和发光边缘。
- 有秩序的几何线，不做杂乱电路板。

### 3.3 公众号封面

- 推荐比例：`2.35:1`
- 推荐尺寸：`2350 x 1000` 或 `2048 x 872`
- 标题区：右侧或上方保留干净留白。
- 主视觉：星图、能量场、光之建筑、透明界面、疗愈空间、高维知识结构、梦境自然景观，或适合主题的东方文明意象。

构图要求：

- 需要为后期标题排版保留稳定区域。
- 入口图要能在公众号列表里识别标题和主题。
- 不让生图模型生成大量中文。

避免：

- 满版细节导致标题无处放。
- 图片里直接生成大量中文。
- 画面元素比文章主题更抢眼。

封面提示词基线：

```text
用途：微信公众号文章封面，不生成图中文字。
任务：为「墨予镜」的一篇中文个人文章生成一张星际文明感封面。
视觉方向：灵性科技、高维疗愈、发光的秩序、安定而有力量。
画面场景：星图、能量场、光之建筑、透明界面、疗愈空间、高维知识结构、梦境自然景观，或适合主题的东方文明意象。
构图要求：横版 2.35:1，主体清晰，为后期中文标题排版保留干净区域，有电影感但不要杂乱。
材质：半透明水晶、柔和光场、星尘、几何能量线、月光、细金线、透明能量膜。
色彩气候：可使用深色星域版，也可使用浅色星域版；根据文章主题在月光白、浅金、淡蓝、青绿能量光、柔和星云紫、深蓝夜空之间自由选择。
文字：不生成任何可读文字。
避免：机器人、机械脑袋、赛博朋克霓虹街景、冰冷企业 AI 官网风、混乱科幻界面、廉价玄学符号、卡通治愈贴纸、错误中文。
```

### 3.4 小红书封面

- 推荐比例：`3:4`
- 推荐尺寸：`1536 x 2048`
- 主标题：建议后期排版，不让生图模型直接生成。
- 视觉区和文字区必须分清，避免标题压住主体。

小红书需要比公众号更强入口感，但不能变成焦虑营销。

适合：

- 大标题 + 一句副标题 + 一个清晰视觉主题。
- 单图只讲一个判断。
- 信息层级能被快速扫读。

避免：

- 七八个信息块挤在一张图。
- 大红大黄流量标题。
- “焦虑痛点 + 夸张结果”式版面。

小红书封面提示词基线：

```text
用途：小红书竖版封面，不生成图中文字。
任务：为「墨予镜」生成一张星际文明感竖版封面。
视觉方向：灵性科技、高维疗愈、未来文明、明亮而辽阔。
构图要求：3:4 竖版，上方或中上方有清晰视觉中心，中部或下方保留中文标题叠加区域。
主体元素：星图、光之门、疗愈能量场、水晶界面、高维知识结构、梦境自然景观，或适合主题的东方文明意象。
氛围：开阔、被支持、表达精准、有疗愈感，不焦虑。
色彩气候：可以是深色星域，也可以是浅色月光、浅金、淡蓝、青绿能量光或柔和星云紫，不固定。
文字：不生成任何可读文字。
避免：密集文字、大红大黄营销模板、机器人、赛博朋克街景、廉价玄学、低幼可爱风、错误中文。
```

### 3.5 公众号长文配图

公众号长文配图不是封面，也不是知识卡片。它只服务正文阅读节奏，让读者在一个段落后停一下。

规格：

- 推荐比例：`3:2` 或 `4:3`
- 推荐尺寸：`1536 x 1024` 或 `1600 x 1200`
- 插入频率：1500-2200 字一张，或只在关键转折处放一张。
- 一篇 3000-5000 字长文建议 2-4 张。

适合：

- 只表达当前段落的一个核心信息。
- 图片不抢正文，不承担完整论证。
- 能自然插入段落之间。

避免：

- 做成横版海报。
- 在图里写长句。
- 把整篇文章结构塞进一张图。
- 用封面式强标题。

正文配图提示词基线：

```text
用途：微信公众号长文正文配图，不生成图中文字。
任务：为「墨予镜」的一篇中文长文生成一张横版正文插图。
使用方式：这张图只服务当前小节的一个核心意思，不要做成封面，也不要做成信息图。
视觉方向：高维疗愈、发光结构、星图、能量场、透明界面、神圣几何、轻量东方意象。
构图要求：横版 3:2，一个清楚的视觉意象，有呼吸感，安静但不寡淡。
色彩气候：根据段落情绪自由选择深色或浅色版本，不要求全部颜色出现。
文字：不生成任何可读文字。
避免：可读文字、机器人、冰冷仪表盘界面、混乱科幻面板、赛博朋克霓虹街景、廉价玄学符号、营销海报感。
```

### 3.6 小红书知识卡片

知识卡片用于把公众号长文里的判断、框架和方法拆成可保存、可滑读的图文。它不走封面那种大场景大片感，默认采用手绘涂鸦笔记（Sketchnote）方向，在手绘结构里融入星图、灵性科技和高维疗愈元素。东方、敦煌、丝路等元素只在主题适合时使用。

规格：

- 推荐比例：`3:4`
- 推荐尺寸：`1536 x 2048`
- 一组张数：3-7 张。
- 每张只讲一个判断或一个步骤。
- 每张都是独立完整画布，不把多张图挤在同一张里。

单张结构建议：

1. 顶部：短标题，12 字以内优先。
2. 中部：一个手绘结构图、路径图、星图框架、曼陀罗式信息结构或能量流程图。
3. 下部：2-4 行解释文字或 3 个要点。
4. 页脚：账号名 `墨予镜`，低调放置。

手绘卡片规则：

- 所有要出现在图上的文字都用反引号 `` 包裹，要求原样呈现。
- 每个信息块要放进明确容器，例如横幅、圆形框、星图节点、卷轴框、路径节点。
- 插画必须和文字绑定描述，例如“`判断力` 旁边画一个发光罗盘”。
- 线条可以有轻微手绘感，不要过于僵硬和完美。
- 结构优先，装饰服务理解，不做纯氛围图。
- 可优先使用蜿蜒路径型、竖向递进卡片型、圆环循环型、星座连接型、曼陀罗中心扩散型、成长树型等构图。

卡片提示词基线：

```text
【文字渲染规则 - 严格遵守】
只渲染提示词中用反引号 `` 明确标注的文字内容，原样呈现。
凡是提示词中没有用反引号标注的地方，一律不得自行添加任何文字、字母、数字或符号。
图标、插画、装饰元素可以自由发挥，但不得在其上附加任何未经指定的文字。

【独立画布】
生成一张独立完整的 3:4 竖版知识卡片，不要与其他图片合并。

【整体风格】
手绘涂鸦笔记风格，线条有轻微手绘感；融合星图、灵性科技、高维疗愈和星际文明元素。
不要做成电影封面，不要做成纯氛围插画，要像一张可阅读、可收藏的知识卡片。

【画幅】
3:4 竖版。

【主题】
主题：[卡片标题]
摘要：[卡片摘要]

【构图】
选择一种适合内容逻辑的手绘结构：蜿蜒路径、竖向递进卡片、圆环循环、星座连接、曼陀罗中心扩散、成长树或分区信息图。

【标题区】
- 标题文字：`[卡片标题]`
- 标题放在顶部醒目区域，可使用卷轴框、星图横幅或发光边框。

【内容区】
- 将摘要拆成 2-4 个信息块。
- 每个信息块都放进明确容器，并绑定一个简笔插画或符号。
- 示例：`[要点文字]`（旁边画一个发光罗盘 / 星图节点 / 小卷轴 / 能量环）。

【视觉元素】
```

### 3.7 账号头像

## 4. 公众号排版

### 4.1 排版气质

公众号排版应先服务长文阅读，再用少量星际文明元素建立账号识别。正文不建议整篇深色底，深空感更适合用于封面、分割、引用块、尾部 CTA 或局部强调。

关键词：

- 清晰正文
- 宽松行距
- 清晰标题层级
- 银蓝 / 能量青强调
- 星图式分割线
- 少量光感
- 配图之间有呼吸

### 4.2 建议参数

| 模块 | 建议 |
| --- | --- |
| 正文背景 | `#FFFFFF` |
| 外层底色 | `#F4F7FF` |
| 正文颜色 | `#273142` |
| 标题颜色 | `#07111F` |
| 小标题颜色 | `#433B8F` |
| 弱文字 | `#8897B3` |
| 引用背景 | `#F2F7FF` |
| 引用边线 | `#4DD6D0` |
| 段落间距 | `18px` |
| 小节间距 | `28px` |
| 小标题字号 | `20-22px` |
| 正文字号 | `16-17px` |
| 正文行高 | `1.85-2.0` |
| 图片圆角 | `8px` |
| 引用圆角 | `10px` |

### 4.3 文章结构

推荐结构：

1. 标题。
2. 一段短引子，直接进入真实问题。
3. 2-5 个小标题，每节只讲一个判断。
4. 关键句用引用块或加粗，不频繁上色。
5. 结尾用一个低调行动提示：留言、在看、转发给同样在思考的人。

### 4.4 排版禁区

- 大面积彩色底块。
- 连续使用居中大字。
- 每段都加粗。
- 大量 emoji 或装饰符号。
- 多层卡片嵌套。
- 过度课程化的“总结 / 行动清单 / 福利领取”视觉。
