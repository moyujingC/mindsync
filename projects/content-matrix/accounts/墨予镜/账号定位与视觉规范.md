## 1. 账号定位

`墨予镜` 是创作者本人的个人 IP 账号，归属于 `内容矩阵` 项目。

它承接的是创作者在 AI、产品、研究、内容、疗愈与个人成长交叉处的长期表达。这个账号应让读者感到：这是一个真实在做事的人，在用工程化的方法整理自己的实践、判断和边界。

### 1.1 一句话定位

```text
一个用 AI 做产品、做研究、做内容，也持续观察人如何在工具时代保持清醒的独立开发者 / 疗愈师。
```

### 1.2 账号角色

- 独立开发者：持续搭建产品、工作流、研究系统和内容工具。
- AI 重度使用者：分享真实协作经验、踩坑、边界和方法。
- 产品与研究实践者：把外部观察、开源拆解和项目实践转成可复用框架。
- 疗愈师 / 教练视角持有者：关注人的状态、精力、关系、成长和改变机制。

### 1.3 读者感知

读者打开 `墨予镜` 的内容时，应预期看到：

- 有真实项目现场，而不是抽象建议。
- 有方法和框架，但不压迫人。
- 有 AI 和技术，但人仍然在中心。
- 有成长和疗愈视角，但不做鸡汤式安慰。
- 有判断和边界，不追逐工具崇拜。

### 1.4 不适合的方向

- 纯教程号：只讲工具步骤、提示词模板、效率技巧。
- 情绪流量号：用焦虑、崩溃、逆袭制造点击。
- 玄学人设号：直接把神秘化表达作为第一层传播语言。
- AI 科技媒体号：只追热点、参数、模型发布和行业新闻。
- 产品营销号：把个人号变成产品功能宣传入口。

## 2. 内容气质

### 2.1 关键词

- 表达精准
- 真实
- 有边界
- 有方法
- 疗愈感
- 松弛
- 技术感
- 人文感

### 2.2 语气

默认语气是第一人称复盘 + 分享型表达。

句子应直接、具体，像在把一个真实问题讲清楚，再把其中可复用的观察分享出来。可以有个人判断，但不要替读者下过度绝对的结论，也不要使用居高临下的教学口吻。

适合：

- “我后来发现……”
- “这件事真正麻烦的地方在于……”
- “对我来说，这不是效率问题，而是质量风险。”
- “我现在会把这类任务降级处理。”

避免：

- “你必须……”
- “普通人只要掌握这套方法……”
- “真正厉害的人都……”
- “AI 时代不做这个就会被淘汰。”

### 2.3 内容母题

这里的母题是账号未来 1-3 年的内容领地设计，不是对当前几篇文章的归纳。近期内容可以从其中某一两条展开，但不能反过来限制账号的长期边界。

- 人如何在工具时代保持主体性：AI、自动化、效率、判断力、注意力、精力边界和生活节奏。
- 一人公司与独立创造者系统：从想法、研究、产品、内容、交付到复盘，如何搭建自己的长期操作系统。
- 产品、研究与内容的复合实践：产品观察、行业研究、开源拆解、知识资产、内容转译和作品化表达。
- 疗愈与成长的现代转译：情绪、关系、身体感、内在秩序、自我修复和改变机制，用大众能理解的语言表达。
- 职业与身份重建：求职、转型、能力表达、作品集、个人叙事，以及人在不同阶段如何重新组织自己。
- 东方文化、审美与个人方法：把传统文化、象征系统、节律感和审美体验转成当代可理解、可实践的表达。
- 真实项目现场：产品建设、工具选择、失败复盘、取舍过程和阶段性成果，让读者看到一个人如何把想法落到现实里。

## 3. 视觉素材规格

### 3.1 美术定位

```text
敦煌星际文明风 + 灵性科技 + 高维疗愈感
```

`墨予镜` 的视觉可以把科技和疗愈放在同一套世界观里：科技不是冰冷机器，疗愈也不是软塌塌的情绪安慰，而是一种更高维、更有秩序、更有能量感的文明系统。

画面应像一条通往高维文明的丝路：敦煌飞天、月牙泉、沙海、驼队、星河、经卷、曼陀罗、光之建筑和能量场可以共存。它有科技感，也有灵性；有未来感，也有东方审美；有疗愈感，也有文明叙事的辽阔。

关键词：

- 星际文明
- 灵性科技
- 高维疗愈
- 敦煌飞天
- 丝路、沙海、月牙泉
- 星图与能量场
- 光之建筑
- 神圣几何
- 透明界面
- 水晶质感
- 经卷、曼陀罗、星盘
- 金粉、光河、蝴蝶、莲花
- 安定、开阔、被托举

避免：

- 冰冷硬科技。
- 机器人和机械脑袋。
- 赛博朋克霓虹街景。
- 普通 AI 工具官网风。
- 商业课程海报感。
- 过度玄学、廉价占卜、神秘主义符号堆砌。
- 卡通治愈、手账贴纸、低幼可爱。

### 3.2 色彩与材质

色彩只定义“气候”，不定义死板色值。生成配图时可以根据文章主题自由调配，不要求每张图都同时出现所有颜色。

| 色彩气候 | 参考色 | 用法 |
| --- | --- | --- |
| 深空夜蓝 | `#07111F` / `#10213A` | 星河、夜幕、文明背景 |
| 敦煌鎏金 | `#D9B86F` / `#F2D38B` | 月光、经卷、沙粒、光河 |
| 沙漠暖金 | `#CFA56A` / `#F0C98B` | 沙丘、丝路、日出、温度 |
| 月光银白 | `#F4F7FF` / `#FFF4D6` | 月牙、光体、标题承托区 |
| 青绿能量 | `#4DD6D0` / `#74E7CF` | 频率线、灵性科技、能量流 |
| 星云紫粉 | `#433B8F` / `#B58AE6` | 梦境、高维空间、光雾 |

使用规则：

- 封面可以更浓：深空夜蓝 + 敦煌鎏金 + 月光银白。
- 小红书封面可以更亮：沙漠暖金 + 月光银白 + 青绿能量。
- 正文配图可以更轻：月光银白 + 少量金粉 + 一点星云色。
- 知识卡片优先保证文字可读，色彩只做氛围和层级。
- 不要把色彩方向写成硬性 palette token（调色板令牌），否则会限制单篇文章的发挥。

材质方向：

- 半透明玻璃。
- 水晶、光体、能量膜。
- 细密星尘和微粒光。
- 丝绸、经卷、沙粒、鎏金纹样。
- 柔和发光边缘。
- 有秩序的几何线，不做杂乱电路板。

### 3.3 公众号封面

- 推荐比例：`2.35:1`
- 推荐尺寸：`2350 x 1000` 或 `2048 x 872`
- 标题区：右侧或上方保留干净留白。
- 主视觉：星图、飞天、月牙、沙海、经卷、曼陀罗、光之建筑、能量场、星际疗愈空间或高维知识界面，根据单篇文章确定。

构图要求：

- 需要为后期标题排版保留稳定区域。
- 入口图要能在公众号列表里识别标题和主题。
- 不让生图模型生成大量中文。

避免：

- 满版细节导致标题无处放。
- 图片里直接生成大量中文。
- 画面元素比文章主题更抢眼。

封面提示词基线：

```text
用途：微信公众号文章封面，不生成图中文字。
任务：为「墨予镜」的一篇中文个人文章生成一张敦煌星际文明风封面。
视觉方向：灵性科技、高维疗愈、星际丝路、发光的秩序、安定而有力量。
画面场景：宇宙沙海、月牙、星河、飞天意象、发光经卷、曼陀罗或星图、透明能量场，或来自高维星际文明的疗愈空间。
构图要求：横版 2.35:1，主体清晰，为后期中文标题排版保留干净区域，有电影感但不要杂乱。
材质：半透明水晶、丝绸飘带、发光沙粒、经卷、柔和光场、星尘、几何能量线、月光。
色彩气候：深空夜蓝、敦煌鎏金、沙漠暖金、月光白、青绿能量光，可少量加入星云紫粉。
文字：不生成任何可读文字。
避免：机器人、机械脑袋、赛博朋克霓虹街景、冰冷企业 AI 官网风、混乱科幻界面、廉价玄学符号、卡通治愈贴纸、错误中文。
```

### 3.4 小红书封面

- 推荐比例：`3:4`
- 推荐尺寸：`1536 x 2048`
- 主标题：建议后期排版，不让生图模型直接生成。
- 视觉区和文字区必须分清，避免标题压住主体。

小红书需要比公众号更强入口感，但不能变成焦虑营销。

适合：

- 大标题 + 一句副标题 + 一个清晰视觉主题。
- 单图只讲一个判断。
- 信息层级能被快速扫读。

避免：

- 七八个信息块挤在一张图。
- 大红大黄流量标题。
- “焦虑痛点 + 夸张结果”式版面。

小红书封面提示词基线：

```text
用途：小红书竖版封面，不生成图中文字。
任务：为「墨予镜」生成一张敦煌星际文明风竖版封面。
视觉方向：灵性科技、高维疗愈、星际丝路梦境、未来文明、明亮而辽阔。
构图要求：3:4 竖版，上方或中上方有清晰视觉中心，中部或下方保留中文标题叠加区域。
主体元素：月牙、宇宙沙海、飞天意象、发光经卷、曼陀罗星图、光之门、疗愈能量场、水晶界面或高维知识结构。
氛围：开阔、被支持、表达精准、有疗愈感，不焦虑。
色彩气候：深空夜蓝、敦煌鎏金、沙漠暖金、月光白、青绿能量光，可少量加入星云紫粉。
文字：不生成任何可读文字。
避免：密集文字、大红大黄营销模板、机器人、赛博朋克街景、廉价玄学、低幼可爱风、错误中文。
```

### 3.5 公众号长文配图

公众号长文配图不是封面，也不是知识卡片。它只服务正文阅读节奏，让读者在一个段落后停一下。

规格：

- 推荐比例：`3:2` 或 `4:3`
- 推荐尺寸：`1536 x 1024` 或 `1600 x 1200`
- 插入频率：1500-2200 字一张，或只在关键转折处放一张。
- 一篇 3000-5000 字长文建议 2-4 张。

适合：

- 只表达当前段落的一个核心信息。
- 图片不抢正文，不承担完整论证。
- 能自然插入段落之间。

避免：

- 做成横版海报。
- 在图里写长句。
- 把整篇文章结构塞进一张图。
- 用封面式强标题。

正文配图提示词基线：

```text
用途：微信公众号长文正文配图，不生成图中文字。
任务：为「墨予镜」的一篇中文长文生成一张横版正文插图。
使用方式：这张图只服务当前小节的一个核心意思，不要做成封面，也不要做成信息图。
视觉方向：高维疗愈、发光结构、星图、能量场、透明界面、神圣几何、敦煌天界意象。
构图要求：横版 3:2，一个清楚的视觉意象，有呼吸感，安静但不寡淡。
色彩气候：根据段落情绪自由选择深空夜蓝、敦煌鎏金、月光白、沙漠暖金、青绿能量光和柔和星云紫，不要求全部出现。
文字：不生成任何可读文字。
避免：可读文字、机器人、冰冷仪表盘界面、混乱科幻面板、赛博朋克霓虹街景、廉价玄学符号、营销海报感。
```

### 3.6 小红书知识卡片

知识卡片用于把公众号长文里的判断、框架和方法拆成可保存、可滑读的图文。它不走封面那种大场景大片感，默认采用手绘涂鸦笔记（Sketchnote）方向，在手绘结构里融入敦煌星图、灵性科技和高维疗愈元素。

规格：

- 推荐比例：`3:4`
- 推荐尺寸：`1536 x 2048`
- 一组张数：3-7 张。
- 每张只讲一个判断或一个步骤。
- 每张都是独立完整画布，不把多张图挤在同一张里。

单张结构建议：

1. 顶部：短标题，12 字以内优先。
2. 中部：一个手绘结构图、路径图、星图框架、曼陀罗式信息结构或能量流程图。
3. 下部：2-4 行解释文字或 3 个要点。
4. 页脚：账号名 `墨予镜`，低调放置。

手绘卡片规则：

- 所有要出现在图上的文字都用反引号 `` 包裹，要求原样呈现。
- 每个信息块要放进明确容器，例如横幅、圆形框、星图节点、卷轴框、路径节点。
- 插画必须和文字绑定描述，例如“`判断力` 旁边画一个发光罗盘”。
- 线条可以有轻微手绘感，不要过于僵硬和完美。
- 结构优先，装饰服务理解，不做纯氛围图。
- 可优先使用蜿蜒路径型、竖向递进卡片型、圆环循环型、星座连接型、曼陀罗中心扩散型、成长树型等构图。

卡片提示词基线：

```text
【文字渲染规则 - 严格遵守】
只渲染提示词中用反引号 `` 明确标注的文字内容，原样呈现。
凡是提示词中没有用反引号标注的地方，一律不得自行添加任何文字、字母、数字或符号。
图标、插画、装饰元素可以自由发挥，但不得在其上附加任何未经指定的文字。

【独立画布】
生成一张独立完整的 3:4 竖版知识卡片，不要与其他图片合并。

【整体风格】
手绘涂鸦笔记风格，线条有轻微手绘感；融合敦煌星图、灵性科技、高维疗愈和星际文明元素。
不要做成电影封面，不要做成纯氛围插画，要像一张可阅读、可收藏的知识卡片。

【画幅】
3:4 竖版。

【主题】
主题：[卡片标题]
摘要：[卡片摘要]

【构图】
选择一种适合内容逻辑的手绘结构：蜿蜒路径、竖向递进卡片、圆环循环、星座连接、曼陀罗中心扩散、成长树或分区信息图。

【标题区】
- 标题文字：`[卡片标题]`
- 标题放在顶部醒目区域，可使用卷轴框、星图横幅或发光边框。

【内容区】
- 将摘要拆成 2-4 个信息块。
- 每个信息块都放进明确容器，并绑定一个简笔插画或符号。
- 示例：`[要点文字]`（旁边画一个发光罗盘 / 星图节点 / 小卷轴 / 能量环）。

【视觉元素】
可以使用手绘星图、月牙、细金线、卷轴、曼陀罗小节点、能量线、蝴蝶、莲花、沙粒光点。

【色彩气候】
优先保证文字可读。可根据主题选择月光白、敦煌金、沙漠暖金、青绿能量光、深空夜蓝或柔和星云紫，不要求全部出现。

【避免】
避免拥挤信息图、大红大黄营销模板、赛博朋克霓虹、机器人脸、低幼贴纸、廉价玄学感、密集错误中文。
```

### 3.7 账号头像

头像应成为跨平台稳定识别符号，不绑定真实肖像。推荐方向是“星际镜面 / 高维星图 / 光之印记”：让 `墨予镜` 的“镜”像一个可以映照星图、敦煌纹样和内在秩序的高维界面。

头像元素：

- 圆形星际镜面。
- 星图或光环结构。
- 简洁的神圣几何。
- 可融入极简敦煌纹样或飞天飘带感。
- 水晶或银白光体。
- 小尺寸下仍能识别的中心符号。

不建议：

- 真人 AI 肖像。
- 机器人头像。
- 复杂到小尺寸无法识别的图形。
- 与账号长期定位无关的装饰符号。

头像提示词基线：

```text
用途：社交媒体头像，适配圆形裁切。
任务：为中文个人 IP「墨予镜」生成一个象征性头像。
视觉概念：星际镜面、高维星图、光之印记、极简敦煌几何、灵性科技、疗愈文明。
构图要求：中心符号清晰，轮廓有识别度，小尺寸可读，适合圆形头像。
材质：水晶、银白光、细微星尘、几何能量环、精致金线。
色彩气候：深空夜蓝、月光银白、敦煌鎏金，可少量加入青绿能量光。
文字：不生成任何文字。
避免：真人肖像、机器人、动漫风、赛博朋克霓虹、廉价玄学符号、复杂书法、过度细碎的插画。
```

## 4. 公众号排版

### 4.1 排版气质

公众号排版应先服务长文阅读，再用少量星际文明元素建立账号识别。正文不建议整篇深色底，深空感更适合用于封面、分割、引用块、尾部 CTA 或局部强调。

关键词：

- 清晰正文
- 宽松行距
- 清晰标题层级
- 银蓝 / 能量青强调
- 星图式分割线
- 少量光感
- 配图之间有呼吸

### 4.2 建议参数

| 模块 | 建议 |
| --- | --- |
| 正文背景 | `#FFFFFF` |
| 外层底色 | `#F4F7FF` |
| 正文颜色 | `#273142` |
| 标题颜色 | `#07111F` |
| 小标题颜色 | `#433B8F` |
| 弱文字 | `#8897B3` |
| 引用背景 | `#F2F7FF` |
| 引用边线 | `#4DD6D0` |
| 段落间距 | `18px` |
| 小节间距 | `28px` |
| 小标题字号 | `20-22px` |
| 正文字号 | `16-17px` |
| 正文行高 | `1.85-2.0` |
| 图片圆角 | `8px` |
| 引用圆角 | `10px` |

### 4.3 文章结构

推荐结构：

1. 标题。
2. 一段短引子，直接进入真实问题。
3. 2-5 个小标题，每节只讲一个判断。
4. 关键句用引用块或加粗，不频繁上色。
5. 结尾用一个低调行动提示：留言、在看、转发给同样在思考的人。

### 4.4 排版禁区

- 大面积彩色底块。
- 连续使用居中大字。
- 每段都加粗。
- 大量 emoji 或装饰符号。
- 多层卡片嵌套。
- 过度课程化的“总结 / 行动清单 / 福利领取”视觉。

## 6. 使用规则

- 新文章先判断内容类型，再决定需要哪些视觉素材。
- 默认美术方向使用“星际文明风 + 灵性科技 + 高维疗愈感”。
- 求职向小红书可以更清晰、更结构化，但仍不要做强销售感简历海报。
- 所有涉及第一人称经历和个人立场的内容，仍受 [个人真实信息与表达基线](../../../../company/projects/内容矩阵/个人真实信息与表达基线.md) 约束。
