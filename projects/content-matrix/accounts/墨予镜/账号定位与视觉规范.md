## 1. 账号定位

`墨予镜` 是创作者本人的个人 IP 账号，归属于 `内容矩阵` 项目。

它承接的是创作者在 AI、产品、研究、内容、疗愈与个人成长交叉处的长期表达。这个账号应让读者感到：这是一个真实在做事的人，在用工程化的方法整理自己的实践、判断和边界。

### 1.1 一句话定位

```text
一个用 AI 做产品、做研究、做内容，也持续观察人如何在工具时代保持清醒的独立开发者 / 疗愈师。
```

### 1.2 账号角色

- 独立开发者：持续搭建产品、工作流、研究系统和内容工具。
- AI 重度使用者：分享真实协作经验、踩坑、边界和方法。
- 产品与研究实践者：把外部观察、开源拆解和项目实践转成可复用框架。
- 疗愈师 / 教练视角持有者：关注人的状态、精力、关系、成长和改变机制。

### 1.3 读者感知

读者打开 `墨予镜` 的内容时，应预期看到：

- 有真实项目现场，而不是抽象建议。
- 有方法和框架，但不压迫人。
- 有 AI 和技术，但人仍然在中心。
- 有成长和疗愈视角，但不做鸡汤式安慰。
- 有判断和边界，不追逐工具崇拜。

### 1.4 不适合的方向

- 纯教程号：只讲工具步骤、提示词模板、效率技巧。
- 情绪流量号：用焦虑、崩溃、逆袭制造点击。
- 玄学人设号：直接把神秘化表达作为第一层传播语言。
- AI 科技媒体号：只追热点、参数、模型发布和行业新闻。
- 产品营销号：把个人号变成产品功能宣传入口。

## 2. 内容气质

### 2.1 关键词

- 表达精准
- 真实
- 有边界
- 有方法
- 疗愈感
- 松弛
- 技术感
- 人文感

### 2.2 语气

默认语气是第一人称复盘型表达。

句子应直接、具体，像在把一个真实问题讲清楚。可以有个人判断，但不要替读者下过度绝对的结论。

适合：

- “我后来发现……”
- “这件事真正麻烦的地方在于……”
- “对我来说，这不是效率问题，而是质量风险。”
- “我现在会把这类任务降级处理。”

避免：

- “你必须……”
- “普通人只要掌握这套方法……”
- “真正厉害的人都……”
- “AI 时代不做这个就会被淘汰。”

### 2.3 内容母题

- AI 协作中的判断力、边界、收口和恢复。
- 一人项目里的系统建设、主线推进、取舍和交付。
- 长期研究系统、行业观察、产品拆解和知识资产。
- 疗愈、成长、精力状态和改变机制。
- 求职、职业转型、能力表达和作品化呈现。

## 3. 视觉总原则

### 3.1 视觉定位

```text
克制的中文编辑视觉 + 现实工作台隐喻 + 低饱和人文科技感
```

画面应像一组成熟中文杂志或专栏配图，而不是工具广告、课程海报或科技发布会视觉。

### 3.2 视觉关键词

- 暖白纸面
- 墨黑线条
- 雾蓝灰
- 低饱和绿色
- 少量琥珀光
- 桌面、纸张、电脑、卡片、线稿
- 背影、侧影、手部动作
- 留白、秩序、轻微压力

### 3.3 统一隐喻库

`墨予镜` 的图像应优先使用现实工作与思考场景，不优先使用抽象科技符号。

常用隐喻：

- 工作台：代表真实项目现场。
- 电脑屏幕：代表 AI 协作入口。
- 纸张 / 卡片：代表任务、判断、知识片段。
- 手写线条：代表人的整理、选择和收口。
- 圆形边界：代表精力边界、任务边界、系统边界。
- 微光：代表灵感、注意力和清醒状态。
- 书桌边缘 / 未完成纸张：代表仍在进行中的实践。

少用或禁用：

- 机器人脸、机械脑袋、发光大脑。
- 赛博朋克霓虹、紫蓝渐变、大面积电路纹理。
- 崩溃哭泣人物、红色警报、爆炸式任务流。
- 纯抽象渐变背景。
- 堆满错误中文的 AI 生成海报。

## 4. 账号视觉系统

### 4.1 主色板

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 纸面暖白 | `#FBFAF6` | 公众号正文、卡片背景、留白区域 |
| 暖米色 | `#F3ECDB` | 封面底色、纸感底纹 |
| 墨黑 | `#1F2422` | 标题、主线条、深色主题 |
| 深灰 | `#3D3D3D` | 正文、说明文字 |
| 雾蓝灰 | `#8D9A9B` | 技术感、冷静氛围 |
| 低饱和绿 | `#1F3A36` | 方法、系统、任务卡片 |
| 琥珀棕 | `#B86B3A` | 重点提示、屏幕微光 |
| 旧纸灰 | `#A59F8E` | 分割线、辅助说明 |

### 4.2 字体方向

公众号和封面标题可采用：

- 中文宋体 / 仿宋 / 现代衬线：用于专栏感、长文标题、金句。
- 中文黑体 / 现代无衬线：用于小红书卡片、信息结构、工具界面感。

默认组合：

- 公众号长文：标题偏衬线，正文用高可读黑体或系统字体。
- 知识卡片：标题用黑体或较硬朗衬线，正文用黑体。
- 小红书封面：主标题用黑体，副标题可用较轻字重。

避免：

- 手写字体大面积使用。
- 过度可爱、童趣、复古花字。
- 过窄字体导致移动端阅读吃力。

### 4.3 图像质感

优先级：

1. 轻纹理编辑插画。
2. 纸感信息卡片。
3. 真实工作台的低饱和摄影感图像。

不要让图像过度像：

- 企业 PPT 插画。
- AI 工具官网首屏。
- 情绪营销海报。
- 卡通治愈贴纸。

## 5. 公众号封面

### 5.1 规格

- 推荐比例：`2.35:1`
- 推荐尺寸：`2350 x 1000` 或 `2048 x 872`
- 标题区：右侧或上方保留干净留白。
- 主视觉：人物、工作台或隐喻主体偏左或居中偏左。

### 5.2 构图

适合：

- 左侧工作台 / 人物背影，右侧标题留白。
- 中间大面积纸面或桌面，标题在上方压住。
- 背景低对比，标题清晰压在画面上。

避免：

- 满版细节导致标题无处放。
- 图片里直接生成大量中文。
- 科技感元素比人和工作现场更抢眼。

### 5.3 封面 Prompt 基线

```text
Use case: WeChat public account article cover image, no in-image text.
Create a restrained Chinese editorial illustration for a personal essay by "墨予镜".
The account voice is clear-minded, precise, reflective, slightly tired but not anxious.
Scene: a quiet realistic workspace with a laptop, paper notes, task cards, handwritten lines, and subtle traces of AI collaboration.
Subject: one human figure from behind, side view, or only hands; focused and composed.
Style: mature editorial illustration, soft paper texture, low-saturation humanistic technology feeling, magazine essay cover.
Composition: landscape 2.35:1, main visual slightly left of center, clean negative space on the right or top for Chinese title overlay.
Color palette: warm off-white, ink black, misty blue-gray, muted green, small amber light.
Text: none.
Avoid: robots, glowing brain, cyberpunk neon, purple-blue gradients, chaotic UI, red alert, exaggerated burnout, stock photo, readable fake Chinese text.
```

## 6. 小红书封面

### 6.1 规格

- 推荐比例：`3:4`
- 推荐尺寸：`1536 x 2048`
- 主标题：建议后期排版，不让生图模型直接生成。
- 视觉区：上半部或中上部。
- 文字区：中下部保留高对比底面。

### 6.2 构图

小红书需要比公众号更强入口感，但不能牺牲账号的克制气质。

适合：

- 大标题 + 一句副标题 + 一个清晰视觉隐喻。
- 背景保留纸感或桌面感。
- 局部使用琥珀色或低饱和绿提升识别度。

避免：

- 七八个信息块挤在一张图。
- 大红大黄流量标题。
- “焦虑痛点 + 夸张结果”式版面。

### 6.3 小红书封面 Prompt 基线

```text
Use case: Xiaohongshu vertical cover image, no in-image text.
Create a vertical editorial illustration for a thoughtful Chinese knowledge post by "墨予镜".
The image should feel useful, clear, quiet, and slightly sharper than a WeChat cover.
Scene: a calm desk, laptop glow, paper cards, handwritten organizing marks, one simple visual metaphor related to judgment, AI collaboration, research, or personal energy boundaries.
Composition: vertical 3:4, main visual in the upper two-thirds, clean lower third for Chinese title overlay.
Style: restrained editorial illustration, paper texture, low-saturation colors, not cute, not commercial tech poster.
Color palette: warm off-white, ink black, muted green, misty blue-gray, small amber accent.
Text: none.
Avoid: robots, neon, busy infographic, excessive icons, fake Chinese text, dramatic anxiety, over-decorated social media template.
```

## 7. 公众号长文配图

### 7.1 用途

公众号长文配图不是封面，也不是知识卡片。它只服务正文阅读节奏，让读者在一个段落后停一下。

### 7.2 规格

- 推荐比例：`3:2` 或 `4:3`
- 推荐尺寸：`1536 x 1024` 或 `1600 x 1200`
- 插入频率：1500-2200 字一张，或只在关键转折处放一张。
- 一篇 3000-5000 字长文建议 2-4 张。

### 7.3 配图规则

适合：

- 只表达当前段落的一个意象。
- 用手、卡片、桌面、边界线、光线变化表达抽象概念。
- 留白充足，低对比，不能抢正文。

避免：

- 做成横版海报。
- 在图里写长句。
- 把整篇文章结构塞进一张图。
- 用封面式强标题。

### 7.4 正文配图 Prompt 基线

```text
Use case: WeChat article inline illustration, no in-image text.
Create a restrained horizontal editorial illustration for the middle of a Chinese long-form essay by "墨予镜".
The image should support reading rhythm, not act as a cover or infographic.
Represent only one core metaphor from the current section: judgment, closure, energy boundary, research system, AI collaboration, or project work.
Scene: realistic workspace elements such as paper notes, task cards, laptop, notebook, hand-drawn boundary lines, or hands sorting cards.
Style: mature editorial illustration, quiet, textured, clear, human-centered.
Composition: horizontal 3:2, simple focal point, generous negative space, no clutter.
Color palette: warm off-white, ink gray, misty blue-gray, muted green, small amber highlights.
Text: none.
Avoid: readable text, robots, sci-fi UI, charts, busy productivity dashboards, dramatic panic, marketing poster style.
```

## 8. 小红书知识卡片

### 8.1 用途

知识卡片用于把公众号长文里的判断、框架和方法拆成可保存、可滑读的图文。它应比正文配图更结构化，但仍保持简洁。

### 8.2 规格

- 推荐比例：`3:4`
- 推荐尺寸：`1536 x 2048`
- 一组张数：3-7 张。
- 每张只讲一个判断或一个步骤。

### 8.3 版式

单张结构建议：

1. 顶部：短标题，12 字以内优先。
2. 中部：一个视觉隐喻或结构图。
3. 下部：2-4 行解释文字或 3 个要点。
4. 页脚：账号名 `墨予镜`，低调放置。

### 8.4 卡片风格

默认三套可选：

| 风格名 | 适合内容 | 视觉说明 |
| --- | --- | --- |
| 墨予镜 · 手绘知识卡 | 方法、步骤、框架 | 纸感底纹、手绘箭头、低饱和绿和琥珀强调 |
| 墨予镜 · 克制留白版 | 观点、金句、短判断 | 大留白、细线框、标题强但元素少 |
| 墨予镜 · 深墨观点版 | 强观点、反常识判断 | 深墨底、暖白文字、少量金色强调 |

### 8.5 知识卡片 Prompt 基线

```text
Use case: Xiaohongshu knowledge card, Chinese layout, minimal text.
Create one 3:4 knowledge card for "墨予镜".
Theme: [card title].
Summary: [card summary].
Style: restrained Chinese editorial knowledge card, paper texture, clear hierarchy, humanistic technology feeling.
Layout: short title area, one simple visual metaphor or diagram area, concise explanation area, small account mark "墨予镜".
Color palette: warm off-white, ink black, muted green, misty blue-gray, small amber accent.
Typography direction: clean Chinese title, readable body, no decorative fonts.
Constraints: do not generate long paragraphs; if text is included, keep it sparse and visually controlled.
Avoid: crowded infographic, fake dense Chinese text, cute stickers, neon AI style, red/yellow marketing template.
```

## 9. 账号头像

### 9.1 头像目标

头像应成为跨平台稳定识别符号，优先表达“墨、镜、清醒观察、个人方法论”，不要做真实肖像绑定。

### 9.2 推荐方向

主方案：

```text
圆形头像中，一个抽象墨色镜面 / 纸上圆镜符号，带少量手绘线条和微光。
```

视觉元素：

- 圆镜或镜面轮廓。
- 墨色边缘。
- 暖白纸面背景。
- 一点琥珀微光或低饱和绿线。
- 可加入很轻的手写线条，但不写复杂字。

不建议：

- 真人 AI 肖像。
- 机器人头像。
- 古风水墨人物。
- 复杂篆刻章。
- 过度玄学符号。

### 9.3 头像 Prompt 基线

```text
Use case: social media avatar, circular crop.
Create a minimal symbolic avatar for a Chinese personal IP named "墨予镜".
Visual concept: an abstract ink-colored mirror or circular reflective surface on warm paper, with subtle hand-drawn lines and a tiny amber glint.
Style: restrained, elegant, editorial, humanistic, slightly handmade, not corporate.
Composition: centered icon, strong silhouette, readable at small size, works in circular crop.
Color palette: warm off-white, ink black, muted green-gray, tiny amber accent.
Text: none.
Avoid: human portrait, robot, anime style, fantasy magic symbol, complex calligraphy, neon gradient, over-detailed illustration.
```

## 10. 公众号排版

### 10.1 排版气质

公众号排版应服务长文阅读。它要有专栏感，但不能像设计作品集。

关键词：

- 白底
- 宽松行距
- 清晰标题层级
- 少量强调
- 引用块克制
- 配图之间有呼吸

### 10.2 建议参数

| 模块 | 建议 |
| --- | --- |
| 正文背景 | `#FFFFFF` |
| 外层底色 | `#F4F0E8` |
| 正文颜色 | `#3D3D3D` |
| 标题颜色 | `#1F1F1F` |
| 小标题颜色 | `#2A2A2A` |
| 弱文字 | `#8D816F` |
| 引用背景 | `#F7F2E9` |
| 引用边线 | `#A58352` |
| 段落间距 | `18px` |
| 小节间距 | `28px` |
| 小标题字号 | `20-22px` |
| 正文字号 | `16-17px` |
| 正文行高 | `1.85-2.0` |
| 图片圆角 | `8px` |
| 引用圆角 | `10px` |

### 10.3 文章结构

推荐结构：

1. 标题。
2. 一段短引子，直接进入真实问题。
3. 2-5 个小标题，每节只讲一个判断。
4. 关键句用引用块或加粗，不频繁上色。
5. 结尾用一个低调行动提示：留言、在看、转发给同样在思考的人。

### 10.4 排版禁区

- 大面积彩色底块。
- 连续使用居中大字。
- 每段都加粗。
- 大量 emoji 或装饰符号。
- 多层卡片嵌套。
- 过度课程化的“总结 / 行动清单 / 福利领取”视觉。

## 12. 使用规则

- 新文章先判断内容类型，再选视觉分支。
- AI 协作、研究系统、产品实践类文章默认走“现实工作台”隐喻。
- 疗愈、成长、精力状态类文章可增加纸面、圆形边界、光线变化，但不直接走玄学符号。
- 求职向小红书可以更清晰、更结构化，但仍不要做强销售感简历海报。
- 所有涉及第一人称经历和个人立场的内容，仍受 [个人真实信息与表达基线](../../../../company/projects/内容矩阵/个人真实信息与表达基线.md) 约束。
