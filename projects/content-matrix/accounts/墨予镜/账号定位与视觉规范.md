## 1. 账号定位

`墨予镜` 是一个面向**企业 AI 落地**的账号，归属于 `内容矩阵` 项目。

它现在的功能是**引流**：让准客户看完想来咨询，让同行看完想来合作。变现路径是最终承接企业 AI 落地项目（咨询 + 交付）。

### 1.1 一句话定位

```text
墨予镜 —— 一个把 AI 落进企业业务的实践者，用系统的诊断方法、试点打法和交付标准，帮中小企业负责人判断「该不该上、从哪上、怎么不白花钱」。
```

### 1.2 账号角色：实践者 + 顾问混合

- **实践者这条腿**：第一人称，真实记录自己把 AI 落进业务的判断、过程和边界。
- **顾问这条腿**：输出可复用的诊断方法、试点打法、交付标准。
- **当前阶段（暂无落地案例）**：信任不靠「已交付成果」，而靠「对业务的深刻理解 + 系统的方法」立信。内容方法论先行，等有真实项目后回头补案例这条腿。

### 1.3 读者画像

- **第一读者（准客户，优先）**：中小企业负责人 / 业务负责人，正在犹豫或准备上 AI，核心焦虑是「值不值、怎么起步、怕白花钱 / 被割韭菜」。
- **第二读者（同行）**：AI 落地服务商、咨询 / 培训团队。通过方法论露底自然吸引转介绍与合作，不单独倾斜。

### 1.4 不适合的方向

- 纯教程号：只讲工具步骤、提示词模板、效率技巧。
- AI 科技媒体号：只追热点、参数、模型发布和行业新闻。
- 情绪流量号：用「AI 淘汰谁」「不转行就失业」制造焦虑。
- 个人成长 / 疗愈号：泛 AI 焦虑文、内耗、治愈（旧定位残留，已清）。
- 产品营销号：把账号变成某个工具的功能宣传入口。

## 2. 内容气质

### 2.1 关键词

- 专业
- 克制
- 可信
- 不夸大
- 有判断
- 有方法

### 2.2 语气

默认语气是第一人称复盘 + 顾问型分享。

句子直接、具体，像在把一个真实的业务问题讲清楚，再给出可复用的判断标准。可以有明确判断，但不夸大、不替读者下过度绝对的结论，也不做居高临下的教学口吻。

适合：

- 「判断你的企业该不该上 AI，先看这三件事。」
- 「这件事真正麻烦的地方，不在模型，在于谁对结果负责。」
- 「试点阶段最大的坑，是拿『做出来了』当『做成了』。」

避免：

- 「你必须上 AI，否则就被淘汰。」
- 「这套方法能让你的效率提升 10 倍。」
- 「真正厉害的企业都在用。」
- 「不转型必死。」

### 2.3 内容支柱（顾问腿先行，对准客户决策焦虑）

1. **判断 / 诊断**：你的企业该不该上 AI、该从哪上 —— 决策框架、投入产出、伪需求识别。
2. **方法 / 流程**：正确的落地长什么样 —— 诊断 → 试点 → 交付的完整路径、里程碑、角色分工。
3. **边界 / 避坑**：怎么不白花钱、什么时候该停 —— 坑、止损判断、验收标准。

### 2.4 边界（不写什么）

- 不写工具测评、提示词合集、AI 新闻（和「落地决策」无关）。
- 不吹不存在的成果（暂无落地案例，不虚构数据 / 客户）。
- 不写纯技术实现细节（读者是负责人，不是工程师）。

## 3. 视觉素材规格

### 3.1 美术定位

```text
折纸鹿 IP + 编辑感商务图 + 橙色点睛 + 无文字氛围图
```

以一只**橙色的折纸鹿**作为固定观察者 IP，画风是编辑感商务插画，橙色点睛，全部无文字氛围图。

折纸鹿同时承接两个气质：纸本的手感（人文底色）与几何折面的结构感（企业端的克制与秩序），把「安静、有结构、有判断」落到一个可记忆的符号上。

### 3.2 核心 IP：折纸鹿

- 一只折纸（origami）风格的鹿，由橙色的纸折成，有清晰的折痕、几何折面与棱角。
- 姿态：静立 / 侧身 / 回头望向远处，几何化的分叉鹿角是核心记忆点。
- 气质：安静、克制、敏锐、有结构——对应「企业 AI 落地需要清醒判断」。
- 场景：白板旁、工作台边、抽象流程线 / 信息结构之间，呈观察 / 思考的姿态。

### 3.3 形象一致性：锚点锁定（第 1 档）

纯文生图每次重新生成，做不到「每一根折痕都相同」，但折纸是强符号风格，识别点靠**锚点**而非细节。做法：

1. 先精修一张「标准鹿母版」定稿，确定：鹿角分叉数、折面感觉、身体比例、姿态、橙色明暗。
2. 之后每张图复用同一组锚点（橙色 + 几何折面 + 分叉鹿角 + 纸质感），只换场景、不换本体。
3. 锚点写死进 prompt 的通用底座，跨图一字不改（见 [折纸鹿-配图prompt模板.md](折纸鹿-配图prompt模板.md)）。

若多张对比后发现偏差超预期，再升级到图生图 / 角色参考。

### 3.4 风格：编辑感商务图

- 折纸几何 + 克制留白 + 浅底低饱和。
- 类似高端商业杂志 / 企业 SaaS 配图质感，专业、可信、不花哨。

### 3.5 配色：橙色点睛

- 基底：暖白 / 浅米。
- 结构：石墨深灰（文字、线条、框架）。
- 主色：橙色（克制、企业化的橙，非促销艳橙），用于折纸鹿本体与点缀。
- 折面明暗用不同深浅的橙（焦糖橙 / 浅橙）表现，避免单一平涂。

### 3.6 图：无文字氛围图

- 公众号配图、公众号封面、小红书封面都先用无文字氛围图，文字由正文 / 标题承担。
- 记忆点靠「折纸鹿 + 橙色」承担，不靠文字。

### 3.7 避免

- 写实照片感、3D 渲染（折纸是纸的质感，不是塑料 / 金属）。
- 可爱化 / 低幼手账贴纸。
- 赛博朋克霓虹、大面积蓝紫「AI 平台海报感」。
- 营销海报感、数据面板 / 产品发布会视觉。
- 图中堆砌文字、标题、标签、符号。
