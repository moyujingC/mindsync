## 1. 账号定位

`墨予镜` 是创作者本人的个人 IP 账号，归属于 `内容矩阵` 项目。

它承接的是创作者在 AI、产品、研究、内容、疗愈与个人成长交叉处的长期表达。这个账号应让读者感到：这是一个真实在做事的人，在用工程化的方法整理自己的实践、判断和边界。

### 1.1 一句话定位

```text
一个用 AI 做产品、做研究、做内容，也持续观察人如何在工具时代保持清醒的独立开发者 / 疗愈师。
```

### 1.2 账号角色

- 独立开发者：持续搭建产品、工作流、研究系统和内容工具。
- AI 重度使用者：分享真实协作经验、踩坑、边界和方法。
- 产品与研究实践者：把外部观察、开源拆解和项目实践转成可复用框架。
- 疗愈师 / 教练视角持有者：关注人的状态、精力、关系、成长和改变机制。

### 1.3 读者感知

读者打开 `墨予镜` 的内容时，应预期看到：

- 有真实项目现场，而不是抽象建议。
- 有方法和框架，但不压迫人。
- 有 AI 和技术，但人仍然在中心。
- 有成长和疗愈视角，但不做鸡汤式安慰。
- 有判断和边界，不追逐工具崇拜。

### 1.4 不适合的方向

- 纯教程号：只讲工具步骤、提示词模板、效率技巧。
- 情绪流量号：用焦虑、崩溃、逆袭制造点击。
- 玄学人设号：直接把神秘化表达作为第一层传播语言。
- AI 科技媒体号：只追热点、参数、模型发布和行业新闻。
- 产品营销号：把个人号变成产品功能宣传入口。

## 2. 内容气质

### 2.1 关键词

- 表达精准
- 真实
- 有边界
- 有方法
- 疗愈感
- 松弛
- 技术感
- 人文感

### 2.2 语气

默认语气是第一人称复盘 + 分享型表达。

句子应直接、具体，像在把一个真实问题讲清楚，再把其中可复用的观察分享出来。可以有个人判断，但不要替读者下过度绝对的结论，也不要使用居高临下的教学口吻。

适合：

- “我后来发现……”
- “这件事真正麻烦的地方在于……”
- “对我来说，这不是效率问题，而是质量风险。”
- “我现在会把这类任务降级处理。”

避免：

- “你必须……”
- “普通人只要掌握这套方法……”
- “真正厉害的人都……”
- “AI 时代不做这个就会被淘汰。”

### 2.3 内容母题

这里的母题是账号未来 1-3 年的内容领地设计，不是对当前几篇文章的归纳。近期内容可以从其中某一两条展开，但不能反过来限制账号的长期边界。

- 人如何在工具时代保持主体性：AI、自动化、效率、判断力、注意力、精力边界和生活节奏。
- 一人公司与独立创造者系统：从想法、研究、产品、内容、交付到复盘，如何搭建自己的长期操作系统。
- 产品、研究与内容的复合实践：产品观察、行业研究、开源拆解、知识资产、内容转译和作品化表达。
- 疗愈与成长的现代转译：情绪、关系、身体感、内在秩序、自我修复和改变机制，用大众能理解的语言表达。
- 职业与身份重建：求职、转型、能力表达、作品集、个人叙事，以及人在不同阶段如何重新组织自己。
- 东方文化、审美与个人方法：把传统文化、象征系统、节律感和审美体验转成当代可理解、可实践的表达。
- 真实项目现场：产品建设、工具选择、失败复盘、取舍过程和阶段性成果，让读者看到一个人如何把想法落到现实里。

## 3. 视觉素材规格

### 3.1 美术定位

```text
折纸鹿 IP + 编辑感商务图 + 橙色点睛
```

`墨予镜` 已从「个人疗愈 IP」转向「企业 AI 落地」账号。视觉随之重定义：以一只**橙色的折纸鹿**作为固定观察者 IP，画风是编辑感商务插画，用橙色点睛，全部是无文字氛围图。

折纸鹿同时承接两个气质：纸本的手感（原账号的人文底色）与几何折面的结构感（企业端的克制与秩序），把「安静、有结构、有判断」落到一个可记忆的符号上。

#### 3.1.1 核心 IP：折纸鹿

- 一只折纸（origami）风格的鹿，由橙色的纸折成，有清晰的折痕、几何折面与棱角。
- 姿态：静立 / 侧身 / 回头望向远处，几何化的鹿角是核心记忆点。
- 气质：安静、克制、敏锐、有结构——对应「企业 AI 落地需要清醒判断」。
- 场景：白板旁、工作台边、抽象流程线 / 信息结构之间，呈观察 / 思考的姿态。

#### 3.1.2 风格：编辑感商务图

- 折纸几何 + 克制留白 + 浅底低饱和。
- 类似高端商业杂志 / 企业 SaaS 配图质感，专业、可信、不花哨。
- 折纸的折面与棱角本身就是「结构感」的视觉表达。

#### 3.1.3 配色：橙色点睛

- 基底：暖白 / 浅米。
- 结构：石墨深灰（文字、线条、框架）。
- 主色：橙色（克制、企业化的橙，非促销艳橙），用于折纸鹿本体与点缀。
- 折面明暗可用不同深浅的橙（焦糖橙 / 浅橙）表现，避免单一平涂。

#### 3.1.4 图：无文字氛围图

- 公众号配图、公众号封面、小红书封面都先用无文字氛围图，文字由正文 / 标题承担。
- 记忆点靠「折纸鹿 + 橙色」承担，不靠文字。

#### 3.1.5 避免

- 写实照片感、3D 渲染（折纸是纸的质感，不是塑料 / 金属）。
- 可爱化 / 低幼手账贴纸。
- 赛博朋克霓虹、大面积蓝紫「AI 平台海报感」。
- 营销海报感、数据面板 / 产品发布会视觉。
- 图中堆砌文字、标题、标签、符号。
