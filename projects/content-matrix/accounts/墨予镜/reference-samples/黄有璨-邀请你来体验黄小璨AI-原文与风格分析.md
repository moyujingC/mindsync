# 黄有璨：邀请你，来体验黄小璨AI - 原文与风格分析

## 用途

这篇作为 `墨予镜` 的参考样本，主要用于学习“招募转化型文章”里更具体的一种写法：产品体验试用型。

重点学习：

- 如何先把产品说清楚，再顺着用户最关心的问题一路往下回答
- 如何用“是什么 / 能干啥 / 靠谱么 / 怎么试”这种问答结构降低理解门槛
- 如何通过能力清单、截图和真实反馈建立试用信心
- 如何把一次低门槛试用包装成值得上手的体验入口

## 原文

邀请你，来体验黄小璨AI

来吧，兄弟姐妹们，邀请你们来体验一个有点意思的产品。

正式介绍下——

黄小璨AI，一个长期陪伴型的 AI 个人商业私教。

黄小璨 AI 重点服务年收入 100 万以下的早期个体创业者/自由职业者，一部分正面临职场转型、想重新寻找方向的人，和一部分成长期的创业者。

可以简单理解为：让 AI 版的老黄，担任你的个人私教、创业顾问和商业顾问。

快速回答几个问题。

1. 黄小璨AI 是什么？

我们独立开发的智能体，经过训练，ta掌握了我的核心语料、价值观、商业认知、思考判断方式，可以理解为是我的AI 分身。

并且，它的语料库，后续将是实时更新的——也就是说，我又学习研究了什么新的案例，有什么新的认知和总结，它也将实时掌握。

它的目标不是只回答问题，而是要持续帮助你看清问题、推进问题、解决问题、带来改变。

它不是简单的聊天机器人，而是让你能持续获取到我的最新认知、思考，也让这些认知和思考，可以更好帮你解决你自己的问题。有点像是，找了一个持续在“AI+OPC 创业”一线持续实践、学习和思考的专家，可以陪在你身边，有事你随时可以找他，他也会每天都跟你聊聊他的最新思考、见闻和心得。

它的专业能力，重点覆盖商业、一人公司、个人内在成长、心力成长等方向。

2. 黄小璨AI 能干啥？

黄小璨已开通的核心能力包括——

1. 针对想要或刚开始进行个体创业、一人公司的用户，进行测评，并结合测评结果来帮助你在需要的地方进行提升，或者进行深入交流。

2. “问我”——随时随地，可以向ta 进行答疑和提问。比如，你可以问 ta，我的业务是这样的，成交转化不好，我的私域运营该怎么做？

我的情况是这样的，我现在到底是做小红书好还是视频号好？

我一直卡在某个地方动不了，该怎么办？

3. “深度咨询”——在常规答疑交流的基础上，黄小璨AI 还支持“深度咨询”模式，这是一个整合了教练技术、我的一部分“深度挖掘+看见”能力的长对话模式，可以帮你一起深度梳理+讨论一个你当前自己可能都没太想清楚的问题，挖掘问题背后的根源，找到真正有效的解决方案。

无论是商业问题，还是所谓“内在成长、心力卡点”的问题，深度咨询都能很好支持。

4. 记忆能力。黄小璨AI 可以记住你们的对话，会根据过往对话中你的特点、关注点、业务和需求来跟你进行对话。

5. 我的每日日课。

简单理解，就是我每个工作日都会固定更新的每日创业+商业思考，目前我过去 4 年写过了超过 100 万字日课，全部在黄小璨AI 中可查，无形中也会是你的一份“个体创业知识库”。

6. 课程。黄小璨AI 也支持课程模式，并且，这个课程也是AI 化的，简单理解的话，根据你的个人背景和情况，课程会进行不同的有针对性的讲解。

比如同样讲AI应用，你是电商行业的和你是做知识付费的，课程的讲述方式会有不同。

目前已上线“AI 时代的一人公司通识课”+“龙虾，从开通到好用”两门课程。

跟大模型的聊天机器人不同，黄小璨AI 除了在专业能力和行业 know-how 上拥有我的语料之外，ta 也会是一个不会一味讨好你，而是该刀你时会刀你，该耐心时也会比较温柔耐心的一个AI 商业教练。

## 表达分析

### 1. 文章类型

这是“招募转化型文章”里的产品体验试用型。

它不是先讲宏大理念，也不是先讲活动玩法，而是顺着用户最常见的疑问，一层层把产品说明白，再把试用门槛降到最低。

### 2. 主体结构

文章大致按这个顺序推进：

1. 先一句话定义产品是什么、适合谁。
2. 再用问答结构，回答用户最关心的几个问题。
3. 在“能干啥”这一段里，把能力、场景、课程和风格逐步讲全。
4. 再用真实反馈补一层信任。
5. 最后才讲试用方式、价格、限制和推荐人群。

### 3. 关键写法

- 结构非常顺手，几乎就是用户脑子里的问题顺序。
- 不急着讲价值观，先把“这到底是什么”讲明白。
- 能力展示是“功能 + 场景 + 示例”的组合，不只是功能表。
- 通过“靠谱不靠谱”这一问，主动接住用户的怀疑。
- 试用价格、限制条件、适合谁，都讲得很具体，减少试用顾虑。

### 4. 它为什么好用

- 适合 AI 产品开放体验、订阅试用、工具首发、小程序上线这类内容。
- 能同时完成说明、消疑、建立信任和完成转化。
- 对 `墨予镜` 来说，这种写法很适合未来做产品页式文章、体验邀请和轻量销售页。

### 5. 不适合直接模仿的部分

- 如果产品能力本身还不够成熟，这种写法会把短板暴露得很直接。
- 问答结构好用，但不能答得太散，不然会像客服 FAQ。
- 功能多时最怕堆砌，还是要围绕用户为什么会用来讲。

## 可迁移规则

- 产品试用类文章可用结构：一句话定义 -> 是什么 -> 能干啥 -> 靠谱么 -> 怎么试 -> 适合谁。
- 先把产品是什么讲清楚，再讲理念，不然读者容易飘。
- 功能介绍最好和使用场景绑在一起，而不是孤立列清单。
- 主动回答“靠谱吗”这种防御性问题，会比回避更有效。
- 试用价格、使用范围、限制条件、适合人群都要写具体。

## 可复用句式

```text
先别急着判断它值不值得试。
你可以先把几个最关键的问题看完：
它到底是什么，能帮你做什么，适不适合你，以及你可以怎么低门槛地试一下。
```
