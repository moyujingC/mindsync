# 黄有璨：幸福流工作坊招募 - 原文与风格分析

## 用途

这篇作为 `墨予镜` 的参考样本，主要用于学习“招募转化型文章”的表达方式。

重点学习：

- 如何先讲理念和状态，再承接招募
- 如何把抽象价值翻译成读者能对号入座的痛点
- 如何做明确筛选，而不是泛泛招募
- 如何把“卖产品”写成“邀请进入一个场域”

## 原文

正式告知大家，我将第一次对外开放我的“幸福流个人IP/小而美创业”5天深度工作坊的报名。

我的“幸福流小而美创业工作坊”，首次开放招募

具象点讲，就是我实证体验了一种小而美创业的理想模式，既能保持团队人效至少在80-100w/人.年左右，又能让自己和团队长期保持在上述状态下，有一种很稳定的幸福感，同时业务还能保持长期的稳定复利式增长。

这个模式，特别适用于个人IP、一人公司，还有30人以内的小团队小组织。

这个工作坊，就是带大家深度体验，怎么才能做到这样的状态，到底是哪些东西在阻碍着你。

关于这个深度工作坊，其实可以5天，也可以7天，之前其实已经做过好几次了，只不过都是私密范围内面向我的一些学员做，没有正式对外开放过。

4月2日-7日期间，我们会正式对外开放1次5天版本的工作坊对外报名，地点在北京怀柔，慕田峪长城下的某小院，环境很好。

（2）
这个工作坊，我用3段话描述吧——

1）未来10年，我给自己发的身份牌，是要做好一个“土壤”，而不是做一棵“大树”。
一个“土壤”最大的价值，就是要能支持和承载更多人能生长得更好，能变得更闪光更牛逼。

且，我很确信，我一定会是一个顶级的“土壤”。
更人话一点的话，就是今天的我特别懂得怎么才能让一家公司或者一个人，可以长期幸福、稳定，还能保持长期人生复利效应的赚钱，把商业变得更有人文气息和幸福感。

如果你想要深度体会下这种“土壤”的价值，申请参加这个工作坊+到线下来一起深度互动下，会是最好的方式。

2）这个工作坊最大的价值，是“看见”和“突破”。

即：身处这个场域里，也许能让你“看见”很多之前让你觉得混沌、不清晰的东西，尤其是很多内在的“不顺”和“卡点”。

然后，你将有机会去通过训练改变它，有了“突破”。

过往来看，之前的同学们每次参与，都能从中有重大突破。

3）很多人会反复来参加这个工作坊。他们的理由是：每次参加过+完成一些训练后，都会在很长时间里感觉自己“强得可怕”。

举办这个工作坊，既是为了更好支持我的很多学员们不断有突破有成长，也是为了不断能找到很多对脾气、有意思的人，大家可以长期一起愉快玩耍。

首先，你得是个创业者，做个人IP，做一人公司，或者做其他有点“小而美”属性的创业，都可以。

其次，最好你心里多少还有点人文情怀和小理想主义。

7. 经常会觉得，自己没有把自己放对位置，没有把自己充分用好；

## 表达分析

### 1. 文章类型

这是“招募转化型文章”。

它不是一上来就讲课程安排，也不是先堆卖点，而是先建立一种读者想进入的状态，再把报名动作自然接上。

### 2. 主体结构

文章大致按这个顺序推进：

1. 先讲理念：什么是“幸福流小而美创业”。
2. 再讲状态：这套东西能把人带到什么状态。
3. 再讲价值：工作坊能帮助你“看见”和“突破”。
4. 再做人群筛选：什么样的人适合来，什么问题会被它击中。
5. 最后才讲形式、模块、时间、地点和报名方式。

### 3. 关键写法

- 先卖世界观，再卖产品。
- 先让人觉得“这说的是我”，再进入报名信息。
- 价值不只写成“能学到什么”，而是写成“能进入什么状态”。
- 用明确筛选提高信任感，而不是把所有人都往里装。
- 抽象理念后面，马上接具体困境和场景。

### 4. 它为什么有转化力

- 不是在推一个课程，而是在邀请读者进入一个场域。
- 不是在罗列功能，而是在命名读者说不清的问题。
- 不是广撒网，而是在筛选“对的人”。
- 这样反而会让目标读者更愿意靠近。

### 5. 不适合直接模仿的部分

- 个人人格势能很强，这一点不能硬学。
- “强得可怕”“顶级土壤”这类表达，借的是作者已有信任，不适合平移。
- 对 `墨予镜` 而言，更该学的是结构和承接关系，不该学过满的自我确认。

## 可迁移规则

- 招募类文章可用结构：理念 -> 状态 -> 痛点 -> 人群筛选 -> 转化承接。
- 先回答“这件事为什么值得”，再回答“它具体怎么卖”。
- 如果理念偏抽象，后面必须立刻接具体痛点，不然会飘。
- 不要急着讲模块、价格、报名方式，这些应放在读者完成自我识别之后。
- 明确写“什么样的人适合来”，比泛泛说“欢迎大家报名”更有效。

## 可复用句式

```text
我想做的，不只是一个产品。
更准确地说，我想提供的是一种状态、一种场域，或者一种更适合你的做事方式。

如果下面这些描述里，有几条明显说中了你，那这件事大概率就是为你准备的。
```
