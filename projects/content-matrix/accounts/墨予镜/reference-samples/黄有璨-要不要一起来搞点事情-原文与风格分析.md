# 黄有璨：要不要，一起来搞点事情？ - 原文与风格分析

## 用途

这篇作为 `墨予镜` 的参考样本，主要用于学习“招募转化型文章”里更具体的一种写法：联合召集 / 共创招募型。

重点学习：

- 如何不是直接卖一场活动，而是先招募一批“共同把事做起来的人”
- 如何把传播动作包装成一次有参与感的共创
- 如何同时完成筛选、动员、利益绑定和价值预告
- 如何让“帮忙推广”这件事不显得像廉价拉新

## 表达分析

### 1. 文章类型

这是“招募转化型文章”里的联合召集 / 共创招募型。

它不是直接招最终用户，而是先招一批愿意一起把事情做起来的人。用户买到的，不只是参与资格，也包括参与感、学习机会和利益绑定。

### 2. 主体结构

文章大致按这个顺序推进：

1. 先讲这件事为什么重要，对作者本人意味着什么。
2. 再讲这场公开课的更大意义和判断背景。
3. 再抛出这次真正的招募对象：不是学员，而是联合召集人。
4. 再讲召集人能获得什么，包括学习、福利、玩法、奖励和实战机会。
5. 最后才讲时间线、费用、退出机制和操作方式。

### 3. 关键写法

- 不是“帮我拉人”，而是“跟我一起搞一件有意思的事”。
- 把传播任务改写成学习机会、共创机会和社交玩法。
- 先让人认同这件事的方向，再承接到招募动作。
- 收费不是盈利逻辑，而是筛选机制，这一点被明确讲出来。
- 退出机制和退款机制讲得清楚，降低参与顾虑。

### 4. 它为什么好用

- 适合公开课召集人、内测共创官、种子用户、城市合伙人、传播搭子这类招募。
- 它能同时解决三件事：筛选人、绑定人、放大传播。
- 对 `墨予镜` 来说，这种写法后面也很适合用在共创活动、志愿者招募、种子用户招募。

### 5. 不适合直接模仿的部分

- 如果事情本身不够有吸引力，只靠“来一起玩”撑不住。
- 奖励可以讲，但不能让整篇只剩分销味。
- 共创招募最怕权责不清，所以时间线、门槛、退出机制一定要讲清楚。

## 可迁移规则

- 共创招募类文章可用结构：事情意义 -> 更大判断 -> 招募对象 -> 参与收益 -> 时间机制 -> 退出保障。
- 不要一上来就说“帮我推广”，先让读者认同这件事值得被做。
- 把参与者得到的东西讲清楚：学习、关系、玩法、奖励，至少要成立两样。
- 如果设置费用，最好明确说明它是筛选和投入承诺，不是盈利目的。
- 退出机制、退款机制和时间安排讲清楚，会极大降低防御感。

## 可复用句式

```text
我不是单纯想再招一批参与者。
我更想先找到一批愿意一起把这件事做起来的人。

如果你认同这件事本身值得被做，那这次参与，对你来说就不只是一次报名，更像是一次共同发起。
```
