# 骨架库 JSON 说明

骨架库是「完整 HTML 骨架」的集合，把公众号排版的块级元素原样保留，只把文字/图片换成占位符。这是实现 1:1 无损复刻的关键——不复刻「抽取的字段」，而是复刻「原文的 HTML」。

## 结构

```json
{
  "name": "风格名",
  "source": "复刻来源链接",
  "blocks": [
    { "role": "paragraph", "count": 89, "skeleton": "<p style=\"color: rgb(51, 51, 51);font-size: 16px;line-height: 1.8em;...\">{{text}}</p>" },
    { "role": "heading",   "count": 6,  "skeleton": "<h1 style=\"margin-top: 30px;...\"><span style=\"font-size: 24px;color: rgb(110, 127, 168);...\">{{text}}</span></h1>" },
    { "role": "list", "count": 5,
      "skeleton": "<section style=\"margin:4px 0;padding-left:25px;...\">{{items}}</section>",
      "listItem": "<span style=\"text-indent:-1em;display:block;margin:8px 0;\">•{{text}}</span>" }
  ],
  "inline": { "strong": { "color": "rgb(51,51,51)", "weight": "bold", "background": null } },
  "container": "<section style=\"...padding-left:10px;...\">{{content}}</section>"
}
```

## 占位符

| 占位符 | 含义 | 复刻时填入 |
|---|---|---|
| `{{text}}` | 一段文字 | 内联 HTML（含 `<strong>` 等，`**加粗**` 已转换） |
| `{{img}}` | 一张图片 URL | 图片地址 |
| `{{items}}` | 列表项容器 | 复制 `listItem` 模板 N 次 |
| `{{content}}` | 外层容器内容 | 全部块 HTML |

## 角色类型

`blocks[].role` 是块的角色，决定复刻时新文章块套哪个骨架：

| role | 对应 markdown | 识别依据 |
|---|---|---|
| `paragraph` | 普通段落 | 默认（字号≈正文基准） |
| `heading` | `##`/`###` | 字号 > 正文基准 +1px |
| `quote` | `>` 引用 | blockquote 标签，或「背景色 + 左边框」 |
| `list` | `-`/`1.` 列表 | ul/ol 标签，或「•/数字. 符号 + 缩进」 |
| `image` | `![alt](url)` | 含 img |

每个角色可能有多个变体（`count` 不同），复刻时取 count 最多（最典型）的那个。

## 留骨架 vs 抽字段

旧方案预设字段（字号/颜色/间距），抽取后重拼「干净」HTML——有损：

- 预设字段换一篇结构不同的文章就失效
- 丢掉嵌套关系、容器边框、列表符号、span 拆分

本方案不预设字段，原样保留「标签 + 完整 style + 嵌套」，只换文字/图片。几种结构的处理：

- **内联 span 拆分**：拍平（span 是内容拆分，非排版），文字合并成一个 `{{text}}`
- **内联强调**（strong/b/em…）：标签拍平，颜色/字重抽进 `inline` 库（bold 位置是内容，样式才是排版）
- **语义容器**（blockquote/ul/ol/figure/table）：整体保留，不下钻（保住边框/列表符号/表格）
- **外层容器**（mdnice 的 section）：识别「覆盖大部分内容的那个分叉容器」，抽成 `container`
- **隐藏元素**（display:none）：跳过（微信的版权声明尾巴）

## 两种形态的实现差异

| | 公众号（`render-wechat`） | 小红书（`render-xhs`） |
|---|---|---|
| 原理 | HTML 骨架填字，100% 复刻 | 从骨架反推 token，SVG 卡片 |
| 正文字号 | 骨架里原值（16px） | 放大到 34px |
| 布局 | 流式长文 + 外层容器 | 3:4 画布，撑满再换页 |

小红书是「重新排版」，无法直接用 HTML 骨架，所以从骨架反推 token（正文色/字号/行高、标题色/字号/左边框、强调色、引用色），再按 `bodySize=34` 整体放大。反推逻辑在 `lib/style-tokens.mjs`。

## 手改骨架

直接编辑 JSON 即可，不必重新抓取。常用调整：

- 想改正文颜色：改 `paragraph` 骨架里 `style="..."` 的 `color`
- 想改标题字号：改 `heading` 骨架里的 `font-size`
- 想换强调色：改 `inline.strong.color`
- 想加/改列表符号：改 `list` 变体的 `listItem` 里的符号

> 注意：手改只影响公众号 HTML 的复刻；小红书 token 是运行时从骨架反推的，改骨架会自动反映到小红书卡片。
