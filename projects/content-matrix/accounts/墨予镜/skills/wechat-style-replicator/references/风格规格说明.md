# 风格规格 JSON 说明

风格规格是一份「比例化 token」，把公众号排版的可复用要素抽出来，供两种视口（公众号 / 小红书）展开。

## 结构

```json
{
  "name": "风格名",
  "source": "复刻来源链接",
  "colors": {
    "title": "#303543",   // 主标题 / 一级标题（深色）
    "heading": "#6e7fa8", // 小节标题 / 强调色（蓝雾）
    "body": "#393d49",    // 正文
    "strong": "#333333",  // 加粗强调
    "meta": "#a8b1c4",    // 辅助 / 图注 / 页脚
    "blockBg": "#f0f3fa"  // 引用块背景
  },
  "typography": {
    "body": { "size": 16, "lineHeight": 1.8, "weight": 400 },
    "title": { "sizeRatio": 1.44, "color": "title", "weight": 600 },
    "headingPrimary": { "sizeRatio": 1.5, "color": "heading", "weight": 600, "border": null },
    "headingSecondary": { "sizeRatio": 1.38, "color": "heading", "weight": 600, "border": null },
    "strong": { "color": "strong", "weight": 600 },
    "quote": { "sizeRatio": 1.0, "color": "heading", "weight": 400 }
  },
  "spacing": { "paraGap": 1.125, "headingTop": 2.125, "headingBottom": 0.94 }
}
```

## 关键约定

### 字号 = 比例，不是绝对值

`sizeRatio` 是相对正文字号的比例。正文 `body.size` 是唯一存绝对 px 的字号。

- 标题实际字号 = `body.size × sizeRatio`
- 公众号视口 `body.size = 16` → 标题 23px
- 小红书视口 `body.size = 34` → 标题 49px（等比放大）

### 颜色 = 引用

`typography.*.color` 存的是 `colors` 里的键名（如 `"title"`、`"heading"`），渲染时按键取值。这样「标题色」「小节标题色」语义清晰，改一处即可全局生效。

### 标题边框装饰（可选）

`headingPrimary.border` / `headingSecondary.border` 存标题的装饰边框（如增长女黑客的橙色竖条）：

```json
"border": { "side": "left", "width": 4, "color": "#e8501a", "style": "solid" }
```

- `null` = 无边框（默认，mdnice 等纯文字标题）
- 抽取自标题的 `border-left` 简写；公众号渲染成 `border-left + padding-left`，小红书渲染成竖线
- 边框宽度在小红书视口按正文字号比例缩放（4px → 9px）

### 两种视口的分工

| 要素 | 公众号（`render-wechat`） | 小红书（`render-xhs`） |
|---|---|---|
| 正文字号 | `body.size`（≈16px） | 34px |
| 小节标题色 | `heading`（蓝雾，h2 惯例） | `title`（深色，一级标题惯例） |
| 布局 | 流式长文，不分页 | 3:4 画布，撑满一页再换页 |

> 注意：同一份风格里 `title`（深）和 `heading`（蓝）两个色都保留，两个渲染器各取所需——公众号小节标题用蓝雾、小红书卡片标题用深色，这符合账号两条渠道各自的视觉惯例。

## 抽取与归一化

`extract-style.mjs` 从公众号 `content.html` 里：

1. 正文 `p` 的 font-size / line-height / color 取众数 → `body` + `colors.body`
2. 标题 `h1/h2/h3` 的字号除以正文字号 → `sizeRatio`，颜色 → `colors.title/heading`
3. 强调 `strong` 的 color / weight → `colors.strong` + `typography.strong.weight`
4. 引用 `blockquote` 的 background → `colors.blockBg`

抽取不到时回退到账号默认「蓝雾静读版」（`DEFAULT_SPEC`）。

## 手改风格

直接编辑 JSON 即可，不必重新抓取。常用调整：

- 想标题再大一点：加大 `headingPrimary.sizeRatio`
- 想换强调色：改 `colors.heading` 或 `colors.strong`
- 想正文更松：加大 `spacing.paraGap`
