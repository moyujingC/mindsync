# 公众号去 AI 味模式清单（De-AI Style）

> 用途：在 `表达降噪` 轮使用。识别并消除公众号判断型长文里的 AI 写作痕迹。
> 这不是学术降 AIGC 检测率，也不是把文章改成口语大白话；目标是「删掉空泛套话，留下精准判断」。

## 0. 一个总原则：去 AI 味 ≠ 去判断

AI 味的问题从来不是"太像人在写"，而是"只有套话、没有判断"。

所以去 AI 味的正确方向是：**把空泛的套话换成具体的判断**，而不是把判断也删掉、把文章磨成四平八稳的说明文。

- 删：口号、空话、模板化的起承转合、无出处的"专家认为"、每段结尾的拔高。
- 留：作者自己的判断、具体的画面、有轻重缓急的论述。

宁可保留一句带偏见的判断，也不要一句无懈可击的废话。

## 1. 内容层的 AI 味

### 模式 1：口号式结论

AI 爱把结论写成大词口号，而不是落到具体判断。

| 触发词 | 问题 |
| --- | --- |
| 底层逻辑、认知升级、重新定义、赋能、抓手、闭环、心智、破局、重构、重塑 | 抽象名词堆砌，读者不知道到底在说什么 |

**改前：**
> 企业 AI 落地的底层逻辑，是认知的升级。

**改后：**
> 企业上 AI，卡住的从来不是买不起工具，而是说不清要先改哪条流程。

**规律：** 把大词口号，换成"谁 + 卡在哪 + 该怎么做"的具体陈述。

### 模式 2：防御型表达

先虚构一个读者未必关心的误解，再否定它，读起来像在替观点辩护。

| 触发句式 | 问题 |
| --- | --- |
| "不是 A，也不是 B，而是 C" | 先制造两个假靶子再进入正题 |
| "不在于 A，也不在于 B，真正重要的是 C" | 同上 |

**改前：**
> 企业上 AI，重点不在于买什么工具，也不在于上多少培训，真正重要的是选对流程。

**改后：**
> 企业上 AI，第一件事是挑一条真实流程，把它跑通。

**例外：** 只有当读者确实存在明确误解、且这个误解会挡住理解时，才用先否定再重构。否则直接给判断。

### 模式 3：模板化并列

"首先/其次/最后"三条等长等重，每条一句话带过，没有轻重。

**改前：**
> 企业上 AI 有三个关键：第一，选工具；第二，找人才；第三，定流程。

**改后：**
> 企业上 AI，最要命的是流程。工具反正是要换的，人才也可以慢慢补，但流程没选对，前面全是白搭。

**规律：** 最重要的先说、说透；次要的一笔带过。真实的人写作，理由本来就轻重不一。

### 模式 4：段末拔高总结句

每段结尾都要"升华"一句，形成整齐的节奏，反而暴露是机器写的。

**触发词：** 这背后、这恰恰说明、究其根本、本质上、归根结底、由此可见

**改前：**
> ……报价要经过三个岗位。这背后，是企业流程协作的深层困境。

**改后：**
> ……报价要经过三个岗位，谁都不知道中间卡在哪一步。

**规律：** 删掉拔高句；如果需要衔接，用转折或追问代替，让节奏往前走。

## 2. 语言层的 AI 味

### 模式 5：AI 高频词

| AI 高频词 | 替换建议 |
| --- | --- |
| 值得注意的是 | 删，或改成"有个细节" |
| 综上所述 / 由此可见 / 不难发现 | 删 |
| 需要指出的是 | 删，或改成"不过" |
| 深入 / 系统地 / 全面 | 删，直接说做了什么 |
| 赋能 / 助力 / 引领 / 打造 | 换成具体动词：帮、让、做成 |

**规律：** 一个词如果删掉后句子意思不变，就删掉。

### 模式 6：无主语被动分析

AI 用"该 XX 体现了"把人的主观判断描述成自动发生的结果，缺主体性。

**改前：**
> 这套流程的设计，体现了对效率与风险的平衡考量。

**改后：**
> 我坚持在这套流程里留一道人工审核，因为报价算错，损失的是客户。

**规律：** 说明"谁、为什么这么做"，而不是"该处理体现了什么"。

### 模式 7：模糊归因

**触发词：** 专家认为、研究表明、业内人士普遍认为、有观点认为（无具体出处）

**改前：**
> 业内人士普遍认为，企业 AI 落地的关键是场景。

**改后：**
> （有出处就写具体来源；没出处就改成自己的判断）我看过的案例里，落地好的都先把场景切得很小。

**规律：** 禁止无出处的"专家认为"。有来源写来源，没来源就写"我看到的/我判断的"。

### 模式 8："在当下这个时代"式起笔

**改前：**
> 在 AI 快速发展的今天，企业纷纷寻求智能化转型。

**改后：**
> 最近找 AI 服务商的企业，第一句话几乎都是同一个工具名。

**规律：** 删掉时代背景铺垫，直接进入具体场景。

## 3. 风格层的 AI 味

### 模式 9：破折号 / 加粗滥用

- 破折号一段内超过 4 次 → 删减，部分改为句子切分。
- 加粗全文超过 5 处 → 削减，只保留真正需要强调的 1-2 处。

### 模式 10：情绪空转

**触发词：** 令人震撼、让人深思、不可想象、颠覆性、史无前例

**规律：** 删掉情绪形容词，让事实和判断本身说话。读者觉得震撼，才会真的震撼；你喊"震撼"，读者反而无感。

### 模式 11：节奏单一

- 每句话长度接近、每段长度接近 → 是 AI 痕迹。
- 有意制造长短交替：长句铺陈，短句收束、转折、下判断。

**改前：**
> 企业上 AI 需要选对流程，选对流程需要看清现状，看清现状需要真实记录。

**改后：**
> 企业上 AI，先看清一条真实流程。别的都可以后说。

## 4. 硬约束（输出前逐项核查，命中即修）

| 约束项 | 硬上限 |
| --- | --- |
| AI 高频词（模式 5） | 每段 ≤2 个 |
| 段末拔高句（模式 4） | 全文 ≤1 处 |
| 防御型"不是 A 而是 B"（模式 2） | 全文 ≤1 处（且确有读者误解才用） |
| 模糊归因（模式 7） | 全文 0 处 |
| 空泛大词（模式 1：赋能/抓手/底层逻辑等） | 全文 ≤3 个 |
| 加粗 | 全文 ≤5 处 |
| 破折号 | 单段 ≤4 次 |

## 5. 噪声预算（防止过度修改）

**不要把所有段落都改得风格一致。** 人类写作本身有波动。

- 每千字允许保留 2-3 处轻微 AI 特征，作为自然噪声。
- 首选保留：轻度的并列（两项即可，不是三元对称）、个别无伤大雅的过渡词。
- 不保留：口号式结论、"专家认为"、段末拔高——这些权重高，直接暴露。

全部消除，反而会因过度均质化，产生一种新的、更隐蔽的"机器感"。

## 6. 去 AI 味之后，还差一步：表达准确

去 AI 味解决的是"不像机器写的"，是底线。但一篇好文章还要"像你写的"，这靠**表达准确**，来自黄有璨的风格锚点：

- 判断精准，不绕着说；宁可锋利，不磨成四平八稳。
- 分类清楚，让读者感到"你脑子里有完整地图"。
- 抽象结论后面，配一个具体画面或比喻。
- 每句话都在推进论点，不浪费篇幅做铺垫。
- 结尾把判断权踢回读者，而不是给一个标准答案。

这一层在 `风格校准` 轮完成，见 [editing-rounds.md](editing-rounds.md) 第 4 轮。

## 7. 快速自检清单

| 检查项 | 标准 |
| --- | --- |
| 口号大词 | 全文 ≤3 个"赋能/抓手/底层逻辑"类 |
| 防御句式 | ≤1 处，且确有读者误解 |
| 段末拔高 | ≤1 处 |
| 模糊归因 | 0 处"专家认为" |
| AI 高频词 | 每段 ≤2 个 |
| 加粗/破折号 | 加粗 ≤5、单段破折号 ≤4 |
| 节奏 | 有长短句交替 |
| 判断 | 有"我的判断是/我看到的"这类主体性表达 |
| 噪声 | 每千字留 2-3 处轻微特征，不过度清洁 |
