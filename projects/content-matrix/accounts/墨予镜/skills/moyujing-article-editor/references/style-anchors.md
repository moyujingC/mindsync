# Style Anchors

Use only the anchor type that best matches the current draft. Do not load every section by default.

## 1. Personal Milestone Type

Use for:

- personal state change
- stage review
- important personal turning point
- turning personal experience into a broader judgment

Reusable rules:

- open with a state or judgment
- translate abstract ideas into human wording quickly
- use personal experience as evidence, not self-display
- allow a light lift at the end, but do not force elevation

Main sample:

- `../../reference-samples/黄有璨-四十岁生日自述-原文与风格分析.md`

## 2. Trend Judgment Type

Use for:

- AI热点
- platform changes
- public debates triggered by AI
- enterprise AI shifts
- tool waves and ecosystem changes

Reusable structure:

`现象 -> 担心 -> 底层问题 -> 错位 -> 建设方向`

Reusable rules:

- acknowledge importance first
- separate visible heat from the deeper issue
- do not stop at critique; give a constructive direction
- if the topic is platform or layoff related, continue into entry points, power shifts, contracts, identity, or social order as needed

Main samples:

- `../../reference-samples/黄有璨-全民龙虾热与OPC叙事-原文与风格分析.md`
- `../../reference-samples/黄有璨-微信AI正在悄然改变游戏规则-原文与风格分析.md`
- `../../reference-samples/黄有璨-关于微信AI会如何落地的一些猜想-原文与风格分析.md`
- `../../reference-samples/黄有璨-张雪峰skill背后的争议和思考-原文与风格分析.md`
- `../../reference-samples/黄有璨-当大厂不再需要活人-原文与风格分析.md`

## 3. Stage Judgment Type

Use for:

- stage models
- growth or maturity paths
- “what should be done at this stage” questions

Reusable structure:

`核心框架 -> 阶段解释 -> 不能跳阶段 -> 行动建议`

Reusable rules:

- give a short frame early
- answer what to do, what not to do, and what goes wrong if mixed up
- translate abstraction into action
- end with self-check or action advice

Main sample:

- `../../reference-samples/黄有璨-一人公司创业三阶段-原文与风格分析.md`

## 4. Concept Breakdown Type

Use for:

- easy-to-confuse concepts
- personal vs organization boundaries
- “是不是一回事” questions

Reusable structure:

`误区提出 -> 重新定义 -> 本质判断 -> 前置条件 -> 为什么重要 -> 边界修正`

Reusable rules:

- redefine before judging
- explain both what it is and what it is not
- attach a signal, image, or metaphor to abstract judgment

Main sample:

- `../../reference-samples/黄有璨-老板们是不是更应该把自己先AI化-原文与风格分析.md`

## 5. Character Profile Type

Use for:

- founders
- operator profiles
- creator transformation
- a person as a window into a larger era

Reusable structure:

`反差场景 -> 事实补底 -> 时间节点 -> 矛盾拆解 -> 外部切片 -> 核心追问`

Reusable rules:

- start with contrast, not resume
- let facts support judgment
- keep complexity alive instead of flattening the person

Main sample:

- `../../reference-samples/黄有璨-追觅俞浩一个天才CEO的自我流放和社会实验-原文与风格分析.md`

## 6. Recruitment Conversion Type

Use for:

- workshop or camp recruitment
- product or community beta recruitment
- co-creator or seed-user recruitment
- trial invitation

Reusable base structure:

`理念 -> 状态 -> 痛点 -> 人群筛选 -> 转化承接`

Important variants:

- AI learning/community beta:
  `../../reference-samples/黄有璨-一个有关AI加OPC创业学习的新尝试-原文与风格分析.md`
- co-creator recruitment:
  `../../reference-samples/黄有璨-要不要一起来搞点事情-原文与风格分析.md`
- product trial invitation:
  `../../reference-samples/黄有璨-邀请你来体验黄小璨AI-原文与风格分析.md`
- worldview-first workshop recruitment:
  `../../reference-samples/黄有璨-幸福流工作坊招募-原文与风格分析.md`

Reusable rules:

- do not open with logistics
- explain why this should exist before explaining how to buy or join
- if it is beta or trial based, make constraints, price, and refund logic concrete
- if it is co-creation based, frame it as doing something together, not just helping with promotion

## 7. Research Breakdown Type

Use for:

- report explanations
- podcast or speech extraction
- long external material reframed for readers

Reusable structure:

`来源交代 -> 提炼框架 -> 分层拆解 -> 关键判断 -> 开放问题`

Reusable rules:

- tell the reader why the source is worth their time
- act as first-pass filter, not as搬运工
- keep both information and judgment present

Main sample:

- `../../reference-samples/黄有璨-从超级个体到超级团队-原文与风格分析.md`
