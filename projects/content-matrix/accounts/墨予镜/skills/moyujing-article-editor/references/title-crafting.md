# 标题润色（Title Crafting）

> 用途：成稿编辑的收尾轮。正文判断定稿后，把标题打磨到「像墨予镜、能点进来、不发假」。
> 本轮必须先读本文。目标不是起更多标题，是给每个标题一个能追溯到正文判断的理由。

## 0. 定位：标题是判断的浓缩，不是文案的包装

墨予镜不做「爆款钩子」，做「一句话判断」。

- 读者点进来，是因为这句判断戳中了他们正在想、但还没想清的事。
- 标题必须和正文是同一句判断——标题承诺 A、正文讲 B，是发假。
- 宁可平淡但准确，不要抓眼但空泛。标题发假，读者点进来就走，还会记住你发假。

## 1. 标题 DNA（墨予镜的标题像什么样）

从已通过的正例反推，不套外来的自媒体公式。

正例：《企业上AI，第一步从来不是选工具》

它的特征，就是墨予镜标题 DNA：

1. **先给判断，不绕**——「从来不是」直接否定，不是「关于企业上AI的几点思考」。
2. **反常识但确定**——否定的是「选工具」这个大家以为的第一步，有立场但不喊。
3. **表达准确，不用大词**——没有「底层逻辑/认知升级/赋能」，用「第一步/选工具」这种具体词。
4. **短句收束**——一句话、一个判断、一个对象。
5. **不装专家**——不出现「我服务过 N 家企业」这类包装。

对照黄有璨「表达准确」：判断精准、分类清楚、配画面、每句推进——标题同样要「一句话判断」，不铺垫、不绕。

## 2. 公众号 vs 小红书：标题差异

| 维度 | 公众号 | 小红书 |
| --- | --- | --- |
| 字数 | 20-35 字，最多 64 | ≤20 字（含标点/emoji） |
| 读者关系 | 订阅者，有信任基础 | 陌生人，靠标题抢注意力 |
| 标题该给什么 | 「值得深读」的感觉 | 「快速有用」的感觉 |
| 禁忌 | 震惊体、诱导词（震惊/万万没想到/重磅/突发） | 过度夸张、虚假承诺 |
| 情感 vs 信息 | 情感共鸣是优势 | 信息刺激是优势 |

## 3. 可迭代的模式库（不是死规则）

这些模式是从墨予镜已有的判断、已通过的正例反推的，可以不断补充。每个标题要能追溯到某个模式 + 它为什么适合这篇正文的判断。不是「必须套这个句式」，是「这篇正文的判断，天然接近这个形状」。

### 模式 1：纠偏否定型

先否定大家以为的起点，再给判断。

- 形状：「[领域]上[动作]，第一步从来不是[大家以为的事]」
- 正例：《企业上AI，第一步从来不是选工具》
- 变形：
  - 「[动作]之前，先别急着[大家急着做的事]」→《对接AI服务商，先别急着比报价》
  - 「[大家在做的事]，是这件事的最晚一步」→《选工具，是上AI的最晚一步》
- 适用正文：核心判断是「大家以为的起点是错的」

### 模式 2：问题诊断型

把一句模糊的常见需求，拆出具体问题。

- 形状：「一句[大家常说的话]，藏着[几个]决定[成败]的问题」
- 例子：《一句"做个智能体"，藏着五个决定项目死活的问题》
- 适用正文：核心是把一句模糊需求，拆成几个具体问题

### 模式 3：反常识结论型

一个精准判断，短句收束。

- 形状：「[一个大家以为的东西]，不是[它其实是什么]」
- 例子：《一个工具名，不是需求》
- 适用正文：正文里有一句一针见血的判断，可以直接拿来做标题

### 模式 4：场景代入型

从一个高频真实场景切入。

- 形状：「当[具体场景发生]，[真正在发生什么]」
- 例子：《客户说"我们想做个智能体"时，他其实在说"我有一条流程很痛"》
- 适用正文：正文从一个高频真实场景切入

### 模式 5：提问踢回型（慎用）

一个直击读者的追问。

- 形状：一个直击读者的追问
- 例子：《你上一次被这条流程卡住，是什么时候？》
- 注意：公众号提问式标题通常偏弱，只有正文结尾确实把判断权踢回读者时，才用它做次选。

## 4. 工作流程

1. **判断正文类型**：先看这篇正文的核心判断是什么、接近上面哪种模式（可能跨 1-2 种）。
2. **生成 5-8 个变体**：围绕核心判断发散，不要只顺着第一个想到的写。
3. **用墨予镜标准筛选**：逐个过 §5 质量门，淘汰发假、大词、诱导、不准确的。
4. **每个标题给理由**：它追溯到哪个模式、为什么适合这篇正文的判断、命中了哪 2 项张力。
5. **收敛出 Top 3**：给真实判断，不是随便选。

## 5. 质量门（发布前逐项核查，命中即修）

| 检查项 | 标准 |
| --- | --- |
| 先给判断 | 标题是一句判断，不是「关于…的思考/浅析/几点想法」 |
| 去 AI 味 | 无「底层逻辑/认知升级/赋能/降维打击」大词；无「一文读懂/深度解析」报告腔；无「在这个 AI 时代」铺垫（见 ai-de-style.md） |
| 不装专家 | 无「我服务过 N 家企业」「我见过上百个」类包装 |
| 不发假 | 标题承诺的，正文必须兑现 |
| 平台字数 | 公众号 20-35 字；小红书 ≤20 字 |
| 平台禁忌 | 公众号无震惊体/诱导词 |
| 张力检查 | 对比 / 悬念 / 共鸣 / 数字 / 立场 / 结果承诺，至少命中 2 项 |

## 6. 常见失败模式

- 起了一堆标题，但没有一个能追溯到正文的核心判断 → 说明正文判断还不清晰，回第 2 轮结构审稿。
- 标题比正文抓眼得多 → 发假，读者点进来会走。
- 用问句当公众号主标题 → 偏弱，除非结尾确实踢回读者。
- 关键词堆砌读起来像 SEO → 违反「像人话」。
