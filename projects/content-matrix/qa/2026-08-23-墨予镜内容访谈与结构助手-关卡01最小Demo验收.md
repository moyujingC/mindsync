> 状态：ready

> Hermes Profile ID：`myjcontentagent`
> 输入与输出合同：[岗位卡](../agent-workflow/moyujing-content-interviewer/README.md)

## 目标

验证这个 Agent 能接收一张脱敏主题卡，通过提问与选项确认观点和结构，并在聊天中交付可人工审阅的草稿。它不需要下载素材、写文件或调用工具；这些动作不属于本岗位。

## 运行前条件

- [x] 独立 Hermes Profile 已存在，SOUL 已部署，`cli` 和 `feishu` 均为零工具。
- [ ] Profile 已配置独立模型凭证或独立授权。
- [ ] 独立飞书应用机器人已创建，且仅白名单私聊。
- [ ] Gateway 已在不影响既有服务的前提下启动。

未满足后三项时，可先在 Hermes CLI 做同一份无工具 Demo；结果必须标记为“本地演练”。

## 输入卡

```yaml
topic: 企业上 AI，第一步为什么不该从选工具开始
reader: 正在考虑上 AI 的中小企业负责人或业务负责人
confirmed_evidence:
  - 公开案例与已有研究反复出现：工具名不能替代流程定义
  - 已有成稿中的核心判断：先看清一条真实的业务流程
author_input_needed:
  - 你最想让读者放下的一个误区是什么？
  - 你愿意公开讲的观察或经历有哪些？
goal_action: 评论或留下一个具体流程问题
do_not_claim:
  - 未发生的客户项目、量化效果、收入增长、自动化发布能力
```

## 验收点

- [ ] Agent 对不清楚的观点给出问题和 2-3 个可选判断；创作者明确确认后，复述为已确认写作依据。
- [ ] 输出包含“已确认写作依据 + 草稿 v1 + 审阅问题”，并产出完整草稿。
- [ ] 未经明确确认的判断不写成第一人称；不把推断写成个人经历或客户成果。
- [ ] 人工指出草稿问题后，Agent 能先澄清意思或观点，再输出修订稿 v2。
- [ ] 不要求、不重复敏感资料；对含敏感资料的输入提示先脱敏。
- [ ] 工具调用数为 0；不写入飞书、文件、公众号或任务系统。
- [ ] 保存输出文本或截图，并填写下表。
