# 内容视觉工坊 A+B 验收基线

## 1. 验收对象

验收对象是“文章成稿 -> 配图生成 -> 公众号草稿”的第一版闭环。

## 2. 必过主链路

### 用例 1：标准文章生成草稿

输入：

- 标题 1 条
- 正文 800-2000 字
- 开启知识卡片
- 开启公众号封面

期望：

1. 成功生成卡片方案
2. 成功生成至少 1 张知识卡片
3. 成功生成 1 张公众号封面
4. 成功生成公众号正文排版结果
5. 成功写入公众号草稿箱

### 用例 2：只做排版不做卡片

输入：

- 标题 1 条
- 正文 500-1500 字
- 关闭知识卡片
- 开启公众号封面

期望：

1. 不生成卡片
2. 仍能生成封面
3. 仍能生成正文排版
4. 仍能成功写入草稿

### 用例 3：单张图片重生成

前置条件：

- 已生成 3 张以上知识卡片

期望：

1. 可仅重做其中 1 张
2. 其他图片不被覆盖
3. 草稿再次同步后内容更新正确

## 3. 边界情况

### 边界 1：长文

- 输入正文超过 3000 字
- 系统应提示建议拆图更多，或在能力边界内继续生成
- 不能直接无响应

### 边界 2：空标题或空正文

- 应阻止生成
- 应给明确错误提示

### 边界 3：图片接口失败

- 应标记失败状态
- 应允许重试
- 不应导致整个页面卡死

### 边界 4：公众号草稿同步失败

- 应给出失败原因或错误状态
- 已生成图片和排版结果应保留

## 4. 验收标准

### 4.1 功能标准

- 能生成图片
- 能生成排版
- 能写入草稿
- 能查看同步状态
- 能单张重生成

### 4.2 体验标准

- 用户能理解当前处于哪一步
- 失败状态有明确反馈
- 主操作按钮数量受控
- 工作台不要求用户理解底层提示词

### 4.3 内容标准

- 卡片标题与文章主旨一致
- 封面不偏题
- 正文排版层级清楚
- 图片插入位置合理

## 5. 不通过条件

出现以下任一情况，则当前版本不得进入正式使用：

1. 图片能生成，但无法创建公众号草稿
2. 草稿能创建，但正文结构明显错乱
3. 单张重生成会覆盖其他图片
4. 任一步失败后用户无法恢复

## 6. 人工验证方式

每次验收至少做：

1. 真实文章试跑 2 篇
2. 不同长度文章各 1 篇
3. 公众号后台草稿实际打开检查
4. 图片与正文对应关系人工复核

## 7. 后续自动化切入点

后续可补自动化验证：

- 内容编排结构快照测试
- 草稿 payload 结构测试
- 图片任务状态机测试
- 前端关键路径 E2E（端到端）测试
