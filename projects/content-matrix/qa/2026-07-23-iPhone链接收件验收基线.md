# iPhone 链接收件验收基线

## 自动化测试

- 收件 API 只接受正确的 Bearer Token、JSON 请求和受支持平台链接。
- 请求在短链解析后入本地队列；同一原始或最终链接幂等返回同一收件 ID。
- 无 Token、错误 Token、非平台 URL、超长请求体和超限请求不会创建记录。
- 博主页和未识别链接进入“需人工处理”，不会触发详情采集。
- Worker 成功时调用详情研究 Workflow、保存研究请求 ID 并改为“已完成”。
- Worker 失败时改为“失败”；显式重试后可再次领取。
- 飞书字段映射、Lark CLI 字段顺序和文档中的 npm 命令持续有效。

## 真实联调

- 在有效 HTTPS 域名上用 iPhone 快捷指令提交一条脱敏或公开测试链接。
- 飞书“链接收件箱”可看到原始链接、最终链接、来源、状态和处理结果。
- Worker 运行后，既有“内容更新”“评论样本”“研究请求”表可读回相应记录。
- 飞书群机器人已配置时收到收件与完成/失败提示；未配置时主链路不受影响。
- 转写或成稿只在人工确认和合法媒体输入后执行，不因收件自动触发。
