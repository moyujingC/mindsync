# TikHub 真实响应合同校验实施计划

## 目标

让真实响应捕获后的验收可重复执行：自动发现脱敏遗漏、失败响应和平台接口覆盖缺口，再交给人工复核字段语义。

## 实施

1. 只读扫描脱敏合同样本目录。
2. 校验捕获结构、HTTP/业务成功状态、敏感字段和 URL 查询参数。
3. 按平台检查详情、搜索、账号列表和评论四类成功样本覆盖。
4. 输出缺失类型与无效文件；不调用 TikHub、不写飞书或台账。

## 验收

- 完整脱敏样本覆盖通过。
- 脱敏遗漏或缺失接口类型被明确报告，且无效样本不计入覆盖。
- 完整 `npm test` 通过。
