# 微信搜索真实联调实施计划

## 目标

验证公众号和视频号的 TikHub 关键词搜索，修正与官方 OpenAPI 不一致的调用合同，并将可标准化的搜索样本受控写入飞书。

## 实施

1. 使用官方 OpenAPI 确认微信搜索端点、HTTP 方法和请求体。
2. 以 `--dry-run --no-comments --limit 1` 依次探测公众号和视频号，不写飞书或本地台账。
3. 适配公众号 `results.data[].items[]` 与视频号 `results.data[].subBoxes[].items[]` 的嵌套结果、内容 ID、来源名称、时间、点赞数和分页游标。
4. 在飞书写入边界映射公众号“文章”为已有的“图文”单选项。
5. 每个平台各执行一条受控写入，并只读复核内容和研究请求；搜索结果不含可追踪账号 ID 时不创建博主账号。

## 验收

- 两个平台按官方合同成功返回真实搜索响应，且 dry-run 无写入。
- 真实嵌套结果可转为稳定内容唯一键和待审核候选。
- 内容和研究请求可写入并在飞书只读复核。
- 不把搜索来源名称、无评论样本或候选假设误作账号、需求或业务结论。
- 完整 `npm test` 与 `git diff --check` 通过。
