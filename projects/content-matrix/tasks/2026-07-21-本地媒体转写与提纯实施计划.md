# 本地媒体转写与提纯实施计划

## 目标

让合法取得的本地音频和视频可独立进入媒体提纯组件，不依赖 TikHub 或任何内容平台。

## 实施方式

1. `media:transcribe` 使用本地 `ffmpeg`（媒体处理工具）抽取标准 WAV 音频，再调用本地 Whisper（语音转文字工具）生成 SRT 字幕。
2. `media:refine` 继续只处理字幕和逐字稿，保留原始文本并输出清理稿。
3. `media:process` 串联转写与提纯，输出可填入手工研究 `refinedTextPath` 的本地清理稿。
4. 每一步写入本地 manifest（运行清单），记录输入、产物、模型和命令类型；不写飞书、不下载媒体、不上传媒体或逐字稿。

## 验收

- 音频、视频和文本输入有明确的支持范围与错误提示。
- 转写命令以参数数组调用，测试可替换执行器，不拼接 shell 字符串。
- 产物包含原媒体、抽取音频、字幕、原始字幕和清理稿的可追溯路径。
- 单元测试覆盖转写、失败处理和一键串联；完整 `npm test` 通过。
