# 内容反馈到服务验证交接实施计划

## 目标

让真实内容反馈进入 AI 服务样本沟通台账时，仍能回到来源研究候选和发布链接，同时避免复制不必要的公开评论或私信正文。

## 实施方式

1. 解析反馈模板中的研究候选 ID、发布链接、真实问题、资料样本意愿和反对意见。
2. 转存备注保留候选 ID、链接、服务信号和最多 120 字反对意见摘要。
3. 新反馈用候选 ID 去重；没有候选 ID 的历史反馈继续用“日期 + 对象”去重。
4. 不改写客户阶段、报价、成交或样本沟通状态；这些仍由人工决定。

## 验收

- 新反馈可从服务台账回到来源研究候选。
- 同一候选不会重复转存。
- 历史无候选 ID 的反馈仍不重复写入。
- 不复制评论/私信全文。
