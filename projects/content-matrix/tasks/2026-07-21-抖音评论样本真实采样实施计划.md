# 抖音评论样本真实采样实施计划

## 目标

验证一条有公开评论的抖音内容的评论字段、首页分页游标、标准化、去重与受控研究写入。

## 实施

1. 用最小关键词搜索找到评论数大于 0 的公开视频。
2. 先以评论接口 dry-run 读取第一页，确认评论数组、唯一键和游标。
3. 以详情加评论 Workflow 执行一次受控研究写入，最多采 20 条一级评论。
4. 捕获轻量脱敏评论合同，并用真实合同测试覆盖包装和分页。
5. 只读复核飞书记录；若当前 CLI 不稳定，保留台账证据并将飞书复核列为待办。

## 验收

- 真实评论接口返回非空评论数组和下一页游标。
- 评论标准化产生稳定唯一键，研究候选因多条评论提升到“观察”。
- 本地台账和去重库记录内容与评论样本。
- 飞书读回必须有独立证据，不能用写入请求或本地台账代替。
