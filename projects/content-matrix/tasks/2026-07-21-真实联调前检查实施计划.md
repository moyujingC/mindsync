# 真实联调前检查实施计划

## 目标

在运行 TikHub 写入模式前，一次检查账号 Key、飞书配置、已有真实闭环记录和可选的最小接口探针，避免靠零散文档判断运行条件。

## 实施方式

1. 默认读取环境变量、飞书配置和研究台账，不写入任何文件或远程服务。
2. 输出阻断项、警告项、研究请求数、已发布候选数和已验证候选数。
3. 只有显式 `--probe` 才调用 TikHub 详情接口，且必须提供平台和公开链接。
4. 探针失败（例如 402）作为阻断项返回；不调用采集、飞书写入或去重存储。

## 验收

- 缺少 Key 时阻断。
- 完整飞书配置与已有发布反馈可通过本地检查。
- 402 探针失败不改写研究台账。
