# TikHub 真实响应合同捕获实施计划

## 目标

在 TikHub 权限恢复后，用可复跑、脱敏的方式保存真实接口合同样本，避免将真实联调与飞书写入或用户数据混在一起。

## 实施

1. 给 `TikHubClient` 增加响应观察钩子，不改变正常采集返回值。
2. `capture:tikhub-contract` 固定以 `dry-run` 调用采集流程。
3. 保存请求路径、方法、已脱敏参数和已脱敏响应；不保存授权、Cookie、用户标识、正文/评论或 URL 查询参数。
4. 权限恢复后，对四个平台分别捕获详情、搜索、账号列表、评论列表，并人工复核字段与分页。

## 验收

- 捕获文件不包含敏感字段或 URL 查询参数。
- 捕获过程不写飞书、研究台账或本地去重库。
- 完整 `npm test` 通过。
