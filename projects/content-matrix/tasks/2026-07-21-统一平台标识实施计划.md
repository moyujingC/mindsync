# 统一平台标识实施计划

## 目标

让手工内容研究、TikHub 采集、研究请求台账和飞书展示使用同一份平台合同，避免同一内容因中文平台名和内部平台 ID 不同而重复入库。

## 实施方式

1. 允许输入 `小红书`、`抖音`、`公众号`、`视频号` 或 TikHub 内部 ID。
2. 内容唯一键、评论键、研究请求台账和 TikHub 调用统一使用内部 ID。
3. 飞书仍写入中文展示名称。
4. 去重同时识别新内部 ID 唯一键和历史中文唯一键。
5. 不支持 B 站等已移出系统的平台，输入时明确拒绝。

## 验收

- 中文输入可规范化为内部 ID。
- 飞书平台字段保持中文。
- 历史中文唯一键不会被重新导入。
- 手工和 TikHub 路径保持一致的内容唯一键。
