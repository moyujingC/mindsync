# 小红书四类真实合同联调实施计划

## 目标

利用已有真实小红书样本，补齐搜索、详情、账号列表、评论四类 TikHub 响应合同，验证分页字段和脱敏边界。

## 实施

1. 从本地已入库的真实笔记中读取笔记 ID，不向飞书写入或重新创建研究请求。
2. 执行详情和评论 dry-run；从详情响应取得账号标识后，再执行账号列表 dry-run。
3. 适配详情 `data.data[0].note_list[0]`、评论 `data.comments[]`、账号列表 `data.notes[]` 与首项 `cursor`。
4. 将 `userid` 纳入脱敏规则，防止真实小红书账号标识进入版本库。
5. 捕获四类响应到真实合同目录并运行覆盖校验。

## 验收

- 四类请求均返回 HTTP 200 和业务 `code: 200`。
- 详情、评论、账号列表均可得到内容或分页元数据。
- 真实合同不含凭据、用户 ID、昵称、正文、评论正文和 URL 查询参数。
- 合同覆盖校验和完整自动化回归通过。
