# 手工内容研究入口实施计划

## 目标

在 TikHub 额度或接口受限时，仍能把随机发现的公开内容和人工评论样本接入同一研究、飞书、人工确认与内容交接链路。

## 实施方式

1. 复用 `manual-import` 的内容标准化、唯一键、飞书内容表写入和去重。
2. 增加可选的手工评论格式；只有显式启用评论时才解析和写入评论表。
3. 以 `manual-research` 作为研究来源，调用次数固定为 0，不冒充 TikHub 数据。
4. 复用研究模板、台账、飞书“研究请求”表、确认和交接 Workflow。
5. 同一请求 ID 重跑时跳过内容/评论写入，只重试研究请求的飞书同步。
6. 可选读取 `refinedTextPath` 指向的本地媒体清理稿，作为洞察输入；台账和简报只保存路径、字符数和有限片段，飞书不保存逐字稿正文。

## 不做

- 不解析私密链接、绕过平台权限或伪造评论来源。
- 不自动判断手工摘录的真实性。
- 不将客户非公开材料或可识别个人信息写入内容系统。
