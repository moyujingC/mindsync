# 抖音真实联调与无评论降级实施计划

## 目标

验证 TikHub 抖音关键词搜索和飞书写入，确认真实响应字段。评论接口未确认时，研究请求必须能明确降级为仅采集博主和内容，且不输出评论需求结论。

## 实施

1. 用关键词“企业 AI 工作流”执行一次限制为 1 条的真实 `dry-run`，不采集评论。
2. 兼容真实搜索卡片数组与 `aweme_info` 视频包装；写入前删除链接查询参数。
3. 记录默认评论端点的 HTTP 405，不猜测替代端点；新增 `--no-comments` 覆盖模板默认评论采集。
4. 用固定请求 ID 执行一次受控写入，只读复核飞书博主、内容和研究请求表。

## 验收

- 抖音真实搜索返回内容，且 `dry-run` 不写本地台账、简报或飞书。
- 无评论模式可覆盖模板默认值，返回的候选只标为线索和假设。
- 受控写入后，博主、内容和研究请求表均可按稳定 ID 复核。
- 完整 `npm test` 与 `git diff --check` 通过。
