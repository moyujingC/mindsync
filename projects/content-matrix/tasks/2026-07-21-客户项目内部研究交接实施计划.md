# 客户项目内部研究交接实施计划

## 目标

让客户项目调研与内容账号的公开草稿流程保持隔离，避免将内部样本包误转为公开内容或客户承诺。

## 实施

1. 识别 `client_project` 研究模板。
2. 已转选题候选只输出内部研究包：样本证据、待确认问题和交接边界。
3. 不生成草稿种子，阻断 `promote:draft` 的后续路径。
4. 明确客户项目不自动发布、报价、联系客户或上传非公开材料。

## 验收

- 客户模板的交接结果包含内部研究包路径，草稿种子路径为 `null`。
- 内容账号模板保持已有的简报与草稿种子交接。
- 完整 `npm test` 通过。
