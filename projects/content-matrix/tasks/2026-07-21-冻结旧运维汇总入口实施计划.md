# 冻结旧运维汇总入口实施计划

## 目标

阻止旧的日更追踪、周复盘和连续运行审计被误用为当前研究请求主路径或 Agent Loop。

## 实施方式

1. 移除带固定历史日期的 `weekly:review` npm 默认脚本。
2. 历史周汇总 CLI 必须显式传入 `--historical-summary`、开始日期和结束日期。
3. 输出改名为“历史运行汇总”，并声明不生成下一轮研究、选题或服务决策。
4. README 和组件化方案明确 `daily-summary`、`ops-audit`、`weekly-review` 的冻结语义。

## 不做

- 不删除历史汇总代码和运行记录。
- 不在没有 3-5 轮真实闭环前实现每周 Agent Loop。
