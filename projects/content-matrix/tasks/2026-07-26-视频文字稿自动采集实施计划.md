# 视频文字稿自动采集实施计划

> 状态：completed
> 日期：2026-07-26
> 范围：`tools/influencer-tracker` 链接收件箱

## 目标

对通过链接收件箱采到的公开视频，生成可追溯的本地文字稿，使后续洞察和选题能引用视频原话，而不只依赖标题和评论。

## 处理合同

```text
TikHub 内容详情
-> 查找平台返回的字幕文本或字幕地址
-> 有字幕：保留原字幕并清理为文字稿
-> 无字幕：下载该详情返回的临时播放地址
-> ffmpeg 抽音频 -> Whisper 转写 -> 清理文字稿
-> 本地保存产物路径，研究简报引用文字稿
```

- 字幕来源优先级高于语音转写。
- 原视频、字幕、原始转写稿和清理稿保存在服务器 `logs/media-evidence/`，飞书不保存全文。
- 单个媒体下载上限 300 MB；只接受 TikHub 返回的 HTTPS 地址。
- 转写失败只标记该视频文字稿失败，内容、评论和研究简报仍完成，人工可后续重试。

## 验收

1. 有字幕的 fixture 不触发下载或 Whisper，清理稿可读取。
2. 无字幕的 fixture 下载视频并进入转写步骤。
3. 媒体地址缺失或转写失败时，研究采集不被阻断且错误可定位。
4. 服务器安装 `ffmpeg` 与 Whisper 后，用一条真实公开视频检查产物和飞书“处理结果”。
