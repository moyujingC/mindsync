# 内容方法验证实验闭环实施计划

## 验收目标

在“社交媒体内容研究验证台”中建立独立的“内容实验与反馈”表。人工可以在发布前登记一条实验，发布后补数据和结论；系统可按实验状态和选题来源查看，不自动判定转化。

## 实施步骤

1. 在代码中定义实验表 schema（字段合同）和两个筛选视图。
2. 实现 `experiment:setup` 命令：仅创建或复用该表，并将表 ID 写回忽略的本地飞书配置。
3. 实现 `experiment:record` 命令：从人工 JSON 输入创建或更新同一实验 ID。
4. 用模拟客户端验证字段映射、去重和视图配置；再创建真实空表验证飞书权限。
5. 发布第一篇实验内容后，再进行真实发布反馈填写；不使用模拟数据得出内容方法结论。

## QA 基线

- 重复运行初始化不创建第二张同名表。
- 缺少实验 ID、选题来源或目标动作时拒绝写入。
- 缺少发布链接时允许保留“待发布”，但不能标记“已发布待复盘”。
- 更新同一实验 ID 必须回写原 `record_id`，不得新增副本。
- 模拟数据只验证流程，不进入方法有效性的统计或结论。
