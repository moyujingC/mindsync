# 抖音四类真实合同联调实现记录

此前抖音搜索已可用，但账号列表和评论误用了 POST 与通用字段，因此评论返回 HTTP 405。TikHub OpenAPI 的正确合同是 GET：账号列表使用 `sec_user_id` 与 `max_cursor`，评论使用 `aweme_id` 与 `cursor`，首次请求必须显式传 `0`。

客户端已改为这些参数，并为首页游标增加回归测试。真实联调中，详情可得到内容和博主标识，账号列表返回 11 条视频并带游标，评论端点返回成功。该视频没有公开评论，响应 `total: 0`；系统没有把空结果写作评论需求证据。

四类合同位于 `fixtures/tikhub-contracts/real/`，使用统一轻量脱敏策略：保留接口包装、列表、游标与分页字段，去除账号/视频标识、标题、正文、评论、媒体与深层附带对象。评论字段的真实结构仍需从有公开评论的视频取得。
