# 本地媒体转写与提纯实现记录

## 实现方式

1. `media:transcribe` 只接受本地音频/视频路径，以参数数组调用 `ffmpeg` 抽取 16 kHz 单声道 WAV，再调用 Whisper 生成 SRT 字幕。
2. 每次转写写入 `transcribe-media-manifest.json`，失败时也保留失败原因；运行产物只在本地目录。
3. `media:process` 将输出字幕交给既有 `media:refine`，生成原始字幕副本、清理稿和第二份运行清单。
4. 研究仍只通过 `refinedTextPath` 引用清理稿；不下载平台媒体、不上传媒体、不写飞书正文。

## 验证

- 单元测试覆盖转写参数、字幕产物、失败运行清单、文本提纯串联和 URL 拒绝。
- 在本机以 1 秒静音 WAV 执行 `npm run media:process -- --input <local.wav> --output-dir <tmp> --model base --language zh`，成功产出 WAV、SRT、原始 SRT、清理稿和两份 manifest。
- 完整 `npm test` 结果记录在对应验收文档。
