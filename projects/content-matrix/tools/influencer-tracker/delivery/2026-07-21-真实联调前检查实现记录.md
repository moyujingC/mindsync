# 真实联调前检查实现记录

## 实现方式

1. 新增 `preflight:readiness`，默认只读环境变量、可选飞书配置和研究台账。
2. 输出 TikHub Key、飞书配置、研究请求数、已发布候选数、已验证候选数、阻断项和警告项。
3. 只有显式 `--probe` 才调用 TikHub 一条公开详情链接；探针不调用采集、飞书写入或本地去重存储。
4. 缺少 Key、飞书配置不合法或探针失败均会阻止写入模式。

## 验证

- 缺少 Key 的实际只读运行返回阻断项，未写入项目文件。
- 专项测试覆盖 Key、飞书/台账就绪与 402 无写入边界。
- 完整回归：`npm test`，112 passed。
