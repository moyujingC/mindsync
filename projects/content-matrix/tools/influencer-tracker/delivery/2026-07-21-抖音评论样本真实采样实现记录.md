# 抖音评论样本真实采样实现记录

使用关键词搜索找到公开评论数较高的抖音视频后，正确的 GET 评论接口返回了真实评论。第一页响应含 21 条评论、下一页游标 `20` 和 `has_more: true`；研究 Workflow 按 `comment-limit 20` 采样 20 条，并生成稳定评论唯一键。

受控研究请求 `research-2026-07-21-douyin-comments-sample-001` 已写入本地研究台账、简报和内容去重库。候选由于评论数量达到观察阈值，状态为“观察 / 假设 / 待人工审核”。轻量合同仅保留一条被脱敏的评论、分页和游标；短 ID、唯一名、头像、媒体 URI、评论正文和视频 ID 都会被替换。

后续使用飞书 CLI 按唯一键和请求 ID 精确筛选，只读读回了 20 条评论和 1 条研究请求；研究请求状态为“待人工确认”，内容样本数为 1，评论样本数为 20。内容表读回同一内容唯一键的 2 条记录，确认存在 1 条历史重复。

重复原因是旧版飞书去重依赖全表读取，读取不稳定时未能识别已存在记录。客户端现已支持字段投影和精确筛选，采集前会逐键检查内容和评论，研究请求同步也按请求 ID 精确查询。历史重复记录没有自动删除，等待人工确认，避免误删人工编辑过的数据。
