# 微信详情账号评论合同校正实现记录

公众号和视频号的搜索接口已经真实联调，但详情、账号和评论此前仍使用通用参数。TikHub OpenAPI 指定了不同的正式输入：公众号使用文章链接和 `gh_username`；视频号使用短链接、数字 `object_id`、短期 `export_id` 和 `finder username`。

客户端现将公众号详情、账号列表和评论改为对应的 POST 请求体；视频号详情只接收短链接或数字对象 ID，视频号评论只接收数字对象 ID。统一评论 Workflow 会把标准化内容链接传给客户端，因此拥有有效公众号文章链接的详情采集能够沿用同一入口。

缺少正式输入时，客户端在发起网络调用前直接报出可操作错误。搜索页的来源显示名、视频号非数字 `docID` 不会被当成账号 ID 或评论对象。本阶段未消耗真实接口额度；真实响应验收仍需有效的页面链接或账号标识。
