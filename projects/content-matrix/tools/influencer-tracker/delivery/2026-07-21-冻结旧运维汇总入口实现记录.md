# 冻结旧运维汇总入口实现记录

## 实现方式

1. 删除带固定历史日期的 `weekly:review` npm 默认入口。
2. 周汇总 CLI 要求 `--historical-summary` 和明确日期范围，否则拒绝运行。
3. 输出标题改为“历史运行汇总”，明确只汇总既有文件，不产生下一轮研究、选题或服务决策。
4. README、组件化方案和测试同步声明：旧日常/周报/运维审计不是 Agent Loop。

- CLI 专项测试覆盖未声明历史模式时的拒绝行为。
- 显式历史汇总命令可生成汇总文件。
