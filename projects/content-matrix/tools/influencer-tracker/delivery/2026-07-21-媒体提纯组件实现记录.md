# 媒体提纯组件实现记录

## 实现目标

将媒体提纯从采集器中拆出，避免字幕、转写和原文整理依赖特定平台或账号追踪逻辑。

## 新增能力

- `refine-media` Workflow 接收 `.srt`、`.vtt` 或 `.txt`。
- 原始文本复制为 `.original` 文件，保证原文可追溯。
- 清理字幕编号、时间轴、空行和冗余空白，输出 `.refined.txt`。
- 生成 `refine-media-manifest.json`，记录输入、输出、来源标签和字符数。
- 手工研究 JSON 可用 `refinedTextPath` 引用清理稿；研究候选会保留本地路径、字符数和有限原文片段，辅助人工审核。

## 使用边界

- 本组件不下载视频、不转码、不调用语音识别服务。
- 后续任意下载或语音转写能力只需产出字幕或逐字稿文本，即可接入本组件。
- 清理只处理结构噪声，不摘要、不改写原意、不新增事实。
- 飞书只接收标准化内容、评论和研究请求摘要，不接收逐字稿正文。

## 验证

- 专项测试覆盖 SRT 清理、原文保留、manifest 输出、不支持格式拒绝、清理稿参与候选生成，以及飞书不写入稿件正文。
- 通过 `npm run media:refine -- --input <字幕或逐字稿>` 可独立运行。
