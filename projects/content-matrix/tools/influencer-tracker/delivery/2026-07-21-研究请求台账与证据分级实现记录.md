# 研究请求台账与证据分级实现记录

## 实现方式

1. 新增 `src/storage/research-request-store.mjs`，把每次请求、采集摘要、候选、状态、人工决定和简报路径写到 `logs/research-requests.json`。
2. 更新 `src/jobs/research-request.mjs`：候选产生时保存`证据等级`和`结论等级`；内容样本为线索，两条以上相关评论为观察，自动洞察一律是假设。
3. 新增 `src/cli/confirm-research-request.mjs` 和 `npm run research:confirm`。该命令支持转选题、已发布、结束和验证；验证必须附带人工证据。
4. 人工确认后重写原研究简报，避免 JSON 台账与 Markdown 简报状态不一致。

## 验证

- `node --test tests/research-request.test.mjs`：5 passed。
- `npm test`：76 passed。

## 边界

该实现没有触发草稿生成、发布、私信或服务成交。飞书“研究请求”表和真实 TikHub 调用待后续阶段处理。
