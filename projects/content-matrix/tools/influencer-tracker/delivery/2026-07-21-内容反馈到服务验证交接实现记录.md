# 内容反馈到服务验证交接实现记录

## 实现方式

1. `promote:feedback` 读取研究候选 ID、发布链接、真实问题、资料样本意愿和反对意见。
2. 写入 AI 服务样本沟通记录时，备注保留最小引用链：候选 ID、链接、服务信号和最多 120 字反对意见摘要。
3. 新反馈按候选 ID 去重；历史反馈缺少候选 ID 时，回退到记录日期和对象去重。
4. 不复制评论/私信全文，不自动修改客户阶段、报价、成交或沟通状态。

## 验证

- 专项测试覆盖引用链、新去重、历史兼容与反对意见摘要。
- 完整回归：`npm test`，108 passed。
