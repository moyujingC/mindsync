# 飞书研究请求台账实现记录

## 实现方式

1. 在已有飞书多维表格中创建“研究请求”表，字段合同与本地 `research-requests.json` 对齐：请求 ID、目标、采集范围、样本与调用量、状态、下一步、简报路径和时间。
2. `research:run --feishu` 在完成本地台账写入后，按请求 ID 创建或更新飞书记录；同一请求 ID 重跑不会再次调用 TikHub。
3. `research:confirm --feishu` 在人工转选题、发布、结束或验证后同步更新同一条飞书记录。
4. 飞书不存候选详情、评论原文或 API 原始响应；研究简报路径仅接受项目内相对路径，避免写入本机临时目录和绝对路径。
