# 多业务研究模板实现记录

## 实现方式

1. 添加四类业务模板：`enterprise_ai_service`、`moyujing`、`yijing_yishu`、`client_project`。
2. 模板不调用外部服务，只在研究请求开始前合并默认参数与约束；命令行显式参数优先。
3. 研究简报和 JSON 台账记录模板名称、项目代号、交付重点、后续工作流建议和约束。
4. 客户项目强制内部项目代号；一镜一梳强制把匿名、非诊断边界写入简报。

## 验证

- 模板与研究请求相关测试：12 passed。
- 全量测试：`npm test`，92 passed。

## 边界

模板不改变 TikHub 采集器、飞书表结构或人工审核规则。真实 TikHub 额度、发布反馈和客户交付仍需后续验证。
