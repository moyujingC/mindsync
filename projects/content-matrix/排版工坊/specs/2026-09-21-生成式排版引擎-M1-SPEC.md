# 生成式排版引擎 M1 SPEC

> 状态：current
> 版本：0.1.0
> last_updated：2026-09-21
> 项目：排版工坊（内部版）
> 阶段：M1 最小可用

## 要解决的问题

确定性骨架法复刻 HiStyle 风格只能到 70 分（见 teardown 复盘）。M1 改用生成式路线：风格 = 样章参考 + 风格描述，渲染 = LLM 把文章内容装配为组件化 HTML。该路线同时是未来开源版的内核。

## 管线

```
成稿.md + 风格（样章 HTML + 元数据）
  → 构建风格上下文（style-context）
  → LLM 装配（prompts/layout-v1.md，自研）
  → 抽取 HTML（去代码围栏）
  → juice 内联 → <成稿名>-公众号成品.html
  → playwright 截图（QA 用）
```

## 硬边界（Hard Boundaries）

1. **逐字保留原文**：不改写、不增删段落（标准版模式；灵动版以后另设开关，默认关）
2. **微信合规**：输出不得依赖 <script>/<iframe>/<form>/class+外部样式；允许一个 <style> 块由程序内联；图片只用占位路径（上传由 publish-draft.mjs 负责）
3. **输出契约**：只输出 HTML 片段（可含 <style>），外层 <div id="article-root">；正文阅读宽度内排版
4. Key 只从 .env 读，不入 git、不打印

## 异常路径

| 异常 | 处理 |
| --- | --- |
| LLM 返回非 HTML / 缺 article-root | 报错退出，保留原始响应到 *.raw.txt 供排查 |
| 响应被截断（未闭合标签） | 检测后重试一次（temperature 0），再失败则报错 |
| key/网络错误 | 原样抛出，不吞错 |

## 验收（M1 出口）

1. FDE 成稿 × 1 套风格端到端出成品 HTML + 截图
2. 原文逐字校验：成品内正文与成稿 md 文本一致（程序 diff，不靠肉眼）
3. juice 内联后无 class 依赖残留（成品在禁用样式表环境下渲染不塌）
