这里存放 AI 副业相关案例的原始输入和分析记录。

## 建档方式

每个案例使用一个独立目录，建议命名为：

`YYYY-MM-DD-案例主题/`

目录内按需要包含：

- `原文.md` 或 `OCR原文.md`：链接、粘贴文本、截图转录或聊天记录全文。
- `分析.md`：从原文中提取的事实、假设、待核验项和初步判断。
- `素材/`：仅保存有权使用且确有必要的截图、附件或公开材料。

## 分析最低字段

`分析.md` 至少回答：

1. 案例来源和可核验程度如何？
2. 面向谁收费，解决什么问题？
3. 对方卖的是什么，如何交付？
4. AI 和自动化分别参与哪些环节？
5. 有哪些收入、成本或耗时证据？哪些只是说法？
6. 涉及哪些平台、数据、版权或合规风险？
7. 是否值得继续研究；下一步要核验什么？

未经核验的案例收入、规模和结果，统一标记为“案例声称”，不得写成项目已确认事实。
