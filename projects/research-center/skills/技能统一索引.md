## 3. 按问题查找

### 3.1 任务刚进来，不知道该给谁

- 用 `task-routing`

### 3.2 不确定当前能不能进入下一阶段

- 用 `artifact-readiness-check`

### 3.3 已经有结论，但不知道怎么交给下一角色

- 用 `handoff-packaging`
- 如果上游是研究结论，也可用 `insight-handoff`

### 3.4 研究还没收束成正式任务

- 用 `research-brief`

### 3.5 研究做完了，想入库

- 用 `knowledge-ingest`

### 3.5A 研究材料很多，但还没形成综合结论

- 用 `research-synthesis`

### 3.6 需要做产品定义

- 用 `product-framing-spec`

### 3.7 需要做商业判断

- 用 `business-diagnosis`

### 3.8 需要进入架构定义

- 用 `architecture-boundary-plan`

### 3.9 需要做验收或质量门

- 用 `qa-gate-review`

### 3.10 需要把真实素材转成内容输入

- 用 `content-grounded-transform`

## 4. 后续自动发现建议

如果后续要做轻量自动发现，建议优先读取：

1. 本索引文档
2. `skills/*/SKILL.md` frontmatter
3. `技能清单与角色映射.md`

自动发现时至少应支持：

- 按角色筛选
- 按关键词筛选
- 按工作流阶段筛选
