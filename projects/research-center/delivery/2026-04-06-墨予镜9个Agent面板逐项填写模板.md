> 阶段：delivery

每个 agent 都按下面这些字段填写：

- `Title`
- `Reports to`
- `Capabilities`
- `Agent instructions file`
- `Timeout`
- `Heartbeat on interval`
- `Max concurrent runs`
- `Can create new agents`
- `Can assign tasks`

## 1. 统一填写规则

- 非 CEO：
  - `Reports to = CEO`
- 第一轮：
  - `Heartbeat on interval = 关`
- 全部：
  - `Max concurrent runs = 1`
- 只有 CEO：
  - `Can create new agents = 开`
  - `Can assign tasks = 开`
- 其他全部：
  - `Can create new agents = 关`
  - `Can assign tasks = 关`
