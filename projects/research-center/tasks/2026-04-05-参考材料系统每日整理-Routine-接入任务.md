这份任务文档用于收束“每日整理 routine”第一版接入。

## 1. 本轮目标

把“每天自动整理知识库和偏好记忆”从概念推进到可执行接入准备。

## 2. 本轮范围

本轮要完成：

1. 起草 `knowledge-relink-maintenance` skill
2. 起草 routine spec
3. 明确报告落位
4. 明确接入 Paperclip routine 时的建议参数

本轮不要求完成：

1. 真实 routine 创建
2. 自动改写全部知识文件
3. 自动关闭或删除条目

## 3. 接入步骤

1. 确认 `Research & Knowledge Lead` 作为 assignee。
2. 确认 `研究中心` 作为 project。
3. 按 spec 创建 routine。
4. 增加一个 `schedule` trigger。
5. 首次以手动 run 方式试跑。
6. 观察一轮 maintenance report 后，再决定是否正式启用每日调度。

## 4. 推荐参数

- status：`paused`
- priority：`medium`
- concurrencyPolicy：`coalesce_if_active`
- catchUpPolicy：`skip_missed`
- timezone：`Asia/Shanghai`

建议先以 `paused` 创建，先做一次手动 run 验证。

## 5. 输出物

接入完成后应至少能稳定产出：

- 每日 maintenance report
- 待人工确认事项清单

## 6. 完成标准

本任务达标的最小标准：

1. 相关 skill 与 spec 已齐备。
2. routine 创建参数已经明确。
3. 首次试跑方式已经明确。
4. 自动与人工边界已经写清。
