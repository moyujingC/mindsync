这份任务文档用于收束“参考材料摄取与偏好记忆系统”的第一版最小实现。

目标不是一次性把所有自动化全部接完，而是先跑通：

- 正式文档入口
- 偏好记忆骨架
- review 反馈可入记忆
- 后续 skill 有默认读取入口

## 1. 本轮范围

本轮要完成：

1. 补系统设计 spec。
2. 建立 `preference-memory/` 目录与初始文件。
3. 定义 `review-patterns.yaml` 的最小字段。
4. 为后续 skill 接入预留读取约定。

本轮不要求完成：

1. 全自动抓取外部平台内容。
2. 完整的 Paperclip routine 接线。
3. 所有新 skill 的全部实现。
4. 复杂向量检索或外部 memory provider 接入。

## 2. 执行步骤

### 2.1 P0：文档与目录骨架

- 新增系统设计 spec。
- 新增最小实现任务文档。
- 新增 `kb/preference-memory/README.md`。
- 新增 `kb/preference-memory/MEMORY.md`。
- 新增 `kb/preference-memory/review-patterns.yaml`。

### 2.2 P1：skill 契约落地

- 起草 `reference-intake-routing`
- 起草 `insight-extraction`
- 起草 `expression-extraction`
- 起草 `review-feedback-to-memory`

### 2.3 P2：例行整理接入

- 定义每日 routine 的输入输出
- 约定整理报告落位
- 约定哪些条目可自动升格为候选原则
- 起草 `knowledge-relink-maintenance`

## 3. 产物清单

本轮最小产物：

- 系统 spec
- 实现任务文档
- 偏好记忆目录
- 初始 memory 文件
- 初始结构化 YAML
- 4 个主链 skill 初稿

## 4. 完成标准

本轮完成可视为“开始执行”的最小标准：

1. 研究中心已有正式 spec 可引用。
2. 偏好记忆有稳定落位，不再只停留在口头设想。
3. 后续 skill 可以引用同一份偏好记忆文件。
4. 后续 Paperclip routine 可以围绕该目录继续扩展。

## 5. 后续依赖

本轮之后，优先继续：

1. `review-feedback-to-memory` skill
2. `insight-extraction` 与 `expression-extraction` 的记忆读取约定
3. 每日整理 routine 的具体执行文档
