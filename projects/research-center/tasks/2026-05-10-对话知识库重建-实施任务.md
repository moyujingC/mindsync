## 1. 任务目标

基于 `2026-05-10-对话知识库重建-SPEC.md`，把实验性的 `ai-product-agent-wiki` 从当前入口中降级，创建新的 `conversation-knowledge-wiki` 骨架，用于长期沉淀用户与 AI 讨论后产生的可复用知识。

## 2. 执行范围

本任务执行：

- 创建 `projects/research-center/kb/conversation-knowledge-wiki/`；
- 添加新知识库入口说明；
- 添加 Agent 协作说明；
- 添加 inbox / source / entry / review 模板；
- 更新 `projects/research-center/kb/README.md`；
- 冻结旧 `ai-product-agent-wiki` 入口说明。

本任务不执行：

- 不物理删除旧目录；
- 不批量迁移旧内容；
- 不把旧内容默认为可信知识；
- 不引入数据库、向量检索或自动化脚本。

## 3. 验收标准

- 新目录结构存在；
- 新 `README.md` 明确说明知识库定位、收录范围、不收录范围和目录结构；
- 新 `AGENTS.md` 明确说明 Agent 入库规则；
- 模板至少覆盖：
  - inbox；
  - source；
  - entry；
  - review；
- 旧库 README 明确标记为归档或历史参考；
- `kb/README.md` 指向新入口，并说明旧库处理状态；
- `git diff` 检查无误；
- 本次改动独立提交。

## 4. 边界情况

- 如果用户后续要求“完全删除旧库”，应先确认是否需要保留归档提交记录，再执行删除。
- 如果某个旧条目看起来仍有价值，也不能直接迁入 `entries/`，必须先生成 review。
- 如果新知识来自一次聊天，但没有明确来源时间和复用场景，只能进 `inbox/`。

## 5. 验证方式

人工验证：

- 检查新旧入口表述是否一致；
- 检查模板字段是否支持入库质量门；
- 检查旧库没有继续被描述为当前默认入口。

命令验证：

```bash
git diff -- projects/research-center/kb projects/research-center/specs projects/research-center/tasks
find projects/research-center/kb/conversation-knowledge-wiki -maxdepth 2 -type f | sort
```
