## 1. 决策

从 2026-04-13 起，`Get笔记` 作为 `墨予镜` 的外部内容采集层接入 `mindsync` / `Paperclip` / 本机 Claude Code / Codex。

它的角色不是替代 `mindsync` 正式文档系统，而是专门承接以下输入：

- 抖音链接
- 小红书链接
- 公开网页链接
- 临时文本笔记
- 后续需要召回的外部素材

## 2. 为什么这样做

当前 `mindsync` 已有研究、转写、知识入库和 handoff 主链路，但对外部平台内容存在两个现实缺口：

- 本机没有稳定的视频提取 / 抓取能力
- 抖音、小红书等内容难以直接进入现有研究闭环

`Get笔记` 已具备外部内容抓取、保存、搜索和召回能力，适合作为前置采集层。

## 3. 边界

`Get笔记` 负责：

- 外部内容采集
- 原始素材保存
- 笔记搜索与召回

`mindsync` 继续负责：

- 正式 spec
- research / synthesis
- qa
- delivery
- 跨角色 handoff
- 长期知识沉淀

默认不把 `Get笔记` 当成公司正式主知识库。

## 4. 运行策略

- 本机运行：
  - `~/.codex/skills/getnote`
  - `~/.claude/skills/getnote`
- Paperclip 运行：
  - 以 company skill 方式接入
  - 只同步给 `Research & Knowledge Lead`、`Content Lead`、`Engineer`
- 凭证策略：
  - 前期采用一套共享 `GETNOTE_*` 凭证
  - 后续若出现权限边界问题，再拆为 agent 专属凭证

## 5. 一句话结论

`Get笔记` 是 `墨予镜` 的外部采集入口，不是正式知识库；采集在外部完成，结论在 `mindsync` 内收束。
