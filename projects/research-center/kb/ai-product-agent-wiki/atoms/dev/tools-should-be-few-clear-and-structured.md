# Tools Should Be Few Clear And Structured

## Claim

Agent 工具应该少而清楚，并且用结构化输入输出表达能力边界。

## Type

- pattern

## Applies To

- dev

## Source

- [[../../wiki/sources/building-with-llms-notes]]

## Notes

- 工具太多会增加选择错误和调试成本。
- 结构化输入输出能让 eval、trace 和状态机更容易判断发生了什么。
