# Trace Enables Agent Explainability

## Claim

Trace 是 Agent 可解释性的基础，因为它记录目标、上下文、工具结果、状态变化和决策理由。

## Type

- insight

## Applies To

- dev

## Source

- [[../../wiki/sources/building-with-llms-notes]]

## Notes

- 没有 trace，只能看最终输出，很难定位问题来自上下文、工具、模型还是状态判断。
- trace 不等于把所有 token 留下来，而是保留能复盘决策的关键事件。
