# 多 Agent 需要清晰理由

## 断言

多智能体只有在职责、模型能力或并行性有明确收益时才值得拆。

## 类型

- pattern

## 适用对象

- dev

## 来源

- [[../../wiki/sources/building-with-llms-notes]]
- [[../../wiki/sources/ai-product-strategy-notes]]

## 备注

- 常见拆分理由包括不同专业职责、不同工具权限、不同模型能力、可并行执行的独立任务。
- 如果只是为了显得更像 Agent 系统，多智能体通常会降低稳定性。
