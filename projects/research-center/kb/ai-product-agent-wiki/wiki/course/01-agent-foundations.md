# 01 Agent Foundations

## Goal

分清普通 LLM 调用、workflow 和 agent 的边界，先判断问题是否真的需要 Agent。

## Key Questions

- 用户问题是什么？
- 固定 workflow 是否已经足够？
- Agent 是否需要自主判断下一步？
- 哪些步骤必须可追踪和可回放？
