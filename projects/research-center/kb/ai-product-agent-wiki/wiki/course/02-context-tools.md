# 02 Context And Tools

## Goal

理解 Agent 不是只靠 prompt 工作，而是依赖上下文、工具和领域知识。

## Key Questions

- Agent 当前任务需要哪些上下文？
- 哪些能力应该做成工具？
- 工具输出是否结构化？
- 什么时候应该补知识，而不是改 prompt？
