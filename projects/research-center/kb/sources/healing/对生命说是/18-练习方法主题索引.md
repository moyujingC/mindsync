本文把《对生命说是》中可转化为疗愈方案候选的练习进行主题索引。索引以转述和归类为主，不替代原文，也不代表已可产品化。

## 使用原则

- 这些练习目前只能作为研究素材。
- 进入产品前需要重写成安全、短小、可退出的版本。
- 涉及创伤、疾病、死亡、强烈情绪和家庭冲突时，应优先加入专业支持提示。
- AI 不应强行引导用户独自进入深层情绪或身体经验。

## 练习索引

| 练习方向 | 来源定位 | 可服务议题 | 产品化风险 |
|----------|----------|------------|------------|
| 重写自我评语 | 第一章 / 重写你的自我评语 | 不值得感、自我否定、不可爱、失败感。 | 中：可能触发强烈自责或创伤记忆。 |
| 区分事实与判断 | 第一章 / 当情绪出现时，一个事实将会变成一个判断 | 情绪反应、身体接纳、自我评价。 | 低：适合改写为追问。 |
| 关系冲突中的呼吸和诚实表达 | 第二章 / 取代争吵，可以运用这些指引帮助你们变得更加亲密 | 争吵、指责、伴侣沟通。 | 中：不适用于暴力或高风险关系。 |
| 关系利弊清单 | 第二章 / 衡量利弊，做出选择 | 是否继续关系、关系选择。 | 中：不能替代法律、婚姻或安全建议。 |
| 深层信念质疑 | 第三章 / 对引起你痛苦的深层信念提出疑问 | 关系结束、失落、没人理解我。 | 中：可能触发创伤和孤独感。 |
| 陌生人投射观察 | 第四章 / 以全新的姿态迎向别人 | 批评他人、投射、社交紧张。 | 低：适合日常觉察。 |
| 冲突中的情绪归属 | 第四章 / 移向真正惹恼你的人 | 人际冲突、被冒犯、想改变别人。 | 中：需避免把责任推给受害者。 |
| 真实说“不” | 第四章 / 想说“不”，就说“不” | 边界不清、取悦、妥协后怨恨。 | 中：不适用于需要安全计划的关系。 |
| 通过批评他人认识自己 | 第四章 / 借着对别人的批评来认识自己 | 投射、讨厌某类人、重复冲突。 | 低到中：需要防止自责化。 |
| 父母态度清单 | 第五章 / 对父母相关段落 | 父母关系、价值观、代际影响。 | 中：可能引发家庭创伤。 |
| 愚忠识别 | 第五章 / 对父母的愚忠限制了我们的生命 | 不敢超越父母、重复家族模式。 | 中：家庭系统解释需要降级为线索。 |
| 情绪观看 | 第六章 / 看 / 还有理解 | 生气、恐惧、情绪压抑或爆发。 | 高：强烈情绪、惊恐、解离时不适用。 |
| 身体反应记录 | 第六章 / 当你察觉到一种情绪时，它已经在影响着你的身体 | 身体紧绷、情绪觉察、压力。 | 中：不能解释为医学诊断。 |
| 对反应负责 | 第七章 / 另一个选择——对你的反应负责任 | 处境困住、抱怨、无力感。 | 高：必须区分不可控事件和个人反应。 |
| 问题视角转换静心 | 第七章 / 静心让你从不同观点看“问题” | 反刍、问题感、焦虑。 | 中：焦虑严重时需谨慎。 |
| 习惯保护功能识别 | 第八章 / 如何了解和处理你的顽固习惯 | 拖延、完美主义、悲观、逃避。 | 中：成瘾和失控行为需专业支持。 |
| 改变利弊清单 | 第九章 / 如何面对变化和不安全的状况 | 害怕改变、安全感、舒适区。 | 低到中：可用于决策准备，不替代专业建议。 |
| 角色和保护墙溶解想象 | 第九章 / 古印度的静心技巧 | 面具、角色、保护机制。 | 高：可能触发不稳定感，产品化需简化。 |
| 想象自己消失 | 第九章 / 一种西藏静心技巧 | 自我重要性、死亡觉察、控制感。 | 高：不适用于抑郁、自伤风险和死亡焦虑严重用户。 |
| 悲伤允许与感恩 | 第十章 / 假如我们让悲伤顺其自然 | 哀伤、失去、死亡、疾病。 | 高：不能用感恩绕过悲伤。 |
| 价值观质疑 | 第十章 / 质疑你的价值观 | 父母价值观、世界观、应该怎样。 | 中：可作为温和自我探索。 |
| 在“不”和“是”之间移动 | 第十章 / 在“不”和“是”之间移动 | 注意力转向、抱怨、资源觉察。 | 中：需要避免把“是”变成压抑。 |

## 优先产品化候选

较低风险、可优先改写成产品练习的方向：

- 区分事实与判断。
- 重写自我评语。
- 陌生人投射观察。
- 真实说“不”的微练习。
- 习惯保护功能识别。
- 改变利弊清单。
- 在“不”和“是”之间移动。

## 暂不建议自动化引导的练习

以下练习应暂缓进入 AI 自动生成方案，除非已有专业安全设计：

- 情绪观看中的强烈愤怒、恐惧或身体释放。
- 父母愚忠相关深度练习。
- 角色和保护墙溶解想象。
- 想象自己消失。
- 疾病、死亡、哀伤场景中的深度引导。

这些练习可留在研究母库，等待人工 review 和安全边界设计。
