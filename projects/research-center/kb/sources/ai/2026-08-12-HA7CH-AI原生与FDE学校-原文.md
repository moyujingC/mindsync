## README 关键表述

### 项目定位

README 将项目描述为一个 Claude Code Skill（也提供 Codex 安装方式）：加载后，Agent 成为带学导师，按学习者能力和节奏逐节教学。

它强调的体验包括：

- 加载后直接开始选课；
- 入口 Skill 只承担“教务处”职责，课程和讲义按需渐进加载；
- 教学在主对话中进行，学习者可随时打断提问；
- 根据能力画像动态安排课程顺序；
- 用真实产品或练习承接实验课；
- 将学习进度存到本机，以便跨会话继续。

### 已公开课程

#### AI Native（AI 原生）

README 列出四个主题：

1. 零 Token（模型调用计费单位）设计。
2. ChatGPT Work 之后的工作方式。
3. 把简历变成 `cv.ha7ch.com` 活页面的实操。
4. HA7CH 精选延伸阅读。

#### FDE（Forward Deployed Engineer，前线部署工程）

README 列出四个主题：

1. 用起点、终点和四条硬指标解释 FDE，并区分 FDE 与外包。
2. 商务、产品、研发 × 三层客户的 FDE 九宫格。
3. 通过内置诊断与“货代擂台”练习真实需求摸查。
4. 北上深杭 builder（实践者）调查所描述的市场坐标。

#### 共修内容

README 还包含：

- GitHub 协作词汇和首次 issue / PR（问题单 / 合并请求）实验。
- 与企业一号位沟通：会前准备、会中建立信任与边界、会后把兴趣推进成带数据、指标、负责人和停止条件的 POC（概念验证 / 小试点）。

### 课程编排与教学法文件的公开表述

`references/pedagogy.md` 的公开内容要求：先讲授，避免把教学变成连续盘问；每节围绕“是什么、为什么、怎么用、例子、原话”组织，并在自然处允许可选提问。

`references/course-fde.md` 将 FDE 能力拆成：

- Echo：商务、摸需求与把客户模糊表达落到可追踪问题；
- Delta：技术、端到端构建与交付。

课程文件称九宫格用于判断客户所在层级和相应打法；课程也会在准备见企业、讨论竞品或进入 POC 时接入“一号位沟通”专项。

### 分发、更新与本地状态

README 给出安装方式：

```bash
npx @ha7ch/school
npx @ha7ch/school --codex
npx @ha7ch/school --force
```

`manifest.json`（版本 `1.4.0`）列出按需下载的课程文件、讲义、诊断 Skill 和一号位沟通资源。README 称每次开课会比较本地与线上 manifest 版本；有更新时自动以 `--force` 重装，学习进度单独存储在 `~/.ha7ch-school/{handle}.json`。
