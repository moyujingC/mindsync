## 摘要

这批来源围绕一个共同问题展开：AI Agent 进入软件使用链路后，产品设计不再只面对人类用户，也要面对 Agent、自动化系统和其他 AI 应用。

当前可分为四类材料：

1. 产品判断型：强调软件交互主体从人转向 Agent，产品需要为 Agent 设计接口、上下文和反馈闭环。
2. UX 设计型：讨论 Agent UX / Agentic UX 的设计原则、信任、透明度、控制权和用户旅程。
3. 工程接口型：讨论 CLI、API、MCP、工具调用和结构化执行界面。
4. 行业观察型：讨论不能被 Agent 使用的产品未来可能失去入口。

## 初步判断

这批材料支持一个方向：

> AI 应用设计正在从只设计 UX，扩展到同时设计 UX 和 AX。

这里的 UX 是人类用户体验，AX 是 Agent 使用体验。

目前更稳的表达不是“UI 已死”，而是：

> UI 仍然重要，但它不再是唯一入口。成熟 AI 应用需要同时提供人能理解的交互界面，和 Agent 能稳定调用的能力界面。

## 可提取 atoms

- AI 应用需要同时服务人类用户和 Agent 用户。
- Agent 时代的软件入口会从 GUI 扩展到 CLI、API、MCP 和结构化能力契约。
- UI/UE 原型在 AI 应用里应验证人机分工，而不是只验证页面跳转。
- Agent 可用性需要明确输入、输出、状态、权限、失败和反馈机制。
- 不能被 Agent 使用的软件，可能在未来失去重要入口。
- 前端在 Agentic 时代可能从展示层扩展为执行界面和任务控制层。
