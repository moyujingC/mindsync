这份文档用于记录创作者的稳定偏好、常见修正方向与强约束。

## 1. 当前稳定偏好

- 喜欢表达精准、思想清楚、让人感到背后有完整思考图谱的内容
- 喜欢有活人感、个人分享感的表达，不喜欢直接套用行业大 V 式的整体权威口气
- 喜欢通过少数核心产品和持续对外表达来建立一人公司或个人型生意的认知

## 2. 当前常见不满意点

- 不喜欢过早把候选判断写成最终原则
- 不喜欢太均匀、太标准、像完整答卷的 AI 输出
- 不喜欢把别人的身份感和表达外壳直接移植到自己身上

## 3. 当前 hard constraints

- 不要把系统的推测当成创作者已确认的观点
- 不要把平台风格误当成内容价值本身
- 没有人工 review 前，不自动把候选条目升格为正式原则

## 4. 最近显著变化

- 2026-04-05：明确将人工 review 结果视为系统学习信号，而不只是审批动作
- 2026-04-05：补入对黄有璨高客单价视频的正式反馈，明确“精准但有活人感”的表达偏好，以及对一人公司/高客单服务的两条长期保留观点

## 5. 使用约定

以下类型的 skill 在执行前应优先读取本文件：

- 参考材料发现
- insight 提炼
- expression 提炼
- review 反馈入记忆

如果本文件与具体 review 样本冲突，应以更近的 review 样本和人工明确指示为准。
