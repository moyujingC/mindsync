你好，我是 Leo，欢迎你和我学习具身智能开发。

上一讲，我们用“机器人收起纸杯”说明了分层机制：大模型把任务拆成抓取、搬运和放置等技能；策略模型根据相机画面和关节状态预测动作；执行程序再把动作发给电机，并配合限位、限幅和停止机制运行。

这解释了各部分怎样配合，却还没有回答一个关键问题：策略模型为什么知道，夹爪没对准时应该继续移动，夹住纸杯后才应该抬起？这一讲就从“怎样把这些动作教给模型”开始。

我们还是用上一讲的纸杯任务来理解这个问题。摄像头拍到了桌面、纸杯和收纳盒，编码器记录了六个关节的位置。策略模型要根据这些信息，连续完成靠近、对准、闭合、抬起、移动和松开。如果杯子的位置始终固定，我们可以提前写好规则和运动轨迹。但只要杯子的位置、姿态或遮挡发生变化，规则就会越来越多，也越来越难维护。这时，我们需要换一种思路：不再由人写死每一步，而是教策略模型根据现场情况决定动作。

![](https://static001.geekbang.org/editor-compose/resourceimage/compose/93/82/93829c58cfcb89c4dd630aee7e6d2482.png)

那么，我们具体可以怎样教策略模型？先看两种教动作的方法，再看任务需要随语言指令变化时，可以用什么样的模型。

你可以亲自操作机械臂，把成功完成任务的动作示范给策略模型。策略模型照着这些动作学习，这就是模仿学习。

你也可以让策略模型自己尝试，用动作结果或整次任务的得分给它反馈。策略模型根据分数调整行为，这就是强化学习。

如果任务还要求模型听懂语言，例如根据指令选择不同的物体和目标，就可以考虑视觉 - 语言 - 动作模型（Vision-Language-Action，VLA）。VLA 让图像、语言和机器人状态一起参与动作预测。不过，VLA 解决的是语言怎样进入策略；训练 VLA 时，仍然可以让它跟着人的操作学，也可以用奖励继续练。因此，“用 VLA”与“用模仿学习”可以同时成立：前者选择模型，后者选择教模型的方法。

这一讲不比较具体模型的参数规模，而是解决一个工程问题：拿到一个机器人任务后，你怎样判断应该从哪条路开始。

## 先弄清楚：这几个名字分别在说什么

选型时容易混淆，是因为资料中的名字并不都指同一件事。下面把它们放回各自的位置：先区分“用什么反馈来训练”，再区分“选什么模型来预测动作”。这样，后面看到 ACT、PPO 或 VLA，就知道它们分别解决哪一部分问题。

| 名字 | 它指什么 | 放到纸杯任务里怎样理解 |
| --- | --- | --- |
| 模仿学习 | 根据示范学习动作的方法 | 人录下正确操作，模型学习在相应画面和关节状态下怎样动。本节课以行为克隆为例。 |
| 强化学习 | 根据尝试结果的奖励改进策略的方法 | 程序评价抓取结果，训练根据反馈调整动作；需要合适的试错、重置和评分条件。 |
| VLA | 把视觉、语言与动作联系起来的一类模型 | 让“拿纸杯”或“拿积木”这样的指令影响动作。VLA 可以通过模仿学习训练，也可以采用奖励训练。 |
| ACT | 预测一段动作的策略模型 | 本课程先用人的示范训练 ACT，完成固定抓放；第 04、05 讲再展开它怎样生成和执行动作。 |
| PPO | 强化学习中的一种训练算法 | 用尝试得到的奖励更新策略参数。它与 ACT 所指的层级不同，不能只按名字作二选一。 |

可以这样记：ACT 主要回答“动作怎么预测”，PPO 主要回答“策略怎么根据奖励变好”。这节课我们先确定训练任务需要哪些条件，ACT 怎样预测一段动作，第 04、05 讲会结合抓取过程继续讲。

### 先说清楚任务怎样运行

要把这些区别用到自己的任务上，还需要明确模型每一步能看到什么、能控制什么，以及怎样判断任务完成。否则，“给模型示范”或“给模型打分”都还只是一句空话。我们可以借用熟悉的 Coding Agent 执行过程来理解。

假设 Coding Agent 正在修复登录接口：它先读代码和日志，修改文件后运行测试，再根据新报错继续改。机器人也有类似的执行过程：读取图像和关节状态，移动夹爪，再用新的画面判断下一步怎样动。两者都需要根据上一步的结果继续行动。

这里要先分清“任务”和“策略”。任务说的是最终要完成什么，例如把纸杯放进盒子；策略说的是每一步该怎么做，也就是根据当前看到的信息决定下一个动作。要训练这个策略，必须先说清楚它能看到什么、能发出什么动作、动作会带来什么变化，以及怎样判断任务结束。下面用 Coding Agent 做对照：

| 概念 | Coding Agent | 机器人任务 |
| --- | --- | --- |
| 状态或观测 | 代码、日志和历史调用 | 图像、关节位置和夹爪状态 |
| 动作 | 调用搜索、编辑或测试工具 | 发送关节位置或末端位移 |
| 环境变化 | 工具调用改变文件和进程 | 机械臂动作改变自身姿态和物体位置 |
| 奖励 | 训练时用来更新策略的反馈，例如通过了多少测试 | 训练时用来更新策略的反馈，例如纸杯是否被抓起 |
| 评测 | 在训练之外，用保留任务检验 Agent | 在训练之外，按固定流程统计成功率 |
| 终止条件 | 问题修复、超出预算或触发安全限制 | 任务成功、超时或触发急停 |
| 策略 | 根据当前信息决定下一步调用什么工具 | 根据当前观测决定机械臂下一步怎样运动 |

表里区分“奖励”和“评测”，是因为它们用途不同：奖励参与训练，影响模型怎样调整动作；评测则是在训练之外检查完整任务是否做成。即使训练得分提高了，我们仍要单独测试纸杯是否真的进了盒子。

实际执行时，模型只能根据相机和编码器提供的信息作判断。有时一张画面还不够，例如要连续看几帧，才能判断纸杯是不是正在滑落。因此，开始训练前，先把下面四个问题的答案写清楚：

每一步，模型能看到哪些画面和关节信息？

模型可以让机械臂执行哪些动作？

机械臂动一下以后，画面、关节和物体会怎样变化？

出现什么结果算成功，什么情况算失败？

这四个问题写清楚以后，训练方法就不再是凭名字选。能把正确过程做给模型看，就先让模型照着示范学；没有示范，但程序能自动打分，而且允许模型反复尝试，再考虑强化学习；如果希望同一套策略根据语言切换目标和动作，可以把 VLA 纳入选择，它同样可以用示范来训练。

我们现在做的是固定的纸杯任务，也能用遥操作稳定地完成示范。因此，最顺手的起点是模仿学习。下面就来看看，一遍人的操作怎样变成模型可以学习的数据。

## 模仿学习：把一遍操作变成模型能学的数据

本课程用遥操作来采集示范：你移动作为输入设备的 Leader 臂，实际工作的 Follower 臂跟着运动，系统同时记录画面、关节状态和发出的动作。我们常说的“专家示范”，在这里就是熟练操作者完成任务的记录，“专家”指提供示范的人。抓取纸杯时，一次示范会包含下面这些步骤：

靠近纸杯 → 调整夹爪 → 闭合 → 抬起 → 移到盒子上方 → 松开

从任务开始到成功、失败或超时的一次完整尝试，叫一个 episode。采集时，系统按时间保存相机画面、关节状态和当时发出的动作，并记录任务指令与时间戳。这样才能回看“在什么情况下，操作者做了什么”，而不是只知道最后成功或失败。

假设一条演示保留了 150 帧，就记录了 150 个时刻的画面、关节状态和对应动作。记录保留的是整个操作过程，而不只是最后那个“成功”结果。例如：

看到夹爪还在纸杯右侧、没有对准时，你把夹爪向左移动了一点

看到夹爪已经对准时，你开始闭合夹爪

看到杯子已经夹稳后，你向上抬起机械臂

训练时，我们把某个时刻的画面、关节状态和当时的操作动作配在一起，让模型预测在这种情况下应该怎样动，再让预测逐渐接近示范动作。这种照着示范学习动作的方法叫行为克隆（Behavior Cloning，BC）；预测接下来一段动作的模型，也可以采用这种训练方式。

这与用完整操作记录训练 Coding Agent 很像：只写“测试通过”，并没有告诉模型怎样修复代码；保留读日志、改文件、跑测试的过程，才提供了可以学习的具体做法。机器人示范中的每一步动作，也是同样的作用。

有了这些示范，模型一开始就能看到正确动作，不必先在真机上胡乱尝试，碰巧成功后再猜哪些动作有用。因此，用人的操作数据训练，通常更容易做出第一个可用版本。

### 50 次完整操作，不是只有 50 个学习样本

我们来算一笔训练数据的账。假设每条演示保留 150 帧，50 条演示就有 7500 帧。训练逐帧动作预测模型时，每一帧都可以组成一组“画面、关节状态 - 当时动作”记录。训练 ACT 时，模型还可以从某个时刻开始，把后续一段动作作为预测目标。因此，一条完整演示能够提供许多个训练起点。

但 7500 帧不等于 7500 种不同场景。连续两帧可能几乎一样；反复录很多次中央抓取，也没有教过模型杯子靠近桌边时该怎样抓。因此，要同时看操作是否完整稳定，以及场景变化是否覆盖实际使用范围。

演示次数本身不能保证成功率。第一次实验可以先采集一小批稳定操作，训练后在限速、可随时停止的条件下测试，找到反复失败的场景，再补录正确操作并重新训练。每一轮都要用实际运行结果决定下一轮补什么，避免只增加熟悉场景里的重复记录。

### 模仿学习会照着示范学，也会照搬数据里的偏差

示范能告诉模型怎样动作，但模型未必学到了我们期待的判断依据。假设所有演示都把纸杯放在桌面中央：模型可能学会了根据杯子位置移动，也可能只是记住“先把夹爪移到桌面中央”。在这些示范上，两种做法都很像人的操作，但杯子向右挪 5 厘米以后，第二种做法却会抓空。

所以，检查模仿学习的数据时，不要只看录了多少条。还要看下面三件事：

人的操作稳不稳。如果示范时经常来回试探、抓到一半又换方向，模型也会把这些犹豫的动作学进去。

数据有没有包含机器人实际会遇到的变化。比如只在桌面中央录过纸杯，杯子换到右边以后，模型可能就不知道该怎么动。相机角度和光线发生明显变化，也会带来同样的问题。

同一种情况下，数据里有没有互相冲突的动作。比如夹爪与纸杯之间有一个水壶，一部分示范从水壶左边绕行，另一部分从右边绕行。两种做法单独看都能成功，但模型可能把左右两种动作平均一下，反而从中间撞上水壶。第一次采集时可以先统一绕行方式；确实需要保留不同做法时，再考虑怎样让模型选出一条完整路线。第 05 讲会用这个例子解释不同动作模型的区别。

以上做法都在改善“给模型什么示范”。如果我们还能自动判断任务做得好不好，并且允许机器人安全地反复尝试，就多了一种训练手段：用尝试得到的分数调整动作。这就是强化学习。它也需要合适的训练环境，并不会自动解决所有没见过的场景。

## 强化学习：不给答案，只给分数

为了看清它与模仿学习的区别，先设想一个不提供示范的训练过程：策略尝试控制机械臂，程序根据动作结果或整次任务的结果给分。例如，我们可以尝试设置下面这些奖励，但随后还要检查它们是否真的鼓励了完整任务：

靠近目标，得到一点奖励

抓起物体，得到更多奖励

放进收纳盒，得到最终奖励

碰撞或超时，得到惩罚

策略反复执行任务，再根据奖励调整参数，这就是强化学习（Reinforcement Learning，RL）。可以类比让 Coding Agent 自己修代码：不给现成补丁，只用测试结果反馈这次修改做得如何。不过，结果只说明最终表现，还需要训练算法把得分与此前的行为联系起来，判断哪些动作值得保留、哪些应该调整。这通常叫“信用分配”。

### 奖励涨了，为什么还是抓不起杯子？

假设你让策略自己练习抓杯子，并给“夹爪离杯子更近”加分。训练曲线慢慢上升，你打开录像，却发现夹爪一直停在杯子旁边。它学会了靠近，却没学会抓起。这是因为奖励变高与任务完成是两件需要分别检查的事。

这里有两个容易混在一起的困难。

第一个是很难获得第一次成功：从接近、对准，到夹住、抬起和放入盒子，需要连续做对多个步骤。如果模型刚开始几乎随机尝试，只有最后放进盒子才得分，就可能连续很多次都没有正反馈，难以知道该往哪个方向改。这就是“稀疏奖励”：有用的得分出现得太少。

第二个困难是中间得分可能偏离最终目标。例如，只要夹爪留在杯子附近就能反复得分，策略便可能不再尝试抓起。如果只奖励“靠近”，模型就没有足够的反馈去学“抓起并放入”。

训练会奖励能够拿到高分的动作，但奖励写得不准确，它就可能找到一条“分数很高，但任务没有完成”的捷径。遇到这种情况，先看录像，确认策略究竟在重复什么动作。再检查这些动作是不是恰好能够持续得分，却没有推动任务完成。如果是，就需要修改奖励，再重新评测。如果修改后得分提高了，还要按固定流程测试纸杯是否真正被抓起并放入盒子，不能只看奖励曲线。

### 强化学习更适合什么条件？

是否采用强化学习，首先取决于能否安全、持续地尝试，以及评分是否准确反映任务完成。仿真通常更容易复位和重复实验；真机失败后可能要扶正物体、检查设备，成本高得多。奖励也要经得起检查：物体是否进盒比较明确，“动作自然”或“没有轻微损伤”却不容易自动判定。

具备这些条件以后，再考虑从哪里开始训练。如果已经能采集示范，可以先用模仿学习获得基本动作，再用奖励继续改进，减少从随机动作开始的探索。这并不免除前面的要求：有了初始能力，仍然需要可靠评分和可控的试错环境。

到这里，模仿学习和强化学习的区别就落在了训练反馈上：一个主要从示范动作学习，一个根据尝试得到的奖励改进。接下来再看另一个问题：同一张桌面上有多个物体，指令要求拿哪个，模型就要改抓哪个。此时，语言也需要参与动作选择，这就涉及到了 VLA。

## VLA：让任务文字直接影响机器人怎么动

前面我们一直使用固定的纸杯任务。在本课程的基础 ACT 配置里，策略根据图像和关节状态预测动作，并没有把任务文字作为输入。即使每条数据旁边都写着“把纸杯放进盒子”，也不能据此说模型理解了这句话。

VLA 要处理的就是任务文字改变动作目标的情况。例如，同一张桌面上同时放着红色积木、蓝色积木和纸杯：“把红色积木放进左边盒子”要求选择红块，“把蓝色积木推到黄色区域”要求改选蓝块并执行推动，“拿起纸杯”则要换成抓取。画面没有变，任务文字变了，模型就应该相应改变目标和动作。

可以把 VLA 的工作方式先记成下面这行：

图像 + 语言指令 + 机器人状态 → 动作

在上节课的 Agent 分层机制里，大模型先决定要做什么，再调用抓取、放置等技能。VLA 可以承担其中根据画面和指令生成动作的工作：例如，任务编排已经决定“拿红块”，VLA 再根据红块当前的位置给出机械臂动作。它参与的是具体动作执行，不代表任务编排和设备保护都由它完成。

放回上一讲的分层机制就更容易理解了：大模型或 Planner 先决定任务顺序，VLA 或其他策略模型决定机械臂下一步怎么动，执行程序再检查并发送动作。动作能否安全执行，还取决于设备限制、现场条件和停止机制，不能只靠策略模型保证。

### 认识纸杯以后，还要学会怎样抓它

许多 VLA 使用经过图像和文字预训练的模型作为基础，帮助识别物体，并把任务文字与目标联系起来。但认识纸杯，不等于已经会控制本机：还要通过机器人数据学会画面与关节状态怎样对应动作、各个动作数值代表什么，以及怎样连续执行。这与 Coding Agent 会写 Python、却仍需适应公司的工具和运行环境类似。VLA 也要接好本机的相机、关节和动作接口，再验证实际任务效果。

对于本课程第一个固定的纸杯任务，我们先用 ACT，把数据、训练和控制流程跑通。需要根据语言切换目标时，再评估 VLA。预训练 VLA 也可以用于固定任务，但是否更合适，要比较可用数据、计算资源和实际效果。另外，“随语言指令改变任务”不等于“支持所有语言”，中文或英文指令是否有效，还取决于模型和训练数据。

## 拿到任务后，用这五个问题做选型

![](https://static001.geekbang.org/editor-compose/resourceimage/compose/d8/8a/d827dffeaa2d3dbf7ebe77a6db49a38a.png)

前面我们已经充分理解了具身智能策略学习的三大范式，那究竟怎么选呢？可以套用到具体任务上。下面五个问题需要结合起来看：既要确定怎样获得训练反馈，也要确定模型是否需要接收语言，才能选出适合当前任务的起点。

| 先问什么 | 怎样据此作判断 |
| --- | --- |
| 任务是否随指令变化？ | 固定纸杯任务可以先用 ACT；需要同一策略根据语言换物体、换动作时，再评估 VLA。选了 VLA，仍要决定用哪些示范或奖励来训练。 |
| 能否稳定地提供示范？ | 能遥操作完成任务，就有了模仿学习的起点。没有示范时，只有在允许安全试错、环境能重置且评分可靠的条件下，才考虑从探索开始。 |
| 评分是否真的反映任务完成？ | 检查停在杯子附近能否一直得分、抓起和放入是否会被识别。若高分可以靠漏洞获得，先修评分，再谈强化学习。 |
| 一次失败要付出什么代价？ | 真机失败可能需要人工复位，也可能损坏设备。试错代价高时，优先用稳定示范建立基本能力，并在受控条件下测试。 |
| 当前失败发生在哪一步？ | 抓不准或掉杯，先查画面、数据和动作接口；如果同一画面下改了指令却不换目标，再检查语言输入、训练数据和模型对指令的使用。 |

对于第一个 SO-101 纸杯任务，我们有稳定示范、任务目标固定，又不适合在真机上大量随机试错，因此先用示范训练 ACT。测试之后，如果发现某类场景反复失败，就补采正确操作；如果需求变成按指令选择不同物体，再评估 VLA。

### 选型卡：把选择理由记下来

算法选型不要只停留在与 AI 的对话或临时讨论里，最好把当时的判断依据记录下来。下面用一张表记录第一个纸杯任务的选择和判断依据。

| 记录项 | 第一个纸杯任务的判断 |
| --- | --- |
| 任务目标 | 把同一种纸杯放进同一个盒子，暂不要求根据语言更换目标。 |
| 可用训练反馈 | 能够通过遥操作稳定完成任务，因此可以采集正确示范。 |
| 试错条件 | 目前没有可大量重置的仿真训练环境，也没有验证过的可靠奖励，不从随机真机探索开始。 |
| 初始方案 | 先用示范训练 ACT，验证从相机、数据、模型到机械臂执行的完整流程。 |
| 先看哪些证据 | 用固定流程统计完整任务成功率，并查看首次偏差发生在哪里；训练误差只作辅助。 |
| 何时重新评估方案 | 确认多条有效路线被折中后，比较其他动作生成方式；需要按语言换目标时，评估 VLA；已有基本能力且试错、重置和评分条件齐备时，再评估奖励训练。 |

这份记录把“为什么先选 ACT”与“什么时候需要重新评估”分开了。这是因为，一次抓空不代表必须换模型，先沿运行记录查清原因。即使出现了表里的新条件，也应做小规模对比，确认新方案在同一任务、同一测试规则下确实有收益，再进行更换。

### 选好方法后，第一轮实验怎么做

第一轮实验围绕一个完整任务展开。

每次保存画面、关节状态、动作和时间，失败后才能判断是没看清杯子、移动偏了，还是夹住后掉落。这些记录首先用于诊断，不能把失败动作原样当作正确示范；用于行为克隆时，应补录正确操作，或选取合格的人工接管纠正片段。

让模型自己从开始运行到结束的一次尝试，通常叫 rollout，也就是一次策略执行。测试时要统计完整任务成功了几次、常在哪一步失败、是否触发停止。行为克隆训练中的 loss，表示预测动作与示范动作的差距；它变小了，也不能代替实际任务测试。

如果抓取失败，先检查相机是否看清杯子、示范是否覆盖当前位置、动作记录和发送给电机的数值是否正确，再决定补数据、修程序或调整训练。先把固定任务跑通，再加语言和任务编排，才能分清新问题出现在哪一环，而不是每次抓空就增加训练步数或更换模型。

课程也按这个顺序推进：先理解动作学习和误差，再准备并检查示范数据，训练和评测 ACT 等策略；根据失败补充正确操作以后，再尝试 VLA 的语言条件任务，最后接入任务编排、运行保护与交付流程。这节课我们先把选择依据讲清楚，后面的课程再逐步落实到实验。

## 小结：带着选型卡，开始第一个任务

回到纸杯任务，我们选择 ACT 的依据是：任务固定，能够采集稳定示范，希望先验证数据到机械臂动作的完整流程。后续是否增加语言或采用奖励训练，要由任务需求和实验条件决定。选型卡把这些依据留下来，方便实验失败时有针对性地调整。

不过，用人的示范训练还留下一个问题：训练时的画面来自示范者的操作，运行时的下一帧却由模型自己的上一个动作造成。第一次只偏了 1 厘米，下一帧就可能变成示范里少见的局面；模型如果不能纠正，误差还会继续累积。

下一讲，我们就跟着这一次“偏了 1 厘米”的抓取继续分析：前一步的误差怎样改变下一帧画面，误差又为什么会越积越多。
