# 课程资料协作说明

> 状态：current
> 版本：0.1.0
> owner：CEO
> last_updated：2026-09-14
> source_of_truth：projects/research-center/courses/AGENTS.md

本目录集中保存正在学习的 AI 课程原文。每门课程一个目录，章节按篇单独存放。课程索引和收录状态以 [README.md](./README.md) 为准。

## 基本规则

- 默认使用中文；行业常用英文专有名词（如 Harness、Agent、Skill）可保留，首次出现时补中文解释。
- 课程原文保留来源属性。作者的观点、案例和数据是课程事实，不改成研究中心的结论。
- 个人批注、理解和待验证问题写在对应章节文件内，用 `> 我的笔记：` 标识，与原文区分。
- 不预先创建未发布或未收录的章节文件。
- 课程带来的行动想法进入对应项目的 `tasks/`、`specs/` 或 `delivery/`，不写回课程原文。

## 单门课程结构

```text
课程名/
  00｜章节标题-课程名-平台.md
  01｜章节标题-课程名-平台.md
  配套课件.pdf    # 可选，保留原文件
  课程信息.md     # 可选：讲师、平台、链接、学习进度、版权备注
```

- 章节文件名沿用 `序号｜标题-课程名-平台.md` 格式，数字与课程目录对齐。
- 用 Obsidian 转存插件导入后，删除正文前的课程页 UI（学习人数、目录、时长、播放控件等），从 `<audio>` / `<video>` 标签或第一个正文段落开始保留。
- 录音转写稿保留原样，不把识别结果改写为课程事实。

## 入库边界

- 加密媒体缓存（`*.sz`）、视频（`*.mp4`）、压缩包（`*.zip`）体积大且可重新下载，只留本地，不入库（见 `.gitignore`）。
- 配套代码若为独立 Git 仓库（如 CodexFDE），本地保留，不入库。
- 网盘占位文件（macOS 上 `ls -lO` 显示 `dataless`）内容未落地，不计入收录数；需先在网盘客户端下载落地，再补提交。

## Git 子模块

`HA7CH-AI-Native-School/` 是上游 GitHub 仓库的 Git 子模块（跟踪 `master`），更新命令见 [README.md](./README.md) 的“外部课程仓库的更新”。父仓库只记录子模块提交指针，更新后须提交父仓库。

## 内容流转

```text
课程章节原文与个人批注
  -> 需要正式研究：进入 research/
  -> 需要作为来源：进入 kb/sources/ai/
  -> 证据充分、经确认：进入 kb/atoms/ai/ 和 kb/wiki/ai/
  -> 明确行动：进入具体业务项目
```

- 不因内容出自课程而直接进入 `kb/`。
- 已有同主题 wiki 时，把课程当作补充来源链接进去，不建平行结论。
- 收录状态变化（完结、新增篇数）时同步更新 README 索引表。
