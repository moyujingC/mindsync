# 第 45 课代码说明：生产交付与上线边界

本课不新增 Agent 能力，复用第 41 课综合演练版：

```text
code/agent-course-versions/lesson-41-final-rehearsal/backend/
```

这里关注的不是“再加一个功能”，而是把能不能交付说清楚：灰度、回滚、兜底转人工、验收证据和风险清单。

## 本课验证材料

```text
production_delivery_checklist.json
```

你可以把 `production_delivery_checklist.json` 当作交付前自查表，重点看两件事：

- 交付清单里是否包含上线边界、验收证据、回滚和转人工策略。
- 第 41 课 `/eval/run` 的大促回归场景是否仍然全部通过。
- 再用 `电子发票通常多久能准备好？` 这类 FAQ 问题观察模型调用证据：有模型配置时，路由模型和最终话术模型参与；没有配置时，系统要明确降级，而不是伪装成模型成功。

## 没有提前做的能力

- 不创建真实发布平台。
- 不做自动灰度控制器。
- 不接入真实客服工单或告警系统。
- 不承诺 Agent 可以无人值守处理资金动作。
