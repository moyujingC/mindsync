## 课程介绍

2026 年 8 月，DeepSeek 面向全球开发者开放了 DeepSeek Harness 开发者预览版 v0.1，并同步以 MIT 协议开放源代码。这是 Agent 开发领域的一个重要信号——Harness 解决的核心问题，是让 Agent 真正进入项目、调用工具、使用插件，并完成一套完整的工作流。  
但刚接触这个项目，很多开发者都会面临同一个问题：到底从哪里开始？源码信息量太大，文档分散，从零摸索成本高。  
极客时间教研组连夜整理了这份《DeepSeek Harness 极简入门》，不堆理论、不啃源码，带你从安装到实战，亲手跑通一遍，真正理解 Harness 在 Agent 开发里解决什么问题。

**课程亮点**

- 极简上手：从 0 开始，不需要先研究一堆源码，先把基本玩法跑通
- 完整链路：装 Harness → 配模型 → 换 Agent → 加插件 → 自己做 Agent → 让 Agent 独立完成项目维护
- 实战导向：最后一节课让自定义 Agent 独立完成一次项目维护，学完即用
- 开源教程，免费领取
