## 课程介绍

## 为什么做这门课？

AI 工程化浪潮中，开发者普遍陷入一个矛盾循环：每天都在学习新框架、追新产品，但遇到真实业务需求时，依然不知道选什么、怎么搭、如何交付。  
想跳出这个怪圈，缺少的是一套“即学即用”的脚手架实战体系，能把前沿框架直接映射到业务实现现场。这门课真正想做的，就是从纷繁复杂的 Agent 开发生态中，精选四套自带 Harness 能力的生产级脚手架，结合四个真实业务场景的完整项目，沉淀出一套 " 场景→框架→代码→交付 " 的实战方法论，帮助开发者在 AI 工程实践中快速选型、高效落地，不再做疲于追赶的旁观者。

## 这门课教什么？

课程围绕四套前沿 Harness 脚手架与四个生产级项目展开。课程精心设计了以下篇章：  
![](https://static001.geekbang.org/resource/image/7a/dc/7aea2eb3fa695f2e847d0687f4bb82dc.jpg?wh=2726x1887)

- **快速交付篇（Smolagents）：** 通过 CodeAct 代码执行范式，实现 CSV 数据洞察 Agent。你将掌握如何用哪个这个核心代码仅千行的轻量级框架，告别“问一句→调一次→等结果”的低效循环，实现端到端自动化的数据处理 Agent。
- **进阶应用篇 & 深度编排篇（Claude Agent SDK）：** 利用自动上下文压缩机制、SubAgent 机制与 Skills 技能固化，来实现金融研报生成 Agent；之后还会挑战多任务协同投研平台，借助 Fork 分叉机制和 Hooks 安全护栏，攻克长链路上下文管理、多文档交叉验证与并行分支探索等难题，同时接入 OpenTelemetry 实现全链路成本监控。
- **知识沉淀篇（DeepAgents）：** 掌握 DeepAgents 框架，作为 LangChain 技术栈的全面进化版，它融入上下文管理、安全沙箱、文件系统、Skills 及子 Agent 等完整 Harness 模块。这个篇章里，我们将实现 LLM-Wiki 智能知识库，把“自进化”理念封装为 Agent Skills，让知识库具备自动沉淀、结构化更新与深度问答的能力。
- **工程交付篇（Pi-mono）：** TypeScript 生态中难得一见的全功能 Harness 脚手架。我们将构建合同审查助手 Runtime，借助分层架构实现多模型抽象，通过多层安全拦截管道保障权限校验与合规审查，并利用 ChatPanel 组件让审查报告可交互展示。  
	每个篇章都有源码剖析与完整工程实现，让你快速上手这四套主流 Agent 开发框架，成长为能快速交付生产级 Agent 的工程实践者 / 达人。

## 学完课程有哪些收获？

- **一套“场景→框架”的选型方法论。** 以后再遇到新业务，你不再需要在各个框架的文档之间反复横跳、纠结选型，而是能快速判断：这个场景适合轻量的 CodeAct 方案，还是需要 Claude SDK 的深度编排，抑或是需要统一 LangChain 技术栈的 DeepAgents，又或者因 TypeScript 栈而选择 Pi-Mono。
- **四个即学即用的实战项目。** CSV 数据洞察助手、多任务协同投研平台、LLM-Wiki 智能知识库、合同审查助手 Runtime，每一份项目配套的代码都是能够供你参考、二开的真实资产。
- **沉浸式的项目演练体验。** 所有的知识点服务于实战项目，而项目里凝聚了数据洞察、研报生成、知识库进化、合规审查等典型业务痛点的解决方案。你跟着走一遍，就等于亲自踩过了这些坑，下次遇到类似问题，你知道怎么拆、怎么选、怎么交付。

AI 应用开发这个领域变化太快，没人能保证你学完就成专家。但如果你能把这四个脚手架用起来，并且踏踏实实把课程中的四个项目亲自动手操练一遍，至少能让你具备快速实现生产级 Agent 的工程水平。
