本节摘要

每天早上打开手机，AI 领域又有了新动态——新模型发布、开源项目爆火、技术方向突破……你想跟上节奏，但信息源太多太散，光刷资讯就要花半小时。

但如果有个工具，一个命令就能自动抓取、去重、排版，直接给你生成一份赛博朋克风格的每日 AI 资讯页面呢？

这节课教你打造一个专属的 AI 日报机器人。5 分钟搞定原来要花半小时的信息整理工作。

## 痛点场景：信息焦虑的真实困境

相信我，这种痛苦你一定经历过：早上到公司，泡杯咖啡，打开电脑——AIBase 有新文章，36Kr 有深度报道，量子位有快讯，机器之心有技术分析……一个一个网站看过去，光打开和加载就要花几分钟。然后微信群里又有人分享了链接，Telegram 频道里又刷出十几条消息，推特上又有人讨论……

半小时过去了，你发现真正有用的信息可能就两三条。

传统获取 AI 资讯的方式，问题我总结了三个：

**第一，信息源分散。** 同一个新闻，AIBase 发了一遍，36Kr 又发了一遍，量子位也发了一遍。你看了三遍，才发现是同一件事。

**第二，筛选效率低。** 80% 的内容是噪音，只有 20% 是真正有用的信息。但你得把 100% 的内容都看完，才能找出那 20%。

**第三，整理耗时。** 即使你手动收集了有用的信息，整理成结构化的内容又是一项工作。复制标题、写摘要、贴链接、打标签……又花了半小时。

而且最可怕的是： **这套流程每天都要重复一遍。** 像个机器人一样，日复一日地刷网站、筛信息、整理内容。

AI 日报 Skill 要解决的就是这个问题。

**把「信息获取 → 筛选整理 → 可视化展示」三步流程自动化。**

你可以把它理解为一个 AI 资讯助手。你说：“获取今天的 AI 新闻。”它自动去各大网站抓取最新资讯，去除重复内容，生成一份精美的展示页面。

## 前置知识：认识 Agent Browser

在拆解提示词之前，需要先了解一个关键工具——Agent Browser。

它是一个浏览器自动化工具，可以让 AI 像人一样操作浏览器——打开网页、点击按钮、提取内容。

简单理解：Claude Code 是大脑，Agent Browser 是手和眼睛。

Claude Code 负责「怎么分析」，Agent Browser 负责「怎么看网页」。

对于我们这个 Skill 来说，它扮演的角色就是“数据采集员”。

### 安装步骤

只需要两步：

第一步：安装 Agent Browser CLI

复制代码

```bash
npm install -g agent-browser

agent-browser install
```

第二步：将它注册为 Claude Code 的 Skill

复制代码

```bash
npx skills add vercel-labs/agent-browser --skill agent-browser
```

安装完成后，Claude Code 就有了浏览器操作能力。不需要你写任何浏览器操作代码，底层的工作 Agent Browser 已经封装好了。

## Prompt 深度拆解：两段式流水线

我设计的提示词采用了「两段式流水线」结构：

复制代码

```
┌──────────────────────────────────────────┐

│  第一段：数据获取                         │

│  —— 告诉 Claude " 去哪里抓，抓什么格式 "      │

├──────────────────────────────────────────┤

│  第二段：展示生成                         │

│  —— 告诉 Claude " 用什么风格展示 "            │

└──────────────────────────────────────────┘
```

这种结构的好处是 **解耦** ——数据源可以随时替换，展示风格可以独立调整。

比如明天你想换成抓前端技术新闻，只需要改第一段的 URL，第二段的展示完全不用动。

### 第一段：数据获取

这是整个 Skill 的核心—— **如何高效、准确地从网页中提取资讯数据。**

提示词要求 Agent Browser 分别访问两个数据源：AIBase 和 36Kr 的 AI 频道。然后把抓到的内容整理成 JSON 格式，包含标题、摘要、链接和标签。

**设计思路 1：多数据源策略**

注意看！为什么选这两个数据源？

AIBase，专注 AI 领域的资讯平台，内容垂直、更新快。

36Kr AI 频道，科技领域综合媒体，覆盖面广、有深度报道。

两个数据源互补，一个垂直深耕，一个横向覆盖——确保资讯的全面性。

**设计思路 2：JS 变量输出 + 数据模板分离**

要求输出 JS 变量文件而不是自由文本，有三个好处：

第一，机器可解析，HTML 页面通过 `<script src>` 引入数据，直接读取 `NEWS_DATA` 变量。

第二，字段约束，通过固定字段确保数据完整性。

第三，质量控制，description 限制 80 字，迫使 AI 做信息提炼，而不是照搬原文。

而且数据文件和展示页面是 **完全分离的** ——HTML 页面通过 `<script src>` 引入数据文件，你可以单独更新数据而不动页面，也可以单独调样式而不动数据。

**设计思路 3：五条防护栏**

这是重点！提示词中还包含了五条关键约束条件：

复制代码

```markdown
1. 双引号必须转义 → 防止 JS 语法错误

2. 网站挂了就跳过 → 容错降级策略

3. 每个源至少 5 条，总计 15-20 条 → 数量控制

4. 去除重复资讯 → 自动去重

5. 链接不完整就补全 → 自动补全域名
```

这五条防护栏的思路适用于所有需要「从网页抓取数据」的 Skill。你在设计自己的数据采集 Skill 时，也应该加上类似的约束。

### 第二段：展示生成

数据抓取完成后，需要把它转化为可视化的展示页面。

提示词里明确了几项要求：赛博朋克风格、卡片式布局、响应式设计，还要包含日期和资讯条数信息。

为什么要用赛博朋克风格？因为这和 AI 技术的调性天然匹配——深色背景、霓虹绿光、终端窗口风格，营造出「AI 正在为你工作」的科技感。

由于我们已经有完整的设计规范，Skill 会自动应用这套规范：

- 深黑背景配霓虹绿强调色
- JetBrains Mono 代码字体
- 终端风格卡片、标签系统
- 淡入揭示、光标闪烁、悬停光晕等动画效果
- 响应式设计，手机和电脑都能正常浏览
- 数据与模板分离，通过 `<script src>` 引入数据文件

## 实操演示：真实案例

### 环境准备

现在到了最激动人心的环节，实际运行这个 Skill。

确保你已完成三件事：

1. 安装了 Claude Code
2. 安装了 Agent Browser
3. 注册了 Agent Browser Skill

### Skill 演示

**第一步：创建 Skill**

使用 skill-creator，将提示词交给 AI：

复制代码

```
/skill-creator

 

使用 skill-creator 创建一个 AI 资讯 Skill，用于获取每日最新的 AI 资讯

[粘贴完整的提示词]

请将该 Skill 保存到当前工作目录.claude/skills 下
```

等待生成完成。SKILL.md 文件会保存在 `.claude/skills/` 目录下。

**第二步：运行 Skill**

复制代码

```
使用 AI 资讯 Skill，获取今天的 AI 新闻
```

Skill 会自动开始工作：

数据采集：

复制代码

```
[Agent Browser] 正在访问 https://www.aibase.com/zh/news ...

[Agent Browser] 页面加载完成，开始提取资讯

[Agent Browser] 已提取 8 条资讯

[Agent Browser] 正在访问 https://www.36kr.com/information/AI/ ...

[Agent Browser] 页面加载完成，开始提取资讯

[Agent Browser] 已提取 12 条资讯
```

数据清洗与去重：

复制代码

```
[数据处理] 合并两个数据源，共 20 条资讯

[去重处理] 识别到 3 条重复资讯，已去除

[最终数据] 共 17 条精选 AI 资讯
```

生成展示页面：

复制代码

```
[页面生成] 应用赛博朋克风格设计规范

[页面生成] 生成 HTML 文件：ai-news.html
```

### 执行结果

最终我们得到两个文件：

1. **ai-news-data.js** ：结构化的资讯数据，JS 变量格式，17 条精选 AI 资讯
2. **ai-news.html** ：赛博朋克风格的展示页面，通过 `<script src>` 引入数据文件，实现数据与模板分离

打开 HTML 文件，你会看到一个深色背景的前端页面：

- 顶部是标题栏，显示 AI Daily News、当前日期和资讯条数
- 下方是资讯卡片网格，每张卡片包含标题、摘要、标签和原文链接
- 标题带绿色发光效果，卡片有悬停光晕动画
- 点击蓝色链接可以直接跳转到原文

整个流程从输入命令到生成页面，全自动完成。

原来要花 30-60 分钟的信息收集和整理工作，现在一个命令搞定。

这就是自动化的力量！

## 避坑指南

注意！任何工具都有边界，用错了会翻车。

### 坑 1：网站改版导致抓取失败

**【避坑指南】**  
AIBase 或 36Kr 改版后，页面结构变了，Agent Browser 可能无法正确提取内容。

**【解决方案】**  
Skill 内置了容错降级策略，一个网站失败不影响另一个。如果两个都失败，尝试替换数据源 URL。

### 坑 2：JSON 格式错误

**【避坑指南】**  
AI 生成的 JS 数据文件偶尔会有格式错误，比如双引号没转义、缺少逗号。

**【解决方案】**  
可以在提示词中增加一条校验步骤：

复制代码

```
生成 JS 文件后，请自行检查语法是否正确。如有错误，自动修复后再输出。
```

### 坑 3：Agent Browser 安装失败

**【避坑指南】**  
在某些系统上，Chromium 下载可能会超时。

**【解决方案】**  
确保网络环境能访问 npm 和 Chromium 下载地址。如果下载超时，可以配置代理。Windows 用户建议在管理员权限的终端中执行安装。

### 坑 4：反爬机制拦截

**【避坑指南】**  
某些网站有反爬机制，可能导致 Agent Browser 被拦截。

**【解决方案】**  
优先选择反爬力度较小的资讯平台。如果某个网站持续被拦截，直接换成其他同类网站。

### 坑 5：资讯质量参差不齐

**【避坑指南】**  
抓到的资讯里可能有广告、软文、标题党。

**【解决方案】**  
在提示词中增加质量过滤条件，比如：

复制代码

```asciidoc
过滤规则：去除以下类型的资讯

- 纯广告推广内容

- 标题党（标题与内容严重不符）

- 字数少于 100 字的短讯
```

还可以增加一个“可信度评分”字段，让 AI 对每条资讯打分。

## 总结

让我们回顾一下今天学到的：

1. **痛点价值** ：信息分散、筛选低效、整理耗时——自动化是唯一出路
2. **关键工具** ：Agent Browser 让 Claude Code 具备了浏览器操作能力
3. **两段式架构** ：数据获取加展示生成，数据与模板分离，灵活替换
4. **五条防护栏** ：转义、容错、数量控制、去重、补全——确保数据采集的鲁棒性
