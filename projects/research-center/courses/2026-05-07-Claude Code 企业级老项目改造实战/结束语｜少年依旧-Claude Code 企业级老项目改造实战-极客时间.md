你好，我是 Robert。

这门课到这里就结束了，很高兴遇见你。

33 讲一路走过来，你应该已经摸到了那一套体系。开篇词里我说过，Claude Code 改老项目这件事，差的不是 AI，差的是用法，大部分人还没把这个体系用起来。

整门课带你走过了三种形式：公司内的老代码、基于开源做需求、给陌生开源项目贡献代码。三种形式背后是同一套方法论，你已经在三个不同的载体上都跑过一遍。

但这不是这门课真正想告诉你的。

Claude Code 是工具，工具会迭代、会被替代，也许两年后有更好的东西出现，今天的提示词模板大半都得重写。

这门课你真正学到的，是工具背后的几样东西：

面对陌生代码的判断力。拿到一个跑了几年、文档稀缺、原作者早就离开的老项目，你知道怎么用四维度框架快速建立顶层认知，知道哪些事让 AI 帮你做、哪些事必须自己读代码确认。这个能力换任何 AI 编程工具，你都能用。

对方向的判断力。AI 给你 80 分初稿，你要做的不是改成 95 分，是先判断这个初稿有没有建立在对的方向上。25 讲那个“路径选对了吗”的反问，30 讲挑项目的三道题，31 讲挑 issue 的三条标准，本质上都是同一件事：关键决策点不能让 AI 替你拍。

对边界的判断力。哪些事大量交给 Claude Code，哪些事必须自己兜底。写代码、跑测试、补文档，AI 比你快得多，但 review 别人的代码、跟 Maintainer 沟通、长期跟踪一个 issue，这些事换 AI 反而做不好。让 Claude Code 加速产出，把时间投在它替代不了的事上，这是这门课最值钱的工作姿势。

长期主义。这是这门课最不容易学到的一条，也是最值钱的一条。开源不是技术比赛，是耐心比赛。老项目改造也是这样。频次大于单次重量，3 个月、6 个月、1 年后回头看，你拿到的不是某一次惊艳的产出，是一种慢慢沉淀出来的能力。

AI 时代，一切都很快。新工具每周都在出，新框架每月都在更新，新概念每天都在刷屏。AI 编程相关的内容多到看不完，焦虑很正常。我自己也焦虑过，看到同行用一个新工具做出东西，心里就乱，想立刻试一试。

但你回头看这门课跑过的所有东西。摸一个陌生项目的顶层认知，要花几天来建立。第一次翻译跑出来的方案，要停下来反问“路径选对了吗”。第二个 PR 提之前，要先做一份针对找 issue 任务的项目地图。一个 Contributor 身份，要持续提 PR 几年才能慢慢长出来。真正有价值的东西，都是慢慢长出来的。

快的是 Claude Code 的执行速度，慢的是你对一个领域的理解、对一个方向的判断、对一套工作姿势的内化。前者 AI 可以给你，后者只有你自己能积累。

不必焦虑。在一个什么都快的时代，能慢下来、能坚持、能在一件事上持续深耕的工程师，反而越来越稀缺。AI 替代不了坚持，替代不了你跟一个项目相处几年的体感，替代不了你在无数个细节里磨出来的判断力。

去把这门课带回你自己的项目吧。可能是你公司里那个跑了几年没人愿意碰的老系统，可能是你早就关注但一直没勇气提 PR 的那个开源项目。这门课给了你方法，Claude Code 给了你加速，但最终走完全程的是你自己。

少年依旧，不是一种状态，是一个选择。这个选择，你可以每天做一次。

谢谢你看到这里，很高兴能有机会跟你分享我这些年踩过的坑、思考过的事。

AI 真好玩，编程真好玩，这一行能做很多有意思的事情。希望你在编程的旅途里，常常感受到这种快乐！
