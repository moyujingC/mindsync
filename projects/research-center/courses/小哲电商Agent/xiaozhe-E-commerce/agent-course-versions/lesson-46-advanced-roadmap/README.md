# 第 46 课材料：生产增强路线图与项目收束

本课不新增 Agent 后端。它是在第 41 课综合演练版已经能跑通后，整理“还能怎么继续变强”的生产增强路线图，并把小哲电商客服 Agent 收束成简历和项目答辩里能使用的完整工程能力材料。

## 材料文件

```text
advanced_roadmap.json
project_wrap_up.json
```

`advanced_roadmap.json` 描述生产增强方向、适用场景、取舍和排期层次，不把高级能力硬塞进当前 Agent 主链路。

本课还要明确运营侧下一步能提升什么：活动规则运营、售后政策运营、知识质检、反馈闭环、成本与人效运营、权限与审计。它们是小哲电商公司生产运营体系里的增强能力，不是第 41 课共享 Agent 后端要继续堆进去的聊天链路功能。

`project_wrap_up.json` 把项目亮点、完整工程能力、成长路线和全课收束整理成结构化材料。

## 覆盖方向

- 知识运营后台
- RAG Fusion
- 多知识库与权限过滤
- 完整 BM25 / ES
- ANN 深入
- 缓存与成本优化
- 反馈闭环与 RLHF 边界
- Subagents

## 路线图阶段

- 下一阶段可落地：知识运营后台、政策版本发布、质检工作台、反馈闭环、成本与缓存治理、多知识库与权限过滤。
- 更长期方向：RAG Fusion、完整 BM25 / ES、ANN 深入、Subagents、RLHF 或偏好数据训练。

## 没有提前做的能力

- 不创建知识运营后台。
- 不接入 ES、向量数据库集群或 ANN 基础设施。
- 不训练 RLHF 模型。
- 不把 Subagents 写进当前客服 Agent 主链路。
- 不新增第 41 课共享 Agent 之外的后端实现。

## 使用方式

本课是材料课，不新增可启动的 Agent 后端，也不要求在本目录执行 `python main.py`。

阅读 `advanced_roadmap.json` 时，重点看每个增强方向解决什么问题、适合放在哪个阶段、为什么没有硬塞进当前客服 Agent 主链路。

阅读 `project_wrap_up.json` 时，重点看项目亮点、工程能力和答辩表达如何从第 41 课已经跑通的综合版中归纳出来。

如果需要回看运行证据，请启动第 41 课综合演练后端，并用调试后台或 `/eval/run` 观察 Tool、RAG、Workflow、HITL、Trace、Evaluation 和 Cost 的完整链路。
