这份题库把 AI Agent 基础通识课和“小哲电商 Agent 生死局”故事课串成一套面试准备材料。基础课部分回答通用知识点，故事课部分回答项目实现、架构取舍、生产边界和答辩追问。 使用时不要死背名词，也不要假设面试官看过项目代码。面试官通常只能根据你的描述继续追问，所以回答要先把项目背景讲清楚，再展开知识点和工程经验。 每道题都按四个层次准备： 1. 先补背景：这是一个小哲电商客服 / 售后 Agent，面向订单物流、商品咨询、售后政策和退款退货等场景。 2. 再说概念：这个能力解决什么问题。 3. 再说工程机制：系统里怎样落地，为什么这样拆。 4. 最后说项目证据：用一个具体业务场景说明它怎么生效，比如物流查 Tool、政策查 RAG、退款进 workflow / HITL、trace / eval 验证路径。 回答时第一次提到内部名词要顺手解释，例如 `/chat` 是 Agent 服务入口，RoutePlan 是本轮请求的路径计划，Trace 是公开执行证据链。不要直接说“第几课讲了什么”或“代码里是这样写的”，要翻译成面试官听得懂的业务问题、设计取舍、踩坑和后果。
