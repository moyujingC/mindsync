第 18 讲我们已经得到了可重放的回测轨迹，这节课要回答一个更难的问题：这些数字能不能被相信。收益率最高不等于策略最好，所以我们的目标不是让 Codex 宣布“哪个策略最好”，而是让每个判断都能回到样本、计算口径、命令和输出。

一份合格的绩效解释，必须同时说明收益、回撤、风险调整和多次试验后的可信度。所以从这一讲开始，绩效评估不再是“看一个漂亮数字”，而是建立一套证据契约：先确认数据和路径，再解释指标，最后才比较策略。

需要注意的是，本讲使用固定的离线教学样本，复核收益、最大回撤、夏普比率（Sharpe Ratio）、卡玛比率（Calmar Ratio）、概率夏普比率（PSR）与修正夏普比率（DSR），所有结论都只针对离线教学样本，不代表未来收益。

## 1\. 绩效评估的证据契约

绩效评估不能从排行榜开始，而要从证据边界开始。单独看收益率很容易误导：一条策略赚了 30%，但中途经历 60% 最大回撤；另一条策略只赚 5%，但回撤显著更低。前者可能只是高波动或运气，后者可能更适合继续做稳健性检查。

外部资料提供的是口径，而不是装饰性术语。夏普比率强调单位风险上的超额收益；最大回撤强调从历史峰值到后续谷值的样本内路径损失；卡玛比率和 MAR 比率把收益放到最大回撤代价旁边阅读；修正夏普比率提醒多次试验和非正态收益会让漂亮的夏普比率偏乐观；回测过拟合概率（PBO）和组合对称交叉验证（CSCV）则把“挑冠军”本身当成需要审计的风险。

把这些口径落到本仓库，绩效解释要遵守四条硬规则：

任何绩效指标必须写清输入序列、时间频率、样本长度和成本假设。

任何收益结论必须同时报告最大回撤、交易次数和风险调整指标。

任何多策略或多参数比较必须报告试验次数，不能只展示被挑出来的冠军。

任何统计显著性表述都必须降级为“样本内证据”，不能写成未来收益承诺。

这些指标分别压缩权益路径的不同侧面。总收益只关心起点和终点；最大回撤关心从历史峰值到后续低点的最坏路径；夏普比率把逐期收益均值和波动放到同一尺度；卡玛比率把收益与最大回撤直接相除；PSR / DSR 进一步追问“这个夏普比率是否经得起样本长度、非正态收益和多次试验的审计”。

因此，本讲的第一条规则是：指标必须按证据层级阅读，而不是按排名阅读。先确认权益路径是否由真实成交和成本假设生成，再从权益路径推导收益、回撤和逐期收益，最后才比较不同策略的排序。表 19-2 把这条规则落到仓库对象、可生成指标和 Codex 复核动作上。

## 2\. 权益路径、回撤与卡玛比率

收益只告诉最终结果，权益路径才显示过程中的压力。下面我们会把绩效解释从“最终赚了多少”转向“中间经历了什么”：最大回撤、恢复时间和卡玛比率都来自同一条权益路径，不能从不同报告片段里拼接。

### 2.1 从权益曲线复算最大回撤

最大回撤和卡玛比率是最适合训练“路径复核”的两个指标。它们的计算并不复杂，却能立刻暴露很多报告问题：收益和回撤是否来自同一条权益曲线，回撤符号约定是否一致，图上的谷值是否能被函数复算出来。代码 19-1 展示 src/backtest/runner.py 中的最大回撤口径。

def maximum\_drawdown(equity: list\[float\]) -> float:

peak = equity\[0\]

worst = 0.0

for value in equity:

peak = max(peak, value)

worst = min(worst, value / peak - 1)

return worst

卡玛比率的解释方式很直接：同样 10% 收益，最大回撤 5% 和最大回撤 25% 是两种完全不同的风险代价。但卡玛比率不能单独作为批准按钮：

课程中为了和当前样本报告保持一致，使用总收益除以最大回撤绝对值，但许多资产管理语境会使用年化收益除以最大回撤，跨系统比较时必须先写清口径。

最大回撤只记录样本内已经发生过的最坏峰谷差，不等于未来最大亏损上限。

最大回撤对路径非常敏感。两个策略最终收益相同，只要一个先涨后跌、另一个先跌后涨，最大回撤就可能完全不同。

最大回撤还要和“恢复时间”一起读。两个策略的最大回撤都可能是 20%，但一个三天后修复，另一个长期停留在水下，研究含义完全不同。本仓库当前没有单独实现水下持续时间（underwater duration），但可以在绩效卡里保留字段：峰值日期、谷值日期、恢复日期、未恢复标记。这样后续扩展时，不必重写绩效解释逻辑。

在本仓库里，Codex 复核卡玛比率时要做三件事。

先检查 maximum\_drawdown\_pct 的符号约定：报告里通常是正数百分比或负数跌幅，进入 calmar\_ratio() 时必须确认是否取绝对值。

再检查收益和回撤是否来自同一条权益曲线，不能把策略收益和买入持有回撤混用。

最后检查图 19-1 的回撤谷值是否能被公式复算出来，如果图和函数输出不一致，优先相信可复算路径。

最后，再强调一下容易被忽略的细节：卡玛比率、回撤收益比（Return over Maximum Drawdown, RoMaD）、MAR 比率这类指标，都把收益和最大回撤放在同一个框架里，但分子不一定相同。有的用总收益，有的用年化收益，有的用三年窗口，有的用成立以来窗口。因此本讲只允许说“教学口径下的卡玛比率”，不能把它和外部基金报告里的卡玛比率直接比较。跨系统比较前，必须先补齐三项口径：收益是否年化、回撤窗口多长、最大回撤以正数还是负数记录。

## 3\. 夏普比率、PSR 与 DSR 审计

风险调整指标的作用，是把收益放回波动、样本长度和试验次数中阅读。

### 3.1 夏普比率的输入与边界

夏普比率把收益和波动放到同一口径里。它的共同前提是收益序列、样本长度和年化频率必须清楚，否则再精致的比率也只是漂亮数字。代码 19-3 来自 src/backtest/metrics.py：它先从权益序列计算逐期收益，再用日频 sqrt(365) 年化。

def sharpe\_ratio(

equity\_values: list\[float\],

\*,

periods\_per\_year: int = 365,

) -> float:

if len(equity\_values) < 2:

return 0.0

returns = \[

equity\_values\[index\] / equity\_values\[index - 1\] - 1

for index in range(1, len(equity\_values))

\]

if len(returns) < 2:

return 0.0

mean\_r = sum(returns) / len(returns)

variance = sum((value - mean\_r) \*\* 2 for value in returns) / (len(returns) - 1)

std\_r = math.sqrt(variance) if variance > 0 else 0.0

if std\_r == 0:

return 0.0

return (mean\_r / std\_r) \* math.sqrt(periods\_per\_year)

代码 19-3 从权益曲线计算夏普比率

在本仓库的最小实现里，示范样本暂时没有引入显式无风险收益，所以代码使用逐期权益收益的均值除以样本标准差，再按 periods\_per\_year 年化。这个简化适合我们的教学复核，但报告必须说明它的边界：如果数据频率是日线却按小时年化，夏普比率会被放大；如果收益序列存在极端尾部、非对称分布或连续缺口，标准差并不能完整代表风险；如果策略很少交易，夏普比率可能主要由少数持仓日决定。解释夏普比率时，至少要绑定表 19-4 中的辅助字段。

| 辅助字段 | 为什么必须一起看 | 本讲判断方式 |
| --- | --- | --- |
| periods\_per\_year | 年化倍数直接影响夏普比率 | 日频示范使用 365，跨市场需改成匹配频率 |
| total\_trades | 少数交易会让均值和波动不稳定 | 少于十几笔时只写描述，不写稳定优势 |
| max\_drawdown\_pct | 波动低不代表峰谷损失低 | 夏普比率高但回撤深，需要解释路径代价 |
| num\_trials | 多次调参会抬高被选中的夏普比率 | 进入 PSR/DSR 审计，而不是直接排名 |

表 19-4 夏普比率解释必须绑定的辅助字段

夏普比率的优点是简洁，缺点也来自简洁。它默认用标准差代表风险，因此上行波动和下行波动都被放进同一个分母；它对样本长度和极端值敏感；它还会被年化倍数放大。实务上常见的补充指标包括索提诺比率（Sortino Ratio）、欧米伽比率（Omega Ratio）、风险价值（Value at Risk, VaR）、预期损失（Expected Shortfall）以及收益偏度和峰度。

本仓库为了保持教学最小实现，没有在第 19 讲引入这些指标，但报告中应写明“未覆盖下行半方差和尾部损失”。这不是自曝短板，而是防止把夏普比率误读成完整风险审计。

### 3.2 用 PSR 与 DSR 处理显著性和多次试验

概率夏普比率（Probabilistic Sharpe Ratio，PSR）估计“真实夏普比率高于某个基准”的概率。修正夏普比率（Deflated Sharpe Ratio，DSR）进一步考虑多次试验和非正态收益，惩罚回测过拟合和选择偏差。代码 19-4 展示 src/backtest/audit/dsr.py 的核心路径：先算 PSR，再估计多次试验后可能出现的最高夏普比率，最后用这个更高基准复算 DSR。

psr = probabilistic\_sharpe\_ratio(

observed\_sr,

benchmark\_sr,

sample\_length,

skewness=skewness,

excess\_kurtosis=excess\_kurtosis,

)

e\_max = expected\_max\_sharpe(num\_trials, variance\_of\_trials)

dsr = probabilistic\_sharpe\_ratio(

observed\_sr,

e\_max,

sample\_length,

skewness=skewness,

excess\_kurtosis=excess\_kurtosis,

)

代码 19-4 概率夏普比率（PSR）与修正夏普比率（DSR）的核心计算路径

这里的关键差别是：PSR 主要审计单条策略；DSR 审计“多次试验后挑出来的冠军”。如果研究者试了很多参数、很多规则、很多样本切法，被选出来的最高夏普比率本来就更容易偏高，因此基准夏普比率不能再固定为 0 或某个简单门槛，而要提高到“多次试验后本来就可能看到的最高夏普比率”。表 19-5 给出 PSR / DSR 在报告中可以写与不能写的边界。

| 场景 | 可以写 | 不能写 |
| --- | --- | --- |
| 单条策略、少量参数 | PSR 支持“样本内夏普比率高于基准的概率描述” | PSR 高，所以可以实盘 |
| 多策略比较后挑冠军 | 必须报告 num\_trials 和 DSR | 只展示冠军夏普比率 |
| 收益分布偏态或厚尾 | 说明偏度、峰度会影响显著性 | 假设收益正态且风险对称 |
| 试验记录缺失 | 把结论降级为探索性观察 | 写成已经通过统计审计 |

DSR 不是让研究停止的红灯，而是让结论降级的刹车。若 DSR 很低，可以继续做研究，但写法要从“策略有效”改为“样本内出现值得复查的现象”；下一步不是继续加参数，而是补试验日志、做滚动窗口、检查成本敏感性，并把第 20 讲的回测过拟合概率（PBO）和组合对称交叉验证（CSCV）审计接上。这样第 19 讲负责解释绩效，第 20 讲负责审计污染，两讲之间形成自然闭环。

## 4\. 多策略比较：从排名转向权衡

单策略指标只能回答“这条路径如何”，多策略比较才会暴露“不同目标之间如何取舍”。比较的目标不是挑出一个“最好”的名字，而是在同一样本、同一成本口径下，同时看收益冠军、回撤冠军和风险调整后的权衡。

### 4.2 读懂收益冠军、回撤冠军和权衡榜

本次在当前仓库中实际运行，输出为：

WEB3-DEMO/USDT 1day 120

ma\_crossover -8.09 12.68 -7.19 -0.64 4

boll\_mean\_reversion -5.82 11.47 -5.06 -0.51 4

rsi\_mean\_reversion -11.7 17.85 -4.66 -0.66 9

macd 19.78 25.62 2.53 0.77 30

buy\_and\_hold 20.16 32.77 2.7 0.62 27

highest\_return buy\_and\_hold

lowest\_drawdown boll\_mean\_reversion

这段输出有两个直接结论：收益冠军是 buy\_and\_hold，回撤最低的是 boll\_mean\_reversion，二者不是同一个策略。buy\_and\_hold 在当前样本中的总收益为 20.16%，最大回撤为 32.77%，夏普比率为 2.7，卡玛比率为 0.62，交易次数为 27；boll\_mean\_reversion 的最大回撤为 11.47%，但总收益为 -5.82%，夏普比率为 -5.06。因此不能简单写“买入持有最好”或“布林均值回归最好”，而要写成权衡：buy\_and\_hold 是固定教学样本的收益冠军，但承受了更深回撤；boll\_mean\_reversion 回撤较低，却没有给出正收益。

这个案例还可以再读深一层。macd 的收益为 19.78%，略低于 buy\_and\_hold 的 20.16%，但最大回撤为 25.62%，低于 buy\_and\_hold 的 32.77%，卡玛比率反而更高。这说明“收益冠军”和“更好的收益 / 回撤权衡”也不是同一个问题。如果作为教学演示，buy\_and\_hold 可以作为基准；如果是继续开发策略，macd 可能比单纯收益冠军更值得进入滚动窗口和成本敏感性检查；如果是控制回撤，boll\_mean\_reversion 虽然回撤最低，但负收益意味着还不能进入正向策略候选。

多策略比较至少要给出三个榜单：

| 榜单 | 排序字段 | 解释方式 |
| --- | --- | --- |
| 收益榜 | total\_return\_pct 降序 | 谁在样本内赚得最多 |
| 回撤榜 | max\_drawdown\_pct 升序 | 谁在样本内路径承压最小 |
| 权衡榜 | calmar\_ratio 或夏普比率 | 谁的收益与风险代价更协调 |
