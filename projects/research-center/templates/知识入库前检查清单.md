这份清单用于在执行 `knowledge-ingest` 之前，快速判断当前内容是否具备正式入知识库的资格。

适用链路：

`research-draft` -> `fact-check-note` -> `machine-review-note` -> `review-note` -> `knowledge-ingest`

## 1. 前置 artifact 检查

- [ ] 已存在正式 `research-draft`
- [ ] 已存在正式 `fact-check-note`
  - 已填写明确路径或链接，不能只写一句核查摘要
- [ ] 已存在正式 `machine-review-note`
  - 已填写明确路径或链接，不能只写一句 `pass`
- [ ] 已存在正式 `review-note`
  - 已填写明确路径或链接，不能只写一句 `approve_for_ingest`

## 2. 核查结果检查

- [ ] `fact-check-note` 已逐条拆分关键事实主张
- [ ] 不存在未处理的 `do_not_publish`
- [ ] `needs_source` 内容已删除或降级改写
- [ ] 核查结论不是“暂不进入 review”

## 3. 机器预审检查

- [ ] `machine-review-note` 的 `final_decision` 为 `pass`
- [ ] 不存在仍要求先改后审的阻塞项

## 4. Review 结果检查

- [ ] `review-note` 的 `final_decision` 为 `approve_for_ingest`
- [ ] 已明确允许入库的范围
- [ ] 已明确不允许入库的范围
- [ ] 不存在仍要求先修改再入库的阻塞项

## 5. 入库准备检查

- [ ] 知识条目已回链到原始研究文档
- [ ] 知识条目已回链到 `fact-check-note`
- [ ] 知识条目已回链到 `machine-review-note`
- [ ] 知识条目已回链到 `review-note`
- [ ] 当前内容具备长期复用价值，不是一次性状态记录
- [ ] 不存在“已核查/已审核通过”但无法追溯到正式 artifact 的表述

## 6. 结论

- 是否允许进入 `knowledge-ingest`：
  - 是 / 否
- 若否，退回阶段：
  - `research-draft` / `fact-check` / `machine-review` / `review`
