## v0.2 重排说明（CEO 评审意见的三处落实）

1. **自我疗愈概念提前**：L01 结尾即植入概念（「这些方法有一个共同的名字：自我疗愈」），L02 专节展开概念与边界。概念不再是隐含线索，而是第一章主线。
2. **第二、三章加厚**：静心章从 2 节扩到 4 节（日常化 / 身体-情绪 / 身体对话 / 初心，各配完整练习）；地图章从 2 节扩到 4 节（总览 + 书写与呼吸 / 冥想与身体 / 艺术疗愈与曼陀罗三组分讲），每组「是什么 + 什么状态下选 + 5 分钟小动作」。
3. **静心免费/付费再平衡**：免费段只保留静心入口（L03 误解破除 + 第一次呼吸练习），静心的主体内容（身体、初心、日常化方法）全部在付费段。付费段的静心内容占 4 节，是课程体系里被低估的付费价值。

## 内容量分配说明

- 第一章（3 节，免费）：点火器三章任务全部在免费段兑现——困扰共鸣与需求激活（L01）、概念植入（L01-L02）、第一次小练习（L03）。
- 静心章（4 节，付费）：静心校订版是全文素材中体量最大、完整度最高的来源；「对静心深入了解」是认知层获得感的主体，值得付费。
- 地图章（4 节，付费）：课1 的差异化承诺，分三组详解避免一节塞爆。
- 带练章（4 节，付费）：对应已定案的 4 次练习结构（方案乙：L12 轻量进入 → L15 综合深练收尾）。
- 收尾（1 节）：练习记录整理 + 地图对照 + 后续路径。

## 免费/付费切分建议（v0.2）

**建议：L01-L03 免费，L04 起付费。**

理由（按输入包判定标准逐条对照）：

1. **免费部分独立完成"需求激活 + 概念植入"**：L01-L02 完成前两条点火器任务，L03 带练专注呼吸完成"第一次小练习"。三条全部兑现，且兑现得比 v0.1 更完整（概念有专节）。
2. **切分点落在"想要更多"的心理位置**：L04 起是静心的深化（日常化、身体、初心），其后还有地图和全部曼陀罗带练，付费理由层层递进。
3. **免费段是完整成立的获客内容**：困扰共鸣 → 概念 → 破误解 → 5 分钟呼吸练习，独立看是一门完整的「自我疗愈初体验」小课。
4. **付费占比**：16 节中 13 节付费（81%），且付费段含静心主体、全部地图详解和全部曼陀罗带练——付费学员感到"免费只是引子"；免费学员拿到了概念和可独立使用的练习，不觉得被欺骗。

备选切分点：L01-L04 免费。启用条件同 v0.1（数据显示 L03 流失且原因是"还没体验到价值"）；首发不建议，身体感知（L05）是付费后的第一个惊喜点。
