## 内容量分配说明

- 底座层（静心）：L01-L05，5 节。静心校订版是全文素材中体量最大、完整度最高的来源，且「认知层获得感」要求对静心有深入了解，分配近半课时。
- 地图层：L06-L07，2 节。地图是课1 的差异化承诺，独立成章但控制在 2 节，避免课变成"工具百科"。
- 带练层：L08-L11，4 节，对应已定案的 4 次练习结构（默认方案乙：前轻后重，L11 综合深练收尾）。
- 首尾各 1 节：L01 负责点火器开场（困扰共鸣 + 到达状态采集 + 免责声明），L12 负责获得感收口（练习记录 + 地图对照 + 后续路径）。

## 免费/付费切分建议

**建议：L01-L03 免费，L04 起付费。**

理由（按输入包判定标准逐条对照）：

1. **免费部分独立完成"需求激活 + 概念植入"**：L01 让学员确认"我的困扰属于自我疗愈范围"，L02-L03 完成静心概念植入并带练专注呼吸（第一次小练习）。三条点火器任务在免费段全部兑现。
2. **切分点落在"想要更多"的心理位置**：身体感知（L04）是静心体验的加深，地图（L06）和曼陀罗带练（L08-L11）是明确的新内容，付费理由充足。
3. **免费段是完整成立的获客内容**：困扰共鸣 → 破误解 → 5 分钟练习，单独看是一篇完整的"静心入门"小课，不是付费内容的缩水试读。
4. **付费占比**：12 节中 9 节付费（75%），且付费部分含全部曼陀罗带练和地图——付费学员感到"免费只是冰山一角"；免费学员拿到了可独立使用的练习，不觉得被欺骗。

备选切分点：L01-L04 免费（把身体感知也放进免费段）。只建议在一个条件下采用——如果上线后数据显示大量用户在 L03 流失且流失原因指向"还没体验到价值"。首发不建议，因为身体感知是付费后的第一个"惊喜点"，放免费会削弱付费动机。
