## 课1 案例选用四标准（2026-09-28 定，后续选用沿用）

1. **高频**：市场层频率靠前（43 则案例分布 + 后续搜索词数据）
2. **当下可认领**：症状粒度——学员看到会认"说的就是我"，不是模式标签
3. **5 分钟可兑现**：课1 承诺自我处理，选的痛点必须有小动作真能接上；5 分钟解决不了的深层模式（讨好、关系创伤）课1 只负责"看见"，纵深留给课2
4. **可复用**：虚构复合体可改写进自媒体——选用案例同时是该痛点的"标准示范行"，三产品线共用（见 docs/2026-09-28-痛点全景-状态体系-课程体系三层关系.md）
