这份材料是给 `AI 师傅` 的财富议题课程输入稿。

它只收束这一件事：**把财富议题从“我想赚更多钱”转成一门能帮助学员觉察金钱、价值、资源、行动和安全感关系的 AI 互动式图文课程。**

## 1. 最少启动层

### 1.1 课程主题

- 课程名称：财富议题自我疗愈课
- 一句话描述：面向对金钱焦虑、匮乏感、配得感、收钱困难或行动卡点有觉察需求的人，用曼陀罗、书写和提问探索自己与财富的关系。

### 1.2 目标人群

- 面向谁：想处理财富、金钱、收入、收钱、花钱、定价、配得感和价值交换议题的人
- 年龄段：默认面向成年学员
- 背景或状态：
  - 对财富议题敏感，容易焦虑、紧绷或内耗
  - 有“想赚钱但行动卡住”“想收钱但不敢要”“有收入但存不住”等困扰
  - 对曼陀罗、自我疗愈、书写或教练式提问有兴趣
- 已有基础：不强制要求曼陀罗基础；完全零基础学员可先学习《曼陀罗自我疗愈入门》，或在本课中完成极简前置练习
- 最典型的学习动机：想看见自己和钱之间的真实关系，并找到一个可执行的小调整

### 1.3 核心框架

这里写这门课自己的方法论主线。财富课不重新发明议题体系，直接使用疗愈体系知识库中的财富议题框架。

- 这门课使用的主要方法：财富议题识别 + 曼陀罗练习 + 书写复盘 + 教练式提问 + 小行动
- 关键概念：
  - 财富不只是“有没有钱”，也包含安全感、价值感、交换关系、行动力和与世界的链接
  - 金钱可能承载安全、自由、尊严、被支持、被看见等感受
  - 财富卡点不一定来自能力不足，也可能来自旧脚本、羞耻、匮乏感、家庭经验或行动承载力不足
  - 曼陀罗在本课中是议题外化工具，不是财富结果预测工具
- 练习路径：
  1. 识别当下最明显的财富议题
  2. 看见自己对钱的第一反应和身体感受
  3. 用曼陀罗承载一个具体财富主题
  4. 观察画面中的颜色、位置、形状和身体反应
  5. 用书写和提问连接现实处境
  6. 找到一个可执行的小行动
- 判断标准：
  - 学员是否能说清自己当前最想探索的财富问题
  - 学员是否能区分现实财务问题和内在感受问题
  - 学员是否能看见一个和财富相关的信念、情绪或行动卡点
  - 学员是否能形成一个低风险、可执行的小行动
- 与其他方法或课程的关系：
  - 与《曼陀罗自我疗愈入门》共享曼陀罗基础方法
  - 与后续“用曼陀罗如何做解读”共享画面观察素材，但本课不教专业解读师训练
  - 与疗愈体系知识库的财富议题、浮现议题和财富报告包保持一致

### 1.4 关键约束

- 这门课不教什么：
  - 不教投资、理财、资产配置、创业决策或职业选择
  - 不做现实收入预测
  - 不教专业曼陀罗解读体系
  - 不把财富问题简化成“能量不够”或“信念错了”
- 这门课不能承诺什么：
  - 不能承诺画完曼陀罗就能赚钱
  - 不能承诺显化结果
  - 不能承诺解决债务、失业、现金流危机等现实问题
  - 不能替代财务顾问、心理咨询、医学诊疗或法律建议
- 哪些内容属于后续课程：
  - 深度作品解读
  - 个案陪跑
  - 高端私人陪跑式疗愈服务
  - 疗愈师商业化与服务设计
- 哪些情况需要提醒学员暂停或寻求专业支持：
  - 债务、家暴、经济控制、诈骗、成瘾消费等现实风险
  - 强烈羞耻、自责、恐惧或创伤反应
  - 练习过程中出现持续身体不适或情绪失控
- 和其他课程的边界：
  - 本课只解决“如何用曼陀罗探索财富议题”
  - 不解决“如何成为财富疗愈师”
  - 不解决“如何做高客单财富陪跑服务”

## 2. 建议补充层

### 2.1 核心观点

- 观点 1：钱不是单纯的数字，它也可能承载安全、尊严、自由、支持和被看见。
- 观点 2：财富议题不是判断你有没有能力，而是帮助你看见自己如何创造、交换、承接和使用资源。
- 观点 3：财富疗愈的目标不是立刻变有钱，而是让你和金钱的关系更清明、更稳定、更有行动力。

### 2.2 学习者体验

- 主感受：清晰结构感
- 辅助感受：温暖陪伴感
- 需要避免：羞耻感、恐吓感、神秘承诺感、被推销感

### 2.3 图像与意象方向

- 主要视觉意象：流动的资源、稳定的容器、种子、交换、桥梁、光线进入圆形空间
- 色彩倾向：可以使用金色、黄色、绿色、蓝色等象征资源、承载、生长和流动的颜色，但不做固定吉凶解释
- 不希望出现的画面：钞票堆、暴富符号、炫富、赌博、投资盘、夸张显化
- 是否需要东方美学、自然意象、身体意象或抽象图形：可以使用自然意象和抽象图形，保持安定、真实和可练习

## 3. 本课必讲内容

### 3.1 财富议题是什么

需要用通俗语言解释：

- 财富议题不是判断一个人有没有钱。
- 财富议题关注的是一个人与金钱、价值、资源、世界和行动之间的关系。
- 学员探索财富议题时，不只是在问“我怎样赚更多”，也可能是在问：
  - 我是否允许自己拥有更多？
  - 我是否敢收钱、敢谈价、敢表达价值？
  - 我是否把钱当作唯一安全感来源？
  - 我是否用赚钱证明自己值得？
  - 我是否能承接机会、收入和被看见？

### 3.2 财富中的常见卡点

课程可以讲 6 类常见卡点：

1. 配得感不足：觉得自己不值得拥有更多，不敢收取或不敢被支持。
2. 匮乏感和安全感不足：长期担心不够用，有钱也不安心。
3. 求认可式赚钱：把赚钱、成绩和客户认可当成“我好不好”的证明。
4. 情绪型漏财：通过消费安抚情绪、补偿自己或逃避压力。
5. 承载力不足：有机会、有收入，但接不住、留不住或很快变成新压力。
6. 行动力不足：想法很多，但容易被情绪、关系、自我怀疑或身体疲惫打断。

AI 师傅讲这些卡点时，要使用“可能”“值得观察”“可以看看”这类表达，不能直接给学员贴标签。

### 3.3 财富曼陀罗练习

本课可以设计一个财富主题曼陀罗练习。

建议流程：

1. 选择一个具体主题，例如“我和收钱的关系”“我对金钱的焦虑”“我是否允许自己拥有更多”。
2. 练习前做身体自检：想到这个主题时，身体哪里最有感觉。
3. 用颜色和形状自由画出这个主题，不追求好看。
4. 画完后先观察，不急着解释。
5. 记录 3 个词：一个颜色词、一个情绪词、一个身体词。
6. 回到现实，写下一个小行动。

### 3.4 书写和提问

画后可以用这些问题：

- 当我想到钱时，最先出现的感受是什么？
- 我最害怕钱变多之后发生什么？
- 我最害怕钱不够时发生什么？
- 我是否允许别人为我的价值付费？
- 我现在最想通过钱获得什么：安全、自由、尊严、选择权，还是被认可？
- 如果我不再通过钱证明自己，我还想创造什么？
- 这张画提醒我下一步可以做哪一个小行动？

### 3.5 小行动设计

财富课的小行动必须低风险、可执行，不涉及高风险财务决策。

示例：

- 写下一条旧金钱信念，并改写成更温和的版本。
- 记录 3 笔花钱时的真实感受。
- 给一个服务或作品写出清楚的价值说明。
- 和一个可信任的人练习表达自己的价格或需求。
- 每天写 3 条感恩，但不否认现实压力。
- 完成一个 10 分钟的身体稳定练习，再处理财务相关事项。

### 3.6 安全边界

课程必须明确：

- 如果学员面对债务、诈骗、经济控制、失业或法律风险，应优先寻求现实支持。
- 如果财富议题触发强烈羞耻、恐惧、自责或创伤反应，应暂停练习。
- 曼陀罗可以帮助学员看见自己，但不能替代财务、法律、心理或医疗专业支持。
