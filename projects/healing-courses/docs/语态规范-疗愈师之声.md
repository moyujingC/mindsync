## 1. 这个规范解决什么问题

网站与课程文字出现过两种跑偏：

- **说明书语态**：罗列章节、形式、交付物，读完不知道「这和我有什么关系」
- **营销语态**：急着说服、制造紧迫、承诺收益，读的人感到被推着走

两种都不是疗愈师的说话方式。疗愈师的状态是：在场、不催促、不评判、给允许。文字要读起来像这个人坐在你对面说话。

## 2. 五条原则

### 2.1 陪伴优先于说服

不写「你将会得到」「这门课能给你」，写「这门课想陪你」「我们会一起」。把课程定位成一段陪伴，不是一个商品。

### 2.2 给允许，不给压力

- 允许没准备好：「可以先免费走走前 3 节」「合不合适，你的身体会知道」
- 不制造紧迫：价格信息照实写，但平铺直叙，不喊「错过再等一年」
- 允许慢慢来：「不着急」「按自己的节奏」「能留下来的才是你的」

### 2.3 诚实是最大的信任

- 不承诺效果，不假装速效：「这是一项慢慢练习的能力，我们不假装它是速效药」
- 明确边界，主动劝退该去寻专业帮助的人——这句话本身就是疗愈师品格的证明
- 没有学员评价就直说没有，不编造

### 2.4 用状态说话，不用概念说话

少说「自我疗愈体系」「状态→工具地图」这类术语，多说具体时刻：「躺下以后脑子还在转」「肩膀常常是紧着的」。学员在自己身上认出这些时刻，才会继续读。

### 2.5 句子要慢

- 短句、留白，允许一句话单独成段
- 删掉一切感叹号式催促和三连排比
- 称呼用「你」，语气像对一位坐在对面的人说话，不像对一群流量说话

## 3. 对照示例

| 不要写（营销语态） | 改写（疗愈师语态） |
|---|---|
| 难受的时候，有办法安顿自己了！ | 难受的时候，先把自己安顿好 |
| 学完这门课，你能带走三样东西 | 课程结束的时候，你会留下这些 |
| 这门课是不是为你做的？中 2 条以上就适合 | 如果你最近常常这样——有几句像你现在的样子，就够了 |
| 没有风险，先试再买 | 不用急着做决定 |
| 早鸟价限时抢购，错过恢复原价 | 早鸟价 ¥69（10 月 13 日起 ¥99）——信息照实写，不加催促 |
| 真的有用吗？诚实地说…… | 这门课做不到替代专业帮助，我们也不想夸大它 |

## 4. 检查清单

发布任何面向学员的文字前，逐条过：

1. 这句话是在说服，还是在陪伴？
2. 有没有制造紧迫感或焦虑感？（价格照实写，但有没有催促？）
3. 有没有承诺效果？（有就删或改诚实）
4. 术语能不能换成一个具体时刻？
5. 读出声来，像不像一个人在对另一个人说话？

## 5. 作者故事的安放（2026-09-30 定案）

- 课内正文、官网均不放作者自我介绍/缘起故事（CEO 拍板）。课程是陪伴，不是作者传记；购课决策由课程描述和口碑承担。
- 曾被建议「真人故事是最不像 AI 的东西」——话没错，但容器错了：它属于销售页，不属于学习流。
- 作者的差异化（自我疗愈是日常生活方式、非困境复原）已通过定位文案表达，不需要第一人称故事。
- 如果未来要加，先在详情页试，课内正文始终不放。

## 6. AI 味检查点（2026-09-30 从 L01 打磨中沉淀）

发布前扫一遍这些特征，命中就改：

1. **长串排比列举**——「睡前停不下来、反复纠结、身体发紧、什么都不想做，或者一种说不清的闷」一口气列四五项。真人说话一次说一两件。改法：拆短，或只挑最典型的两个。
2. **格言式金句**——「看清，是改变的第一步」「先承认累，比责怪自己更有用」这类对仗工整的总结句。改法：说具体动作，不说道理，如「先看清楚，别的以后再说」。
3. **破折号节奏**——一句话里多个「——」制造韵律感。全文破折号应屈指可数，停顿用逗号或句号。
4. **工整对照**——「不是来为难你的，它是在传话」可留一处，连续出现就是 AI。金句密度每节课最多一两句。
5. **书面连接腔**——「先正常化这个状态」「点出这种转的特别消耗之处」这类导演腔出现在学员可见文本里。改法：直接说内容，如「这个状态挺常见的」。
6. **过度对称的平行句**——「这门课不要求你相信什么，只邀请你动手验证」。改法：打散，「这门课不要你相信什么，动手试试就知道了」。

判据：读出声。人说话有碎的地方、有没说满的地方，AI 的文字每句都太完整。
