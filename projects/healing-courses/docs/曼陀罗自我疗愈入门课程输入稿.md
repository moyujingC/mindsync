这份材料是给 `AI 师傅` 的首门课输入稿。

它只收束这一件事：**把《曼陀罗自我疗愈入门》做成一门适合第一次接触曼陀罗的人上手的 AI 互动式图文课程。**

## 1. 最少启动层

### 1.1 课程主题

- 课程名称：曼陀罗自我疗愈入门
- 一句话描述：面向第一次接触曼陀罗、但有自我疗愈需求的人，建立一个自我疗愈的基本框架，并以曼陀罗作为主要工具。

### 1.2 目标人群

- 面向谁：第一次接触曼陀罗，但对自我疗愈、情绪整理、内在觉察有兴趣的人
- 年龄段：先不做硬限定，默认面向成年学员
- 背景或状态：没有曼陀罗绘画经验，可能有压力、迷茫、情绪卡住或想更了解自己的需求
- 已有基础：不要求绘画基础，不要求传统文化基础
- 最典型的学习动机：想用一种低门槛、可自己练习的方法，先开始照顾自己

### 1.3 核心框架

这里写这门课自己的方法论主线。当前先按“可教学、可练习、可复盘”的路径收束。

- 这门课使用的主要方法：曼陀罗绘画 + 温和观察 + 书写复盘 + 小行动
- 关键概念：
  - 曼陀罗不是美术考试
  - 画面是自我观察的线索，不是绝对结论
  - 自我疗愈首先是建立安全感和自我承接
- 练习路径：
  1. 先安顿状态
  2. 再完成绘画
  3. 再观察自己的画
  4. 再写下感受和问题
  5. 最后落到一个可执行的小行动
- 判断标准：
  - 学员是否能完成一次练习
  - 学员是否敢观察自己的作品
  - 学员是否能说出自己的感受
  - 学员是否能得到一个温和的后续照顾动作
- 与其他方法或课程的关系：
  - 与《用曼陀罗如何做解读》共享曼陀罗知识库，但本课不讲系统解读
  - 与后续个案、沙龙和疗愈师课程衔接，但不承担职业训练

### 1.4 关键约束

- 这门课不教什么：
  - 不教专业解读体系
  - 不教疗愈师训练
  - 不教完整职业路径
  - 不教传统文化大课
- 这门课不能承诺什么：
  - 不能承诺治疗
  - 不能承诺诊断
  - 不能承诺一次练习就解决长期问题
- 哪些内容属于后续课程：
  - 作品解读方法
  - 沙龙主持与活动设计
  - 个案陪跑
  - 疗愈师职业与商业路径
- 哪些情况需要提醒学员暂停或寻求专业支持：
  - 强烈情绪失控
  - 创伤闪回
  - 严重失眠或明显身心不适
  - 绘画过程中出现持续不适
- 和其他课程的边界：
  - 本课只解决“怎么开始”
  - 不碰“怎么深度解读”
  - 不碰“怎么做个案服务”

## 2. 建议补充层

### 2.1 核心观点

- 观点 1：先画出来，再谈理解。
- 观点 2：画面不是答案，画面只是线索。
- 观点 3：疗愈不是一次性解决问题，而是学会更稳定地照顾自己。

### 2.2 学习者体验

- 主感受：温暖陪伴感
- 辅助感受：清晰结构感

### 2.3 图像与意象方向

- 主要视觉意象：圆、层层展开的结构、安静的中心、自然生长感
- 色彩倾向：低饱和、柔和、稳定，不要过于刺激
- 不希望出现的画面：复杂压迫、强对抗、诊断感、医疗化表达
- 是否需要东方美学、自然意象、身体意象或抽象图形：可以偏自然意象和抽象图形，但保持简洁
