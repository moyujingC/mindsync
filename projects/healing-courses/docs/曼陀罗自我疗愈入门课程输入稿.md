这份材料是给 `AI 师傅` 的首门课输入稿。

它只收束这一件事：**把《曼陀罗自我疗愈入门》做成一门适合第一次接触曼陀罗的人上手的 AI 互动式图文课程。**

## 1. 最少启动层

### 1.1 课程主题

- 课程名称：曼陀罗自我疗愈入门
- 一句话描述：面向第一次接触曼陀罗、但有自我疗愈需求的人，先理解曼陀罗艺术疗愈的基本原理，再通过四种基础画法建立自己的入门练习路径。

### 1.2 目标人群

- 面向谁：第一次接触曼陀罗，但对自我疗愈、情绪整理、内在觉察有兴趣的人
- 年龄段：先不做硬限定，默认面向成年学员
- 背景或状态：没有曼陀罗绘画经验，可能有压力、迷茫、情绪卡住或想更了解自己的需求
- 已有基础：不要求绘画基础，不要求传统文化基础
- 最典型的学习动机：想用一种低门槛、可自己练习的方法，先开始照顾自己

### 1.3 核心框架

这里写这门课自己的方法论主线。当前先按“可教学、可练习、可复盘”的路径收束。

- 这门课使用的主要方法：曼陀罗艺术疗愈入门讲解 + 四种基础画法 + 温和观察 + 书写复盘 + 小行动
- 关键概念：
  - 曼陀罗可以作为一个安全、稳定、可反复进入的自我觉察容器
  - 曼陀罗不是美术考试
  - 画面是自我观察的线索，不是绝对结论
  - 自我疗愈首先是建立安全感和自我承接
- 练习路径：
  1. 先理解曼陀罗艺术疗愈是什么
  2. 再理解为什么画曼陀罗可以支持自我疗愈
  3. 判断自己是否适合当下练习
  4. 学习四种基础画法
  5. 完成一次入门练习
  6. 观察自己的画
  7. 写下感受和问题
  8. 最后落到一个可执行的小行动
- 判断标准：
  - 学员是否能说清曼陀罗艺术疗愈的大意
  - 学员是否理解画曼陀罗可能带来的支持，不把它误解成治疗承诺
  - 学员是否知道自己适不适合在当下练习
  - 学员是否掌握四种基础画法的适用场景
  - 学员是否能完成一次练习
  - 学员是否敢观察自己的作品
  - 学员是否能说出自己的感受
  - 学员是否能得到一个温和的后续照顾动作
- 与其他方法或课程的关系：
  - 与《用曼陀罗如何做解读》共享曼陀罗知识库，但本课不讲系统解读
  - 与后续个案、沙龙和疗愈师课程衔接，但不承担职业训练

### 1.4 关键约束

- 这门课不教什么：
  - 不教专业解读体系
  - 不教疗愈师训练
  - 不教完整职业路径
  - 不教传统文化大课
  - 不把四种基础画法讲成专业认证体系
- 这门课不能承诺什么：
  - 不能承诺治疗
  - 不能承诺诊断
  - 不能承诺一次练习就解决长期问题
- 哪些内容属于后续课程：
  - 作品解读方法
  - 沙龙主持与活动设计
  - 个案陪跑
  - 疗愈师职业与商业路径
- 哪些情况需要提醒学员暂停或寻求专业支持：
  - 强烈情绪失控
  - 创伤闪回
  - 严重失眠或明显身心不适
  - 绘画过程中出现持续不适
- 和其他课程的边界：
  - 本课只解决“怎么开始”
  - 不碰“怎么深度解读”
  - 不碰“怎么做个案服务”

## 2. 建议补充层

### 2.1 核心观点

- 观点 1：曼陀罗不是为了画得好看，而是为了给内在状态一个可以被看见的空间。
- 观点 2：画面不是答案，画面只是线索。
- 观点 3：疗愈不是一次性解决问题，而是学会更稳定地照顾自己。

## 3. 本课必讲内容

### 3.1 曼陀罗艺术疗愈是什么

需要用通俗语言解释：

- 曼陀罗是一种围绕“圆”和“中心”展开的图像表达方式。
- 在疗愈课程中，它可以作为自我觉察、自我安顿和情绪整理的工具。
- 这里说的艺术疗愈，不是美术训练，也不是医学治疗，而是借由图像、身体感受和书写帮助学员靠近自己。

### 3.2 为什么画曼陀罗可以支持自我疗愈

需要讲清楚几条简单机制：

- 圆形边界可以给人稳定感和承接感。
- 重复线条、颜色和形状可以帮助注意力慢下来。
- 绘画过程能把模糊的情绪和感受外化到纸上。
- 画完后的观察和书写，可以把“感觉到了什么”整理成“我现在需要什么”。

表达时要避免说成“画曼陀罗一定能治好某个问题”。

### 3.3 什么人适合画曼陀罗

适合人群：

- 想自我觉察，但不想一开始就做很重的心理分析的人
- 有压力、迷茫、情绪卡住，想用温和方式整理自己的人
- 没有绘画基础，但愿意通过颜色和形状表达的人
- 想建立日常自我照顾练习的人

需要谨慎或暂停的人群：

- 正在经历强烈情绪失控的人
- 有明显创伤闪回的人
- 绘画过程中身体或情绪明显不适的人
- 需要专业心理或医学支持的人

### 3.4 可能带来的效果

可以描述为“可能支持”，不能描述为“保证效果”。

可讲效果：

- 帮助情绪安顿
- 增加自我觉察
- 看见当下内在状态
- 把模糊感受整理成语言
- 形成一个小的自我照顾行动

不能承诺：

- 治愈疾病
- 诊断人格或心理问题
- 一次练习解决长期困扰
- 替代心理咨询、医学诊疗或其他专业支持

## 4. 建议补充层

### 4.1 学习者体验

- 主感受：温暖陪伴感
- 辅助感受：清晰结构感

### 4.2 图像与意象方向

- 主要视觉意象：圆、层层展开的结构、安静的中心、自然生长感
- 色彩倾向：低饱和、柔和、稳定，不要过于刺激
- 不希望出现的画面：复杂压迫、强对抗、诊断感、医疗化表达
- 是否需要东方美学、自然意象、身体意象或抽象图形：可以偏自然意象和抽象图形，但保持简洁
