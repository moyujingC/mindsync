这份文档用于定义 `疗愈课程体系` 中按议题组织的课程系列。

这里的“议题”指学员真实想处理的生活主题，例如财富、关系、原生家庭、事业、身体、情绪、内在小孩等。

这个系列和 [疗愈体系知识库](../../../projects/aimandala/docs/疗愈体系知识库) 是一一对应的：

- 课程中的议题分类，直接取自知识库的议题层。
- 课程中的练习方法，优先从知识库里的疗愈方案层、流派层和案例材料中抽取。
- 课程中的知识表达，要把知识库里的内容转成学员能听懂、能练、能追问的形式。
- 课程不在这份边界文档里重新发明一套议题体系。

## 1. 与曼陀罗系列的区别

`曼陀罗系列` 按工具和能力成长路径组织：

- 先学如何用曼陀罗自我疗愈
- 再学如何解读曼陀罗
- 再学如何做沙龙、个案和疗愈师职业化

`议题系列` 按学员的问题入口组织：

- 学员不是先问“我要学什么工具”
- 而是先问“我现在卡在财富、关系、家庭、事业或情绪里的哪个问题”

两类课程可以共享工具，但入口不同：

- 曼陀罗系列：工具优先
- 议题系列：问题优先

## 2. 议题课的默认结构

每一门议题课默认采用同一套结构：

1. 议题识别：这个议题通常表现成什么样。
2. 自我觉察：学员如何看见自己在这个议题里的状态。
3. 曼陀罗练习：用曼陀罗承载和外化这个议题。
4. 书写与提问：把画面、感受和现实处境连接起来。
5. 小行动：把觉察落到一个可执行动作。
6. 边界提醒：什么情况需要暂停，什么情况需要专业支持。

默认交付形态仍然是 `AI 线上互动式图文教学 + 追问`。

如果议题涉及长期陪伴、案例反馈或情绪强度较高，再考虑直播课或社群服务。

## 3. 首个议题：财富议题

`财富议题` 是议题系列的首个候选方向。

它可以承接：

- 金钱焦虑
- 匮乏感
- 配得感
- 价值感
- 收入、定价、收钱和交换边界
- 家庭或成长经历中形成的金钱脚本
- 行动力、显化愿望和现实落地之间的关系

财富议题课可以使用曼陀罗作为核心练习工具，但不应变成纯粹的“财富显化承诺”。

## 4. 财富议题课的边界

### 4.1 可以讲

- 如何觉察自己对钱的感受
- 如何通过曼陀罗看见匮乏感、恐惧、委屈、欲望和行动卡点
- 如何把愿望从模糊期待转成可行动的小目标
- 如何用感恩、清理、意图设定和书写练习支持财富议题探索
- 如何区分“我想要更多钱”和“我真正想通过钱获得什么”

### 4.2 不讲或谨慎讲

- 不承诺画完曼陀罗就能赚到钱
- 不做投资、理财、职业选择或商业诊断建议
- 不把财富困难简单归因到“能量不够”
- 不把学员现实处境的复杂问题简化为个人信念问题
- 不用羞耻、恐吓或神秘化语言推动学员付费

## 5. 与曼陀罗入门课的关系

财富议题课不替代《曼陀罗自我疗愈入门》。

建议关系：

- 《曼陀罗自我疗愈入门》解决“我怎么开始画、怎么安全观察自己”
- 《财富议题课》解决“我如何用曼陀罗探索金钱、价值和交换问题”

因此财富议题课可以默认把曼陀罗基础知识讲得更短，重点放在财富议题本身。

如果学员完全没有曼陀罗经验，可以先引导他们学习入门课，或在财富议题课中提供一个极简前置练习。

## 6. 后续可扩展议题

后续可按同样结构扩展：

- 关系议题
- 原生家庭议题
- 事业表达议题
- 身体与健康议题
- 情绪能量议题
- 内在小孩议题
- 自我价值与配得感议题

每个议题都需要单独确认：

- 目标人群
- 议题边界
- 适合使用的曼陀罗练习
- 不该承诺的效果
- 是否需要直播、社群或个案支持
