## 用途

存放课1（及后续课程）对外发布的自媒体内容成稿：小红书双号笔记、公众号文字与贴图。

选题从 `../2026-09-27-自媒体选题库.md` 池中取，一篇内容只打一个钩子；发布规则见 `../../tasks/2026-09-27-课1至课4制作与运营综合计划.md` 第 3 节。

## 文件约定

- 按批次建文件夹：`YYYY-MM-DD-<批次名>/`，批次根放 `00-批次说明.md`（发布节奏、A/B 安排、检查清单）。
- 一篇待发内容一个文件，文件名前缀为发布顺序号：`01-老号-选题10-标题.md`。
- 文件头固定字段：状态（待发布/已发布/已回填）、计划发布时间与账号、单一动作（收藏/关注/转化）、选题库出处。

## 状态流转

1. `待发布`：文案已就绪，等配图或发布动作。
2. `已发布`：发布当天把实际标题、链接补进文件头。
3. `已回填`：发布后第 3 天和第 7 天填数据（模板见下），并把效果记入选题库对应行。

## 数据回填模板

每篇笔记发布后记两行：

```
D3（发布+3天）：阅读__ 赞__ 收藏__ 评论__ 新增关注__
D7（发布+7天）：阅读__ 赞__ 收藏__ 评论__ 新增关注__
评论区意图：__（「我也想试试」「怎么报名」类记入候选名单）
```

分账号记录，两号分开才能看出 A/B 差异。

## 口径红线（所有稿件通用）

- 师承口径（2026-09-28 CEO 定案）：曼陀罗是能量密码，颜色与形状是内在能量的呈现，画面照见状态；「注意力管理工具」仅作为对西方视角的说明出现，不作本账号立场。
- 内容深度（09-29 定案）：只讲现象层（画面看得见的现象 + 轻量体系词汇），五行/三圈的系统教学留到课程里。
- 人设（09-29 定案）：轻人设，主理人第一人称（练习者 + 师承 + 课程主讲三件套）；不虚构身份、不编造案例。
- 不承诺治疗效果。
- 严重心理困扰引导就医：情绪危机、持续影响睡眠饮食的，引导优先寻求专业帮助。
- 课1 上线前不挂任何购买链接；引导动作只有收藏、关注、评论互动。
