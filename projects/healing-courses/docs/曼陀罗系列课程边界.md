这份文档用于切开曼陀罗系列课程的内容边界，避免每门课重复讲同一批内容。

曼陀罗系列当前按 6 门课规划：

1. 曼陀罗自我疗愈入门
2. 用曼陀罗如何做解读
3. 如何做曼陀罗主题的定制沙龙
4. 曼陀罗疗愈师个案陪跑营
5. 从 0-1 转行做疗愈师
6. 如何做高端私人陪跑式疗愈服务

## 1. 总体分层

### 1.1 入门认知层

包括：

- 曼陀罗自我疗愈入门
- 用曼陀罗如何做解读

目标是让学员先会用、再会看。

### 1.2 应用交付层

包括：

- 如何做曼陀罗主题的定制沙龙
- 曼陀罗疗愈师个案陪跑营

目标是让学员能把曼陀罗方法交付给他人。

### 1.3 职业变现层

包括：

- 从 0-1 转行做疗愈师
- 如何做高端私人陪跑式疗愈服务

目标是让学员理解疗愈师职业，并设计自己的服务和商业路径。

## 3. 每门课的一句话边界

### 3.1 曼陀罗自我疗愈入门

只讲普通人如何用曼陀罗完成第一次自我疗愈练习。

重点是自我疗愈框架、体验、练习和温和观察，不讲专业解读体系。

### 3.2 用曼陀罗如何做解读

只讲如何读一幅曼陀罗作品。

重点是解读方法、案例、议题分类和基础边界，不深入个案陪伴训练。

### 3.3 如何做曼陀罗主题的定制沙龙

只讲如何把曼陀罗做成一场线上或线下活动。

重点是活动设计、流程、主持、互动和风险控制，不教完整疗愈师能力。

### 3.4 曼陀罗疗愈师个案陪跑营

只讲疗愈师如何做个案。

重点是通用个案流程、倾听、澄清、引导、陪练，以及曼陀罗 + 完形 + 家排的个案体系。

### 3.5 从 0-1 转行做疗愈师

只讲如何理解疗愈师职业，并开始规划自己的入行路径。

重点是职业认知、学习路径、商业计划和落地执行问题，不承担深度个案训练。

### 3.6 如何做高端私人陪跑式疗愈服务

只讲如何设计和交付高客单私人陪跑服务。

重点是客户筛选、服务结构、交付边界、长期陪跑节奏和商业闭环，不再教基础入门。

## 4. 课程衔接关系

推荐学习路径：

1. 先学 `曼陀罗自我疗愈入门`，建立体验和自我练习能力。
2. 再学 `用曼陀罗如何做解读`，学习如何观察和解释作品。
3. 想做活动的人进入 `曼陀罗主题定制沙龙`。
4. 想做一对一个案的人进入 `曼陀罗疗愈师个案陪跑营`。
5. 想转行的人进入 `从 0-1 转行做疗愈师`。
6. 已经具备服务基础、想做高客单的人进入 `高端私人陪跑式疗愈服务`。

这条路径允许跳课，但需要明确前置能力：

- 没有曼陀罗经验的人不建议直接进入课程 2。
- 没有解读基础的人不建议直接做沙龙。
- 没有个案基础的人不建议直接做高端私人陪跑。

## 5. 统一交付原则

所有课程默认以 `AI 线上互动式图文教学` 为基础，支持学员追问。

直播课和社群服务只在以下情况下增加：

- 图文和追问不足以让学员完成练习。
- 学员需要案例拆解、现场示范或集中答疑。
- 学员需要长期练习、同伴支持或个案陪练。
- 课程进入职业训练、高客单服务或复杂交付阶段。
