## 1. 本轮交付目标

本轮交付不新增后端能力，也不改 release 路径。

交付重点只有一件事：把当前治理控制台的主路径做成更容易首次理解和操作的状态。

## 2. 本轮收口内容

- 默认入口继续保持 `/models`
- 核心导航收口为：
  - `模型库`
  - `任务库`
  - `运行记录`
- `Dashboard` 保留页面与路由，但不再作为当前主路径心智中心
- 支持模块统一弱化
- 模型库、任务库、运行记录三页补足：
  - 首屏使用语义
  - 更明确的表单顺序
  - 必填校验
  - 操作反馈

## 3. 本轮不变项

- 不改默认 `main.tsx`
- 不改 `relayhub/dev` 作为服务器测试分支的策略
- 不改 release 部署方式
- 不改 control-plane 接口和返回 shape（返回结构）
- 不重做 Dashboard

## 4. 下一阶段建议

完成这一轮后，下一阶段应优先考虑：

- 首页与主路径文案继续减噪
- 模型库、任务库、运行记录的表单细节和状态反馈继续打磨
- 预置模型目录质量
- 单独立项的 Dashboard 重设计

不建议下一轮重新回到 deployment 或 runtime seam 方向。
