## Summary

本轮交付把 RelayHub 的预置中转入口从“固定写死一个默认模型标识”推进到“可拉上游可用模型列表后再手动选择当前模型”。

交付后，用户处理像 `AITechFlux` 这类入口时，路径变成：

1. 补 `API Key`
2. 获取可用模型
3. 选择真实可用的当前模型
4. 保存配置
5. 测试连接
6. 去任务库绑定或切换

## Delivery Notes

- 新增 `control-plane` 只读接口：
  - `GET /models/:id/catalog`
- 该接口只支持预置 `relay-api` 中转入口
- 不持久化完整上游模型列表
- 预置入口继续锁定：
  - `kind`
  - `baseUrl`
- 预置入口的 `modelId` 改为“从拉取结果中选择后保存”
- console mock 与 server 语义保持一致
- `AITechFlux` 与 `PPChat` 已补首批 mock 目录样本

## Verification Result

- `control-plane` 定向测试通过
- console service / routes 测试通过
- `dev-relay` 回归测试通过
- console build 已纳入本轮回归要求

## Remaining Notes

- 本轮仍不是模型测评或推荐系统
- 真实选择逻辑仍然由人手动决定
- 后续如果扩展到更多中转入口，可沿用同一 `catalog` 读接口与半锁定 `modelId` 交互
