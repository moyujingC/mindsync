这份任务文档用于把 `RelayHub` 控制台当前已经独立落位的前端只读 contract，继续从页面 view model 依赖中解耦出来。

## 1. 任务目标

本轮目标是：

- 保持 `contracts/` 只承载前端只读 raw response 契约
- 让 `contracts/` 不再直接 import `models/console.ts`
- 让 `services/consoleData.ts` 明确承担 contract 到页面 view model 的解包与映射职责
- 保持页面 helper 函数名与返回语义不变

## 2. 当前固定决策

实现过程中必须沿用以下固定决策：

- 页面层继续不直接 import `contracts/`
- `mocks/consoleApi.ts` 继续返回本地 mock 的 raw contract response
- `services/consoleData.ts` 继续同时提供 raw helper 与页面 helper
- 不引入真实只读 API，不引入写操作，不改页面信息架构

## 3. 本轮要做的实现

### 3.1 contract payload 独立化

要求：

- 在资源级 contract 文件中定义最小 payload 类型
- `ContractMeta` 对 `filters` 采用泛型化表达，避免基础层反向依赖页面模型
- `providers` 的筛选快照 contract 独立定义，不再复用页面 `ProviderFilters`

### 3.2 service 职责收束

要求：

- raw helper 继续返回 contract response
- 页面 helper 明确返回页面 view model
- contract 到页面 model 的转换逻辑集中在 `consoleData.ts`

### 3.3 行为保持

要求：

- 页面显示与 URL 行为不变
- 原有 route 测试继续通过
- provider `meta.filters`、environment `not-found` 等既有语义保持不变

## 4. 本轮明确不做

本轮不做：

- 更接近真实后端 wire format 的命名迁移
- 真实只读 API 接入
- 页面层消费 contract `meta`
- contract codegen
- 任何真实控制动作

## 5. 完成标准

只有同时满足下面条件，才算本轮完成：

- `contracts/` 已不再直接依赖页面 `models`
- `services/consoleData.ts` 已明确承接 contract 到 view model 的映射
- `npm test` 通过
- `npm run build` 通过
- 已补 QA 验证记录与交付说明
