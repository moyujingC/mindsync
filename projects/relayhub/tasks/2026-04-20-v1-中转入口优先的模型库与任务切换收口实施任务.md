## 1. 实施目标

把模型库和任务库的语义从“模型清单”收口为“入口接入与入口内模型切换”。

## 2. 具体工作

### A. 模型库

- 改模型库首屏文案，强调“接入入口”
- 预置区分官方入口与中转入口
- 预置条目锁定 `baseUrl` / `modelId` / `kind`
- 自定义模型保留完全可编辑

### B. 任务库

- 把“默认模型”文案改成“入口内默认模型”
- 快速切换文案强调只影响任务后续使用
- 不引入全局模型切换心智

### C. control-plane / mock 对齐

- 保持现有路由不变
- 对预置条目的更新增加最小约束
- mock 与 server 保持相同语义

### D. 文档与测试

- 新增 spec / task / qa / delivery
- 更新 README 索引
- 补模型库与任务库相关路由测试

## 3. 完成标准

- 用户第一次进入时能看懂预置给的是“入口”
- 用户不需要手填官方入口 URL 和模型标识
- 任务库的切换动作被理解为“入口内默认模型切换”
