这份任务文档用于把 `RelayHub` 控制台当前 `consoleData` 与 `mockApi` 之间，插入一层资源级只读数据源接口。

## 1. 任务目标

本轮目标是：

- 抽出统一的资源级只读数据源接口
- 让 mock 实现以显式数据源身份提供 `Contract*` response
- 让 `consoleData.ts` 依赖数据源接口而不是直接依赖 `mockApi`
- 为后续真实只读 API 接入预留稳定替换点

## 2. 当前固定决策

实现过程中必须沿用以下固定决策：

- 一次覆盖 `dashboard / environments / providers / eval` 四类资源
- 数据源层返回值继续使用当前 `Contract*` response
- 默认数据源固定为 mock 实现
- 不引入真实 API、不引入运行时切换、不改页面结构

## 3. 本轮要做的实现

### 3.1 数据源接口

要求：

- 新增 `ConsoleReadonlyDataSource`
- 接口方法覆盖四类资源的 raw contract 读取能力
- 参数继续沿用 `MockRequestOptions` 与 `ProviderFilters`

### 3.2 mock 数据源实现

要求：

- 新增 mock 数据源实现文件
- 明确导出默认数据源实例
- `mockApi` 现有 response 语义保持不变

### 3.3 service 依赖调整

要求：

- `consoleData.ts` 改为依赖默认数据源实例
- raw helper / `ReadonlyApiResponse()` helper / 页面 helper 的函数名与返回语义不变
- adapter 层继续保持独立

### 3.4 数据源测试

要求：

- 新增数据源层测试
- 覆盖 dashboard / environments / providers / eval
- 至少验证 `meta.filters`、`empty`、`not-found`

## 4. 本轮明确不做

本轮不做：

- 真实只读 API
- runtime 数据源切换
- payload 字段向后端 wire format 命名迁移
- 页面层消费数据源接口
- 任何真实控制动作

## 5. 完成标准

只有同时满足下面条件，才算本轮完成：

- 资源级只读数据源接口已落位
- `consoleData.ts` 已改为依赖默认数据源
- `npm test` 通过
- `npm run build` 通过
- 已补 QA 验证记录与交付说明
