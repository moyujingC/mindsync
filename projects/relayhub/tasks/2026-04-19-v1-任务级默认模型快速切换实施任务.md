## 1. 实施目标

把 `任务库` 从“只能通过编辑任务改默认模型”收口为“可在任务列表里直接快速切换默认模型”。

## 2. 具体工作

### A. 页面语义收口

- 调整 `TasksPage` 顶部文案，让页面先服务绑定 / 切换默认模型
- 在任务表格里强化“当前默认模型”和“快速切换”列

### B. 行内快速切换

- 每一行任务都支持选择已激活模型
- 当前无绑定任务也可直接在任务行里绑定
- 切换成功后立即刷新表格显示
- 提示明确说明仅对后续使用和后续新运行记录生效

### C. 保留完整编辑模式

- 保留原有编辑任务入口
- 不删除 description 和 switchNote 的完整编辑能力
- 但默认模型切换不再要求先进入编辑表单

### D. 验证

- 补路由 / UI 测试：
  - 已绑定任务快速切换
  - 未绑定任务快速绑定
  - 无已激活模型时的引导
- 跑 `npm test`
- 跑 `npm run build`

## 3. 完成标准

- 用户可以在 `/tasks` 里直接完成默认模型切换
- 切换成功后表格立即显示新默认模型
- 当前无激活模型时，不会让用户卡在空操作上
