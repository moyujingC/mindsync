## 1. 实施目标

把当前 `/runs` 从“可录入”收口成“绑定后顺手记录”的页面。

## 2. 具体工作

### A. 页面语义

- 调整 `RunsPage` 文案，让页面先服务“为当前任务记一次真实结果”
- 弱化 `治理概览` 的主导感

### B. 任务与模型默认值

- 进入页面时优先选中最近使用任务
- 若任务已有默认模型，模型字段自动带出
- 切换任务时，模型字段按任务默认模型同步
- 未绑定任务时给出明确提示

### C. 上下文与提交反馈

- 增加“当前任务记录上下文”提示块
- 明确区分“沿用默认模型记录”和“临时手动选模型记录”
- 提交成功后保留任务上下文，只清理结果输入字段

### D. 文档与验证

- 新增 spec / task / qa / delivery
- 更新 README 索引
- 补 Runs 页相关路由 / UI 测试

## 3. 完成标准

- 用户进入 `/runs` 后能知道当前该为哪个任务记结果
- 用户不需要重复选择已经绑定好的默认模型
- 临时改模型时，页面不会让人误以为任务默认绑定已被修改
