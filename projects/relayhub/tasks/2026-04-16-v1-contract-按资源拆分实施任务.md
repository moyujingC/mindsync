这份任务文档用于把 `RelayHub` 控制台当前单文件的前端只读 contract，继续拆成按资源组织的结构。

## 1. 任务目标

本轮目标是：

- 将 `contracts/console.ts` 拆成按资源组织的文件
- 保持 contract 与页面 model 的职责边界清晰
- 保持 `mocks / services / tests` 继续只依赖 contract 层
- 不改变页面 helper 的返回语义

## 2. 当前固定决策

实现过程中必须沿用以下固定决策：

- `base.ts` 只承载 envelope / meta / resource 基础契约
- 资源级 contract 按 `dashboard / environments / providers / eval` 拆分
- 页面层继续不直接 import `contracts/`
- 不改 contract 名称，不引入真实 API 命名迁移

## 3. 本轮要做的实现

### 3.1 contract 文件拆分

至少新增：

- `contracts/base.ts`
- `contracts/dashboard.ts`
- `contracts/environments.ts`
- `contracts/providers.ts`
- `contracts/eval.ts`
- `contracts/index.ts`

### 3.2 依赖方向调整

要求：

- `mocks/consoleApi.ts` 从资源级 contract 文件 import
- `services/consoleData.ts` raw helper 类型改为从资源级 contract 文件 import
- `consoleData.test.ts` 改为依赖拆分后的 resource-level contract types

### 3.3 行为保持

要求：

- 页面 helper 返回值保持不变
- raw helper 返回值保持不变
- 原有测试继续通过

## 4. 本轮明确不做

本轮不做：

- 真实只读 API
- 页面层消费 contract
- contract codegen
- 真实控制动作
- 资源级命名改写

## 5. 完成标准

只有同时满足下面条件，才算本轮完成：

- contract 已按资源拆分
- `npm test` 通过
- `npm run build` 通过
- 已补验证记录与交付说明
