这份任务文档用于把 `RelayHub` 控制台当前散落在 `models / mocks / services` 的原始响应契约，抽成独立的前端只读 contract 层。

## 1. 任务目标

本轮目标是：

- 新增 `contracts/` 目录承载原始响应契约
- 将 envelope / meta / resource 语义从页面模型中拆出
- 让 `mocks/` 与 `services/` 共用 contract types
- 保持页面继续只消费稳定 view model

## 2. 当前固定决策

实现过程中必须沿用以下固定决策：

- contract 只服务前端只读响应层
- contract 不替代页面 view model
- 页面层不直接 import `contracts/`
- 不引入真实后端语义或 codegen
- 不改现有页面 helper 的函数名与行为

## 3. 本轮要做的实现

### 3.1 contract 落位

新增 `projects/relayhub/console/src/contracts/`，至少包含：

- 基础 envelope / meta contract
- `dashboard / environments / providers / eval` 资源级 contract
- providers filter snapshot contract

### 3.2 models / mocks / services 调整

要求：

- `models/console.ts` 继续保留页面消费模型
- `mocks/consoleApi.ts` 改为依赖新 contract types
- `consoleData.ts` raw helper 返回 contract response
- 页面 helper 继续返回 view model

### 3.3 测试补齐

要求：

- 补 contract 层相关测试或在现有 service 测试中验证 contract 抽离后行为不变
- 验证 raw helper 仍返回带 contract meta 的响应
- 验证页面 helper 继续返回原 view model

## 4. 本轮明确不做

本轮不做：

- 真实只读 API
- 页面层消费 contract/meta
- contract codegen
- 真实控制动作
- E2E

## 5. 完成标准

只有同时满足下面条件，才算本轮完成：

- `contracts/` 已新增并承载原始响应契约
- `models` 与 `contracts` 职责已分开
- `npm test` 通过
- `npm run build` 通过
- 已补验证记录与交付说明
