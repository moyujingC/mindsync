## Summary

本轮目标是为系统预置中转入口补一条最小可用链路：

- `baseUrl` 与 `API Key` 已有后
- 用户可以主动拉上游 `/models`
- 从可用模型列表中选择当前 `modelId`
- 保存后再测试连接

## Tasks

1. 补齐正式 artifact
   - 新增 spec / task / qa / delivery 四份文档
   - 更新 `specs/README.md`、`tasks/README.md`、`qa/README.md`、`delivery/README.md`

2. 先补失败测试
   - `control-plane`：
     - `GET /models/:id/catalog` 成功
     - 缺少 `API Key` 失败
     - 不支持的入口失败
     - 上游非 `2xx` 失败
     - 上游返回结构不合法失败
   - console service：
     - `getModelCatalog(id)` 的 server/mock 路径
   - `/models` 路由/UI：
     - 预置中转入口显示“获取可用模型”
     - 拉取成功后展示选择控件
     - 保存后提示下一步测试连接

3. 实现 control-plane 最小 catalog 接口
   - 新增 `GET /models/:id/catalog`
   - 只支持预置 `relay-api`
   - 用服务端存储的 `API Key` 请求 `<baseUrl>/models`
   - 返回最小结构，不持久化上游列表

4. 调整预置入口保存约束
   - 继续锁定 `kind`、`baseUrl`
   - 允许保存选中的 `modelId`
   - 不开放自由手填

5. 实现 console service 与 mock
   - 新增 `ModelCatalogResponse` 类型
   - 新增 `getModelCatalog(id)`
   - 补 `AITechFlux`、`PPChat` 的 mock 目录

6. 实现模型库编辑区交互
   - 中转预置入口显示：
     - 当前模型标识
     - 获取可用模型
     - 可用模型列表
   - 自定义入口继续保留自由手填 `modelId`

7. 完成回归验证
   - `cd projects/relayhub/control-plane && npm test`
   - `cd projects/relayhub/console && npm test`
   - `cd projects/relayhub/console && npm run build`
   - `cd projects/relayhub/dev-relay && npm test`
