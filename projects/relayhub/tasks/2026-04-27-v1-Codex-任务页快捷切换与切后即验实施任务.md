## 1. 实施目标

把 `Codex Repo Coding` 补成和 `Claude Code` 对称的任务页主路径：

- 可以在任务页顶部直接切当前绑定模型
- 可以在切换后直接做一次本地真链路验证
- 不满足 `Responses`（原生响应接口）流式能力的入口继续被明确阻断

## 2. 实施范围

### 2.1 console

- 在 `/tasks` 顶部新增 `Codex 当前模型` 快捷区
- 直接操作 `task-codex-repo` 当前绑定
- 新增 `验证 Codex 当前模型`
- 失败时给出可读错误
- 继续沿用 `Responses` 流式能力门禁

### 2.2 control-plane service

- 新增前端服务层 `verifyCodexRelay`
- 固定调用本地 `dev-relay /v1/responses`
- 从 `Responses` 输出结构中提取可读文本

### 2.3 tests

至少覆盖：

- `Codex` 快捷入口切换成功
- 选择不支持 `Responses` 流式的入口时按钮阻断
- `验证 Codex 当前模型` 命中本地 `dev-relay /v1/responses`

## 3. 非目标

本轮不做：

- 新增 control-plane 路由
- `Responses -> chat/completions` 协议转译
- release 节点 smoke
- Codex 运行记录自动入库

## 4. 回归要求

必须继续通过：

- `cd projects/relayhub/console && npm test`
- `cd projects/relayhub/console && npm run build`
