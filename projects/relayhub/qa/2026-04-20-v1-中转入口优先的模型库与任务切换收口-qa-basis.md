## 1. 验证目标

确认 RelayHub 当前主路径已经从“模型清单”收口为“入口接入与入口内模型切换”。

## 2. 自动化验证

### console

- `cd projects/relayhub/console && npm test`
- `cd projects/relayhub/console && npm run build`

至少覆盖：

- `/models` 首屏强调“可接入入口”
- 预置条目显示购买 / 充值入口
- 预置条目的 `Base URL` / `模型标识` 不允许编辑
- 自定义模型仍允许完整填写
- `/tasks` 快速切换语义是“入口内默认模型”

### control-plane

- `cd projects/relayhub/control-plane && npm test`

至少覆盖：

- 预置条目更新时不会改写锁定字段
- 自定义条目仍可更新 `baseUrl` / `modelId`

## 3. 通过标准

- 预置模型的产品语义已收口为“入口”
- 任务切换的产品语义已收口为“入口内默认模型”
- 现有主路径和运行记录页未被破坏
