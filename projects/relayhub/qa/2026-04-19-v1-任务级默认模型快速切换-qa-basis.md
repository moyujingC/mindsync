## 1. 验证目标

确认 `任务库` 已具备“同页快速切换默认模型”的最小可用能力。

## 2. 自动化验证

- `cd projects/relayhub/console && npm test`
- `cd projects/relayhub/console && npm run build`

至少覆盖：

- `/tasks` 页面强调默认模型绑定 / 切换，而不是泛化编辑
- 已绑定任务可直接切换默认模型
- 未绑定任务可直接绑定默认模型
- 成功提示明确说明仅对后续使用和后续新运行记录生效
- 没有已激活模型时，页面明确提示先回模型库激活
- 原有完整编辑任务路径不回归

## 3. Release Smoke

验证入口：

- [relayhub.jingshu.cc/tasks](https://relayhub.jingshu.cc/tasks)

至少执行：

### 已绑定任务切换

1. 找到一个已有默认模型的任务
2. 直接切到另一个已激活模型
3. 页面立即显示新的默认模型
4. 页面提示该切换对后续使用生效

### 未绑定任务绑定

1. 找到一个尚未绑定模型的任务
2. 直接绑定一个已激活模型
3. 页面立即显示绑定结果

## 4. 通过标准

- 用户不需要进入完整编辑表单，也能完成默认模型切换
- 界面不会误导为“切换已影响历史记录”
- 没有激活模型时，页面能给出明确下一步
