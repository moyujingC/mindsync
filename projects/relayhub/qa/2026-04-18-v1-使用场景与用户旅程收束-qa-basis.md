## 1. 核心验收

- 新 spec 明确写出目标用户、第一核心任务、第一主路径。
- 新 spec 明确说明当前试用版的真实能力边界：
  - 目录可见
  - 详情可读
  - 不是完整治理后台
- 新 spec 明确说明 `Dashboard`、`Environments`、`Eval` 当前属于非主路径模块。
- 新 spec 明确指出当前偏差来源是缺少使用场景与用户旅程收束层，而不是简单功能不足。
- 新 spec 输出了下一轮页面重排所需的直接输入，不留核心决策给实现者。

## 2. 一致性检查

- 与 `架构与产品定义` 不冲突
- 与 `控制台页面级线框与字段草图` 不冲突
- 与 `openai-compatible models trial` 当前真实能力边界一致

## 3. 可交接性检查

- 读完新 spec 后，下一轮实现者能够直接回答：
  - 这个试用版是给谁看的
  - 用户第一次打开要完成什么
  - 第一主路径是什么
  - 哪些页面不是主路径
  - 下一轮应优先重排哪些页面表达
