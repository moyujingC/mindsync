这份文档定义 `RelayHub` 控制台在抽出资源级只读数据源接口时的最小验证口径。

## 1. 目标行为

本轮应满足以下目标行为：

1. `consoleData.ts` 不再直接依赖 `mockApi`
2. 存在统一的资源级只读数据源接口与默认 mock 实现
3. raw helper、`ReadonlyApiResponse()` helper 与页面 helper 行为不变
4. 现有只读边界与页面行为保持不变

## 2. 验收标准

### 2.1 数据源接口层

必须满足：

- 存在 `ConsoleReadonlyDataSource`
- 存在默认 mock 数据源实例或获取函数
- 数据源层覆盖四类资源

### 2.2 行为稳定

必须满足：

- `consoleData.ts` 通过数据源读取 raw contract
- `meta.filters`、`empty`、`not-found` 语义不变
- 页面 helper 返回值不变

### 2.3 边界保持

必须满足：

- 不引入真实 API
- 不新增真实控制动作
- 生产边界与只读边界不被改写

## 3. 验证方式

本轮至少执行：

1. `npm test`
2. `npm run build`
3. 误导表达全文搜索

## 4. 通过标准

只有同时满足下面条件，才允许宣布本轮完成：

- 资源级只读数据源接口已落位
- 自动化测试通过
- 构建通过
- `RelayHub` 项目边界未被改写
