## 1. 验证目标

确认 `/runs` 已经收口成“任务绑定后顺手记一次结果”的页面，而不是要求用户每次从零配置。

## 2. 自动化验证

### console

- `cd projects/relayhub/console && npm test`
- `cd projects/relayhub/console && npm run build`

至少覆盖：

- `/runs` 打开后优先选中最近任务或首个任务
- 已绑定任务自动带出默认模型
- 切换任务后模型字段按默认模型同步
- 未绑定任务时出现明确提示
- 临时改模型后提交，不会自动改动任务默认绑定
- 提交成功后只清空结果输入字段，不丢任务上下文
- 提交成功后任务统计切到对应任务

### control-plane

- `cd projects/relayhub/control-plane && npm test`

本轮只要求现有 `POST /runs` 与 `GET /tasks/:id/stats` 回归不破坏。

## 3. Release Smoke

验证入口：

- [relayhub.jingshu.cc/runs](https://relayhub.jingshu.cc/runs)

至少执行两条路径：

### 已绑定任务

1. 打开 Runs 页
2. 看到默认模型已自动带出
3. 快速录入一条结果
4. 看到任务统计刷新

### 未绑定任务

1. 切到一个未绑定默认模型的任务
2. 看到页面提示尚未绑定
3. 手动选择一个已激活模型
4. 仍可成功保存记录

## 4. 通过标准

- 记录入口不再要求用户每次都自己重建任务上下文
- 已绑定任务的默认模型能够减少重复选择
- 临时记录与默认绑定的边界表达清楚
