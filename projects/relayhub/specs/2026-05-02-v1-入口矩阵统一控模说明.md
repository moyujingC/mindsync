# RelayHub v1 入口矩阵统一控模说明

> 状态：current
> 版本：0.1.0
> owner：Architect / Engineer
> last_updated：2026-05-02
> source_of_truth：projects/relayhub/specs/2026-05-02-v1-入口矩阵统一控模说明.md

这轮把 RelayHub 的主控制轴从“任务默认模型”切到“入口默认模型”。

当前正式入口矩阵包括：

- `entry-claude-ide-local`
- `entry-codex-ide-local`
- `entry-claude-mobile-observe`
- `entry-paperclip-claude-local-mac`
- `entry-paperclip-claude-local-server`
- `entry-paperclip-codex-local-mac`
- `entry-paperclip-codex-local-server`
- `entry-paperclip-pi-local-mac`
- `entry-paperclip-pi-local-server`
- `entry-paperclip-hermes-local-server`

当前固定口径：

- `Claude 手机 app` 只做观测，不接入 RelayHub 数据面
- `dev-relay` 优先识别 `relayhub-entry-*`
- 旧 `relayhub-task-*` 继续兼容
- `Paperclip` 的本地和服务器 adapter 入口必须分开绑定
- `hermes_local` 当前只规划服务器入口
- `entry-paperclip-codex-local-server`
  - 当前默认绑定：`preset-ppchat-relay`
  - 已通过 `Responses` 真链路探测
  - 当前可安全绑定给 Paperclip 服务器侧 `codex_local`

当前一句话目标：

- 以后你要切模型，优先在 RelayHub 改入口绑定，而不是去每个 IDE、CLI、adapter 单独改
