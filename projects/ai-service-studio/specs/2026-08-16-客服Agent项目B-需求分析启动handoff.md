## 4. 已定技术决策（spec 直接引用，勿重开）

1. **五层骨架**：采集治理 → 结构化 → 检索 → 生成护栏 → 运营闭环，每层要有验收物
2. **本体论**：第一版不用本体，用 taxonomy + 元数据 schema + 受控词表；疗愈概念图谱留二期，与项目 C 联动评估
3. **复用粒度**：组件级全复用（解析/向量库/嵌入）；主线框架级组装（LangGraph/LlamaIndex 级）；平台（Dify/RAGFlow）仅作 2-3 天对照实验 + FDE 技能储备
4. **护栏四件套不可省**：引用溯源、拒答、转人工、疗愈伦理红线（不诊断/不承诺疗效/危机识别转介）
5. **评测集第一版就要有**：20-30 题含故意越界问题，badcase 归因表
6. **对话状态机是网**：LLM 判断意图决定跳转，状态机决定每个状态下的行为规则，护栏无条件生效；预约/报价/课程介绍等状态互为可跳转
7. **第一版不做**：rerank、多库路由、权限感知检索（单租户自用无 ACL 需求）、Agent 长期记忆
