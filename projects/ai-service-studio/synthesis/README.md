这里存放 `知行AI服务` 的阶段性纵向复盘文档。

它不是单篇参考材料目录，也不是最终业务系统。

## 目录定位

```text
references/
  单篇原文 + 单篇业务转译

synthesis/
  多篇材料放在一起纵向对比，提炼模式、冲突、候选规则

system/
  当前业务要执行的产品、售前、报价、交付、合同规则
```

## 使用节奏

每篇新材料先进入 `references/`。

每累计 5-8 篇，或某个主题已经有足够材料，再进入 `synthesis/`。

当 synthesis 结论被确认后，再集中更新 `system/`。

## 推荐主题

- 第一单路径
- 售前认知 gap
- 报价边界
- 交付坑点
- 产品形态
- 客户分层
- 能力与合作边界
