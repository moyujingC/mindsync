## 1. 行业定位

心理与疗愈行业是 `墨予镜企业AI服务` 当前最适合直接深耕的行业。

这里的客户不是泛泛的“心理行业”，而是已经有服务或产品、需要持续获客和交付整理的专业服务者：

- 心理咨询师。
- 疗愈师。
- 教练。
- 身心灵 / 成长类课程主理人。
- 有咨询、体验课、工作坊、课程或私域服务的小团队。

当前先区分两类客户，不混成一个产品：

| 客户类型 | 主要问题 | 适合切口 |
| --- | --- | --- |
| 成熟从业者 | 有咨询、课程或服务，但被初访、内容、资料、跟进和运营琐事消耗 | 初访流程诊断、内容到咨询链路、脱敏资料整理 |
| 转行 / 启航者 | 知识体系不稳、缺少练习、内容和专业呈现不足、怕接不住第一个客户 | 学习路径、概念卡、内容启动、初访导航清单 |

## 2. 为什么优先这个行业

当前具备三个基础：

- 自身长期方向与心理、疗愈、AI 心理学和课程产品有关。
- 已有 `一镜一梳`、`疗愈课程体系` 和 `墨予镜` 相关内容 / 产品语境。
- 行业内很多从业者同时面临内容、资料、私域、个案记录和课程资料整理压力。

这意味着可以先从真实业务流程入手，而不是先包装行业大方案。

## 3. 典型客户问题

优先观察这些问题：

- 内容生产不稳定，不知道如何把专业经验转成选题。
- 线上内容和线下咨询、体验课、工作坊之间缺少清晰承接。
- 私信沟通、客户初筛和样本沟通没有固定记录方式。
- 个案记录、学员反馈、课程资料和文章素材分散。
- 想用 AI，但担心伤害咨询 / 疗愈工作的专业性、伦理和信任。
- 不知道哪些环节可以交给 AI，哪些必须由人判断。

## 4. 可调用能力包

当前优先调用：

- [AI 营销获客](../../capabilities/ai-marketing-acquisition/README.md)：适合从内容、私信、样本沟通和服务入口切入。
- [AI 工作流诊断 SOP](../../sops/AI工作流诊断-SOP.md)：适合梳理从业者的一条真实工作流。
- [AI 文档知识库整理 SOP](../../sops/AI文档知识库整理-SOP.md)：适合整理脱敏笔记、课程资料、文章素材和反馈。

后续可观察：

- 课程资料整理。
- 学员 FAQ 和课后反馈整理。
- 体验课报名和私信承接流程。
- 行业内容素材库。
- 初访助理 demo 和摘要模板。
- 转行者学习 / 内容 / 初访清单启航包。

## 5. 合规和伦理边界

当前必须守住：

- 不让 AI 替代心理咨询、诊断、治疗或疗愈判断。
- 不处理未脱敏的敏感个案资料。
- 不承诺咨询效果、疗愈效果、获客结果或收入增长。
- 不把客户隐私、来访者材料、学员反馈包装成案例。
- 不建议从业者用 AI 直接回复高风险心理危机内容。
- 不碰医疗诊断、用药建议和危机干预。
- 不把 AI 包装成“AI 心理咨询师”“AI 疗愈师”。
- 不用 AI 生成虚假资质、个案经历、客户反馈或专业背书。
- 不把来访者资料、量表、初访记录用于训练、营销分析或交叉销售。
- 不承诺接案成功、咨询转化、疗愈效果或专业速成。
- 不使用未经授权或版权不清的教材、课程和专业材料搭建知识库。

推荐表达：

```text
AI 只适合处理资料整理、内容辅助、流程记录和低风险重复工作。
真正涉及来访者判断、咨询关系和伦理责任的部分，必须由专业人士负责。
```

## 6. 当前可验证切口

第一阶段只验证五个小切口：

1. 内容到咨询的小闭环
   - 看 3-5 篇内容和 3-5 条互动，梳理选题、服务入口和私信承接。

2. 一条真实工作流诊断
   - 例如从一篇文章发布到私信沟通，再到一次样本沟通。

3. 一批脱敏资料整理
   - 例如课程资料、公开文章、脱敏反馈或 FAQ，不接未脱敏个案。

4. 初访助理流程诊断
   - 只看预约前问答、初访字段、摘要模板、FAQ 和人工跟进流程。
   - 可以做模拟 demo，不直接接入真实来访者。

5. 转行者启航清单
   - 只做学习路径、概念卡、内容选题、专业简介草稿和初访导航清单。
   - 不承诺获得资质、接到客户或具备咨询能力。

## 6.1 初访助理候选边界

初访助理只能定位为预约前信息收集和流程引导工具。

可以做：

- 说明咨询师服务流程、费用范围、预约方式和保密原则。
- 收集来访者自述的基本关切、时间偏好和咨询目标。
- 生成严格基于用户输入的结构化摘要。
- 把摘要推送给咨询师，由咨询师人工判断是否跟进。

不能做：

- 心理诊断。
- 治疗建议。
- 风险等级判断。
- 危机干预结论。
- 自动向来访者发送专业建议。

上线前必须先完成模拟测试、危机词触发测试、隐私说明和咨询师人工兜底流程。

## 8. 下一步

近期只做最小验证：

- 找 3 位心理咨询师 / 疗愈师 / 教练做样本沟通。
- 每次只看一个具体流程或一批脱敏资料。
- 记录客户真实问题、是否愿意付费、愿意付费的对象和价格区间。
- 根据反馈决定 `AI 营销获客`、`工作流诊断`、`资料整理` 哪个切口更容易成交。
