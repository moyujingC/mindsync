## 1. 文档目的

这份文档定义心理与疗愈行业当前适合优先开发的自动化工作流。

这里说的“自动化”，不是让 AI 代替咨询、疗愈、诊断或专业判断，而是让 AI 先处理这些低风险重复工作：

- 内容整理。
- 资料归档。
- 线索记录。
- 反馈分类。
- 选题提炼。
- FAQ 草稿整理。

## 2. 自动化边界

当前只做：

- 公开内容和公开评论的整理。
- 私信线索和样本沟通记录的结构化。
- 已脱敏资料的分类、提炼和归档。
- 课程、工作坊、体验课相关的运营辅助。

当前不做：

- 未脱敏个案记录处理。
- AI 自动回复高风险心理危机内容。
- AI 自动生成咨询判断、疗愈判断或诊断建议。
- 医疗、危机干预、用药相关自动化。
- 对外承诺“自动获客”或“自动成交”。

## 3. 优先级判断

优先选择满足这四个条件的流程：

1. 高频：每周都会发生。
2. 低风险：错了不会直接伤害来访者或学员。
3. 有固定输入：例如评论、私信、报名表、反馈表、课程资料。
4. 有明确输出：例如记录表、选题池、FAQ 草稿、归档目录。

## 4. 当前建议先做的 4 条工作流

### 4.1 内容反馈 -> 选题池 -> 私信承接工作流

适合对象：

- 心理咨询师。
- 疗愈师。
- 教练。
- 课程主理人。

目标：

- 把内容评论、私信和互动信号变成下一轮选题和样本沟通线索。

输入：

- 小红书 / 公众号 / 视频号内容链接。
- 评论区文本。
- 私信截图或整理文本。
- 当前服务入口，例如体验课、工作流诊断、资料整理。

自动化步骤：

1. 收集最近 7 天内容链接和互动。
2. 提取高频问题、顾虑、咨询意向和反对点。
3. 自动分类为：
   - 纯互动
   - 内容问题
   - 服务线索
   - 风险内容
4. 生成：
   - 下周选题建议
   - 私信回复草稿
   - 样本沟通优先名单
5. 人工审核后，写回内容表和线索表。

人工审核点：

- 是否涉及敏感心理危机表达。
- 是否把普通互动误判成高意向客户。
- 私信草稿是否过度承诺。

输出：

- 选题池。
- 私信承接话术草稿。
- 样本沟通名单。
- 高频问题清单。

可用价值：

- 解决“写了内容但没有沉淀服务线索”的问题。

### 4.2 报名 / 私信 -> 样本沟通初筛工作流

适合对象：

- 体验课主理人。
- 工作坊组织者。
- 提供一对一咨询前置沟通的人。

目标：

- 把零散报名和私信，整理成可判断、可跟进的初筛记录。

输入：

- 报名表。
- 私信文本。
- 朋友圈 / 微信 / 邮件咨询文本。

自动化步骤：

1. 汇总所有入口的咨询信息。
2. 提取字段：
   - 身份类型
   - 想解决的问题
   - 当前阶段
   - 是否有可脱敏材料
   - 是否适合体验 / 诊断 / 课程
3. 自动标记优先级：
   - 可直接沟通
   - 需要补充信息
   - 暂不适合
   - 高风险需人工单独处理
4. 生成跟进建议：
   - 发送体验邀约
   - 发送补充问题
   - 转人工深聊
   - 礼貌拒绝

人工审核点：

- 高情绪、高危机、高依赖表达必须人工处理。
- 不允许 AI 自动决定是否适合接受心理咨询或疗愈服务。
- 不允许 AI 自动承诺疗效。

输出：

- 初筛台账。
- 跟进动作建议。
- 补充提问模板。

可用价值：

- 解决“线索很多但靠记忆管理”的问题。

### 4.3 课程 / 工作坊资料 -> 知识库整理工作流

适合对象：

- 课程主理人。
- 工作坊带领者。
- 长期积累内容和讲义的从业者。

目标：

- 把散乱的课程资料、讲义、练习、反馈和宣传文案整理成可复用资产。

输入：

- 课程大纲。
- 讲义。
- 练习题。
- 学员常见问题。
- 公开宣传文案。
- 已脱敏反馈。

自动化步骤：

1. 批量盘点资料类型。
2. 自动按用途分类：
   - 对外介绍
   - 授课材料
   - 练习材料
   - FAQ
   - 学员反馈
   - 归档资料
3. 生成统一命名建议。
4. 提取重复出现的问题和主题。
5. 产出：
   - 目录结构建议
   - FAQ 草稿
   - 后续内容选题来源

人工审核点：

- 是否混入未授权公开的学员材料。
- FAQ 是否误改原意。
- 课程方法是否被 AI 过度简化。

输出：

- 目录结构。
- 命名规则。
- FAQ 初稿。
- 内容素材清单。

可用价值：

- 解决“资料越积越多，但每次开课还得重新找”的问题。

### 4.4 体验课 / 工作坊反馈 -> 复盘摘要工作流

适合对象：

- 经常办体验课、工作坊、小组活动的人。

目标：

- 把分散反馈快速转成下一轮改版输入。

输入：

- 问卷反馈。
- 群聊反馈。
- 课后私信。
- 复盘笔记。

自动化步骤：

1. 收集本次活动全部反馈。
2. 自动拆分为：
   - 最喜欢的部分
   - 卡住的部分
   - 想继续的方向
   - 对价格 / 时长 / 形式的反馈
3. 生成：
   - 活动复盘摘要
   - 下一轮改动建议
   - 可公开引用的脱敏反馈候选
4. 人工筛掉敏感内容后，更新课程版本记录。

人工审核点：

- 是否包含身份线索。
- 是否把个体情绪表述误读成普遍结论。
- 是否错误提炼为营销文案。

输出：

- 复盘摘要。
- 版本迭代建议。
- 可复用用户语言清单。

可用价值：

- 解决“反馈收到了，但没有进入下一轮产品迭代”的问题。

## 5. 推荐实施顺序

如果现在只先做 1-2 条，建议顺序如下：

1. 内容反馈 -> 选题池 -> 私信承接
   - 最容易先看到外部结果。
2. 报名 / 私信 -> 样本沟通初筛
   - 最容易减少手工整理。
3. 课程 / 工作坊资料 -> 知识库整理
   - 最容易形成长期资产。
4. 体验课 / 工作坊反馈 -> 复盘摘要
   - 适合有稳定活动的人。

## 6. 最小实现方式

第一阶段不追求复杂系统，优先用轻量组合：

- 表单或飞书多维表格：收集报名、反馈、私信字段。
- 文档目录 + 命名规则：承接课程和内容资料。
- LLM（大语言模型，大型文本生成与分析模型）：做分类、提炼、草稿生成。
- 自动化连接器：把表单、文档和消息汇总到同一个记录表。

一句话原则：

```text
先把输入收齐、字段定清、人工审核点留住，再考虑更深自动化。
```

## 7. 一个可直接开做的试点

如果现在就要做第一个试点，推荐：

### 心理疗愈内容获客小闭环

范围：

- 最近 10 篇内容。
- 最近 30 条评论 / 私信。
- 一个服务入口，例如体验课或 AI 工作流诊断。

交付：

- 高频问题清单。
- 选题池。
- 私信初筛表。
- 3 条跟进话术草稿。

验收标准：

- 不再手工翻聊天记录找线索。
- 能区分内容互动和服务线索。
- 能从反馈里稳定提取下一轮选题。

## 8. 后续可继续展开的方向

- 疗愈师内容素材库自动整理。
- 课程报名 -> 分班 -> 提醒 -> 课后反馈链路。
- 公开文章 -> 短内容拆分 -> 发布待办链路。
- FAQ -> 体验课说明 -> 报名前置说明链路。

前提仍然不变：

- 不碰未脱敏敏感材料。
- 不把专业判断自动化。
- 不把效果承诺自动化。

## 9. 四条工作流的最小实现版

这一部分不讨论复杂系统，只回答四个问题：

1. 输入从哪里来。
2. 中间用什么表来接。
3. AI 实际做哪 1-2 个动作。
4. 最后人工审核后输出什么。

### 9.1 内容反馈 -> 选题池 -> 私信承接

#### 真实一天里的样子

从业者上午发一篇内容，晚上回来时已经有：

- 10-30 条评论。
- 5-15 条私信。
- 若干收藏、转发和表情反馈。

她最常见的状态不是“没反馈”，而是“反馈有了，但没有被整理成下一步”。

#### 最小实现版

输入来源：

- 最近 7 天发布内容的链接。
- 评论区复制文本。
- 私信手工整理文本或截图转文字。

承接表：

- 一张 `内容反馈总表`。

建议字段：

- 日期
- 平台
- 内容标题
- 用户原话
- 来源类型（评论 / 私信）
- 人工备注

AI 动作：

1. 自动分类每条反馈：
   - 共鸣互动
   - 具体问题
   - 服务线索
   - 风险表达
2. 自动提炼本周高频主题和 3-5 个候选选题。

人工审核：

- 删掉误判的风险内容。
- 确认哪些私信可以继续跟进。
- 改写 AI 给出的私信回复草稿，避免越界或过度承诺。

最终输出：

- 一份本周高频问题清单。
- 一个下周选题池。
- 3-5 条可用的私信承接草稿。
- 一份样本沟通候选名单。

#### 最小闭环验收

达到下面三点，就算跑通：

- 不再需要翻聊天记录回忆“大家最近在问什么”。
- 能从评论和私信里稳定提炼选题。
- 能把少数高意向线索单独拉出来。

### 9.2 报名 / 私信 -> 样本沟通初筛

#### 真实一天里的样子

一个体验课或工作坊刚发出去后，信息会从多个入口进来：

- 报名表。
- 微信私信。
- 公众号留言。
- 熟人转介绍。

从业者最容易卡住的不是“没人来”，而是“来了以后怎么快速分清谁该先聊、谁要补资料、谁不适合当前服务”。

#### 最小实现版

输入来源：

- 报名表提交结果。
- 私信手工复制文本。
- 转介绍备注。

承接表：

- 一张 `线索初筛表`。

建议字段：

- 日期
- 姓名或代号
- 来源渠道
- 身份类型
- 想解决的问题
- 当前阶段
- 是否有可脱敏材料
- 跟进状态

AI 动作：

1. 从原始文本里提取字段，自动填表。
2. 给出一个辅助标签：
   - 建议继续沟通
   - 建议补充信息
   - 暂不适合当前服务
   - 高风险需人工处理

人工审核：

- 确认高风险表达。
- 决定是否进入样本沟通。
- 决定回复方式，是继续邀约、补问题，还是礼貌收口。

最终输出：

- 一张可排序的初筛台账。
- 一组补充提问模板。
- 一组不同状态下的跟进话术。

#### 最小闭环验收

达到下面三点，就算跑通：

- 每个线索都有记录，不靠脑子记。
- 能快速区分“可聊”和“先别聊”。
- 高风险内容不会被混进普通跟进流程。

### 9.3 课程 / 工作坊资料 -> 知识库整理

#### 真实一天里的样子

从业者准备下一次课程时，会打开很多旧资料：

- 过往讲义。
- 海报文案。
- 课堂练习。
- 学员常见问题。
- 课后反馈。

她的问题通常不是“没有内容”，而是“找不到、用不上、每次都重新翻”。

#### 最小实现版

输入来源：

- 一个课程相关文件夹。
- 10-30 份代表性样本资料。
- 过往反馈和常见问题。

承接表：

- 一张 `资料盘点表`。

建议字段：

- 文件名
- 资料类型
- 用途
- 是否长期保留
- 是否可复用
- 是否敏感

AI 动作：

1. 初步判断资料类型和用途。
2. 提炼重复出现的问题，生成 FAQ 草稿和目录建议。

人工审核：

- 确认哪些资料能留下。
- 确认哪些反馈不能公开或不能二次使用。
- 调整目录结构，避免过度分类。

最终输出：

- 一份最小目录结构。
- 一套命名规则。
- 一版 FAQ 草稿。
- 一份可复用素材清单。

#### 最小闭环验收

达到下面三点，就算跑通：

- 下次开课前，不再需要到处翻资料。
- 能快速找到讲义、练习、文案和 FAQ。
- 知道哪些内容是长期资产，哪些只是临时材料。

### 9.4 体验课 / 工作坊反馈 -> 复盘摘要

#### 真实一天里的样子

一场体验课结束后，反馈会散在很多地方：

- 问卷。
- 群聊。
- 私信。
- 口头感受转成的复盘笔记。

如果不整理，下一次往往只能靠模糊印象改课。

#### 最小实现版

输入来源：

- 问卷结果。
- 群聊文本。
- 课后私信。
- 主讲人的复盘笔记。

承接表：

- 一张 `活动反馈表`。

建议字段：

- 日期
- 活动名称
- 反馈原话
- 来源
- 标签
- 是否可公开引用

AI 动作：

1. 自动按主题归类反馈：
   - 最喜欢的部分
   - 卡住的部分
   - 想继续的方向
   - 对价格 / 时长 / 形式的反馈
2. 生成一版复盘摘要和 3 条优化建议。

人工审核：

- 删掉带身份线索的反馈。
- 防止把个体意见误当共性。
- 决定哪些话可以脱敏后作为公开素材。

最终输出：

- 一份活动复盘摘要。
- 一份下一轮改动清单。
- 一组可复用用户语言。

#### 最小闭环验收

达到下面三点，就算跑通：

- 每次活动后都能得到结构化复盘。
- 下一次改版有明确动作，不靠印象。
- 用户原话能沉淀为课程优化和文案素材。

## 10. 先做哪一条最合适

如果现在只允许做 1 条，我建议先做：

### 内容反馈 -> 选题池 -> 私信承接

原因很直接：

- 最贴近当前外部获客验证。
- 输入最容易拿到，不需要复杂权限。
- 风险相对最低，主要处理公开内容和低风险私信。
- 最容易产出两个直接结果：下一轮内容选题、样本沟通线索。

如果第一条跑顺，再接第二条：

### 报名 / 私信 -> 样本沟通初筛

这样两条接起来，就形成一个最小外部闭环：

```text
内容发布
  -> 评论 / 私信反馈
  -> 线索分类
  -> 样本沟通初筛
  -> 人工跟进
```
