## 1. 合同文件类型

当前可以先准备三类轻量文件：

1. 服务确认单
   - 适合小诊断、小额资料整理。
   - 重点写清服务范围、费用、交付物和时间。

2. 项目服务协议
   - 适合工作坊、小实验、工作流搭建。
   - 需要写清客户输入、验收、知识产权、保密和付款。

3. 月度支持协议
   - 适合后续陪跑或企业试点。
   - 需要写清服务次数、响应时间、边界和终止方式。

## 2. 基本信息

合同或确认单应包含：

- 甲方名称
- 乙方名称
- 联系人
- 联系方式
- 服务名称
- 服务周期
- 服务地点或线上方式
- 签署日期

## 3. 服务范围

必须写清“包含什么”。

示例：

```text
乙方为甲方提供一次 AI 工作流诊断服务。
服务对象限定为甲方提供的【销售跟进流程】。
乙方将基于甲方提供的脱敏资料和一次访谈，输出简版流程诊断结论。
```

可包含：

- 访谈
- 资料阅读
- 会议纪要
- 流程拆解
- 简版诊断报告
- 小实验建议
- 交付前演示视频
- 一次交付说明
- 一次复盘会议

建议按轻量 `SOW / SOP / SLA` 写清：

| 项目 | 合同中要写清 |
| --- | --- |
| SOW：工作范围 | 服务对象、资料范围、交付物、包含事项、不包含事项 |
| SOP：交付流程 | 甲方输入、乙方动作、节点时间、反馈方式、验收流程 |
| SLA：响应约定 | 响应渠道、响应时间、答疑次数、维护期、紧急事项边界 |

候选条款：

```text
本项目服务范围以本协议约定的 SOW 为准。
如甲方提出新增场景、新增资料、新增系统、新增部门或新增交付物，双方应另行确认范围、周期和费用。
```

## 4. 不包含事项

必须写清“不包含什么”。

候选条款：

- 不包含软件系统开发。
- 不包含私有化部署。
- 不包含客户内部系统账号配置。
- 不包含客户业务数据清洗。
- 不包含法律、财务、税务、医疗、投资等专业意见。
- 不包含客户内部员工管理和推动。
- 不承诺收入增长、成本下降、获客结果或组织转型结果。
- 不承诺客户新增客资数量、签单数量、成交率提升或利润增长。
- 不承诺 AI 落地路径图、SOP、工具建议或自动化建议必然产生经营结果。
- 不承诺 AI 输出完全准确。
- 不包含服务范围外的长期答疑。
- 不包含 demo、POC 或试点范围外的生产级上线、监控、运维和稳定性保障。
- 不承诺无人值守 Agent 长期稳定运行。
- 不承诺爆款内容、平台流量、GMV、ROI 或全自动发布效果。

## 5. 客户输入

必须写清客户需要提供什么。

客户可能需要提供：

- 脱敏流程材料
- 现有 SOP
- 表格、文档、话术、FAQ 或案例
- 访谈对象
- 当前工具或系统截图
- 业务背景说明
- 验收人和反馈人

候选条款：

```text
甲方应保证其提供材料的真实性、完整性和合法性。
如甲方未按约定提供资料或访谈配合，乙方交付时间相应顺延。
```

如项目涉及知识库、内部助手或资料治理，应额外写清资料责任：

- 哪些资料可以进入项目范围。
- 哪些资料只能归档或作为背景，不作为正式回答依据。
- 谁确认资料版本、适用范围和有效期。
- 谁负责补充、纠错、下架或更新资料。
- 谁确认资料权限和可见范围。

### 5.1 知识库 PoC 的统一范围字段

如项目包含知识库 PoC（概念验证），SOW（工作范围说明）、交付清单和验收条款必须使用同一组字段：

- 场景：约定岗位、问题类型和不覆盖范围。
- 资料：代表资料范围、数量、格式、可入库资格和资料责任人。
- 测试：测试问题、来源引用要求、拒答 / 转人工规则和反馈方式。
- 使用：使用人数、使用入口、验收人与反馈责任人。
- 维护：PoC 期间的资料更新、错误修正、答疑次数和截止日期。
- 费用：模型、平台、解析、存储及第三方服务费用的承担方。
- 排除项：全量迁移、复杂权限、源系统同步、生产运维和结果保证。

候选条款：

```text
本 PoC 仅在约定场景、代表资料和测试环境内验证可行性。
甲方指定的资料责任人负责确认资料的版本、适用范围和可作为回答依据的资格；
乙方不将未确认或超出范围的资料作为正式回答依据。
```

## 6. 数据安全和保密

当前默认不接触敏感原始数据。

候选条款：

- 甲方应优先提供脱敏资料。
- 甲方不得向乙方提供超出本项目必要范围的敏感个人信息、商业秘密或受监管数据。
- 乙方仅为本项目目的使用甲方资料。
- 未经甲方书面同意，乙方不得公开披露甲方非公开资料。
- 如需使用第三方 AI 工具处理资料，应提前说明使用范围和风险。

需要特别注意：

- 医疗、金融、政务、芯片、制造核心工艺等高敏数据，当前只做流程梳理，不处理真实敏感数据。

## 6.1 录音和会议纪要

如服务过程需要录音、转写或使用 AI 工具生成会议纪要，应提前取得甲方同意。

候选条款：

- 乙方仅在甲方同意后进行会议录音、转写或 AI 纪要整理。
- 录音、转写和会议纪要仅用于需求确认、服务交付、报价依据和项目记录。
- 如甲方不同意录音，乙方可改用手工笔记，不影响服务继续推进。
- 经双方确认的会议纪要，可作为后续报价、服务范围确认和验收沟通的辅助依据。
- 未经甲方书面同意，乙方不得将包含甲方非公开信息的录音、转写或会议纪要对外披露。

## 6.2 客户私有数据和行业复用

AI 服务中需要区分客户私有资产和乙方通用能力。

候选条款：

- 甲方原始资料、业务数据、客户信息、内部流程细节和非公开方法属于甲方资料。
- 乙方不得擅自将甲方非公开资料用于其他客户项目。
- 乙方可复用通用方法、通用模板、通用流程、工具经验和不包含甲方非公开信息的抽象经验。
- 如乙方需要将本项目经验沉淀为案例、模板或行业方法，应先进行脱敏，不得包含甲方身份、人员、客户、价格、内部数据和独有业务方法。
- 如甲方要求乙方在一定期限内不服务同行业客户，应在协议中单独约定范围、期限、地域、同行定义和额外费用。

边界说明：

```text
可复用的是通用方法，不是甲方私有数据。
如果甲方要求限制乙方服务同行，需要另行协商排他范围和费用。
```

## 7. 交付物

必须写清交付物名称和格式。

候选交付物：

- AI 工作流诊断简报
- 当前流程拆解图
- AI 落地路径图
- SOP 九要素卡
- 工具与成本估算
- 试点定义书
- 高频 / 结构化 / 可评判评分
- AI 可介入节点清单
- 人工审核点清单
- 7 天小实验建议
- 资料分类和命名规则
- 知识库结构建议
- 工作坊材料
- 会议纪要
- 交付前演示视频

知识库 / 资料治理类项目可增加：

- 资料准入清单
- 可入库 / 暂不入库 / 归档材料清单
- 版本冲突问题清单
- 文档画像字段建议
- 可信度和使用价值分层
- 评测 badcase 归因记录

格式可以是：

- Markdown
- PDF
- 飞书文档
- 表格
- 会议讲解
- 录屏视频

## 8. 验收

小单验收应以交付物完成为准，不以客户业务结果为准。

候选条款：

```text
乙方按约定提交交付物并完成一次交付说明后，视为完成本阶段服务。
甲方如对交付物有修改意见，应在 3 个工作日内一次性提出。
```

可约定：

- 修改次数
- 反馈期限
- 逾期视为确认
- 超范围修改另行报价

如项目包含 demo、POC、知识库样板或自动化试点，验收应限定在约定样本、约定流程和约定测试环境内。

候选条款：

```text
样板、demo 或 POC 仅用于验证约定场景的可行性，不代表可直接进入甲方全量生产环境。
如需扩展到更多部门、更多资料、更高并发或正式生产环境，双方应另行确认治理、权限、安全、维护和费用。
```

demo、POC、试点和生产级的验收口径应分开：

- demo：验收是否完成约定演示和说明，不验收稳定运行。
- POC：验收是否在约定样本、测试环境和人工审核下跑通。
- 试点：验收是否有真实使用记录、反馈记录和异常处理记录。
- 生产级：只有在权限、数据、日志、监控、回滚、维护和责任机制另行约定后，才讨论生产级验收。

知识库 PoC 还应验收：约定测试问题是否能返回来源入口或明确拒答；是否完成至少一轮 badcase 分类和修正；资料责任人能否完成一次更新或错误反馈。该验收不代表回答完全准确，也不替代生产环境的权限、审计和运维要求。

## 9. 付款

候选付款方式：

### 小诊断

```text
签署确认单后一次性支付 100% 服务费。
```

### 工作坊 / 小实验

```text
签署后支付 50% 定金，交付前支付剩余 50%。
```

### 月度支持

```text
按月预付。
当月未使用的服务次数不自动顺延，除非双方另有书面约定。
```

## 10. 取消和改期

候选条款：

- 甲方如需改期，应至少提前 3 个工作日通知。
- 甲方临时取消，已支付定金不退，但可在双方协商后改期一次。
- 因甲方资料未准备导致延期，交付时间顺延。
- 因不可抗力导致延期，双方协商处理。

## 11. 知识产权

需要区分：

- 甲方原始资料归甲方所有。
- 乙方通用方法、模板、SOP 和工具经验归乙方所有。
- 为甲方定制的交付物，甲方可在内部使用。
- 未经乙方同意，甲方不得转售、公开发布或改作培训产品。

候选条款：

```text
乙方在服务中使用的通用方法、模板、流程和工具经验不因本项目转让给甲方。
甲方可在其内部业务中使用本项目交付物，但不得对外转售、公开传播或用于第三方商业培训。
```

## 12. 案例使用

默认不公开客户身份。

如需沉淀案例，应采用脱敏方式，并取得客户同意。

候选条款：

- 经甲方书面同意，乙方可使用脱敏后的项目背景、流程类型、交付物类型和方法总结作为案例。
- 未经甲方同意，不公开甲方名称、人员、内部数据和具体业务资料。
- 未经甲方同意，不公开授课照片、现场视频、聊天截图、会议截图、客户 logo、客户名称或可识别项目结果。
- 如甲方同意公开展示，应单独确认可展示范围、展示渠道、展示期限和是否需要甲方审核。

案例授权应区分：

| 类型 | 默认规则 |
| --- | --- |
| 内部复盘 | 可保留脱敏记录，用于改进服务 |
| 售前脱敏案例 | 需去除客户身份、人员、价格、数据和独有业务细节 |
| 公开宣传案例 | 需取得书面授权 |
| 照片 / 视频 / logo / 客户名 | 需单独授权 |

## 13. 第三方工具

AI 服务可能涉及第三方工具。

候选条款：

- 第三方工具账号、费用、服务稳定性和数据政策由对应平台负责。
- 乙方可提供工具建议，但不保证第三方工具持续可用。
- 如第三方工具规则变化导致方案不可用，双方另行协商调整。

## 13.1 自动化 / Agent / 自动发布专项条款

项目涉及 Agent、自动化流程、自动发布、自动发送、自动写入系统或客户账号操作时，应补充专项条款。

授权和账号：

- 甲方应确认自动化可操作的账号、系统、数据范围和权限边界。
- 乙方不得使用超出项目必要范围的账号、cookie、API Key 或密钥。
- 如需使用测试账号、测试数据或沙箱环境，应优先使用测试环境。

日志和回溯：

- 自动化试点应保留必要的执行记录，例如日志、截图、表格记录、通知记录或人工确认记录。
- 自动化结果应能被甲方指定人员复核。

人工审核和兜底：

- 高风险动作、对外发布、客户承诺、财务、合同、合规、质量判断等环节应保留人工审核。
- 甲方应指定兜底人，负责暂停、回滚、重试或改回人工处理。

边界和责任：

- 乙方不承诺自动化零失败、第三方平台永久可用或无人值守长期稳定运行。
- 因甲方账号权限变化、第三方平台规则变化、验证码、风控、网络环境、数据质量或甲方内部流程变化导致的异常，双方应按约定范围协商处理。

候选条款：

```text
本项目如涉及自动化或 Agent 执行，仅限于双方约定的测试环境、账号权限、样本数据和操作范围。
未经双方另行书面确认，乙方不承担生产环境无人值守运行、自动发布结果、第三方平台稳定性或经营结果责任。
```

## 14. 合作方和分包

如果项目涉及合作方，应在合同或服务确认单中提前写清。

候选条款：

- 乙方可根据项目需要引入合作方参与部分服务，但应提前告知甲方合作方参与范围。
- 合作方仅在本项目必要范围内接触甲方资料。
- 如合作方需要接触甲方非公开资料，应遵守与乙方相同的保密义务。
- 乙方负责协调合作方按约定范围完成其负责部分。
- 未经甲方同意，合作方不得将甲方资料用于本项目以外用途。

需要拆分说明：

- 乙方自己负责的部分。
- 合作方负责的部分。
- 甲方需要配合的部分。
- 各部分的交付物和验收方式。

如果合作方尚未确定，不应在合同中承诺具体开发、部署或系统上线结果。

## 14.1 资源方合作和利益分配

资源方参与时，不能只写“介绍客户”，要拆清获客、售前、策略、执行、回款和售后责任。

候选条款：

- 客户来源、客户归属和后续复购归属。
- 资源方是否参与售前沟通、方案制定、交付执行或售后响应。
- 费用由客户支付给谁，谁负责开票和收款。
- 返佣、分成或服务费的计算口径、支付时间和退款处理。
- 客户延期付款、拒付或退款时，双方如何承担风险。
- 二次需求、转介绍客户和同集团客户是否纳入合作范围。
- 双方是否存在独家合作、行业限制或地域限制。

候选条款：

```text
双方确认，本次合作仅限于本协议约定客户和项目范围。
```

## 14.2 知识库和资料治理专项条款

涉及企业知识库、内部 AI 助手、资料入库和知识治理时，应补充专项条款。

资料准入：

- 甲方应先确认哪些资料可用于本项目。
- 旧版、草稿、会议纪要、临时讨论材料、个人经验稿等材料是否可作为回答依据，应由甲方确认。
- 未经确认的资料，乙方可建议归档、暂缓入库或仅作为背景材料。

版本和责任：

- 每类资料应指定甲方责任人。
- 资料版本、适用范围、生效时间和废止状态由甲方确认。
- 乙方可协助发现版本冲突，但不替代甲方作最终业务口径判断。

权限和安全：

- 甲方负责确认资料权限、可见范围和授权边界。
- 涉及个人信息、商业秘密或受监管数据时，应优先提供脱敏或测试资料。

维护和错误回溯：

- AI 回答错误时，应区分资料缺失、版本冲突、分片问题、召回问题、权限问题和用户提问不清。
- 交付后由谁更新资料、修正标签、调整权限、反馈 badcase，应在协议中写清。
- 如甲方要求乙方持续维护知识库，应单独约定维护期、响应时间、资料量、新增需求和费用。

候选条款：

```text
乙方不保证未经甲方确认、未清洗、未授权或存在版本冲突的资料可产生稳定准确的 AI 问答效果。
甲方应指定资料责任人负责确认资料准入、版本、适用范围和后续更新。
```

## 14.3 心理 / 疗愈行业专项条款

项目涉及心理咨询师、疗愈师、教练、来访者资料、初访记录、量表、个案记录、课程学员反馈或疗愈相关服务时，应补充专项边界。

服务定位：

- AI 工具仅用于信息收集、资料整理、内容草稿、流程提醒、预约辅助和低风险行政工作。
- AI 不提供心理咨询、心理治疗、医疗诊断、用药建议、风险等级判断或危机干预结论。
- 涉及专业判断、伦理责任、来访者关系和危机处理的事项，应由甲方或其指定专业人员负责。

数据和隐私：

- 来访者资料、初访记录、量表、个案记录、咨询笔记和学员反馈默认视为高敏资料。
- 甲方应优先提供脱敏、模拟或测试资料。
- 未经来访者和甲方明确授权，乙方不得将相关资料用于模型训练、营销分析、案例宣传、交叉销售或其它项目。

人工审核和危机处理：

- AI 生成的摘要、提醒、内容草稿或跟进建议，必须由甲方人工审核后使用。
- 如项目包含危机关键词提醒，提醒仅用于提示甲方关注，不构成风险评估或处置建议。
- 高危表达、危机干预、转介和紧急联系流程，应由甲方按其专业规范和所在地法律法规处理。

专业呈现和版权：

- 乙方不协助甲方生成虚假资质、虚假个案、虚假客户反馈、虚假专业背书或误导性宣传。
- 用于知识库、学习材料或内容生成的资料，应确认来源、授权和版权边界。
- 乙方可协助整理学习路径、概念卡和模板，但不承诺甲方获得资质、接案成功或具备专业咨询能力。

候选条款：

```text
双方确认，本项目所涉 AI 工具仅作为信息整理、流程辅助和低风险行政支持工具，
不构成心理咨询、心理治疗、医疗诊断、风险评估或危机干预服务。
甲方应对其向来访者、学员或客户提供的专业服务、专业判断和最终表达承担责任。
```

## 15. 责任限制

候选条款：

- 乙方交付的是诊断、建议、结构和方法，不替代甲方内部经营决策。
- 乙方提供的 AI 落地路径图、SOP、工具建议和自动化方案均为实施建议，不构成对经营结果的保证。
- 甲方基于交付物采取的业务行动，由甲方自行判断和承担责任。
- 乙方不对间接损失、预期收益、客户流失或第三方工具故障承担责任。
